Частые вопросы

Denon AVR-X2800H + AVR Maestro

Есть ли приложение для управления Denon AVR-X2800H?
Да - AVR Maestro это премиальный сторонний пульт для X2800H. По сети он управляет режимами объёмного звука, Audyssey MultEQ XT, пресетами колонок, уровнями, мультизоной, тюнером и сценами в одно касание.
Поддерживает ли X2800H Dirac Live в приложении?
Denon AVR-X2800H использует Audyssey MultEQ XT и не поддерживает Dirac Live - это аппаратное ограничение модели, а не приложения. AVR Maestro управляет Audyssey MultEQ, Dynamic EQ, Dynamic Volume и LFC на X2800H в реальном времени с телефона. Смотрите руководство по Audyssey & Dirac.
Нужна ли облачная учётная запись?
Нет, оно общается с X2800H напрямую по локальной сети. Без облачной учётной записи, без подписки и без дополнительного оборудования.
Как подключиться?
Включите сетевое управление на X2800H, узнайте его IP-адрес и добавьте ресивер в приложении. Подробные шаги - в руководстве по началу работы.

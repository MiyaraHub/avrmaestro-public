Частые вопросы

Marantz AV10 + AVR Maestro

Есть ли приложение для управления Marantz AV10?
Да - AVR Maestro это премиальный сторонний пульт для AV10. По сети он управляет режимами объёмного звука, Audyssey MultEQ XT32 и Dirac Live, пресетами колонок, уровнями, мультизоной, тюнером и Сценами в одно касание.
Управляет ли AVR Maestro Dirac Live на AV10?
Да. На Marantz AV10 с лицензией Dirac Live AVR Maestro показывает слоты фильтров Dirac по названиям и переключает активный. При стандартном пресете Audyssey вместо этого он управляет MultEQ, Dynamic EQ, Dynamic Volume и LFC. См. руководство по Audyssey & Dirac.
Нужна ли облачная учётная запись?
Нет - он общается с AV10 напрямую по вашей локальной сети. Без облачной учётной записи, без подписки, без дополнительного оборудования, а конфигурация вашего ресивера никогда не покидает вашу сеть.
Как подключиться?
Включите сетевое управление на AV10, узнайте его IP и добавьте его в приложении. Все шаги - в руководстве по началу работы.

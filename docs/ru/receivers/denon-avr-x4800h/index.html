Частые вопросы

Denon AVR-X4800H + AVR Maestro

Есть ли приложение для управления Denon AVR-X4800H?
Да - AVR Maestro это премиальный сторонний пульт для AVR-X4800H. По сети он управляет режимами объёмного звука, Audyssey MultEQ XT32 и Dirac Live, пресетами колонок, уровнями, мультизоной, тюнером и сценами в одно касание.
Управляет ли AVR Maestro Dirac Live на AVR-X4800H?
Да. На Denon AVR-X4800H с лицензией Dirac Live приложение AVR Maestro показывает ваши слоты фильтров Dirac по названиям и переключает активный. При стандартном пресете Audyssey оно вместо этого управляет MultEQ, Dynamic EQ, Dynamic Volume и LFC. Смотрите руководство по Audyssey & Dirac.
Нужна ли облачная учётная запись?
Нет - приложение общается с AVR-X4800H напрямую по локальной сети. Без облачной учётной записи, без подписки, без дополнительного оборудования, а конфигурация вашего ресивера никогда не покидает вашу сеть.
Как подключиться?
Включите сетевое управление на AVR-X4800H, узнайте его IP-адрес и добавьте ресивер в приложении. Подробные шаги - в руководстве по началу работы.

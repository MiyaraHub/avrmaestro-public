Частые вопросы

Marantz SR6015 + AVR Maestro

Есть ли приложение для управления Marantz SR6015?
Да - AVR Maestro это премиальный сторонний пульт для SR6015. По сети он управляет режимами объёмного звука, Audyssey MultEQ XT32 и Dirac Live, пресетами колонок, уровнями, мультизоной, тюнером и Сценами в одно касание.
Управляет ли AVR Maestro Dirac Live на SR6015?
Да. На Marantz SR6015 с лицензией Dirac Live AVR Maestro показывает слоты фильтров Dirac по названиям и переключает активный. При стандартном пресете Audyssey вместо этого он управляет MultEQ, Dynamic EQ, Dynamic Volume и LFC. См. руководство по Audyssey & Dirac.
Нужна ли облачная учётная запись?
Нет - он общается с SR6015 напрямую по вашей локальной сети. Без облачной учётной записи, без подписки, без дополнительного оборудования, а конфигурация вашего ресивера никогда не покидает вашу сеть.
Как подключиться?
Включите сетевое управление на SR6015, узнайте его IP и добавьте его в приложении. Все шаги - в руководстве по началу работы.

Альтернатива приложению Audyssey для ежедневного управления

Ищете альтернативу приложению Audyssey? AVR Maestro переключает настройки Audyssey вашего ресивера Denon или Marantz прямо с телефона: кривую MultEQ (Референс, Обход L+R, Flat или Выкл), Dynamic EQ, Reference Level Offset, Dynamic Volume и LFC. Калибровку приложение не выполняет: этим по-прежнему занимаются микрофон и приложение Audyssey, а для собственных целевых кривых нужно платное приложение MultEQ Editor.

Честно о возможностях

Что AVR Maestro умеет, а что нет

AVR Maestro не инструмент калибровки. Он кладёт ежедневное управление вам в карман, а измерения оставляет инструментам, созданным для них.

Частые вопросы

Audyssey с телефона: ответы на вопросы

Есть ли альтернатива приложению Audyssey для повседневного использования?
Да. AVR Maestro считывает и переключает MultEQ (Референс / Обход L+R / Flat / Выкл), Dynamic EQ, Reference Level Offset, Dynamic Volume и LFC на ресиверах Denon и Marantz с Audyssey прямо из приложения.
Может ли AVR Maestro откалибровать мою комнату?
Нет. AVR Maestro не выполняет калибровку. Это делают микрофон и программа Audyssey или Dirac Live, а приложение управляет результатом каждый день.
Можно ли редактировать целевые кривые Audyssey в AVR Maestro?
Нет. Для собственных целевых кривых Audyssey нужно платное приложение MultEQ Editor. Зато в AVR Maestro есть 9-полосный графический эквалайзер, который может стартовать с вашей измеренной кривой Audyssey; он доступен, когда MultEQ и Dirac выключены.
А с Dirac Live оно тоже работает?
Да. Если на ресивере есть лицензия Dirac Live, приложение показывает ваши слоты фильтров по названиям и переключает активный одним касанием.

Альтернатива приложению Audyssey для повседневного управления

Ищете альтернативу приложению Audyssey? AVR Maestro переключает настройки Audyssey вашего ресивера Denon или Marantz с телефона: кривую MultEQ (Reference, Bypass L+R, Flat или Off), Dynamic EQ, Reference Level Offset, Dynamic Volume и LFC. Калибровку он не выполняет: её по-прежнему делают микрофон и приложение Audyssey, а для собственных целевых кривых нужно платное приложение MultEQ Editor.

Графический эквалайзер

Честные границы

Что AVR Maestro делает, а что нет

AVR Maestro не является инструментом калибровки. Он кладёт ежедневное управление вам в карман, а измерения оставляет инструментам, созданным для этого.

Переключать кривую MultEQ, Dynamic EQ, Dynamic Volume, LFCДа
Переключать слоты фильтров Dirac Live по названиямДа, при наличии лицензии Dirac Live
Выполнять калибровку с микрофономНет, это делает приложение Audyssey
Настраиваемые целевые кривыеНет, для этого нужно платное приложение MultEQ Editor

На Denon и Marantz Audyssey и Dirac Live привязаны к пресету колонок, и одновременно активен только один из них. См. управление Audyssey и Dirac Live и сравнение Audyssey и Dirac Live. AVR Maestro - независимое приложение, не связанное с Audyssey.

Частые вопросы

Audyssey с телефона: ответы

Есть ли альтернатива приложению Audyssey для ежедневного использования?
Да. AVR Maestro считывает и переключает MultEQ (Reference / Bypass L+R / Flat / Off), Dynamic EQ, Reference Level Offset, Dynamic Volume и LFC на ресиверах Denon и Marantz с Audyssey прямо из приложения.
Может ли AVR Maestro откалибровать мою комнату?
Нет. AVR Maestro не выполняет калибровку. Её делают микрофон и программное обеспечение Audyssey или Dirac Live, а приложение управляет результатом изо дня в день.
Можно ли редактировать целевые кривые Audyssey в AVR Maestro?
Нет. Для собственных целевых кривых Audyssey нужно платное приложение MultEQ Editor. Зато в AVR Maestro есть 9-полосный графический эквалайзер, который может начинать с вашей измеренной кривой Audyssey и доступен, когда MultEQ и Dirac выключены.
Работает ли он и с Dirac Live?
Да. Если на ресивере есть лицензия Dirac Live, приложение показывает слоты фильтров по названиям и переключает активный одним касанием.

Управляйте ресивером с клавиатуры

В версиях из Mac App Store и Microsoft Store используйте Cmd на macOS или Ctrl на Windows. Мультимедийные клавиши вашей клавиатуры тоже работают, и ничего не срабатывает, пока вы вводите текст в поле. Подробнее в руководстве по пульту.

Частые вопросы

Windows и Mac: ответы на вопросы

Есть ли приложение Denon или Marantz для Windows?
Да. AVR Maestro есть в Microsoft Store: оно управляет сетевыми AV-ресиверами Denon и Marantz с ПК на Windows, подключённого к той же сети, что и ресивер.
Есть ли приложение Denon или Marantz для Mac?
Да. AVR Maestro есть в Mac App Store, с сочетаниями клавиш на Cmd и поддержкой мультимедийных клавиш.
Есть ли в настольном приложении сочетания клавиш?
Да. Используйте Cmd на macOS или Ctrl на Windows: Space для воспроизведения/паузы, . (точка) для остановки, Влево/Вправо для предыдущего/следующего трека, Вверх/Вниз для громкости и M для отключения звука. Мультимедийные клавиши тоже работают, а сочетания приостанавливаются, пока вы вводите текст в поле.
Работает ли помощник на Windows?
Нет. Помощнику нужна модель на устройстве: Apple Intelligence на iPhone, iPad или Mac (macOS 26) либо Gemini Nano на Android. Всё остальное из этого списка работает на Windows. Смотрите руководство по помощнику.

Aide & dépannage

Résoudre les problèmes courants de l'application Denon & Marantz

Des solutions rapides aux questions les plus courantes. Si vous êtes toujours bloqué, le journal de débogage intégré à l'app (Paramètres → Aide → Enregistrer & partager) est le moyen le plus rapide d'obtenir de l'aide - contactez le développeur sur Discord ou dans le groupe d'entraide Facebook, les réponses sont rapides.

Connexion

Établir la connexion

« Tester la connexion » échoue
Vérifiez que le téléphone et le récepteur sont sur le même réseau Wi-Fi et le même sous-réseau - les systèmes mesh, les réseaux invités et les VLAN IoT peuvent isoler les appareils. Sur le récepteur, Setup → Network → Network Control doit être sur On. Revérifiez l'IP dans l'écran Network → Information du récepteur lui-même, car les adresses DHCP changent. HTTP est indispensable ; Telnet et HEOS sont un plus. Si le récepteur est joignable mais que sa pile réseau est saturée - trop d'apps de contrôle qui gardent des connexions ouvertes - l'app l'indique par un message clair de réseau occupé au lieu d'un échec générique ; fermez un autre contrôleur ou patientez quelques secondes. Toutes les étapes dans le guide de prise en main.
La connexion tombe toutes les quelques secondes
Les ports Telnet du récepteur peuvent se bloquer après de longues durées de fonctionnement - coupez l'alimentation du récepteur au secteur pour libérer l'écoute. Sur un mesh Wi-Fi 6, forcez le téléphone sur la même bande que le récepteur (les AVR sont généralement sur 2.4 GHz ; les téléphones préfèrent 5 GHz).
Comment savoir si mon récepteur est pris en charge ?
Tout dépend de votre réseau, pas seulement du modèle. Si le portail web du récepteur, l'app HEOS et l'app officielle Denon/Marantz peuvent tous l'atteindre, AVR Maestro le pourra aussi. Voir la page des récepteurs pris en charge.
Commandes & affichage

Pourquoi quelque chose semble anormal

L'affichage du volume semble incorrect
Les récepteurs indiquent le volume en absolu (0-98) ou en relatif (-80 à +18 dB). L'app gère les deux ; si vous avez récemment modifié le réglage d'affichage du volume du récepteur, redémarrez l'app pour qu'elle relise l'échelle. Vous pouvez choisir la valeur affichée en premier dans Paramètres → Audio.
Des modes sonores ou des pastilles de fonctionnalités sont grisés / « N/A »
Les modes surround et les fonctionnalités dépendent du format audio de l'entrée et du mode sonore actif - une source 2 canaux n'activera pas Dolby Atmos. C'est le comportement du récepteur, pas de l'app. Touchez le (?) à côté d'une pastille N/A pour connaître la condition exacte.
Certains onglets Son ou Enceintes sont absents
Les onglets dépendent du modèle et du mode. Audyssey, Dirac Live, IMAX, Auro-3D, Surround Shape, Distances et Crossovers n'apparaissent que sur les récepteurs qui les exposent. Consultez Paramètres → Appareils → Informations sur l'appareil pour voir ce que l'app a détecté, ou rajoutez un onglet masqué depuis Paramètres → Personnaliser les onglets / Personnaliser la navigation.
L'onglet Radio ne s'affiche pas
La radio dépend des fonctionnalités : elle n'apparaît que sur les récepteurs dotés d'un tuner FM/AM intégré. Si le vôtre en a un mais que l'onglet est masqué, vérifiez que le tuner apparaît comme une entrée du récepteur et réactivez-le depuis Paramètres → Personnaliser la navigation. Voir le guide de la radio.
La carte Lecture en cours est vide
L'entrée actuelle n'expose pas de métadonnées - les sources analogiques, optiques/coaxiales et la plupart des sources HDMI en passthrough ne transmettent pas les informations de piste. Pour les sources HEOS, touchez Lancer HEOS pour démarrer la lecture, puis revenez : les métadonnées s'afficheront.
Le widget de l'écran d'accueil affiche « AVR off » ou « Standby »
C'est l'état éteint du widget, pas une panne. Quand le récepteur est éteint, en veille ou injoignable, les widgets (iOS et Android) affichent « AVR off » / « Standby » au lieu de la dernière entrée et du dernier volume, pour que vous ne lisiez jamais de données périmées. Sur le widget Quick Control, les boutons de volume et de sourdine se masquent dans cet état, mais le bouton d'alimentation reste actif - touchez-le pour réveiller le récepteur directement depuis le widget (Network Standby doit être activé sur le récepteur).
Certains écrans d'enceintes s'ouvrent dans le contrôle web du récepteur
Sur certains récepteurs d'avant 2025 (catégorie X4500H / X6700H / S960H / X4700H), le récepteur ne peut pas fournir à l'app les écrans Disposition des enceintes ou Sortie caisson ; AVR Maestro vous propose donc un bouton qui ouvre en un toucher le contrôle web du récepteur pour ces modifications. Tout le reste fonctionne normalement ; avec un micrologiciel plus récent, chaque écran est fourni dans l'app.

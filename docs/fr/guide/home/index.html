Écran d'accueil

L'écran d'accueil : votre base, à votre façon

Une carte d'état de l'appareil reste épinglée en haut - modèle, connexion, alimentation - avec en dessous une grille de widgets personnalisable. Ajoutez, supprimez et réorganisez les cartes pour que l'écran d'accueil affiche exactement ce qui vous importe.

Faites-en votre propre univers

Personnalisez en quelques secondes

Touchez l'icône Personnaliser l'accueil (en haut à gauche) pour passer en mode édition :

  • Faites glisser une carte pour la réorganiser.
  • Touchez le cercle rouge pour supprimer une carte.
  • Ajouter ouvre une feuille avec les widgets que vous n'avez pas encore.
  • Réinitialiser rétablit les réglages par défaut ; Terminé quitte le mode édition.
Les cartes sont atténuées pendant la modification pour que vous ne changiez pas un réglage du récepteur par accident. Les widgets ne s'affichent que si votre récepteur prend en charge la fonction.
Nommez vos pièces

« Salon », pas « MAIN ZONE »

Appuyez longuement sur le nom de la zone sur l'écran d'accueil pour renommer n'importe quelle zone - y compris la zone principale. Le nom est écrit sur le récepteur lui-même, pas seulement dans l'application, il apparaît donc dans l'application du fabricant et dans tous les autres clients, et cela fonctionne aussi sur les anciens châssis. Renommez une fois, et tous les contrôleurs de la maison s'accordent sur le nom de la pièce.

Commandes du son

Interrupteurs rapides dans Son

  • Égaliseur graphique : activez ou désactivez l'égaliseur graphique du récepteur depuis Son, Fonctionnalités audio. Disponible uniquement quand ni Dirac Live ni Audyssey n'assure la correction acoustique - l'application applique la règle du récepteur lui-même.
  • Caisson de basses : coupez ou activez le caisson de basses depuis Son, Fonctionnalités audio, sans passer par la configuration des enceintes. Affiché uniquement sur les récepteurs qui le signalent et l'acceptent.
  • Restaurateur audio : le restaurateur d'audio compressé du récepteur - Restorer sur Denon, M-DAX sur Marantz - sous forme d'interrupteur dans Son, Tonalité, juste à côté du filtre DAC. Redonnez vie aux MP3 et aux sources de streaming sans passer par le menu à l'écran.
Lecture en cours & HEOS

Voyez et contrôlez ce qui est en cours de lecture

Quand la source active expose des métadonnées, la carte Lecture en cours affiche la pochette, les infos de morceau / artiste / station et les commandes de lecture (lecture / pause / suivant / précédent).

Pour parcourir la musique - stations, files d'attente, services de streaming, pièces HEOS - touchez Lancer HEOS sur la carte Lecture en cours. AVR Maestro ouvre l'application HEOS officielle pour la navigation ; une fois la lecture lancée, AVR Maestro reprend la main sur l'affichage de lecture en cours, les commandes de lecture et les widgets. Les sources analogiques, optiques/coaxiales et en transmission HDMI ne signalent pas de métadonnées : la carte reste donc vide pour celles-ci.

Questions fréquentes

FAQ sur l'écran d'accueil

Puis-je personnaliser l'écran d'accueil ?
Oui - touchez Personnaliser l'accueil, puis faites glisser pour réorganiser, touchez le cercle rouge pour supprimer, Ajouter pour plus de widgets, Réinitialiser pour revenir aux réglages par défaut, Terminé pour finir. Les cartes s'atténuent pendant la modification pour que vous ne changiez pas un réglage par accident.
Puis-je renommer mes zones, y compris la zone principale ?
Oui - appuyez longuement sur le nom de la zone sur l'écran d'accueil. Le nom est écrit sur le récepteur lui-même, il apparaît donc dans l'application du fabricant et dans tous les autres clients, et cela fonctionne aussi sur les anciens châssis.
Affiche-t-il ce qui est en cours de lecture ?
Oui, pour les sources qui exposent des métadonnées - pochette, titre/artiste/station et commandes de lecture. Touchez Lancer HEOS pour parcourir ; AVR Maestro reprend la main sur l'affichage de lecture en cours dès que la lecture démarre.

Écran d'accueil

L'écran d'accueil : votre base, à votre façon

Une carte d'état de l'appareil reste épinglée en haut - modèle, connexion, alimentation - avec en dessous une grille de widgets personnalisable. Ajoutez, supprimez et réorganisez les cartes pour que l'écran d'accueil affiche exactement ce qui vous importe.

Faites-en votre propre univers

Personnalisez en quelques secondes

Touchez l'icône Personnaliser l'accueil (en haut à gauche) pour passer en mode édition :

  • Faites glisser une carte pour la réorganiser.
  • Touchez le cercle rouge pour supprimer une carte.
  • Ajouter ouvre une feuille avec les widgets que vous n'avez pas encore.
  • Réinitialiser rétablit les réglages par défaut ; Terminé quitte le mode édition.
Les cartes sont atténuées pendant la modification afin de ne pas changer un réglage du récepteur par accident. Les widgets ne s'affichent que si votre récepteur propose la fonction. Un écran d'accueil neuf commence avec Smart Select / Quick Select, Volume, Source, Mode sonore, Scènes, Informations sur le signal, Lecture en cours et Zones. Plus de détails sur chaque carte dans le guide des widgets.
Plusieurs récepteurs

Changez de récepteur depuis le titre

Lorsqu'un récepteur est connecté, son nom apparaît à côté d'AVR Maestro en haut de l'écran d'accueil. Touchez-le pour voir tous les récepteurs ajoutés, en choisir un pour le rendre actif, ou choisissez Gérer les récepteurs pour les ajouter et les réorganiser (Réglages › Gérer les récepteurs). Le champ de recherche sous la carte d'état trouve n'importe quel réglage de l'application ; voir le guide de la recherche, le guide des récepteurs et comment se repérer dans l'application.

Préréglages de volume

Huit niveaux de volume, à une touche

  • Touchez un emplacement vide pour y enregistrer le volume actuel.
  • Touchez un emplacement rempli pour passer à ce volume.
  • Appuyez longuement sur un emplacement pour y enregistrer le volume actuel à la place de l'ancien, ou pour le vider.

Plus de détails dans le guide du volume.

Nommez vos pièces

« Salon », pas « MAIN ZONE »

Appuyez longuement sur le nom de la zone sur l'écran d'accueil pour renommer n'importe quelle zone - y compris la zone principale. Le nom est écrit sur le récepteur lui-même, pas seulement dans l'application, il apparaît donc dans l'application du fabricant et dans tous les autres clients, et cela fonctionne aussi sur les anciens châssis. Renommez une fois, et tous les contrôleurs de la maison s'accordent sur le nom de la pièce.

Commandes du son

Interrupteurs rapides dans Son

  • Égaliseur graphique : l'interrupteur se trouve sur la page Égaliseur graphique elle-même (Son › Égaliseur graphique), dans la ligne d'en-tête à côté de Réinitialiser et Copier. Les bandes ne sont modifiables que si ni Dirac Live ni Audyssey n'applique de correction acoustique ; l'application suit la règle propre du récepteur. Voir le guide de l'égaliseur graphique.
  • Caisson de basses : coupez ou activez le caisson depuis Son › Surround › Fonctionnalités audio, sans plonger dans la configuration des enceintes. Affiché uniquement sur les récepteurs qui le signalent et l'acceptent.
  • Restaurateur audio : le restaurateur d'audio compressé du récepteur - Restorer sur Denon, M-DAX sur Marantz - sous Son › Tonalité. Redonnez de la vie aux MP3 et aux sources de streaming sans passer par le menu à l'écran.
Lecture en cours & HEOS

Voyez et contrôlez ce qui est en cours de lecture

Quand la source active expose des métadonnées, la carte Lecture en cours affiche la pochette, les infos de morceau / artiste / station et les commandes de lecture (lecture / pause / suivant / précédent).

Pour parcourir la musique - stations, files d'attente, services de streaming, pièces HEOS - touchez Lancer HEOS sur la carte Lecture en cours. AVR Maestro ouvre l'application HEOS officielle pour la navigation ; dès que la lecture démarre là-bas, AVR Maestro reprend l'affichage de lecture en cours, les commandes et les widgets. Les sources analogiques, optiques/coaxiales et le passthrough HDMI ne signalent pas de métadonnées, la carte reste donc vide pour elles. Le bouton Favoris et tout le reste de la carte sont décrits dans le guide Lecture en cours et HEOS.

Questions fréquentes

FAQ sur l'écran d'accueil

Puis-je personnaliser l'écran d'accueil ?
Oui - touchez Personnaliser l'accueil, puis faites glisser pour réorganiser, touchez le cercle rouge pour supprimer, Ajouter pour plus de widgets, Réinitialiser pour revenir aux réglages par défaut, Terminé pour finir. Les cartes s'atténuent pendant la modification pour que vous ne changiez pas un réglage par accident.
Puis-je renommer mes zones, y compris la zone principale ?
Oui - appuyez longuement sur le nom de la zone sur l'écran d'accueil. Le nom est écrit sur le récepteur lui-même, il apparaît donc dans l'application du fabricant et dans tous les autres clients, et cela fonctionne aussi sur les anciens châssis.
Puis-je passer d'un récepteur à l'autre depuis l'écran d'accueil ?
Oui. Touchez le nom du récepteur à côté d'AVR Maestro en haut et choisissez un autre récepteur, ou choisissez Gérer les récepteurs pour en ajouter ou les réorganiser.
Affiche-t-il ce qui est en cours de lecture ?
Oui, pour les sources qui exposent des métadonnées - pochette, titre/artiste/station et commandes de lecture. Touchez Lancer HEOS pour parcourir ; AVR Maestro reprend la main sur l'affichage de lecture en cours dès que la lecture démarre.

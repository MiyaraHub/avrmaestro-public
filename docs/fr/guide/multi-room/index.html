Multi-Room

Multi-Room : groupes, principaux, file d'attente et musique

Sur les récepteurs qui prennent en charge le multi-room, l'application AVR Maestro liste toutes les enceintes, vous permet de les grouper et de les dissocier, règle un volume unique pour un groupe et parcourt, recherche et met en file d'attente la musique pour celui-ci. Ce guide passe en revue chaque partie de l'écran.

L'écran

Un seul écran pour toutes les enceintes

  • Ouvrez-le depuis la carte Multi-Room de l'accueil (touchez Ouvrir) ou depuis la navigation. Le titre est Multi-Room.
  • Les cartes de groupe sont en haut. Chacune affiche le nom du groupe, ce qui est en lecture, précédent / lecture / suivant, un bouton de sourdine, un curseur de volume pour tout le groupe et le résumé de la file d'attente.
  • Pas dans un groupe liste toutes les enceintes qui sont seules, chacune avec un bouton Options de l'appareil.
  • Pendant que l'application recherche des enceintes, vous voyez Recherche des enceintes. Si la connexion est coupée, elle affiche Connexion Multi-Room perdue. Reconnexion. et montre les derniers groupes connus jusqu'à son rétablissement.
Volume

Volume du groupe et volume des enceintes

  • Le grand curseur est le volume du groupe. Déplacez-le et tous les membres bougent ensemble.
  • Touchez Volume des enceintes pour ouvrir un curseur par membre, chacun avec sa propre sourdine. Utilisez-le pour équilibrer une pièce calme face à une pièce bruyante.
  • Une enceinte mise en sourdine affiche Réactiver le son et indique 0%.
Lecture

Lecture en cours, avec la pochette

  • La carte affiche en direct la pochette, le titre et l'artiste de ce que le groupe diffuse. Quand rien n'est lu, elle indique Aucune lecture.
  • Précédent, lecture ou pause et suivant commandent tout le groupe.
Groupes

Créer, modifier et dissocier un groupe

  • Créer un groupe : touchez-le, cochez au moins deux enceintes (la feuille affiche Choisissez au moins deux enceintes tant que ce n'est pas fait), puis Enregistrer. Dès que deux enceintes sont cochées, chaque ligne affiche une pastille Principal : touchez celle que vous voulez comme principal. Si vous n'en choisissez aucune, la première cochée devient le principal.
  • Principal : l'enceinte depuis laquelle le groupe est lu, indiquée par la pastille Principal. Le récepteur affiche Ce récepteur quand le principal est celui auquel vous êtes connecté.
  • Modifier le groupe : changez les membres ou le principal avec la même feuille. Une enceinte déjà dans un autre groupe affiche Dans un autre groupe.
  • Dissocier : supprime aussitôt le groupe et tous les membres repassent à Pas dans un groupe. L'application confirme avec Groupe supprimé.
  • Renommer le groupe : touchez le crayon sur la carte. Le nom ne change que dans cette application.
  • Les enceintes en cours de lecture peuvent s'arrêter pendant la modification d'un groupe, et la feuille vous avertit au préalable.
Glisser-déposer

Maintenez appuyé pour rejoindre, déplacer ou retirer

  • Maintenez appuyée une pastille d'enceinte, puis déposez-la sur un groupe pour le rejoindre, ou sur une pièce pour l'y déplacer.
  • Déposez-la sur Déposer ici pour retirer du groupe pour sortir cette seule enceinte.
  • Si l'enceinte est en lecture, l'application demande confirmation avant de passer à ce que lit le groupe : Rejoindre quand même.
Musique

Services musicaux, navigation et favoris

  • Touchez Musique sur une carte de groupe pour ouvrir la liste des services configurés sur le récepteur, comme les services de streaming, la radio, Playlists, Historique et Entrée AUX.
  • Touchez un service pour le parcourir. Retour remonte d'un niveau.
  • Sur les éléments, vous pouvez choisir Lire maintenant, Lire ensuite, Ajouter à la fin de la file d'attente ou Remplacer la file d'attente et lire.
  • Les très longues listes affichent Affichage des N premiers éléments.
  • Le bouton en forme de cœur Ajouter la lecture en cours aux favoris enregistre ce qui est en lecture ; le même bouton le retire. Si le service ne conserve pas la modification, l'application le signale.
  • Un service qui exige une connexion affiche Ce service exige une connexion. Connectez-vous une fois dans l'application propre au récepteur. Il en va de même pour Aucun service musical n'est configuré.
Recherche

Rechercher dans un service musical

  • Les services qui permettent la recherche affichent un champ de recherche et une pastille par type de recherche, par exemple Artiste, Album, Titre ou Playlist. Les pastilles proviennent du service lui-même, elles diffèrent donc d'un service à l'autre.
  • Choisissez une pastille, saisissez votre texte et lancez la recherche. Effacer vide le champ.
  • Sans correspondance, l'application indique Aucun résultat.
  • Si le service n'est pas connecté sur le récepteur, la recherche est refusée avec Cet appareil n'a pas accepté la demande. Réessayez.
File d'attente

La file d'attente

  • La carte du groupe résume la file d'attente (3 dans la file d'attente) et les titres suivants. Touchez File d'attente pour l'ouvrir.
  • La feuille porte le nom du principal, liste les titres dans l'ordre et comporte un bouton Effacer qui la vide. La répétition (désactivée, tout, un titre) et Aléatoire s'y trouvent aussi ; si le service ne conserve pas un mode de lecture, l'application le signale.
  • Une file d'attente vide affiche Rien dans la file d'attente. Si l'enceinte ne répond pas, Impossible de lire la file d'attente.
Pièces

Organiser : pièces et noms des appareils

  • Touchez Organiser. Ajouter une pièce crée une pièce, et chaque enceinte peut y être déplacée avec Options de l'appareil → Déplacer vers une pièce.
  • Une fois les enceintes dans des pièces, Grouper cette pièce les groupe toutes d'un coup.
  • Renommer l'appareil ne change le nom que dans cette application. Utiliser le nom d'origine le rétablit.
  • Sur un récepteur à plusieurs zones, toutes les zones partagent la seule enceinte de ce récepteur, le groupement s'applique donc à l'ensemble du récepteur.
Accueil

Carte d'accueil et widget d'écran d'accueil

  • La carte Multi-Room de l'accueil liste les enceintes et les groupes sous forme de pastilles, avec un bouton Gérer qui ouvre cet écran.
  • Épingler au widget d'accueil sur une enceinte ou un groupe le place sur le widget Multi-Room, qui affiche ce qui est lu avec les commandes de lecture et de volume. L'application confirme avec <nom> est sur le widget Multi-Room.
Dépannage

Quand quelque chose ne fonctionne pas

  • Impossible de joindre Multi-Room sur ce récepteur : vérifiez que le récepteur est allumé et sur le même réseau.
  • Aucune enceinte trouvée : le récepteur n'en liste aucune. Utilisez Connexion par adresse IP et saisissez l'adresse IPv4 de votre enceinte indiquée par votre routeur ; Oublier cette enceinte la supprime de nouveau.
  • Ne peut pas être groupé : la carte indique la raison, par exemple que le récepteur n'est pas listé ou ne prend pas en charge le multi-room.
  • Une modification de groupe échoue : l'application indique ce qui s'est produit : la liste des groupes a changé, les enceintes n'ont pas répondu à temps, la modification n'a pas été envoyée car une autre est encore en cours, une enceinte est occupée, ou la modification n'a pas été confirmée. Vérifiez les groupes et réessayez.
Questions fréquentes

FAQ Multi-Room

Qu'est-ce que Multi-Room dans AVR Maestro ?
C'est l'écran et la carte d'accueil qui listent toutes les enceintes visibles par le récepteur, les groupes dont elles font partie et la musique diffusée dans chacun, avec un curseur de volume par groupe.
Que fait l'enceinte principale du groupe ?
L'enceinte principale est celle depuis laquelle le groupe est lu. Les autres membres la suivent. Sa file d'attente et sa lecture en cours sont celles du groupe.
Comment dissocier des enceintes ?
Ouvrez Multi-Room, repérez la carte du groupe et touchez Dissocier. Tous les membres repassent à Pas dans un groupe. Pour retirer une seule enceinte, maintenez-la appuyée et déposez-la sur Déposer ici pour retirer du groupe.
Pourquoi la recherche indique-t-elle que l'appareil ne l'a pas acceptée ?
Le service musical n'est pas connecté sur le récepteur. Connectez-vous une fois dans l'application propre au récepteur, puis relancez la recherche depuis AVR Maestro.
Quels récepteurs sont compatibles ?
Les récepteurs qui prennent en charge le multi-room et apparaissent dans la liste Multi-Room. Un récepteur qui n'apparaît pas figure sous Ne peut pas être groupé, avec la raison.

Questions fréquentes

Denon AVR-A1H + AVR Maestro

Existe-t-il une application pour piloter le Denon AVR-A1H ?
Oui - AVR Maestro est une télécommande tierce haut de gamme pour l'A1H. Via votre réseau, elle contrôle les modes surround, Audyssey et Dirac Live, les préréglages d'enceintes, les niveaux des canaux, le multizone, le tuner et les Scènes en une touche.
Gère-t-elle tous les canaux et toutes les zones ?
Oui. Elle lit l'ensemble des capacités de l'A1H à la connexion et propose les niveaux par canal, la disposition, les préréglages et un contrôle multizone indépendant.
Ai-je besoin d'un compte cloud ?
Non - elle dialogue directement avec l'A1H sur votre réseau local. Pas de compte cloud, pas d'abonnement, pas de matériel supplémentaire, et la configuration de votre récepteur ne quitte jamais votre réseau.
Comment le connecter ?
Activez le contrôle réseau sur l'A1H, relevez son IP et ajoutez-le dans l'application. Les étapes complètes se trouvent dans le guide de démarrage.

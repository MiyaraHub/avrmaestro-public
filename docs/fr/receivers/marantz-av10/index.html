Questions fréquentes

Marantz AV10 + AVR Maestro

Existe-t-il une application pour contrôler le Marantz AV10 ?
Oui - AVR Maestro est un contrôleur tiers haut de gamme pour l'AV10. Via votre réseau, il pilote les modes surround, Audyssey MultEQ XT32 et Dirac Live, les préréglages d'enceintes, les niveaux, le multizone, le tuner et les Scènes en un geste.
AVR Maestro contrôle-t-il Dirac Live sur l'AV10 ?
Oui. Sur un Marantz AV10 avec une licence Dirac Live, AVR Maestro liste vos emplacements de filtres Dirac par nom et bascule celui qui est actif. Avec un préréglage Audyssey standard, il contrôle à la place MultEQ, Dynamic EQ, Dynamic Volume et LFC. Consultez le guide Audyssey & Dirac.
Ai-je besoin d'un compte cloud ?
Non - il dialogue directement avec l'AV10 sur votre réseau local. Pas de compte cloud, pas d'abonnement, pas de matériel supplémentaire, et la configuration de votre récepteur ne quitte jamais votre réseau.
Comment le connecter ?
Activez le Contrôle réseau sur l'AV10, relevez son IP et ajoutez-le dans l'application. Les étapes complètes figurent dans le guide de prise en main.

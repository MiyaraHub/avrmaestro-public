Une application Denon & Marantz pour Windows et Mac

Oui, vous pouvez piloter un récepteur Denon ou Marantz depuis votre ordinateur. AVR Maestro fonctionne sur Windows via le Microsoft Store et sur Mac via le Mac App Store, et dialogue avec le récepteur sur votre réseau local : modes surround, Audyssey et Dirac Live, préréglages d'enceintes, multizone et Scènes en une pression, avec des raccourcis clavier sur les deux. Achat unique, sans publicité, sans abonnement.

Ce que vous pilotez depuis Windows ou Mac

Le récepteur sur votre bureau, sans chercher la télécommande ni ouvrir les menus à l'écran du récepteur.

⌨

Raccourcis clavier

Lecture, pause, arrêt, saut de piste, volume et sourdine au clavier : Cmd sur macOS, Ctrl sur Windows.

🎵

Touches multimédias

Les touches dédiées de votre clavier (lecture, pause, suivant, précédent, arrêt, volume et sourdine) pilotent le récepteur.

🎭

Scènes en une pression

Enregistrez l'entrée, le volume, le mode sonore, Audyssey ou Dirac, le préréglage d'enceintes, les zones et le tuner, et rappelez le tout d'un seul clic.

🎲

Audyssey & Dirac Live

Basculez entre les courbes MultEQ, Dynamic EQ et Dynamic Volume, ou choisissez les emplacements de filtres Dirac Live par leur nom, sur les récepteurs qui les proposent.

🔊

Préréglages d'enceintes & niveaux

Contrôle des préréglages d'enceintes, réglages de niveau par canal et crossovers : les réglages avancés que l'application d'origine n'expose pas.

🏠

Multi-zone

Alimentation, entrée et volume indépendants pour la Zone 2 et la Zone 3.

Raccourcis clavier

Pilotez le récepteur au clavier

Dans les versions Mac App Store et Microsoft Store, utilisez Cmd sur macOS ou Ctrl sur Windows. Les touches multimédias de votre clavier fonctionnent aussi, et rien ne se déclenche pendant que vous tapez dans un champ de texte. Plus de détails dans le guide de la télécommande.

RaccourciAction
Cmd + Espace / Ctrl + EspaceLecture / Pause
Cmd + . / Ctrl + . (point)Stop
Cmd + Gauche / Droite, Ctrl + Gauche / DroitePiste précédente / suivante
Cmd + Haut / Bas, Ctrl + Haut / BasVolume + / -
Cmd + M / Ctrl + MActiver/désactiver la sourdine
Questions fréquentes

Windows et Mac : vos questions

Existe-t-il une application Denon ou Marantz pour Windows ?
Oui. AVR Maestro est disponible sur le Microsoft Store et pilote les récepteurs AV Denon et Marantz connectés au réseau depuis un PC Windows situé sur le même réseau que le récepteur.
Existe-t-il une application Denon ou Marantz pour Mac ?
Oui. AVR Maestro est disponible sur le Mac App Store, avec raccourcis clavier Cmd et prise en charge des touches multimédias.
L'application de bureau propose-t-elle des raccourcis clavier ?
Oui. Utilisez Cmd sur macOS ou Ctrl sur Windows : Space pour Lecture/Pause, . (point) pour Arrêt, Gauche/Droite pour la piste précédente/suivante, Haut/Bas pour le volume et M pour couper le son. Les touches multimédias fonctionnent aussi, et les raccourcis se mettent en pause pendant que vous tapez dans un champ de texte.
L'assistant fonctionne-t-il sur Windows ?
Non. L'assistant nécessite un modèle exécuté sur l'appareil : Apple Intelligence sur iPhone, iPad ou Mac (macOS 26), ou Gemini Nano sur Android. Tout le reste de cette liste fonctionne sur Windows. Consultez le guide de l'assistant.

Když propojení nebo skript nefunguje

Home Assistant, když nefunguje

Většina potíží s Home Assistant se týká stavu propojení, ID entity přijímače nebo sítě mezi telefonem a serverem. Začněte tím, co říká karta propojení, a pokračujte dál.

Co vám říká karta propojení

Karta nad tlačítkem Synchronizovat ukazuje stav propojení a tlačítko se jím řídí.

  • Propojeno s Home Assistant: ověřené volání právě uspělo. Tlačítko Synchronizovat je dostupné.
  • Propojení s Home Assistant vypršelo: server odpověděl a uložený token odmítl. Tlačítko Synchronizovat je neaktivní, dokud se znovu nepřihlásíte.
  • Nelze dosáhnout Home Assistant: k serveru se nepodařilo připojit a token přitom může být zcela v pořádku. Tlačítko Synchronizovat zůstává dostupné a nic se nemění.
  • Nepropojeno s Home Assistant: zatím není uložena adresa ani token. Přidejte svou adresu a přihlaste se.
  • Propojení s Home Assistant nebylo zkontrolováno: je zapnutý demo režim nebo je Domácí automatizace uzamčena, takže se do vaší domácnosti nic neodeslalo a token nebyl vyzkoušen.
Pouze první stav hlásí Propojeno, a to jen proto, že se něco úspěšně ověřilo. Samotný uložený token se za propojení nikdy nepočítá.

Skript nic nedělá nebo hlásí Entity Not Found

  • Nainstalujte v Home Assistant oficiální integraci Denon AVR v části Settings, Devices & Services.
  • Ujistěte se, že Receiver Media Player Entity ID v nastavení AVR Maestro přesně odpovídá ID entity v Home Assistant.
  • Ignorujte každou entitu, která po smazání nebo opětovném vytvoření scény hlásí unavailable. Skripty scén se jmenují podle doby vytvoření scény, takže v části Domácí automatizace zjistíte, jak se ID skriptů jednou změní.

Nová scéna se v Home Assistant nezobrazuje

Scény se synchronizují na pozadí při každém přidání, úpravě nebo smazání, takže nemusíte pokaždé stisknout Synchronizovat. Pokud některá chybí, telefon se k serveru nedostal.

  • Připojte telefon ke stejné místní síti Wi-Fi jako Home Assistant.
  • Otevřete Nastavení a klepněte na Synchronizovat scény. Pokud se to nezdaří, zobrazí se přesná chyba sítě.

Failed login v protokolu Home Assistant

Několik neúspěšných pokusů nebo prohlížeč, který ukončil spojení před dokončením propojení, zanechá v Home Assistant varování. Je to historie, ne aktuální závada, a jakmile propojení funguje, můžete ho ignorovat.

Další věci, které se mohou pokazit

  • Dlaždice dashboardu se nikdy nerozsvítí: viz průvodce dashboardem Home Assistant.
  • Webhook nedorazí: viz Domácí automatizace.
  • Pořád to nejde? Zeptejte se na Discordu nebo navštivte Nápovědu.
Časté dotazy

Potíže s Home Assistant, odpovědi

Můj skript se spustil, ale zobrazuje Entity Not Found, nebo se nic neděje.
Ujistěte se, že je v Home Assistant nainstalována oficiální integrace Denon AVR. Poté zkontrolujte, zda Receiver Media Player Entity ID v nastavení AVR Maestro přesně odpovídá ID entity v Home Assistant, například media_player.living_room_receiver.
Proč protokol Home Assistant hlásí Failed login?
Pokud se při propojování několikrát nezdařil pokus, nebo prohlížeč ukončil spojení dřív, než se dokončilo, Home Assistant zaznamená varování. Jakmile se propojení podařilo, můžete toto staré varování bezpečně ignorovat.
Vytvořil(a) jsem novou scénu a v Home Assistant se nezobrazuje.
Ověřte, že je váš telefon ve stejné místní síti Wi-Fi jako server Home Assistant, protože synchronizace na pozadí selže, když se telefon k serveru nedostane. Otevřete Nastavení a klepněte na Synchronizovat scény, kde uvidíte přesnou chybu sítě, pokud nějaká je.
Musí být aplikace otevřená, aby se mé skripty spustily?
Ne. Skripty jsou uložené v Home Assistant, takže běží z vašeho dashboardu, automatizací nebo hlasových asistentů, zatímco máte telefon v kapse. Aplikace je jen vytváří a aktualizuje, když změníte scénu.

Spelas nu & HEOS

Spelas nu: vad som spelas, på en skärm

När din källa rapporterar metadata placerar kortet Spelas nu i AVR Maestro albumomslaget, spåret och uppspelningsknapparna direkt på hemskärmen - och lämnar över till HEOS för bläddring, för att sedan ta över igen så fort musiken startar.

Allt du lyssnar på, i ett kort

  • Albumomslag och spårinfo: kortet visar omslaget, spåret och artisten eller stationen för det som spelas.
  • Uppspelningsknappar: spela, pausa, nästa och föregående, direkt på kortet - ingen behöver leta efter fjärrkontrollen.
  • Starta HEOS för att bläddra: tryck på den för att öppna den officiella HEOS-appen för stationer, köer, HEOS-rum och strömningstjänster. Starta något där så tar AVR Maestro över visningen av vad som spelas, uppspelningsknapparna och widgetarna igen.
  • En del av din hemskärm: kortet Spelas nu ligger tillsammans med dina widgetar för volym, källa och ljudläge, så vad som spelas är aldrig mer än en blick bort.
Kortet fylls i för HEOS och nätverkskällor som rapporterar metadata. Analoga, optiska/koaxiala källor och HDMI-genomsläpp skickar ingen spårinfo till mottagaren, så kortet förblir tomt för dem - det är källan, inte appen.
Vanliga frågor

Vanliga frågor om Spelas nu

Visar den vad som spelas?
Ja - för källor som rapporterar metadata via HEOS får du albumomslag, spår, artist eller station och uppspelningsknappar (spela, pausa, nästa, föregående), live från din mottagare.
Hur bläddrar jag bland musik?
Tryck på Starta HEOS på kortet Spelas nu. AVR Maestro öppnar den officiella HEOS-appen så att du kan bläddra bland stationer, köer, HEOS-rum och streamingtjänster. När uppspelningen har startat tar AVR Maestro tillbaka visningen av vad som spelas och uppspelningsknapparna.
Varför är kortet tomt på vissa ingångar?
Analoga, optiska/koaxiala källor och HDMI-genomsläpp rapporterar inte spårmetadata, så det finns inget att visa. Kortet fylls i för HEOS och nätverkskällor som gör det.
Var finns kortet Spelas nu?
På din hemskärm, tillsammans med de widgetar du väljer - volym, källa, ljudläge, zoner med mera.

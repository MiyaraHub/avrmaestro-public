FM/AM-tuner

En riktig FM/AM-radio, med namngivna förval

På Denon- och Marantz-mottagare med inbyggd tuner ger AVR Maestro dig ett riktigt gränssnitt för FM/AM-radio. Stationskortet visar aktuellt band, aktuell frekvens och aktivt förval och följer mottagaren i realtid.

Så fungerar det

Ställ in, sök och spara

  • Band: FM / AM. Avstämningsläge: Auto (söker till nästa starka station) eller Manuell (stegar med bandets stegvärde).
  • Avstämning: de två Tune-knapparna stegar skalan; Ange frekvens öppnar ett tangentbord för att hoppa direkt till en station (kräver manuellt läge).
  • Förval: ett rutnät med förvalsplatser plus upp- och nerknappar. Tryck länge på en plats för att Spara aktuell station, Lägga till / byta namn på etikett ("Jazz 88", "NPR") eller Rensa etikett.
Om fliken Radio är dold, lägg till den igen från Inställningar → Anpassa navigeringen - den visas bara när din mottagare har en tuner.
Vanliga frågor

Vanliga frågor om tunern

Kan jag styra FM/AM-radion från appen?
Ja, på mottagare med inbyggd tuner - live-visning av band, frekvens och förval, FM/AM-växling, automatisk eller manuell avstämning, ett tangentbord för att hoppa till en frekvens och ett rutnät med förval.
Kan jag döpa mina förval?
Ja - tryck länge på en plats för att spara aktuell station, lägga till eller byta namn på en etikett ("Jazz 88", "NPR") eller rensa den.
Varför ser jag inte fliken Radio?
Den visas bara på mottagare med inbyggd tuner. Om din har en, kontrollera att tunern visas som en ingång och aktivera fliken igen under Inställningar, Anpassa navigeringen.

Samma nätverk och subnät

Telefonen och mottagaren måste dela nätverk. Mesh-system, gästnätverk och IoT-VLAN kan isolera enheter, och en mottagare på ett annat subnät hittas inte av sig själv.

Network Control på

Slå på Network Control under Inställningar på mottagaren så att den går att nå och väcka från standby. Den exakta menyvägen varierar mellan modeller.

Kontrollera IP-adressen

Läs av adressen på mottagarens egen skärm Network, Information och jämför den med den i appen. DHCP-adresser ändras, så reservera den i routern om den fortsätter att flytta sig.

En upptagen mottagare

Om för många kontrollappar håller anslutningar säger appen att nätverket är upptaget i stället för att misslyckas utan förklaring. Stäng den andra kontrollern eller ge den några sekunder.

Vanliga frågor

Mottagaren hittas inte, besvarat

Varför hittar AVR Maestro inte min Denon- eller Marantz-mottagare?
Telefonen och mottagaren måste vara på samma nätverk och subnät. Mesh-system, gästnätverk och IoT-VLAN kan isolera enheter. Kontrollera att mottagaren är påslagen med Network Control inställt på On och försök sedan igen, eller lägg till den med dess IP-adress.
Var slår jag på Network Control?
Öppna Inställningar på mottagaren, sedan General eller Network, och ställ in Network Control på On så att mottagaren går att nå i standby. Den exakta menyvägen varierar mellan modeller.
Var hittar jag mottagarens IP-adress?
På mottagarens egen skärm Network, Information. DHCP-adresser kan ändras, så kontrollera den igen om en mottagare som fungerade slutar ansluta, eller reservera adressen i routern.
Anslutningen bryts hela tiden. Vad hjälper?
Starta om mottagaren genom att dra ur strömmen för att rensa en fastnad Telnet-lyssnare. På ett Wi-Fi 6-mesh, lägg telefonen på samma band som mottagaren, eftersom mottagare oftast sitter på 2.4 GHz medan telefoner föredrar 5 GHz.
Vad betyder meddelandet om upptaget nätverk?
Mottagaren går att nå, men dess nätverksstack är överbelastad, oftast för att flera kontrollappar håller anslutningar samtidigt. Stäng den andra kontrollern eller vänta några sekunder.
Stöds min mottagarmodell?
Det finns ingen vitlista över modeller. AVR Maestro identifierar vad din mottagare stöder när den ansluter, så om mottagarens webbportal och den officiella Denon- eller Marantz-appen kan nå den bör AVR Maestro kunna det också.

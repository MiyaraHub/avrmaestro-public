Hjälp & felsökning

Lös vanliga problem med Denon & Marantz-appen

Snabba lösningar på de vanligaste frågorna. Om du fortfarande sitter fast är Felsökningsloggen i appen (Inställningar → Hjälp → Spara & dela) det snabbaste sättet att få support - nå utvecklaren på Discord eller i Facebook-supportgruppen, svaren kommer snabbt.

Anslutning

Att få kontakt

”Testa anslutningen” misslyckas
Kontrollera att telefonen och mottagaren finns på samma Wi-Fi-nätverk och subnät - mesh-system, gästnätverk och IoT-VLAN kan isolera enheter. På mottagaren måste Setup → Network → Network Control vara På. Kontrollera IP-adressen mot mottagarens egen skärm Network → Information, eftersom DHCP-adresser ändras. HTTP krävs; Telnet och HEOS är trevligt att ha. Om mottagaren går att nå men dess nätverksstack är överbelastad - för många kontrollappar som håller anslutningar - säger appen det med ett tydligt meddelande om att nätverket är upptaget i stället för ett allmänt fel; stäng en annan kontroll eller ge det några sekunder. Fullständiga steg i guiden Kom igång.
Anslutningen bryts var några sekunder
Telnet-portar på mottagare kan fastna efter lång drifttid - slå av och på mottagaren vid vägguttaget för att rensa lyssnaren. På Wi-Fi 6-mesh, tvinga telefonen till samma band som mottagaren (AVR-mottagare sitter oftast på 2,4 GHz; telefoner föredrar 5 GHz).
Hur vet jag att min mottagare stöds?
Det beror på ditt nätverk, inte bara på modellen. Om mottagarens webbportal, HEOS-appen och den officiella Denon/Marantz-appen alla kan nå den bör AVR Maestro kunna det också. Se sidan om mottagare som stöds.
Kontroller & skärm

Varför något ser konstigt ut

Volymavläsningen ser fel ut
Mottagare rapporterar volym som absolut (0-98) eller relativ (-80 till +18 dB). Appen hanterar båda; om du nyligen ändrat mottagarens inställning för volymvisning, starta om appen så att den läser av skalan på nytt. Du kan växla vilket värde som visas överst i Inställningar → Ljud.
Ljudlägen eller funktionsmarkeringar är utgråade / "N/A"
Surroundlägen och funktioner styrs av ingångens ljudformat och det aktiva ljudläget - en 2-kanalskälla aktiverar inte Dolby Atmos. Det är mottagarens beteende, inte appens. Tryck på (?) bredvid en N/A-markering för det exakta kravet.
Vissa flikar för Ljud eller Högtalare saknas
Flikarna anpassas efter modell och läge. Audyssey, Dirac Live, IMAX, Auro-3D, Surround Shape, Avstånd och Delningsfrekvenser visas bara på mottagare som erbjuder dem. Kontrollera Inställningar → Enheter → Enhetsinformation för att se vad appen identifierade, eller lägg tillbaka en dold flik från Inställningar → Anpassa flikar / Anpassa navigering.
Fliken Radio visas inte
Radio styrs av funktioner: den visas bara på mottagare med inbyggd FM/AM-tuner. Om din har en men fliken är dold, kontrollera att tunern finns som ingång på mottagaren och aktivera den igen från Inställningar → Anpassa navigering. Se guiden om Radio.
Kortet Spelas nu är tomt
Den aktuella ingången lämnar inga metadata - analoga, optiska/koaxiala och de flesta HDMI-genomföringskällor rapporterar inga spårdata. För HEOS-källor, tryck på Starta HEOS för att starta uppspelningen, gå sedan tillbaka så fylls metadatan i.
Widgeten på hemskärmen säger "AVR off" eller "Standby"
Det är widgetens frånläge, inte ett fel. När mottagaren är av, i vänteläge eller inte går att nå visar widgetarna (iOS och Android) "AVR off" / "Standby" i stället för senaste ingång och volym, så att du aldrig läser inaktuella data. På widgeten Quick Control döljs volym- och tystknapparna i det läget, men strömknappen förblir aktiv - tryck på den för att väcka mottagaren direkt från widgeten (Network Standby måste vara aktiverat på mottagaren).
Vissa högtalarskärmar öppnas i mottagarens webbkontroll
På vissa mottagare från före 2025 (klassen X4500H / X6700H / S960H / X4700H) kan mottagaren inte leverera skärmarna Högtalarlayout eller Subwooferutgång till appen, så AVR Maestro ger dig en knapp med ett tryck in i mottagarens egen webbkontroll för de ändringarna. Allt annat fungerar som vanligt; nyare firmware levererar varje skärm i appen.

Audyssey

שליטה מלאה ב-Audyssey MultEQ

כל מה שיש בתפריט Audyssey של המקלט, במסך אחד שקורא את המצב החי.

  • MultEQ: מעבר בין רפרנס, עקיפה L+R, שטוח וכבוי.
  • Dynamic EQ ו-קיזוז רמת הרפרנס להאזנה בעוצמה נמוכה.
  • Dynamic Volume כדי ליישר את ההבדלים בין קטעים חזקים לשקטים.
  • LFC (Low Frequency Containment) עם בורר לרמת ההכלה.
  • כל פקד מופיע רק כשהמקלט שלכם באמת חושף אותו.
Dirac Live

  • בוחרים חריץ מסנן לפי השם שנתתם לו בתוכנת Dirac Live - ולא לפי מספר חריץ סתום.
  • חריצים ריקים מוסתרים כך שתראו רק את המסננים האמיתיים שלכם.
  • החריץ הפעיל מתעדכן בזמן אמת אם שיניתם אותו מהמקלט או ממקום אחר.
  • מחליפים את כל כוונון החדר בנגיעה - מסנן לסרטים, מסנן למוזיקה, מסנן לשעות הלילה.

שאלות נפוצות על Audyssey & Dirac Live

אפשר לשלוט ב-Audyssey מהטלפון?
כן - במקלטים שיש בהם Audyssey, AVR Maestro קוראת ומחליפה את MultEQ (רפרנס / עקיפה L+R / שטוח / כבוי), Dynamic EQ, Dynamic Volume, קיזוז רמת הרפרנס ו-LFC, ישר מהאפליקציה.
האם AVR Maestro יכולה להחליף מסנני Dirac Live?
כן. כשיש רישיון Dirac Live במקלט, האפליקציה מציגה את חריצי המסנן שלכם לפי שם ומחליפה את הפעיל בנגיעה. חריצים ריקים מוסתרים, והחריץ הפעיל מתעדכן בזמן אמת.
מה ההבדל בין Audyssey ל-Dirac Live?
שתיהן מתקנות את החדר שלכם. Audyssey MultEQ מובנית ברוב מקלטי Denon ו-Marantz ומכוילת באפליקציה בטלפון; Dirac Live היא רישיון אופציונלי בתשלום שהרבה חובבים מעדיפים, והכיול שלה נעשה מהמחשב. במקלטים האלה אי אפשר להפעיל את שתיהן יחד בכל פריסט רמקולים, ו-AVR Maestro שולטת במערכת שבה הפריסט הפעיל שלכם משתמש.
אפשר להפעיל את שתיהן במקביל?
לא - ב-Denon וב-Marantz הן סותרות זו את זו וקשורות לפריסט הרמקולים. AVR Maestro מזהה זאת בכל פריסט, ולכן כדי לשנות את הכיול הפעיל פשוט עוברים לפריסט רמקולים אחר.

מחפשים חלופה לאפליקציית Audyssey? AVR Maestro מחליפה את הגדרות Audyssey של מקלט ה-Denon או ה-Marantz שלכם מהטלפון: עקומת MultEQ (Reference, Bypass L+R, Flat או Off), Dynamic EQ, Reference Level Offset, Dynamic Volume ו-LFC. היא לא מריצה את הכיול: המיקרופון ואפליקציית Audyssey עדיין עושים זאת, ועקומות יעד מותאמות אישית דורשות את אפליקציית MultEQ Editor בתשלום.

מה היא מחליפה

הגדרות Audyssey שלכם, במסך אחד

הפקדים שמגיעים אליהם אחרי הכיול, נקראים בזמן אמת מהמקלט. כל אחד מהם מופיע רק כשהמקלט שלכם חושף אותו.

🎲

עקומת MultEQ

עברו בין Reference, Bypass L+R, Flat ו-Off בלי לפתוח את התפריט שעל המסך של המקלט.

🔈

Dynamic EQ ו-Reference Level Offset

שמרו על בס וסראונד מלאים בעוצמה נמוכה, וקבעו את הקיזוז לפי החדר והטעם שלכם.

📈

Dynamic Volume

איזנו בין קטעים רועשים לשקטים להאזנה בשעות הלילה.

🎤

LFC

Low Frequency Containment עם בורר צעדים לרמת ההכלה.

🎚

אקולייזר גרפי

עקומה בת 9 פסים לכל רמקול, מ-63Hz עד 16kHz, מ--20 עד +6 dB. Copy מתחיל מעקומת Audyssey שנמדדה אצלכם. המקלט מפעיל תיקון חדר או את האקולייזר הידני, אף פעם לא את שניהם.

🎭

נשמר בסצנות

שמרו את בחירות ה-Audyssey שלכם בסצנה ושחזרו אותן יחד עם הקלט, העוצמה, מצב הסאונד והפריסט לרמקולים בהקשה אחת.

שאלות נפוצות

Audyssey מהטלפון, תשובות

האם יש חלופה לאפליקציית Audyssey לשימוש יומיומי?
כן. AVR Maestro קוראת ומחליפה את MultEQ (Reference / Bypass L+R / Flat / Off), את Dynamic EQ, את Reference Level Offset, את Dynamic Volume ואת LFC במקלטי Denon ו-Marantz שיש בהם Audyssey, ישירות מהאפליקציה.
האם AVR Maestro יכולה לכייל את החדר שלי?
לא. AVR Maestro לא מריצה את הכיול. המיקרופון ותוכנת Audyssey או Dirac Live עושים זאת; האפליקציה שולטת בתוצאה מיום ליום.
האם אפשר לערוך עקומות יעד של Audyssey ב-AVR Maestro?
לא. עקומות יעד מותאמות אישית של Audyssey דורשות את אפליקציית MultEQ Editor בתשלום. ל-AVR Maestro יש אקולייזר גרפי בן 9 פסים שיכול להתחיל מעקומת Audyssey שנמדדה אצלכם, וניתן להשתמש בו כש-MultEQ ו-Dirac כבויים.
האם היא עובדת גם עם Dirac Live?
כן. עם רישיון Dirac Live במקלט, האפליקציה מציגה את חריצי המסננים שלכם לפי שם ומחליפה את הפעיל בהקשה אחת.

Când o conectare sau un script nu funcționează corect

Home Assistant, când nu funcționează

Majoritatea problemelor Home Assistant se reduc la starea conectării, ID-ul entității receiverului sau rețeaua dintre telefon și server. Începeți cu ce spune cardul de conectare, apoi mergeți mai departe.

Ce vă spune cardul de conectare

Cardul de deasupra butonului Sync arată starea conectării, iar butonul o urmează.

  • Conectat la Home Assistant: un apel autentificat a reușit chiar acum. Butonul Sync este disponibil.
  • Conexiunea cu Home Assistant a expirat: serverul a răspuns și a refuzat tokenul salvat. Butonul Sync este dezactivat până vă autentificați din nou.
  • Nu se poate contacta Home Assistant: serverul nu a putut fi contactat, iar tokenul poate fi perfect valid. Butonul Sync rămâne disponibil și nu se modifică nimic.
  • Neconectat la Home Assistant: nu este salvată încă nicio adresă sau niciun token. Adăugați adresa și autentificați-vă.
  • Conexiunea cu Home Assistant nu a fost verificată: modul demo este activ sau Automatizare Locuință este blocată, deci nu s-a trimis nimic spre locuința dumneavoastră, iar tokenul nu a fost încercat.
Doar prima spune Conectat, și doar pentru că ceva s-a autentificat. Un token salvat nu înseamnă niciodată, de unul singur, o conectare.

Un script nu face nimic sau spune Entity Not Found

  • Instalați integrarea oficială Denon AVR în Home Assistant, la Setări, Dispozitive & Servicii.
  • Asigurați-vă că Receiver Media Player Entity ID din Setările AVR Maestro se potrivește exact cu ID-ul entității din Home Assistant.
  • Ignorați orice entitate care spune unavailable după ce o scenă a fost ștearsă sau recreată. Scripturile scenelor poartă numele momentului în care a fost creată scena, deci consultați Automatizare Locuință pentru felul în care ID-urile scripturilor se schimbă o singură dată.

O scenă nouă lipsește din Home Assistant

Scenele se sincronizează în fundal ori de câte ori adăugați, editați sau ștergeți una, deci nu trebuie să apăsați Sync de fiecare dată. Dacă una lipsește, telefonul nu a putut contacta serverul.

  • Conectați telefonul la aceeași rețea Wi-Fi locală cu Home Assistant.
  • Deschideți Setări și atingeți Sync Scenes. Dacă eșuează, afișează eroarea de rețea exactă.

Failed login în jurnalul Home Assistant

Mai multe încercări eșuate sau un browser care a pierdut conexiunea înainte de finalizarea conectării lasă un avertisment în Home Assistant. Este istorie, nu o defecțiune actuală, și îl puteți ignora după ce conectarea funcționează.

Alte lucruri care merg prost

  • Un element al panoului nu se aprinde niciodată: consultați ghidul panoului Home Assistant.
  • Un webhook nu ajunge: consultați Automatizare Locuință.
  • Încă sunteți blocat? Întrebați pe Discord sau consultați Ajutor.
Întrebări frecvente

Probleme Home Assistant, cu răspunsuri

Scriptul meu a rulat, dar apare Entity Not Found sau nu se întâmplă nimic.
Asigurați-vă că integrarea oficială Denon AVR este instalată în Home Assistant. Apoi verificați dacă Receiver Media Player Entity ID din Setările AVR Maestro se potrivește exact cu ID-ul entității din Home Assistant, de exemplu media_player.living_room_receiver.
De ce apare Failed login în jurnalul meu Home Assistant?
Dacă ați avut mai multe încercări eșuate la conectare sau browserul v-a pierdut conexiunea înainte de finalizare, Home Assistant înregistrează un avertisment. După ce conectarea a reușit, puteți ignora în siguranță acel avertisment vechi.
Am creat o scenă nouă și nu apare în Home Assistant.
Verificați dacă telefonul este în aceeași rețea Wi-Fi locală cu serverul Home Assistant, deoarece sincronizarea în fundal eșuează când telefonul nu îl poate contacta. Deschideți Setări și atingeți Sync Scenes pentru a vedea eroarea de rețea exactă, dacă există.
Trebuie să fie aplicația deschisă pentru ca scripturile mele să ruleze?
Nu. Scripturile se află în Home Assistant, deci rulează din panoul dumneavoastră, din automatizări sau de la asistenții vocali în timp ce telefonul este în buzunar. Aplicația le creează și le actualizează doar când modificați o scenă.

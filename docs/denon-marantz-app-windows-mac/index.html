Keyboard shortcuts

Drive the receiver from the keyboard

On the Mac App Store and Microsoft Store builds, use Cmd on macOS or Ctrl on Windows. Your keyboard's media keys work too, and nothing fires while you're typing in a text field. More in the remote guide.

Common questions

Windows and Mac, answered

Is there a Denon or Marantz app for Windows?
Yes. AVR Maestro is on the Microsoft Store and controls network-enabled Denon and Marantz AV receivers from a Windows PC on the same network as the receiver.
Is there a Denon or Marantz app for Mac?
Yes. AVR Maestro is on the Mac App Store, with Cmd keyboard shortcuts and media-key support.
Does the desktop app have keyboard shortcuts?
Yes. Use Cmd on macOS or Ctrl on Windows: Space for Play/Pause, . (period) for Stop, Left/Right for previous/next track, Up/Down for volume and M to mute. Media keys work too, and shortcuts pause while you type in a text field.
Does the assistant work on Windows?
No. The assistant needs an on-device model: Apple Intelligence on iPhone, iPad or Mac (macOS 26), or Gemini Nano on Android. Everything else in this list works on Windows. See the assistant guide.

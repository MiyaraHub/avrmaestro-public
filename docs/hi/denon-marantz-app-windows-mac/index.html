Windows और Mac, सवाल-जवाब

क्या Windows के लिए कोई Denon या Marantz ऐप है?
हां। AVR Maestro, Microsoft Store पर उपलब्ध है और रिसीवर के समान नेटवर्क पर मौजूद Windows PC से नेटवर्क-सक्षम Denon और Marantz AV रिसीवर नियंत्रित करता है।
क्या Mac के लिए कोई Denon या Marantz ऐप है?
हां। AVR Maestro, Mac App Store पर उपलब्ध है, जिसमें Cmd कीबोर्ड शॉर्टकट और मीडिया-कीज़ का समर्थन है।
क्या डेस्कटॉप ऐप में कीबोर्ड शॉर्टकट हैं?
हां। macOS पर Cmd या Windows पर Ctrl इस्तेमाल करें: Play/Pause के लिए Space, Stop के लिए . (पीरियड), पिछले/अगले ट्रैक के लिए Left/Right, वॉल्यूम के लिए Up/Down और म्यूट के लिए M। मीडिया कीज़ भी काम करती हैं, और टेक्स्ट फ़ील्ड में टाइप करते समय शॉर्टकट रुक जाते हैं।
क्या असिस्टेंट Windows पर काम करता है?
नहीं। असिस्टेंट को ऑन-डिवाइस मॉडल चाहिए: iPhone, iPad या Mac (macOS 26) पर Apple Intelligence, या Android पर Gemini Nano। इस सूची में बाकी सब कुछ Windows पर काम करता है। असिस्टेंट गाइड देखें।

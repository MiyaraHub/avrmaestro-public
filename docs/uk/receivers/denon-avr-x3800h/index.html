Поширені запитання

Denon AVR-X3800H + AVR Maestro

Чи є застосунок для керування Denon AVR-X3800H?
Так - AVR Maestro - це преміальний сторонній контролер для X3800H. Через вашу мережу він керує режимами об'ємного звуку, Audyssey і Dirac Live, пресетами акустики, рівнями, кількома зонами, тюнером і сценами одним дотиком.
Чи керує він Dirac Live на X3800H?
Так. З ліцензією Dirac Live він перемикає ваші слоти фільтрів за назвами; зі стандартним пресетом Audyssey він керує MultEQ, Dynamic EQ, Dynamic Volume і LFC. Дивіться посібник з Audyssey & Dirac.
Чи потрібен хмарний обліковий запис?
Ні - він спілкується з X3800H безпосередньо через вашу локальну мережу. Без хмарного облікового запису, без підписки і без додаткового обладнання.
Як його підключити?
Увімкніть Network Control на X3800H, дізнайтеся його IP і додайте його в застосунку. Усі кроки - у посібнику з початку роботи.

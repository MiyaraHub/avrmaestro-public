Denon AVC-X8500HA + AVR Maestro

Onko Denon AVC-X8500HA -vastaanottimen ohjaamiseen olemassa sovellusta?
Kyllä - AVR Maestro on premium-luokan kolmannen osapuolen ohjain X8500HA:lle. Verkon yli se ohjaa surround-tiloja, Audyssey MultEQ XT32:ta ja Dirac Livea, kaiutinesiasetuksia, tasoja, usean vyöhykkeen ohjausta, viritintä ja yhden napautuksen tilanteita.
Ohjaako AVR Maestro Dirac Livea X8500HA:ssa?
Kyllä. Denon AVC-X8500HA -vastaanottimessa, jossa on Dirac Live -lisenssi, AVR Maestro luettelee Dirac-suodatinpaikkasi nimillä ja vaihtaa aktiivisen. Tavallisella Audyssey-esiasetuksella se ohjaa sen sijaan MultEQ:ta, Dynamic EQ:ta, Dynamic Volumea ja LFC:tä. Katso Audyssey & Dirac -opas.

Ei - se puhuu X8500HA-vastaanottimen kanssa suoraan paikallisverkossasi. Ei pilvitiliä, ei tilausta eikä lisälaitteita.

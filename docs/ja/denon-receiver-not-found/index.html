DenonまたはMarantzのレシーバーが見つからない場合の接続の修正

AVR Maestroがレシーバーを見つけられない、または接続できない場合、原因はほぼ常にアプリではなくネットワークです。Network Control、サブネット、IPアドレス、レシーバーのビジー状態の順に確認してください。

接続の問題の大半を解決する4つの確認

どれも1分で済みます。レシーバーに接続できた時点で止めて構いません。

📶

同じネットワークと同じサブネット

スマートフォンとレシーバーは同じネットワークを共有している必要があります。メッシュシステム、ゲストネットワーク、IoT用VLANは機器を隔離することがあり、別のサブネットにあるレシーバーは自動では見つかりません。

🔌

Network Controlをオンにする

レシーバーのSetupでNetwork Controlをオンにすると、スタンバイからでも接続して起動できます。メニューの正確な場所は機種によって異なります。

🔍

IPアドレスを確認する

レシーバー本体のNetwork、Information画面でアドレスを読み取り、アプリのアドレスと比べてください。DHCPのアドレスは変わるため、頻繁に変わる場合はルーターで固定してください。

⏳

レシーバーがビジー状態

多くのコントローラーアプリが接続を保持していると、アプリは理由もなく失敗する代わりに、ネットワークがビジーであると表示します。ほかのコントローラーを閉じるか、数秒待ってください。

それでも切れる場合

接続できたあとで切れる

2つの対処でほとんど解決します。

電源プラグを抜いて入れ直す

長時間稼働したあと、レシーバーのTelnetリスナーが固まることがあります。レシーバーの電源プラグをしばらく抜くと解消します。

Wi-Fiの周波数帯を合わせる

レシーバーは通常2.4 GHzを使い、スマートフォンは5 GHzを優先します。Wi-Fi 6のメッシュ環境では、スマートフォンをレシーバーと同じ周波数帯に接続してください。

詳しい手順ははじめにガイドとヘルプとトラブルシューティングのページにあります。お使いの機種が対応しているかどうかは、対応レシーバーのページで確認できます。

よくある質問

レシーバーが見つからない場合の回答

AVR MaestroがDenonまたはMarantzのレシーバーを見つけられないのはなぜですか？
スマートフォンとレシーバーは同じネットワークおよび同じサブネットにある必要があります。メッシュシステム、ゲストネットワーク、IoT用VLANは機器を隔離することがあります。レシーバーの電源が入っていてNetwork ControlがOnになっていることを確認してから再試行するか、IPアドレスを指定して追加してください。
Network Controlはどこでオンにしますか？
レシーバーでSetupを開き、GeneralまたはNetworkを選んで、Network ControlをOnにします。これでスタンバイ中でもレシーバーに接続できます。メニューの正確な場所は機種によって異なります。
レシーバーのIPアドレスはどこで確認できますか？
レシーバー本体のNetwork、Information画面で確認できます。DHCPのアドレスは変わることがあるため、動いていたレシーバーが接続できなくなった場合は再確認するか、ルーターでアドレスを固定してください。
接続が頻繁に切れます。どうすればよいですか？
レシーバーの電源プラグを抜いて入れ直し、固まったTelnetリスナーを解消します。Wi-Fi 6のメッシュ環境では、スマートフォンをレシーバーと同じ周波数帯に接続してください。レシーバーは通常2.4 GHzを使い、スマートフォンは5 GHzを優先するためです。
ネットワークビジーのメッセージは何を意味しますか？
レシーバーには到達できますが、ネットワークスタックが飽和している状態です。多くの場合、複数のコントローラーアプリが同時に接続を保持していることが原因です。ほかのコントローラーを閉じるか、数秒待ってください。
私のレシーバーの機種は対応していますか？
対応機種のホワイトリストはありません。AVR Maestroは接続時にレシーバーが対応している機能を検出するため、レシーバーのWebポータルやDenonまたはMarantzの公式アプリから接続できるなら、AVR Maestroからも接続できるはずです。

1分以内に接続

買い切り。広告なし、サブスクリプションなし。DenonやMarantzのレシーバーに1分足らずで接続できます。

AVR Maestro プレスキット

AVR Maestroについて書くために必要な情報をまとめました。アプリの概要、変わらない基本情報、使用できるアプリアイコンとスクリーンショットです。

アプリの概要

AVR Maestroは、DenonとMarantzのAVレシーバーを操作する独立系のネットワークリモコンです。ローカルネットワーク経由でレシーバーと通信し、アカウントも広告もクラウドサービスも介さず、お使いのレシーバーのモデルに実際にある機能だけを表示します。

基本情報

  • 価格：$9.99の買い切り。サブスクリプションも広告もありません。オプションのHome Automation Proアドオンは$2.99です。
  • 対応プラットフォーム：iPhone、iPad、Mac、Android、Windows。
  • 対応レシーバー：DenonとMarantzのネットワークレシーバー。レシーバー一覧をご覧ください。
  • 対応言語：30言語。
  • 開発元：MiyaraHub Technologies LLC。
  • プライバシー：不具合の修正に役立てるため、匿名のクラッシュレポートと利用統計がFirebaseに送信されます。プライバシーポリシーをご覧ください。

AVR Maestroは独立系のアプリであり、Denon、Marantz、Masimoとは提携していません。DenonとMarantzはそれぞれの所有者の商標で、アプリが対応するレシーバーを示すためだけに記載しています。

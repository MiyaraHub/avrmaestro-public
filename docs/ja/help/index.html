接続

接続するには

「接続をテスト」が失敗する
スマートフォンとレシーバーが同じWi-Fiネットワークおよびサブネットにあることを確認してください。メッシュシステム、ゲストネットワーク、IoT用VLANでは、機器同士が分離されることがあります。レシーバー側では、Setup → Network → Network Controlがオンになっている必要があります。DHCPのアドレスは変わることがあるため、IPアドレスはレシーバー自身のNetwork → Informationの画面で再確認してください。HTTPは必須で、TelnetとHEOSはあると望ましい程度です。レシーバーには到達できてもネットワークスタックが飽和している場合(接続を保持しているコントローラーアプリが多すぎる場合)、アプリは漠然とした失敗ではなく、はっきりとしたネットワークビジー表示でお知らせします。ほかのコントローラーを閉じるか、数秒待ってください。詳しい手順ははじめにガイドをご覧ください。
数秒おきに接続が切れる
長時間稼働し続けると、レシーバーのTelnetポートが固まることがあります。コンセントから電源を抜いて入れ直し、リスナーをクリアしてください。Wi-Fi 6のメッシュ環境では、スマートフォンをレシーバーと同じ帯域に切り替えてください(AVRは通常2.4 GHzで動作し、スマートフォンは5 GHzを優先します)。
レシーバーが対応しているかどうか、どう確認できますか?
決め手は機種だけでなく、ネットワークです。レシーバーのWebポータル、HEOSアプリ、Denon/Marantz公式アプリのすべてから接続できるなら、AVR Maestroからも接続できるはずです。対応レシーバーのページをご覧ください。
コントロール&表示

表示がおかしい場合の原因

音量の表示がおかしい
レシーバーは音量を、絶対値(0-98)または相対値(-80～+18 dB)で報告します。アプリは両方に対応しています。レシーバーの音量表示設定を最近変更した場合は、アプリを再起動してスケールを読み直してください。どちらの値を上に表示するかは、設定 → オーディオで切り替えられます。
サウンドモードや機能ピルがグレーアウトまたは「N/A」になっている
サラウンドモードや機能は、入力のオーディオフォーマットと有効なサウンドモードによって制限されます。たとえば2チャンネルのソースではDolby Atmosは有効になりません。これはアプリではなくレシーバーの動作です。N/Aピルの横の(?)をタップすると、必要な条件が正確に表示されます。
サウンドタブやスピーカータブの一部が表示されない
タブは、機種とモードに応じて表示が変わります。Audyssey、Dirac Live、IMAX、Auro-3D、サラウンドシェイプ、距離、クロスオーバーは、それらを公開しているレシーバーにのみ表示されます。設定 → デバイス → デバイス情報でアプリが検出した内容を確認するか、設定 → タブをカスタマイズ / ナビゲーションをカスタマイズから、非表示にしたタブを再び追加してください。
ラジオタブが表示されない
ラジオは機能に応じて表示されます。FM/AMチューナーを内蔵したレシーバーにのみ表示されます。お使いの機種にチューナーがあるのにタブが非表示の場合は、レシーバーの入力にチューナーが表示されていることを確認し、設定 → ナビゲーションをカスタマイズから再び有効にしてください。ラジオガイドをご覧ください。
再生中カードが空白になる
現在の入力がメタデータを提供していません。アナログ、光/同軸、ほとんどのHDMIパススルーのソースは、曲の情報を報告しません。HEOSソースの場合は、HEOSを起動をタップして再生を開始し、戻ってくるとメタデータが表示されます。
ホーム画面のウィジェットに「AVR off」または「Standby」と表示される
これは故障ではなく、ウィジェットのオフ状態の表示です。レシーバーがオフ、スタンバイ、または到達不能の場合、ウィジェット(iOSとAndroid)は直前の入力や音量ではなく「AVR off」/「Standby」と表示するので、古いデータを読まされることはありません。クイックコントロールウィジェットでは、この状態で音量とミュートのボタンは非表示になりますが、電源ボタンは有効なままです。タップすれば、ウィジェットからそのままレシーバーを起動できます(レシーバー側でネットワークスタンバイを有効にしておく必要があります)。
一部のスピーカー画面がレシーバーのWebコントロールで開く
2025年より前の一部のレシーバー(X4500H / X6700H / S960H / X4700Hクラス)では、スピーカーレイアウトやサブウーファー出力の画面をアプリに提供できません。そのため、AVR Maestroはそれらの編集用に、レシーバー自身のWebコントロールへ直接移動できるボタンを1タップで表示します。それ以外は通常どおり動作し、新しいファームウェアではすべての画面がアプリ内で提供されます。

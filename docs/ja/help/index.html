ヘルプ&トラブルシューティング

Denon&Marantzのアプリでよくある問題を解決

よくある質問の簡単な解決方法です。それでも解決しない場合は、設定 › AVR Maestroについて › すべての関連ログからログを送ってください。サポートを受ける最速の方法です。開発者にはDiscordまたはFacebookサポートグループで連絡でき、返信は迅速です。

接続

接続するには

「接続をテスト」が失敗する
スマートフォンとレシーバーが同じWi-Fiネットワークおよびサブネットにあることを確認してください。メッシュシステム、ゲストネットワーク、IoT用VLANでは、機器同士が分離されることがあります。レシーバー側では、Setup → Network → Network Controlがオンになっている必要があります。DHCPのアドレスは変わることがあるため、IPアドレスはレシーバー自身のNetwork → Informationの画面で再確認してください。HTTPは必須で、TelnetとHEOSはあると望ましい程度です。レシーバーには到達できてもネットワークスタックが飽和している場合(接続を保持しているコントローラーアプリが多すぎる場合)、アプリは漠然とした失敗ではなく、はっきりとしたネットワークビジー表示でお知らせします。ほかのコントローラーを閉じるか、数秒待ってください。詳しい手順ははじめにガイドをご覧ください。
数秒おきに接続が切れる
長時間稼働し続けると、レシーバーのTelnetポートが固まることがあります。コンセントから電源を抜いて入れ直し、リスナーをクリアしてください。Wi-Fi 6のメッシュ環境では、スマートフォンをレシーバーと同じ帯域に切り替えてください(AVRは通常2.4 GHzで動作し、スマートフォンは5 GHzを優先します)。
レシーバーが対応しているかどうか、どう確認できますか?
決め手は機種だけでなく、ネットワークです。レシーバーのWebポータル、HEOSアプリ、Denon/Marantz公式アプリのすべてから接続できるなら、AVR Maestroからも接続できるはずです。対応レシーバーのページをご覧ください。
コントロール&表示

表示がおかしい場合の原因

音量の表示がおかしい
音量は2つのスケールで表示できます。0-98スケールと、-80から+18 dBのデシベルスケールです。どちらも同じ音量を表しています。設定 › レシーバーを管理 › お使いのレシーバー › オーディオで、絶対音量を上に表示は大きい数値をどちらにするかを、リモコンの音量表示はリモコンタブで使うスケールを選びます。音量のガイドをご覧ください。
サウンドモードや機能ピルがグレーアウトまたは「N/A」になっている
サラウンドモードや機能は、入力の音声フォーマットと有効なサウンドモードによって制限されます。2チャンネルのソースでは、Dolby Atmosは有効になりません。これはアプリではなく、レシーバーの動作です。ロックされたコントロールのガイドで、コントロールがロックされる理由と、ロックを解除する方法を説明しています。
サウンドタブやスピーカータブの一部が表示されない
タブは、モデルとモードに応じて表示されます。Audyssey、Dirac Live、IMAX、Auro-3D、サラウンドのシェイプ、距離、クロスオーバーは、レシーバーが対応している場合にのみ表示されます。アプリが検出した内容は、設定 › レシーバーを管理 › お使いのレシーバー › デバイス情報で確認できます。オフにしたサブタブは設定 › タブをカスタマイズから、下部のタブは設定 › ナビゲーションをカスタマイズから戻せます。ナビゲーションのガイドをご覧ください。
ラジオタブが表示されない
ラジオは機能に応じて表示されます。内蔵のFM/AMチューナーを備えたレシーバーにのみ表示されます。お使いのレシーバーにチューナーがあるのにタブが表示されない場合は、チューナーがレシーバーの入力として表示されていることを確認し、設定 › ナビゲーションをカスタマイズから再び有効にしてください。ラジオのガイドをご覧ください。
再生中カードが空白になる
現在の入力がメタデータを提供していません。アナログ、光/同軸、ほとんどのHDMIパススルーのソースは、曲の情報を報告しません。HEOSソースの場合は、HEOSを起動をタップして再生を開始し、戻ってくるとメタデータが表示されます。
ホーム画面のウィジェットに「AVR off」または「Standby」と表示される
これはウィジェットのオフ状態であり、不具合ではありません。クイックコントロールとステータスのウィジェット(iOSとAndroid)は、レシーバーがスタンバイのときは「Standby」、到達できないときは「AVR off」と表示し、最後の入力や音量は表示しないので、古いデータを読むことはありません。Androidでは、その状態でクイックコントロールの音量とミュートのボタンは非表示になりますが、電源ボタンは有効なままです。タップすると、ウィジェットから直接レシーバーを起動できます(レシーバーでネットワークスタンバイを有効にしておく必要があります)。ウィジェットのガイドをご覧ください。
一部のスピーカー画面がレシーバーのWebコントロールで開く
DenonやMarantzの一部のファームウェアは、スピーカーレイアウト、スピーカー距離、スピーカークロスオーバーをアプリに返しません。その場合、ページにその旨が表示され、再試行ボタンと、その画面をレシーバー自身のWebコントロールで開くボタンが付きます。使わない場合は、設定 › タブをカスタマイズでタブを非表示にしてください。レシーバーのWebコントロールのページをブラウザーで開いている場合は、レシーバーをビジー状態にすることがあるので、先に閉じてください。
シーンが完全に適用されなかった
現在の入力、信号、サウンドモードが許可しない設定は、レシーバーが拒否することがあります。確認すべき点は、シーンのガイドの、シーンが完全に適用されないときのセクションで説明しています。
サポート

ヘルプの入手とログの送信

サポートに関するすべては、設定 › AVR Maestroについてのサポートとコミュニティにあります。

  • Discordコミュニティ: MiyaraHubコミュニティに参加して、開発者に直接質問できます。
  • Facebookサポートグループ: AVR Maestroユーザーの交流とQ&A。
  • すべての関連ログ: アプリとレシーバーのすべてのログを1つのzipファイルにまとめ、すぐに送れる状態にします。
  1. 問題が起きているレシーバーに接続し、可能であれば、一度問題を再現してください。
  2. 設定 › AVR Maestroについてを開き、すべての関連ログを探します。
  3. ダウンロードをタップするとzipが保存され、共有をタップするとお好みのアプリで送信でき、メールをタップするとメールに添付できます。処理中は、アプリが収集している内容と進行状況を表示します。
  4. 何が起きたかの短い説明を添えて、zipをDiscordまたはFacebookグループで送ってください。
zipには、アプリのデバッグログと、デバイス情報や機能など、アプリがレシーバーから読み取った内容が含まれます。お使いのデバイスにメールアプリがない場合、メールは代わりに共有シートを開きます。

まだ解決しませんか?すぐにお手伝いします

設定 › AVR Maestroについてからすべての関連ログを送り、開発者にはDiscordまたはFacebookで連絡してください。返信は迅速です。

FM/AMチューナー

名前付きプリセットに対応した本格的なFM/AMラジオ

チューナー内蔵のDenon・Marantzレシーバーなら、AVR Maestroで本格的なFM/AMラジオの操作画面を使えます。局カードには現在のバンド、周波数、選択中のプリセットが表示され、レシーバーの状態にリアルタイムで追従します。

使い方

選局、スキャン、保存

  • バンド:FM / AM。選局モード:オート(次の強い局までスキャン)またはマニュアル(バンドの刻み幅で移動)。
  • 選局:2つの選局ボタンでダイヤルを1ステップずつ動かします。周波数を入力でキーパッドを開き、目的の局へ直接ジャンプできます(マニュアルモードが必要です)。
  • プリセット:プリセットスロットのグリッドと上下ステッパー。スロットを長押しすると、現在の局を保存、ラベルを追加 / 変更(「Jazz 88」「NPR」など)、ラベルを消去が行えます。
ラジオタブが非表示の場合は、設定 → ナビゲーションをカスタマイズから再度追加してください。レシーバーがチューナーを公開している場合にのみ表示されます。
よくある質問

チューナーのよくある質問

アプリからFM/AMラジオを操作できますか?
はい。チューナー内蔵のレシーバーなら、バンド・周波数・プリセットのライブ表示、FM/AMの切り替え、オートまたはマニュアルの選局、周波数へ直接ジャンプするキーパッド、プリセットグリッドを利用できます。
プリセットに名前を付けられますか?
はい。スロットを長押しすると、現在の局を保存したり、ラベル(「Jazz 88」「NPR」など)を追加・変更したり、消去したりできます。
ラジオタブが表示されないのはなぜですか?
ラジオタブは、チューナー内蔵のレシーバーでのみ表示されます。お使いの本体に搭載されている場合は、チューナーが入力として表示されていることを確認し、「設定」の「ナビゲーションをカスタマイズ」からタブを再度有効にしてください。

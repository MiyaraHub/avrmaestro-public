マルチルーム

マルチルーム：グループ、リーダー、キュー、音楽

マルチルームに対応したレシーバーでは、AVR Maestroがすべてのスピーカーを一覧表示し、グループ化と解除、グループ全体の音量設定、音楽の閲覧、検索、キューへの追加ができます。このガイドでは、画面の各部分を順に説明します。

画面

すべてのスピーカーをひとつの画面で

  • ホームのマルチルームカード（開くをタップ）またはナビゲーションから開きます。タイトルはマルチルームです。
  • 上部にはグループカードが並びます。各カードには、グループ名、再生中の内容、前へ/再生/次へ、ミュートボタン、グループ全体の音量スライダー、キューの概要が表示されます。
  • グループ未所属には、単独のスピーカーがすべて一覧表示され、それぞれにデバイスのオプションボタンがあります。
  • アプリがスピーカーを探している間はスピーカーを検索中と表示されます。接続が切れるとマルチルームとの接続が切れました。再接続中です。と表示され、復旧するまで最後に確認できたグループが表示されます。
音量

グループ音量とスピーカー音量

  • 大きなスライダーがグループ音量です。動かすと、すべてのメンバーがそろって動きます。
  • スピーカーの音量をタップすると、メンバーごとのスライダーが開き、それぞれ個別にミュートできます。静かな部屋と騒がしい部屋のバランスを取るときに使います。
  • ミュートしたスピーカーにはミュート解除が表示され、音量は0%になります。
再生

アルバムアートつきの再生中表示

  • カードには、グループが再生中の曲のアルバムアート、タイトル、アーティストがリアルタイムで表示されます。何も再生していないときは再生中のものはありませんと表示されます。
  • 前へ、再生または一時停止、次へは、グループ全体を操作します。
グループ

グループの作成、編集、解除

  • グループを作成：タップして2台以上のスピーカーにチェックを入れます（チェックするまで、シートにはスピーカーを2台以上選択してくださいと表示されます）。その後保存をタップします。2台にチェックが入ると、各行にリーダーチップが表示されます。リーダーにしたいスピーカーのチップをタップしてください。何も選ばなかった場合は、最初にチェックしたスピーカーがリーダーになります。
  • リーダー：グループの再生元となるスピーカーで、チップにリーダーと表示されます。接続中のレシーバーがリーダーの場合はこのレシーバーと表示されます。
  • グループを編集：同じシートで、メンバーやリーダーを変更できます。すでに別のグループに入っているスピーカーには別のグループに所属と表示されます。
  • グループ解除：グループを即座に削除し、すべてのメンバーがグループ未所属に戻ります。アプリはグループを削除しましたと表示して知らせます。
  • グループ名を変更：カードの鉛筆アイコンをタップします。名前が変わるのはこのアプリ内だけです。
  • 再生中のスピーカーは、グループの変更中に停止することがあります。その場合は、事前にシートで警告が表示されます。
ドラッグ&ドロップ

長押しして、追加、移動、削除

  • スピーカーのチップを長押しし、グループにドロップすると参加させられ、ルームにドロップすると移動させられます。
  • ここにドロップしてグループから削除にドロップすると、そのスピーカー1台だけをグループから外せます。
  • スピーカーが再生中の場合、グループの再生内容に切り替える前にアプリが確認します。それでも参加を選ぶと切り替わります。
音楽

音楽サービス、閲覧、お気に入り

  • グループカードの音楽をタップすると、レシーバーに設定されているサービスの一覧が開きます。ストリーミングサービス、ラジオ、プレイリスト、履歴、AUX入力などです。
  • サービスをタップすると閲覧できます。戻るで1つ上の階層に戻ります。
  • 項目に対して、今すぐ再生、次に再生、キューの最後に追加、キューを置き換えて再生ができます。
  • リストが非常に長い場合は、最初のN件を表示していますと表示されます。
  • ハート型の再生中の曲をお気に入りに追加ボタンで、再生中の曲を保存できます。同じボタンでもう一度削除できます。サービス側で変更が保持されない場合は、アプリがその旨を表示します。
  • ログインが必要なサービスにはこのサービスにはサインインが必要ですと表示されます。レシーバー本体のアプリで一度サインインしてください。音楽サービスが設定されていませんと表示された場合も同様です。
検索

音楽サービスを検索

  • 検索に対応したサービスには、検索ボックスと、検索の種類ごとのチップが表示されます。たとえばアーティスト、アルバム、トラック、プレイリストです。チップはサービス側から取得されるため、サービスごとに異なります。
  • チップを選び、入力して、検索を押します。クリアで入力欄を空にできます。
  • 一致するものがない場合は結果なしと表示されます。
  • サービスがレシーバーでサインインされていない場合、検索はデバイスが受け付けませんでした。もう一度お試しください。と表示されて拒否されます。
キュー

キュー

  • グループカードには、キューの概要（キューに3曲）と次の曲が表示されます。キューをタップすると開きます。
  • シートの名前はリーダーにちなんで付けられ、曲が順番に並びます。キューを空にするクリアボタンがあり、リピート（オフ、すべて、1曲）とシャッフルもここにあります。サービス側で再生モードが保持されない場合は、アプリがその旨を表示します。
  • キューが空の場合はキューは空ですと表示されます。スピーカーが応答しない場合はキューを読み取れませんでしたと表示されます。
ルーム

整理：ルームとデバイス名

  • 整理をタップします。ルームを追加でルームを作成でき、各スピーカーはデバイスのオプション → ルームに移動でルームに入れられます。
  • スピーカーをルームに入れたら、このルームをグループ化で、そのルームのスピーカーをまとめてグループにできます。
  • デバイス名を変更で変わるのは、このアプリ内の名前だけです。元の名前を使用で元に戻せます。
  • 複数のゾーンがあるレシーバーでは、すべてのゾーンがこのレシーバーの1台のスピーカーを共有します。そのため、グループ化はレシーバー全体に適用されます。
ホーム

ホームカードとホーム画面ウィジェット

  • ホームのマルチルームカードには、スピーカーとグループがチップとして一覧表示され、この画面を開く管理ボタンがあります。
  • スピーカーまたはグループのホーム画面ウィジェットに固定を使うと、そのスピーカーまたはグループがマルチルームウィジェットに追加されます。ウィジェットには再生中の内容が表示され、再生と音量を操作できます。アプリは<name>をマルチルームウィジェットに追加しましたと表示して知らせます。
トラブルシューティング

うまく動作しないとき

  • このレシーバーのマルチルームに接続できません：レシーバーの電源が入っていて、同じネットワークに接続されていることを確認してください。
  • スピーカーが見つかりません：レシーバーが一覧に何も表示していません。IPアドレスで接続を使い、ルーターで確認したスピーカーのIPv4アドレスを入力してください。このスピーカーを削除で再び削除できます。
  • グループ化できません：カードに理由が表示されます。たとえば、レシーバーが一覧にない、またはマルチルームに対応していない、などです。
  • グループの変更に失敗する：次のどれが起きたかをアプリが表示します。グループの一覧が変わった、スピーカーが時間内に応答しなかった、別の変更が実行中のため変更が送信されなかった、スピーカーがビジー状態、または変更が確認されなかった、のいずれかです。グループを確認して、もう一度お試しください。
よくある質問

マルチルームのよくある質問

AVR Maestroのマルチルームとは？
レシーバーが認識しているすべてのスピーカー、所属するグループ、それぞれで再生中の音楽を一覧表示する画面とホームカードです。グループごとに音量スライダーが1つあります。
グループのリーダーは何をしますか？
リーダーは、グループの再生元となるスピーカーです。ほかのメンバーはリーダーに追従します。リーダーのキューと再生中の内容が、そのままグループのものになります。
スピーカーのグループを解除するには？
マルチルームを開き、グループカードで「グループ解除」をタップします。すべてのメンバーが「グループ未所属」に戻ります。スピーカーを1台だけ外すには、そのスピーカーを長押しして「ここにドロップしてグループから削除」にドロップします。
検索で「デバイスが受け付けませんでした」と表示されるのはなぜですか？
その音楽サービスがレシーバーでサインインされていません。レシーバー本体のアプリで一度サインインしてから、AVR Maestroでもう一度検索してください。
どのレシーバーが対応していますか？
マルチルームに対応し、マルチルームの一覧に表示されるレシーバーです。表示されないレシーバーは、理由とともに「グループ化できません」の下に一覧表示されます。

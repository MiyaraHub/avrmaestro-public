はじめに

スマートフォンからDenonやMarantzを操作

AVR Maestroは、ネイティブプロトコルを使ってローカルネットワーク経由でレシーバーと通信します。クラウドアカウントも追加のハードウェアも不要です。短いウェルカムガイドに従えば、数分で接続して最初のシーンを作成できます。

初回起動

セットアップを進める5ステップのウェルカムガイド

AVR Maestroを初めて開くと、短いガイドがゼロから最初のシーンまで案内します。上部のバーで進み具合が分かり、戻るで前のどのステップにも戻れます。自分で試したい場合は、いつでもスキップできます。

  1. ようこそ。AVR Maestroは、ご自宅のネットワークを通じてDenonやMarantzをフルにコントロールでき、クラウドを一切経由しません。できないことも明確にしています。独立したアプリであり、キャリブレーションツールでもストリーミングアプリでもないので、始める前に何を期待できるかが分かります。
  1. レシーバー。アプリがネットワークをスキャンし、見つかったレシーバーをすべて一覧表示します。お使いのものをタップして追加してください。複数台ある場合は、さらに追加できます。何も表示されませんか?IPアドレスで追加を使うか、代わりにデモを試すをタップして、すぐに試せるシーンが用意されたデモ用レシーバーで操作を体験してください。
  1. 各機能の場所。アプリの簡単な案内図です。ホームは全ゾーンの電源、音量、入力、サウンドはサウンドモード、Audyssey、Dirac、シーンは保存したセットアップです。
  1. シーン。ワンタップでシーンができること、そしてレシーバー標準のSmart SelectやQuick Selectのスロットをどう超えるのかを紹介します。最大20個のシーン、ホーム画面のウィジェットとショートカット、そしてレシーバーがすべての設定を本当に反映したかどうかを後から確認する機能です。最初のシーンを作成をタップすると、シーン作成ツールがその場で開きます。
  1. 準備完了です。ヘルプの入手先として、Discordコミュニティとフェイスブックのサポートグループを案内します。うまくいかない場合は、設定 → アプリについて → 関連するすべてのログからログを共有する方法も確認できます。
もう一度ツアーを見たい、あるいは新しいレシーバーにアプリをセットアップしたいときは、設定 → ウェルカム&セットアップガイドをいつでも開いてください。設定もご覧ください。
始める前に

必要なもの

  • レシーバーと同じネットワーク上にある、iPhone、iPad、Mac、Androidのスマートフォンまたはタブレット、あるいはWindows PC。
  • アプリが電源を入れて接続できるよう、ネットワークスタンバイを有効にしたレシーバーの電源が入っていること(セットアップ → 一般 → ネットワーク → ネットワークコントロール → オン)。
  • それ以外は不要です。アプリがネットワーク上のレシーバーを自動で見つけます。ネットワークの設定で機器同士が見えない場合は、代わりにレシーバーのIPアドレス(セットアップ → 一般 → ネットワーク → 情報)を使います。
  • オプション: Wake-on-LANを有効にすると、完全なスタンバイ状態からレシーバーの電源を入れられます。
後からレシーバーを追加する

レシーバーが複数台ありますか?

  1. 設定 → デバイスを開き、レシーバーを追加をタップします。
  2. 画面がネットワークをスキャンし、応答したDenonとMarantzのレシーバーをすべて一覧表示します。お使いのものをタップし(何も応答しない場合はIPアドレスを入力し)、アプリがHTTP、Telnet、HEOSを確認します。
  3. 検出されたモデルと機能を確認して、保存します。
  4. レシーバーの切り替えは、設定 → デバイスからいつでも行えます。アプリが記憶しているのはアドレスではなくレシーバー自体です。ルーターによってアドレスが変わっても、アプリが追従し、一度だけお知らせします。
トラブルシューティング

接続できない場合

接続の問題の多くはネットワークに起因します。スマートフォンとレシーバーが別のサブネットにある、間にゲストネットワークやIoT用VLANがある、レシーバーのネットワークコントロールがオフになっている、などです。ヘルプとトラブルシューティングのページでは、接続テストが失敗する場合、接続が頻繁に切れる場合、お使いのレシーバーが対応しているかの確認方法を順に説明しています。

設定:自分好みにカスタマイズ

AVR Maestroをあなたとお手持ちの機器に合わせるためのすべてがここにあります。レシーバーの管理、カラーテーマによるアプリ全体のテーマ設定、音量ステップの調整、サポート用のデバッグログの取得、設定全体のファイルへのバックアップ。

アプリの外でも

ホーム画面ウィジェットとデバイスの音量ボタン

  • ホーム画面ウィジェット(iOSとAndroid):クイックコントロール(電源 / 音量 / ミュート / ソース)、再生中、ステータス。複数のサイズがあり、タップのみで操作でき、自動で更新されます。レシーバーがオフのとき、または到達できないときは、古い入力や音量ではなく「AVR off」/「スタンバイ」とはっきり表示されます。電源ボタンは操作可能なままなので、ウィジェットから直接レシーバーを起動できます。
  • デバイスの音量ボタン(AndroidとiOS):AVR Maestroが前面にある間は、デバイスの物理的な音量ボタンでレシーバーの音量を操作できます(音量ステップの設定が使われます)。長押しで連続変化します。前面にある間のみ有効で、アプリが別のアプリの背面に回ると、ボタンはすぐにデバイス本来の動作に戻ります。「設定」の「オーディオ」にあるスイッチで、この切り替えをオフにできます。
ウィジェット、テーマ設定、バックアップ & 復元、音量ボタンの連動は、すべてiOSとAndroidの両方で動作します。
よくある質問

設定のよくある質問

アプリのテーマや色を変更できますか?
はい。ライト、ダーク、デバイス、AMOLED(真っ黒)に加え、好きなアクセントカラーを選ぶとアプリがパレットを作り直すカラーテーマがあります。カラーホイールを使うか、16進コード(#FF8C00、または3桁の短縮形)を入力してください。コードが正しくない場合、アプリは単に拒否するのではなく、何が問題なのかをお伝えします。ディスプレイ/ウィジェットサイズの設定や、ナビゲーションとタブのカスタマイズも可能です。
設定をバックアップできますか?
はい。「設定」の「バックアップ」で、すべてのレシーバー、プリセット、環境設定を.zipファイルにエクスポートできます。カスタム入力アイコンも一緒に含まれ、新しいスマートフォンでインポートすれば復元できます。古い.jsonバックアップも問題なくインポートできます。ファイルに認証情報は含まれないため、共有しても安全です。
音量プリセットは、目標値に直接ジャンプしますか、それとも徐々に変化しますか?
お好みで選べます。「設定」の「オーディオ」に「緩やか / 直接」の切り替えがあります。「緩やか」(デフォルト)は、プリセットの目標値に向かって滑らかに変化するため、タップした瞬間に音量が急に跳ね上がってスピーカーに負担をかけることがありません。「直接」は即座に適用されます。メインゾーンとZone 2/3で動作します。
アプリからレシーバーの物理リモコンをロックできますか?
はい、対応しているレシーバーでは可能です。「設定」の「レシーバー」にリモコンロックのスイッチがあり、レシーバー自体のIRリモコンをロックまたは解除できます。
ホーム画面ウィジェットはAndroid専用ですか?
いいえ。クイックコントロール(電源 / 音量 / ミュート / ソース)、再生中、ステータスの各ウィジェットは、iOSとAndroidの両方で利用できます。レシーバーがオフのとき、または到達できないときは、古い情報ではなく「AVR off」/「スタンバイ」とはっきり表示されます。クイックコントロールの電源ボタンは操作可能なままなので、ウィジェットからレシーバーを起動できます。
スマートフォンの音量キーでレシーバーを操作できますか?
Androidでは可能です。アプリが前面にある間は、音量キーでレシーバーの音量を操作できます。iOSではこの動作は許可されていません。
非表示のデバッグメニューはどうやって開きますか?
「設定」の「バージョン情報」を開き、バージョン番号を7回タップします。デバッグメニューは、「デバッグメニューを削除」をタップして再び非表示にするまで、起動後も利用できます。ライブのデバッグログのほか、サポート用のローコマンドツールや診断機能があります。
「MiyaraHubの他のアプリ」とは何ですか?
「設定」にあるセクションで、当社のすべてのアプリを見るボタンがあります。タップするとアプリストアが開き、MiyaraHubのデベロッパーページが表示されます。お使いのデバイスに応じて、Google Play、App Store、Microsoft Storeのいずれかが開き、当社のすべてのアプリを閲覧できます。

設定、セクションごとに

設定 › 外観

お好みの見た目に

  • テーマ:ライト、ダーク、AMOLED(真っ黒)。
  • アクセントカラー:ブランドは、おなじみのオレンジを維持します。カラーテーマはピッカーを開きます。好きな色を選ぶか、#FF8C00のような16進コード(または3文字の省略形)を入力すると、アプリがその色を中心にパレットを作り直します。アプリが読み取れないコードは理由とともに拒否され、ほぼ黒に近い色は、AMOLEDテーマでは背景に対して見えなくなるため拒否されます。スイッチの横の丸い色見本をタップすると、ピッカーが再び開きます。
  • 表示サイズ:小からデフォルト、XLまで、アプリの文字サイズを調整するスライダー。
  • ウィジェットサイズ:小、中、大、特大。アプリ内のカード、ボタン、余白を調整します。
  • ハイコントラストウィジェットとウィジェットをアプリの色に合わせる(スマートフォンとタブレット): ホーム画面ウィジェットの色を決めます。ハイコントラストはグレースケールを使い、そうでなければウィジェットはおなじみのオレンジ、またはウィジェットをアプリの色に合わせるがオンのときはカラーテーマのアクセントを使います。ウィジェットのガイド →
  • 言語:システムのデフォルトはデバイスの設定に従います。または、アプリの言語をその言語自身の名前で選べます。言語のガイド →
設定 › レイアウト

タブを選ぶ

  • ナビゲーションをカスタマイズ:下部のバーに置くタブを選び、ドラッグして好きな順序に並べます。プレビューで結果を確認できます。保存で確定し、リセットでデフォルトに戻ります。
  • タブをカスタマイズ:タブ内で使わないサブビューを非表示にします。

設定 › ヘルプ

説明カード、ようこそガイド、このマニュアル

  • 説明カードを表示:多くのページには、内容を説明する短いバナーがあります。バナーをタップすると展開し、長押しすると非表示になります。このスイッチをオフにすると、アプリ全体のすべてのバナーが非表示になります。
  • 閉じたカードを復元:長押しして消したバナーを一覧表示します。ひとつずつ復元をタップするか、すべて復元をタップします。非表示のものがない場合は閉じたカードはありませんと表示されます。
  • ようこそ&セットアップガイド:初回起動時に表示されたイントロとネットワーク設定のヒントを再生します。はじめに →
  • アプリマニュアル:このオンラインのユーザーガイドを開きます。

特定の設定をすばやく見つけるには、スクロールする代わりに検索を使ってください。検索のガイド →

設定 › バックアップ&アプリについて

バックアップ、評価、サポート

  • バックアップと復元:アプリのすべての設定をファイルにエクスポートするか、バックアップから復元します。バックアップのガイド →
  • AVR Maestroを評価:ストアのページを開いて、評価を残せます。
  • AVR Maestroについて:バージョン情報、サポート、ライセンス。Discordコミュニティ、Facebookサポートグループ、そして問題が起きたときに必要なログをまとめるすべての関連ログはここにあります。
  • MiyaraHubのその他のアプリ:お使いのデバイスのストアにあるMiyaraHubのページを開き、ほかのホームシアターアプリを紹介します。
よくある質問

設定のよくある質問

設定 › デバイスと設定 › オーディオはどこへ行きましたか?
バージョン5.3.0から、どちらもレシーバーごとの設定になりました。設定 › レシーバーを管理を開いてレシーバーをタップすると、そのページに、オーディオセクション(音量ステップ、音量表示、音量プリセット、デバイスの音量ボタン、音量コントロール)、画面&ロック、このレシーバーについて、そして名前の変更、IPを変更、レシーバーを検索、削除があります。
アプリのテーマや色を変更できますか?
はい。設定 › 外観で、テーマはライト、ダーク、AMOLED(真っ黒)から選べ、アクセントカラーはブランドまたはカラーテーマから選べます。カラーテーマでは、ピッカーから、または#FF8C00のような16進コードやその3文字の省略形を入力して、好きなアクセントカラーを選べます。アプリが読み取れないコードは理由とともに拒否され、ほぼ黒に近い色は、AMOLEDテーマでは見えなくなるため拒否されます。
スマートフォンの音量ボタンでレシーバーを操作できますか?
はい。AndroidとiPhone、iPadで使えます。アプリを開いている間は、デバイスの音量ボタンでレシーバーの音量を変更できます。デフォルトでオンで、レシーバーごとに設定します: 設定 › レシーバーを管理 › お使いのレシーバー › オーディオ › デバイスの音量ボタン。
閉じた説明カードを元に戻すには?
設定 › ヘルプを開きます。閉じたカードを復元には、長押しして消したカードがすべて一覧表示されます。ひとつずつ復元をタップするか、すべて復元をタップします。説明カードを表示で、すべてを一度にオフまたはオンにできます。
ようこそガイドをもう一度見るには?
設定 › ヘルプ › ようこそ&セットアップガイドを開きます。イントロとネットワーク設定のヒントが再生されます。同じセクションのアプリマニュアルで、このオンラインガイドが開きます。
設定をバックアップできますか?
はい。設定 › バックアップと復元で、アプリのすべての設定をファイルにエクスポートし、バックアップから復元できます。ファイルの内容は、バックアップと復元のガイドをご覧ください。
非表示のデバッグメニューはどうやって開きますか?
設定 › AVR Maestroについてを開き、バージョン番号を7回タップします。デバッグメニューが表示され、デバッグメニューを削除で取り除くまで使えます。これはサポート用です。ログを送るには、同じページのすべての関連ログを使ってください。

1つのアプリで29言語

すべての画面、すべての設定、すべてのダイアログがあなたの言語で表示されます。アプリは初期状態で端末の言語に従い、設定から好きな言語を選ぶこともできます。ヘブライ語とアラビア語ではレイアウト全体が左右反転します。DenonとMarantzの公式アプリが対応しているのは、英語を含めこのうち11言語。残りの18言語はAVR Maestroだけの対応です。

設定の場所

設定 › 言語

設定を開き、言語をタップします。システムのデフォルトは端末の言語に従います。その下にはすべての言語がそれぞれの言語名で並んでいるので、他の言語を読まなくても自分の言語を見つけられます。選択はすぐに反映され、再起動後も保持され、バックアップ&復元にも含まれます。

ヘブライ語とアラビア語では、アプリ全体の向きが反転します。ナビゲーション、カード、リスト、スライダーが左右反転し、dBや音量の表示はその中でも左から右の向きのままです。

よくある質問

言語に関するよくある質問

アプリはスマートフォンの言語に自動で合わせてくれますか?
はい。初期状態では端末の言語に従います。自分で選ぶには、設定 › 言語を開いてください。「システムのデフォルト」を選ぶと、選択が端末に戻ります。
ヘブライ語とアラビア語は右から左のレイアウトになりますか?
はい。ナビゲーション、カード、リスト、スライダーを含むアプリ全体が左右反転します。ただし、dBや音量の表示は、その中でも左から右の向きのままです。
入力名やサウンドモードが英語のままなのはなぜですか?
それらはアプリではなく、レシーバー自身の表記だからです。入力名、サウンドモード、Dolby Atmos、Audyssey、Smart Select、HEOSといったブランド名やフォーマット名、そしてレシーバーが報告するすべての値は、レシーバーが示すとおりに表示されます。翻訳されるのは、アプリ自身の文言だけです。
言語の設定はバックアップに含まれますか?
はい。選択した言語はバックアップ&復元の対象なので、復元したスマートフォンでも以前の言語で起動します。

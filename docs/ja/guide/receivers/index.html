レシーバーを管理、レシーバーごとに1ページ

お持ちの数だけDenonとMarantzレシーバーを追加し、2タップで切り替えて、それぞれに専用のオーディオ設定を持たせられます。すべてのレシーバーに、名前、アドレス、ロック、ファームウェア用の専用ページがあります。

設定の場所

レシーバーを管理を開く

設定を開きます。一番上のカードがレシーバーを管理で、レシーバーの台数とアクティブなレシーバーが表示されます。これをタップします。

表示される内容: 「レシーバーをタップしてセットアップ。丸をタップしてアクティブにします。ドラッグして並べ替えます。」という行と、名前、IPアドレス、モデルが付いたレシーバーの一覧。アクティブなレシーバーは強調表示され、丸が塗りつぶされます。一覧の下にはレシーバーを追加ボタンがあり、すでにデモモード中でなければデモモードセクションがあります。

  • レシーバーをタップすると、そのレシーバー専用のページが開きます。
  • 行の先頭の丸をタップすると、そのレシーバーがアクティブになります。アプリが切り替えましたとレシーバー名で知らせます。
  • 行の末尾のハンドルをドラッグすると、順序を変更できます。ホームの上部にあるレシーバーの一覧も、同じ順序に従います。
  • レシーバーを長押しすると、名前の変更、IPを変更、レシーバーを検索、削除のクイックメニューが表示されます。
手順

レシーバーを追加

  1. 設定 › レシーバーを管理を開き、レシーバーを追加(または右上の+)をタップします。
  2. iPhone、iPad、Mac、Android、Windowsでは、画面がネットワークをスキャンし、ネットワーク上で見つかったレシーバーを一覧表示します。お使いのレシーバーをタップしてください。何も応答しない場合は、再スキャンをタップするか、IPアドレスにレシーバーのアドレスを入力してテストして保存をタップします。
  3. アプリは接続をテストし、レシーバーをまとめて保存します。検出されたモデルと機能が表示され、新しいレシーバーがアクティブになります。
レシーバーのIPアドレスは、レシーバー自身のメニューのSetup › General › Network › Informationにあります。スマートフォンやコンピューターは、レシーバーと同じネットワークに接続している必要があります。ネットワークのチェックリストははじめにをご覧ください。
2タップ

ホームからレシーバーを切り替え

  1. ホームタブで、画面上部のAVR Maestroの横に表示されているレシーバー名をタップします。
  2. レシーバーの一覧が開き、アクティブなレシーバーにチェックが付いています。別のレシーバーをタップすると切り替わります。一覧の下部にあるレシーバーを管理をタップすると、フルページが開きます。

各レシーバーは自分のデータをお使いのデバイスに保持しているので、切り替えるとすぐにそのレシーバーの設定が読み込まれます。

設定 › レシーバーを管理 › お使いのレシーバー

レシーバーのページ

レシーバーをタップすると、そのページが開きます。上部のカードに、接続状態と詳細が表示されます。アクティブなレシーバーでない場合は、カードの下にアクティブにするボタンがあります。音量制限、表示、ロックは、アクティブなレシーバーでのみ変更できるためです。アクティブでも到達できない場合、ページには「アプリは現在レシーバーに接続していません。」と表示されます。

オーディオ

このレシーバーに対するお好みの設定です。各レシーバーが自分の値を保持します。音量のガイド →

  • 音量ステップ:1回押すと音量がどれだけ動くか。0.5、1、1.5、2 dBから選びます。アプリ内のすべての音量ボタンがこれを使います。
  • 絶対音量を上に表示:音量表示で、どちらの数値を大きくするかを入れ替えます。オフ(デフォルト)ではdBが大きく、音量スケールが小さく表示され、オンでは音量スケールが大きく、dBが小さく表示されます。
  • リモコンの音量表示:リモコンタブにdBスケール(絶対値(dB)、例: -40.5 dB)を表示するか、0-98スケール(相対値、例: 39.5)を表示するか。
  • 音量プリセットを緩やかに変化:オン(デフォルト)では、音量プリセットをタップすると小刻みなステップで音量が変化し、オフでは保存したレベルに直接切り替わります。
  • デバイスの音量ボタン(スマートフォンとタブレット): アプリを開いている間、デバイス本体の音量ボタンでレシーバーの音量を変更します。デフォルトでオンです。オフにすると、ボタンはデバイスに戻ります。
  • 音量コントロール:音量制限、電源オン時の音量、ミュートの深さを、レシーバー自体に書き込みます。アプリがこのレシーバーに接続している間のみ表示されます。音量コントロールのガイド →

画面とロック

接続中のアクティブなレシーバーに表示されます。

  • オンスクリーンディスプレイ:音量表示、情報バナー、再生中、21:9。オンスクリーンディスプレイのガイド →
  • セットアップロック:レシーバー本体のセットアップメニューをロックします。ロックされている間は、オーディオ、ビデオ、スピーカーなどのセットアップ設定は、レシーバーのメニューでも、このアプリでも、Webポータルでも、どこからも変更できません。音量、入力、ディマーなどの日常的なコントロールは引き続き使えます。オンにする前に確認が表示され(レシーバーメニューをロックしますか?、次にロック)、スイッチをオフにするとロックが解除されます。
  • リモートロック:ロックを解除するまで、レシーバーが赤外線リモコンのボタン操作を無視するようにします。アプリと前面パネルは引き続き使えます。
セットアップロックとリモートロックは、レシーバーがその状態を報告する場合にのみ表示されます。レシーバーがロックを報告しない場合、スイッチは推測で表示されず、非表示になります。セットアップロックが原因でアプリの他の場所でグレーアウトしているコントロールについては、コントロールがロックされる理由で説明しています。

このレシーバーについて

  • デバイス情報:レシーバーの詳細なステータス。
  • ファームウェア:インストールされているファームウェアのバージョン。確認をタップすると、アップデートがあるかをレシーバーに問い合わせます。その下の行に、最新のファームウェアであること、アップデートがあること、アップデートが進行中であること、またはステータスを読み取れなかったことが表示されます。アップデートはアプリからではなく、レシーバー自身のSetupメニューからインストールします。アップデート中はレシーバーの電源を切らないでください。

管理

  • 名前の変更:デバイス名に新しい名前を入力して、保存をタップします。名前はアプリ内にのみ保存されます。
  • IPを変更:たとえばルーターが新しいアドレスを割り当てた後に、新しいIPアドレスまたはホスト名を入力して保存をタップします。レシーバーの保存済み設定はすべて維持され、変わるのはアドレスだけです。ほかのレシーバーですでに使われているアドレスは受け付けられません。
  • レシーバーを検索:このレシーバーの新しいアドレスをネットワークから探します。別の場所でレシーバーが見つかった場合は、このアドレスを使用をタップします。保存済みのアドレスがすでに正しい場合、何も応答がなかった場合、複数のレシーバーが該当しうる場合はその旨が表示され、最後の場合は何も変更されないので、代わりにIPを変更を使います。
  • 削除:レシーバーを削除しますか?と確認し、レシーバーとそのすべての保存済み設定をアプリから削除します。アクティブなレシーバーを削除すると、アプリは別のレシーバーに切り替わります。
レシーバー不要

デモモードの開始と終了

デモモードは、アプリ内でシミュレートされたMarantz CINEMA 30を動かします。すべての画面が実機と同じように動作し、ネットワークには何も送信されません。

  1. 開始は、設定 › レシーバーを管理 › デモモードを試す、レシーバーを追加画面のデモモードを試す、またはようこそガイドの代わりにデモを試すから行えます。デモ用レシーバーがアクティブになり、アプリがホームを開きます。
  2. Proをプレビュー。デモの実行中、設定にデモモードセクションが表示されます。そのPro機能をプレビュースイッチで、このデモセッションに限り、ホームオートメーションとトリガーが解除されます。購入は発生しません。
  3. 終了は設定 › デモモードを終了から行います。デモ用レシーバーが削除され、アプリはお使いのレシーバーに戻ります。
よくある質問

レシーバー、よくある質問

別のレシーバーに切り替えるには?
ホームタブで、上部のAVR Maestroの横にあるレシーバー名をタップし、一覧から別のレシーバーを選びます。設定 › レシーバーを管理を開いて、レシーバーの行の先頭にある丸をタップしても切り替えられます。アプリは、切り替えましたとレシーバー名で知らせます。
レシーバーのIPアドレスが変わりました。どうすればいいですか?
通常は何もしなくて大丈夫です。ルーターがレシーバーのアドレスを変更すると、アプリが再びレシーバーを見つけ、追従したことを一度だけお知らせします。見つからない場合は、設定 › レシーバーを管理を開いてレシーバーをタップし、レシーバーを検索でネットワークを検索するか、IPを変更で新しいアドレスを自分で入力してください。レシーバーの保存済み設定はすべて維持され、変わるのはアドレスだけです。
画面&ロックやこのレシーバーについてが表示されないのはなぜですか?
これらのセクションはレシーバーをライブで読み書きするため、アプリが接続しているアクティブなレシーバーにのみ表示されます。アクティブにするでレシーバーをアクティブにして、接続されるまでお待ちください。
セットアップロックとリモートロックの違いは何ですか?
セットアップロックはレシーバー本体のセットアップメニューをロックするので、ロックを解除するまで、このアプリを含め誰も、セットアップやキャリブレーションの設定を変更できません。音量と入力は引き続き使えます。リモートロックは、レシーバーが赤外線リモコンを無視するようにします。アプリと前面パネルは引き続き使えます。それぞれのスイッチは、レシーバーがそのロックを報告する場合にのみ表示されます。
レシーバーを削除するとどうなりますか?
アプリはレシーバーと、そのレシーバーのすべての保存済み設定を削除します。それがアクティブなレシーバーだった場合は、別のレシーバーに切り替わります。レシーバー本体は何も変更されず、いつでも再び追加できます。
レシーバーがなくてもアプリを試せますか?
はい。設定 › レシーバーを管理のデモモードを試す、またはレシーバーを追加画面のデモモードを試すをタップします。デモモードはアプリ内でシミュレートされたMarantz CINEMA 30を動かし、ネットワークには何も送信しません。終了は設定 › デモモードを終了からできます。

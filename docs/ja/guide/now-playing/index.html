再生中

再生中: 今かかっている曲を1画面で

ソースがメタデータを送信している場合、AVR Maestroの「再生中」カードはアルバムアート、曲名、再生操作をホーム画面にそのまま表示し、音楽を閲覧、検索、キュー追加したいときはMulti-Room画面を開きます。

聴いているものすべてを、1枚のカードに

カードの見出しはメディアプレーヤーです。何も再生していないときは再生中のメディアはありませんと表示されます。

  • アルバムアートと曲情報:再生中のもののカバー、曲名、アーティストまたは局名。
  • 再生コントロール:前へ、プレーヤーの実際の状態に追従するひとつの再生 / 一時停止ボタン、停止、次のトラック。別のアプリやレシーバーで一時停止または再生すると、ボタンもそれに追従します。
  • お気に入り：Multi-Roomお気に入りを開き、アプリを離れずにレシーバーで1曲を再生します。レシーバーのプレーヤーが接続されているときに表示されます。
  • Multi-Roomボタン：スピーカーグループのアイコンでMulti-Room画面が開き、スピーカーのグループ化や、アプリ内での音楽の閲覧、検索、キュー追加ができます。
  • HEOSを起動：公式のHEOSアプリを使いたい場合に開きます。そこで再生を始めると、AVR Maestroが再生中の表示、再生操作、ウィジェットを引き継ぎます。
  • ホームと各ゾーン：このカードはホーム画面にあり、各ゾーンのカードにはそのゾーンのプレーヤー用のカードが表示されます。
手順

お気に入りを再生する

  1. 再生中カード(ホーム、またはゾーンのカードならそのゾーン)で、お気に入りをタップします。
  2. Multi-Roomお気に入りの一覧が開きます。再生したいものをタップします。
  3. 一覧が閉じ、再生中とその名前が表示されます。音楽が始まると、カードの内容が更新されます。
一覧はレシーバーに保存されているお気に入りです。HEOSお気に入りはまだありませんと表示された場合は、HEOSアプリでいくつか追加してから一覧を開き直してください。プレーヤーを利用できませんと表示された場合は、そのゾーンのレシーバーのプレーヤーに現在アクセスできません。
停止は停止です

停止するとカードが消去されます

停止をタップすると、カードがホーム画面ウィジェットとともにすぐに消去され、そのままの状態を保ちます。レシーバーが記憶している最後の曲が戻ってくることはありません。何かの再生が実際に始まると、すぐにカードが再び表示されます。

カードは、メタデータを送信するネットワークソースで表示されます。アナログ、光/同軸、HDMIパススルーのソースは曲情報をレシーバーに送らないため、これらではカードは空のままです。原因はソースであり、アプリではありません。
よくある質問

再生中に関するよくある質問

再生中の内容は表示されますか?
はい。メタデータを送信するソースでは、アルバムアート、曲名、アーティストまたは局名と、再生操作（再生、一時停止、次へ、前へ）がレシーバーからリアルタイムで表示されます。
音楽はどうやって探せますか?
「再生中」カードのMulti-Roomボタンをタップすると、AVR Maestro内で音楽サービスの閲覧、検索、キューの管理ができます。HEOS公式アプリを使いたい場合は、HEOSを起動で引き続き開けます。保存したお気に入りを再生するには、代わりにお気に入りをタップします。
お気に入りを再生するには？
「再生中」カードのお気に入りをタップします。Multi-Roomお気に入りの一覧が開くので、1つ選ぶとAVR Maestroを離れずにレシーバーで再生されます。ゾーンのカードでは、そのゾーンで再生されます。
停止をタップするとどうなりますか?
カードとホーム画面ウィジェットはすぐに消去され、そのままの状態を保ちます。何かの再生が始まったときにのみ、再び表示されます。
入力によってカードが空なのはなぜですか?
アナログ、光/同軸、HDMIパススルーのソースは曲のメタデータを送信しないため、表示できる情報がありません。カードは、メタデータを送信するネットワークソースで表示されます。
再生中カードはどこにありますか?
ホーム画面にあり、音量、ソース、サウンドモード、ゾーンなど、選んだウィジェットと並んで表示されます。

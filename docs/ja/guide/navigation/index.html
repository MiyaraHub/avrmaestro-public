画面の移動

タブ、スワイプ、ジェスチャー

AVR Maestroの使い方: 下部のタブとその変更方法、ページ間のスワイプ、タップと長押しの動作、戻るボタン、アップデートの通知、メッセージ、そしてコンピューターでのキーボードショートカット。

下部のタブ

画面下部のバーに、メインのタブが並びます。初期状態では、ホーム、リモコン、サウンド、ゾーン、シーン、スピーカー、設定です。ラジオも追加できます。検索ボタンは、すべてのタブでバーの右端にあります(検索をご覧ください)。

  • ホームは常に含まれ、常に先頭です。
  • ラジオは、選択中のレシーバーにチューナーがある場合にのみ表示されます。ラジオをご覧ください。
  • タブは2から7個まで設定できます。
手順

タブの追加、削除、並べ替え

  1. 設定 › ナビゲーションをカスタマイズを開きます。上部にバーのプレビューが表示されます。
  2. 利用可能なタブで、タブにチェックを入れると追加、外すと削除されます。
  3. アクティブなタブで、行のハンドルをドラッグして順序を変更します。
  4. 保存をタップします。ナビゲーションを更新しましたというメッセージで確認できます。リセットで、デフォルトのタブと順序に戻ります。
手順

使わないサブタブを非表示にする

サウンド、スピーカー、リモコンの各タブには、上部にサブタブの列があります。たとえばサウンドには、Audyssey、Dirac Live、グラフィックEQ、チャンネル、トーンがあります。

  1. 設定 › タブをカスタマイズを開きます(使わないサブビューを非表示)。
  2. サウンド、スピーカー、リモコンの下で、不要なサブビューをそれぞれオフにします。結果はプレビューで確認できます。
  3. 戻ります。変更はすべてのレシーバーに適用されます。
レシーバーが機能に対応していない場合(たとえばAudysseyのないレシーバーのAudyssey)、そのサブタブはすでに非表示で、ここには一覧表示されません。タブをカスタマイズは、その上に重ねる2段目の設定です。

ページ間をスワイプ

  • ページを左右にスワイプすると、次または前のサブタブに移動します。
  • 最後のサブタブでさらにスワイプすると、次の下部タブに進みます。最後のタブの先は、設定した順序で最初のタブに戻ります。
  • 下部のタブバーをスワイプすると、タブを直接切り替えられます。こちらも最後まで行くと最初に戻ります。
  • スライダーのあるページでは、ゆっくりドラッグするとスライダーが動きます。ページを切り替えるには、素早く、ほぼ横方向にはじいてください。

iPhone、iPad、Macで1つ前に戻るスワイプ

ガイド付きのシーン作成ツール、ようこそ&セットアップガイド、Home Assistantのサインインページでは、画面の左端から内側にスワイプすると1つ前の手順に戻ります。右から左へ書く言語では、右端から内側にスワイプします。半分以上スワイプするか、素早くはじいてください。

タップと長押し

多くのコントロールは、タップと長押しで別の動作をします。

  • 音量プリセット。プリセットスロットは8つあります。+が付いた空のスロットをタップすると、現在の音量が保存されます。保存済みのスロットをタップすると、その音量に切り替わります。スロットを長押しすると、現在の音量で上書き保存するか、消去できます。切り替えではなくフェードさせたい場合は、設定 › レシーバーを管理 › お使いのレシーバー › オーディオで音量プリセットを緩やかに変化をオンにします。音量をご覧ください。
  • Quick SelectとSmart Select。スロットをタップすると呼び出します。長押しすると、現在の状態を保存または名前を変更ができます。
  • ホームの入力グリッド。長押しすると、グリッドの編集が始まります。ホーム画面をご覧ください。
  • リモコンの入力。入力を長押しすると、カスタムアイコンを設定できます。カスタムアイコンをご覧ください。
  • ゾーン名。ゾーン名を長押しすると、名前を変更できます。マルチゾーンをご覧ください。
  • ラジオのプリセット。タップで呼び出し、長押しで現在の局を保存します。ラジオをご覧ください。
  • シーン。タップで適用し、長押しでオプションを表示します。シーンをご覧ください。
  • レシーバー。設定 › レシーバーを管理で、レシーバーを長押しするとオプションが表示されます。
  • 説明カード。バナーをタップすると展開し、長押しすると非表示にします。非表示にしたカードは設定 › 非表示にしたカードを復元から戻せます。

戻る、終了、メッセージ

  • サブページで戻るを押すと、タブの最上部に戻ります。ホームの編集中は、戻るを押すとまず編集モードを終了します。
  • タブの最上部で戻るを押すと、AVR Maestroを終了しますか?と表示されます。アプリを終了をタップするとアプリが閉じ、キャンセルをタップするとそのままです。これはAndroidの戻るボタンと戻るジェスチャーに適用されます。
  • 画面下部のメッセージには閉じるボタンがあります。エラーメッセージは、閉じるまで残ります。その他のメッセージは数秒後に自動で閉じ、長いメッセージほど長く表示されます。新しいメッセージが表示されると、画面上のメッセージは置き換わります。
スマートフォンのアクセシブルなナビゲーション設定がオンの場合、すべてのメッセージは閉じるまで残ります。

アップデートがあるとき

AVR Maestroの新しいバージョンが公開されると、ホーム画面にアップデートがありますと表示されます。

  • アップデートで、Google Play、App Store、またはMicrosoft Storeのアプリのページが開きます。
  • 後でを選ぶと、通知が3日間非表示になります。
  • このバージョンをスキップを選ぶと、そのバージョンの通知が表示されなくなります。
必須とされたバージョンの場合、通知にはアップデートが必要ですと表示され、アップデートボタンのみで、閉じることはできません。

WindowsとMacのキーボードショートカット

WindowsではCtrl、MacではCmdを使い、次のキーと組み合わせます。

  • 上 / 下矢印: 音量を上げる / 下げる
  • M: ミュートのオン / オフ
  • Space: 再生または一時停止
  • 右 / 左矢印: 次または前のトラック
  • ピリオド(.): 停止

キーボードのメディアキー(再生、一時停止、次へ、前へ、停止、音量、ミュート)も使えます。

テキストフィールドに入力している間は、ショートカットは何もしません。ミュートと再生/一時停止は、レシーバーが現在の状態を報告するまで待機します。

プラットフォーム別の注意

  • Android:戻るを押すと、終了前に確認が表示されます。アプリを開いている間は、スマートフォンの音量ボタンでレシーバーの音量を変更できます(デバイスの音量ボタン、レシーバーごと、デフォルトでオン)。
  • iPhoneとiPad:ガイド付きの手順では、端から内側にスワイプすると1つ前に戻ります。デバイスの音量ボタンもここで使えます。
  • Mac:端からのスワイプで1つ前に戻る、Cmdショートカット、メディアキー。
  • Windows:Ctrlショートカットとメディアキー。
よくある質問

ナビゲーション、よくある質問

AVR Maestroの下部に表示するタブを変更するには?
設定 › ナビゲーションをカスタマイズを開きます。「利用可能なタブ」でタブのチェックを外すと削除、チェックを入れると追加、「アクティブなタブ」の行をドラッグすると順序を変更できます。最後に「保存」をタップします。ホームは常に含まれ、常に先頭です。タブは2から7個まで設定できます。
IMAXやAuro-3Dなど、使わないサブタブを非表示にするには?
設定 › タブをカスタマイズを開き、サウンド、スピーカー、リモコンの下で不要なサブビューをオフにします。この設定はすべてのレシーバーに適用されます。レシーバーが対応していない機能はすでに非表示で、ここには一覧表示されません。
ラジオタブがないのはなぜですか?
ラジオは設定 › ナビゲーションをカスタマイズで追加できますが、選択中のレシーバーにチューナーがある場合にのみタブが表示されます。
タブ間をスワイプで移動できますか?
はい。ページを左右にスワイプすると、サブタブを移動できます。最後のサブタブで次にスワイプすると次の下部タブに移り、最後のタブからは最初のタブに戻ります。下部のタブバー自体をスワイプすることもできます。
AVR Maestroが閉じる前に確認するのはなぜですか?
Androidでは、タブの最上部で戻るを押すと「AVR Maestroを終了しますか?」と表示されるので、誤って戻るを押してもアプリは閉じません。「アプリを終了」をタップすると閉じ、「キャンセル」をタップするとそのままです。サブページから戻るを押すと、まずタブの最上部に戻ります。
WindowsとMacでAVR Maestroのキーボードショートカットは使えますか?
はい。WindowsではCtrl、MacではCmdに加えて、上下の矢印キーで音量、Mでミュートの切り替え、Spaceで再生/一時停止、左右の矢印キーで前/次へのスキップ、ピリオドキーで停止ができます。キーボードのメディアキーも使えます。テキストフィールドに入力している間は、ショートカットは何もしません。

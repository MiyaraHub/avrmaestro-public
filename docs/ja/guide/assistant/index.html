レシーバーに聞いてみよう

アシスタントに質問すると、答えはレシーバーから返ってきます

多くのアシスタントはレシーバー全般について詳しく知っています。このアシスタントが知っているのは、あなたのレシーバーのことです。今の音量、実行中のスピーカープリセット、Dynamic EQのオン/オフ、今まさにデコードしているフォーマットまで。あなたのレシーバーを読み取り、その情報をもとに答えます。使うのは、どこか別の場所にあるサービスではなく、端末上で動作するモデルです。

場所

アシスタントタブ

質問を入力するか、マイクボタンを押したまま話しかけてください。サインインも、キーの貼り付けも、アカウントも不要です。端末でオンデバイスモデルが動作すれば、開いてすぐにアシスタントを使えます。

普段の言葉で聞いてください。「音量は今どれくらい?」「今、何で見てる?」「どのDiracスロットが読み込まれてる?」「Dynamic EQはオン?」など、意図した内容をレシーバーが実際に報告する情報と照らし合わせて解釈するので、設定名を知らなくても大丈夫です。

答えられること

アプリがレシーバーから読み取るすべての情報、つまりこのガイドの各画面にある情報です。固定のリストではありません。IMAXを報告するシャーシにはIMAXについて質問でき、報告しないシャーシには提案すらされません。

質問できること把握している内容
電源と音量オンかスタンバイか、dB単位のレベル、ミュート、エコモード、レシーバー自体の音量制限
ソースとサウンドあなたが付けた名前で表示される選択中の入力、サウンドモード、デコード中のフォーマット
キャリブレーションAudyssey MultEQ、Dynamic EQ、Dynamic Volume、リファレンスレベルオフセット、LFC、読み込み中のDirac Liveスロット
スピーカーレイアウト、チャンネルごとのトリム、サブウーファーのレベル、設定されているサブウーファーの台数
映像入出力の解像度とHDR、ピクチャーモード、映像処理、入力モード、HDMIオーディオ出力、オートリップシンク
ゾーン各ゾーンの電源、入力、音量、チャンネルトリム、スリープタイマー、Smart Select / Quick Selectスロット
シャーシフロントパネルの明るさ、オートスタンバイ、Bluetoothトランスミッター、各トリガーを番号ごとに
再生中の内容ネットワークソースの曲と再生状態
各回答の下には、答えを導くために何を読み取ったかが表示されます。この行はモデルが書いたものではなく記録されたものなので、でっち上げられることはありません。説得力のある間違った答えと本物の答えを見分ける、いちばん手早い方法です。

代わりにやってくれること

変更を頼めば、その通りに変更します。違いは、操作ごとに確認の手間がどれだけかかるかで、この差は意図的なものです。

依頼内容動作
電源のオン/オフ、ミュート、ミュート解除すぐに実行し、送信した内容を報告します
音量を下げるすぐに実行します。もっと静かにしたいときは、ダイアログが最も邪魔になるタイミングだからです
音量を上げる先に確認します。最悪の場合ドライバーが破損するおそれがあり、その場にいる人でも元に戻せない唯一の操作だからです
入力を切り替えるあなたが付けた名前を含め、ソースリストと照合して判断します。候補が2つあるときは、どちらかを尋ねます

量はあなたが決められます。「5 dB下げて」と言えば5 dB下がり、数字なしの「下げて」なら、ボタンを1回押したのと同じ1ステップ下がります。言っていない数値を勝手に決めることはありません。

ここからのサウンドモードの変更は、まだ対応していません。レシーバーはサウンドモードをカテゴリ別に整理し、有効なカテゴリの中から選択するため、送信できる単一の名前ではありません。サウンドタブなら正しく操作できます。

意見を求める

「キャリブレーションのおすすめは?」「セリフを聞き取りやすくするには?」「Dynamic EQはオンにすべき?」といった質問は、単なる値の確認とは異なり、アシスタントも別の扱いをします。読み取り値をもとに考え、レシーバーに実在する設定を挙げた具体的な選択肢をいくつか示し、最初に試したいものも伝えます。

変わらないのは、数値の出どころです。自由に推論はしますが、与えられていない数値を述べることはありません。読み取り値が推奨を裏付けない場合は、推測せずに、何が確認できれば判断できるかを伝えます。

入力せず、話しかける

マイクボタンを押したまま話してください。送信前に確認できるよう、話した内容が入力ボックスに入ります。

ご注意:言語モデルは端末上で動作し、レシーバーも自宅のネットワーク内にあるため、入力した質問とその回答はハードウェアの外に出ません。音声をテキストに変換するのはスマホ標準の音声認識機能で、多くのスマホでは文字起こしのために音声がプラットフォーム提供元に送信されます。これを行うのはアプリではなくOSで、キーボード入力なら完全に避けられます。

利用できる端末

アシスタントは、お使いの端末上で言語モデルを動作させます。アカウントもサーバーもサインインも不要です。その分、端末にモデルが入っている必要があります。これはアプリがインストールしてあげられるものではなく、私たちにも回避できない唯一の要件です。

AndroidGoogle AICore経由のGemini Nano。アプリはGoogleのML Kit Prompt APIを通じてこれを利用しますが、このAPIには独自の対応端末リストがあります。以下をご覧ください。

トラブルシューティング

「お手伝いできません」と表示されたとき

それぞれ対処法が異なるため、メッセージもあえて別の文言にしています。

  • 「このデバイスではオンデバイスモデルを実行できません。」アシスタントには、iPhone、iPad、MacではApple Intelligence、AndroidではGoogle AICore経由のGemini Nanoが必要です。性能の高いデバイスでも対象外のものは多く、一部の現行タブレットや、他の用途ではGemini Nanoが動作する一部のフラッグシップスマートフォンも含まれます。上の対応デバイスをご覧ください。アプリ側でできる対処はありません。
  • モデルのダウンロードが必要です。Androidでは初回にバックグラウンドで取得されます。一度きりですが、サイズが大きいためWi-Fi接続をおすすめします。
  • 「お使いのレシーバーにその機能はありますが、現在報告できる内容はありません。」機能自体は存在し、ただ待機中という状態です。何も再生していないときに再生中の内容を尋ねるとこの表示になり、レシーバーがHEOSに対応していないという意味ではありません。
  • 「このレシーバーはその情報を報告しません。」お使いのハードウェアに関する正確な回答です。その筐体にはそのような機能がなく、アプリもあるかのように装うことはしません。
  • サブシステムを読み取れませんでした。「存在しない」ではなく「不明」です。読み取りの失敗を、お使いのレシーバーにない機能として扱うことはせず、その旨をお伝えします。
  • 「その項目はまだここからは変更できません。」これはレシーバーではなくアシスタント側の制限です。専用の画面からなら変更できます。
アシスタントは無料です。有料なのはホームオートメーションで、両者は別物です。レシーバーに何かを尋ねるだけならProは不要です。
よくある質問

アシスタントのよくある質問

アシスタントはデータをどこかに送信しますか?
言語モデルはお使いのデバイス上で動作し、レシーバーもご自宅のネットワーク内にあるため、入力した質問とその回答がハードウェアの外に出ることはありません。音声入力だけは例外で、音声のテキスト変換はスマートフォン'標準の音声認識機能が行い、多くのスマートフォンでは文字起こしのために音声がプラットフォーム提供元へ送信されます。キーボードで入力すれば、これを完全に避けられます。
アシスタントが「この端末では使えない」と表示するのはなぜですか?
アシスタントにはオンデバイスモデルが必要です。iPhone、iPad、MacではApple Intelligence、AndroidではGoogle AICore経由のGemini Nanoです。性能が十分な端末でも、モデルを搭載していないものは少なくありません。アプリは機能を隠すのではなく、現在どの状態にあるかを正確に表示するので、ダウンロードが必要なのか、設定の問題なのか、ハードウェアの問題なのかがわかります。
アシスタントは確認なしに設定を変更しますか?
電源、ミュート、入力、音量を下げる操作は、その場にいる人がすぐ元に戻せるため、直接実行します。音量を上げる操作だけは、最悪の場合ドライバーが破損するおそれがあるため、必ず先に確認します。
「わからない」と答えることがあるのはなぜですか?
推測しないからです。アシスタントが示す数値はすべて、レシーバーから取得した読み取り値に基づいています。値が取得できなかった場合は、それらしい数字をでっち上げるのではなく、そのサブシステムを読み取れなかったと伝えます。もっともらしい間違った答えは、答えがないよりも悪いからです。

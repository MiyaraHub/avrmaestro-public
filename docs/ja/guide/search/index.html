メニューをスクロールするのはもうやめましょう

検索、どのタブからでも

レシーバーには、タブ、サブタブ、メニューの奥に何百もの設定が隠れています。目的の設定の数文字を入力して結果をタップするだけで、AVR Maestroが正しいページを開き、その設定までスクロールして点滅させるので、場所がひと目でわかります。

2つの入口

  • ホームの検索ボックス。ホームタブのレシーバーカードの下にあります。タップして入力を始めてください。
  • 検索ボタン。すべてのタブで、下部のタブバーの右端にあります。今開いているページの上にシートとして同じ検索が開くので、先にホームへ戻る必要はありません。
手順

3タップで設定を見つける

  1. 単語を入力します。名前の一部で十分です。dialogと入力すると、Dialog EnhancerとDialog & DRCが見つかります。1文字の間違いは許容されるので、voluneでもVolume Limitが見つかります。
  2. 結果を選びます。最初の8件が表示されます。さらにある場合は、すべて表示の行に残りが一覧表示されます。入力した文字で始まる結果が最初に、次にそれを含む名前、その次に関連キーワードの順です。
  3. 設定に移動します。アプリが正しいタブとサブタブを開き、設定までスクロールして、しばらく点滅させます。その場で変更できます。
対象範囲

レシーバーの設定とアプリ自体

  • サウンド:Dynamic EQ、Dynamic Volume、Dialog Enhancer、Center Level、トーンコントロール、Audyssey MultEQ、Dirac Liveフィルターなど。
  • システム:HDMI出力、トリガー、Eco、オートスタンバイ、スリープタイマー、HDMI CEC、ピクチャーモードと映像モード、オーディオディレイ、ディマーなど。
  • レシーバーのページ:レシーバーを管理、音量コントロール、オンスクリーンディスプレイ、デバイス情報。
  • アプリ:言語、ナビゲーションとタブの表示、アシスタント、バックアップ、ウィジェットのサイズ、ハイコントラストウィジェット、アプリについてのページ。これらにはアプリというラベルが付き、レシーバーを選択していなくても使えます。
  • 操作:レシーバーの名前変更、IPアドレスの変更、レシーバーを検索、削除、アプリの評価、ログの共有、マニュアルを開く、ようこそガイドの再生、デモモードの開始と終了。
正直な結果

レシーバーにあるものだけを提示

検索は、接続中のレシーバーにできることを問い合わせるので、お使いのシャーシにない設定が一覧に出ることはありません。別のレシーバーに切り替えると、入力し直さなくても結果が変わります。

レシーバーにはあるものの、現在は変更できない設定は、理由を添えて薄く表示されます。たとえば、現在のサウンドモードがロックしている、などです。レシーバーがまだ報告していない設定は不明と表示されます。アプリが「まだ応答がない」を「利用できない」にすり替えることはありません。

すべての言語

ご自身の入力方法で

検索は、アプリのすべての言語で使えます。アクセント記号、ウムラウト、トルコ語のドット付きとドットなしのi、全角文字、アラビア語の母音記号、ヘブライ語のニクダーは、入力しなくても構いません。レシーバー自身のメニューやマニュアルが英語の用語を使うため、設定の英語名でも、どの言語でも見つかります。その場合は、ご自身の言語での一致の後に表示されます。

よくある質問

検索、よくある質問

AVR Maestroの検索はどこにありますか?
ホームタブでは、レシーバーカードの下に検索ボックスがあります。すべてのタブでは、下部のタブバーの右端にも検索ボタンがあります。どちらも同じ検索を開きます。
何を検索できますか?
サウンド、スピーカー、ゾーン、システムの各ページにあるレシーバーの設定、言語、バックアップ、ウィジェットのサイズなどのアプリ自体のオプション、そしてレシーバーの名前変更やデモモードの終了といった一部の操作です。アプリ自体の結果には「アプリ」というラベルが付きます。
結果がグレーアウトしているのはなぜですか?
グレーの結果は、レシーバーにはあるものの、現在は変更できない設定です。その下の行に理由が表示されます。たとえば、現在のサウンドモードがロックしている、などです。「不明」と表示された結果は、レシーバーがまだ応答していないことを意味し、アプリは推測しません。
探している設定が一覧にないのはなぜですか?
お使いのレシーバーにその設定がないためです。AVR Maestroは、接続中のレシーバーが提供するものだけを一覧表示するので、古いレシーバーには、備わっていない設定は表示されません。レシーバーが2台ある場合、結果は選択中のレシーバーに従います。
検索は自分の言語で使えますか?
はい。検索はすべてのアプリ言語で使えます。アクセント記号を入力する必要はなく、設定の英語名でも、どの言語でも見つかります。その場合は、ご自身の言語での一致の後に表示されます。

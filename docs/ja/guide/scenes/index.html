シーン:部屋まるごと、ワンタップで

Movie Night、Late Night、Vinyl Evening。それぞれワンタップで、入力、サウンドモード、AudysseyまたはDirac、レベル、ゾーンを好みどおりに設定します。シーンを作るのに、レシーバーのメニューを知っている必要はありません。アプリがいくつかの簡単な質問をし、お使いのレシーバーが実際にできることだけを提示します。

★★★★★ 4.9 · 303件の評価(2026年10月時点)
2つの始め方

「シーンを追加」をタップして、作り方を選びます

  • シーン作成ツールは、いくつかの質問に答えながら作成します。レシーバーが対応する項目だけが表示されます。最初のシーンや、やりたいことはわかっていても設定がどのメニューにあるかわからないときに最適です。
  • ゼロから作成は、レシーバーの現在の状態をそのまま記録します。好みの音に整えて、保持したい設定にチェックを入れ、保存するだけです。
シーンタブがまだ空ですか?レシーバーに合った「映画とテレビ」や「深夜」などの出発点がいくつか提案されます。1つタップすると、選択済みの状態でシーン作成ツールが始まります。
シーン作成ツールを、ステップごとに

最初のシーンを約1分で

シーン作成ツールは、あなたの答えからシーンを作ります。レシーバーを読み取ることはなく、保存しても何も変わらないので、気軽にいろいろ試せます。上部のステップカウンターで現在位置がわかり、「戻る」で以前の答えに戻れます。

  1. 名前を付けます。慌ただしい夜でもひと目でわかる名前にしましょう。Movie Night、Saturday Records、子ども向けアニメなど。
  2. 用途を選びます。映画とテレビ、音楽、ゲーム、深夜、他の部屋、またはすべて自分で選びたい場合のカスタムです。この選択は、通常合う設定を強調表示するだけで、勝手にチェックが入ることはありません。
  1. 制御したい項目にチェックを入れます。設定は、考えやすいようにルーティング&音量、サウンド、Audyssey&Dirac、スピーカー&レベル、ゾーン、その他、外観に分類されています。レシーバーが対応する設定だけが表示され、おすすめと表示された項目は、ステップ2で選んだ用途で通常選ばれるものです。
AudysseyとDirac Liveは別々のルーム補正システムで、レシーバーはスピーカープリセットごとにどちらか一方を使います。Dirac Liveが有効な間は、一部のAudyssey設定がレシーバー自体によってロックされます。その場合、適用できないシーンを保存させるのではなく、チェックを入れた時点でアプリがお知らせします。コントロールがロックされる理由をご覧ください。
  1. 各設定の値を選びます。チェックを入れた設定ごとに短いページが表示され、レシーバーが報告する値(サウンドモード、入力、Diracスロット、スピーカープリセット)が並びます。レベルはレシーバーでの表示どおりに示されます。
  • 他のジャンルを表示。レシーバーは、再生中のジャンルのサウンドモードしか一覧表示しません。これをタップすると、アプリが少しの間ほかのジャンルを読み取り、その後レシーバーを元の状態にきちんと戻します。
  • AudysseyかDiracかを表示。スピーカープリセットでも同じ方法を使い、選ぶ前に各スロットにラベルを表示します。
  • チャンネルレベルは、保存時の状態がそのまま維持されます。変えたい場合は、先にスピーカータブで調整してから戻ってきてください。
  1. 確認して保存します。最後のページには、シーンに保存される内容が、アプリの他の画面と同じ分類で正確に一覧表示されます。保存をタップすると、シーンのリストに追加され、いつでも使える状態になります。
ステップ数は、チェックを入れた項目の数に応じて増えます。チェックした設定ごとに1ページずつ表示されるため、3つの設定のシーンは、10個の設定のシーンより短くなります。
ゼロから作成

すでに完璧な音なら、そのまま保存

部屋の音がすでに理想的なら、答える質問はありません。シーンを追加をタップし、ゼロから作成を選んで名前を付け、保持したい項目にチェックを入れます。シーンには、レシーバーの現在の値が、選んだ設定の分だけ保存されます。

シーン作成ツールでカスタムを選ぶと、レシーバーを読み取らずに同じ完全なリストが表示されます。あとで使うために準備しておきたいときに便利です。

シーンに保存できる内容

ほとんどすべて。ただし、選んだものだけ

シーンを適用すると、そのシーンが保持している設定だけが変更されます。たとえば深夜用のシーンなら、入力、サウンドモード、キャリブレーションはそのままに、音量を下げてDynamic Volumeをオンにすることができます。

🎥

電源、ルーティング&音量

メインゾーンの電源、入力ソース、マスター音量。シーンの読み込み時にレシーバーの電源を入れることもできます。

🎵

サウンドモード、Restorer、Dialog Enhancer、トーン、Cinema EQ、Graphic EQ、IMAX Enhanced、スピーカーバーチャライザー、センタースプレッド。

🔊

スピーカープリセット、チャンネルごとのレベル、サブウーファーレベル。

追加機能

ECO、スリープタイマー、ディマー、HDMIオーディオ出力、チューナーの局、レシーバーのセットアップロック、さらにはアプリ自身のカラーテーマまで。

実際に表示される項目は、お使いのレシーバーによって異なります。アプリはお使いのモデルが報告する項目だけを表示するため、存在しない設定を前提にシーンを作ってしまうことはありません。

シーンの使い方と変更

タップで適用、長押しでその他の操作

シーンをタップすると、設定が安全な順序で1つずつ送信されている間、タイルに適用中...と表示されます。長押しすると、以下の操作が行えます。

  • 現在の設定で更新は、名前、アイコン、設定のリストはそのままに、レシーバーの現在の値を取り込みます。削除して保存し直す必要はありません。
  • 記録した設定を編集で、シーンに設定を追加または削除できます。
  • シーン名を変更とアイコンと色を変更 &(お手持ちの画像も使えます。カスタムアイコンをご覧ください)。
  • シーンを複製すると、Movie NightとMovie Night(子どもが寝た後)のようなバリエーションを、最初から作り直さずに作成できます。
  • ホームオートメーション(Pro)は、シーンをHome AssistantまたはHubitatに送信するので、1つのオートメーションで照明を落としてレシーバーも一緒に設定できます。ホームオートメーションをご覧ください。
  • シーンを削除すると、ここから削除され、次回のHome Assistant同期で、作成されたスクリプトも削除されます。
シーンをハンドルでドラッグすると、一覧の順序を変更できます。シーンはホーム画面にもカードとして表示され、アプリを開かなくても、スマートフォンのホーム画面から呼び出せます。Androidではランチャーのウィジェット一覧からAVR Scenesウィジェットを、iPhoneではウィジェットギャラリーからシーンウィジェットを追加します。ウィジェットをご覧ください。
シーンと Smart Select / Quick Select

レシーバーのスロットを、本来の名前で

レシーバーには、本体専用のプリセットスロットもあります。MarantzではSmart Select、DenonではQuick Selectと呼ばれ、AVR Maestroはホーム画面の行、リモコンタブ、タブをカスタマイズ、セットアップガイドなど、すべての画面でお使いのレシーバーと同じ名前を使います。Marantz CINEMA 30には5つあります。

  • Smart Select / Quick Selectはレシーバーに保存されます。ホーム画面またはリモコンからスロットを実行でき、長押しで名前を変更できます。
  • シーンはアプリ内に保存され、1台のレシーバーにつき最大20個まで、それぞれ名前、アイコン、色を持ち、選んだ設定だけを保存します。ホーム画面ウィジェットから呼び出したり、Home Assistantのスクリプトにしたりできます。

両者が互いを上書きすることはないので、両方を活用してください。レシーバー本体のクイック切り替えにはスロット、それ以外のすべてにはシーンが向いています。

トラブルシューティング

シーンが完全には適用されないとき

シーンは1つのコマンドではありません。レシーバーが処理できるようペースを調整しながら、意図した順序で送信される一連の操作です。そのため、一瞬で終わらず、少し時間がかかります。

  • 電源が最初で、止まっているレシーバーには起動する時間を与えます。シーンがレシーバーの電源を入れる場合、起動中のレシーバーは設定を受け付けないため、ほかの操作はすべて起動を待ちます。
  • チャンネルレベルは確認され、1回だけ再送されます。レシーバーは、一度に多くのデータが届くと一部のチャンネルを取りこぼすことがあります。アプリは反映された内容を読み戻し、反映されなかった分を再送し、再試行したチャンネルをお知らせします。
  • ロックされたコントロールは、何をしても適用できません。スピーカープリセットがDirac Liveの管理下にある場合、レシーバー自体がAudysseyの変更を拒否します。それを含むシーンも、画面上のコントロールと同じ理由で拒否されます。コントロールがロックされる理由をご覧ください。
  • 変更されるのは、シーンが保持している内容だけです。期待した項目が変わらない場合は、おそらくチェックが入っていません。2つ目のシーンを作るのではなく、シーンを長押しして「記録した設定を編集」を使ってください。
  • シーンは1台のレシーバーに属します。表示されるのは、現在選択中のレシーバーのシーンです。別のレシーバーには、それぞれのシーンがあります。
タップした後

シーンの後のメッセージの意味

シーンが完了すると、アプリはレシーバーの動作を読み戻し、画面下部にメッセージをひとつ表示します。色で結果がわかります。すべてのメッセージに閉じるボタンがあり、赤のメッセージは閉じるまで残ります。

  • 緑 - シーン「名前」を適用しました。シーンの内容がすべて反映されました。
  • オレンジ - レシーバーが別の値を選びました。レシーバーが次の値を別のものに選びました: ...レシーバーは一部の設定を入力信号ごとに記憶しており、挙げられた項目について独自の値を選びました。これは想定内の動作です。シーンをもう一度タップして再試行してください。
  • 青 - 送信しましたが、確認できていません。レシーバーから応答がありませんでした: ...またはレシーバーがスピーカーレベルを確認しませんでした。それらが反映されたかどうか、アプリは判断できません。失敗したとは言っていません。もう一度シーンをタップして確認してください。
  • 赤 - 設定の読み戻した値が異なります。レシーバーが報告する次の値が異なります: ...シーンをもう一度タップするか、レシーバーを確認してください。
  • 赤 - スピーカーレベルが受け付けられませんでした。レシーバーが次のスピーカーレベルを受け付けませんでした: ...サウンドモードの切り替え中でビジーなときに起こることがあります。アプリはすでに一度再試行しています。もう一度シーンをタップして設定してください。
よくある質問

シーンのよくある質問

シーンとは?
シーンとは、映画、レコード、ゲーム、静かな深夜など、目的に合わせてレシーバーをワンタップでセットアップする機能です。入力、音量、サウンドモード、AudysseyまたはDirac、スピーカープリセット、チャンネルレベル、ゾーン、チューナーの局、電源を記録できます。適用すると、選んだ設定だけが変更され、それ以外はそのまま維持されます。
最初のシーンはどう作りますか?
シーンタブを開いて「シーンを追加」をタップし、「シーン作成ツール」を選びます。名前を付け、用途(映画とテレビ、音楽、ゲーム、深夜、他の部屋、カスタム)を選び、制御したい項目にチェックを入れ、レシーバーが提示する値から各設定の値を選び、保存前にサマリーを確認します。所要時間は約1分です。
シーン作成ツールからシーンを保存すると、レシーバーの設定が変わりますか?
いいえ。シーン作成ツールはあなたの選択からシーンを作るため、保存時にレシーバーから何かを読み取ることも、レシーバーへ何かを送ることもありません。レシーバーが変わるのは、シーンを適用したときだけです。
「ゼロから作成」は何のためにありますか?
すでにある設定をそのまま記録するためのものです。レシーバーを好みの音に整えてから「シーンを追加」をタップし、「ゼロから作成」を選んで名前を付け、保持したい設定にチェックを入れます。シーンには、レシーバーの現在の値が保存されます。
シーンを適用すると、レシーバーに負荷がかかりませんか?
いいえ。設定は安全な順序でペースを守って1つずつ送信され、電源が最初に処理されます。レシーバーが受け取るまで、タイルには「適用中...」と表示されます。チャンネルレベルは読み戻して確認し、レシーバーが取りこぼした項目はもう一度送信されます。
シーンはあとから変更できますか?
はい。長押しすると、シーンを適用、現在の設定で更新、記録した設定を編集、シーン名を変更、アイコンと色を変更 & シーンを複製、ホームオートメーション(Pro)、シーンを削除が選べます。シーンのハンドルをドラッグすると、リストの順序を並べ替えられます。
シーンでレシーバーの電源を入れられますか?
はい。電源状態を含めると、シーンの適用時に最初にメインゾーンの電源がオン(またはオフ)になります。ただし、スリープ中でもアプリから接続できるよう、レシーバーでネットワークスタンバイが有効になっている必要があります。
シーンの後に表示される色付きのメッセージは何を意味しますか?
緑はすべて反映されたことを意味します。オレンジは、レシーバーが入力信号ごとに記憶する設定について独自の値を選んだことを意味し、これは想定内の動作です。シーンをもう一度タップして再試行してください。青は、レシーバーが一部の設定を確認しなかったため、反映されたかどうかをアプリが判断できないことを意味します。赤は、設定の読み戻した値が異なる、またはレシーバーが一部のスピーカーレベルを受け付けなかったことを意味します。シーンをもう一度タップしてください。赤のメッセージは、閉じるまで残ります。
シーンと Smart Select / Quick Select の違いは何ですか?
Smart Select(Marantz)とQuick Select(Denon)は、同じレシーバー機能の2つの呼び名で、レシーバー内部に保存される少数のスロットです(Marantz CINEMA 30では5つ)。AVR Maestroはアプリ内のどこでも、お使いのレシーバー自身の呼び名を使い、ホーム画面とリモコンから呼び出せ、名前も変更できます。シーンはAVR Maestro独自のもので、1台のレシーバーにつき最大20個まで、それぞれ名前、アイコン、色を持ち、選んだ設定だけを保存します。ホーム画面ウィジェットから呼び出したり、Home AssistantやHubitatへ送ったりもできます。両者が互いを上書きすることはありません。

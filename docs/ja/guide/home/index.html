ホーム画面

ホーム画面: あなたの拠点を、あなた好みに

デバイスのステータスカードは上部に固定され、モデル、接続、電源が表示されます。その下に、カスタマイズ可能なウィジェットのグリッドが並びます。カードを追加、削除、並べ替えて、ホーム画面に本当に必要なものだけを表示できます。

自分好みに

数秒でカスタマイズ

左上のホームをカスタマイズアイコンをタップして編集モードに入ります。

  • カードをドラッグして並べ替えます。
  • 赤い丸をタップしてカードを削除します。
  • 追加を押すと、まだ追加していないウィジェットの一覧が開きます。
  • リセットで初期状態に戻し、完了で終了します。
編集中はカードが暗く表示されるので、レシーバーの設定を誤って変更することはありません。ウィジェットは、レシーバーがその機能に対応している場合にのみ表示されます。最初のホーム画面には、Smart Select / Quick Select、音量、ソース、サウンドモード、シーン、信号情報、再生中、ゾーンが並びます。各カードの詳細はウィジェットのガイドをご覧ください。
複数のレシーバー

タイトルからレシーバーを切り替え

レシーバーに接続すると、ホーム画面の上部、AVR Maestroの横にレシーバー名が表示されます。タップすると追加したすべてのレシーバーが表示され、選んでアクティブにできます。レシーバーを管理を選ぶと、追加や並べ替えができます(設定 › レシーバーを管理)。ステータスカードの下の検索ボックスで、アプリ内のどの設定も探せます。検索のガイド、レシーバーのガイド、アプリの操作をご覧ください。

音量プリセット

8つの音量レベルをワンタップで

  • 空のスロットをタップすると、現在の音量がそこに保存されます。
  • 保存済みのスロットをタップすると、その音量に切り替わります。
  • スロットを長押しすると、現在の音量で上書き保存するか、消去できます。

詳しくは音量のガイドをご覧ください。

部屋に名前を付ける

「MAIN ZONE」ではなく「リビング」

ホーム画面でゾーン名を長押しすると、メインゾーンも含め、どのゾーンでも名前を変更できます。名前はアプリだけでなくレシーバー本体に書き込まれるため、メーカー純正アプリやその他のすべてのクライアントにも表示され、古い筐体でも使えます。一度名前を変えれば、家中のどのコントローラーでも部屋の呼び名がそろいます。

サウンドコントロール

サウンドのクイックトグル

  • グラフィックEQ:オン/オフスイッチは、グラフィックEQページ(サウンド › グラフィックEQ)内のヘッダー行、ResetとCopyの横にあります。バンドを編集できるのは、Dirac LiveもAudysseyも音場補正を実行していないときだけです。アプリはレシーバー自身のルールに合わせています。グラフィックEQのガイドをご覧ください。
  • サブウーファー:スピーカー設定に入らなくても、サウンド › サラウンド › オーディオ機能からサブウーファーをミュートまたは有効にできます。レシーバーが報告して受け付ける場合のみ表示されます。
  • オーディオリストアラー:レシーバーの圧縮オーディオ用リストアラーで、DenonではRestorer、MarantzではM-DAXと呼ばれ、サウンド › トーンにあります。オンスクリーンメニューに行かなくても、MP3やストリーミングソースに活気を取り戻せます。
再生中&HEOS

再生中の内容を確認して操作する

現在のソースがメタデータを提供している場合、再生中カードにアルバムアート、曲名 / アーティスト / 局名、再生コントロール(再生 / 一時停止 / 次へ / 前へ)が表示されます。

楽曲(局、キュー、ストリーミングサービス、HEOSルーム)を探すには、再生中カードのHEOSを起動をタップします。AVR Maestroが公式のHEOSアプリを開いて探せるようにし、そこで再生が始まると、AVR Maestroが再生中の表示、再生コントロール、ウィジェットを引き継ぎます。アナログ、光/同軸、HDMIパススルーのソースはメタデータを報告しないため、これらではカードは空のままです。お気に入りボタンやカードのその他の機能は、再生中とHEOSのガイドで説明しています。

よくある質問

ホーム画面のFAQ

ホーム画面をカスタマイズできますか?
はい。「ホームをカスタマイズ」をタップし、ドラッグで並べ替え、赤い丸をタップで削除、「追加」でウィジェットを追加、「リセット」で初期状態に戻し、「完了」で終了します。編集中はカードが暗くなるので、うっかり設定を変えてしまう心配はありません。
メインゾーンを含め、ゾーンの名前を変更できますか?
はい。ホーム画面でゾーン名を長押ししてください。名前はレシーバー本体に書き込まれるため、メーカー純正アプリやその他のすべてのクライアントにも表示され、古い筐体でも使えます。
ホーム画面からレシーバーを切り替えられますか?
はい。上部のAVR Maestroの横にあるレシーバー名をタップして別のレシーバーを選ぶか、「レシーバーを管理」を選んで追加や並べ替えをします。
再生中の内容は表示されますか?
はい。メタデータを提供するソースであれば、アルバムアート、曲名/アーティスト/局名、再生コントロールが表示されます。「HEOSを起動」をタップして選曲し、再生が始まるとAVR Maestroが再生中の表示を引き継ぎます。

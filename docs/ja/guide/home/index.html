ホーム画面

ホーム画面: あなたの拠点を、あなた好みに

デバイスのステータスカードは上部に固定され、モデル、接続、電源が表示されます。その下に、カスタマイズ可能なウィジェットのグリッドが並びます。カードを追加、削除、並べ替えて、ホーム画面に本当に必要なものだけを表示できます。

自分好みに

数秒でカスタマイズ

左上のホームをカスタマイズアイコンをタップして編集モードに入ります。

  • カードをドラッグして並べ替えます。
  • 赤い丸をタップしてカードを削除します。
  • 追加を押すと、まだ追加していないウィジェットの一覧が開きます。
  • リセットで初期状態に戻し、完了で終了します。
編集中はカードが暗くなるので、うっかりレシーバーの設定を変えてしまうことはありません。ウィジェットは、レシーバーがその機能に対応している場合にのみ表示されます。
部屋に名前を付ける

「MAIN ZONE」ではなく「リビング」

ホーム画面でゾーン名を長押しすると、メインゾーンも含め、どのゾーンでも名前を変更できます。名前はアプリだけでなくレシーバー本体に書き込まれるため、メーカー純正アプリやその他のすべてのクライアントにも表示され、古い筐体でも使えます。一度名前を変えれば、家中のどのコントローラーでも部屋の呼び名がそろいます。

固定できるすべての項目

ECO、スリープ、DRC、リストアラー、映像、ルームサイズ、LFEワンタップで切り替えられるトグルとピッカー。対応している場合にのみ表示されます。
サウンドコントロール

サウンドのクイックトグル

  • グラフィックEQ:サウンド、オーディオ機能から、レシーバーのグラフィックEQをオン/オフできます。Dirac LiveもAudysseyもルーム補正を行っていない場合にのみ使えます。アプリはレシーバー自身のルールに合わせています。
  • サブウーファー:サウンド、オーディオ機能から、スピーカー設定を開かなくてもサブウーファーをミュートまたは有効にできます。レシーバーが状態を報告し、操作を受け付ける場合にのみ表示されます。
  • オーディオリストアラー:圧縮オーディオを復元するレシーバーの機能で、DenonではRestorer、MarantzではM-DAXと呼ばれます。サウンド、トーンの下にあるDACフィルターのすぐ隣で、トグルとして使えます。オンスクリーンメニューを開かなくても、MP3やストリーミングソースに生気を取り戻せます。
再生中&HEOS

再生中の内容を確認して操作する

現在のソースがメタデータを提供している場合、再生中カードにアルバムアート、曲名 / アーティスト / 局名、再生コントロール(再生 / 一時停止 / 次へ / 前へ)が表示されます。

ステーション、キュー、ストリーミングサービス、HEOSルームなどから音楽を選ぶには、再生中カードのHEOSを起動をタップします。AVR Maestroが選曲用に純正のHEOSアプリを開き、そこで再生が始まると、再生中の表示、再生コントロール、ウィジェットをAVR Maestroが引き継ぎます。アナログ、光/同軸、HDMIパススルーのソースはメタデータを提供しないため、これらではカードは空のままです。

よくある質問

ホーム画面のFAQ

ホーム画面をカスタマイズできますか?
はい。「ホームをカスタマイズ」をタップし、ドラッグで並べ替え、赤い丸をタップで削除、「追加」でウィジェットを追加、「リセット」で初期状態に戻し、「完了」で終了します。編集中はカードが暗くなるので、うっかり設定を変えてしまう心配はありません。
メインゾーンを含め、ゾーンの名前を変更できますか?
はい。ホーム画面でゾーン名を長押ししてください。名前はレシーバー本体に書き込まれるため、メーカー純正アプリやその他のすべてのクライアントにも表示され、古い筐体でも使えます。
再生中の内容は表示されますか?
はい。メタデータを提供するソースであれば、アルバムアート、曲名/アーティスト/局名、再生コントロールが表示されます。「HEOSを起動」をタップして選曲し、再生が始まるとAVR Maestroが再生中の表示を引き継ぎます。

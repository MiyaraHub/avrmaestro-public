AVR-X4000世代

古いDenonレシーバーをフルサポート

AVR Maestroアプリは、AVR-X4000世代のDenonレシーバーをネットワーク経由で操作します。古いレシーバーは現行機種より応答できる項目が少ないため、レシーバーが報告したコントロールだけを表示し、でっち上げは一切しません。

できること

古いレシーバーのコントロール

  • お気に入り1から4：システムページにメインゾーン用のお気に入り行があります。スロットをタップすると呼び出せます。長押しすると、確認後に再生中の内容が保存されます。
  • Video Select：システムページでビデオソースを選べます。
  • アスペクト比とビデオ解像度：システムページで設定でき、横にHDMI解像度が表示されます。
  • Network Presets：リモコンページのパネルです。プリセットをタップすると呼び出せます。長押しすると、確認後に現在の放送局が保存されます。
  • HD Radio：北米モデルでは、レシーバーがHD局を報告すると、ラジオページにHD Radioパネルが表示されます。
  • ゾーンのお気に入りとスリープタイマー：各ゾーンカードには4つのお気に入りがあり、タップで呼び出し、長押しで保存できます。スリープタイマーはオフ、30、60、90、120分から選べます。
上記の各項目は、レシーバーが応答した場合にのみ表示されます。項目がない場合は、レシーバーが報告しなかったということで、アプリではなくレシーバー側の事情です。
提供されないもの

古いレシーバーが応答できないコントロール

この世代ではBluetooth、Loudness、Cinema EQは提供されません。レシーバーが応答できないためです。AVR Maestroアプリは、何も起きないスイッチを表示する代わりに、これらを省いています。

よくある質問

古いレシーバーのよくある質問

AVR Maestroアプリは、AVR-X4000のような古いDenonレシーバーで使えますか？
はい。ネットワーク経由でメインゾーン、ゾーン2、ゾーン3を操作できます。古いレシーバーは現行機種より応答できる項目が少ないため、コントロールはレシーバーが応答した場合にのみ表示されます。
古いレシーバーで一部のコントロールが表示されないのはなぜですか？
アプリは、レシーバーが報告したコントロールだけを表示します。古いDenonレシーバーにはBluetooth、Loudness、Cinema EQがないため、これらは表示されません。
古いレシーバーでお気に入りを保存するには？
お気に入りをタップすると呼び出せます。長押しすると、再生中の内容がそこに保存されます。確認画面が出たら承認してください。

ホーム画面のウィジェット

アプリを開かなくても、電源、音量、ミュート、再生中の内容、現在の信号、シーンを、ホーム画面からそのまま操作できます。ウィジェットはAndroid、iPhone、iPadで使えます。MacとWindowsにはウィジェットはありません。

4つのウィジェット

  • クイックコントロール(Android: AVR Quick Control)。レシーバー名、入力、音量に加え、電源、音量ダウン、音量アップ、ミュート。Androidではアプリを開くボタンもあり、レシーバーがオフの間は音量とミュートのボタンが非表示になり、電源だけが残ります。
  • 再生中(Android: AVR Now Playing)。カバーアート、曲名、アーティスト、局名に加え、前へ、再生または一時停止、次へ。何も再生していないときは、Androidでは「No media playing」、iPhoneとiPadでは「Nothing playing」と表示されます。
  • レシーバーステータス(Android: AVR Signal Status)。入力、入力と出力の音声・映像信号、サンプルレート、音量。
  • シーン(Android: AVR Scenes)。レシーバーに保存したシーン。タップすると、アプリを開かずに適用されます。シーンをご覧ください。
ウィジェットは、アプリで選択中のレシーバーに従います。クイックコントロールとステータスには、レシーバーがスタンバイのときはStandby、到達できないときはAVR offと表示されます。
手順

ウィジェットを追加

  1. ウィジェットに表示する内容があるよう、AVR Maestroを一度開いてレシーバーに接続します。
  2. ホーム画面の空いている部分を長押しし、スマートフォンのウィジェットのオプションを選びます。
  3. AVR Maestroを探し、ウィジェットを選びます。Androidでは、名前がAVRで始まります。iPhoneとiPadでは、クイックコントロール、再生中、レシーバーステータスは中サイズ、シーンは中または大サイズです。
  4. Androidでは、ウィジェットの端をドラッグしてサイズを変更できます。小さいサイズでは、コンパクトなレイアウトに切り替わります。
iPhoneとiPadのウィジェットには、iOSまたはiPadOS 17以降が必要です。

ウィジェットを最新に保つ

  • 更新ボタン。クイックコントロール、再生中、シーンには、ウィジェットをすぐに更新する更新ボタンがあります。Androidの再生中では、大きいサイズで表示されます。
  • 自動更新。クイックコントロールとステータスは約15分ごとに自動で更新され、Androidでは再生中も同様です。Androidではネットワーク接続が必要です。シーンは、アプリでシーンを変更したとき、または更新をタップしたときに更新されます。
Androidでは、ウィジェットを初めて使うときに、アプリがホーム画面ウィジェットについて説明し、設定を開くを提案します。バックグラウンドの更新を最も確実にするには、バッテリー設定でAVR Maestroのバックグラウンド実行を許可してください。

ウィジェットの色

どちらの設定も、Android、iPhone、iPadの設定の外観にあります。

  • ハイコントラストウィジェットは、ウィジェットをグレースケールにします。
  • ウィジェットをアプリの色に合わせるは、ウィジェットにおなじみのオレンジの代わりに、カラーテーマのアクセントを使います。ハイコントラストウィジェットがオンの間は、このスイッチは使えず、ウィジェットはグレースケールのままです。
同じセクションのウィジェットサイズは、ホーム画面のウィジェットを変更しません。アプリ内のボタン、チップ、カードのサイズを調整します(小、中、大、特大)。設定をご覧ください。
よくある質問

ウィジェット、よくある質問

AVR Maestroにはどのホーム画面ウィジェットがありますか?
AndroidとiPhone、iPadで、4種類あります。クイックコントロール(電源、音量、ミュート)、再生中(再生中の内容と、前へ、再生または一時停止、次へ)、iPhoneではレシーバーステータス、Androidでは信号ステータス(入力と音声・映像信号)、そしてシーン(保存したシーンの適用)です。MacとWindowsにはウィジェットはありません。
ウィジェットはどのくらいの頻度で更新されますか?
クイックコントロールとステータスは約15分ごとに自動で更新され、Androidでは再生中も同様です。クイックコントロール、再生中、シーンには更新ボタンもあり、ウィジェットをすぐに更新できます。
ウィジェットに「AVR off」や「Standby」と表示されるのはなぜですか?
Standbyは、レシーバーがスタンバイ状態であることを意味します。AVR offは、ウィジェットがレシーバーに到達できなかったことを意味します。たとえば、電源が抜けている、または別のネットワークにある場合です。
シーンのウィジェットに、シーンがないと表示されるのはなぜですか?
ウィジェットには、選択中のレシーバーに保存されたシーンが一覧表示されます。先にAVR Maestroを開いてシーンを作成してください。シーンのガイドをご覧ください。
ウィジェットサイズで、ホーム画面のウィジェットは変わりますか?
いいえ。設定 › ウィジェットサイズで変わるのは、アプリ内のボタン、チップ、カードのサイズです。ホーム画面のウィジェットのサイズを変えるには、ホーム画面上でサイズを調整してください。
ウィジェットにテーマカラーを使えますか?
はい。設定 › ウィジェットをアプリの色に合わせるをオンにすると、ウィジェットがオレンジの代わりにアクセントカラーを使います。ハイコントラストウィジェットがオンの間は、そのウィジェットがグレースケールのため使えません。

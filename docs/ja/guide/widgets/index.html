ホーム画面のウィジェット

アプリを開かなくても、電源、音量、ミュート、再生中の内容、現在の信号、シーン、HDMI出力をホーム画面から直接操作できます。ウィジェットはAndroid、iPhone、iPadで利用できます。MacとWindowsにはウィジェットがありません。

6つのウィジェット

  • クイックコントロール(Android: AVR Quick Control)。レシーバー名、入力、音量に加え、電源、音量ダウン、音量アップ、ミュート。Androidではアプリを開くボタンもあり、レシーバーがオフの間は音量とミュートのボタンが非表示になり、電源だけが残ります。
  • 再生中(Android: AVR Now Playing)。カバーアート、曲名、アーティスト、局名に加え、前へ、再生または一時停止、次へ。何も再生していないときは、Androidでは「No media playing」、iPhoneとiPadでは「Nothing playing」と表示されます。
  • レシーバーステータス(Android: AVR Signal Status)。入力、入力と出力の音声・映像信号、サンプルレート、音量。
  • シーン(Android: AVR Scenes)。レシーバーに保存したシーン。タップすると、アプリを開かずに適用されます。シーンをご覧ください。
  • Multi-Room（Android：Multi-Room）。固定したスピーカーやグループの再生内容を、ジャケット画像、曲名、アーティスト名とともに表示し、音量を下げる、前へ、再生または一時停止、次へ、音量を上げるの操作ができます。アプリ内のホームウィジェットに固定でスピーカーやグループを固定します。固定するまでは、ウィジェットにアプリでルームを固定してくださいと表示されます。固定したスピーカーに接続できないときはスピーカーに接続できません、待機中は再生中のものはありませんと表示されます。Multi-Roomもご覧ください。
  • HDMI Output(Android: AVR HDMI Output)。HDMI出力ごとに1つのボタンがあります。たとえばAuto、TV 1とTV 2、お使いのレシーバーがそう呼ぶ場合はMonitor 1とMonitor 2で、現在の出力に印が付きます。タップすると、アプリを開かずにレシーバーのHDMI出力を切り替えられます。ウィジェットに表示されるのは、アプリが最後に読み取ったときにレシーバーが報告した出力だけで、タップのたびに、変更を表示する前にレシーバーから設定を読み戻します。レシーバーがその時点で変更を許可しない場合はレシーバーは現在この変更を許可していませんと表示され、アプリが設定を読み取るまではAVR Maestroを開いてHDMI出力を読み取ってくださいと表示されます。
ウィジェットは、アプリで選択中のレシーバーに従います。クイックコントロールとステータスには、レシーバーがスタンバイのときはStandby、到達できないときはAVR offと表示されます。
手順

ウィジェットを追加

  1. ウィジェットに表示する内容があるよう、AVR Maestroを一度開いてレシーバーに接続します。
  2. ホーム画面の空いている部分を長押しし、スマートフォンのウィジェットのオプションを選びます。
  3. AVR Maestro を探すか、AVR で検索して、ウィジェットを選びます。Android では、Multi-Room を除き、名前は AVR で始まります。iPhone と iPad では、クイックコントロール、再生中、レシーバーステータス、Multi-Room、HDMI出力は中サイズ、シーンは中または大サイズで提供されます。
  4. Androidでは、ウィジェットの端をドラッグしてサイズを変更できます。小さいサイズでは、コンパクトなレイアウトに切り替わります。
上の画面は Pixel 上の Smart Launcher です。ランチャーによって手順の表現は異なりますが、最終的にはどれも同じ AVR Maestro ウィジェットの一覧にたどり着きます。
iPhoneとiPadのウィジェットには、iOSまたはiPadOS 17以降が必要です。

ウィジェットを最新に保つ

  • 更新ボタン。クイックコントロール、再生中、シーンには、ウィジェットをすぐに更新する更新ボタンがあります。スピーカーやグループを固定したMulti-Roomにもあります。Androidでは、再生中は大きいサイズで表示されます。
  • 自動更新。クイックコントロールとステータスは約15分ごとに自動で更新され、Androidでは再生中も同様です。Androidではネットワーク接続が必要です。シーンは、アプリでシーンを変更したとき、または更新をタップしたときに更新されます。
Androidでは、ウィジェットを初めて使うときに、アプリがホーム画面ウィジェットについて説明し、設定を開くを提案します。バックグラウンドの更新を最も確実にするには、バッテリー設定でAVR Maestroのバックグラウンド実行を許可してください。
Android

ライト、ダーク、不透明度、コントラスト

設定の外観にある4つの項目で、すべてのウィジェットの見た目が決まります: 高コントラストウィジェット、ウィジェットをアプリの色に合わせる、ウィジェットの背景の不透明度、ウィジェットの外観。

  • ウィジェットの外観。システムのデフォルトはスマートフォンの設定に従い、ライトはすべてのウィジェットを淡いカードで、ダークは暗いカードで表示します。スマートフォンの設定は関係ありません。
  • ウィジェットの背景の不透明度。100%、75%、50%、25%、0% から選びます。100% ではカードが不透明になり、値を下げると壁紙が透けて見え、0% ではボタンと文字だけが残ります。
  • 高コントラストウィジェット。オレンジのアクセントをすべてグレースケールに置き換えます。
  • ウィジェットをアプリの色に合わせる。オレンジの代わりにカラーテーマのアクセントを使います。高コントラストウィジェットがオンの間は使えません。

ウィジェットの色

どちらの設定も、Android、iPhone、iPadの設定の外観にあります。

  • ハイコントラストウィジェットは、ウィジェットをグレースケールにします。
  • ウィジェットをアプリの色に合わせるは、ウィジェットにおなじみのオレンジの代わりに、カラーテーマのアクセントを使います。ハイコントラストウィジェットがオンの間は、このスイッチは使えず、ウィジェットはグレースケールのままです。
同じセクションのウィジェットサイズは、ホーム画面のウィジェットを変更しません。アプリ内のボタン、チップ、カードのサイズを調整します(小、中、大、特大)。設定をご覧ください。

外観、サイズ、背景の不透明度

  • ウィジェットの外観。設定の外観設定は、デバイスのテーマに関係なく、すべてのウィジェットをライトまたはダークで描画します。自動、ライト、ダークから選べます。Android では自動は「システムのデフォルト」と表示されます。自動ではデバイスに従い続けます。シーンの行も同様に従います。この設定はバックアップと復元の対象で、Android だけでなく iPhone と iPad でも表示されます。
  • 丸いガラス調のボタン。Android では、クイックコントロールの電源、音量、ミュートが、発光リング付きの丸いガラス調ボタンになり、ウィジェット全体に均等に配置されます。再生中も同じ丸いガラス調のアイコンボタンを使います。発光リングはライトとダークのどちらの外観でも表示されます。ウィジェットを引き伸ばしてもボタンの高さは固定のままなので、幅の広いウィジェットでボタンが巨大になることはありません。電源、音量を下げる、音量を上げる、ミュート、アプリを開く、シーンを適用は文字ではなくアイコンで表示されるため、どの言語でも同じように読め、それぞれの名前はお使いの言語でスクリーンリーダーが読み上げます。
  • 5 つのサイズ。iPhone と iPad では、コンテンツが 5 段階のサイズに合わせて拡大縮小します。Android では、クイックコントロールがサイズ変更に合わせて丸いボタンを 5 段階で拡大縮小し、Android 12 以降ではステータスが 5 つのサイズを切り替え、テキストは段階ごとに最大 30 パーセント大きくなります。ウィジェットは縦横どちらにもサイズ変更でき、カードとボタンはより丸みを帯び、再生中ではアルバムカバーが大きくなります。
  • ロック画面ウィジェット。iPhone と iPad では、ステータス、クイックコントロール、再生中に長方形のロック画面ウィジェットが追加されます。
  • 大きなサイズ。iPhone と iPad では、クイックコントロール、再生中、HDMI 出力に大きなサイズが追加されます。
  • ウィジェットの背景の不透明度。ウィジェットカードの不透明度を 100、75、50、25、0 パーセントにでき、ウィジェットを壁紙の上に透明に置くことができます。デフォルトは 100 パーセントで、従来と同じ見た目です。設定の外観と操作性の下にある行です。
Android:不透明度の行は 5 段階のままです。iPhone と iPad:ウィジェットの透明度は Apple が制御しているため、この行でその旨を説明し、ホーム画面のカスタマイズから「クリア」または「色合い」を選ぶよう案内します。不透明度が 0 のとき、ウィジェットのテキストはシステムの外観に従うため、ライトの外観でもシステムの暗い背景に暗い文字が描画されることはなくなります。
よくある質問

ウィジェット、よくある質問

AVR Maestroにはどのホーム画面ウィジェットがありますか?
AndroidとiPhoneまたはiPadで、6種類あります。Quick Control(電源、音量、ミュート)、Now Playing(再生中の内容と、前へ、再生または一時停止、次へ)、iPhoneではReceiver Status、AndroidではSignal Status(入力と音声・映像信号)、Scenes(保存したシーンを適用)、Multi-Room(固定したスピーカーやグループの再生内容と、再生および音量の操作)、HDMI Output(レシーバーのHDMI出力の切り替え)です。MacとWindowsにはウィジェットがありません。
ウィジェットはどのくらいの頻度で更新されますか?
クイックコントロールとステータスは約15分ごとに自動で更新され、Androidでは再生中も同様です。クイックコントロール、再生中、シーンには更新ボタンもあり、ウィジェットをすぐに更新できます。
ウィジェットに「AVR off」や「Standby」と表示されるのはなぜですか?
Standbyは、レシーバーがスタンバイ状態であることを意味します。AVR offは、ウィジェットがレシーバーに到達できなかったことを意味します。たとえば、電源が抜けている、または別のネットワークにある場合です。
シーンのウィジェットに、シーンがないと表示されるのはなぜですか?
ウィジェットには、選択中のレシーバーに保存されたシーンが一覧表示されます。先にAVR Maestroを開いてシーンを作成してください。シーンのガイドをご覧ください。
ウィジェットサイズで、ホーム画面のウィジェットは変わりますか?
いいえ。設定 › ウィジェットサイズで変わるのは、アプリ内のボタン、チップ、カードのサイズです。ホーム画面のウィジェットのサイズを変えるには、ホーム画面上でサイズを調整してください。
ウィジェットにテーマカラーを使えますか?
はい。設定 › ウィジェットをアプリの色に合わせるをオンにすると、ウィジェットがオレンジの代わりにアクセントカラーを使います。ハイコントラストウィジェットがオンの間は、そのウィジェットがグレースケールのため使えません。

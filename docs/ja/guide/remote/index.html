リモコン

本物のリモコンに、ライブの映像情報をプラス

十字キーと再生コントロールをフルに操作でき、ライブヘッダーには入力、サウンドモード、実際に使用中のチャンネルが表示されます。DenonやMarantzが今何をしているかが常にわかります。上部のページタブをスワイプまたはタップすると、最大5ページを移動できます。

最大5ページ

物理リモコンなしで、すべてを操作

リモコンタブを開きます。表示されるページはレシーバーによって異なり、レシーバーにない機能のページは表示されません。

  • メインリモコン:コマンドバー(電源 / 情報 / セットアップ / オプション / 戻る)、十字キー、再生操作、音量バー。ライブヘッダーには入力、サウンドモード、使用中のIN/OUTチャンネルが表示されます。
  • 入力:すべてのソースのグリッド。タイルをタップすると入力が切り替わります。タイルを長押しするとカスタムアイコンを設定できます。グリッドは、ご自身で付けた名前と順序を使います(下の入力の名前変更と並べ替えをご覧ください)。
  • Smart Select / Quick Select:AVR Maestroでは、お使いのレシーバーと同じ呼び方になります。MarantzならSmart Select、DenonならQuick Selectです。スロットをタップすると、レシーバーに保存されている内容を呼び出せます。長押しすると名前を変更または現在の状態を保存ができます(ウィザードで、どの設定を記録するかを細かく選べます)。スロット名の変更もレシーバーに保存されるため、他のアプリにも引き継がれます。
  • システム:レシーバー全体の直接コントロール(下記)。
  • トリガーアウト:12Vトリガー出力のあるレシーバーのみ。各トリガーをオンにするゾーン、入力、HDMI出力を選びます(下記参照)。
使わないページは設定 › タブをカスタマイズで非表示にできます。この設定はすべてのレシーバーに適用されます。
手順

入力の名前変更と並べ替え

入力に「Nvidia Shield」「Xbox」「PS5」のようなわかりやすい名前を付け、よく使うものを先頭に並べましょう。

  1. ホームタブで入力ソースカードをタップし、ソースの一覧を開きます。
  2. いずれかのタイルを長押しします。一覧が編集に切り替わります。タイルをタップして名前を変更するか、ドラッグして並べ替えます。終わったら完了をタップします。
  3. 名前を変更するには、タイルをタップし、新しい名前を入力して保存をタップします。
  4. 並べ替えるには、タイルを新しい位置にドラッグします。
  5. 完了をタップします。
新しい名前はレシーバー自体に書き込まれるので、メーカーのアプリや、古いシャーシを含むほかのクライアントにも表示され、アプリはソース名を変更しましたと知らせます。レシーバーが受け付けない場合はこのデバイスでのみソース名を変更しましたと表示され、名前はAVR Maestroにだけ残ります。順序はレシーバーごとに保存され、リモコンの入力ページでも使われます。
リモコン › システム

レシーバー全体の直接コントロール

システムページには、レシーバーが備えていると報告するものだけが表示されるため、モデルによって一覧は短くなります。表示される可能性のある項目を上から順に示します。

  • HDMI出力とイルミネーションまたはディマー(前面ディスプレイの明るさ)。
  • トリガー:12Vトリガーを手動でオンまたはオフにします。トリガーをゾーン、入力、HDMI出力に連動させるには、代わりにトリガーアウトページを使います。
  • ECOモード、オートスタンバイ、スリープタイマー。
  • HDMI CECとHDMIオーディオデコード(AMPまたはTV)。
  • スピーカープリセット:レシーバーのスピーカープリセットを切り替えます。
  • Bluetoothトランスミッター:Bluetoothヘッドホンやスピーカーに音声を送信できるモデルで使えます。トランスミッターをオンまたはオフにし、BT+スピーカー(Bluetoothと部屋のスピーカーを同時に使用)かBTのみを選びます。
  • ピクチャーモードと映像処理モード(Auto、Game、Movie、Bypass)。Game、Movie、Bypassは、HDMIソースが映像を再生している間のみ有効で、それ以外ではレシーバーはAutoのままです。
  • オールゾーンステレオ、オートリップシンク(Marantz)、オーディオディレイ、LFEレベル。
  • 入力モード(Auto、HDMI、Digital、Analog)。
  • デジタル入力フォーマット:Autoはレシーバーが判断し、PCMはPCMデコードを、DTSはDTSデコードを強制します。ソースが送るフォーマットをレシーバーが誤認識して無音になるときに使います。
レシーバーによっては、特定の入力やサラウンドモードが有効な間、デジタル入力フォーマットやLFEレベルをロックします。その場合、アプリはボタンの代わりに、現在の値とロックのバナーを表示します。入力やモードを変更した後は、見出しの横の更新アイコンをタップすると再確認できます。コントロールがロックされる理由をご覧ください。
リモコン › トリガーアウト

スクリーン、サブウーファー、アンプの電源を自動で入れる

12Vトリガー出力は、ほかの機器に電源オンを知らせます。トリガー出力のあるレシーバーでは、トリガーアウトページで各トリガーをオンにする条件を選べます。有効にした項目のいずれかがアクティブになると、トリガーが作動します。一覧はレシーバーからライブで読み取ります。

  1. リモコンタブを開き、トリガーアウトまでスワイプします。
  2. レシーバーに複数のトリガーがある場合は、上部でトリガーアウト1、トリガーアウト2などを選びます。
  3. ゾーン、ソース、HDMI出力にまとめられた項目のうち、作動させたいもののスイッチをオンにします。
各スイッチは、すぐにレシーバーへ送信されます。レシーバーが変更を受け付けない場合は、トリガーアウト:で始まるメッセージが知らせ、スイッチにはレシーバーの実際の状態が表示されます。トリガーのあるレシーバーでトリガーアウトを利用できませんと表示される場合、レシーバーがビジー状態の可能性があります。ブラウザーでWebコントロールのページを開いているなら閉じて、再試行をタップしてください。
音量は、思いのままに

音量をdBまたは相対スケールで表示

メインのリモコンの音量バーにはマスター音量がライブで表示され、ヘッダーのチップも同じ値を示します。dBよりレシーバー自体の数値のほうがよいですか? 表示をdBスケール(例: -40.5 dB、デフォルト)と0-98スケール(例: 39.5)で切り替えられます。ヘッダーのチップと音量バーの両方が、選んだ表示に従います。

  1. 設定 › レシーバーを管理を開き、お使いのレシーバーをタップします。
  2. オーディオの下でリモコンの音量表示を開き、スケールを選びます。
この選択はレシーバーごとに保存されるので、2台のレシーバーで異なるスケールを表示できます。
長押し

音量ボタンは、リモコンと同じように連続変化

プラスまたはマイナスをタップすると、音量が1ステップ動きます。押し続けると、指を離すまで滑らかに動き続けます。物理リモコンと同じ動作で、手の感覚どおりです。指を離せば、レシーバーは止めたステップにぴったり止まり、行き過ぎることはありません。

内部では、アプリがコマンドをまとめて処理しています。向かう先を蓄積し、実際に送信する量をペース配分するため、長押ししても応答の遅いレシーバーに負荷をかけません。小さな変化も滑らかで、数デシベルの変更でも一気に飛ばず、なだらかに変化します。

信号をライブで確認

入ってくる信号と、出ていく信号

リモコンのヘッダーには、コンパクトなチャンネルストリップがあります。1行目に入力信号、もう1行にレシーバーが駆動している出力を表示し、レシーバーが認識しているスピーカーをすべて示します。ネットワーク経由のステレオ曲なら、入力は2チャンネル、出力はフルアップミックスと表示されます。

よくある質問

リモコンのよくある質問

入力の名前変更や並べ替えはできますか?
はい。ホームタブで入力ソースカードをタップし、いずれかのタイルを長押しすると編集が始まります。タイルをタップして名前を変更し、ドラッグして並べ替え、終わったら完了をタップします。新しい名前はレシーバー自体に書き込まれるので、メーカーのアプリやほかのクライアントにも表示されます。レシーバーが受け付けない場合、アプリはこのデバイスでのみソース名を変更しましたと表示します。順序はレシーバーごとに保存され、リモコンの入力ページもそれに従います。
入力にカスタムアイコンを設定できますか?
はい。入力タイルを長押しして好きな画像(PNG、JPG、ICO、WebPなど)を選び、パスポート写真風のトリミング画面で位置を調整して保存します。手順の詳細は、カスタム入力アイコンのガイドをご覧ください。
バーチャルリモコンでは何を操作できますか?
メインのリモコンページには、コマンドバー(電源/情報/セットアップ/オプション/戻る)、十字キー、再生コントロール、音量があり、上部のヘッダーには入力、サウンドモード、使用中のチャンネルがライブで表示されます。システムページでは、直接コントロール(HDMI出力、ディマー、トリガー、ECO、スリープ、CEC、Bluetoothトランスミッター、デジタル入力フォーマットなど)を追加し、レシーバーに12Vトリガー出力がある場合は、別にトリガーアウトページが表示されます。レシーバーが対応していないものは非表示です。
Smart Select / Quick Selectとは何ですか?
Marantzのスマートセレクト(Smart Select)とDenonのクイックセレクト(Quick Select)は、どちらもレシーバー自体のメモリースロットです。AVR Maestroでは、お使いのレシーバーと同じ呼び方になります。Marantzなら Smart Select、Denonなら Quick Select です。タップで呼び出し、長押しで名前の変更や、キャプチャウィザードによる現在の状態の保存ができます。
トリガーアウトページとは何ですか?
レシーバーに12Vトリガー出力がある場合、リモコンに表示されます。トリガーごとに、どのゾーン、入力ソース、HDMI出力でオンにするかを選びます。有効にした項目のいずれかがアクティブになるとトリガーが作動するので、プロジェクタースクリーン、サブウーファー、アンプを自動で起動できます。一覧はレシーバーからライブで読み取ります。レシーバーが変更を受け付けない場合は、アプリがその旨を知らせ、レシーバーの実際の状態を表示します。
デスクトップ版のAVR Maestroにキーボードショートカットはありますか?
はい。MacとWindowsでは、再生操作と音量をキーボードから操作できます。macOSではCmd、WindowsではCtrlを使います。Spaceで再生/一時停止、.(ピリオド)で停止、左/右で前/次のトラック、上/下で音量、Mでミュートです。専用のメディアキー(再生、一時停止、次へ、前へ、停止、音量、ミュート)も使えます。テキスト入力中はショートカットが一時停止します。

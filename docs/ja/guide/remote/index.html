リモコン

本物のリモコンに、ライブの映像情報をプラス

十字キーと再生操作をフルに備え、ライブヘッダーに入力、サウンドモード、実際に使用中のチャンネルを表示します。Denon・Marantzがいま何をしているか、いつでも一目でわかります。ページは4つあり、スワイプまたはページタブのタップで切り替えます。

4つのページ

物理リモコンなしで、すべてを操作

  • メインリモコン:コマンドバー(電源 / 情報 / セットアップ / オプション / 戻る)、十字キー、再生操作、音量バー。ライブヘッダーには入力、サウンドモード、使用中のIN/OUTチャンネルが表示されます。
  • 入力:すべてのソースを一覧できるグリッド。お手持ちの機器に合わせて、ソースの名前変更と並べ替えができます。ソースリストを開き、タイルをタップして編集し、ソースをタップして名前を変更、ドラッグして並べ替えます。名前の変更はレシーバー本体に書き込まれるため、ここでも、メーカーのアプリでも、その他すべてのクライアントでもすぐに反映されます。古い機種でも同様です。並び順はレシーバーごとに保存されます。
  • Smart Select / Quick Select:AVR Maestroでは、お使いのレシーバーと同じ呼び方になります。MarantzならSmart Select、DenonならQuick Selectです。スロットをタップすると、レシーバーに保存されている内容を呼び出せます。長押しすると名前を変更または現在の状態を保存ができます(ウィザードで、どの設定を記録するかを細かく選べます)。スロット名の変更もレシーバーに保存されるため、他のアプリにも引き継がれます。
  • システム:HDMI出力、ディマー/イルミネーション、トリガー、ECO、オートスタンバイ、スリープタイマー、CEC、HDMIオーディオ出力、スピーカープリセット、映像/ビデオモード、オールゾーンステレオ、オートリップシンク、オーディオディレイ、入力モードを直接操作できます。非対応の項目は非表示になります。
音量は、思いのままに

音量をdBまたは相対スケールで表示

メインリモコンの音量バーにはマスター音量がリアルタイムで表示され、ヘッダーのチップにも同じ値が反映されます。デシベルよりレシーバー本来の数値のほうが好みですか?設定で、音量表示を絶対値(dB)(例:-62.5 dB)と相対スケールで切り替えられます。ヘッダーのチップも音量バーも選択に従うので、リモコン全体があなたの使い慣れた単位で表示されます。

長押し

音量ボタンは、リモコンと同じように連続変化

プラスまたはマイナスをタップすると、音量が1ステップ動きます。押し続けると、指を離すまで滑らかに動き続けます。物理リモコンと同じ動作で、手の感覚どおりです。指を離せば、レシーバーは止めたステップにぴったり止まり、行き過ぎることはありません。

内部では、アプリがコマンドをまとめて処理しています。向かう先を蓄積し、実際に送信する量をペース配分するため、長押ししても応答の遅いレシーバーに負荷をかけません。小さな変化も滑らかで、数デシベルの変更でも一気に飛ばず、なだらかに変化します。

信号をライブで確認

入ってくる信号と、出ていく信号

リモコンのヘッダーには、コンパクトなチャンネルストリップがあります。1行目に入力信号、もう1行にレシーバーが駆動している出力を表示し、レシーバーが認識しているスピーカーをすべて示します。ネットワーク経由のステレオ曲なら、入力は2チャンネル、出力はフルアップミックスと表示されます。

よくある質問

リモコンのよくある質問

入力の名前変更や並べ替えはできますか?
はい。ソースリストを開き、タイルをタップして編集し、ソースをタップして名前を変更、ドラッグして並べ替えます。「Nvidia Shield」「Xbox」「PS5」のように名前を付けると、新しい名前はレシーバー本体に書き込まれるため、AVR Maestro、メーカーのアプリ、その他すべてのクライアントですぐに反映されます。古い機種でも同様です。並び順はレシーバーごとにどの端末でも保存されます。
入力にカスタムアイコンを設定できますか?
はい。入力タイルを長押しして好きな画像(PNG、JPG、ICO、WebPなど)を選び、パスポート写真風のトリミング画面で位置を調整して保存します。手順の詳細は、カスタム入力アイコンのガイドをご覧ください。
バーチャルリモコンでは何を操作できますか?
コマンドバー(電源/情報/セットアップ/オプション/戻る)、十字キー、再生操作、音量を備え、ライブヘッダーに入力、サウンドモード、使用中のチャンネルが表示されます。システムページでは、HDMI出力、ディマー、トリガー、ECO、スリープ、CECなどを直接操作できます。非対応の項目は非表示になります。
Smart Select / Quick Selectとは何ですか?
Marantzのスマートセレクト(Smart Select)とDenonのクイックセレクト(Quick Select)は、どちらもレシーバー自体のメモリースロットです。AVR Maestroでは、お使いのレシーバーと同じ呼び方になります。Marantzなら Smart Select、Denonなら Quick Select です。タップで呼び出し、長押しで名前の変更や、キャプチャウィザードによる現在の状態の保存ができます。
デスクトップ版のAVR Maestroにキーボードショートカットはありますか?
はい。MacとWindowsでは、再生操作と音量をキーボードから操作できます。macOSではCmd、WindowsではCtrlを使います。Spaceで再生/一時停止、.(ピリオド)で停止、左/右で前/次のトラック、上/下で音量、Mでミュートです。専用のメディアキー(再生、一時停止、次へ、前へ、停止、音量、ミュート)も使えます。テキスト入力中はショートカットが一時停止します。

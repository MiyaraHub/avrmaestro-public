AVR Maestro用語集

AVR Maestroとこのガイドで使われる用語を、短くやさしく説明します。このうちどれがお使いのレシーバーにあるかは、モデルによって異なります。

アプリ

  • シーン。入力、サウンドモード、音量など、レシーバーの設定を組み合わせて保存したもので、ワンタップで適用できます。シーンをご覧ください。
  • Quick Select / Smart Select。入力、音量、サウンドモードを記憶するレシーバー本来のメモリースロット。DenonはQuick Select、MarantzはSmart Selectと呼びます。リモコンをご覧ください。
  • 音量プリセット。アプリに保存できる8つの音量レベルのひとつ。タップするとその音量に切り替わります。音量をご覧ください。
  • デモモード。アプリ内でシミュレートされたMarantz CINEMA 30を動かし、レシーバーがなくてもすべての画面を試せます。ネットワークには何も送信されません。
  • ホームオートメーションPro。レシーバーをHome Assistant、Hubitat、Webhookに接続するアドオン。ホームオートメーションをご覧ください。
  • アシスタント。普通の言葉でレシーバーの変更を頼めます。お使いのデバイス上で動作し、対応しているデバイスにのみ表示されます。アシスタントをご覧ください。
  • Webhook。別のシステムがアプリに何かを実行させるために呼び出す、またはアプリが何かが起きたときに呼び出すWebアドレス。
  • Home Assistant / HACS / Hubitat。ホームオートメーションのシステム。HACSはHome Assistant Community Storeで、アドオンのインストールに使います。Home Assistantダッシュボードをご覧ください。
  • ロックされたコントロール。サウンドモードや信号などが原因で、レシーバーが現在変更を受け付けない設定。ロックされたコントロールをご覧ください。

ネットワークと接続

  • IPアドレス。ホームネットワーク上のレシーバーのアドレス。例: 192.168.1.20。アプリはこれを使って接続します。
  • MACアドレス。レシーバーのネットワークポートに固有のハードウェアID。デバイス情報に表示されます。
  • HTTPとTelnet。アプリがネットワーク経由でレシーバーと通信する2つの方法。HTTPがコマンドを送り、Telnetがライブの更新を返します。
  • HEOS。新しめのDenonおよびMarantzレシーバーに内蔵されたストリーミングとマルチルームのシステム。再生中をご覧ください。
  • Network Standby。スタンバイ中もネットワークをオンに保つレシーバーの設定。これによりアプリから電源を入れられます。

キャリブレーションと音場補正

  • Audyssey MultEQ。DenonとMarantzの音場補正。マイクで部屋を測定し、音を補正します。MultEQ XT32が最も精密なバージョンです。
  • Dynamic EQ。小音量でも低音とサラウンドのバランスを保つAudysseyの機能。オンの間は、トーンコントロールがロックされます。
  • Reference Level Offset。コンテンツがどれくらいの音量でミックスされたかをDynamic EQに伝え、補正を調整します。
  • Dynamic Volume。突然の大きな音と小さな音の差をならすAudysseyの機能。
  • LFC(Low Frequency Containment)。隣の部屋に届く低音を抑えるAudysseyの機能。Containment Amountで抑える量を設定します。
  • Dirac Live。Diracの音場補正で、一部のレシーバーで利用できます。有効にするとAudysseyの代わりに使われます。結果はスロットに保存されます。
  • スピーカープリセット。プリセット1またはプリセット2。レイアウト、距離、レベル、クロスオーバー、キャリブレーションをそれぞれ持つ、2つの完全なスピーカー設定です。

サウンドモードと処理

  • Dolby Atmos / DTS:X。ハイトチャンネルを含むサラウンドフォーマット。
  • Dolby Surround。Dolbyのアップミキサー。ステレオやサラウンドをすべてのスピーカーに広げます。Center Spreadはこのモードでのみ機能します。
  • Neural:X。DTSのアップミキサー。DTS:Xのサウンドモードで利用できます。
  • Auro-3D / Auro-Matic。Auro Technologiesのイマーシブフォーマットとアップミキサー。対応するレシーバーで利用できます。
  • IMAX Enhanced。IMAX Enhancedコンテンツ用の設定。対応するレシーバーで利用できます。
  • Pure Direct / Direct。ほとんどの処理を省いて、最もクリーンな信号経路にするサウンドモード。
  • DRC(ダイナミックレンジ圧縮)。大きな音と小さな音の差を小さくします。Dolby信号で機能します。
  • Loudness Management。Dolbyコンテンツを一定のレベルに保ちます。
  • Dialog Enhancer。声を聞き取りやすくします。
  • Cinema EQ。映画のサウンドトラックのきつい高音を和らげます。
  • M-DAX。圧縮された音楽のディテールを復元するMarantzの機能。Off、Low、Med、Highから選びます。
  • Restorer。圧縮された音楽のディテールを復元するDenonの機能。
  • Speaker Virtualizer。お持ちでないスピーカーを仮想的に再現します。
  • Room Size、Panorama、Dimension、Center Width。音場の広がり方の調整で、サウンド › シェイプにあります。
  • トーンコントロール。低音と高音の調整。サウンドをご覧ください。
  • グラフィックEQ。スピーカーごとのバンド別イコライザー。グラフィックEQをご覧ください。

スピーカーと低音

  • Amp Assign。レシーバーのアンプチャンネルの使い方。たとえばハイトスピーカーや第2ゾーンに割り当てます。
  • クロスオーバー。この周波数より下のスピーカーの低音を、代わりにサブウーファーへ送る境目の周波数。
  • HPF / LPF。ハイパスフィルターとローパスフィルター。音をスピーカーとサブウーファーに振り分けます。
  • バス管理。レシーバーがスピーカーとサブウーファーの間で低音をどう振り分けるか。
  • LFE。Low Frequency Effects。映画のサウンドトラックに含まれる独立した低音チャンネルで、5.1の「.1」にあたります。
  • サブウーファーモード。LFEは低音チャンネルだけをサブウーファーに送ります。LFE + Mainは、メインスピーカーの低音も送ります。
  • チャンネルレベル。各スピーカーの、他のスピーカーに対する音量。
  • 距離。各スピーカーから座席までの距離。レシーバーはこれを使って音のタイミングを合わせます。
  • Center Level Adjust。センタースピーカーを手早く上げ下げする調整。
  • スピーカーグリッド。お使いのスピーカーと、どれが鳴っているかを示すアプリのライブ表示。スピーカーをご覧ください。

レシーバーとシステム

  • Zone 2 / Zone 3。レシーバーが音を出せる追加の部屋で、それぞれ電源、音量、入力を持ちます。マルチゾーンをご覧ください。
  • オールゾーンステレオ。メインゾーンのソースをすべてのゾーンで再生します。
  • HDMI CEC。テレビとレシーバーがHDMI経由で互いを制御できるようにします。
  • eARC。Enhanced Audio Return Channel。テレビからレシーバーへ、HDMI経由でフル品質の音を送ります。
  • ECOモード。レシーバーの省電力機能。
  • オートスタンバイ。一定時間、信号も操作もないとレシーバーをオフにします。
  • スリープ。レシーバーをオフにするタイマー。
  • トリガーアウト。レシーバーに合わせて、スクリーンやアンプなどの他の機器をオン/オフする12V出力。搭載するレシーバーでは、リモコンに専用のサブタブがあります。
  • デジタル入力フォーマット。レシーバーがデジタル入力をどう読み取るかを固定します。Auto、PCM、DTSから選びます。
  • Bluetoothトランスミッター。レシーバーの音をBluetoothヘッドフォンやスピーカーに送ります。
  • セットアップロック / リモートロック。メニューの変更やリモコン操作を防ぐレシーバーのロック。ロックされたコントロールをご覧ください。
  • オンスクリーンディスプレイ。音量など、レシーバーがテレビに表示する情報。オンスクリーンディスプレイをご覧ください。
  • 信号情報。入力と出力の音声および映像フォーマット。色空間や画素深度など。
よくある質問

用語、よくある質問

Quick SelectとSmart Selectは同じものですか?
はい。レシーバーのメモリースロットを、DenonはQuick Select、MarantzはSmart Selectと呼んでいます。AVR Maestroは、お使いのレシーバーに合った名前を使います。
LFEとサブウーファーの違いは何ですか?
LFEはサウンドトラックに含まれる独立した低音チャンネルです。サブウーファーはそれを再生するスピーカーで、レシーバーが他のスピーカーから振り分けた低音も再生します。
AudysseyとDirac Liveの両方が必要ですか?
いいえ。これらは2種類の音場補正です。Dirac Live対応のレシーバーでは、有効なDirac Liveキャリブレーションがある場合、Audysseyの代わりに使われます。

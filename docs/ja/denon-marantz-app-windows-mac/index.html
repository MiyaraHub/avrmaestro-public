キーボードショートカット

キーボードでレシーバーを操作

Mac App StoreとMicrosoft Store版では、macOSはCmd、WindowsはCtrlを使います。キーボードのメディアキーも使え、テキストフィールドに入力している間は何も反応しません。詳しくはリモコンガイドをご覧ください。

ショートカット動作
Cmd + Space / Ctrl + Space再生 / 一時停止
Cmd + . / Ctrl + .(ピリオド)停止
Cmd + Left / Right、Ctrl + Left / Right前 / 次のトラック
Cmd + Up / Down、Ctrl + Up / Down音量を上げる / 下げる

WindowsとMac、よくある質問

Windows用のDenonまたはMarantzアプリはありますか?
はい。AVR MaestroはMicrosoft Storeで提供され、レシーバーと同じネットワーク上のWindows PCから、ネットワーク対応のDenonおよびMarantz AVレシーバーを操作できます。
Mac用のDenonまたはMarantzアプリはありますか?
はい。AVR MaestroはMac App Storeで提供され、Cmdキーのキーボードショートカットとメディアキーに対応しています。
デスクトップアプリにキーボードショートカットはありますか?
はい。macOSではCmd、WindowsではCtrlを使います。Spaceで再生/一時停止、.(ピリオド)で停止、Left/Rightで前/次のトラック、Up/Downで音量、Mでミュートです。メディアキーも使え、テキストフィールドに入力している間はショートカットが一時停止します。
Windowsでもアシスタントは使えますか?
いいえ。アシスタントにはオンデバイスモデルが必要です。iPhone、iPad、Mac(macOS 26)ではApple Intelligence、AndroidではGemini Nanoです。このリストのそれ以外の機能はすべてWindowsで使えます。アシスタントガイドをご覧ください。

デスクからレシーバーを操作

買い切り。広告なし、サブスクリプションなし。DenonやMarantzのレシーバーに1分足らずで接続できます。

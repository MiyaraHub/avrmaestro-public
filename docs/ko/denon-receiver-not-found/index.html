리시버를 찾을 수 없을 때의 답변

AVR Maestro가 내 Denon 또는 Marantz 리시버를 찾지 못하는 이유는 무엇인가요?
휴대폰과 리시버는 같은 네트워크와 서브넷에 있어야 합니다. 메시 시스템, 게스트 네트워크, IoT VLAN은 기기를 서로 격리할 수 있습니다. 리시버의 전원이 켜져 있고 Network Control이 On으로 설정되어 있는지 확인한 뒤 다시 시도하거나, IP 주소로 직접 추가하세요.
Network Control은 어디에서 켜나요?
리시버에서 Setup을 열고 General 또는 Network로 이동한 다음 Network Control을 On으로 설정하면 대기 모드에서도 리시버에 접속할 수 있습니다. 정확한 메뉴 경로는 모델마다 다릅니다.
리시버의 IP 주소는 어디에서 확인하나요?
리시버 자체의 Network, Information 화면에서 확인합니다. DHCP 주소는 바뀔 수 있으므로 잘 되던 리시버가 연결되지 않으면 다시 확인하거나, 공유기에서 주소를 고정하세요.
연결이 계속 끊깁니다. 어떻게 해야 하나요?
리시버의 전원 플러그를 뽑았다가 다시 꽂아 멈춘 Telnet 리스너를 초기화하세요. Wi-Fi 6 메시에서는 휴대폰을 리시버와 같은 대역에 연결하세요. 리시버는 보통 2.4 GHz를 사용하고 휴대폰은 5 GHz를 선호하기 때문입니다.
네트워크 사용 중 메시지는 무슨 뜻인가요?
리시버에는 접속할 수 있지만 네트워크 스택이 포화된 상태입니다. 보통 여러 컨트롤러 앱이 동시에 연결을 유지하고 있기 때문입니다. 다른 컨트롤러를 닫거나 몇 초 기다려 보세요.
내 리시버 모델도 지원되나요?
모델 허용 목록은 없습니다. AVR Maestro는 연결할 때 리시버가 지원하는 기능을 감지하므로, 리시버의 웹 포털과 Denon 또는 Marantz 공식 앱이 리시버에 접속할 수 있다면 AVR Maestro도 접속할 수 있습니다.

FM/AM 튜너

이름을 붙이는 프리셋까지, 진짜 FM/AM 라디오

내장 튜너가 있는 Denon 및 Marantz 리시버에서 AVR Maestro가 본격적인 FM/AM 라디오 화면을 제공합니다. 방송국 카드에 현재 밴드, 주파수, 활성 프리셋이 표시되며 리시버와 실시간으로 동기화됩니다.

사용 방법

튜닝하고, 검색하고, 저장하세요

  • 밴드: FM / AM. 튜닝 모드: 자동(다음으로 강한 방송국까지 검색) 또는 수동(밴드 간격 단위로 이동).
  • 튜닝: 튜닝 버튼 두 개로 다이얼을 한 단계씩 움직입니다. 주파수 입력은 키패드를 열어 원하는 방송국으로 바로 이동합니다(수동 모드 필요).
  • 프리셋: 프리셋 슬롯 그리드와 위/아래 스테퍼입니다. 슬롯을 길게 누르면 현재 방송국 저장, 라벨 추가 / 이름 변경("Jazz 88", "NPR"), 라벨 지우기를 선택할 수 있습니다.
라디오 탭이 숨겨져 있다면 설정 → 탐색 메뉴 설정에서 다시 추가하세요. 리시버에서 튜너가 확인될 때만 나타납니다.
자주 묻는 질문

튜너 자주 묻는 질문

앱에서 FM/AM 라디오를 제어할 수 있나요?
네, 내장 튜너가 있는 리시버에서 가능합니다. 밴드, 주파수, 프리셋 실시간 표시와 FM/AM 전환, 자동 또는 수동 튜닝, 주파수로 바로 이동하는 키패드, 프리셋 그리드를 지원합니다.
프리셋에 이름을 붙일 수 있나요?
네. 슬롯을 길게 눌러 현재 방송국을 저장하고, 라벨("Jazz 88", "NPR")을 추가하거나 이름을 바꾸거나 지울 수 있습니다.
라디오 탭이 보이지 않는 이유는 무엇인가요?
내장 튜너가 있는 리시버에서만 나타납니다. 튜너가 있다면 입력에 튜너가 표시되는지 확인한 뒤, 설정, 탐색 메뉴 설정에서 탭을 다시 켜세요.

이동하기

탭, 스와이프, 제스처

AVR Maestro에서 이동하는 방법을 안내합니다. 하단 탭과 변경 방법, 페이지 간 스와이프, 탭과 길게 누르기의 동작, 뒤로 버튼, 업데이트 알림, 메시지, 컴퓨터의 키보드 단축키를 다룹니다.

하단 탭

화면 하단의 바에 주요 탭이 있습니다. 기본 상태에서는 홈, 리모컨, 사운드, 존, 장면, 스피커, 설정이며 라디오도 추가할 수 있습니다. 모든 탭의 바 오른쪽 끝에 검색 버튼이 있습니다(검색 참고).

  • 홈은 항상 포함되며 항상 맨 앞에 옵니다.
  • 라디오는 선택한 리시버에 튜너가 있을 때만 나타납니다. 라디오를 참고하세요.
  • 탭은 2개에서 7개까지 둘 수 있습니다.
단계별 안내

탭 추가, 제거, 순서 변경

  1. 설정 › 내비게이션 사용자 지정을 여세요. 상단에 바의 미리 보기가 표시됩니다.
  2. 사용 가능한 탭에서 탭을 선택하면 추가되고 선택을 해제하면 제거됩니다.
  3. 활성 탭에서 행의 핸들을 드래그해 순서를 바꾸세요.
  4. 저장을 탭하세요. 내비게이션이 업데이트되었습니다 메시지로 확인할 수 있습니다. 재설정을 누르면 기본 구성과 순서로 돌아갑니다.
단계별 안내

쓰지 않는 하위 탭 숨기기

사운드, 스피커, 리모컨 탭에는 각각 상단에 하위 탭 행이 있습니다. 예를 들어 사운드에는 Audyssey, Dirac Live, 그래픽 EQ, 채널, 톤이 있습니다.

  1. 설정 › 탭 사용자 지정(쓰지 않는 하위 보기 숨기기)을 여세요.
  2. 사운드, 스피커, 리모컨 아래에서 원하지 않는 하위 보기를 각각 끄세요. 미리 보기에 결과가 표시됩니다.
  3. 뒤로 돌아가세요. 변경 사항은 모든 리시버에 적용됩니다.
리시버가 기능을 지원하지 않는 경우, 예를 들어 Audyssey가 없는 리시버의 Audyssey는 하위 탭이 이미 숨겨져 있으며 여기에 표시되지 않습니다. 탭 사용자 지정은 그 위에 더해지는 두 번째 단계입니다.

페이지 간 스와이프

  • 페이지에서 왼쪽 또는 오른쪽으로 스와이프하면 다음 또는 이전 하위 탭으로 이동합니다.
  • 마지막 하위 탭에서 계속 스와이프하면 다음 하단 탭으로 넘어갑니다. 마지막 탭을 지나면 설정한 순서대로 처음 탭으로 돌아갑니다.
  • 하단 탭 바를 따라 스와이프하면 탭을 바로 전환합니다. 이 경우에도 처음으로 돌아갑니다.
  • 슬라이더가 있는 페이지에서는 천천히 드래그하면 슬라이더가 움직입니다. 페이지를 바꾸려면 빠르게, 거의 수평으로 튕기듯 스와이프해야 합니다.

iPhone, iPad, Mac에서 한 단계 뒤로 스와이프

안내형 장면 만들기, 환영 및 설정 안내, Home Assistant 로그인 페이지에서는 화면 왼쪽 가장자리에서 안쪽으로 스와이프하면 한 단계 뒤로 갑니다. 오른쪽에서 왼쪽으로 쓰는 언어에서는 오른쪽 가장자리에서 스와이프하세요. 화면의 절반 넘게 스와이프하거나 빠르게 튕기세요.

탭과 길게 누르기

많은 컨트롤은 탭하면 하나의 동작을, 길게 누르면 다른 동작을 합니다.

  • 볼륨 프리셋. 프리셋 슬롯은 8개입니다. +가 표시된 빈 슬롯을 탭하면 현재 볼륨이 저장됩니다. 저장된 슬롯을 탭하면 해당 볼륨으로 이동합니다. 슬롯을 길게 누르면 현재 볼륨으로 덮어쓰거나 슬롯을 비울 수 있습니다. 프리셋으로 바로 이동하지 않고 서서히 변하게 하려면 설정 › 리시버 관리 › 내 리시버 › 오디오에서 점진적 볼륨 프리셋을 켜세요. 볼륨을 참고하세요.
  • Quick Select와 Smart Select. 슬롯을 탭하면 불러옵니다. 길게 누르면 현재 상태 저장 또는 이름 변경을 선택할 수 있습니다.
  • 홈 입력 그리드. 길게 누르면 그리드 편집이 시작됩니다. 홈 화면을 참고하세요.
  • 리모컨 입력. 입력을 길게 누르면 사용자 지정 아이콘을 지정할 수 있습니다. 사용자 지정 아이콘을 참고하세요.
  • 존 이름. 존 이름을 길게 누르면 이름을 변경할 수 있습니다. 멀티 존을 참고하세요.
  • 라디오 프리셋. 탭하면 불러오고, 길게 누르면 현재 방송국을 저장합니다. 라디오를 참고하세요.
  • 장면. 탭하면 적용하고, 길게 누르면 옵션이 표시됩니다. 장면을 참고하세요.
  • 리시버. 설정 › 리시버 관리에서 리시버를 길게 누르면 옵션이 표시됩니다.
  • 설명 카드. 배너를 탭하면 펼쳐지고, 길게 누르면 닫힙니다. 설정 › 숨긴 카드 복원에서 다시 불러올 수 있습니다.

뒤로, 종료, 메시지

  • 하위 페이지에서 뒤로를 누르면 탭 맨 위로 돌아갑니다. 홈에서 편집 중이라면 뒤로가 먼저 편집 모드를 종료합니다.
  • 탭 맨 위에서 뒤로를 누르면 AVR Maestro를 종료하시겠습니까?라고 묻습니다. 앱을 닫으려면 앱 종료를, 그대로 두려면 취소를 탭하세요. Android의 뒤로 버튼과 뒤로 제스처에 적용됩니다.
  • 화면 하단의 메시지에는 닫기 버튼이 있습니다. 오류 메시지는 닫을 때까지 유지됩니다. 다른 메시지는 몇 초 후 저절로 닫히며, 긴 메시지일수록 더 오래 표시됩니다. 새 메시지가 오면 화면의 메시지를 대체합니다.
휴대폰의 접근성 내비게이션 설정이 켜져 있으면 모든 메시지가 닫을 때까지 유지됩니다.

업데이트가 있을 때

AVR Maestro의 새 버전이 게시되면 홈 화면에 업데이트 가능이 표시됩니다.

  • 업데이트를 누르면 Google Play, App Store 또는 Microsoft Store의 앱 페이지가 열립니다.
  • 나중에를 누르면 3일 동안 알림이 숨겨집니다.
  • 이 버전 건너뛰기를 누르면 해당 버전의 알림이 더 이상 표시되지 않습니다.
필수로 지정된 버전이면 알림에 업데이트 필요가 표시되고 업데이트 버튼만 있으며 닫을 수 없습니다.

Windows와 Mac의 키보드 단축키

Windows에서는 Ctrl, Mac에서는 Cmd와 함께 다음을 사용하세요.

  • 위 / 아래 화살표: 볼륨 높이기 또는 낮추기
  • M: 음소거 켜기 또는 끄기
  • Space: 재생 또는 일시정지
  • 오른쪽 / 왼쪽 화살표: 다음 또는 이전 트랙
  • 마침표 (.): 정지

키보드의 미디어 키(재생, 일시정지, 다음, 이전, 정지, 볼륨, 음소거)도 작동합니다.

텍스트 필드에 입력하는 동안에는 단축키가 작동하지 않습니다. 음소거와 재생 또는 일시정지는 리시버가 현재 상태를 보고할 때까지 기다립니다.

플랫폼별 참고 사항

  • Android: 뒤로를 누르면 종료 전에 확인합니다. 앱이 열려 있는 동안 휴대폰의 볼륨 버튼으로 리시버의 볼륨을 바꿀 수 있습니다(리시버별 기기 볼륨 버튼, 기본값은 켜짐).
  • iPhone과 iPad: 안내형 흐름에서는 가장자리에서 스와이프해 한 단계 뒤로 갑니다. 기기 볼륨 버튼도 여기서 작동합니다.
  • Mac: 가장자리 스와이프로 한 단계 뒤로, Cmd 단축키, 미디어 키.
  • Windows: Ctrl 단축키와 미디어 키.
FAQ

내비게이션, 질문과 답변

AVR Maestro 하단에 표시되는 탭을 바꾸려면 어떻게 하나요?
설정 › 내비게이션 사용자 지정을 여세요. 사용 가능한 탭에서 탭의 선택을 해제하면 제거되고, 선택하면 추가됩니다. 활성 탭 아래의 행을 드래그해 순서를 바꾼 다음 저장을 탭하세요. 홈은 항상 포함되며 항상 맨 앞에 옵니다. 탭은 2개에서 7개까지 둘 수 있습니다.
IMAX나 Auro-3D처럼 쓰지 않는 하위 탭을 숨기려면 어떻게 하나요?
설정 › 탭 사용자 지정을 열고 사운드, 스피커, 리모컨 아래에서 원하지 않는 하위 보기를 끄세요. 이 선택은 모든 리시버에 적용됩니다. 리시버가 지원하지 않는 기능은 이미 숨겨져 있으며 이 목록에 표시되지 않습니다.
라디오 탭이 없는 이유는 무엇인가요?
라디오는 설정 › 내비게이션 사용자 지정에서 추가할 수 있지만, 선택한 리시버에 튜너가 있을 때만 탭이 나타납니다.
탭 사이를 스와이프할 수 있나요?
네. 페이지에서 왼쪽 또는 오른쪽으로 스와이프하면 하위 탭을 이동합니다. 마지막 하위 탭에서 한 번 더 스와이프하면 다음 하단 탭으로 넘어가고, 마지막 탭에서는 처음 탭으로 돌아갑니다. 하단 탭 바 자체를 따라 스와이프할 수도 있습니다.
AVR Maestro는 종료하기 전에 왜 확인하나요?
Android에서는 탭 맨 위에서 뒤로를 누르면 AVR Maestro를 종료하시겠습니까?라고 물어, 실수로 뒤로를 눌러도 앱이 닫히지 않습니다. 앱 종료를 탭하면 닫히고 취소를 탭하면 그대로 유지됩니다. 하위 페이지에서는 뒤로를 누르면 먼저 탭 맨 위로 돌아갑니다.
Windows와 Mac에서 AVR Maestro의 키보드 단축키를 사용할 수 있나요?
네. Windows에서는 Ctrl, Mac에서는 Cmd와 함께 위 또는 아래 화살표를 누르면 볼륨이 바뀌고, M은 음소거 전환, Space는 재생 또는 일시정지, 왼쪽 또는 오른쪽 화살표는 이전 또는 다음 트랙으로 건너뛰기, 마침표 키는 정지입니다. 키보드의 미디어 키도 작동합니다. 텍스트 필드에 입력하는 동안에는 단축키가 작동하지 않습니다.

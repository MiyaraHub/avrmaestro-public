홈 화면

홈 화면: 나만의 방식으로 꾸미는 홈 베이스

맨 위에는 모델, 연결, 전원이 표시되는 장치 상태 카드가 고정되어 있고, 그 아래에는 사용자 지정이 가능한 위젯 그리드가 있습니다. 카드를 추가, 제거, 재배열해서 홈 화면에 꼭 필요한 정보만 표시하세요.

나만의 스타일로

몇 초 만에 사용자 지정

왼쪽 위의 홈 사용자 지정 아이콘을 탭하면 편집 모드로 들어갑니다.

  • 카드를 드래그해서 순서를 바꿉니다.
  • 빨간 원을 탭해 카드를 제거합니다.
  • 추가를 누르면 아직 없는 위젯 목록이 열립니다.
  • 초기화는 기본값을 복원하고, 완료는 편집을 마칩니다.
편집하는 동안 카드가 흐리게 표시되어 리시버 설정을 실수로 바꾸지 않습니다. 위젯은 리시버가 해당 기능을 지원할 때만 표시됩니다. 처음 시작하는 홈 화면에는 Smart Select / Quick Select, 볼륨, 소스, 사운드 모드, 장면, 신호 정보, 재생 중, 존이 있습니다. 모든 카드에 대한 자세한 내용은 위젯 가이드를 참고하세요.
두 대 이상의 리시버

제목에서 리시버 전환

리시버가 연결되어 있으면 홈 화면 상단의 AVR Maestro 옆에 리시버 이름이 표시됩니다. 탭하면 추가한 모든 리시버가 보이고, 하나를 골라 활성화하거나 리시버 관리를 선택해 리시버를 추가하고 순서를 바꿀 수 있습니다(설정 › 리시버 관리). 상태 카드 아래의 검색창은 앱의 모든 설정을 찾아 줍니다. 검색 가이드, 리시버 가이드, 앱 둘러보기를 참고하세요.

볼륨 프리셋

8개의 볼륨 레벨, 한 번의 탭으로

  • 빈 슬롯을 탭하면 현재 볼륨이 그 슬롯에 저장됩니다.
  • 저장된 슬롯을 탭하면 해당 볼륨으로 바로 이동합니다.
  • 슬롯을 길게 누르면 현재 볼륨으로 덮어쓰거나 슬롯을 비울 수 있습니다.

자세한 내용은 볼륨 가이드를 참고하세요.

방 이름 정하기

“MAIN ZONE”이 아니라 “거실”로

홈 화면에서 존 이름을 길게 누르면 메인 존을 포함한 모든 존의 이름을 바꿀 수 있습니다. 이름은 앱에만 저장되는 것이 아니라 리시버 자체에 기록되므로 제조사 앱과 다른 모든 클라이언트에도 표시되며, 구형 본체에서도 작동합니다. 한 번 바꾸면 집 안의 모든 컨트롤러가 그 방을 같은 이름으로 부릅니다.

위젯기능

사운드 모드현재 서라운드 모드이며, 탭하면 그룹별 선택기가 열립니다.
신호 정보AUDIO IN / AUDIO OUT, VIDEO IN / VIDEO OUT(해상도와 HDR), 샘플링 레이트, 그리고 색 공간과 픽셀 심도 등 리시버가 HDMI 신호에 대해 보고하는 모든 세부 정보입니다. 리시버가 보고하지 않는 값은 빈 칸으로 표시하지 않고 생략합니다.
지금 재생 중HEOS 소스의 앨범 아트, 트랙 정보, 재생 컨트롤이 있으며 즐겨찾기와 HEOS 실행 버튼이 있습니다. 자세한 내용은 재생 중 및 HEOS 가이드를 참고하세요.
존존 2 / 존 3의 간단한 상태와 빠른 제어를 제공하며, 해당 존 자체의 Smart Select 또는 Quick Select 슬롯도 포함됩니다. 슬롯을 탭하면 불러오고, 길게 누르면 존의 현재 상태를 저장합니다. 멀티 존 리시버에서만 표시됩니다.
Smart Select / Quick Select리시버 자체의 메모리 슬롯이며, 리시버가 부르는 이름 그대로 표시됩니다. Marantz에서는 Smart Select, Denon에서는 Quick Select입니다. 이름을 바꾼 슬롯은 리시버에 저장되므로 모든 앱에 같은 이름이 표시됩니다.
ECO 모드Auto, On, Off를 한 번의 탭으로 전환합니다.
취침 타이머Off, 30분, 60분, 90분, 120분.
Speaker Preset리시버가 Speaker Preset을 보고하면 표시되는 프리셋 1 / 2 전환기입니다.
오디오 리스토어압축 오디오 리스토러: Off, Low, Med, High. 리시버가 응답할 때만 표시됩니다.
장면저장된 장면을 한 번의 탭으로 불러옵니다. 장면은 장면 페이지에서 만듭니다.
스피커 구성5.1.2 같은 입력 및 출력 채널 구성입니다.
스피커 그리드어떤 스피커가 재생 중인지 입력과 출력을 나란히 보여 주는 실시간 그리드입니다. 이를 제공하는 리시버에서만 표시됩니다. 스피커 가이드를 참고하세요.
비디오 처리비디오 모드: Auto, Movie, Game, Bypass.
DRC다이내믹 레인지 압축: Auto, Off, Low, Mid, High.
Dirac Live 필터현재 Speaker Preset의 Dirac Live 슬롯이며 딥 링크가 있습니다. Dirac 리시버에서만 표시됩니다.
Audyssey 상태MultEQ, Dynamic EQ, Reference Level Offset, Dynamic Volume, LFC, 억제량을 한눈에 볼 수 있습니다. Audyssey 리시버에서만 표시됩니다.
채널 레벨 스냅샷리시버가 보고하는 모든 채널 레벨을 읽어 보여 줍니다.
서브우퍼 레벨빼기와 더하기 버튼이 있는 서브우퍼 레벨 조정입니다. 서브우퍼가 설정되어 있고 오디오 신호가 있을 때 표시됩니다.
오디오 지연리시버가 보고하는 경우 0~500 ms의 립싱크 지연입니다.
LFE 레벨리시버가 보고하는 경우 LFE 채널 레벨입니다.
사운드 컨트롤

사운드의 빠른 토글

  • 그래픽 EQ: 켜기/끄기 스위치는 그래픽 EQ 페이지 자체(사운드 › 그래픽 EQ)의 머리글 행에서 재설정 및 복사 버튼 옆에 있습니다. 밴드는 Dirac Live와 Audyssey가 모두 룸 보정을 실행하지 않을 때만 편집할 수 있으며, 앱은 리시버 자체의 규칙을 그대로 따릅니다. 그래픽 EQ 가이드를 참고하세요.
  • 서브우퍼: 스피커 설정으로 들어가지 않고 사운드 › 서라운드 › 오디오 기능에서 서브우퍼를 음소거하거나 켤 수 있습니다. 리시버가 이를 보고하고 받아들일 때만 표시됩니다.
  • 오디오 리스토러: 리시버의 압축 오디오 리스토러로, Denon에서는 리스토러, Marantz에서는 M-DAX이며 사운드 › 톤에 있습니다. 온스크린 메뉴로 들어가지 않고도 MP3와 스트리밍 소스에 생기를 되살립니다.
지금 재생 중 & HEOS

재생 중인 내용을 보고 제어하세요

현재 소스가 메타데이터를 제공하면 지금 재생 중 카드에 앨범 아트, 트랙 / 아티스트 / 방송국 정보와 재생 컨트롤(재생 / 일시정지 / 다음 / 이전)이 표시됩니다.

음악(방송국, 대기열, 스트리밍 서비스, HEOS 룸)을 탐색하려면 재생 중 카드에서 HEOS 실행을 탭하세요. AVR Maestro가 탐색을 위해 공식 HEOS 앱을 열고, 그곳에서 재생이 시작되면 AVR Maestro가 다시 재생 중 화면, 재생 컨트롤, 위젯을 이어받습니다. 아날로그, 광/동축, HDMI 패스스루 소스는 메타데이터를 보고하지 않으므로 이 경우 카드는 비어 있습니다. 즐겨찾기 버튼과 카드의 나머지 기능은 재생 중 및 HEOS 가이드에서 다룹니다.

홈 화면 FAQ

홈 화면을 사용자 지정할 수 있나요?
네. 홈 사용자 지정을 탭한 다음, 드래그로 순서를 바꾸고, 빨간 원을 탭해 제거하고, 추가로 위젯을 더하고, 초기화로 기본값으로 되돌리고, 완료로 마치세요. 편집하는 동안 카드가 흐리게 표시되므로 실수로 설정이 바뀌지 않습니다.
메인 존을 포함해 존 이름을 바꿀 수 있나요?
네. 홈 화면에서 존 이름을 길게 누르세요. 이름이 리시버 자체에 기록되므로 제조사 앱과 다른 모든 클라이언트에도 표시되며, 구형 본체에서도 작동합니다.
홈 화면에서 리시버를 전환할 수 있나요?
네. 상단의 AVR Maestro 옆 리시버 이름을 탭하고 다른 리시버를 선택하세요. 리시버 관리를 선택하면 리시버를 추가하거나 순서를 바꿀 수 있습니다.
재생 중인 내용도 표시되나요?
네. 메타데이터를 제공하는 소스라면 앨범 아트, 트랙/아티스트/방송국 정보, 재생 컨트롤이 표시됩니다. HEOS 실행을 탭해 음악을 찾아보세요. 재생이 시작되면 AVR Maestro가 다시 지금 재생 중 화면을 이어받습니다.

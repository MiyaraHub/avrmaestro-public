홈 화면

홈 화면: 나만의 방식으로 꾸미는 홈 베이스

맨 위에는 모델, 연결, 전원이 표시되는 장치 상태 카드가 고정되어 있고, 그 아래에는 사용자 지정이 가능한 위젯 그리드가 있습니다. 카드를 추가, 제거, 재배열해서 홈 화면에 꼭 필요한 정보만 표시하세요.

나만의 스타일로

몇 초 만에 사용자 지정

왼쪽 위의 홈 사용자 지정 아이콘을 탭하면 편집 모드로 들어갑니다.

  • 카드를 드래그해서 순서를 바꿉니다.
  • 빨간 원을 탭해 카드를 제거합니다.
  • 추가를 누르면 아직 없는 위젯 목록이 열립니다.
  • 초기화는 기본값을 복원하고, 완료는 편집을 마칩니다.
편집하는 동안 카드가 흐리게 표시되므로 실수로 리시버 설정을 바꾸지 않습니다. 위젯은 리시버가 해당 기능을 제공할 때만 표시됩니다.
방 이름 정하기

“MAIN ZONE”이 아니라 “거실”로

홈 화면에서 존 이름을 길게 누르면 메인 존을 포함한 모든 존의 이름을 바꿀 수 있습니다. 이름은 앱에만 저장되는 것이 아니라 리시버 자체에 기록되므로 제조사 앱과 다른 모든 클라이언트에도 표시되며, 구형 본체에서도 작동합니다. 한 번 바꾸면 집 안의 모든 컨트롤러가 그 방을 같은 이름으로 부릅니다.

위젯

위젯기능
볼륨dB 표시가 있는 슬라이더, 음소거, 저장된 볼륨 프리셋 8개.
소스입력 선택기를 엽니다. 타일을 길게 눌러 순서를 바꿀 수 있습니다. 이름을 바꾼 소스와 리모컨의 입력 그리드에서 설정한 사용자 지정 입력 아이콘도 여기에 표시됩니다.
사운드 모드현재 서라운드 모드이며, 탭하면 그룹별 선택기가 열립니다.
지금 재생 중HEOS 소스의 앨범 아트, 트랙 정보, 재생 컨트롤.
존간단한 Zone 2 / Zone 3 상태와 빠른 컨트롤. 해당 존의 Smart Select 또는 Quick Select 슬롯도 포함되며, 슬롯을 탭하면 불러오고 길게 누르면 존의 현재 상태를 그 슬롯에 저장합니다.
Smart Select / Quick Select리시버 자체의 메모리 슬롯이며, 리시버가 부르는 이름 그대로 표시됩니다. Marantz에서는 Smart Select, Denon에서는 Quick Select입니다. 이름을 바꾼 슬롯은 리시버에 저장되므로 모든 앱에 같은 이름이 표시됩니다.
Speaker PresetPreset 1 / 2 전환기이며, 프리셋이 둘 이상인 리시버에서만 표시됩니다.
Audyssey / Dirac보정 상태를 한눈에 보여 주고 바로 이동할 수 있는 링크.
채널 / 서브우퍼 레벨스텝퍼로 조절하는 채널별 및 서브우퍼 레벨 스냅샷이며, 서브우퍼 개수는 현재 리시버 구성을 따릅니다.
ECO, 슬립, DRC, Restorer, 비디오, 룸 크기, LFE탭 한 번으로 쓰는 토글과 선택기이며, 각각 지원되는 경우에만 표시됩니다.
사운드 컨트롤

사운드의 빠른 토글

  • 그래픽 EQ: 사운드, 오디오 기능에서 리시버의 그래픽 EQ를 켜거나 끕니다. Dirac Live나 Audyssey가 룸 보정을 실행하고 있지 않을 때만 사용할 수 있으며, 앱은 리시버 자체의 규칙을 그대로 따릅니다.
  • 서브우퍼: 스피커 설정으로 들어가지 않고 사운드, 오디오 기능에서 서브우퍼를 음소거하거나 활성화합니다. 해당 기능을 보고하고 받아들이는 리시버에서만 표시됩니다.
  • 오디오 리스토러: 압축된 오디오를 복원하는 리시버 기능으로, Denon에서는 Restorer, Marantz에서는 M-DAX이며, 사운드, 톤에서 DAC 필터 바로 옆의 토글로 제공됩니다. 온스크린 메뉴를 거치지 않고도 MP3와 스트리밍 소스에 생기를 되살려 보세요.
지금 재생 중 & HEOS

재생 중인 내용을 보고 제어하세요

현재 소스가 메타데이터를 제공하면 지금 재생 중 카드에 앨범 아트, 트랙 / 아티스트 / 방송국 정보와 재생 컨트롤(재생 / 일시정지 / 다음 / 이전)이 표시됩니다.

방송국, 대기열, 스트리밍 서비스, HEOS 룸 등 음악을 찾아보려면 지금 재생 중 카드에서 HEOS 실행을 탭하세요. AVR Maestro가 둘러보기를 위해 공식 HEOS 앱을 열며, 그곳에서 재생이 시작되면 AVR Maestro가 다시 지금 재생 중 화면, 재생 컨트롤, 위젯을 이어받습니다. 아날로그, 광/동축, HDMI 패스스루 소스는 메타데이터를 보고하지 않으므로 해당 소스에서는 카드가 비어 있습니다.

홈 화면 FAQ

홈 화면을 사용자 지정할 수 있나요?
네. 홈 사용자 지정을 탭한 다음, 드래그로 순서를 바꾸고, 빨간 원을 탭해 제거하고, 추가로 위젯을 더하고, 초기화로 기본값으로 되돌리고, 완료로 마치세요. 편집하는 동안 카드가 흐리게 표시되므로 실수로 설정이 바뀌지 않습니다.
메인 존을 포함해 존 이름을 바꿀 수 있나요?
네. 홈 화면에서 존 이름을 길게 누르세요. 이름이 리시버 자체에 기록되므로 제조사 앱과 다른 모든 클라이언트에도 표시되며, 구형 본체에서도 작동합니다.
재생 중인 내용도 표시되나요?
네. 메타데이터를 제공하는 소스라면 앨범 아트, 트랙/아티스트/방송국 정보, 재생 컨트롤이 표시됩니다. HEOS 실행을 탭해 음악을 찾아보세요. 재생이 시작되면 AVR Maestro가 다시 지금 재생 중 화면을 이어받습니다.

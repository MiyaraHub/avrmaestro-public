AVR Maestro 사용 설명서

Denon 또는 Marantz 리시버에서 AVR Maestro를 설정하고, 연결하고, 완전히 활용하는 데 필요한 모든 것을 담았습니다. 모든 화면은 사용 중인 모델에 맞춰 달라지며, 앱은 본체가 실제로 지원하는 제어 항목만 표시하므로 내 화면에는 여기 나열된 것보다 적은 옵션이 보일 수 있습니다.

1장

시작하기

앱을 설치하고, 리시버를 추가하고, 사용법을 익히세요.

시작하기

요구 사항, 네트워크 설정, 그리고 1분 안에 리시버를 추가하는 방법.

리시버 관리

리시버를 추가, 이름 변경, 전환, 삭제하는 방법과 각 리시버가 기억하는 내용을 안내합니다.

앱 탐색

하단 탭, 내비게이션 사용자 지정, 각 기능의 위치를 안내합니다.

검색

설정 이름을 입력하면 바로 이동합니다. 어떤 앱 언어로도 가능합니다.
2장

일상적인 제어

매일 저녁 사용하는 화면입니다.

홈 화면

내 마음대로 꾸미는 홈 화면 - 볼륨, 소스, 사운드 모드, 존 등을 위한 위젯.

볼륨 컨트롤

볼륨 상한, 전원을 켤 때의 볼륨, 음소거 시 낮추는 폭, 0-98 단위와 데시벨 표시를 설정합니다.

리모컨

방향 패드, 재생 컨트롤, 사용자 지정 아이콘을 지정할 수 있는 이름 변경 가능 입력, 트리거 출력, 시스템 제어를 다룹니다.

존

존 2와 존 3의 전원, 입력, 볼륨을 독립적으로 제어하며, 각 존의 Smart Select 슬롯도 있습니다.

지금 재생 중

앨범 아트, 트랙 정보, 재생 컨트롤, 그리고 앱 안에서 HEOS 즐겨찾기를 재생하는 방법입니다.

멀티룸

스피커를 그룹으로 묶고 해제하며, 리더를 지정하고, 음악을 탐색하고 검색하고 대기열에 추가합니다.

구형 리시버

AVR-X4000 세대 Denon 리시버에서 AVR Maestro 앱이 제어하는 기능.

라디오(FM, AM 및 HD Radio)

주파수로 직접 튜닝하거나 저장해 둔 방송국 프리셋을 불러오세요.

장면

전체 설정을 저장하고 한 번의 탭으로 불러옵니다. 대표 기능입니다.
3장

사운드와 스피커

듣는 소리를 조정하세요.

사운드

열 개 페이지 전체: 서라운드 모드, 다이얼로그 및 DRC, Audyssey, Dirac Live, 형태, 채널별 트림, 톤, IMAX, Auro-3D.

그래픽 EQ

Audyssey와 Dirac이 꺼져 있을 때 스피커마다 9밴드 곡선을 만드세요. 전체, 좌/우, 개별 중에서 선택할 수 있습니다.

스피커

구성, 거리, 레벨, 크로스오버, 서브우퍼, 스피커 프리셋.

컨트롤이 잠기는 이유

리시버가 고정하는 항목의 전체 지도와 잠금을 해제하는 방법입니다.
4장

나만의 스타일로

디자인, 사용감, 언어.

설정

리시버 관리, 디자인, 레이아웃, 부가 기능, 도움말, 백업, 앱 정보.

위젯

Android와 iPhone의 홈 화면 위젯과 각 위젯이 보여 주는 내용입니다.

사용자 지정 아이콘

모든 입력과 장면에 고유한 아트워크를 지정하세요. 자르고, 모양을 바꾸고, 백업에도 함께 담깁니다.

온스크린 디스플레이

볼륨 표시 위치 또는 끄기, 정보 배너, 지금 재생 중, 21:9, 화면 보호기를 설정합니다.

지원 언어

자동으로 감지하거나 설정에서 선택합니다. 히브리어와 아랍어는 앱 전체가 좌우 반전됩니다.
5장

연결 및 자동화

리시버를 앱 너머로 확장하세요.

어시스턴트

내 리시버에 궁금한 점을 물어보거나 원하는 변경 사항을 말해 보세요. 모델은 사용 중인 기기에서 실행됩니다.

Home Automation

Home Assistant, Hubitat, 웹훅까지 - 장면이 스크립트가 되어 휴대폰 없이도 실행됩니다.

Home Assistant 대시보드

전체 YAML이 담긴 실제 예제입니다. 실시간 소스 강조, 실제 dB 볼륨, 장면, 그래프까지 다룹니다.

Home Assistant 문제 해결

연결 카드의 의미, Entity Not Found, 누락된 장면, Failed login 경고.

백업 & 복원

모든 설정을 파일 하나로 내보내고 새 휴대폰에서 복원하세요. 리시버, 아이콘, 장면, 테마까지 그대로 옮겨집니다.
6장

참고 자료 및 도움말

정의나 해결 방법이 필요할 때.

용어집

앱과 리시버에서 쓰는 용어를 쉬운 말로 정의합니다.

지원 리시버

어떤 Denon 및 Marantz 모델이 작동하는지, 그리고 확인하는 방법을 안내합니다.

도움말 & 문제 해결

연결 테스트 실패, 연결 끊김, 회색으로 표시된 사운드 모드 등 빠른 해결 방법입니다.

Home Assistant가 작동하지 않을 때

Home Assistant 문제의 대부분은 연결 상태, 리시버 엔티티 ID, 또는 휴대폰과 서버 사이의 네트워크에서 비롯됩니다. 연결 카드가 알려 주는 내용부터 확인하고 아래로 차례로 살펴보세요.

연결 카드가 알려 주는 것

동기화 버튼 위의 카드는 연결 상태를 보여 주며, 버튼은 그 상태를 따릅니다.

  • Home Assistant에 연결됨: 방금 인증된 호출이 성공했습니다. 동기화 버튼을 사용할 수 있습니다.
  • Home Assistant 연결이 만료됨: 서버가 응답했지만 저장된 토큰을 거부했습니다. 다시 로그인할 때까지 동기화 버튼이 비활성화됩니다.
  • Home Assistant에 접속할 수 없음: 서버에 접근하지 못했으며 토큰은 멀쩡할 수도 있습니다. 동기화 버튼은 계속 사용할 수 있고 아무것도 변경되지 않습니다.
  • Home Assistant에 연결되지 않음: 아직 저장된 주소나 토큰이 없습니다. 주소를 추가하고 로그인하세요.
  • Home Assistant 연결 확인 안 됨: 데모 모드가 켜져 있거나 홈 오토메이션이 잠겨 있어서 집으로 아무것도 전송되지 않았고 토큰도 시도되지 않았습니다.
연결됨이라고 표시되는 것은 첫 번째뿐이며, 그것도 무언가 인증에 성공했기 때문입니다. 저장된 토큰만으로는 연결로 간주되지 않습니다.

스크립트가 아무 동작도 하지 않거나 Entity Not Found가 표시될 때

  • Home Assistant의 설정, 기기 & 서비스에서 공식 Denon AVR 통합을 설치하세요.
  • AVR Maestro 설정의 리시버 미디어 플레이어 엔티티 ID가 Home Assistant의 엔티티 ID와 정확히 일치하는지 확인하세요.
  • 장면을 삭제하거나 다시 만든 뒤 unavailable이라고 표시되는 엔티티는 무시하세요. 장면 스크립트 이름은 장면이 만들어진 시각을 따르므로, 스크립트 ID가 한 번 바뀌는 방식은 홈 오토메이션을 참고하세요.

새 장면이 Home Assistant에 없을 때

장면은 추가, 편집, 삭제할 때마다 백그라운드에서 동기화되므로 매번 동기화를 누를 필요가 없습니다. 장면이 없다면 휴대폰이 서버에 접근하지 못한 것입니다.

  • 휴대폰을 Home Assistant와 같은 로컬 Wi-Fi 네트워크에 연결하세요.
  • 설정을 열고 장면 동기화를 탭하세요. 실패하면 정확한 네트워크 오류가 표시됩니다.

Home Assistant 로그의 Failed login

여러 번의 실패한 시도나 연결이 끝나기 전에 브라우저가 연결을 끊은 경우 Home Assistant에 경고가 남습니다. 이것은 기록일 뿐 현재의 오류가 아니며, 연결이 작동하면 무시해도 됩니다.

그 밖에 잘못될 수 있는 것들

  • 대시보드 타일이 켜지지 않을 때: Home Assistant 대시보드 가이드를 참고하세요.
  • 웹훅이 도착하지 않을 때: 홈 오토메이션을 참고하세요.
  • 아직 해결되지 않았나요? Discord에서 질문하거나 도움말을 확인하세요.
자주 묻는 질문

Home Assistant 문제, 답변 모음

스크립트가 실행되었는데 Entity Not Found가 표시되거나 아무 일도 일어나지 않습니다.
Home Assistant에 공식 Denon AVR 통합이 설치되어 있는지 확인하세요. 그런 다음 AVR Maestro 설정의 리시버 미디어 플레이어 엔티티 ID가 Home Assistant의 엔티티 ID와 정확히 일치하는지 확인하세요. 예를 들면 media_player.living_room_receiver입니다.
Home Assistant 로그에 Failed login이 보이는 이유는 무엇인가요?
연결하는 동안 여러 번 실패했거나 브라우저가 완료되기 전에 연결을 끊은 경우 Home Assistant가 경고를 기록합니다. 연결에 성공한 뒤에는 이 오래된 경고를 무시해도 안전합니다.
새 장면을 만들었는데 Home Assistant에 나타나지 않습니다.
휴대폰이 Home Assistant 서버와 같은 로컬 Wi-Fi 네트워크에 있는지 확인하세요. 휴대폰이 서버에 접근하지 못하면 백그라운드 동기화가 실패합니다. 설정을 열고 장면 동기화를 탭하면 네트워크 오류가 있을 때 정확한 내용을 볼 수 있습니다.
스크립트를 실행하려면 앱이 열려 있어야 하나요?
아니요. 스크립트는 Home Assistant 안에 있으므로 휴대폰이 주머니에 있어도 대시보드, 자동화, 음성 어시스턴트에서 실행됩니다. 앱은 장면을 변경할 때만 스크립트를 만들고 업데이트합니다.

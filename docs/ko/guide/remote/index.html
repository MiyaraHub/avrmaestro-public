리모컨

진짜 리모컨에 실시간 화면까지

방향 패드와 재생 제어를 모두 갖추었으며, 입력, 사운드 모드, 실제로 사용 중인 채널을 실시간으로 보여 주는 헤더가 있어 Denon 또는 Marantz가 지금 무엇을 하는지 항상 알 수 있습니다. 상단의 페이지 탭을 스와이프하거나 탭하여 최대 다섯 페이지 사이를 이동하세요.

최대 다섯 페이지

실물 리모컨 없이도 모든 것을

리모컨 탭을 여세요. 보이는 페이지는 리시버에 따라 다르며, 리시버에 없는 기능의 페이지는 표시되지 않습니다.

  • 메인 리모컨: 명령 바(전원 / 정보 / 설정 / 옵션 / 뒤로), 방향 패드, 재생 제어, 볼륨 바를 제공하며, 헤더에 입력, 사운드 모드, 사용 중인 IN/OUT 채널이 실시간으로 표시됩니다.
  • 입력: 전체 소스 그리드입니다. 타일을 탭하면 입력이 전환됩니다. 타일을 길게 누르면 사용자 지정 아이콘을 지정할 수 있습니다. 그리드에는 직접 정한 이름과 순서가 사용됩니다(아래 입력 이름 바꾸기 및 순서 변경 참조).
  • Smart Select / Quick Select: AVR Maestro는 리시버와 같은 이름으로 표시합니다. Marantz에서는 Smart Select, Denon에서는 Quick Select입니다. 슬롯을 누르면 리시버에 저장된 상태를 불러오고, 길게 누르면 이름 변경 또는 현재 상태 저장을 선택할 수 있습니다(마법사에서 캡처할 설정을 정확히 고를 수 있습니다). 슬롯 이름도 리시버에 저장되므로 다른 모든 앱에서도 그대로 적용됩니다.
  • 시스템: 리시버 전체에 대한 직접 제어입니다(아래에 나열).
  • 트리거 출력: 12V 트리거 출력이 있는 리시버에만 표시됩니다. 각 트리거를 켜는 존, 입력, HDMI 출력을 선택합니다(아래 참조).
쓰지 않는 페이지가 있나요? 설정 › 탭 사용자 지정에서 숨기세요. 이 설정은 모든 리시버에 적용됩니다.

입력 이름 바꾸기 및 순서 변경

입력에 "Nvidia Shield", "Xbox", "PS5"처럼 실제 기기 이름을 붙이고 가장 자주 쓰는 것을 맨 앞에 두세요.

  1. 홈 탭에서 입력 소스 카드를 탭하여 소스 목록을 여세요.
  2. 아무 타일이나 길게 누르세요. 목록이 편집 모드로 바뀝니다. 타일을 탭하면 이름을 바꾸고, 끌면 순서를 바꿉니다. 끝나면 완료를 탭하세요.
  3. 이름을 바꾸려면 타일을 탭하고 새 이름을 입력한 다음 저장을 탭하세요.
  4. 순서를 바꾸려면 타일을 새 위치로 끌어 놓으세요.
  5. 완료를 탭하세요.
새 이름은 리시버 자체에 기록되므로 제조사 앱과 다른 모든 클라이언트(오래된 모델 포함)에도 표시되며, 앱이 소스 이름이 바뀜으로 확인해 줍니다. 리시버가 이름을 받아들이지 않으면 이 기기에서만 소스 이름이 바뀜이 표시되고 이름은 AVR Maestro에만 남습니다. 순서는 리시버별로 저장되며 리모컨의 입력 페이지도 이를 사용합니다.
리모컨 › 시스템

리시버 전체에 대한 직접 제어

시스템 페이지에는 리시버가 갖고 있다고 보고한 항목만 표시되므로 모델에 따라 목록이 더 짧을 수 있습니다. 위에서 아래로 다음과 같은 항목이 보일 수 있습니다.

  • HDMI 출력과 조명 또는 디머(전면 디스플레이 밝기).
  • 트리거: 각 12V 트리거를 직접 켜거나 끕니다. 트리거가 존, 입력, HDMI 출력을 따르게 하려면 대신 트리거 출력 페이지를 사용하세요.
  • ECO 모드, 자동 대기, 슬립 타이머.
  • HDMI CEC와 HDMI 오디오 디코드(AMP 또는 TV).
  • 스피커 프리셋: 리시버의 스피커 프리셋 사이를 전환합니다.
  • Bluetooth 송신기: Bluetooth 헤드폰이나 스피커로 오디오를 보낼 수 있는 모델에서 사용합니다. 송신기를 켜거나 끈 다음 BT+스피커(Bluetooth와 방의 스피커를 함께) 또는 BT 전용을 선택하세요.
  • 화면 모드와 비디오 처리 모드(자동, 게임, 영화, 바이패스). 게임, 영화, 바이패스는 HDMI 소스가 영상을 재생하는 동안에만 적용되며, 그렇지 않으면 리시버는 자동 상태로 유지됩니다.
  • 전 존 스테레오, 자동 립 싱크(Marantz), 오디오 지연, LFE 레벨.
  • 입력 모드(자동, HDMI, 디지털, 아날로그).
  • 디지털 입력 형식: 자동은 리시버가 결정하고, PCM은 PCM 디코딩을, DTS는 DTS 디코딩을 강제합니다. 소스가 리시버가 잘못 읽는 형식을 보내 소리가 나지 않을 때 사용하세요.
일부 리시버는 특정 입력이나 서라운드 모드가 활성화된 동안 디지털 입력 형식 또는 LFE 레벨을 잠급니다. 이 경우 앱은 버튼 대신 잠금 배너와 함께 현재 값을 표시합니다. 입력이나 모드를 바꾼 뒤 다시 확인하려면 제목 옆의 새로고침 아이콘을 탭하세요. 컨트롤이 잠기는 이유를 참조하세요.
리모컨 › 트리거 출력

스크린, 서브우퍼, 앰프의 전원을 자동으로 켜세요

12V 트리거 출력은 다른 장비에 전원을 켜라고 알려 줍니다. 트리거 출력이 있는 리시버에서는 트리거 출력 페이지에서 각 트리거를 무엇이 켤지 선택할 수 있습니다. 활성화된 항목 중 하나라도 켜져 있으면 트리거가 작동합니다. 목록은 리시버에서 실시간으로 읽어 옵니다.

  1. 리모컨 탭을 열고 트리거 출력으로 스와이프하세요.
  2. 리시버에 트리거가 둘 이상이면 상단에서 트리거 출력 1, 트리거 출력 2 등을 선택하세요.
  3. 트리거를 작동시킬 항목의 스위치를 켜세요. 항목은 존, 소스, HDMI 출력으로 나뉘어 있습니다.
각 스위치는 즉시 리시버로 전송됩니다. 리시버가 변경을 받아들이지 않으면 트리거 출력:으로 시작하는 메시지가 알려 주고 스위치에는 리시버의 실제 상태가 표시됩니다. 트리거가 있는 리시버에서 트리거 출력 사용 불가가 보이면 리시버가 바쁜 상태일 수 있습니다. 브라우저에서 웹 제어 페이지가 열려 있다면 닫고 다시 시도를 탭하세요.
내 방식대로 조절하는 볼륨

볼륨을 dB 또는 상대 단위로 확인하세요

메인 리모컨의 볼륨 막대는 마스터 볼륨을 실시간으로 보여 주며, 헤더 칩도 같은 값을 표시합니다. 데시벨보다 리시버 자체의 숫자를 선호하나요? 표시를 dB 눈금(예: -40.5 dB, 기본값)과 0-98 눈금(예: 39.5) 사이에서 전환할 수 있습니다. 헤더 칩과 볼륨 막대 모두 선택에 따라 바뀝니다.

  1. 설정 › 리시버 관리를 열고 리시버를 탭하세요.
  2. 오디오에서 리모컨 볼륨 표시를 열고 눈금을 선택하세요.
선택은 리시버별로 저장되므로 두 리시버가 서로 다른 눈금을 표시할 수 있습니다.
길게 누르기

볼륨 버튼은 실물 리모컨처럼 연속으로 조절됩니다

더하기나 빼기를 누르면 볼륨이 한 단계 움직입니다. 계속 누르고 있으면 손을 뗄 때까지 부드럽게 계속 움직입니다. 실물 리모컨과 같은 방식이라 손에 익은 그대로입니다. 손을 떼면 리시버는 멈춘 단계에 정확히 맞춰지며, 그 단계를 넘어가지 않습니다.

내부적으로는 앱이 명령을 모아서 처리합니다. 목표 방향을 누적한 뒤 실제로 전송하는 속도를 조절하므로, 오래 눌러도 응답이 느린 리시버에 명령이 몰리지 않습니다. 작은 조절도 부드럽습니다. 몇 데시벨 정도의 변화도 한 번에 튀지 않고 서서히 올라갑니다.

실시간 신호

들어오는 신호와 나가는 신호

리모컨 헤더에는 간결한 채널 스트립이 있습니다. 한 줄에는 들어오는 신호를, 다른 한 줄에는 리시버가 구동하는 신호를 리시버가 인식하는 모든 스피커와 함께 표시합니다. 네트워크로 재생하는 스테레오 트랙은 입력이 2채널, 출력이 전체 업믹스로 표시됩니다.

리모컨 자주 묻는 질문

입력 이름을 바꾸고 순서를 바꿀 수 있나요?
네. 홈 탭에서 입력 소스 카드를 탭한 다음 아무 타일이나 길게 눌러 편집을 시작하세요. 타일을 탭하면 이름을 바꾸고, 끌어서 순서를 바꾸며, 끝나면 완료를 탭합니다. 새 이름은 리시버 자체에 기록되므로 제조사 앱과 다른 모든 클라이언트에도 표시됩니다. 리시버가 이름을 받아들이지 않으면 앱에 이 기기에서만 소스 이름이 바뀜이라고 표시됩니다. 순서는 리시버별로 저장되며 리모컨의 입력 페이지도 이를 따릅니다.
입력에 사용자 지정 아이콘을 쓸 수 있나요?
네. 입력 타일을 길게 눌러 원하는 이미지(PNG, JPG, ICO, WebP 등)를 고르고, 증명사진 스타일 자르기 도구에서 위치를 맞춘 뒤 저장하세요. 자세한 방법은 사용자 지정 입력 아이콘 안내를 참고하세요.
가상 리모컨으로 무엇을 제어하나요?
메인 리모컨 페이지에는 명령 막대(전원/정보/설정/옵션/뒤로), 방향 패드, 재생 제어, 볼륨이 있고, 입력, 사운드 모드, 사용 중인 채널을 실시간으로 보여 주는 헤더가 있습니다. 시스템 페이지에서는 직접 제어(HDMI 출력, 디머, 트리거, ECO, 슬립, CEC, Bluetooth 송신기, 디지털 입력 형식 등)를 추가로 사용할 수 있고, 리시버에 12V 트리거 출력이 있으면 별도의 트리거 출력 페이지가 나타납니다. 리시버가 지원하지 않는 항목은 숨겨집니다.
Smart Select / Quick Select란 무엇인가요?
Marantz의 Smart Select와 Denon의 Quick Select는 리시버 자체의 메모리 슬롯입니다. AVR Maestro는 리시버와 같은 이름으로 표시합니다. Marantz에서는 Smart Select, Denon에서는 Quick Select입니다. 누르면 불러오고, 길게 누르면 이름을 바꾸거나 캡처 마법사로 현재 상태를 저장할 수 있습니다.
트리거 출력 페이지는 무엇인가요?
리시버에 12V 트리거 출력이 있으면 리모컨에 나타납니다. 각 트리거마다 어떤 존, 입력 소스, HDMI 출력이 트리거를 켤지 선택하며, 활성화된 항목 중 하나라도 켜져 있으면 트리거가 작동하므로 프로젝터 스크린, 서브우퍼, 앰프가 저절로 켜지게 할 수 있습니다. 목록은 리시버에서 실시간으로 읽어 옵니다. 리시버가 변경을 받아들이지 않으면 앱이 알려 주고 리시버의 실제 상태를 보여 줍니다.
데스크톱에서 AVR Maestro 키보드 단축키를 지원하나요?
네. Mac과 Windows에서는 키보드로 재생 제어와 볼륨을 조작할 수 있습니다. macOS에서는 Cmd, Windows에서는 Ctrl을 함께 누르세요. Space는 재생/일시정지, .(마침표)는 정지, 왼쪽/오른쪽 방향키는 이전/다음 트랙, 위/아래 방향키는 볼륨, M은 음소거입니다. 키보드의 전용 미디어 키(재생, 일시정지, 다음, 이전, 정지, 볼륨, 음소거)도 작동합니다. 텍스트 입력란에 입력하는 동안에는 단축키가 작동하지 않습니다.

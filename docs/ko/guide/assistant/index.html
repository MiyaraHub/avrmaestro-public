리시버에게 물어보기

어시스턴트에게 물어보세요. 답은 리시버에서 나옵니다

대부분의 어시스턴트는 리시버 일반에 대해 많이 압니다. 이 어시스턴트는 내 리시버를 압니다. 지금 볼륨이 얼마인지, 어떤 Speaker Preset으로 작동 중인지, Dynamic EQ가 켜져 있는지, 지금 이 순간 무엇을 디코딩하고 있는지까지요. 내 리시버를 직접 읽고 거기에서 답하며, 어딘가의 서비스가 아니라 내 기기에서 실행되는 모델을 사용합니다.

위치

어시스턴트 탭

질문을 입력하거나 마이크를 누른 채 말씀하세요. 로그인할 곳도, 붙여넣을 키도, 계정도 없습니다. 기기에서 온디바이스 모델을 실행할 수 있다면 열자마자 어시스턴트가 작동합니다.

평소 말투 그대로 물어보세요. "소리가 얼마나 커?", "지금 뭐로 보고 있지?", "Dirac 슬롯 어느 게 불러와져 있어?", "Dynamic EQ 켜져 있어?" 같은 질문이 리시버가 실제로 알려 주는 항목에 맞춰 해석되므로, 설정 이름을 몰라도 됩니다.

알려 줄 수 있는 것

앱이 리시버에서 읽어 오는 모든 것, 즉 이 가이드의 화면에 나오는 모든 것입니다. 고정된 목록이 아닙니다. IMAX를 보고하는 기기에는 IMAX에 대해 묻고, 그렇지 않은 기기에는 아예 제안하지 않습니다.

질문 대상알고 있는 것
전원과 볼륨켜짐 또는 대기 상태, dB 단위 레벨, 음소거, 절전 모드, 리시버 자체의 볼륨 제한
소스와 사운드내가 붙인 이름으로 표시되는 선택된 입력, 사운드 모드, 디코딩 중인 형식
보정Audyssey MultEQ, Dynamic EQ, Dynamic Volume, 레퍼런스 레벨 오프셋, LFC, 그리고 불러온 Dirac Live 슬롯
스피커구성, 채널별 조정값, 서브우퍼 레벨, 설정된 서브우퍼 수
비디오입출력 해상도와 HDR, 화면 모드, 비디오 처리, 입력 모드, HDMI 오디오 출력, 자동 립싱크
존각 존의 전원, 입력, 볼륨, 채널 조정값, 취침 타이머, Smart Select / Quick Select 슬롯
본체전면 패널 밝기, 자동 대기, Bluetooth 송신기, 번호별 트리거
재생 중인 콘텐츠네트워크 소스의 트랙과 재생 상태
모든 답변 아래에 답을 만들기 위해 무엇을 읽었는지가 표시됩니다. 이 줄은 모델이 쓴 것이 아니라 기록된 것이므로 지어낼 수 없으며, 진짜 답과 자신만만하게 들리는 틀린 답을 가장 빠르게 가려내는 방법입니다.

대신 해 주는 일

무언가를 바꿔 달라고 하면 바꿉니다. 다른 점은 동작마다 거치는 절차의 무게이며, 이 비대칭은 의도된 것입니다.

요청동작
전원 켜기/끄기, 음소거, 음소거 해제즉시 실행한 뒤 무엇을 보냈는지 알려 줍니다
볼륨 낮추기즉시 실행합니다. 소리를 줄이고 싶은 순간은 대화창이 가장 귀찮은 순간이기 때문입니다
볼륨 높이기먼저 묻습니다. 최악의 경우인 드라이버 손상을 방 안에 있는 사람이 되돌릴 수 없는 유일한 동작이기 때문입니다
입력 전환내 소스 목록에서, 내가 바꿔 붙인 이름 기준으로 찾습니다. 일치하는 항목이 둘이면 어느 쪽인지 묻습니다

양은 직접 정하시면 됩니다. "5 dB 낮춰"라고 하면 5 dB를 움직이고, 숫자 없이 "낮춰"라고 하면 버튼을 한 번 누른 것과 같이 한 단계 움직입니다. 말하지 않은 수치를 임의로 정하지는 않습니다.

여기에서 사운드 모드를 바꾸는 기능은 아직 지원되지 않습니다. 리시버는 사운드 모드를 카테고리별로 구성하고 활성 카테고리 안에서 선택하므로 하나의 이름으로 보낼 수 있는 값이 아닙니다. 사운드 탭에서 제대로 설정할 수 있습니다.

의견 묻기

"보정 추천 있어?", "대사를 더 또렷하게 하려면?", "Dynamic EQ를 켜야 할까?" 같은 질문은 단순 조회와 다르며 어시스턴트도 다르게 처리합니다. 읽어 온 값을 바탕으로 추론해 리시버에 실제로 있는 설정을 짚어 가며 구체적인 옵션 몇 가지를 제시하고, 그중 무엇을 먼저 시도하겠는지도 말해 줍니다.

변하지 않는 것은 수치의 출처입니다. 자유롭게 추론할 수는 있지만 받지 못한 수치를 말할 수는 없습니다. 읽어 온 값으로 추천을 뒷받침할 수 없다면, 추측하는 대신 무엇을 더 봐야 하는지 알려 줍니다.

입력 대신 말하기

마이크 버튼을 누른 채 말씀하세요. 말한 내용이 입력창에 채워지므로 전송 전에 확인할 수 있습니다.

알아 두세요: 언어 모델은 사용자의 기기에서 실행되고 리시버는 사용자의 네트워크 안에 있으므로, 입력한 질문과 답변은 사용자의 하드웨어에 머뭅니다. 음성을 텍스트로 바꾸는 일은 휴대폰 자체의 인식기가 처리하며, 대부분의 휴대폰에서는 변환을 위해 오디오가 플랫폼 업체로 전송됩니다. 이는 앱이 아닌 OS가 하는 일이며, 직접 입력하면 완전히 피할 수 있습니다.
기기 요구 사항

실행 가능한 기기

어시스턴트는 사용자의 기기에서 언어 모델을 실행합니다. 계정도, 서버도, 로그인할 곳도 없으며, 그만큼 기기에 모델이 있어야 합니다. 앱이 대신 설치해 드릴 수 없는 부분이며, 우리가 우회할 수 없는 유일한 요구 사항입니다.

플랫폼필요한 것
iPhone, iPad, MacApple Intelligence를 사용할 수 있고 켜져 있는 기기에서 iOS 26 또는 macOS 26. 꺼져 있으면 앱이 기능을 숨기지 않고 그 사실을 알려 주며 설정으로 안내합니다.
AndroidGoogle AICore를 통한 Gemini Nano. 앱은 Google의 ML Kit Prompt API로 이에 접근하며, 이 API에는 자체 지원 기기 목록이 있습니다. 아래를 참고하세요.
Windows, Linux실행할 온디바이스 모델이 없으므로 어시스턴트가 표시되지 않습니다. 앱의 나머지 기능에는 영향이 없습니다.

Android: Google 지원 기기

이 목록은 우리가 아닌 Google의 것입니다. Android 휴대폰에 어시스턴트가 나타나는지를 결정하는 유일한 기준이고, Google이 대부분의 사람들이 잘 보지 않는 곳에 게시하기 때문에 여기에 옮겨 두었습니다.

ML Kit GenAI Prompt API에 대해 Google이 공개한 지원 목록이며, 2026년 8월 20일에 확인한 내용입니다. Google은 시간이 지나면서 장치를 추가하고 이 페이지는 그 사본이므로, 사용 중인 장치가 이 목록보다 새로운 모델이라면 Google의 목록을 확인해 보세요.

휴대폰이 해당 목록에 없는데 지원되는 줄 알았다면: Google은 목록을 하나만 공개하지 않습니다. 예를 들어 Galaxy S25와 S25 Ultra는 Gemini Nano를 문제없이 실행하며, 요약, 교정, 문장 다듬기 같은 Google의 다른 온디바이스 기능 목록에는 올라 있습니다. 어시스턴트에는 Prompt API가 필요합니다. 이미 가진 텍스트를 다듬는 것이 아니라 리시버에 대해 자유롭게 질문할 수 있게 해 주는 API인데, 이 API를 지원하는 장치는 더 적습니다. S25는 아직 목록에 없고 S26은 있습니다. S25 시리즈를 추가해 달라는 요청이 Google에 접수되어 있으며, 추가되면 저희가 업데이트하지 않아도 어시스턴트가 자동으로 나타납니다.

저희가 직접 실행해 본 장치

Google의 목록과는 별개이며, 저희가 실제로 손에 쥐어 본 하드웨어만 담았기 때문에 더 짧습니다.

위 Google 목록에 사용 중인 장치가 있다면 어시스턴트가 나타나서 동작합니다. 이 두 번째 표는 저희가 직접 다뤄 본 장치만 정리한 것입니다. 연구소라도 있는 것처럼 보이느니, 한 대라도 솔직하게 밝히는 편이 낫다고 생각합니다.

문제 해결

도움을 드릴 수 없다고 답할 때

각 문구는 의도적으로 서로 다르게 쓰여 있습니다. 문구마다 해결 방법이 다르기 때문입니다.

  • “이 장치에서는 온디바이스 모델을 실행할 수 없습니다.” 어시스턴트를 쓰려면 iPhone, iPad, Mac에서는 Apple Intelligence가, Android에서는 Google AICore를 통한 Gemini Nano가 필요합니다. 성능이 충분한 장치라도 지원되지 않는 경우가 많으며, 일부 최신 태블릿이나 다른 용도로는 Gemini Nano를 실행하는 일부 플래그십 휴대폰도 여기에 해당합니다. 위의 어떤 장치에서 실행할 수 있는지를 참고하세요. 앱에서 바꿀 수 있는 것은 없습니다.
  • 모델을 다운로드해야 합니다. Android는 처음 한 번 백그라운드에서 모델을 받아 옵니다. 한 번만 받으면 되지만 용량이 크므로 Wi-Fi 연결이 필요합니다.
  • “리시버에 해당 기능이 있지만, 지금은 보고할 내용이 없습니다.” 기능은 있으나 현재 사용 중이 아닌 상태입니다. 아무것도 재생하지 않을 때 재생 중인 곡을 물으면 이런 답이 나오며, 리시버에 HEOS가 없다는 뜻은 아닙니다.
  • “이 리시버는 해당 정보를 보고하지 않습니다.” 사용 중인 하드웨어에 대한 정확한 답변입니다. 본체에 그런 기능이 없으며, 앱도 있는 척하지 않습니다.
  • 일부 하위 시스템을 읽지 못했습니다. 없는 것이 아니라 알 수 없는 상태입니다. 읽기에 실패한 것을 없는 기능으로 취급하지 않고, 그대로 알려 드립니다.
  • “아직 여기에서는 그 항목을 변경할 수 없습니다.” 리시버가 아니라 어시스턴트의 한계입니다. 해당 화면에서는 변경할 수 있습니다.
어시스턴트는 무료입니다. 유료인 것은 Home Automation이며, 두 기능은 별개입니다. 리시버에 무엇이든 물어보는 데 Pro는 필요하지 않습니다.
자주 묻는 질문

어시스턴트 Q&A

어시스턴트가 내 데이터를 어딘가로 보내나요?
언어 모델은 사용자의 장치에서 실행되고 리시버는 사용자의 네트워크 안에 있으므로, 입력한 질문과 그 답변은 사용자의 하드웨어 밖으로 나가지 않습니다. 음성 입력은 예외입니다. 음성을 텍스트로 바꾸는 작업은 휴대폰에 내장된 음성 인식기가 처리하며, 대부분의 휴대폰에서는 변환을 위해 음성이 플랫폼 제공업체로 전송됩니다. 직접 입력하면 이를 완전히 피할 수 있습니다.
어시스턴트가 내 기기에서는 실행할 수 없다고 하는 이유는 무엇인가요?
어시스턴트에는 기기 내 모델이 필요합니다. iPhone, iPad, Mac에서는 Apple Intelligence가, Android에서는 Google AICore를 통한 Gemini Nano가 그것입니다. 성능이 충분한 기기라도 이를 갖추지 않은 경우가 많습니다. 앱은 기능을 숨기지 않고 지금 어떤 상태인지 정확히 알려 드리므로, 다운로드가 필요한지, 설정 문제인지, 하드웨어 문제인지 알 수 있습니다.
어시스턴트가 묻지 않고 설정을 바꾸나요?
전원, 음소거, 입력, 볼륨 낮추기는 바로 실행합니다. 이 모두는 방에 있는 사람이 쉽게 되돌릴 수 있기 때문입니다. 볼륨을 높이는 것은 언제나 먼저 묻습니다. 최악의 경우 드라이버가 손상될 수 있는 유일한 동작이기 때문입니다.
가끔 알려 줄 수 없다고 말하는 이유는 무엇인가요?
추측하지 않기 때문입니다. 어시스턴트가 알려 주는 모든 수치는 리시버에서 읽어 온 값에서 나오므로, 값이 도착하지 않았다면 그럴듯한 숫자를 지어내는 대신 해당 서브시스템을 읽을 수 없었다고 말합니다. 맞는 듯 들리는 틀린 답은 답이 없는 것보다 나쁩니다.

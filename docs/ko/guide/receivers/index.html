리시버 관리, 리시버마다 한 페이지

가진 만큼 Denon과 Marantz 리시버를 추가하고, 두 번의 탭으로 전환하고, 각각에 고유한 오디오 환경설정을 지정하세요. 리시버마다 이름, 주소, 잠금, 펌웨어를 위한 자체 페이지가 있습니다.

설정 위치

리시버 관리 열기

설정을 여세요. 맨 위의 카드가 리시버 관리이며, 리시버가 몇 대인지와 어느 것이 활성인지 표시합니다. 이 카드를 탭하세요.

표시되는 내용: "리시버를 탭해 설정하세요. 원을 탭하면 활성화됩니다. 드래그해서 순서를 바꾸세요."라는 문구, 그리고 이름, IP 주소, 모델이 표시된 리시버 목록입니다. 활성 리시버는 강조 표시되고 원이 채워져 있습니다. 목록 아래에는 리시버 추가 버튼이 있으며, 이미 데모 모드가 아니라면 DEMO MODE 섹션도 있습니다.

  • 리시버를 탭하면 해당 리시버의 페이지가 열립니다.
  • 행 앞의 원을 탭하면 해당 리시버가 활성화됩니다. 앱에 전환됨과 리시버 이름이 표시됩니다.
  • 행 끝의 핸들을 드래그해 순서를 바꾸세요. 홈 상단의 리시버 목록도 같은 순서를 따릅니다.
  • 리시버를 길게 누르면 이름 변경, IP 변경, 리시버 찾기, 삭제가 있는 빠른 메뉴가 표시됩니다.
단계별 안내

리시버 추가

  1. 설정 › 리시버 관리를 열고 리시버 추가(또는 오른쪽 상단의 +)를 탭하세요.
  2. iPhone, iPad, Mac, Android, Windows에서 화면이 네트워크를 검색하고 네트워크에서 찾은 리시버를 나열합니다. 내 리시버를 탭하세요. 응답하는 리시버가 없으면 다시 스캔을 탭하거나 IP 주소에 리시버의 주소를 입력하고 테스트 및 저장을 탭하세요.
  3. 앱이 연결을 테스트하고 리시버를 한 번에 저장합니다. 감지된 모델과 기능이 표시되며 새 리시버가 활성 리시버가 됩니다.
리시버의 IP 주소는 리시버 자체 메뉴의 Setup › General › Network › Information에 있습니다. 휴대폰이나 컴퓨터가 리시버와 같은 네트워크에 있어야 합니다. 네트워크 점검 목록은 시작하기를 참고하세요.
두 번의 탭

홈에서 리시버 전환

  1. 홈 탭에서 화면 상단의 AVR Maestro 옆에 표시된 리시버 이름을 탭하세요.
  2. 리시버 목록이 열리며 활성 리시버 옆에 체크 표시가 있습니다. 다른 리시버를 탭하면 전환되고, 목록 하단의 리시버 관리를 탭하면 전체 페이지가 열립니다.

각 리시버는 기기에 자체 데이터를 보관하므로, 전환하면 해당 리시버의 설정이 바로 불러와집니다.

설정 › 리시버 관리 › 내 리시버

리시버 페이지

리시버를 탭하면 해당 페이지가 열립니다. 상단의 카드에 연결 상태와 세부 정보가 표시됩니다. 활성 리시버가 아니면 카드 아래에 활성화 버튼이 있습니다. 볼륨 제한, 디스플레이, 잠금은 활성 리시버에서만 변경할 수 있기 때문입니다. 활성 리시버인데 연결할 수 없으면 페이지에 "앱이 지금 리시버에 연결되어 있지 않습니다."라고 표시됩니다.

오디오

이 리시버에 대한 내 환경설정입니다. 리시버마다 자체 값을 유지합니다. 볼륨 가이드 →

  • 볼륨 단계: 버튼을 한 번 누를 때 볼륨이 움직이는 폭으로, 0.5, 1, 1.5, 2 dB 중에서 고릅니다. 앱의 모든 볼륨 버튼에 적용됩니다.
  • 절대 볼륨을 위에 표시: 볼륨 표시에서 어느 숫자를 크게 보일지 바꿉니다. 끄면(기본값) dB가 크게, 볼륨 표시 단위가 작게 보이고, 켜면 볼륨 표시 단위가 크게, dB가 작게 보입니다.
  • 리모컨 볼륨 표시: 리모컨 탭에 dB 눈금(절대값 (dB), 예: -40.5 dB)을 표시할지, 0~98 눈금(상대값, 예: 39.5)을 표시할지 정합니다.
  • 점진적 볼륨 프리셋: 켜면(기본값) 볼륨 프리셋을 탭할 때 볼륨이 작은 단계로 변하고, 끄면 저장된 레벨로 바로 이동합니다.
  • 기기 볼륨 버튼(휴대폰과 태블릿): 앱이 열려 있는 동안 기기 자체의 볼륨 버튼으로 리시버의 볼륨을 바꿉니다. 기본값은 켜짐이며, 끄면 버튼이 기기 본래 기능으로 돌아갑니다.
  • 볼륨 제어: 리시버 자체에 기록되는 볼륨 제한, 전원 켤 때 레벨, 음소거 깊이입니다. 앱이 이 리시버에 연결되어 있는 동안 표시됩니다. 볼륨 제어 가이드 →

화면 및 잠금

연결되어 있는 동안 활성 리시버에 표시됩니다.

  • 온스크린 디스플레이: 볼륨 표시, 정보 배너, 재생 중, 21:9. 온스크린 디스플레이 가이드 →
  • 설정 잠금: 리시버 자체의 설정 메뉴를 잠급니다. 잠겨 있는 동안에는 리시버 메뉴, 이 앱, 웹 포털 어디에서도 오디오, 비디오, 스피커 등의 설정을 바꿀 수 없습니다. 볼륨, 입력, 디머 같은 일상적인 컨트롤은 계속 작동합니다. 켜기 전에 먼저 확인을 묻습니다(리시버 메뉴를 잠그시겠습니까?, 그다음 잠금). 잠금을 해제하려면 스위치를 끄세요.
  • 리모컨 잠금: 잠금을 해제할 때까지 리시버가 IR 리모컨의 버튼 입력을 무시합니다. 앱과 전면 패널은 계속 작동합니다.
설정 잠금과 리모컨 잠금은 리시버가 상태를 보고할 때만 나타납니다. 리시버가 잠금을 보고하지 않으면 추측하지 않고 스위치를 표시하지 않습니다. 설정 잠금 때문에 앱의 다른 곳에서 회색으로 표시되는 컨트롤은 컨트롤이 잠기는 이유에서 설명합니다.

이 리시버 정보

  • 기기 정보: 리시버의 자세한 상태입니다.
  • 펌웨어: 설치된 펌웨어 버전입니다. 확인을 탭하면 업데이트가 있는지 리시버에 묻습니다. 그러면 아래 줄에 최신 펌웨어를 사용 중이거나, 업데이트가 있거나, 업데이트가 진행 중이거나, 상태를 읽을 수 없다는 내용이 표시됩니다. 업데이트는 앱이 아닌 리시버 자체의 Setup 메뉴에서 설치하며, 업데이트 중에는 리시버의 전원을 끄지 마세요.

관리

  • 이름 변경: 기기 이름에 새 이름을 입력하고 저장을 탭하세요. 이름은 앱에만 저장됩니다.
  • IP 변경: 공유기가 새 주소를 할당한 경우처럼 새 IP 주소 또는 호스트 이름을 입력하고 저장을 탭하세요. 리시버에 저장된 모든 설정은 유지되고 주소만 바뀝니다. 다른 리시버가 이미 사용 중인 주소는 거부됩니다.
  • 리시버 찾기: 네트워크에서 이 리시버의 새 주소를 검색합니다. 다른 곳에서 리시버를 찾으면 이 주소 사용을 탭하세요. 저장된 주소가 이미 맞는 경우, 응답한 것이 없는 경우, 내 리시버일 수 있는 것이 여러 개인 경우를 각각 알려 주며, 마지막 경우에는 아무것도 바꾸지 않으므로 IP 변경을 사용하세요.
  • 삭제: 리시버를 삭제하시겠습니까?라고 물은 뒤 리시버와 저장된 모든 설정을 앱에서 제거합니다. 활성 리시버를 삭제하면 앱이 다른 리시버로 전환합니다.
리시버가 필요 없습니다

데모 모드 들어가기와 나오기

데모 모드는 앱 안에서 가상의 Marantz CINEMA 30을 실행합니다. 모든 화면이 실제 하드웨어와 똑같이 작동하며 네트워크로는 아무것도 전송되지 않습니다.

  1. 시작은 설정 › 리시버 관리 › 데모 모드 사용해 보기, 리시버 추가 화면의 데모 모드 둘러보기, 또는 환영 안내의 대신 데모 사용해 보기에서 할 수 있습니다. 데모 리시버가 활성화되고 앱이 홈을 엽니다.
  2. Pro 미리 보기. 데모가 실행되는 동안 설정에 DEMO MODE 섹션이 표시됩니다. 이 섹션의 Pro 기능 미리 보기 스위치는 이 데모 세션에서만 홈 오토메이션과 트리거를 잠금 해제합니다. 아무것도 구매되지 않습니다.
  3. 종료는 설정 › 데모 모드 종료로 합니다. 데모 리시버가 제거되고 앱이 내 리시버로 돌아갑니다.
자주 묻는 질문

리시버, 질문과 답변

다른 리시버로 전환하려면 어떻게 하나요?
홈 탭에서 상단의 AVR Maestro 옆에 있는 리시버 이름을 탭하고 목록에서 다른 리시버를 선택하세요. 설정 › 리시버 관리를 열어 리시버 행 맨 앞의 원을 탭해도 됩니다. 앱이 전환됨과 리시버 이름으로 확인해 줍니다.
리시버의 IP 주소가 바뀌었습니다. 어떻게 해야 하나요?
보통은 아무것도 하지 않아도 됩니다. 라우터가 리시버의 주소를 바꾸면 앱이 다시 찾아내고 따라갔다고 한 번 알려 줍니다. 찾지 못하면 설정 › 리시버 관리에서 리시버를 탭한 뒤 리시버 찾기로 네트워크를 검색하거나, IP 변경으로 새 주소를 직접 입력하세요. 리시버에 저장된 모든 설정은 그대로 유지되며 주소만 바뀝니다.
화면 및 잠금이나 이 리시버 정보가 보이지 않는 이유는 무엇인가요?
이 섹션은 리시버를 실시간으로 읽고 쓰므로, 앱이 연결된 활성 리시버에서만 나타납니다. 활성화로 리시버를 활성 상태로 만들고 연결될 때까지 기다리세요.
설정 잠금과 리모컨 잠금은 어떻게 다른가요?
설정 잠금은 리시버 자체의 설정 메뉴를 잠가, 잠금을 해제하기 전에는 이 앱을 포함해 누구도 설정과 보정 값을 바꿀 수 없습니다. 볼륨과 입력은 계속 작동합니다. 리모컨 잠금은 리시버가 IR 리모컨을 무시하게 하며, 앱과 전면 패널은 계속 작동합니다. 각 스위치는 리시버가 해당 잠금을 보고할 때만 나타납니다.
리시버를 삭제하면 어떻게 되나요?
앱이 리시버와 그 리시버에 저장된 모든 설정을 제거합니다. 활성 리시버였다면 앱이 다른 리시버로 전환합니다. 리시버 자체는 아무것도 바뀌지 않으며 언제든지 다시 추가할 수 있습니다.
리시버 없이 앱을 사용해 볼 수 있나요?
네. 설정 › 리시버 관리에서 데모 모드 체험을 탭하거나 리시버 추가 화면에서 데모 모드 둘러보기를 탭하세요. 데모 모드는 앱 안에서 가상의 Marantz CINEMA 30을 실행하며 네트워크로는 아무것도 보내지 않습니다. 설정 › 데모 모드 종료에서 나갈 수 있습니다.

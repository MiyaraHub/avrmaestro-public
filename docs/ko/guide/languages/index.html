언어 FAQ

앱이 내 휴대폰 언어를 자동으로 따르나요?
네. 기본적으로 기기 언어를 따릅니다. 직접 선택하려면 설정 › 언어를 여세요. 시스템 기본값을 선택하면 언어 선택이 다시 기기로 넘어갑니다.
히브리어와 아랍어는 오른쪽에서 왼쪽으로 표시되나요?
네. 탐색, 카드, 목록, 슬라이더까지 앱 전체가 좌우 반전되며, dB와 볼륨 표시는 그 안에서도 여전히 왼쪽에서 오른쪽으로 읽습니다.
입력 이름과 사운드 모드가 왜 계속 영어로 나오나요?
앱이 아니라 리시버가 직접 쓰는 표현이기 때문입니다. 입력 이름, 사운드 모드, Dolby Atmos, Audyssey, Smart Select, HEOS 같은 브랜드 및 형식 이름, 그리고 리시버가 보고하는 모든 값은 리시버가 말하는 그대로 표시됩니다. 번역되는 것은 앱 자체의 문구뿐입니다.
백업에도 언어 설정이 포함되나요?
네. 언어 선택은 Backup & Restore에 포함되므로, 복원한 휴대폰도 사용하던 언어로 열립니다.

오디오볼륨 단계(0.5-2.0 dB)는 모든 탭, 길게 눌러 연속 조절, 볼륨 버튼에 사용됩니다. 그 밖에 상단에 절대 볼륨과 dB 중 무엇을 표시할지, 기기 볼륨 버튼(기본적으로 켜짐, Android 및 iOS), 점진적 대 다이렉트 볼륨 프리셋을 설정할 수 있습니다. 점진적(기본값)은 프리셋의 목표 볼륨으로 바로 점프하지 않고 부드럽게 올라가며, 메인 존과 존 2/3에서 작동합니다.

개발자 도구정보에서 버전 번호를 일곱 번 누를 때까지 숨겨져 있으며, 이후에는 제거하기 전까지 앱을 다시 실행해도 계속 사용할 수 있습니다. 원시 Telnet / HEOS 명령, AJAX 덤프, 볼륨 제한 와이어 진단을 제공합니다.

앱 그 너머

홈 화면 위젯과 기기 볼륨 버튼

  • 홈 화면 위젯(iOS 및 Android): 퀵 컨트롤(전원 / 볼륨 / 음소거 / 소스), 지금 재생 중, 상태 위젯을 여러 크기로 제공하며, 탭만으로 사용하고 자동으로 새로고침됩니다. 리시버가 꺼져 있거나 연결할 수 없을 때는 오래된 입력과 볼륨 대신 "AVR 꺼짐" / "대기 모드" 상태를 분명하게 표시하며, 전원 버튼은 계속 작동하므로 위젯에서 바로 리시버를 깨울 수 있습니다.
  • 기기 볼륨 버튼(Android 및 iOS): AVR Maestro가 포그라운드에 있는 동안 기기의 실물 볼륨 버튼이 리시버의 볼륨을 제어하고(설정한 볼륨 단계 사용), 길게 누르면 연속으로 조절됩니다. 포그라운드에서만 작동하며, 앱이 다른 앱 뒤로 가면 버튼은 즉시 기기 볼륨으로 돌아갑니다. 설정, 오디오의 스위치로 이 기능을 끌 수 있습니다.
위젯, 테마, 백업 & 복원, 볼륨 버튼 제어 기능은 모두 iOS와 Android 양쪽에서 작동합니다.
자주 묻는 질문

설정 자주 묻는 질문

앱의 테마와 색상을 바꿀 수 있나요?
네. 라이트, 다크, 기기 설정 또는 AMOLED(완전한 검정)에 더해, 원하는 강조 색을 고르면 앱이 팔레트를 새로 구성하는 색상 테마를 지원합니다. 색상환을 사용하거나 16진수 코드(#FF8C00 또는 세 자리 축약형)를 입력하세요. 코드가 올바르지 않으면 앱이 그냥 거부하지 않고 무엇이 문제인지 알려 줍니다. 디스플레이/위젯 크기와 탐색 메뉴 및 탭도 설정할 수 있습니다.
설정을 백업할 수 있나요?
네. 설정, 백업에서 모든 리시버, 프리셋, 환경설정을 사용자 지정 입력 아이콘까지 함께 담은 .zip 파일로 내보내고, 새 휴대폰에서 가져와 복원할 수 있습니다. 이전 .json 백업도 문제없이 가져옵니다. 파일에 자격 증명이 없어 공유해도 안전합니다.
볼륨 프리셋은 목표 볼륨으로 바로 이동하나요, 아니면 서서히 올라가나요?
직접 선택할 수 있습니다. 설정, 오디오에 점진적 / 다이렉트 스위치가 있습니다. 점진적(기본값)은 프리셋의 목표 볼륨을 향해 부드럽게 올라가므로, 한 번 눌러도 갑작스러운 볼륨 점프로 스피커에 충격을 주지 않습니다. 다이렉트는 즉시 적용합니다. 메인 존과 존 2/3에서 작동합니다.
앱에서 리시버의 실물 리모컨을 잠글 수 있나요?
네, 지원하는 리시버에서 가능합니다. 설정, 리시버에 있는 리모컨 잠금 스위치로 리시버 자체의 IR 리모컨을 잠그거나 해제할 수 있습니다.
홈 화면 위젯은 Android에서만 사용할 수 있나요?
아니요. 퀵 컨트롤(전원 / 볼륨 / 음소거 / 소스), 지금 재생 중, 상태 위젯은 iOS와 Android 모두에서 제공됩니다. 리시버가 꺼져 있거나 연결할 수 없을 때는 오래된 데이터 대신 "AVR 꺼짐" / "대기 모드" 상태를 분명하게 표시하며, 퀵 컨트롤의 전원 버튼은 계속 작동하므로 위젯에서 리시버를 깨울 수 있습니다.
휴대폰의 볼륨 키로 리시버를 제어할 수 있나요?
Android에서는 가능합니다. 앱이 포그라운드에 있는 동안 볼륨 키로 리시버의 볼륨을 제어합니다. iOS에서는 허용되지 않습니다.
숨겨진 디버그 메뉴는 어떻게 여나요?
설정, 정보를 열고 버전 번호를 일곱 번 누르세요. 그러면 디버그 메뉴가 앱을 다시 실행해도 계속 유지되며, 실시간 디버그 로그와 지원용 원시 명령 도구 및 진단 기능을 사용할 수 있습니다. "디버그 메뉴 제거"를 눌러 다시 숨길 때까지 유지됩니다.
"MiyaraHub의 다른 앱"이란 무엇인가요?
설정에 있는 섹션으로, 모든 앱 둘러보기 버튼이 있습니다. 누르면 기기에 따라 Google Play, App Store, Microsoft Store 중 해당 앱 스토어가 MiyaraHub 개발자 페이지로 열려, 저희가 만든 모든 앱을 둘러볼 수 있습니다.

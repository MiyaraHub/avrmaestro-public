홈 화면 위젯

앱을 열지 않고도 홈 화면에서 바로 리시버를 제어하세요. 전원, 볼륨, 음소거, 재생 중인 항목, 현재 신호, 장면을 다룰 수 있습니다. 위젯은 Android와 iPhone, iPad에서 사용할 수 있으며 Mac과 Windows에는 위젯이 없습니다.

네 가지 위젯

  • 빠른 제어(Android: AVR Quick Control). 리시버 이름, 입력, 볼륨과 함께 전원, 볼륨 낮추기, 볼륨 높이기, 음소거가 있습니다. Android에는 앱 열기도 있으며, 리시버가 꺼져 있는 동안에는 볼륨과 음소거 버튼이 숨겨지고 전원만 남습니다.
  • 재생 중(Android: AVR Now Playing). 커버 아트, 제목, 아티스트, 방송국과 함께 이전, 재생 또는 일시정지, 다음이 있습니다. 재생 중인 것이 없으면 Android에서는 재생 중인 미디어 없음, iPhone과 iPad에서는 재생 중인 것 없음이라고 표시됩니다.
  • 리시버 상태(Android: AVR Signal Status). 입력, 들어오고 나가는 오디오 및 비디오 신호, 샘플 레이트, 볼륨을 보여 줍니다.
  • 장면(Android: AVR Scenes). 리시버에 저장된 장면입니다. 하나를 탭하면 앱을 열지 않고 적용됩니다. 장면을 참조하세요.
위젯은 앱에서 선택한 리시버를 따릅니다. 빠른 제어와 상태는 리시버가 대기 상태일 때 대기를, 연결할 수 없을 때 AVR 꺼짐을 표시합니다.
단계별 안내

위젯 추가하기

  1. 위젯에 보여 줄 내용이 있도록 AVR Maestro를 한 번 열어 리시버에 연결하세요.
  2. 홈 화면의 빈 곳을 길게 누르고 휴대폰의 위젯 옵션을 선택하세요.
  3. AVR Maestro를 찾아 위젯을 고르세요. Android에서는 이름이 AVR로 시작합니다. iPhone과 iPad에서는 빠른 제어, 재생 중, 리시버 상태는 중간 크기로, 장면은 중간 또는 큰 크기로 제공됩니다.
  4. Android에서는 위젯의 가장자리를 끌어 크기를 조절하세요. 작은 크기에서는 간결한 레이아웃으로 바뀝니다.
iPhone과 iPad 위젯에는 iOS 또는 iPadOS 17 이상이 필요합니다.

위젯을 최신 상태로 유지하기

  • 새로고침 버튼. 빠른 제어, 재생 중, 장면에는 위젯을 즉시 업데이트하는 새로고침 버튼이 있습니다. Android에서 재생 중은 더 큰 크기에서 이 버튼을 표시합니다.
  • 자동 새로고침. 빠른 제어와 상태는 약 15분마다 자동으로 업데이트되며, Android에서는 재생 중도 그렇습니다. Android에서는 네트워크 연결이 필요합니다. 장면은 앱에서 장면을 바꾸거나 새로고침을 탭할 때 업데이트됩니다.
Android에서 위젯을 처음 사용하면 앱이 홈 화면 위젯을 설명하고 설정 열기를 제안합니다. 가장 안정적인 백그라운드 업데이트를 위해 배터리 설정에서 AVR Maestro가 백그라운드에서 실행되도록 허용하세요.

위젯 색상

두 설정은 모두 Android, iPhone, iPad의 설정 아래 디자인에 있습니다.

  • 고대비 위젯은 위젯을 회색조로 만듭니다.
  • 위젯이 앱 색상 따르기는 위젯에 시그니처 주황색 대신 색상 테마 강조 색상을 사용합니다. 고대비 위젯이 켜져 있는 동안에는 이 스위치를 사용할 수 없으며 위젯은 회색조로 유지됩니다.
같은 섹션의 위젯 크기는 홈 화면 위젯을 바꾸지 않습니다. 앱 안의 버튼, 칩, 카드 크기를 조절합니다(작게, 보통, 크게, 더 크게). 설정을 참조하세요.
FAQ

위젯 질문과 답

AVR Maestro에는 어떤 홈 화면 위젯이 있나요?
Android와 iPhone 또는 iPad에서 네 가지가 있습니다. 빠른 제어(전원, 볼륨, 음소거), 재생 중(재생 중인 항목과 이전, 재생 또는 일시정지, 다음), iPhone의 리시버 상태 또는 Android의 신호 상태(입력, 오디오 및 비디오 신호), 장면(저장된 장면 적용)입니다. Mac과 Windows에는 위젯이 없습니다.
위젯은 얼마나 자주 업데이트되나요?
빠른 제어와 상태는 약 15분마다 자동으로 업데이트되며, Android에서는 재생 중 위젯도 그렇습니다. 빠른 제어, 재생 중, 장면에는 위젯을 즉시 업데이트하는 새로고침 버튼도 있습니다.
위젯에 AVR 꺼짐 또는 대기라고 표시되는 이유는 무엇인가요?
대기는 리시버가 대기 상태라는 뜻입니다. AVR 꺼짐은 전원이 뽑혀 있거나 다른 네트워크에 있는 등의 이유로 위젯이 리시버에 연결할 수 없었다는 뜻입니다.
장면 위젯에 장면이 없다고 표시되는 이유는 무엇인가요?
위젯에는 선택한 리시버에 저장된 장면이 나열됩니다. 먼저 AVR Maestro를 열어 장면을 만드세요. 장면 가이드를 참조하세요.
위젯 크기를 바꾸면 홈 화면 위젯도 바뀌나요?
아니요. 설정 › 위젯 크기는 앱 안의 버튼, 칩, 카드 크기를 바꿉니다. 홈 화면 위젯의 크기를 바꾸려면 홈 화면에서 위젯 크기를 조절하세요.
위젯이 내 테마 색상을 사용할 수 있나요?
네. 설정 › 위젯이 앱 색상 따르기를 켜면 위젯이 주황색 대신 강조 색상을 사용합니다. 고대비 위젯이 켜져 있는 동안에는 위젯이 회색조이므로 사용할 수 없습니다.

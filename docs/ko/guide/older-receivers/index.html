AVR-X4000 세대

구형 Denon 리시버 완전 지원

AVR Maestro 앱은 네트워크를 통해 AVR-X4000 세대 Denon 리시버를 제어합니다. 구형 리시버는 최신 모델보다 응답하는 항목이 적으므로, 리시버가 보고하는 컨트롤만 표시하며 지어내는 것은 없습니다.

제공되는 기능

구형 리시버의 컨트롤

  • 즐겨찾기 1에서 4: 시스템 페이지에 메인 존용 즐겨찾기 행이 있습니다. 슬롯을 탭하면 불러오고, 길게 누르면 확인 후 재생 중인 내용이 저장됩니다.
  • Video Select: 시스템 페이지에서 비디오 소스를 선택합니다.
  • 화면 비율과 비디오 해상도: 시스템 페이지에서 설정하며, 옆에 HDMI 해상도가 함께 표시됩니다.
  • Network Presets: 리모컨 페이지의 패널입니다. 프리셋을 탭하면 불러오고, 길게 누르면 확인 후 현재 방송국이 저장됩니다.
  • HD Radio: 북미 모델에서는 리시버가 HD 방송국을 보고하면 라디오 페이지에 HD Radio 패널이 나타납니다.
  • 존 즐겨찾기와 취침 타이머: 각 존 카드에는 즐겨찾기 네 개가 있어 탭으로 불러오고 길게 눌러 저장하며, 취침 타이머는 끔, 30, 60, 90, 120분 중에서 선택합니다.
위의 모든 행은 리시버가 응답할 때만 나타납니다. 행이 없다면 리시버가 보고하지 않은 것이며, 앱이 아니라 리시버 쪽 문제입니다.
제공되지 않는 기능

구형 리시버가 응답할 수 없는 컨트롤

이 세대에서는 Bluetooth, Loudness, Cinema EQ를 제공하지 않습니다. 리시버가 응답할 수 없기 때문입니다. AVR Maestro 앱은 아무 일도 하지 않는 스위치를 보여 주는 대신 이 항목들을 뺍니다.

자주 묻는 질문

구형 리시버 자주 묻는 질문

AVR Maestro 앱은 AVR-X4000 같은 구형 Denon 리시버에서도 작동하나요?
네. 네트워크로 메인 존, 존 2, 존 3을 제어합니다. 구형 리시버는 최신 모델보다 응답하는 항목이 적어서, 리시버가 응답하는 컨트롤만 표시됩니다.
구형 리시버에서 일부 컨트롤이 보이지 않는 이유는 무엇인가요?
앱은 리시버가 보고하는 컨트롤만 표시합니다. 구형 Denon 리시버에는 Bluetooth, Loudness, Cinema EQ가 없으므로 제공되지 않습니다.
구형 리시버에서 즐겨찾기는 어떻게 저장하나요?
즐겨찾기를 탭하면 불러옵니다. 길게 누르면 현재 재생 중인 내용이 저장되며, 확인 메시지가 나오면 확인을 누르세요.

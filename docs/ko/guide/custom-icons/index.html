나만의 스타일로

모든 입력에 나만의 아이콘을

기본 이미지를 나만의 이미지로 바꿔 보세요. 플레이어에는 블루레이 커버를, 게임 입력에는 콘솔 로고를, Phono에는 턴테이블을 올려 한눈에 소스를 알아볼 수 있게 하세요. 아이콘은 입력 타일, 홈 대시보드, 리모컨에 표시되며 설정 백업과 함께 옮겨집니다.

몇 번의 탭으로 아이콘 추가

  • 리모컨 탭의 입력 목록에 있는 입력 타일이나 홈 대시보드의 입력 카드를 길게 누르세요.
  • 원하는 이미지를 고르세요. PNG, JPG, ICO, WebP 등 로고, 커버, 사진 무엇이든 괜찮습니다.
  • 여권 사진 방식의 편집기에서 자르세요. 드래그로 위치를 잡고 핀치로 확대해서 중요한 부분이 프레임 안에 들어오게 하세요.
  • 모양을 고르세요. 원, 둥근 사각형 등을 고를 수 있으며, 자르기 화면에서 바로 아이콘이 해당 모양으로 잘립니다.
  • 저장하세요. 아이콘이 타일을 가득 채우며, 가운데에 작게 놓이는 대신 두 줄짜리 소스 이름 영역까지 차지하고, 입력 목록, 홈 대시보드, 리모컨 탭의 현재 입력 카드 등 해당 입력이 나타나는 모든 곳에 표시됩니다.
장면에도

장면을 위한 나만의 이미지

저장된 모든 장면에도 각자의 이미지를 넣을 수 있습니다. 장면의 아이콘 & 색상 시트를 열고 이미지를 업로드한 뒤 같은 방식으로 자르세요. “영화 감상” 장면에는 영사기 릴을, “일요일의 LP” 장면에는 레코드판을 넣어, 한 번의 탭으로 실행하는 설정을 입력만큼이나 알아보기 쉽게 만들어 보세요.

이미지가 타일 전체를 채우길 원하시나요? 사용자 지정 소스 아이콘과 장면 아이콘은 라벨을 숨길 수 있어서, 위에 텍스트 없이 이미지가 가장자리까지 가득 차게 표시됩니다. 같은 아이콘 & 색상 시트에서 언제든 라벨을 다시 켤 수 있습니다.
자주 묻는 질문

사용자 지정 아이콘 FAQ

사용자 지정 입력 아이콘은 어디에 표시되나요?
리모컨 탭의 입력 목록에 있는 입력 타일, 홈 대시보드의 입력 카드, 리모컨 탭의 현재 입력 카드 등 앱에서 해당 소스가 나타나는 모든 곳에 표시됩니다.
어떤 이미지 형식을 쓸 수 있나요?
PNG, JPG, ICO, WebP 등을 쓸 수 있습니다. 여권 사진 방식의 자르기 도구로 어떤 이미지든 위치, 확대, 모양을 조절할 수 있습니다.
장면에도 사용자 지정 아이콘을 쓸 수 있나요?
네. 저장된 장면의 아이콘 & 색상 시트를 열고 같은 방법으로 이미지를 업로드하세요. 장면을 만들고 불러오는 방법은 장면 가이드를 참고하세요.
앱을 다시 설치하거나 새 휴대폰으로 바꿔도 아이콘이 남아 있나요?
네. 사용자 지정 아이콘은 앱의 설정 백업에 저장됩니다. 설정에서 백업한 뒤 새 장치에서 복원하면 이미지도 함께 옮겨집니다.
이미지가 타일을 가득 채우도록 라벨을 숨길 수 있나요?
네. 사용자 지정 소스 아이콘과 장면 아이콘 모두 라벨 숨기기 옵션이 있어서, 텍스트 없이 이미지가 타일 가운데에 가득 차게 표시됩니다.

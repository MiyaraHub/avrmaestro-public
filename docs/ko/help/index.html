Denon & Marantz 앱의 흔한 문제 해결

가장 흔한 질문에 대한 빠른 해결책입니다. 그래도 해결되지 않으면 설정 › AVR Maestro 정보 › 관련 로그 모두에서 로그를 보내 주세요. 지원을 받는 가장 빠른 방법이며, 개발자는 Discord 또는 Facebook 지원 그룹에서 만날 수 있고 답변이 빠릅니다.

연결

연결하기

“연결 테스트”가 실패합니다
휴대폰과 리시버가 같은 Wi-Fi 네트워크와 서브넷에 있는지 확인하세요. 메시 시스템, 게스트 네트워크, IoT VLAN은 기기를 서로 격리할 수 있습니다. 리시버에서 Setup → Network → Network Control이 On이어야 합니다. DHCP 주소는 바뀔 수 있으므로 리시버 자체의 Network → Information 화면에서 IP를 다시 확인하세요. HTTP는 필수이고, Telnet과 HEOS는 있으면 좋습니다. 리시버에 연결은 되지만 네트워크 스택이 포화 상태일 때 - 연결을 붙잡고 있는 컨트롤러 앱이 너무 많을 때 - 앱은 일반적인 실패 메시지 대신 분명한 네트워크 사용 중 메시지를 보여 줍니다. 다른 컨트롤러를 닫거나 몇 초간 기다려 주세요. 자세한 단계는 시작하기 가이드에서 확인하세요.
몇 초마다 연결이 끊어집니다
오래 켜 두면 리시버의 Telnet 포트가 응답하지 않게 될 수 있으니, 콘센트에서 전원을 뽑았다 다시 꽂아 리스너를 초기화하세요. Wi-Fi 6 메시 환경에서는 휴대폰이 리시버와 같은 대역에 연결되도록 하세요(AVR은 보통 2.4 GHz를 쓰지만 휴대폰은 5 GHz를 선호합니다).
내 리시버가 지원되는지 어떻게 알 수 있나요?
모델뿐 아니라 네트워크에 달려 있습니다. 리시버의 웹 포털, HEOS 앱, 공식 Denon/Marantz 앱이 모두 리시버에 접속할 수 있다면 AVR Maestro도 접속할 수 있을 것입니다. 지원 리시버 페이지를 참고하세요.
컨트롤 & 화면

이상해 보이는 이유

볼륨 표시가 이상해 보입니다
볼륨은 두 가지 눈금으로 표시할 수 있습니다. 0-98 눈금 또는 -80에서 +18 dB의 데시벨 눈금이며, 둘 다 같은 볼륨을 나타냅니다. 설정 › 리시버 관리 › 해당 리시버 › 오디오에서 절대 볼륨을 위에 표시는 어느 쪽을 큰 숫자로 보일지 정하고, 리모컨 볼륨 표시는 리모컨 탭에서 사용할 눈금을 정합니다. 볼륨 가이드를 참조하세요.
사운드 모드나 기능 표시가 회색이거나 "N/A"로 나옵니다
서라운드 모드와 기능은 입력의 오디오 형식과 활성 사운드 모드에 따라 제한됩니다. 2채널 소스에서는 Dolby Atmos를 켤 수 없습니다. 이는 앱이 아니라 리시버의 동작입니다. 잠긴 컨트롤 가이드에서 컨트롤이 잠기는 이유와 잠금을 푸는 방법을 설명합니다.
일부 사운드 또는 스피커 탭이 보이지 않습니다
탭은 모델과 모드에 따라 달라집니다. Audyssey, Dirac Live, IMAX, Auro-3D, 서라운드 형태, 거리, 크로스오버는 해당 기능을 제공하는 리시버에만 나타납니다. 앱이 무엇을 감지했는지 보려면 설정 › 리시버 관리 › 해당 리시버 › 기기 정보를 확인하세요. 끈 하위 탭은 설정 › 탭 사용자 지정에서, 하단 탭은 설정 › 탐색 사용자 지정에서 되돌릴 수 있습니다. 탐색 가이드를 참조하세요.
라디오 탭이 보이지 않습니다
라디오는 기능에 따라 표시됩니다. FM/AM 튜너가 내장된 리시버에만 나타납니다. 튜너가 있는데 탭이 숨겨져 있다면 리시버에서 튜너가 입력으로 표시되는지 확인하고 설정 › 탐색 사용자 지정에서 다시 켜세요. 라디오 가이드를 참조하세요.
지금 재생 중 카드가 비어 있습니다
현재 입력이 메타데이터를 제공하지 않습니다. 아날로그, 광/동축, 대부분의 HDMI 패스스루 소스는 트랙 정보를 보고하지 않습니다. HEOS 소스는 HEOS 실행을 눌러 재생을 시작한 다음 돌아오면 메타데이터가 채워집니다.
홈 화면 위젯에 "AVR 꺼짐" 또는 "대기 모드"라고 나옵니다
이는 고장이 아니라 위젯의 꺼짐 상태입니다. 빠른 제어와 상태 위젯(iOS 및 Android)은 리시버가 대기 상태일 때 "대기"를, 연결할 수 없을 때 "AVR 꺼짐"을 마지막 입력과 볼륨 대신 표시하므로 오래된 데이터를 읽을 일이 없습니다. Android에서는 이 상태에서 빠른 제어의 볼륨과 음소거 버튼이 숨겨지지만 전원 버튼은 계속 작동하며, 탭하면 위젯에서 바로 리시버를 깨울 수 있습니다(리시버에서 네트워크 대기가 켜져 있어야 합니다). 위젯 가이드를 참조하세요.
일부 스피커 화면이 리시버의 웹 컨트롤에서 열립니다
일부 Denon 및 Marantz 펌웨어는 스피커 구성, 스피커 거리, 스피커 크로스오버를 앱에 돌려주지 않습니다. 그러면 페이지가 그렇게 알려 주며 다시 시도와 리시버 자체 웹 제어에서 해당 화면을 여는 버튼이 표시됩니다. 사용하지 않는다면 설정 › 탭 사용자 지정에서 탭을 숨기세요. 리시버의 웹 제어 페이지가 브라우저에서 열려 있다면 리시버를 계속 바쁘게 만들 수 있으므로 먼저 닫으세요.
장면이 완전히 적용되지 않았습니다
현재 입력, 신호 또는 사운드 모드가 허용하지 않는 설정은 리시버가 거부할 수 있습니다. 장면 가이드의 장면이 완전히 적용되지 않을 때 섹션에서 무엇을 확인해야 하는지 설명합니다.

흔한 Denon & Marantz 앱 문제 해결

가장 흔한 질문에 대한 빠른 해결 방법입니다. 그래도 해결되지 않으면 앱의 디버그 로그(설정 → 도움말 → 저장 & 공유)를 보내 주시는 것이 지원을 받는 가장 빠른 방법입니다. Discord 또는 Facebook 지원 그룹에서 개발자에게 문의하세요. 답변이 빠릅니다.

연결

연결하기

“연결 테스트”가 실패합니다
휴대폰과 리시버가 같은 Wi-Fi 네트워크와 서브넷에 있는지 확인하세요. 메시 시스템, 게스트 네트워크, IoT VLAN은 기기를 서로 격리할 수 있습니다. 리시버에서 Setup → Network → Network Control이 On이어야 합니다. DHCP 주소는 바뀔 수 있으므로 리시버 자체의 Network → Information 화면에서 IP를 다시 확인하세요. HTTP는 필수이고, Telnet과 HEOS는 있으면 좋습니다. 리시버에 연결은 되지만 네트워크 스택이 포화 상태일 때 - 연결을 붙잡고 있는 컨트롤러 앱이 너무 많을 때 - 앱은 일반적인 실패 메시지 대신 분명한 네트워크 사용 중 메시지를 보여 줍니다. 다른 컨트롤러를 닫거나 몇 초간 기다려 주세요. 자세한 단계는 시작하기 가이드에서 확인하세요.
몇 초마다 연결이 끊어집니다
오래 켜 두면 리시버의 Telnet 포트가 응답하지 않게 될 수 있으니, 콘센트에서 전원을 뽑았다 다시 꽂아 리스너를 초기화하세요. Wi-Fi 6 메시 환경에서는 휴대폰이 리시버와 같은 대역에 연결되도록 하세요(AVR은 보통 2.4 GHz를 쓰지만 휴대폰은 5 GHz를 선호합니다).
내 리시버가 지원되는지 어떻게 알 수 있나요?
모델뿐 아니라 네트워크에 달려 있습니다. 리시버의 웹 포털, HEOS 앱, 공식 Denon/Marantz 앱이 모두 리시버에 접속할 수 있다면 AVR Maestro도 접속할 수 있을 것입니다. 지원 리시버 페이지를 참고하세요.
컨트롤 & 화면

이상해 보이는 이유

볼륨 표시가 이상해 보입니다
리시버는 볼륨을 절대값(0-98) 또는 상대값(-80 ~ +18 dB)으로 보고합니다. 앱은 둘 다 처리합니다. 최근 리시버의 볼륨 표시 설정을 바꿨다면 앱을 다시 시작해 스케일을 다시 읽게 하세요. 설정 → 오디오에서 위에 표시할 값을 바꿀 수 있습니다.
사운드 모드나 기능 표시가 회색이거나 "N/A"로 나옵니다
서라운드 모드와 기능은 입력의 오디오 형식과 현재 사운드 모드에 따라 제한됩니다. 예를 들어 2채널 소스에서는 Dolby Atmos를 사용할 수 없습니다. 이는 앱이 아니라 리시버의 동작입니다. N/A 표시 옆의 (?)를 누르면 정확한 요구 조건을 볼 수 있습니다.
일부 사운드 또는 스피커 탭이 보이지 않습니다
탭은 모델과 모드에 따라 달라집니다. Audyssey, Dirac Live, IMAX, Auro-3D, Surround Shape, 거리, 크로스오버는 해당 기능을 제공하는 리시버에서만 나타납니다. 설정 → 기기 → 기기 정보에서 앱이 감지한 내용을 확인하거나, 설정 → 탭 사용자 설정 / 내비게이션 사용자 설정에서 숨긴 탭을 다시 추가하세요.
라디오 탭이 보이지 않습니다
라디오는 기능이 있는 기기에서만 표시됩니다. FM/AM 튜너가 내장된 리시버에서만 나타납니다. 튜너가 있는데도 탭이 숨겨져 있다면 리시버에 튜너가 입력으로 나타나는지 확인하고 설정 → 내비게이션 사용자 설정에서 다시 켜세요. 라디오 가이드를 참고하세요.
지금 재생 중 카드가 비어 있습니다
현재 입력이 메타데이터를 제공하지 않습니다. 아날로그, 광/동축, 대부분의 HDMI 패스스루 소스는 트랙 정보를 보고하지 않습니다. HEOS 소스는 HEOS 실행을 눌러 재생을 시작한 다음 돌아오면 메타데이터가 채워집니다.
홈 화면 위젯에 "AVR 꺼짐" 또는 "대기 모드"라고 나옵니다
이는 위젯의 꺼짐 상태 표시이며 오류가 아닙니다. 리시버가 꺼져 있거나 대기 모드이거나 연결할 수 없을 때, 위젯(iOS와 Android)은 마지막 입력과 볼륨 대신 "AVR 꺼짐" / "대기 모드"를 표시하므로 오래된 정보를 보게 되는 일이 없습니다. 빠른 제어 위젯에서는 이 상태일 때 볼륨과 음소거 버튼이 숨겨지지만 전원 버튼은 계속 작동합니다. 눌러서 위젯에서 바로 리시버를 깨울 수 있습니다(리시버에서 Network Standby가 활성화되어 있어야 합니다).
일부 스피커 화면이 리시버의 웹 컨트롤에서 열립니다
2025년 이전 일부 리시버(X4500H / X6700H / S960H / X4700H 계열)는 앱에 스피커 구성 또는 서브우퍼 출력 화면을 제공하지 못하므로, AVR Maestro는 해당 편집을 위해 리시버 자체의 웹 컨트롤로 바로 연결되는 버튼을 제공합니다. 나머지는 모두 정상적으로 작동하며, 최신 펌웨어는 모든 화면을 앱에서 제공합니다.

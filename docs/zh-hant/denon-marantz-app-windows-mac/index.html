用鍵盤操作接收器

在 Mac App Store 與 Microsoft Store 版本中，macOS 使用 Cmd，Windows 使用 Ctrl。鍵盤上的媒體鍵同樣可用，而在文字欄位中輸入時不會觸發任何動作。詳情請見遙控器指南。

快速鍵動作
Cmd + Space / Ctrl + Space播放 / 暫停
Cmd + . / Ctrl + .（句號）停止
Cmd + 左 / 右，Ctrl + 左 / 右上一首 / 下一首
Cmd + 上 / 下，Ctrl + 上 / 下音量調高 / 調低
Cmd + M / Ctrl + M切換靜音
常見問題

Windows 與 Mac 常見問答

有適用於 Windows 的 Denon 或 Marantz 應用程式嗎？
有。AVR Maestro 可在 Microsoft Store 取得，能從與接收器位於同一網路的 Windows 電腦控制具備網路功能的 Denon 與 Marantz AV 接收器。
有適用於 Mac 的 Denon 或 Marantz 應用程式嗎？
有。AVR Maestro 可在 Mac App Store 取得，支援 Cmd 鍵盤快速鍵與媒體鍵。
桌面版應用程式有鍵盤快速鍵嗎？
有。在 macOS 上使用 Cmd，在 Windows 上使用 Ctrl：空白鍵為播放/暫停，. （句點）為停止，左/右為上一首/下一首，上/下為音量，M 為靜音。媒體鍵同樣可用，而在文字欄位中輸入時，快速鍵會暫停作用。
助理能在 Windows 上使用嗎？
不能。助理需要裝置端模型：iPhone、iPad 或 Mac（macOS 26）上的 Apple Intelligence，或 Android 上的 Gemini Nano。此清單中的其他功能在 Windows 上都能使用。請參閱助理指南。

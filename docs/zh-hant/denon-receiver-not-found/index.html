連線說明

Denon 或 Marantz 找不到接收器？修復連線

當 AVR Maestro 找不到或無法連上您的接收器時，原因幾乎都出在網路，而不是應用程式。請依序完成以下檢查：Network Control、子網路、IP 位址，以及接收器是否忙碌。

請依下列順序檢查

四項檢查即可解決大多數連線問題

每項只需一分鐘。接收器一連上就可以停止。

📶

相同的網路與子網路

手機與接收器必須位於同一個網路。Mesh 系統、訪客網路和 IoT VLAN 可能會隔離裝置，位於不同子網路的接收器不會被自動找到。

🔌

開啟 Network Control

在接收器上，到「設定」中開啟 Network Control，這樣才能連線並從待機中喚醒接收器。實際的選單路徑會因型號而異。

🔍

檢查 IP 位址

從接收器本身的 Network、Information 畫面讀取位址，並與應用程式中的位址比對。DHCP 位址會變動，若它一直更動，請在路由器中為它保留位址。

⏳

接收器忙碌

如果有太多控制應用程式佔用連線，應用程式會告知網路忙碌，而不是毫無原因地失敗。請關閉其他控制器，或等待幾秒鐘。

仍然中斷

連線正常，之後卻中斷

兩種做法可以解決大部分情況。

拔掉電源再重新通電

長時間運作後，接收器的 Telnet 監聽可能會卡住。將接收器斷電片刻即可清除。

配合 Wi-Fi 頻段

接收器通常使用 2.4 GHz，而手機偏好 5 GHz。在 Wi-Fi 6 Mesh 網路中，請讓手機與接收器使用相同頻段。

完整步驟請見入門指南與說明與疑難排解頁面。若想確認您的型號是否在清單中，請開啟支援的接收器頁面。

常見問題

找不到接收器，解答

AVR Maestro 為什麼找不到我的 Denon 或 Marantz 接收器？
手機與接收器必須位於同一個網路與子網路。Mesh 系統、訪客網路和 IoT VLAN 可能會隔離裝置。請確認接收器已開機且 Network Control 設為 On，然後再試一次，或透過 IP 位址手動新增。
要在哪裡開啟 Network Control？
在接收器上開啟「設定」，進入 General 或 Network，並將 Network Control 設為 On，這樣接收器在待機時也能被連線。實際的選單路徑會因型號而異。
要在哪裡查看接收器的 IP 位址？
請在接收器本身的 Network、Information 畫面查看。DHCP 位址可能會變動，因此若原本正常的接收器無法連線，請重新確認，或在路由器中為它保留該位址。
連線一直中斷，該怎麼辦？
將接收器的電源從插座拔掉再插上，以清除卡住的 Telnet 監聽。在 Wi-Fi 6 Mesh 網路中，請讓手機與接收器使用相同頻段，因為接收器通常使用 2.4 GHz，而手機偏好 5 GHz。
「網路忙碌」訊息是什麼意思？
接收器可以連上，但其網路堆疊已飽和，通常是因為多個控制應用程式同時佔用連線。請關閉其他控制器，或等待幾秒鐘。
我的接收器型號有受到支援嗎？
沒有型號白名單。AVR Maestro 會在連線時偵測接收器支援的功能，因此只要接收器的網頁入口與 Denon 或 Marantz 官方應用程式能連上它，AVR Maestro 也應該可以。

適合日常控制的 Audyssey 應用程式替代方案

正在尋找 Audyssey 應用程式的替代方案嗎？AVR Maestro 可讓您用手機切換 Denon 或 Marantz 接收器的 Audyssey 設定：MultEQ 曲線（Reference、Bypass L+R、Flat 或 Off）、Dynamic EQ、參考電平偏移、Dynamic Volume 與 LFC。它不執行校正：校正仍由麥克風與 Audyssey 應用程式完成，而自訂目標曲線需要付費的 MultEQ Editor 應用程式。

常見問題

用手機控制 Audyssey 常見問答

日常使用有沒有 Audyssey 應用程式的替代方案？
有。在具備 Audyssey 的 Denon 與 Marantz 接收器上，AVR Maestro 可直接在應用程式中讀取並切換 MultEQ（Reference / Bypass L+R / Flat / Off）、Dynamic EQ、參考電平偏移、Dynamic Volume 與 LFC。
AVR Maestro 能校正我的房間嗎？
不能。AVR Maestro 不執行校正，校正由麥克風與 Audyssey 或 Dirac Live 軟體完成；應用程式負責日常控制校正的結果。
我可以在 AVR Maestro 中編輯 Audyssey 目標曲線嗎？
不行。自訂 Audyssey 目標曲線需要付費的 MultEQ Editor 應用程式。不過 AVR Maestro 內建 9 頻段圖形等化器，可以從您量測到的 Audyssey 曲線開始，在 MultEQ 與 Dirac 皆關閉時使用。
也支援 Dirac Live 嗎？
支援。只要接收器上有 Dirac Live 授權，應用程式就會依名稱列出您的濾波器插槽，並一點即可切換使用中的插槽。

情境

整個空間，一鍵搞定。

電影之夜意味著正確的輸入、正確的音效模式、依您喜好的 Dirac 或 Audyssey、稍微提升的中央聲道，以及關閉分區 2。一個情境就能一次完成這一切。AVR Maestro 會一步一步陪您建立，您再也不必記得哪個選單藏了什麼。

  1. 先說明用途。電影與電視、音樂、遊戲、深夜、其他房間或自訂，建立器會指出通常適合的設定。
  2. 選擇要變更什麼。輸入、音量、音效模式、Audyssey 與 Dirac、喇叭電平、分區等等，依照您思考的方式分組。不會幫您預先勾選任何項目，而且如果接收器目前無法套用某項設定，您一勾選就會立刻告訴您原因。
  3. 檢視並儲存。為它命名，選擇圖示與顏色，並檢查它將儲存的每一項設定。儲存不會變更接收器上的任何設定；情境只有在您點選時才會執行。
  4. 隨處都能點選。從情境分頁、主畫面、Android 小工具或捷徑啟動，或是讓 Home Assistant 代為執行，手機放在口袋裡也行。

常見問題

Denon & Marantz 控制問答

有沒有更好的 App 可以控制 Denon 或 Marantz 接收器？
有 - AVR Maestro 是專為 Denon 與 Marantz AV 接收器打造的高品質第三方控制器。它把官方 App 藏得很深的控制項攤開在眼前，加入官方 App 沒有的一鍵情境，並讓您在同一個地方操作 Audyssey、Dirac Live、喇叭預設、多分區與調諧器。
AVR Maestro 能搭配我的 Denon 或 Marantz 接收器使用嗎？
支援具備網路功能的新款 Denon 與 Marantz AV 接收器，包括 Cinema 系列（Cinema 30/40/50/60）、Denon AVR-X 與 AVR-A 系列（X1800H 到 AVR-A1H）、SR/NR 系列等。AVR Maestro 會在連線時讀取每台接收器的功能，只顯示您的機器實際支援的項目。請參閱支援的接收器完整清單。
需要訂閱或雲端帳號嗎？
不需要。AVR Maestro 是一次買斷 - 沒有訂閱、沒有廣告、不需要雲端帳號。它透過區域網路直接與您的接收器溝通，所以您的設定資料絕不會離開家中。
可以控制 Audyssey MultEQ 與 Dirac Live 嗎？
可以。AVR Maestro 能切換 Audyssey MultEQ 曲線、Dynamic EQ、Dynamic Volume 與 LFC；若是 Dirac Live 接收器，還會依名稱列出您的濾波器插槽，並切換目前使用的那一個。請參閱Audyssey & Dirac 控制指南。
支援多分區（分區 2 與分區 3）嗎？
支援 - 分區 2 與分區 3 各自擁有獨立的電源、輸入、音量，以及 Smart Select / Quick Select 叫用，讓您用手機就能打造全屋音響。
AVR Maestro 是 Denon 或 Marantz 做的嗎？
不是。AVR Maestro 是由 MiyaraHub Technologies LLC 開發的獨立應用程式，與 Denon、Marantz、D&M Holdings 或 Sound United 沒有任何隸屬、背書或贊助關係。它透過區域網路，使用接收器本身的網路通訊協定來控制您的接收器。

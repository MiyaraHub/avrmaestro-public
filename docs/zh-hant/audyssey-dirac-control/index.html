Audyssey

完整的 Audyssey MultEQ 控制

接收器 Audyssey 選單中的所有功能，集中在同一個畫面，並即時讀取目前狀態。

  • MultEQ：在 Reference、Bypass L+R、Flat 與 Off 之間切換。
  • Dynamic EQ 與參考電平偏移，適合小音量聆聽。
  • Dynamic Volume 可平衡大聲與小聲的段落。
  • LFC（低頻抑制），並提供抑制量的調整按鈕。
  • 只有在接收器實際提供該功能時，對應的控制項才會顯示。
Dirac Live

以名稱切換 Dirac Live 濾波器

如果您的接收器已有 Dirac Live 授權，AVR Maestro 會讓濾波器成為最優先的操作項目。

  • 依您在 Dirac Live 軟體中取的名稱選擇濾波器插槽，而不是難以辨識的插槽編號。
  • 空白插槽會自動隱藏，只顯示您真正使用的濾波器。
  • 使用中的插槽會即時更新，無論是在接收器上或其他地方變更。
  • 點一下就能切換整個房間的調校，例如電影濾波器、音樂濾波器、深夜濾波器。

常見問題

Audyssey & Dirac Live 常見問題

我可以用手機控制 Audyssey 嗎？
可以。在配備 Audyssey 的接收器上，AVR Maestro 可直接在應用程式中讀取並切換 MultEQ（Reference / Bypass L+R / Flat / Off）、Dynamic EQ、Dynamic Volume、參考電平偏移與 LFC。
AVR Maestro 可以切換 Dirac Live 濾波器嗎？
可以。只要接收器已有 Dirac Live 授權，應用程式就會以名稱列出您的濾波器插槽，點一下即可切換使用中的插槽。空白插槽會自動隱藏，使用中的插槽也會即時更新。
Audyssey 與 Dirac Live 有什麼不同？
兩者都能修正房間的聲學問題。Audyssey MultEQ 內建於大多數 Denon 與 Marantz 接收器，使用手機應用程式即可調校；Dirac Live 則是許多發燒友偏愛的選購付費授權，需透過電腦進行校正。在這些接收器上，兩者依喇叭預設互斥，而 AVR Maestro 會控制您目前使用的預設所採用的那一套。
可以同時使用兩者嗎？
不行。在 Denon 與 Marantz 上，兩者互斥，並與喇叭預設綁定。AVR Maestro 會針對每個預設自動偵測，因此只要切換喇叭預設，就能切換使用中的校正方式。

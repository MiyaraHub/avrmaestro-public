AVR Maestro 媒體資料包

撰寫 AVR Maestro 所需的一切：它是什麼、不會改變的基本資訊、可以使用的應用程式圖示與截圖。

它是什麼

AVR Maestro 是適用於 Denon 和 Marantz AV 接收器的獨立網路遙控應用程式。它透過區域網路與接收器通訊，無需帳號，沒有廣告，中間也沒有雲端服務，並且只顯示您的接收器型號實際具備的功能。

重點資訊

  • 價格：$9.99，一次購買。沒有訂閱，沒有廣告。選用的 Home Automation Pro 附加元件為 $2.99。
  • 平台：iPhone 和 iPad、Mac、Android 以及 Windows。
  • 接收器：Denon 和 Marantz 網路接收器；請參閱接收器清單。
  • 語言：30 種。
  • 開發者：MiyaraHub Technologies LLC。
  • 隱私：匿名當機報告與使用統計會傳送到 Firebase，用於協助修正錯誤。請參閱隱私權政策。

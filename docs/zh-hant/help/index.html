說明 & 疑難排解

解決常見的 Denon 與 Marantz 應用程式問題

針對最常見問題的快速解法。如果仍然卡住，請從設定 › 關於 AVR Maestro › 所有相關記錄傳送記錄給我們，這是取得支援最快的方式，也可以到 Discord 或 Facebook 支援社團聯絡開發者，回覆很快。

連線

完成連線

「測試連線」失敗
請確認手機與接收器位於同一個 Wi-Fi 網路與子網路 - Mesh 系統、訪客網路與 IoT VLAN 都可能隔離裝置。在接收器上，Setup → Network → Network Control 必須為 On。請與接收器自己的 Network → Information 畫面核對 IP，因為 DHCP 位址可能會改變。HTTP 是必要的；Telnet 與 HEOS 有的話更好。如果接收器可以連上，但網路堆疊已滿載 - 太多控制器 App 佔用連線 - App 會以清楚的網路忙碌訊息告知，而不是籠統的失敗；請關閉另一個控制器，或稍等幾秒。完整步驟請見開始使用指南。
連線每隔幾秒就中斷
接收器的 Telnet 連接埠在長時間運作後可能變得卡住，請直接從牆上拔掉電源再重新插上，以清除監聽程式。在 Wi-Fi 6 Mesh 環境中，請強制手機使用與接收器相同的頻段（AVR 通常使用 2.4 GHz，手機則偏好 5 GHz）。
我怎麼知道我的接收器是否受支援？
重點在於您的網路，而不只是機型。如果接收器的網頁入口、HEOS 應用程式與官方 Denon/Marantz 應用程式都能連上它，AVR Maestro 也應該可以。請參閱支援的接收器頁面。
控制 & 顯示

為什麼看起來不太對

音量讀數看起來不對
音量可以用兩種刻度顯示：0-98 刻度，或從 -80 到 +18 dB 的分貝刻度。兩者描述的是同一個音量。在設定 › 管理接收器 › 您的接收器 › 音訊中，在頂端顯示絕對音量決定哪一個是大數字，遙控器音量顯示則決定遙控器分頁使用的刻度。請參閱音量指南。
音效模式或功能標籤呈現灰色或顯示「N/A」
環繞模式與功能受輸入的音訊格式與使用中的音效模式限制，例如 2 聲道訊源不會啟用 Dolby Atmos。這是接收器的行為，不是應用程式的。控制項鎖定指南說明了控制項為何鎖定，以及怎樣才能解鎖。
有些音效或喇叭分頁不見了
分頁會依機型與模式而定。Audyssey、Dirac Live、IMAX、Auro-3D、環繞形狀、距離與分頻只會出現在提供它們的接收器上。請查看設定 › 管理接收器 › 您的接收器 › 裝置資訊，了解應用程式偵測到什麼。您關閉的子分頁可從設定 › 自訂分頁找回，底部分頁則可從設定 › 自訂導覽找回。請參閱導覽指南。
沒有看到廣播分頁
收音機受功能限制：只有具備內建 FM/AM 調諧器的接收器才會出現。如果您的接收器有調諧器但分頁被隱藏，請確認調諧器在接收器上以輸入形式出現，並從設定 › 自訂導覽重新啟用。請參閱收音機指南。
正在播放卡片是空白的
目前的輸入沒有提供中繼資料 - 類比、光纖/同軸，以及大多數 HDMI 直通訊源都不會回報曲目資料。對於 HEOS 訊源，請點選啟動 HEOS開始播放，再回到這裡，中繼資料就會顯示。
主畫面小工具顯示「AVR off」或「Standby」
這是小工具的關閉狀態，不是故障。快速控制與狀態小工具（iOS 與 Android）在接收器待命時會顯示「待命」，無法連到接收器時顯示「AVR 已關閉」，而不是顯示最後的輸入與音量，讓您不會讀到過時的資料。在 Android 上，快速控制的音量與靜音按鈕在此狀態下會隱藏，但電源按鈕仍然有效，點選它即可直接從小工具喚醒接收器（接收器必須啟用網路待命）。請參閱小工具指南。
有些喇叭畫面會在接收器的網頁控制介面中開啟
部分 Denon 與 Marantz 韌體不會把喇叭配置、喇叭距離或喇叭分頻回傳給應用程式。此時頁面會說明，並提供重試，以及一個在接收器自己的網頁控制介面中開啟該畫面的按鈕。如果您從不使用它，可在設定 › 自訂分頁中隱藏該分頁。如果接收器的網頁控制頁面在瀏覽器中開著，請先關閉，因為它可能讓接收器持續忙碌。
場景沒有完全套用
接收器可能拒絕目前輸入、訊號或音效模式不允許的設定。場景指南在「場景未完全套用時」一節說明了該檢查什麼。
支援

取得協助並傳送記錄

所有支援項目都在設定 › 關於 AVR Maestro的支援與社群之下。

  • Discord 社群：加入 MiyaraHub 社群，直接向開發者提問。
  • Facebook 支援社團：AVR Maestro 使用者與問答。
  • 所有相關記錄：所有應用程式與接收器記錄壓縮成一個 zip 檔，可直接傳送給我們。
  1. 連線到出問題的接收器，如果可以，請讓問題發生一次。
  2. 開啟設定 › 關於 AVR Maestro並找到所有相關記錄。
  3. 點選下載儲存 zip 檔，點選分享以任何應用程式傳送，或點選電子郵件將它附加到郵件。處理期間，應用程式會顯示正在收集什麼以及進度。
  4. 請在 Discord 或 Facebook 社團把 zip 檔傳給我們，並簡短說明出了什麼問題。
zip 檔包含應用程式的偵錯記錄，以及應用程式從您的接收器讀到的內容，例如裝置資訊與功能。如果您的裝置沒有電子郵件應用程式，電子郵件會改為開啟分享選單。

還是卡關嗎？我們很快就能幫上忙

請從「設定 › 關於 AVR Maestro」傳送所有相關記錄，並到 Discord 或 Facebook 聯絡開發者，回覆很快。

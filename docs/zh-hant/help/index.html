說明 & 疑難排解

針對最常見問題的快速解法。如果您仍然卡關，App 內的偵錯記錄（設定 → 說明 → 儲存 & 分享）是取得支援最快的方式 - 歡迎到 Discord 或 Facebook 支援社團聯絡開發者，回覆很快。

連線

完成連線

「測試連線」失敗
請確認手機與接收器位於同一個 Wi-Fi 網路與子網路 - Mesh 系統、訪客網路與 IoT VLAN 都可能隔離裝置。在接收器上，Setup → Network → Network Control 必須為 On。請與接收器自己的 Network → Information 畫面核對 IP，因為 DHCP 位址可能會改變。HTTP 是必要的；Telnet 與 HEOS 有的話更好。如果接收器可以連上，但網路堆疊已滿載 - 太多控制器 App 佔用連線 - App 會以清楚的網路忙碌訊息告知，而不是籠統的失敗；請關閉另一個控制器，或稍等幾秒。完整步驟請見開始使用指南。
連線每隔幾秒就中斷
接收器的 Telnet 連接埠在長時間運作後可能變得卡住，請直接從牆上拔掉電源再重新插上，以清除監聽程式。在 Wi-Fi 6 Mesh 環境中，請強制手機使用與接收器相同的頻段（AVR 通常使用 2.4 GHz，手機則偏好 5 GHz）。
我怎麼知道我的接收器是否受支援？
重點在於您的網路，而不只是機型。如果接收器的網頁入口、HEOS 應用程式與官方 Denon/Marantz 應用程式都能連上它，AVR Maestro 也應該可以。請參閱支援的接收器頁面。
控制 & 顯示

為什麼看起來不太對

音量讀數看起來不對
接收器回報的音量可能是絕對值（0-98）或相對值（-80 至 +18 dB）。App 兩種都能處理；如果您最近變更過接收器的音量顯示設定，請重新啟動 App，讓它重新讀取刻度。您可以在設定 → 音訊中切換最上方顯示哪種數值。
音效模式或功能標籤呈現灰色或顯示「N/A」
環繞模式與功能會受到輸入的音訊格式與目前音效模式限制 - 2 聲道訊源無法啟用 Dolby Atmos。這是接收器的行為，不是 App 的問題。點選 N/A 標籤旁的 (?)，即可看到確切的需求條件。
有些音效或喇叭分頁不見了
分頁會依機型與模式而定。Audyssey、Dirac Live、IMAX、Auro-3D、環繞聲場、距離與分頻，只會出現在有提供這些功能的接收器上。請查看設定 → 裝置 → 裝置資訊，了解 App 偵測到什麼，或從設定 → 自訂分頁 / 自訂導覽重新加入被隱藏的分頁。
沒有看到廣播分頁
廣播取決於機型功能：只有內建 FM/AM 調諧器的接收器才會出現。如果您的機型有調諧器但分頁被隱藏，請確認調諧器有出現在接收器的輸入中，並從設定 → 自訂導覽重新啟用。請參閱廣播指南。
正在播放卡片是空白的
目前的輸入沒有提供中繼資料 - 類比、光纖/同軸，以及大多數 HDMI 直通訊源都不會回報曲目資料。對於 HEOS 訊源，請點選啟動 HEOS開始播放，再回到這裡，中繼資料就會顯示。
主畫面小工具顯示「AVR off」或「Standby」
那是小工具的關閉狀態，不是故障。當接收器關機、待機或無法連線時，小工具（iOS 與 Android）會顯示「AVR off」/「Standby」，而不是上一次的輸入與音量，這樣您就不會讀到過時的資料。在 Quick Control 小工具上，該狀態下音量與靜音按鈕會隱藏，但電源按鈕仍然可用 - 直接點選就能從小工具喚醒接收器（接收器必須啟用 Network Standby）。
有些喇叭畫面會在接收器的網頁控制介面中開啟
在某些 2025 年以前的接收器上（X4500H / X6700H / S960H / X4700H 這一類），接收器無法向 App 提供喇叭配置或重低音輸出畫面，所以 AVR Maestro 提供一個一鍵按鈕，直接進入接收器自己的網頁控制介面進行這些編輯。其他功能一切正常；韌體較新的接收器則能在 App 中直接提供所有畫面。

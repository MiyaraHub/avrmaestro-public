不必再翻找選單

搜尋，從任何分頁都能使用

接收器把數百項設定藏在分頁、子分頁與選單之後。輸入您想要的設定的幾個字母，點選結果，AVR Maestro 就會開啟正確的頁面、捲動到該設定並讓它閃爍，讓您看到它在哪裡。

兩種進入方式

  • 主畫面搜尋框。它位於主畫面分頁的接收器卡片下方。點選它並開始輸入。
  • 搜尋按鈕。位於每個分頁的底部分頁列右端。它會在您目前所在頁面上方的面板中開啟同一個搜尋，所以您不必先回到主畫面。
逐步說明

點三下找到設定

  1. 輸入一個詞。名稱的一部分就夠了：dialog 會找到對白增強與對白與 DRC。打錯一個字母也沒關係，所以 volune 仍然能找到音量上限。
  2. 選擇一個結果。會顯示前 8 筆。如果還有更多，顯示全部這一列會列出其餘的結果。以您輸入內容開頭的結果排在最前面，其次是名稱包含它的，再來是相關的關鍵字。
  3. 直達該設定。應用程式會開啟正確的分頁與子分頁、捲動到該設定並讓它閃動片刻。直接在那裡變更即可。
涵蓋範圍

接收器設定與應用程式本身

  • 音效：Dynamic EQ、Dynamic Volume、對白增強、中央電平、音調控制、Audyssey MultEQ、Dirac Live 濾波器等。
  • 系統：HDMI 輸出、觸發器、Eco、自動待機、睡眠計時器、HDMI CEC、畫面與視訊模式、音訊延遲、亮度等。
  • 接收器頁面：管理接收器、音量控制項、螢幕顯示與裝置資訊。
  • 應用程式：語言、導覽與分頁檢視、助理、備份、小工具大小、高對比小工具與關於頁面。這些帶有應用程式標籤，即使沒有選取接收器也能使用。
  • 動作：重新命名接收器、變更它的 IP 位址、尋找我的接收器、刪除它、為應用程式評分、分享記錄、開啟手冊、重播歡迎指南，以及試用或離開示範模式。
誠實的結果

只提供您的接收器具備的項目

搜尋會詢問已連線的接收器它能做什麼，所以您的機種沒有的設定永遠不會列出。切換到另一台接收器，結果也會隨之改變，不必重新輸入。

接收器具備但目前無法變更的設定，會變暗顯示，並在下方附上原因，例如目前的音效模式將它鎖定。接收器尚未回報的設定則顯示為未知。應用程式絕不會把「尚未回應」變成「無法使用」。

每一種語言

用您的方式輸入

搜尋適用於應用程式的所有語言。重音符號、變音符號、土耳其語有點與無點的 i、全形字母、阿拉伯文母音符號與希伯來文標點都不必輸入。設定的英文名稱在任何語言中也能找到它，並列在您自己語言的符合項目之後，因為接收器本身的選單與手冊都使用英文術語。

常見問題

搜尋常見問答

AVR Maestro 的搜尋在哪裡？
在主畫面分頁的接收器卡片下方有一個搜尋框。每個分頁的底部分頁列右端也有一個搜尋按鈕。兩者開啟的是同一個搜尋。
可以搜尋什麼？
音效、喇叭、分區與系統頁面上的接收器設定、應用程式本身的選項（例如語言、備份與小工具大小），以及一些動作（例如重新命名接收器或離開示範模式）。來自應用程式本身的結果會帶有「應用程式」標籤。
為什麼有的結果呈灰色？
灰色結果是接收器具備、但目前無法變更的設定。其下方的文字會說明原因，例如目前的音效模式將它鎖定。標示為「未知」的結果表示接收器尚未回應，應用程式不會猜測。
為什麼我要找的設定沒有列出？
因為您的接收器沒有這項功能。AVR Maestro 只列出已連線的接收器提供的項目，所以較舊的接收器永遠不會顯示它所缺少的設定。如果您有兩台接收器，結果會依目前選取的那一台而定。
搜尋支援我的語言嗎？
支援。搜尋適用於每一種應用程式語言。您不需要輸入重音符號，而且設定的英文名稱在任何語言中都能找到它，並列在您自己語言的符合項目之後。

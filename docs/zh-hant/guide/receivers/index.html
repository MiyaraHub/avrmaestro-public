管理接收器，每台接收器一個頁面

您有多少台 Denon 與 Marantz 接收器就能新增多少台，點兩下就能在它們之間切換，並為每一台設定自己的音訊偏好。每台接收器都有自己的頁面，用於名稱、位址、鎖定與韌體。

在哪裡設定

開啟管理接收器

開啟設定。最上方的卡片是管理接收器：它會顯示您有幾台接收器以及哪一台是使用中。點選它。

您會看到的內容：「點選接收器即可設定。點選圓圈可設為使用中。拖曳可重新排序。」這一行說明，接著是您的接收器，每台都有名稱、IP 位址與型號。使用中的接收器會醒目標示，且圓圈為實心。清單下方是新增接收器按鈕，以及（除非您已在其中）示範模式區段。

  • 點選接收器即可開啟它自己的頁面。
  • 點選一列開頭的圓圈即可將該接收器設為使用中。應用程式會顯示已切換至與接收器名稱。
  • 拖曳一列末端的把手即可變更順序。主畫面頂端的接收器清單會遵循相同的順序。
  • 長按接收器可開啟快速選單，內含重新命名、變更 IP、尋找我的接收器與刪除。
逐步說明

新增接收器

  1. 開啟設定 › 管理接收器，然後點選新增接收器（或右上角的 +）。
  2. 在 iPhone、iPad、Mac、Android 與 Windows 上，畫面會掃描您的網路並列出在您的網路上找到的接收器。點選您的接收器。如果沒有任何回應，請點選重新掃描，或在 IP 位址中輸入接收器的位址並點選測試並儲存。
  3. 應用程式會一次完成測試連線與儲存接收器。您會看到偵測到的型號與功能，新的接收器也會成為使用中的接收器。
接收器的 IP 位址位於它自己的選單：Setup › General › Network › Information。手機或電腦必須與接收器位於同一個網路。網路檢查清單請見入門。
點兩下

從主畫面切換接收器

  1. 在主畫面分頁，點選畫面頂端 AVR Maestro 旁顯示的接收器名稱。
  2. 會開啟您的接收器清單，使用中的接收器旁有勾號。點選另一台接收器即可切換，或點選清單底部的管理接收器開啟完整頁面。

每台接收器的資料都保存在您的裝置上，所以切換後會立即載入該接收器的設定。

設定 › 管理接收器 › 您的接收器

接收器頁面

點選接收器即可開啟它的頁面。頂端的卡片會顯示它的連線狀態與詳細資料。如果它不是使用中的接收器，卡片下方會有設為使用中按鈕，因為音量上限、顯示與鎖定只能在使用中的接收器上變更。如果它是使用中但無法連線，頁面會顯示「應用程式目前未連接到接收器。」

音訊

您對此接收器的個人偏好。每台接收器各自保存自己的數值。音量指南 →

  • 音量間距：按一次音量移動多少，可選 0.5、1、1.5 或 2 dB。應用程式中的每個音量按鈕都使用它。
  • 在頂端顯示絕對音量：切換音量讀數中哪個數字比較大。關閉（預設）時以大字顯示 dB、小字顯示音量刻度；開啟時以大字顯示音量刻度、小字顯示 dB。
  • 遙控器音量顯示：遙控器分頁顯示 dB 刻度（絕對值（dB），例如 -40.5 dB），還是 0-98 刻度（相對值，例如 39.5）。
  • 漸進式音量預設：開啟時（預設），點選音量預設會以小幅度逐步調整音量；關閉時，則直接跳到儲存的音量。
  • 裝置音量按鈕（手機與平板）：應用程式開啟時，裝置本身的音量按鈕會變更接收器的音量。預設為開啟；關閉後可將按鈕還給裝置。
  • 音量控制項：音量上限、開機音量與靜音深度，會寫入接收器本身。在應用程式已連線到此接收器時顯示。音量控制項指南 →

螢幕與鎖定

在使用中的接收器已連線時顯示。

  • 螢幕顯示：音量讀數、資訊橫幅、正在播放與 21:9。螢幕顯示指南 →
  • 設定鎖定：鎖住接收器本身的設定選單。鎖定期間，音訊、視訊、喇叭及其他設定都無法在任何地方變更，無論是接收器的選單、本應用程式或其網頁入口。音量、輸入與亮度等日常控制仍可使用。開啟時會先詢問（要鎖定接收器選單嗎？，然後鎖定）；關閉開關即可解鎖。
  • 遙控器鎖定：讓接收器在您解鎖之前忽略紅外線遙控器的按鍵。應用程式與前面板仍可使用。
設定鎖定與遙控器鎖定只有在接收器回報它們的狀態時才會出現。如果您的接收器沒有回報鎖定，就不會顯示開關，而不是憑空猜測。應用程式其他地方因設定鎖定而呈灰色的控制項，說明請見控制項為何鎖定。

關於此接收器

  • 裝置資訊：接收器的詳細狀態。
  • 韌體：已安裝的韌體版本。點選檢查可詢問接收器是否有可用的更新。下方的文字會說明您使用的是最新韌體、有可用更新、更新正在進行中，或無法讀取狀態。更新要從接收器本身的設定選單安裝，而不是從應用程式；更新期間請勿關閉接收器電源。

管理

  • 重新命名：在裝置名稱中輸入新名稱並點選儲存。名稱只儲存在應用程式中。
  • 變更 IP：輸入新的 IP 位址或主機名稱並點選儲存，例如在路由器分配了新位址之後。該接收器所有已儲存的設定都會保留，只有位址改變。已被您的另一台接收器使用的位址會被拒絕。
  • 尋找我的接收器：在網路上搜尋此接收器的新位址。如果它在其他位置找到您的接收器，請點選使用此位址。它會告訴您已儲存的位址是否已經正確、沒有任何回應，或是有多台接收器可能是您的，這時它不會變更任何東西，請改用「變更 IP」。
  • 刪除：詢問要刪除接收器嗎？然後從應用程式移除該接收器及其所有已儲存的設定。刪除使用中的接收器會讓應用程式切換到另一台。
不需要接收器

示範模式，進入與離開

示範模式會在應用程式內執行一台模擬的 Marantz CINEMA 30。每個畫面的運作都和真實硬體相同，而且不會透過您的網路傳送任何內容。

  1. 開始：從設定 › 管理接收器 › 試用示範模式、從新增接收器畫面的探索示範模式，或從歡迎指南中的改為試用示範。示範接收器會成為使用中，應用程式會開啟主畫面。
  2. 預覽進階版。示範執行期間，設定會顯示示範模式區段。其中的預覽進階版功能開關只會在這次示範期間解鎖居家自動化與觸發器。不會購買任何項目。
  3. 離開：使用設定 › 離開示範模式。示範接收器會被移除，應用程式回到您自己的接收器。
常見問題

接收器常見問答

如何切換到另一台接收器？
在主畫面分頁，點選頂端 AVR Maestro 旁的接收器名稱，並從清單中選擇另一台接收器。您也可以開啟「設定 › 管理接收器」，並點選接收器那一列開頭的圓圈。應用程式會以「已切換至」加上接收器名稱來確認。
我的接收器取得了新的 IP 位址，該怎麼辦？
通常不需要做任何事：當路由器變更接收器的位址時，應用程式會重新找到它，並只告訴您一次它已跟隨更新。如果找不到，請開啟「設定 › 管理接收器」，點選該接收器，並使用「尋找我的接收器」搜尋網路，或使用「變更 IP」自行輸入新位址。該接收器所有已儲存的設定都會保留，只有位址改變。
為什麼我看不到「螢幕與鎖定」或「關於此接收器」？
這些區段會即時讀取並寫入接收器，因此只有在應用程式已連線到使用中的接收器時才會出現。請用「設為使用中」將該接收器設為使用中，並等待它連線。
設定鎖定和遙控器鎖定有什麼差別？
設定鎖定會鎖住接收器本身的設定選單，因此在您解鎖之前，包含本應用程式在內的任何人都無法變更其設定與校正設定。音量與輸入仍可使用。遙控器鎖定會讓接收器忽略它的紅外線遙控器；應用程式與前面板仍可使用。每個開關只有在您的接收器回報該鎖定時才會出現。
刪除接收器時會發生什麼事？
應用程式會移除該接收器及其所有已儲存的設定。如果它是使用中的接收器，應用程式會切換到另一台。接收器本身不會有任何變更，而且您隨時可以再次新增它。
沒有接收器也能試用應用程式嗎？
可以。在「設定 › 管理接收器」中點選「試用示範模式」，或在新增接收器畫面點選「探索示範模式」。示範模式會在應用程式內執行一台模擬的 Marantz CINEMA 30，不會透過您的網路傳送任何內容。可從「設定 › 離開示範模式」離開。

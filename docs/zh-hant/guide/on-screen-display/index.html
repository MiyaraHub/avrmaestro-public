接收器在電視上顯示的內容

螢幕顯示，坐著就能設定

看電影時突然彈出的音量數字、切換訊源時的橫幅、播放音樂時一直停留的正在播放畫面，這一切都藏在接收器的設定選單裡，也就是說您得起身，把選單叫到您正在看的螢幕上。AVR Maestro 則把這些搬到您的手機上。

您可以變更的項目

  • 音量：底端、頂端或關閉。調整音量時，音量顯示出現在哪裡，或是否顯示。看電影時大家最常去找的就是「關閉」。
  • 資訊：切換訊源或音效模式時，接收器顯示的狀態橫幅。
  • 正在播放：播放網路訊源時，正在播放畫面是否持續顯示，或是在片刻後自動消失。
  • 21:9 模式：重新調整接收器自身選單的位置，以配合 21:9 等高螢幕，避免投影機把選單切掉。
  • 螢幕保護程式：畫面靜止一段時間後移動螢幕上的影像，保護容易燒屏的面板。
只顯示您的接收器擁有的項目

您的機身決定您會看到哪些項目

並非每台接收器都有全部五項。AVR Maestro 不會顯示一個無法使用的控制項，而是向機身詢問它提供哪些螢幕顯示選項，只呈現這些項目，所以沒有螢幕保護程式的舊款接收器，就不會出現那張卡片。

如果某項設定存在，但接收器這次沒有回應，應用程式會如實告訴您，並提供重試。它絕不會把「我們讀取不到」說成「您的接收器沒有這項功能」，這是兩種不同的答案，而且只有一種是真的。

常見問題

螢幕顯示，問與答

可以不讓音量數字出現在電視上嗎？
可以。在 AVR Maestro 中開啟「設定」，再進入「螢幕顯示」，將「音量」設為關閉即可。您也可以不用離開座位，就把它在螢幕底端與頂端之間移動。
21:9 模式有什麼用途？
它會重新調整接收器螢幕選單的位置，以配合 21:9 等高螢幕，避免投影機把選單的上下邊緣切掉。只有在您有這類設備時才需要開啟。
為什麼我看到的選項比截圖少？
因為您的接收器回報的項目比較少。AVR Maestro 會向機身詢問有哪些螢幕顯示選項，只顯示這些項目。沒有螢幕保護程式的舊款接收器，就不會出現那張卡片，也不會讓您看到一個無法使用的控制項。

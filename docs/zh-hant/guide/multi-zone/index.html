多分區

多分區：掌控整個家

在多分區的 Denon 與 Marantz 接收器上，獨立控制分區 2 與分區 3 的電源、輸入與音量 - 場景也能擷取並還原分區狀態。廚房放音樂，劇院看電影，全部由一個應用程式搞定。

分區如何運作

每個分區完全獨立

每個分區都有自己的電源、音量、靜音、輸入與快速音量預設，與主分區完全分開。

🔌

獨立電源

開啟或關閉分區 2 或分區 3，完全不影響主分區。

🎵

專屬訊源與音量

每個分區可使用不同的輸入與音量，並有快速音量預設按鈕 - 預設值預設會平滑漸變（設定、音訊：漸進 / Direct）。

⚡

分區 Smart Select / Quick Select

該分區專屬的 Smart Select 或 Quick Select 插槽就在卡片上 - 點選插槽即可叫用，長按則可將該分區目前的狀態儲存進去。

✍️

重新命名任何分區

在主畫面長按分區名稱 - 主分區也包括在內。名稱會儲存到接收器本身，因此所有應用程式都一致。

🔄

即時同步

從接收器面板或遙控器變更分區後，應用程式會在一秒內更新。

🎧

各分區的正在播放

分區開啟時，其卡片會顯示該分區的即時 HEOS 串流，並附播放控制。

🎭

可由場景擷取

場景可以連同其他所有設定一起擷取並還原分區 2/3 的狀態。

📱

在主畫面上

精簡的分區小工具可在主畫面上一眼看到狀態並快速控制。

開啟分區，並指定它的訊源

  • 1. 開啟分區分頁。接收器宣告的每個分區都會有一張卡片。只有一個分區的接收器不會有這個分頁。
  • 2. 用卡片上的電源控制開啟該分區。主分區完全不受影響。
  • 3. 選擇它的訊源。清單就是您接收器自己的，並套用您重新命名過的名稱，分區可以使用與主房間完全不同的輸入。
  • 4. 設定它的音量。分區有自己的音量與自己的靜音，快速音量按鈕會叫用您在該分區設定的音量。除非在設定、音訊中切換為 Direct，否則預設值會平滑漸變。
  • 5. 選填：儲存起來。長按該分區自己的 Smart Select 或 Quick Select 插槽，即可儲存該分區目前的所有狀態，之後點選就能叫回。

在主畫面長按分區名稱即可重新命名。名稱會寫入接收器，所以前面板與其他所有應用程式都會與此應用程式一致。

值得了解

為什麼關閉主分區不會讓其他房間跟著停止

Denon 與 Marantz 接收器有兩種不同的電源指令，如果家中其他地方正在播放音樂，這個差別就很重要。

全系統待機指令會關閉整個機身，接收器也會連帶關閉其他分區 - 在 Cinema 30 上實測，待機指令送達後一毫秒，機身就回報分區 2 已關閉。因此 AVR Maestro 的主電源控制刻意改送主分區指令。從應用程式關掉劇院，廚房依然繼續播放。

反過來也成立：從完全關機的接收器開啟主分區時，會先喚醒機身，所以使用應用程式前不需要另外開啟接收器電源。

如果主分區變更時某個分區自己關閉了，那是接收器本身的設定造成的，與應用程式無關。部分機型在分區選單中有電源連動選項。
常見問題

多分區常見問題

我可以用手機控制分區 2 與分區 3 嗎？
可以 - 在多分區接收器上，每個分區都有自己的電源、音量、靜音、輸入與快速音量預設，與主分區完全分開，並即時同步。
我可以在分區中使用 Smart Select 或 Quick Select 嗎？
可以 - 每張分區卡片都帶有該分區專屬的插槽，名稱與您的接收器一致：Marantz 是 Smart Select，Denon 是 Quick Select。點選插槽即可叫用；長按則可將該分區目前的狀態直接從卡片儲存進去。
我可以重新命名分區嗎？
可以 - 在主畫面長按分區名稱即可重新命名任何分區，包括主分區。名稱會寫入接收器本身，因此原廠應用程式與其他所有用戶端也會顯示，較舊的機身也一樣。
每個分區都會顯示正在播放的內容嗎？
會 - 當分區開啟時，其卡片會顯示該分區即時的 HEOS 正在播放串流，並附播放控制。
場景可以設定我的分區嗎？
可以 - 場景可以連同其餘設定一起擷取並還原分區 2/3 的電源、輸入與音量。

FM/AM 調諧器

真正的 FM/AM 收音機，還有可命名的預設

在內建調諧器的 Denon 與 Marantz 接收器上，AVR Maestro 為您提供完整的 FM/AM 收音機介面。電台卡片會顯示目前的頻段、頻率與使用中的預設，並即時與接收器同步。

運作方式

調諧、掃描並儲存

  • 頻段：FM / AM。調諧模式：自動（掃描到下一個訊號強的電台）或手動（依頻段間距逐步調整）。
  • 調諧：兩個調頻按鈕可逐步調整頻率；輸入頻率會開啟數字鍵盤，直接跳到某個電台（需要手動模式）。
  • 預設：預設欄位的格狀選單，加上上下調整按鈕。長按欄位即可儲存目前電台、新增 / 重新命名標籤（例如「Jazz 88」、「NPR」），或清除標籤。
如果「廣播」分頁被隱藏，請從設定 → 自訂導覽重新加入。只有在接收器提供調諧器時，這個分頁才會出現。
常見問題

調諧器常見問題

我可以用應用程式控制 FM/AM 收音機嗎？
可以，適用於內建調諧器的接收器。支援即時顯示頻段、頻率與預設、FM/AM 切換、自動或手動調諧、輸入頻率的數字鍵盤，以及預設格狀選單。
我可以幫預設命名嗎？
可以。長按一個欄位即可儲存目前的電台、新增或重新命名標籤（例如「Jazz 88」、「NPR」），也可以清除標籤。
為什麼我看不到「廣播」分頁？
只有內建調諧器的接收器才會出現這個分頁。如果您的接收器有調諧器，請確認調諧器有顯示為輸入，然後到「設定」的「自訂導覽」重新啟用這個分頁。

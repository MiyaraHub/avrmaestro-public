手動等化

真正的圖形等化器編輯器，而不只是開關

當您不使用 Audyssey 或 Dirac 來操作接收器時，手動圖形等化器就由您來調整，而 AVR Maestro 把完整功能都放在您的手機上：每支喇叭都有 63Hz 到 16kHz、-20 到 +6 dB 的 9 頻段曲線，直接在圖表上拖曳，即時套用。

逐個頻段調整音色

開啟音效分頁並選擇圖形等化器頁面。只有在您的接收器回報具備圖形等化器時，此頁面才會出現。

  • 開關：位於圖形等化器頁面的標題列，在「重設」與「複製」按鈕的右側。關閉時，頁面會顯示請先在上方開啟圖形等化器，才能編輯每支喇叭的 9 頻段曲線。它會取代自動房間校正。
  • 九個頻段，63Hz 至 16kHz：與您的接收器提供的頻段中心頻率相同，每個頻段可在 -20 至 +6 dB 之間以 0.5 dB 為單位調整。
  • 在圖表上拖曳：抓住一個頻段上下拉動，曲線會隨之重繪，讓您看見正在建立的形狀。
  • 選擇您的目標：用一條曲線調整全部喇叭、一起調整左/右一對，或單獨調整個別喇叭，與接收器本身的圖形等化器頁面一致。
  • 複製您的 Audyssey 曲線：「複製」按鈕會帶入您量測到的 Audyssey 結果作為起點（已將量測曲線複製到圖形等化器。），讓您微調已驗證的校正，而不是從平直開始。
  • 重設：讓整個圖形等化器回到平直（0 dB）。
  • 套用：您對頻段的變更會等到您點選按鈕才生效，按鈕會顯示變更數量（例如套用 3 個頻段），然後即時送到接收器。曲線儲存在目前的喇叭預設中。
一次只能使用一套系統

房間校正執行時會自動鎖定

您的接收器要嘛執行房間校正（Audyssey MultEQ 或 Dirac Live），要嘛執行手動圖形等化器，不會同時進行。因此只要 MultEQ 或 Dirac 啟用，AVR Maestro 就會鎖定圖形等化器並明確告訴您原因，而不是讓您建立一條接收器會忽略的曲線。關閉房間校正，編輯器會立刻解鎖。

  • Audyssey：在 Audyssey 頁面將 MultEQ 設為 Off。
  • Dirac Live：切換到沒有 Dirac 的喇叭預設。
  • Direct 與 Pure Direct：這些模式會略過所有 DSP，因此圖形等化器在此為關閉。請切換到其他音效模式來編輯頻段。
舊版韌體也一併涵蓋：逐喇叭的頻段編輯在舊機身與新機身上都能運作，而且等化器會維持設定，在 AVC-X6700H 這類接收器上不會再自行關閉。
常見問題

圖形等化器常見問題

我什麼時候可以使用圖形等化器？
當 Audyssey MultEQ 與 Dirac Live 皆關閉，且音效模式不是 Direct 或 Pure Direct 時。接收器執行房間校正或手動圖形等化器，兩者不會同時作用，因此房間校正關閉時編輯器可用，開啟時則鎖定（並附上清楚的說明）。
圖形等化器的開關在哪裡？
就在圖形等化器頁面本身，位於標題列中「重設」與「複製」按鈕的右側。開啟「音效」分頁並選擇圖形等化器頁面。
頻段與增益範圍是多少？
從 63Hz 到 16kHz 共九個頻段，每個頻段可在 -20 至 +6 dB 之間以 0.5 dB 為單位調整，這是接收器本身提供的範圍。
我可以複製我的 Audyssey 校正作為起點嗎？
可以。「複製」會將您量測到的 Audyssey 曲線帶入圖形等化器，讓您微調已經驗證過的結果。「重設」會讓整個圖形等化器回到平直。詳情請見 Audyssey 與 Dirac 指南。
舊款接收器也能使用嗎？
可以。逐喇叭的頻段編輯在舊版韌體與新款機身上都能運作，而且在 AVC-X6700H 這類接收器上，切換開關也不會再自動關閉。

遙控器

真正的遙控器，加上即時畫面

完整的方向鍵與播放控制，搭配顯示輸入、音效模式與實際使用中聲道的即時標題，讓您隨時知道 Denon 或 Marantz 正在做什麼。滑動或點選頂端的頁面分頁，可在最多五個頁面之間切換。

最多五個頁面

一應俱全，不必再找實體遙控器

開啟遙控器分頁。您看到的頁面取決於您的接收器：接收器沒有的功能，其頁面不會出現。

  • 主遙控器：指令列（電源 / 資訊 / 設定 / 選項 / 返回）、方向鍵、播放控制與音量列，並以即時標頭顯示輸入、音效模式與使用中的 IN/OUT 聲道。
  • 輸入：完整的訊源網格。點選圖磚即可切換輸入。按住圖磚可為它設定自訂圖示。網格使用您自己的名稱與順序（請參閱下方的重新命名並重新排序輸入）。
  • Smart Select / Quick Select：AVR Maestro 會用您接收器的名稱來稱呼它們：Marantz 上是 Smart Select，Denon 上是 Quick Select。點一下欄位即可叫用接收器存在其中的內容；長按則可重新命名或儲存目前狀態（精靈會讓您精確選擇要擷取哪些設定）。欄位的名稱同樣會儲存在接收器上，因此會跟著您出現在其他所有應用程式中。
  • 系統：整台接收器的直接控制（列於下方）。
  • 觸發輸出：僅限具備 12V 觸發輸出的接收器。選擇哪些分區、輸入與 HDMI 輸出會開啟各個觸發器（見下方）。
從不使用某個頁面？請在設定 › 自訂分頁中隱藏它。此設定適用於所有接收器。
逐步說明

重新命名並重新排序輸入

把輸入叫成它們實際的樣子，例如「Nvidia Shield」、「Xbox」、「PS5」，並把最常用的放在最前面。

  1. 在主畫面分頁，點選輸入訊源卡片以開啟訊源清單。
  2. 按住任一圖磚。清單會切換為編輯狀態：點選圖磚可重新命名，或拖曳以重新排序。完成後點選「完成」。
  3. 要重新命名，請點選圖磚、輸入新名稱，然後點選儲存。
  4. 要重新排序，請將圖磚拖曳到新位置。
  5. 點選完成。
新名稱會寫入接收器本身，所以在原廠應用程式與其他所有用戶端（包含較舊的機種）中也會顯示，應用程式會以訊源已重新命名確認。如果接收器不接受，您會看到訊源僅在此裝置上重新命名，名稱只會保留在 AVR Maestro 中。順序依接收器分別儲存，遙控器的輸入頁面也會使用它。
遙控器 › 系統

整台接收器的直接控制

系統頁面只顯示您的接收器回報其具備的項目，因此在某些機型上清單較短。您可能看到的內容，由上而下：

  • HDMI 輸出與照明或亮度（前面板顯示亮度）。
  • 觸發器：手動開啟或關閉各個 12V 觸發器。若要讓觸發器跟隨分區、輸入或 HDMI 輸出，請改用觸發輸出頁面。
  • ECO 模式、自動待機與睡眠計時器。
  • HDMI CEC 與 HDMI 音訊解碼（AMP 或 TV）。
  • 喇叭預設：在接收器的喇叭預設之間切換。
  • 藍牙發射器：適用於能將音訊傳送到藍牙耳機或喇叭的機型。開啟或關閉發射器，然後選擇 BT+喇叭（藍牙與房間喇叭同時輸出）或僅 BT。
  • 畫面模式與視訊處理模式（Auto、Game、Movie、Bypass）。Game、Movie 與 Bypass 只在 HDMI 訊源播放視訊時才適用；否則接收器維持在 Auto。
  • 全分區立體聲、自動音畫同步（Marantz）、音訊延遲與 LFE 電平。
  • 輸入模式（Auto、HDMI、Digital、Analog）。
  • 數位輸入格式：Auto 由接收器自行決定，PCM 強制使用 PCM 解碼，DTS 強制使用 DTS 解碼。當訊源送出接收器誤判的格式而導致無聲時使用。
某些接收器在特定輸入或環繞模式啟用時，會鎖定數位輸入格式或 LFE 電平。此時應用程式會以鎖定橫幅顯示目前的數值，而不是按鈕。變更輸入或模式後，請點選標題旁的重新整理圖示再次檢查。請參閱控制項為何鎖定。
遙控器 › 觸發輸出

自動為您的布幕、重低音或擴大機供電

12V 觸發輸出會通知其他設備開機。在具備觸發輸出的接收器上，觸發輸出頁面可讓您選擇由什麼來開啟各個觸發器。只要任何一個已啟用的項目處於作用中，觸發器就會觸發。清單即時從您的接收器讀取。

  1. 開啟遙控器分頁並滑動到觸發輸出。
  2. 如果您的接收器有多個觸發器，請在頂端選擇觸發輸出 1、觸發輸出 2，依此類推。
  3. 為應該觸發它的項目開啟開關，這些項目分組在分區、訊源與 HDMI 輸出之下。
每個開關都會立即傳送到接收器。如果接收器不接受變更，以觸發輸出：開頭的訊息會告訴您，且開關會顯示接收器的實際狀態。如果在具備觸發器的接收器上看到觸發輸出無法使用，可能是接收器忙碌：如果它的網頁控制頁面在瀏覽器中開著，請關閉，然後點選重試。
音量，照您的方式調整

以 dB 或相對刻度讀取音量

主遙控器的音量列會即時顯示主音量，標題晶片也同步顯示。比較喜歡接收器本身的數字而不是分貝嗎？可以在 dB 刻度（例如 -40.5 dB，預設）與 0-98 刻度（例如 39.5）之間切換讀數。標題晶片與音量列都會遵循您的選擇。

  1. 開啟設定 › 管理接收器並點選您的接收器。
  2. 在音訊下，開啟遙控器音量顯示並選擇刻度。
此選擇依接收器分別儲存，所以兩台接收器可以顯示不同的刻度。
長按

音量按鈕會漸進調整，就像遙控器上的按鈕一樣

點一下加號或減號，音量就移動一格。按住不放，音量就會持續平順地移動，直到您放開為止，就像實體遙控器的行為，也符合您手指的預期。放開後，接收器會精準停在您停下的那一格，絕不會多跑。

在底層，應用程式會進行合併處理：它會累積您要前往的目標，並控制實際送出指令的節奏，因此長按時不會讓反應較慢的接收器被指令塞爆。小幅調整同樣平順，幾分貝的變化是漸進完成，而不是一下跳過去。

訊號，即時掌握

進來的是什麼，出去的又是什麼

遙控器標頭帶有一條精簡的聲道列：一列顯示輸入的訊號，另一列顯示接收器正在驅動的聲道，並列出接收器命名的每一支喇叭。透過網路播放的立體聲曲目，會顯示輸入兩個聲道，輸出則是完整的升混。

自訂輸入圖示

為每個輸入設定專屬圖示

您的 Shield、HTPC 與藍光播放機，都能用您手邊任何圖片，在輸入圖磚上換上自己的真面目。它現在有專屬的指南了。

桌面版

Mac & Windows 上的鍵盤快速鍵

在 Mac App Store 與 Microsoft Store 版本中，您可以直接用鍵盤控制播放與音量，不必再伸手去拿滑鼠。macOS 請搭配 Cmd，Windows 請搭配 Ctrl，鍵盤上專用的媒體鍵也同樣有效。在文字欄位中輸入時不會觸發任何快速鍵，所以重新命名輸入或輸入 IP 時絕不會被打斷。

Cmd + Space / Ctrl + Space播放 / 暫停
Cmd + . / Ctrl + .（句號）停止
Cmd + Right / Ctrl + Right下一首
Cmd + Left / Ctrl + Left上一首
Cmd + Up / Ctrl + Up調高音量
Cmd + Down / Ctrl + Down調低音量
Cmd + M / Ctrl + M切換靜音
媒體鍵：播放、暫停、播放 / 暫停、停止對應的播放控制動作
媒體鍵：下一首、上一首跳到下一首 / 上一首
媒體鍵：音量加、音量減、靜音調高音量、調低音量、靜音
常見問題

遙控器常見問題

我可以重新命名並重新排序輸入嗎？
可以。在主畫面分頁點選輸入訊源卡片，然後按住任一圖磚開始編輯。點選圖磚可重新命名，拖曳可重新排序，完成後點選完成。新名稱會寫入接收器本身，所以在原廠應用程式與其他所有用戶端中也會顯示；如果接收器不接受，應用程式會顯示訊源僅在此裝置上重新命名。順序依接收器分別儲存，遙控器的輸入頁面也會跟著使用。
我可以為輸入設定自訂圖示嗎？
可以。長按輸入圖磚，選擇任何圖片（PNG、JPG、ICO、WebP 等），在證件照風格的裁切工具中調整位置後儲存。完整步驟請參閱「自訂輸入圖示」指南。
虛擬遙控器可以控制什麼？
主遙控器頁面有指令列（電源/資訊/設定/選項/返回）、方向鍵、播放控制與音量，以及顯示輸入、音效模式與使用中聲道的即時標題。系統頁面則加入直接控制（HDMI 輸出、亮度、觸發器、ECO、睡眠、CEC、藍牙發射器、數位輸入格式等），當您的接收器具備 12V 觸發輸出時，還會出現獨立的觸發輸出頁面。接收器不支援的項目一律隱藏。
Smart Select / Quick Select 是什麼？
Marantz 的 Smart Select 與 Denon 的 Quick Select，都是接收器本身的記憶欄位。AVR Maestro 會用您接收器的名稱來稱呼它們：Marantz 上是 Smart Select，Denon 上是 Quick Select。點一下即可叫用；長按則可重新命名，或透過擷取精靈儲存目前的狀態。
什麼是觸發輸出頁面？
當您的接收器具備 12V 觸發輸出時，它會出現在遙控器中。對每個觸發器，您可選擇哪些分區、輸入訊源與 HDMI 輸出會將它開啟；只要任何一個已啟用的項目處於作用中，觸發器就會觸發，因此投影布幕、重低音或擴大機可以自動開機。清單即時從您的接收器讀取。如果接收器不接受變更，應用程式會告訴您，並顯示接收器的實際狀態。
AVR Maestro 在桌面版有鍵盤快速鍵嗎？
有。在 Mac 與 Windows 上，您可以用鍵盤控制播放與音量。macOS 請搭配 Cmd，Windows 請搭配 Ctrl：空白鍵為播放 / 暫停，.（句號）為停止，左 / 右為上一首 / 下一首，上 / 下為音量，M 為靜音。鍵盤上專用的媒體鍵（播放、暫停、下一首、上一首、停止、音量、靜音）也同樣有效。在文字欄位中輸入時，快速鍵會暫停作用。

淺顯易懂的定義

AVR Maestro 詞彙表

簡短而淺顯地說明 AVR Maestro 與本指南中使用的術語。其中哪些項目您的接收器具備，取決於它的型號。

應用程式

  • 場景。已儲存的一組接收器設定，例如輸入、音效模式與音量，一點即可套用。請參閱場景。
  • Quick Select / Smart Select。接收器本身用於輸入、音量與音效模式的記憶插槽。Denon 稱為 Quick Select，Marantz 稱為 Smart Select。請參閱遙控器。
  • 音量預設。應用程式中 8 個已儲存音量之一。點一下即可跳到該音量。請參閱音量。
  • 示範模式。在應用程式內執行一台模擬的 Marantz CINEMA 30，讓您不需要接收器就能試用每個畫面。不會透過您的網路傳送任何內容。
  • 居家自動化進階版。一項附加元件，可將您的接收器連接到 Home Assistant、Hubitat 與 Webhook。請參閱居家自動化。
  • 助理。用平常說話的方式要求變更接收器設定。它在您的裝置上執行，且只會出現在能執行它的裝置上。請參閱助理。
  • Webhook。一個網址，供其他系統呼叫以讓應用程式執行某項動作，或在發生某些事件時由應用程式呼叫。
  • Home Assistant / HACS / Hubitat。居家自動化系統。HACS 是 Home Assistant Community Store，用來安裝附加元件。請參閱Home Assistant 儀表板。
  • 鎖定的控制項。接收器目前不允許變更的設定，通常是因為音效模式或訊號。請參閱鎖定的控制項。

網路與連線

  • IP 位址。接收器在您家用網路上的位址，例如 192.168.1.20。應用程式用它來連線。
  • MAC 位址。接收器網路埠的固定硬體識別碼。顯示在裝置資訊中。
  • HTTP 與 Telnet。應用程式透過網路與接收器通訊的兩種方式。HTTP 傳送指令，Telnet 則帶回即時更新。
  • HEOS。內建於較新 Denon 與 Marantz 接收器的串流與多房間系統。請參閱正在播放。
  • 網路待機。接收器的一項設定，讓網路在待機時保持開啟，應用程式才能將它開機。

校正與房間校正

  • Audyssey MultEQ。Denon 與 Marantz 的房間校正。它用麥克風量測您的房間並修正聲音。MultEQ XT32 是最精細的版本。
  • Dynamic EQ。Audyssey 功能，在小音量時維持低音與環繞聲的平衡。開啟時，音調控制會被鎖定。
  • 參考電平偏移。告訴 Dynamic EQ 您的內容混音時有多大聲，以調整它的修正量。
  • Dynamic Volume。Audyssey 功能，平衡突然變大或變小的段落。
  • LFC（Low Frequency Containment）。Audyssey 功能，減少傳到鄰近房間的低音。抑制量決定抑制多少。
  • Dirac Live。Dirac 的房間校正，部分接收器提供。啟用時會取代 Audyssey。其結果儲存在插槽中。
  • 喇叭預設。預設 1 或預設 2：兩組完整的喇叭設定，各自有獨立的配置、距離、電平、分頻與校正。

音效模式與處理

  • Dolby Atmos / DTS:X。包含增高聲道的環繞聲格式。
  • Dolby Surround。Dolby 的升混器，將立體聲或環繞聲擴展到您所有的喇叭。中央擴展僅在此模式下有效。
  • Neural:X。DTS 升混器。可搭配 DTS:X 音效模式使用。
  • Auro-3D / Auro-Matic。Auro Technologies 的沉浸式格式與升混器，限支援的接收器。
  • IMAX Enhanced。IMAX Enhanced 內容的設定，限支援的接收器。
  • Pure Direct / Direct。略過大部分處理、讓訊號路徑最純淨的音效模式。
  • DRC（動態範圍壓縮）。縮小大聲與小聲之間的差距。適用於 Dolby 訊號。
  • 響度管理。讓 Dolby 內容保持一致的音量。
  • 對白增強。讓人聲更容易聽清楚。
  • 影院等化。柔化電影音軌中刺耳的高音。
  • M-DAX。Marantz 功能，為壓縮過的音樂找回細節。可選 Off、Low、Med 或 High。
  • 修復器。Denon 功能，為壓縮過的音樂找回細節。
  • 喇叭虛擬化。模擬您沒有的喇叭。
  • 房間大小、全景聲、縱深感、中央寬度。調整聲場擴展方式的設定，位於音效 › 聲場之下。
  • 音調控制。低音與高音調整。請參閱音效。
  • 圖形等化器。每支喇叭的分頻段等化器。請參閱圖形等化器。

喇叭與低音

  • 擴大機指定。接收器擴大機聲道的用途，例如用於增高喇叭或第二個分區。
  • 分頻。低於此頻率時，喇叭的低音會改送到重低音。
  • HPF / LPF。高通濾波器與低通濾波器。它們在喇叭與重低音之間劃分聲音。
  • 重低音管理。接收器如何在喇叭與重低音之間分配低音。
  • LFE。Low Frequency Effects：電影音軌中獨立的低音聲道，也就是 5.1 中的 .1。
  • 重低音模式。LFE 只將低音聲道送到重低音。LFE + 主聲道則同時送出主喇叭的低音。
  • 聲道電平。每支喇叭相對於其他喇叭的音量。
  • 距離。每支喇叭與您座位的距離。接收器用它來調整聲音的時間。
  • 中央電平調整。快速加強或減弱中央喇叭。
  • 喇叭網格。應用程式即時呈現您的喇叭及哪些正在發聲的畫面。請參閱喇叭。

接收器與系統

  • 分區 2 / 分區 3。接收器可播放的額外房間，各自有獨立的電源、音量與輸入。請參閱多分區。
  • 全分區立體聲。在每個分區播放主分區的訊源。
  • HDMI CEC。讓電視與接收器透過 HDMI 互相控制。
  • eARC。Enhanced Audio Return Channel。透過 HDMI 將電視的完整音質聲音送到接收器。
  • ECO 模式。接收器的省電功能。
  • 自動待機。在一段時間沒有訊號或操作後關閉接收器。
  • 睡眠。關閉接收器的計時器。
  • 觸發輸出。12V 輸出，可隨接收器開關其他設備，例如螢幕或擴大機。在具備此功能的接收器上有專屬的遙控器子分頁。
  • 數位輸入格式。強制指定接收器讀取數位輸入的方式：Auto、PCM 或 DTS。
  • 藍牙發射器。將接收器的聲音傳送到藍牙耳機或喇叭。
  • 設定鎖定 / 遙控器鎖定。阻止選單變更或遙控器操作的接收器鎖定。請參閱鎖定的控制項。
  • 螢幕顯示。接收器顯示在電視上的資訊，例如音量。請參閱螢幕顯示。
  • 訊號資訊。輸入與輸出的音訊與視訊格式，例如色彩空間與像素深度。
FAQ

術語解答

Quick Select 和 Smart Select 是同一個東西嗎？
是。Denon 把接收器的記憶插槽稱為 Quick Select，Marantz 則稱為 Smart Select。AVR Maestro 會使用與您的接收器相符的名稱。
LFE 和重低音有什麼差別？
LFE 是音軌中獨立的低音聲道。重低音則是播放它的喇叭，同時也播放接收器從其他喇叭轉送過來的低音。
我需要同時使用 Audyssey 和 Dirac Live 嗎？
不需要。它們是兩種房間校正。在具備 Dirac Live 的接收器上，啟用中的 Dirac Live 校正會取代 Audyssey。

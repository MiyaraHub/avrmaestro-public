一個應用程式，29 種語言

每個畫面、每項設定、每個對話框 - 都以您的語言呈現。應用程式預設跟隨您的裝置，也可以在設定中自行選擇。希伯來文與阿拉伯文會讓整個版面鏡像翻轉。Denon 與 Marantz 官方應用程式提供其中 11 種語言（含英文），另外 18 種是 AVR Maestro 獨有的。

在哪裡設定

設定 › 語言

開啟設定並點選語言。系統預設會跟隨裝置；其下每種語言都以自己的名稱列出，讓您不必先讀懂另一種語言就能找到自己的語言。選擇後立即生效，重新啟動後仍會保留，並隨備份與還原一起保存。

希伯來文與阿拉伯文會讓整個應用程式左右翻轉：導覽、卡片、清單與滑桿都會鏡像，而其中所有 dB 與音量數值仍維持由左至右閱讀。

常見問題

語言常見問題

應用程式會自動跟隨手機的語言嗎？
會。安裝後預設就跟隨裝置語言。若要自行選擇，請開啟設定 › 語言；選擇「系統預設」即可將決定權交還給裝置。
希伯來文與阿拉伯文是由右至左排版嗎？
是的。整個應用程式都會鏡像翻轉 - 包含導覽、卡片、清單與滑桿 - 而所有 dB 與音量數值仍維持由左至右閱讀。
為什麼我的輸入名稱和音效模式還是英文？
因為那些是接收器本身的用詞，不是應用程式的。輸入名稱、音效模式、品牌與格式名稱（例如 Dolby Atmos、Audyssey、Smart Select 與 HEOS），以及接收器回報的每個數值，都會照接收器的原樣顯示。只有應用程式本身的文字會被翻譯。
語言設定會隨備份一起保存嗎？
會。語言選擇屬於備份與還原的一部分，所以還原後的手機會以您原本的語言開啟。

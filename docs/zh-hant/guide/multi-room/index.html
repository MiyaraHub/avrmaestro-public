多房間

多房間：群組、主導喇叭、佇列與音樂

在支援多房間的接收器上，AVR Maestro 會列出所有喇叭，讓您分組或解散群組、為群組設定單一音量，並為群組瀏覽、搜尋及排入音樂佇列。本指南會逐一說明畫面的每個部分。

畫面介紹

一個畫面管理所有喇叭

  • 開啟方式：從主畫面的多房間卡片點選開啟，或從導覽進入。標題為多房間。
  • 群組卡片位於最上方。每張卡片會顯示群組名稱、正在播放的內容、上一首 / 播放 / 下一首、靜音按鈕、整個群組共用的音量滑桿，以及佇列摘要。
  • 未分組會列出所有單獨存在的喇叭，每個喇叭都有一個裝置選項按鈕。
  • 應用程式搜尋喇叭時會顯示正在搜尋喇叭。若連線中斷，會顯示多房間連線中斷，正在重新連線。，並在恢復之前顯示最後已知的群組。
音量

群組音量與各喇叭音量

  • 最大的滑桿是群組音量。移動它，所有成員會一起調整。
  • 點選各喇叭音量可展開每位成員專屬的滑桿，並各有自己的靜音按鈕。可用來平衡安靜房間與吵雜房間的音量。
  • 已靜音的喇叭會顯示取消靜音，音量讀數為 0%。
播放中

正在播放，含專輯封面

  • 卡片會即時顯示群組正在播放內容的專輯封面、標題與演出者。沒有播放內容時會顯示沒有播放內容。
  • 上一首、播放或暫停、下一首可控制整個群組。
群組

建立、編輯與解散群組

  • 建立群組：點選後勾選兩個或更多喇叭（在勾選之前，面板會顯示請至少選擇兩個喇叭），再點選儲存。勾選兩個之後，每一列都會出現主導標籤：點選您想指定為主導的喇叭。若未選擇，第一個勾選的喇叭即為主導喇叭。
  • 主導喇叭：群組播放內容的來源，其標籤上標示為主導。當主導喇叭就是您目前連線的接收器時，會顯示此接收器。
  • 編輯群組：使用相同的面板變更成員或主導喇叭。已在其他群組中的喇叭會顯示在其他群組中。
  • 解散群組：立即移除群組，所有成員都會回到未分組。應用程式會以群組已移除確認。
  • 重新命名群組：點選卡片上的鉛筆圖示。名稱只會在此應用程式中變更。
  • 群組變更時，正在播放的喇叭可能會停止，面板會事先提醒您。
拖放

按住即可加入、移動或移出

  • 按住喇叭標籤，再拖放到群組上即可加入，或拖放到房間上即可移動。
  • 拖放到拖放到此處以移出群組，即可將該喇叭移出。
  • 若該喇叭正在播放，應用程式會在切換為群組播放內容之前先詢問：仍要加入。
音樂

音樂服務、瀏覽與我的最愛

  • 點選群組卡片上的音樂，即可開啟接收器已設定的服務清單，例如串流服務、廣播、播放清單、記錄與 AUX 輸入。
  • 點選服務即可瀏覽。返回可回到上一層。
  • 在項目上可選擇立即播放、下一首播放、加入佇列尾端或取代佇列並播放。
  • 清單過長時會顯示僅顯示前 N 個項目。
  • 愛心樣式的按鈕將正在播放的內容加入我的最愛會儲存目前播放的內容；再按一次同一按鈕即可移除。若服務未保留此變更，應用程式會告知您。
  • 需要登入的服務會顯示此服務需要您登入。請在接收器專屬的應用程式中登入一次。尚未設定音樂服務的情況也一樣。
搜尋

搜尋音樂服務

  • 支援搜尋的服務會顯示搜尋框，以及每種搜尋類型各一個標籤，例如演出者、專輯、曲目或播放清單。這些標籤來自服務本身，因此各服務會有所不同。
  • 選擇標籤、輸入文字，然後按下搜尋。清除會清空搜尋框。
  • 沒有符合的結果時會顯示沒有結果。
  • 若服務尚未在接收器上登入，搜尋會被拒絕，並顯示此裝置未接受該操作。請再試一次。
佇列

佇列

  • 群組卡片會摘要顯示佇列（佇列中有 3 首）與接下來的曲目。點選佇列即可開啟。
  • 面板以主導喇叭命名，依序列出曲目，並有可清空佇列的清除按鈕。重複播放（關閉、全部、單曲）與隨機播放也在這裡；若服務未保留播放模式，應用程式會告知您。
  • 佇列為空時會顯示佇列中沒有內容。若喇叭沒有回應，則會顯示無法讀取佇列。
房間

整理：房間與裝置名稱

  • 點選整理。新增房間可建立房間，每個喇叭都可透過裝置選項 → 移至房間移入房間。
  • 喇叭放入房間後，將此房間分組可一次將房間內所有喇叭分組。
  • 重新命名裝置只會變更此應用程式中的名稱。使用原始名稱可還原。
  • 在有多個分區的接收器上，所有分區共用此接收器的同一組喇叭，因此分組會套用到整台接收器。
首頁

主畫面卡片與主畫面小工具

  • 主畫面上的多房間卡片會以標籤列出喇叭與群組，並有可開啟此畫面的管理按鈕。
  • 在喇叭或群組上選擇釘選到主畫面小工具，即可將其放到多房間小工具，小工具會顯示它正在播放的內容，並提供播放與音量控制。應用程式會以<name> 已在多房間小工具上確認。
疑難排解

遇到問題時

  • 無法連上此接收器的多房間：請確認接收器已開啟，且位於相同網路。
  • 找不到喇叭：接收器沒有列出任何喇叭。請使用以 IP 位址連線，並輸入您從路由器查到的喇叭 IPv4 位址；忘記此喇叭可再將其移除。
  • 無法分組：卡片會說明原因，例如接收器未列出或不支援多房間。
  • 群組變更失敗：應用程式會告知發生了下列哪一種情況：群組清單已變更、喇叭未及時回應、因另一項變更仍在執行而未送出此變更、喇叭忙碌中，或變更未獲確認。請檢查群組後再試一次。
常見問題

多房間常見問題

AVR Maestro 的多房間是什麼？
這是一個畫面，也是一張主畫面卡片，會列出接收器能看到的所有喇叭、它們所在的群組，以及每個群組正在播放的音樂，每個群組都有一個音量滑桿。
群組的主導喇叭有什麼作用？
主導喇叭是群組播放內容的來源，其他成員會跟隨它。群組的佇列與正在播放的內容都以它為準。
如何解散喇叭群組？
開啟多房間，找到群組卡片並點選「解散群組」，所有成員都會回到「未分組」。若只想移出單一喇叭，請按住該喇叭，並拖放到「拖放到此處以移出群組」。
為什麼搜尋時會顯示裝置未接受？
該音樂服務尚未在接收器上登入。請先在接收器專屬的應用程式中登入一次，再從 AVR Maestro 重新搜尋。
哪些接收器可以使用？
支援多房間且會出現在多房間清單中的接收器。未出現的接收器會列在「無法分組」之下，並附上原因。

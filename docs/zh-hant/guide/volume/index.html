音量控制：上限、開機音量，以及真正好用的靜音

四項設定共同決定您的接收器最大能有多大聲、開機時是什麼音量，以及靜音時降到多低。它們儲存在接收器上，所以不論您用 App、實體遙控器還是前面板，都同樣有效。

在哪裡設定

設定 › 音量控制

開啟設定並捲動到音量控制 - 「音量上限、開機音量與靜音程度」。此頁面上的所有內容都會直接寫入接收器，所以關閉 App 後依然有效，並適用於您控制接收器的每一種方式。

逐項說明

每項設定的作用

音量刻度

音量的顯示方式，包括螢幕上以及接收器自己的顯示幕。0 - 98 是多數人熟悉的相對刻度；-79.5 至 18.0 dB 則是絕對刻度，其中 0.0 dB 為參考電平。如果您看過評測寫「-15 dB」，卻不知道對應到自己的旋鈕是多少，這個開關就能解答。

音量上限

硬性的天花板。一旦設定，任何方式都無法超過它 - App 不行，實體遙控器不行，前面板旋鈕也不行，因為這個上限存在於接收器，而不是 App。最顯而易見的用途，就是避免一時誤觸而傷了喇叭或嚇到滿屋子的人，在把遙控器交給來訪的客人之前，就該先設好它。關閉即可解除上限。

開機音量

使用上次音量預設為開啟：接收器開機時會回到關機前的音量。關閉後，您可以改為固定一個音量，這樣前一晚高音量聆聽到深夜，隔天早上就不會有令人不悅的驚嚇。

靜音程度

靜音時音量降多少。完全即為完全無聲。-40 dB 與 -20 dB 則是衰減而非全靜音，當您想一邊看電影一邊聊天、又不想錯過劇情時，這是更好的選擇。

App 的其他地方

您每天都會用到的控制項

  • 主畫面儀表板提供主分區的總音量、靜音與電源。
  • 遙控器分頁在方向鍵與播放控制鍵旁邊提供音量搖桿，並在調整時顯示目前電平。遙控器指南 →
  • 每一個音量加減按鈕 - 在主畫面儀表板、分區卡片與遙控器分頁中 - 點一下就調一格，按住則持續調整，就像實體遙控器一樣。放開後最多再多走一格就會停止。
  • 您手機的音量鍵在 Android 與 iPhone 上，App 在前景時可直接控制接收器，讓您不用看畫面也能調整。按住同樣會持續漸變。
  • 每個分區都有自己的音量，與主分區互相獨立。分區指南 →
  • 場景可以擷取主音量，因此叫用場景時，音量會與其他設定一併套用。場景指南 →
  • 電視上的螢幕音量顯示可以移動位置，也可以完全關閉。螢幕顯示指南 →
音量變更經過刻意的節奏控制，而不是每移動一個像素就送出一次，所以按住搖桿或滑動滑桿時會平順漸變，不會讓接收器被一堆指令塞爆、排隊後才遲遲套用。
常見問題

音量常見問題

音量上限也適用於實體遙控器嗎？
適用。這個上限是接收器的設定，不是 App 的設定，所以它對所有途徑都有效：App、隨附的遙控器、前面板旋鈕，以及您網路上的任何其他控制器。
這些設定適用於分區 2 與分區 3 嗎？
音量控制涵蓋的是主分區。每個分區都有自己的音量，以及自己的電源與輸入，請在分區分頁中設定。
為什麼評測都用分貝，App 卻顯示 0 至 98？
那是同一個旋鈕的兩種顯示方式。將音量刻度切換為 -79.5 至 18.0 dB，讀數就會與校正電平一般的標示方式一致，其中 0.0 dB 即為參考電平。
我可以用手機的音量鍵嗎？
可以，Android 與 iPhone 皆適用。當 AVR Maestro 在前景執行時，裝置的音量鍵會直接控制接收器，按一下調一格，按住則持續漸變；在設定的音訊中有個開關，可以把按鍵還給裝置。

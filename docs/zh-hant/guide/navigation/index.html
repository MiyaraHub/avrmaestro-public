操作導覽

分頁、滑動與手勢

如何在 AVR Maestro 中移動：底部分頁及其變更方式、在頁面間滑動、點選與長按的作用、返回鍵、更新提示、訊息，以及電腦上的鍵盤快速鍵。

底部分頁

螢幕底部的列放著您的主要分頁。預設為主畫面、遙控器、音效、分區、場景、喇叭與設定，也可以加入收音機。每個分頁的列右端都有一個搜尋按鈕（請參閱搜尋）。

  • 主畫面一律包含且一律在第一位。
  • 收音機只有在所選接收器具備調諧器時才會出現。請參閱收音機。
  • 您可以保留 2 到 7 個分頁。
逐步說明

新增、移除或重新排序分頁

  1. 開啟設定 › 自訂導覽。頂端會顯示列的預覽。
  2. 在可用分頁下，勾選分頁即可新增，取消勾選則移除。
  3. 在使用中分頁下，拖曳一列的把手即可變更順序。
  4. 點選儲存。導覽已更新訊息會確認完成。重設會回到預設的組合與順序。
逐步說明

隱藏您不使用的子分頁

音效、喇叭與遙控器分頁頂端各有一列子分頁，例如音效分頁上的 Audyssey、Dirac Live、圖形等化器、聲道與音調。

  1. 開啟設定 › 自訂分頁（隱藏您不使用的子檢視）。
  2. 在音效、喇叭或遙控器下，關閉您不想要的每個子檢視。預覽會顯示結果。
  3. 返回。此變更適用於所有接收器。
如果您的接收器不支援某項功能，例如沒有 Audyssey 的接收器上的 Audyssey，其子分頁已經隱藏，不會列在這裡。自訂分頁是在那之上的第二層。

在頁面間滑動

  • 在頁面上向左或向右滑動，即可移到下一個或上一個子分頁。
  • 在最後一個子分頁繼續滑動，就會移到下一個底部分頁。超過最後一個分頁後會繞回第一個，順序依您的設定。
  • 沿著底部分頁列滑動可直接切換分頁。這同樣會循環繞回。
  • 在有滑桿的頁面上，緩慢拖曳會移動滑桿。換頁則需要快速、大致橫向的甩動。

在 iPhone、iPad 與 Mac 上滑動返回上一步

在引導式場景建立器、歡迎與設定指南以及 Home Assistant 登入頁面中，從螢幕左緣向內滑動即可返回上一步。在由右至左的語言中，則從右緣向內滑動。滑過超過一半的距離，或快速甩動。

點選與長按

許多控制項點選時有一種作用，按住時又有另一種作用。

  • 音量預設。共有 8 個預設插槽。點選標有 + 的空白插槽，即可將目前音量存入。點選已儲存的插槽，即可跳到該音量。長按任一插槽，可用目前音量覆寫它，或將它清除。若想漸變到預設而不是直接跳到該音量，請在設定 › 管理接收器 › 您的接收器 › 音訊中開啟漸進式音量預設。請參閱音量。
  • Quick Select 與 Smart Select。點選插槽即可叫用。長按可選擇儲存目前狀態或重新命名。
  • 主畫面輸入網格。長按即可開始編輯網格。請參閱主畫面。
  • 遙控器輸入。長按輸入即可為它設定自訂圖示。請參閱自訂圖示。
  • 分區名稱。長按分區名稱即可重新命名。請參閱多分區。
  • 收音機預設。點選即可叫用，長按則可儲存目前電台。請參閱收音機。
  • 場景。點選即可套用，按住可開啟選項。請參閱場景。
  • 接收器。在設定 › 管理接收器中，長按接收器可開啟其選項。
  • 說明卡片。點選橫幅可展開，長按則可關閉。可從設定 › 還原已隱藏的卡片找回。

返回、結束與訊息

  • 在子頁面按返回會回到該分頁的頂端。在主畫面編輯時，按返回會先離開編輯模式。
  • 在分頁頂端按返回會詢問要離開 AVR Maestro 嗎？點選結束應用程式即可關閉應用程式，或點選取消留下。這適用於 Android 的返回鍵與返回手勢。
  • 畫面底部的訊息有一個關閉按鈕。錯誤訊息會停留到您關閉為止。其他訊息會在幾秒後自行關閉，較長的訊息停留較久。新訊息會取代畫面上的訊息。
開啟手機的無障礙導覽設定後，每則訊息都會停留到您關閉為止。

有更新可用時

當 AVR Maestro 發布較新的版本時，主畫面會顯示有可用更新。

  • 更新會開啟應用程式在 Google Play、App Store 或 Microsoft Store 的頁面。
  • 稍後會將提示隱藏 3 天。
  • 略過此版本會停止該版本的提示。
如果某個版本被標示為必要，提示會顯示必須更新，只有更新按鈕，且無法關閉。

Windows 與 Mac 上的鍵盤快速鍵

在 Windows 上使用 Ctrl，在 Mac 上使用 Cmd，搭配：

  • 上 / 下方向鍵：調高或調低音量
  • M：開啟或關閉靜音
  • 空白鍵：播放或暫停
  • 右 / 左方向鍵：下一首或上一首
  • 句點（.）：停止

鍵盤上的媒體鍵（播放、暫停、下一首、上一首、停止、音量與靜音）同樣可用。

在文字欄位中輸入時，快速鍵不會有任何作用。靜音與播放或暫停會等到接收器回報目前狀態後才生效。

各平台說明

  • Android：返回鍵在結束前會先詢問。應用程式開啟時，手機的音量鍵可以變更接收器的音量（裝置音量按鈕，依接收器設定，預設為開啟）。
  • iPhone 與 iPad：在引導式流程中，從邊緣向內滑動即可返回上一步。裝置音量按鈕在這裡也適用。
  • Mac：邊緣滑動返回上一步、Cmd 快速鍵與媒體鍵。
  • Windows：Ctrl 快速鍵與媒體鍵。
FAQ

導覽常見問答

如何變更 AVR Maestro 底部顯示的分頁？
開啟「設定 › 自訂導覽」。取消勾選「可用分頁」下的分頁即可移除，勾選則新增，拖曳「使用中分頁」下的各列可變更順序，然後點選「儲存」。主畫面一律包含且一律在第一位。您可以有 2 到 7 個分頁。
如何隱藏我從不使用的子分頁，例如 IMAX 或 Auro-3D？
開啟「設定 › 自訂分頁」，並在「音效」、「喇叭」或「遙控器」下關閉您不想要的子檢視。此設定適用於所有接收器。接收器不支援的功能已經隱藏，不會列在那裡。
為什麼沒有收音機分頁？
收音機可以在「設定 › 自訂導覽」中新增，但只有在所選接收器具備調諧器時，分頁才會出現。
可以在分頁之間滑動嗎？
可以。在頁面上向左或向右滑動即可在其子分頁間移動。到了最後一個子分頁，下一次滑動會移到下一個底部分頁，從最後一個分頁則會繞回第一個。您也可以沿著底部分頁列本身滑動。
為什麼 AVR Maestro 在關閉前會詢問？
在 Android 上，於分頁頂端按下返回鍵會詢問「要離開 AVR Maestro 嗎？」，避免誤按返回鍵就關閉應用程式。點選「結束應用程式」即可關閉，點選「取消」則留下。從子頁面按返回，會先回到該分頁的頂端。
AVR Maestro 在 Windows 和 Mac 上有鍵盤快速鍵嗎？
有。在 Windows 上使用 Ctrl、在 Mac 上使用 Cmd，搭配上或下方向鍵可調整音量，搭配 M 切換靜音，搭配空白鍵播放或暫停，搭配左或右方向鍵跳到上一首或下一首，搭配句點鍵則停止。鍵盤上的媒體鍵同樣可用。在文字欄位中輸入時，快速鍵不會有任何作用。

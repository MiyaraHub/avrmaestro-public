當連結或腳本出問題時

Home Assistant，無法正常運作時

大多數 Home Assistant 問題都歸結為連結狀態、接收器實體 ID，或是手機與伺服器之間的網路。先看連結卡片上寫了什麼，再逐項往下排查。

連結卡片在告訴您什麼

Sync 按鈕上方的卡片顯示連結的狀態，按鈕會隨之變化。

  • 已連結至 Home Assistant：剛剛有一次通過身分驗證的呼叫成功。Sync 按鈕可用。
  • Home Assistant 連結已過期：伺服器有回應，但拒絕了已儲存的權杖。在您重新登入之前，Sync 按鈕處於停用狀態。
  • 無法連上 Home Assistant：無法連上您的伺服器，而權杖可能完全有效。Sync 按鈕仍然可用，也不會變更任何內容。
  • 未連結至 Home Assistant：尚未儲存位址或權杖。請新增您的位址並登入。
  • Home Assistant 連結未檢查：示範模式已開啟，或居家自動化已鎖定，所以沒有向您的家傳送任何內容，權杖也沒有被嘗試使用。
只有第一種會顯示「已連結」，而且只是因為有內容通過了身分驗證。光是儲存了權杖，從來都不算連結。

腳本沒有任何反應，或顯示 Entity Not Found

  • 在 Home Assistant 的「設定」，「裝置 & 服務」中安裝官方 Denon AVR 整合。
  • 請確認 AVR Maestro 設定中的 Receiver Media Player Entity ID 與 Home Assistant 中的實體 ID 完全一致。
  • 場景被刪除或重新建立後，請忽略任何顯示 unavailable 的實體。場景腳本是依場景建立的時間命名，所以腳本 ID 如何變更一次，請參閱居家自動化。

Home Assistant 中缺少新場景

每當您新增、編輯或刪除場景時，場景都會在背景同步，所以不必每次都按 Sync。如果缺少某個場景，表示手機沒能連上您的伺服器。

  • 讓手機連上與 Home Assistant 相同的區域 Wi-Fi 網路。
  • 開啟設定並點選 Sync Scenes。若失敗，它會顯示具體的網路錯誤。

Home Assistant 記錄中的 Failed login

幾次失敗的嘗試，或是瀏覽器在連結完成前中斷了連線，都會在 Home Assistant 中留下一則警告。它是歷史記錄，不是目前的故障，連結正常之後您可以忽略它。

其他可能出問題的地方

  • 儀表板圖磚始終不亮：請參閱 Home Assistant 儀表板指南。
  • Webhook 沒有送達：請參閱居家自動化。
  • 還是卡住了嗎？請到 Discord 詢問，或查看說明。
常見問題

Home Assistant 問題解答

我的腳本執行了，但顯示 Entity Not Found，或是沒有任何反應。
請確認 Home Assistant 中已安裝官方 Denon AVR 整合。接著檢查 AVR Maestro 設定中的 Receiver Media Player Entity ID 是否與 Home Assistant 中的實體 ID 完全一致，例如 media_player.living_room_receiver。
為什麼我的 Home Assistant 記錄裡寫著 Failed login？
如果連結時有幾次失敗的嘗試，或瀏覽器在完成之前中斷了連線，Home Assistant 就會記錄一則警告。連結成功之後，您可以放心忽略這則舊警告。
我建立了新場景，但它沒有出現在 Home Assistant 中。
請確認手機與 Home Assistant 伺服器位於同一個區域 Wi-Fi 網路，因為手機連不上伺服器時，背景同步會失敗。開啟設定並點選 Sync Scenes，若有網路錯誤，就能看到具體內容。
腳本執行時，應用程式需要保持開啟嗎？
不需要。腳本存放在 Home Assistant 中，所以手機放在口袋裡時，它們也能透過您的儀表板、自動化或語音助理執行。只有在您變更場景時，應用程式才會建置並更新它們。

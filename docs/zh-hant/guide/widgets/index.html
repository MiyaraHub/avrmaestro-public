Android、iPhone 與 iPad

主畫面小工具

不必開啟應用程式就能控制接收器：電源、音量與靜音、正在播放的內容、目前的訊號，以及您的場景，全都在主畫面上。小工具適用於 Android 以及 iPhone 與 iPad。Mac 與 Windows 沒有小工具。

四個小工具

  • 快速控制（Android：AVR Quick Control）。接收器名稱、輸入與音量，附電源、音量減、音量加與靜音。在 Android 上還有「開啟應用程式」，而接收器關閉時會隱藏音量與靜音按鈕，只留下電源。
  • 正在播放（Android：AVR Now Playing）。封面、標題、演出者與電台，附上一首、播放或暫停與下一首。沒有播放內容時，Android 上顯示「沒有播放媒體」，iPhone 與 iPad 上顯示「沒有正在播放的內容」。
  • 接收器狀態（Android：AVR Signal Status）。輸入、輸入與輸出的音訊及視訊訊號、取樣率與音量。
  • 場景（Android：AVR Scenes）。您為接收器儲存的場景。點選其中一個即可套用，不必開啟應用程式。請參閱場景。
小工具會跟隨應用程式中所選的接收器。接收器處於待命時，快速控制與狀態顯示待命；無法連到接收器時，顯示AVR 已關閉。
逐步說明

新增小工具

  1. 請先開啟 AVR Maestro 一次並連線到您的接收器，小工具才有內容可顯示。
  2. 長按主畫面的空白處，並選擇手機的小工具選項。
  3. 找到 AVR Maestro 並選擇一個小工具。在 Android 上，名稱以 AVR 開頭。在 iPhone 與 iPad 上，快速控制、正在播放與接收器狀態提供中型尺寸，場景提供中型或大型。
  4. 在 Android 上，拖曳小工具的邊緣即可調整大小。小尺寸會切換為精簡版面。
iPhone 與 iPad 小工具需要 iOS 或 iPadOS 17 或更新版本。

讓小工具保持最新

  • 重新整理按鈕。快速控制、正在播放與場景有重新整理按鈕，可立即更新小工具。在 Android 上，正在播放在較大的尺寸才會顯示它。
  • 自動重新整理。快速控制與狀態會自行約每 15 分鐘更新一次，在 Android 上正在播放也是如此。在 Android 上這需要網路連線。當您在應用程式中變更場景或點選重新整理時，場景會隨之更新。
在 Android 上，您第一次使用小工具時，應用程式會說明主畫面小工具，並提供開啟設定。為了獲得最可靠的背景更新，請在電池設定中允許 AVR Maestro 在背景執行。

小工具色彩

兩項設定都在設定的外觀之下，適用於 Android、iPhone 與 iPad。

  • 高對比小工具會讓小工具呈灰階。
  • 小工具跟隨應用程式色彩會在小工具上使用您的色彩主題強調色，而不是標誌性的橙色。開啟「高對比小工具」時，此開關無法使用，小工具維持灰階。
同一區段中的小工具大小不會改變主畫面小工具。它縮放的是應用程式內的按鈕、晶片與卡片（小、中、大或特大）。請參閱設定。
FAQ

小工具常見問答

AVR Maestro 有哪些主畫面小工具？
共四個，適用於 Android 與 iPhone 或 iPad：快速控制（電源、音量與靜音）、正在播放（播放內容，附上一首、播放或暫停與下一首）、iPhone 上的接收器狀態或 Android 上的訊號狀態（輸入與音訊及視訊訊號），以及場景（套用已儲存的場景）。Mac 與 Windows 上沒有小工具。
主畫面小工具多久更新一次？
快速控制與狀態小工具會自行約每 15 分鐘更新一次，在 Android 上正在播放也是如此。快速控制、正在播放與場景另有重新整理按鈕，可立即更新小工具。
為什麼我的小工具顯示「AVR 已關閉」或「待命」？
「待命」表示接收器處於待命狀態。「AVR 已關閉」表示小工具無法連到接收器，例如接收器未接電源或在另一個網路上。
為什麼場景小工具顯示沒有場景？
小工具列出的是所選接收器已儲存的場景。請先開啟 AVR Maestro 建立一個場景，請參閱場景指南。
「小工具大小」會改變主畫面小工具嗎？
不會。「設定 › 小工具大小」變更的是應用程式內按鈕、晶片與卡片的大小。要變更主畫面小工具的大小，請在主畫面上調整它。
小工具可以使用我的主題色彩嗎？
可以。開啟「設定 › 小工具跟隨應用程式色彩」，小工具就會使用您的強調色而不是橙色。開啟「高對比小工具」時無法使用，因為那些小工具是灰階的。

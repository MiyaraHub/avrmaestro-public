最具代表性的功能

情境：整個房間，一鍵設定

電影之夜、深夜、黑膠之夜。每一個情境都只需點一下，就能依您喜歡的方式設好輸入、音效模式、Audyssey 或 Dirac、電平與分區。要建立情境，您不必熟悉接收器的選單：應用程式只會問幾個簡單的問題，並且只提供您的接收器真正辦得到的選項。

兩種開始方式

點一下「新增情境」，再選擇建立方式

  • 場景建立器會與您一問一答，並且只提供您的接收器支援的選項。最適合建立第一個情境，或是您知道自己想要什麼，卻不知道設定在哪個選單時使用。
  • 從頭建立會擷取接收器目前的狀態。先把聲音調好，勾選要保留的設定，然後儲存。
「情境」分頁還沒有任何內容嗎？它會根據您的接收器建議幾個起點，例如電影與電視或深夜。點選其中一個，場景建立器就會開啟，並且已經選好該項目。
場景建立器，一步一步來

大約一分鐘，完成您的第一個情境

場景建立器是根據您的回答建立情境的。它不會讀取接收器，儲存也不會變更任何東西，所以您可以放心嘗試各種想法。頂端的步驟計數器會顯示您目前的進度，點「返回」就能回到任何先前的回答。

  1. 為它命名。取個忙碌的夜晚也能一眼認出的名字：電影之夜、週六黑膠、孩子的卡通。
  2. 說明它的用途。電影與電視、音樂、遊戲、深夜、其他房間，或是想自己選擇所有項目時選「自訂」。這個選擇只會醒目標示通常適合的設定，不會替您勾選任何項目。
  1. 勾選它要控制的項目。設定會依照您思考的方式分組：路由 & 音量、音效、Audyssey & Dirac、喇叭 & 電平、分區、其他與外觀。只會列出您的接收器支援的設定，標示為建議的項目，則是針對您在第 2 步的選擇所常見的選項。
Audyssey 與 Dirac Live 是兩種不同的房間校正系統，您的接收器在每個喇叭預設中只會使用其中一種。當 Dirac Live 啟用時，部分 Audyssey 設定會被接收器本身鎖定，應用程式會在您勾選時就告訴您，而不是讓您儲存一個無法套用的情境。請參閱控制項為何被鎖定。
  1. 為每項設定選擇數值。每個勾選的設定都有一個簡短的頁面，列出接收器回報的數值：它的音效模式、輸入、Dirac 插槽與喇叭預設，電平則以接收器顯示的方式呈現。
  • 顯示其他類型。接收器只會列出它正在播放的類型所對應的音效模式。點選這個選項後，應用程式會花片刻讀取其他類型，然後讓您的接收器完全恢復原狀。
  • 顯示哪些預設是 Audyssey 或 Dirac。喇叭預設也用同樣的方法，讓每個欄位在您選擇之前就先標示清楚。
  • 聲道電平在儲存時會維持原狀。想要不同的數值嗎？請先到「喇叭」分頁調整，再回來這裡。
  1. 檢閱並儲存。最後一頁會精確列出情境將儲存的內容，分組方式與應用程式其他部分一致。點一下儲存，它就會出現在您的情境清單中，隨時待命。
步驟的數量會隨著您勾選的項目增加：每個勾選的設定都有自己的一頁，所以只有三項設定的情境，會比有十項設定的情境更短。
從頭建立

聲音已經很完美？那就保留下來

當房間的聲音已經很理想，就不需要回答任何問題。點一下新增情境，選擇從頭建立，為它命名並勾選要保留的項目。情境會儲存接收器目前的數值，而且只儲存那些設定。

在場景建立器中選擇自訂，會在不讀取接收器的情況下給您同樣完整的清單，方便您預先為日後設定。

情境可以包含的內容

幾乎一切，而且只保存您所選的

套用情境只會變更它所包含的設定。深夜情境可以調低音量並開啟 Dynamic Volume，同時讓您的輸入、音效模式與校正維持原狀。

使用與修改情境

點一下即可套用，長按可進行其他操作

點一下情境，設定傳送期間圖磚會顯示套用中...，並依安全的順序逐一送出。長按則可進行其他操作：

  • 以目前設定更新會保留名稱、圖示與設定清單，並擷取接收器目前的數值。不必刪除再重新儲存。
  • 編輯已擷取的設定可以為情境新增或移除設定。
  • 重新命名情境與變更圖示 & 顏色，包括您自己的圖片（請參閱自訂圖示）。
  • 複製情境可以做出變化版本，例如電影之夜與電影之夜（孩子睡了），不必從頭開始。
  • 居家自動化（進階版）會把情境傳送到 Home Assistant 或 Hubitat，讓單一自動化就能同時調暗燈光並設定接收器。請參閱居家自動化。
  • 刪除情境會在這裡移除它，而下一次 Home Assistant 同步時，也會移除它所建立的指令碼。
拖曳情境的把手即可重新排序清單。情境也會以卡片形式顯示在主畫面上，在 Android 上，您還可以從啟動器的小工具清單加入 AVR Scenes 小工具，不必開啟應用程式就能觸發情境。
情境與 Smart Select / Quick Select

接收器的欄位，以它們真正的名稱呈現

您的接收器本身也有幾個預設欄位。Marantz 稱之為 Smart Select，Denon 則稱之為 Quick Select，而 AVR Maestro 在每個畫面都使用您接收器自己的名稱：主畫面的那一列、遙控器分頁、自訂分頁與設定指南。Marantz CINEMA 30 共有五個。

  • Smart Select / Quick Select 存放在接收器內。您可以從主畫面或遙控器觸發某個欄位，長按則可重新命名。
  • 情境存放在應用程式內：每台接收器最多 20 個，各有自己的名稱、圖示與顏色，只保存您選擇的設定，還能變成小工具、捷徑或 Home Assistant 指令碼。

兩者絕不會互相覆寫，所以可以兩者並用：欄位用於接收器本身的快速切換，其他一切則交給情境。

疑難排解

當情境沒有完全套用時

情境不是單一指令。它是一連串刻意安排順序、並控制節奏讓接收器跟得上的指令，所以需要片刻時間，而不是瞬間完成。

  • 電源優先，冷機的接收器會有時間啟動。如果情境會開啟接收器，其他一切都會等它完成開機，因為仍在開機的接收器會忽略設定。
  • 聲道電平會經過檢查並重新傳送一次。一次收到大量指令時，接收器偶爾會漏掉某個聲道。應用程式會讀回實際生效的內容，重新傳送沒有生效的項目，並告訴您哪些聲道必須重試。
  • 被鎖定的控制項，無論如何都無法套用。如果您的喇叭預設由 Dirac Live 掌控，接收器本身就會拒絕 Audyssey 的變更，包含這些變更的情境，也會和螢幕上的控制項一樣被拒絕。請參閱控制項為何被鎖定。
  • 只會變更情境所包含的內容。如果情境沒有改變您預期的項目，很可能是當初沒有勾選。請長按它並使用「編輯已擷取的設定」，而不是另外建立第二個情境。
  • 情境屬於單一接收器。清單就是目前選取的接收器的清單。另一台接收器有它自己的清單。
常見問題

情境常見問題

什麼是情境？
情境就是點一下，讓接收器為某個用途準備就緒：一部電影、一張唱片、一場遊戲，或安靜的深夜。它可以包含輸入、音量、音效模式、Audyssey 或 Dirac、喇叭預設、聲道電平、分區、調諧器電台與電源。套用時，只會變更您選擇的設定，其他一切都維持原狀。
我要怎麼建立第一個情境？
開啟「情境」分頁，點一下「新增情境」，再選擇「場景建立器」。為它取個名字，說明它的用途（電影與電視、音樂、遊戲、深夜、其他房間或自訂），勾選它要控制的項目，從接收器提供的選項中為每項設定選擇數值，並在儲存前檢查摘要。大約只需要一分鐘。
從場景建立器儲存情境會變更接收器上的任何東西嗎？
不會。場景建立器是根據您的選擇建立情境的，所以儲存時不會從接收器讀取任何內容，也不會傳送任何指令給它。只有在您套用情境時，才會變更接收器。
「從頭建立」是做什麼用的？
用來擷取您已經調好的設定。先把接收器調成您想要的聲音，點一下「新增情境」，選擇「從頭建立」，為它命名並勾選要保留的設定。情境會儲存接收器目前的數值。
套用情境會讓接收器負荷過重嗎？
不會。設定會依照安全且有節奏的順序逐一傳送，電源優先，圖磚會顯示「套用中...」，直到接收器全部接收完畢。聲道電平會被讀回確認，接收器漏掉的項目則會再傳送一次。
我之後可以修改情境嗎？
可以。長按情境即可看到「套用情境」、「以目前設定更新」、「編輯已擷取的設定」、「重新命名情境」、「變更圖示 & 顏色」、「複製情境」、「居家自動化（進階版）」與「刪除情境」。拖曳情境的把手即可重新排序清單。
情境可以開啟我的接收器嗎？
可以。只要包含電源狀態，套用情境時就會先開啟（或關閉）主分區，前提是接收器已啟用網路待機，這樣應用程式才能在它休眠時連上它。
情境與 Smart Select 或 Quick Select 有什麼不同？
Smart Select（Marantz）與 Quick Select（Denon）是同一項接收器功能的兩種名稱：儲存在接收器內的少數幾個欄位，Marantz CINEMA 30 上有五個。AVR Maestro 在應用程式各處都使用您接收器自己的名稱，讓您從主畫面與遙控器觸發它們，也可以重新命名。情境則是 AVR Maestro 自己的功能：每台接收器最多 20 個，各有名稱、圖示與顏色，只保存您所選的設定，還能變成主畫面小工具與捷徑，或傳送到 Home Assistant 或 Hubitat。兩者絕不會互相覆寫。

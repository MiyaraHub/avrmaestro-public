喇叭設定 & 預設

專屬的喇叭工作坊

喇叭預設、配置、距離、電平、分頻、重低音與低音管理：完整的設定組合，即時從您的 Denon 或 Marantz 接收器讀取，每個畫面都跟隨使用中的喇叭預設。

每個設定畫面，都在您的手機上

開啟螢幕底部的喇叭分頁。頁面依此順序橫向排列在頂端；點選名稱或左右滑動即可在其間切換。

  • 預設：在喇叭預設 1 與 2 之間切換。每個預設各自儲存配置、距離、電平、分頻與校正，其他所有喇叭頁面都跟隨使用中的那個。只有單一喇叭設定的機型，會顯示喇叭預設無法使用，而不是切換開關。
  • 喇叭配置：擴大機指定與各喇叭的設定。在提供此功能的機型上，前置喇叭設定接收器驅動哪些前置端子（A、B 或 A+B）；接收器將它變灰的地方，應用程式會說它已鎖定，而不是假裝變更會生效。
  • 距離：各喇叭與您座位的距離，單位依接收器而定（m 或 ft）。
  • 電平：儲存在預設中的各喇叭微調電平。
  • 分頻：低於此頻率的低音會送往重低音。這裡只會出現「小」喇叭；0 Hz 表示全頻域。在回報此功能的接收器上，您可以選擇全部（一個共用數值）或個別。
  • 重低音：重低音輸出、LFE 或 LFE + Main，依喇叭預設分別儲存。此頁面只在您的接收器已設定重低音時出現。
  • 低音：LFE 用 LPF（LFE 聲道的低通截止頻率）與 LFE 分配（將 LFE .1 聲道送往全頻域喇叭，僅在接收器允許時提供）。
變更擴大機指定前會先詢問：它會重新設定每支喇叭，並將配置重設為新模式的預設值，因此增高與環繞後置等設定會遺失。在 Audyssey 已校正時，同一個提示也會警告此變更同時會關閉 Audyssey（MultEQ XT32、Dynamic EQ、Dynamic Volume），而頁面會提醒您，變更任何喇叭配置設定都會移除 Dirac Live 濾波器。
較舊的接收器

SR7015 系列與其他使用較早設定選單的接收器

部分較舊的接收器（例如 Marantz SR7015 系列）使用較早版本的設定選單。AVR Maestro 會從接收器自己的選單辨識出來並調整頁面：

  • 喇叭配置顯示擴大機指定（Floor、Height / Dolby speakers、Height layout）以及每一列喇叭設定，而且全部都能從應用程式變更。
  • 低音可編輯：LFE 低通截止頻率與重低音模式（LFE 或 LFE + Main）。LFE 分配區塊會隱藏，因為這些接收器沒有它。
  • 重低音會顯示在此韌體上，重低音輸出設定在低音分頁。請改用低音頁面。
  • 分頻可在全部與個別之間切換，而且只有接收器允許的列才能編輯。
如果接收器回應緩慢，配置頁面會提供重試；如果它的設定選單被鎖定，則會顯示鎖定卡片。只有兩次讀取都被拒絕的接收器才會顯示此韌體上無法使用，並附有在網頁控制介面中開啟按鈕，開啟接收器自己的網頁以進行該項編輯。您可以在設定 › 自訂分頁下隱藏無法使用的頁面。
即時檢視

逐一聲道，看見實際正在播放的內容

喇叭網格在左側顯示輸入訊號攜帶的內容，在右側顯示接收器實際驅動的喇叭。立體聲曲目會在升混器所饋送的每個輸出旁顯示兩個輸入聲道，讓您看到升混的運作。

  • 接收器為自己的喇叭命名。每個標籤都來自接收器，所以即使機型有本應用程式從未見過的喇叭，也能把它們畫在正確的位置。
  • 三種狀態，而非兩種：播放中、已連接但靜音，以及不存在。接收器表示不在此訊號中的喇叭，完全不會被繪出。
  • 在哪裡找到：將喇叭網格卡片新增到主畫面分頁，或查看遙控器分頁的主頁面。
較舊的接收器（X4500H 與 SR7015 系列）對網格要求不回傳任何內容，所以網格在那裡維持隱藏，也不會提供喇叭網格卡片。
懂得與 Dirac 配合

不會讓您送出接收器會拒絕的變更

上述頁面在標準喇叭預設上完全可編輯。但當預設上有作用中的 Dirac Live 濾波器時，Dirac 擁有配置、距離、分頻、重低音輸出與低音管理，所以與其讓您進行接收器會默默忽略的變更，AVR Maestro 會顯示清楚的鎖定並說明原因。請切換到非 Dirac 的預設來編輯它們。

常見問題

喇叭設定常見問題

我可以在 App 中設定距離與電平嗎？
可以。擴大機指定與配置、各喇叭距離、聲道電平、分頻與重低音設定都是即時讀取，並跟隨使用中的喇叭預設。
為什麼有些喇叭畫面被鎖定？
當預設中啟用了 Dirac Live 濾波器時，配置、距離與分頻都由 Dirac 掌管。App 會顯示鎖定，而不是讓您送出接收器會拒絕的變更。請切換到非 Dirac 預設才能編輯。詳情請見 Audyssey & Dirac 指南。
什麼是喇叭預設？
預設 1 與 2 各自儲存自己的配置、距離、電平、分頻與校正。請在預設頁面切換；每個喇叭頁面都會跟隨使用中的預設。只有單一喇叭設定的機型，則會顯示「喇叭預設無法使用」。
我的 SR7015 說重低音輸出設定在低音分頁。這樣對嗎？
對。在該韌體上，重低音模式（LFE 或 LFE + Main）與 LFE 低通截止頻率放在一起，所以應用程式會帶您到低音頁面，兩者都可以在那裡變更。這些接收器上的喇叭配置頁面也完全可編輯，包含擴大機指定。
沒有重低音時，可以把 LFE 聲道送到前置喇叭嗎？
可以，限支援的接收器。當您的主喇叭在分頻中設為全頻域，且接收器沒有把 LFE 送往重低音時，低音頁面的 LFE 分配會把 LFE（.1）聲道送到這些喇叭，並附有各喇叭電平。AVR Maestro 只在接收器允許時才提供：如果喇叭不是全頻域，或重低音被設為接收 LFE，接收器會鎖定該設定，應用程式也會說明原因。同一頁面上的 LFE 用 LPF 控制項，則設定 LFE 聲道的低通截止頻率。

AVR Maestro 使用指南

在您的 Denon 或 Marantz 接收器上設定、連接並精通 AVR Maestro 所需的一切。每個畫面都會依您的機型調整，應用程式只會顯示您的機身實際提供的控制項，因此您的畫面可能比這裡列出的選項少。

瀏覽指南

每個畫面，逐一說明

從設定開始，再深入任何功能。重點主題都有各自的深入指南，其餘則涵蓋在下方各節中。

🚀

入門指南

系統需求、網路設定，以及一分鐘內新增您的接收器。
🏠

主畫面

可自訂的主畫面，提供音量、訊源、音效模式、分區等小工具。
🎭

場景

儲存您的整套設定，一鍵叫出。這是最主打的功能。
🎨

自訂圖示

為每個輸入與場景設計專屬圖片，可裁切、塑形，並包含在您的備份中。
🎵

音效

全部九個頁面：環繞模式、對白 & DRC、Audyssey、Dirac Live、圖形等化器、各聲道微調、音調、IMAX 與 Auro-3D。
🎛️

圖形等化器

在 Audyssey 與 Dirac 關閉時，為每支喇叭調整 9 段曲線：全部、左/右或個別。
🔊

喇叭

配置、距離、電平、分頻、重低音與喇叭預設。
🔒

控制項為何被鎖定

喇叭配置已鎖定、Audyssey 無法使用、圖形等化器被保留：接收器鎖定項目的完整地圖，以及如何解鎖。
💬

助理

向您自己的接收器提問，或直接告訴它要調整什麼。模型在您的裝置上執行。

🏠️

居家自動化

Home Assistant、Hubitat 與 Webhook - 您的場景變成不需要手機也能執行的指令碼。

🖥️

Home Assistant 儀表板

附完整 YAML 的實作範例：即時訊源醒目標示、真實 dB 音量、場景與圖表。
🏢

分區

獨立控制分區 2 與分區 3 的電源、輸入與音量 - 還有各分區專屬的 Smart Select 或 Quick Select 插槽，以及重新命名。
🎮

遙控器

方向鍵、播放控制、可重新命名並附自訂圖示的輸入，以及系統控制。
📻

收音機（FM/AM）

依頻率選台，或叫用已儲存的電台預設。
📺

螢幕顯示

音量顯示位置或關閉、資訊橫幅、正在播放、21:9 與螢幕保護程式。
⚙️

設定

裝置、外觀與以十六進位色碼設定的色彩主題、音訊、說明與備份。
🌐

語言

29 種語言，自動偵測或在設定中選擇；希伯來文與阿拉伯文會讓整個應用程式鏡像翻轉。
🔊

音量控制項

硬性音量上限、開機音量、靜音降低的幅度，以及 0-98 與分貝兩種顯示。
💾

備份 & 還原

將所有設定匯出成一個檔案，並在新手機上還原 - 包含接收器、圖示、場景與主題。
🎧

正在播放 & HEOS

專輯封面、曲目資訊與播放控制，還能啟動 HEOS 瀏覽音樂。
📱

小工具與更多功能

iOS 與 Android 主畫面小工具、各平台皆可備份與還原，兩個平台都支援手機音量鍵。
📡

支援的接收器

哪些 Denon 與 Marantz 機型可以使用，以及如何確認。
依接收器機型

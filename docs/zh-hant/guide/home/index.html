主畫面

主畫面：您的大本營，照您的方式呈現

裝置狀態卡片固定在頂端，顯示機型、連線與電源，下方則是可自訂的小工具格狀排列。新增、移除並重新排序卡片，讓主畫面只顯示您真正在意的內容。

打造專屬於您的樣子

幾秒內完成自訂

點選左上角的自訂主畫面圖示以進入編輯模式：

  • 拖曳卡片以重新排序。
  • 點選紅色圓圈來移除卡片。
  • 新增會開啟尚未加入的小工具清單。
  • 重設會恢復預設值；完成則退出。
編輯時卡片會變暗，避免您不小心更動接收器設定。小工具只會在您的接收器提供該功能時顯示。
為您的房間命名

是「客廳」，而不是「MAIN ZONE」

在主畫面長按分區名稱即可重新命名任何分區，包括主分區。名稱會寫入接收器本身，而不只是應用程式，因此會顯示在原廠自己的應用程式與其他所有用戶端中，舊款機身也適用。只要命名一次，家中每個控制器對這個房間的稱呼就會一致。

小工具功能
音量附有 dB 讀數的滑桿、靜音，以及 8 組已儲存的音量預設。
訊源開啟輸入選擇器；長按圖磚可重新排序。已重新命名的訊源，以及您在遙控器輸入格狀畫面設定的自訂輸入圖示，也會顯示在這裡。
音效模式目前的環繞模式；點選可開啟分組的選擇器。
正在播放HEOS 訊源的專輯封面、曲目資訊與播放控制。
分區精簡的分區 2 / 分區 3 狀態與快速控制，包括該分區自己的 Smart Select 或 Quick Select 記憶位：點選記憶位可叫用，長按則會將該分區目前的狀態儲存進去。
Smart Select / Quick Select您接收器自己的記憶位，名稱與您的接收器一致：Marantz 稱為 Smart Select，Denon 稱為 Quick Select。重新命名的記憶位會儲存在接收器上，因此您取的名稱會顯示在每個應用程式中。
喇叭預設預設 1 / 2 切換器，只會顯示在提供不只一組預設的接收器上。

聲道 / 重低音電平各聲道與重低音的電平快照，附有步進按鈕，重低音的數量會跟隨您接收器即時的設定。
ECO、睡眠、DRC、修復器、視訊、房間大小、LFE一鍵切換與選擇器，每一項只會在受支援時顯示。
音效控制

音效中的快速切換

  • 圖形等化器：在「音效」、「音訊功能」中開啟或關閉接收器的圖形等化器。只有在 Dirac Live 與 Audyssey 都沒有執行房間校正時才可使用，應用程式與接收器本身的規則一致。
  • 重低音：在「音效」、「音訊功能」中將重低音靜音或啟用，不必深入喇叭設定。只會顯示在能回報並接受此項目的接收器上。
  • 音訊修復器：接收器的壓縮音訊修復功能，Denon 稱為Restorer，Marantz 稱為 M-DAX，在「音效」、「音調」下以開關呈現，就在 DAC 濾波器旁邊。不必跑到螢幕選單，就能讓 MP3 與串流訊源重現生氣。
正在播放 & HEOS

查看並控制正在播放的內容

當使用中的訊源提供中繼資料時，「正在播放」卡片會顯示專輯封面、曲目 / 演出者 / 電台資訊，以及播放控制（播放 / 暫停 / 下一首 / 上一首）。

若要瀏覽音樂，包括電台、佇列、串流服務與 HEOS 房間，請點選「正在播放」卡片上的啟動 HEOS。AVR Maestro 會開啟官方 HEOS 應用程式供您瀏覽；一旦在那裡開始播放，AVR Maestro 就會接手正在播放的顯示畫面、播放控制與小工具。類比、光纖/同軸與 HDMI 直通訊源不會回報中繼資料，因此這些訊源的卡片會保持空白。

常見問題

主畫面常見問題

我可以自訂主畫面嗎？
可以。點選「自訂主畫面」，然後拖曳來重新排序，點選紅色圓圈來移除，按「新增」加入更多小工具，按「重設」恢復預設，按「完成」結束。編輯時卡片會變暗，避免您不小心更動設定。
我可以重新命名分區，包括主分區嗎？
可以，長按主畫面上的分區名稱即可。名稱會寫入接收器本身，因此會顯示在原廠應用程式與其他所有用戶端中，舊款機身也適用。
它會顯示正在播放的內容嗎？
會，只要訊源有提供中繼資料，就會顯示專輯封面、曲目/演出者/電台與播放控制。點選「啟動 HEOS」即可瀏覽；播放一開始，AVR Maestro 就會接手正在播放的顯示畫面。

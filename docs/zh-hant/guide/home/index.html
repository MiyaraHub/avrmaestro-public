主畫面

主畫面：您的大本營，照您的方式呈現

裝置狀態卡片固定在頂端，顯示機型、連線與電源，下方則是可自訂的小工具格狀排列。新增、移除並重新排序卡片，讓主畫面只顯示您真正在意的內容。

打造專屬於您的樣子

幾秒內完成自訂

點選左上角的自訂主畫面圖示以進入編輯模式：

  • 拖曳卡片以重新排序。
  • 點選紅色圓圈來移除卡片。
  • 新增會開啟尚未加入的小工具清單。
  • 重設會恢復預設值；完成則退出。
編輯時卡片會變暗，以免您不小心變更接收器設定。小工具只有在您的接收器提供該功能時才會顯示。全新的主畫面一開始包含 Smart Select / Quick Select、音量、訊源、音效模式、場景、訊號資訊、正在播放與分區。每張卡片的詳細說明請見小工具指南。
多台接收器

從標題切換接收器

連接接收器後，它的名稱會顯示在主畫面頂端的 AVR Maestro 旁。點選它即可看到您新增的所有接收器，選擇其中一台設為使用中，或選擇管理接收器來新增並重新排序（設定 › 管理接收器）。狀態卡片下方的搜尋框可找到應用程式中的任何設定；請參閱搜尋指南、接收器指南與應用程式導覽。

音量預設

八段音量，一點即達

  • 點選空白插槽，即可將目前音量存入其中。
  • 點選已儲存的插槽，即可跳到該音量。
  • 長按任一插槽，即可用目前音量覆寫它，或將它清除。

詳情請見音量指南。

為您的房間命名

是「客廳」，而不是「MAIN ZONE」

在主畫面長按分區名稱即可重新命名任何分區，包括主分區。名稱會寫入接收器本身，而不只是應用程式，因此會顯示在原廠自己的應用程式與其他所有用戶端中，舊款機身也適用。只要命名一次，家中每個控制器對這個房間的稱呼就會一致。

小工具

您可以固定的所有項目

小工具功能
音量附 dB 讀數的滑桿、靜音，以及 8 個已儲存的音量預設（見下方）。
訊源開啟輸入選擇器；長按圖磚可重新排序。已重新命名的訊源，以及您在遙控器輸入格狀畫面設定的自訂輸入圖示，也會顯示在這裡。
音效模式目前的環繞模式；點選可開啟分組的選擇器。
訊號資訊AUDIO IN / AUDIO OUT 與 VIDEO IN / VIDEO OUT（解析度與 HDR）、取樣率，以及接收器回報的其他所有 HDMI 訊號細節，例如色彩空間與像素深度。接收器未回報的讀數會直接省略，而不是顯示為空白。
正在播放HEOS 訊源的專輯封面、曲目資訊與播放控制，附有我的最愛與啟動 HEOS按鈕。詳情請見正在播放與 HEOS 指南。
分區精簡的分區 2 / 分區 3 狀態與快速控制，包含該分區自己的 Smart Select 或 Quick Select 插槽：點選插槽即可叫用，按住則可將該分區目前的狀態存入其中。僅限多分區接收器。
Smart Select / Quick Select您接收器自己的記憶位，名稱與您的接收器一致：Marantz 稱為 Smart Select，Denon 稱為 Quick Select。重新命名的記憶位會儲存在接收器上，因此您取的名稱會顯示在每個應用程式中。
ECO 模式一點即可切換 Auto、On 或 Off。
睡眠計時器Off、30、60、90 或 120 分鐘。
喇叭預設預設 1 / 2 切換器，當您的接收器回報有喇叭預設時顯示。
音訊修復壓縮音訊修復器：Off、Low、Med 或 High，僅在接收器回應時顯示。
場景一點即可叫用已儲存的場景。場景在場景頁面建立。
喇叭配置輸入與輸出的聲道配置，例如 5.1.2。
喇叭網格即時顯示哪些喇叭正在發聲的網格，輸入與輸出並列。僅限提供此資料的接收器；請參閱喇叭指南。
視訊處理視訊模式：Auto、Movie、Game 或 Bypass。
DRC動態範圍壓縮：Auto、Off、Low、Mid 或 High。
Dirac Live 濾波器目前喇叭預設上的 Dirac Live 插槽，附深層連結。僅限 Dirac 接收器。
Audyssey 狀態一眼看到 MultEQ、Dynamic EQ、參考電平偏移、Dynamic Volume、LFC 與抑制量。僅限 Audyssey 接收器。
聲道電平快照顯示接收器回報的每個聲道電平。
重低音電平附減號與加號按鈕的重低音電平調整。在已設定重低音且有音訊訊號時顯示。
音訊延遲音畫同步延遲，0 至 500 ms，當接收器回報時顯示。
LFE 電平LFE 聲道電平，當接收器回報時顯示。
音效控制

音效中的快速切換

  • 圖形等化器：開關位於圖形等化器頁面本身（音效 › 圖形等化器），在標題列的「重設」與「複製」旁。只有在 Dirac Live 與 Audyssey 都沒有執行房間校正時才能編輯頻段；應用程式遵循接收器本身的規則。請參閱圖形等化器指南。
  • 重低音：從音效 › 環繞 › 音訊功能將重低音靜音或啟用，不必進入喇叭設定。僅在接收器回報並接受此設定時顯示。
  • 音訊修復器：接收器的壓縮音訊修復器，Denon 上稱為修復器，Marantz 上稱為 M-DAX，位於音效 › 音調之下。不必進入螢幕選單，就能讓 MP3 與串流訊源重新活起來。
正在播放 & HEOS

查看並控制正在播放的內容

當使用中的訊源提供中繼資料時，「正在播放」卡片會顯示專輯封面、曲目 / 演出者 / 電台資訊，以及播放控制（播放 / 暫停 / 下一首 / 上一首）。

要瀏覽音樂（電台、佇列、串流服務、HEOS 房間），請點選正在播放卡片上的啟動 HEOS。AVR Maestro 會開啟官方 HEOS 應用程式供您瀏覽；一旦在那裡開始播放，AVR Maestro 就會接手正在播放的顯示、播放控制與小工具。類比、光纖/同軸與 HDMI 直通訊源不會回報中繼資料，所以這些訊源的卡片會維持空白。我的最愛按鈕與卡片上的其他一切，請見正在播放與 HEOS 指南。

常見問題

主畫面常見問題

我可以自訂主畫面嗎？
可以。點選「自訂主畫面」，然後拖曳來重新排序，點選紅色圓圈來移除，按「新增」加入更多小工具，按「重設」恢復預設，按「完成」結束。編輯時卡片會變暗，避免您不小心更動設定。
我可以重新命名分區，包括主分區嗎？
可以，長按主畫面上的分區名稱即可。名稱會寫入接收器本身，因此會顯示在原廠應用程式與其他所有用戶端中，舊款機身也適用。
我可以從主畫面切換接收器嗎？
可以。點選頂端 AVR Maestro 旁的接收器名稱並選擇另一台接收器，或選擇「管理接收器」來新增或重新排序。
它會顯示正在播放的內容嗎？
會，只要訊源有提供中繼資料，就會顯示專輯封面、曲目/演出者/電台與播放控制。點選「啟動 HEOS」即可瀏覽；播放一開始，AVR Maestro 就會接手正在播放的顯示畫面。

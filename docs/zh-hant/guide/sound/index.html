音效分頁

接收器擁有的每一項音訊控制，盡在一個音效分頁

音效分頁最多有十個頁面，它反映的是接收器自己的音訊選單，而不是簡化版本。本頁逐一介紹：每個控制項的作用、它的要求，以及接收器有時為何不讓您操作它。

這裡有什麼

十個頁面

開啟螢幕底部的音效分頁。頁面橫向排列在頂端；點選頁面名稱或左右滑動即可在其間切換。

頁面控制的內容

哪些頁面會出現由您的接收器決定。沒有 Auro-3D 的機型就沒有 Auro-3D 頁面，沒有 IMAX Enhanced 解碼器的機型就沒有 IMAX 頁面，而聲場頁面只有在播放 Dolby Surround、DTS Neural:X 或 Auro 模式時才會出現。您也可以隱藏從不使用的頁面：設定 › 自訂分頁，然後關閉不想要的頁面。此選擇適用於所有接收器。
第一頁

環繞：選擇音效模式並切換音訊功能

最上方的卡片會依接收器的回報，原樣顯示目前模式。其下方的模式分為電影、音樂、遊戲與純淨，而且只列出接收器針對目前正在解碼的訊號所提供的模式。

  1. 點選一個類別：電影、音樂、遊戲或純淨。
  2. 點選一種模式，例如 Dolby Surround 或 DTS Neural:X。圖磚會亮起，目前模式卡片也會隨之改變。
  3. 如果圖磚看起來是啟用的但沒有任何反應，表示音訊與模式不符：Dolby 選項需要 Dolby 內容，DTS 選項需要 DTS。

音訊功能

在模式清單下方，音訊功能卡片包含您可以變更的開關。每一列都會顯示作用中或未作用；點選膠囊即可開啟或關閉該功能。顯示 N/A 的列表示無法在目前的模式或訊號下使用：點選它的問號，應用程式就會告訴您它需要什麼。

  • Neural:X - 在可使用它的模式中顯示；需要 DTS:X 環繞模式。
  • IMAX Enhanced - 限具備 IMAX 的接收器。IMAX 待命時，開啟的膠囊顯示Auto；接收器偵測到 IMAX 編碼串流後則顯示作用中。
  • 影院等化 - 在 Direct、Pure Direct、Stereo 與 Original Sound 模式下無法使用。
  • 中央擴展 - 僅限 Dolby Surround 音效模式。
  • 響度管理 - 需要 Dolby Digital、Dolby Digital Plus、Dolby TrueHD 或 Dolby Atmos 訊號。
  • 喇叭虛擬化 - 限回報此功能的接收器；需要 Dolby Atmos、Dolby Surround 或「+Dolby Surround」模式。
  • LFE 電平 - 僅在接收器於目前音效模式下提供時顯示。使用減號與加號在接收器回報的範圍內逐步調整。當接收器顯示 LFE 電平但目前不允許變更時，該列會說明原因，而不是顯示數字。
  • 重低音 - 在已設定重低音且允許此操作的接收器上，開啟或關閉重低音輸出。

重低音電平調整

在頁面底部，重低音電平卡片（有多個重低音時為重低音 1 電平、重低音 2 電平，依此類推）是接收器依訊源分別保存的播放偏移。它疊加在您校正過的重低音電平之上，並不會改變它。點選減號或加號逐步調整；步進為 0.5 dB 或 1 dB，依接收器而定。目前訊源沒有音訊訊號時，這張卡片會隱藏。

第二頁

對白與 DRC：更清楚的人聲與夜間聆聽

  • 對白增強 - Off、Low、Medium 或 High。讓人聲更容易聽清楚，而不影響您的校正。
  • 中央電平調整 - 在較舊的接收器（X4500H 與 SR7015 等級）上，這取代了對白增強。它是套用於每個訊源與 Quick Preset 的絕對中央喇叭電平，範圍為 -12.0 至 +12.0 dB，以 0.5 dB 為單位。點選減號或加號變更，或點選中間按鈕回到 0 dB。較新的接收器，例如 Cinema 30，沒有這項功能。
  • 動態範圍壓縮 - Off、Low、Mid、High 或 Auto。縮小耳語與爆炸聲之間的差距，這正是深夜所需要的。

壓縮資料是攜帶在 Dolby 位元串流內的，所以在 PCM、DTS 或網路立體聲訊源上沒有可壓縮的內容。為了避免讓您按一個不起作用的按鈕，應用程式會將該列變灰並說明原因：請播放 Dolby Digital、Dolby Digital Plus、Dolby TrueHD 或 Dolby Atmos 內容來使用它。

第三頁

Audyssey：完整的校正選單，不只是 MultEQ

  • MultEQ - Reference、Bypass LR、Flat 或 Off。Reference 是校正後的標準曲線；Flat 移除高頻衰減；Bypass LR 讓前置左右喇叭不經修正；Off 關閉房間校正，其下方的控制項也會變暗。
  • Dynamic EQ - 開啟或關閉。音量調小時仍能維持正確的音色平衡，不會讓低音變得單薄。
  • 參考電平偏移 - 0、5、10 或 15 dB。告訴 Dynamic EQ 您的內容母帶比參考電平低多少。0 dB 適合電影；較高的偏移值適合音樂與電視節目。
  • Dynamic Volume - Off、Light、Medium 或 Heavy。平衡吵鬧的廣告與安靜的對白。
  • 環繞電平補償 - 關閉、輕、中或重。
  • Audyssey LFC - On 或 Off。Low Frequency Containment 讓深沉的低音不會傳到鄰近的房間。
  • 抑制量 - 減號與加號設定 LFC 的作用強度。它只在 Audyssey LFC 開啟時才有反應；在那之前，頁面會顯示「請先在上方啟用 Audyssey LFC，才能調整抑制量。」

右上角的圓形重新整理按鈕（重新查詢校正狀態）會再次詢問接收器，目前的喇叭預設使用哪種校正。如果您在接收器本身切換預設後，頁面仍然顯示橫幅，請使用它。

您可能會看到橫幅而不是控制項：此喇叭預設沒有 Audyssey 校正、Audyssey 在此喇叭預設中未作用，或Dirac 擁有此喇叭預設 - Audyssey 無法使用。每一則都是接收器自己的狀態。請參閱控制項為何鎖定。
第四頁

Dirac Live：以您自己取的名稱列出濾波器

如果您執行過 Dirac Live，匯出的濾波器會存放在接收器上有編號的插槽中。AVR Maestro 會以您儲存時取的名稱列出它們，下方附上插槽編號，並提供一個關閉選項，讓預設完全不套用任何濾波器。只要點一下就能切換濾波器。

在由 Audyssey 擁有的喇叭預設上，頁面會顯示Audyssey 擁有此喇叭預設 - Dirac 無法使用，而不是顯示空白清單。重新整理按鈕（重新查詢 Dirac 插槽資訊）會再次讀取插槽。

第五頁

圖形等化器：九個頻段，每支喇叭各自調整

一個真正的編輯器：頁面頂端、「重設」與「複製」旁的開/關開關可開啟或關閉圖形等化器，並在圖表上拖曳從 63Hz 到 16kHz、-20 至 +6 dB 的九個頻段。選擇全部、左/右或個別喇叭，使用複製從您量測到的 Audyssey 曲線開始，使用重設歸為平直，並用待處理變更列來套用。

接收器執行房間校正或手動等化器，兩者不會同時作用，因此只要 MultEQ 或 Dirac 正在執行，此頁面就會鎖定，並指出是哪一個。

第六頁

聲道：電影播放中也能微調任何一支喇叭

目前訊號中每支喇叭的各聲道微調（dB）：前置左、前置右、中央、環繞、環繞後置、重低音與增高層，每個下方都附有簡稱，不必猜哪個是哪個。

  • 拖曳滑桿可大幅調整，或點選加號與減號進行單次微調，聆聽的同時都能操作。
  • 全部重設會將所有聲道恢復為 0 dB。
  • 多重低音輸出 - 設定了多個重低音時，會有一張卡片告訴您有幾個；請在聲道清單中微調每一個（SW、SW2 等）。
  • Bass Sync - 重低音延遲微調，0 至 16 ms。點選減號或加號，讓重低音與主喇叭在時間上對齊。在具備此功能的接收器上顯示。
  • 觸覺震動器 - 限接收器自己的選單中有顯示的機型：啟用開關、從 -12 到 +12 dB 以 0.5 dB 為單位的電平，以及從 40 到 250 Hz 的低通濾波器。

多聲道音訊播放時才會顯示聲道電平。Dirac Live 濾波器作用期間，接收器會將它們鎖定，頁面也會說明。這些是即時依訊號的微調；儲存在喇叭預設中、依喇叭設定的參考電平則在喇叭分頁。

第七頁

音調：低音、高音、DAC 濾波器與 M-DAX

  • 音調控制 - 總開關。只有在它開啟時，低音與高音才會傳到接收器。
  • 低音與高音 - -6 dB 至 +6 dB，每次調整 1 dB。
  • DAC 濾波器 - 濾波器 1 聲音較溫暖，衰減緩慢；濾波器 2 則是較銳利的參考響應。
  • 音訊修復器（M-DAX） - Off、Low、Med 或 High。重建因壓縮或串流音訊而流失的細節，這對低位元率串流很有用，但不適合用在無損光碟。
只有 Dynamic EQ 會停用音調控制。它開啟時，頁面會顯示音調控制已被 DYNAMIC EQ 鎖定。要使用低音與高音，請在 Audyssey 頁面關閉 Dynamic EQ，或將 MultEQ 設為 Off，這也會一併關閉 Dynamic EQ。
第八頁

聲場：調整 Dolby Surround 與 Neural:X 升混器

這些控制項決定升混器如何將聲音散布到房間各處。它們在 Dolby Surround 或 DTS Neural:X 作用時才適用，所以聲場頁面只有在其中一種模式（或 Auro 模式）播放時才會出現。請先在環繞頁面切換到其中一種。

  • 房間大小 - Small、Med-S、Medium、Med-L 或 Large。
  • 全景聲 - On 或 Off。透過將主喇叭的聲音混合到中央來加寬前方聲場。僅在 Dolby Surround 模式下聽得到。
  • 縱深感 - 減號與加號將聲場往前或往後移動（Dolby Surround）。
  • 中央寬度 - 減號與加號將中央聲道的人聲向左右主喇叭擴展。
只會顯示您的接收器支援的列。縱深感與中央寬度是以步進傳送的，接收器不會回報它們的位置，所以畫面上的數字是從您開啟頁面起累計的步數。如果需要確切數值，請觀察接收器的螢幕顯示。
第九頁

IMAX：完整的 Enhanced 設定選單

在支援 IMAX Enhanced 的機型上，App 會提供完整選單，而不只是開與關：

  • IMAX 模式 - 自動或關閉。
  • 音訊設定 - Auto 遵循 IMAX 建議；Manual 則開啟下方的控制項。
  • 高通濾波器（HPF） - 40Hz 到 250Hz。
  • 低通濾波器（LPF） - 最高 250Hz；最低的步進依接收器型號而定。
  • 重低音 - 開啟或關閉，以及重低音輸出 - LFE+主聲道或 LFE。
第十頁

Auro-3D：有型有款的升混

  • Auromatic 3D 預設 - 小、中、大、語音或電影。選擇升混器所針對的空間與內容特性。
  • 強度 - Auromatic 產生多少高度資訊。減號與加號在接收器回報的範圍內逐步調整，範圍會印在數值下方。
  • Auro-3D 模式 - Direct 或聲道擴展。

這些設定只在環繞聲頁面選擇了 Auro 模式時才會生效，而且只有配備 Auro-3D 解碼器的機型才會有此頁面。

常見問題

音效分頁常見問題

為什麼音效模式的清單會變動？
因為接收器的清單本來就會變動。Denon 或 Marantz 能接受的模式，取決於它正在解碼的內容：雙聲道串流會提供升混模式，Atmos 串流則提供支援 Atmos 的模式。AVR Maestro 每次都會直接從接收器讀取目前的清單，而不是顯示一份固定選單，因為那樣有一半的時間都會是錯的。
為什麼某個控制項顯示為灰色並標示 N/A？
N/A 表示接收器在目前狀態下無法使用該功能，通常是因為輸入訊號或音效模式不帶有它。點選該列旁的問號，應用程式會說明它需要什麼。灰色的控制項絕不是被隱藏的錯誤，而是接收器自己的答覆。
為什麼我看不到聲場頁面？
聲場頁面只有在播放 Dolby Surround、DTS Neural:X 或 Auro 模式時才會出現，而且僅限至少具備其中一項控制的接收器。請在環繞頁面選擇其中一種模式，聲場頁面就會出現。另外請檢查您是否在「設定 › 自訂分頁」中隱藏了它。
「聲道」與「電平」有什麼差別？
「聲道」（音效分頁）是針對目前正在播放的訊號所做的即時各聲道微調。「電平」（喇叭分頁）則是儲存在喇叭預設上、由您的校正所決定的各喇叭參考電平。調整「聲道」不會改寫您的校正結果。
我可以同時使用音調控制與 Audyssey 嗎？
Dynamic EQ 開啟時不行，因為接收器會接管音調控制。請在 Audyssey 頁面關閉 Dynamic EQ，或將 MultEQ 設為 Off，低音與高音就可以再次編輯。
我需要在同一個網路上嗎？
可以。AVR Maestro 透過區域網路直接與您的接收器溝通，不需要雲端帳號，中間也沒有任何中繼伺服器。請參閱開始使用。

設定

設定：打造專屬於您的應用程式

所有讓 AVR Maestro 貼合您與您設備的設定：管理接收器、用「色彩主題」為整個應用程式換上主題、調整音量間距、取得供支援使用的偵錯記錄，並把整套設定備份到檔案。

每個區塊

「設定」裡有什麼

區塊內容
裝置切換接收器、完整的裝置資訊、管理接收器（重新命名 / 刪除）、新增接收器。
接收器遙控器鎖定：從應用程式鎖定或解除鎖定接收器自己的實體紅外線遙控器。只會顯示在支援此功能的接收器上。
外觀主題（淺色 / 深色 / 跟隨裝置 / AMOLED 純黑）與色彩主題：從色環選擇任何強調色，或輸入像 #FF8C00 這樣的十六進位色碼，應用程式就會圍繞它重新建立配色。無法讀取的色碼會被拒絕並說明原因，太接近黑色的顏色也會被另外拒絕，因為在 AMOLED 主題上，它會沒有可襯托的對象。另外還有顯示大小、小工具大小、自訂導覽與自訂分頁。
語言系統預設會跟隨裝置；其下是 29 種語言，每種都以自己的名稱顯示。語言指南 →
音訊音量間距（0.5-2.0 dB），每次點按、按住漸進調整與音量按鈕都會使用；頂端要顯示絕對音量還是 dB；裝置音量按鈕（預設開啟，適用於 Android 與 iOS）；以及漸進與 Direct 音量預設：漸進（預設）會平順地逐步調整到預設的目標值，而不是直接跳過去，適用於主分區與分區 2/3。

應用程式之外

主畫面小工具與裝置音量按鈕

  • 主畫面小工具（iOS 與 Android）：快速控制（電源 / 音量 / 靜音 / 訊源）、正在播放與狀態，提供多種大小，只需點按並自動重新整理。當接收器關閉或無法連上時，小工具會顯示清楚的「AVR 關閉」/「待機」狀態，而不是過時的輸入與音量，而且電源按鈕仍然可用，讓您直接從小工具喚醒接收器。
  • 裝置音量按鈕（Android 與 iOS）：當 AVR Maestro 位於前景時，裝置的實體音量按鈕會控制接收器的音量（採用您的音量間距），按住則會漸進調整。僅限前景使用；一旦應用程式被其他應用程式蓋住，按鈕就會立刻回到控制裝置本身，而「設定」「音訊」下的開關可以關閉這項接管功能。
小工具、主題、備份 & 還原，以及音量按鈕接管，在 iOS 與 Android 上都能使用。
常見問題

設定常見問題

我可以變更應用程式的主題與顏色嗎？
可以。提供淺色、深色、跟隨裝置或 AMOLED（純黑），另有「色彩主題」可讓您選擇任何強調色，應用程式會重新建立整套配色。您可以使用色環，或輸入十六進位色碼（#FF8C00，或三個字元的簡寫）。如果色碼有誤，應用程式會告訴您錯在哪裡，而不是單純拒絕。您也可以設定顯示 / 小工具大小，並自訂導覽與分頁。
我可以備份我的設定嗎？
可以。「設定」中的「備份」會把每台接收器、預設與偏好設定匯出為 .zip 檔案，其中也包含您的自訂輸入圖示；在新手機上匯入即可還原。舊的 .json 備份仍然可以正常匯入。檔案中不含任何憑證，所以可以放心分享。
音量預設是直接跳到目標，還是漸進調整過去？
由您決定。「設定」的「音訊」中有「漸進 / Direct」開關。漸進（預設）會平順地逐步調整到預設的目標值，所以點一下絕不會讓喇叭突然爆出聲響。Direct 則會立即套用。適用於主分區與分區 2/3。
我可以從應用程式鎖定接收器的實體遙控器嗎？
可以，適用於支援此功能的接收器。「設定」的「接收器」中有「遙控器鎖定」開關，可鎖定或解除鎖定接收器自己的紅外線遙控器。
主畫面小工具只有 Android 才有嗎？
不是。快速控制（電源 / 音量 / 靜音 / 訊源）、正在播放與狀態小工具在 iOS 與 Android 上都有。當接收器關閉或無法連上時，它們會顯示清楚的「AVR 關閉」/「待機」狀態，而不是過時的資料，而且快速控制的電源按鈕仍然可用，讓您能直接從小工具喚醒接收器。
手機的音量鍵可以控制接收器嗎？
在 Android 上可以。應用程式位於前景時，您的音量鍵會控制接收器的音量。iOS 不允許這項功能。
我要怎麼開啟隱藏的偵錯選單？
開啟「設定」，進入「關於」，然後連續點七下版本號碼。之後偵錯選單會在每次啟動時持續可用，其中包含即時偵錯記錄、原始指令工具與供支援使用的診斷功能，直到您點選「移除偵錯選單」再次將它隱藏為止。
「更多 MiyaraHub 作品」是什麼？
「設定」中的一個區塊，內有瀏覽我們所有的應用程式按鈕。點一下，您的應用程式商店就會開啟 MiyaraHub 開發者頁面，視您的裝置而定，可能是 Google Play、App Store 或 Microsoft Store，讓您瀏覽我們製作的每一款應用程式。

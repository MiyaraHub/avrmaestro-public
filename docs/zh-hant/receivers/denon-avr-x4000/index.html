Denon AVR-X4000 遙控 App：用手機控制它

AVR-X4000 是較早世代的 Denon 接收器。AVR Maestro 使用該接收器能理解的指令，從手機控制它，並隱藏它無法回應的控制項。不需要雲端帳號、不需要訂閱、沒有廣告。

AVR-X4000 能做的一切

Denon AVR-X4000 上可用的功能

在 Denon AVR-X4000 上，AVR Maestro 可控制電源、輸入、接收器回報的環繞模式、Audyssey MultEQ、音調與聲道電平。瀏覽網路收音機與媒體伺服器選單，以及喇叭配置尚未提供。

此接收器尚未提供配置、距離與分頻。聲道電平可在「音效」分頁中調整。

資訊、設定、選項與返回鍵在此接收器上尚無作用。電源、輸入與系統鍵則可使用。

依指令清單實作

分區 2、分區 3、我的最愛、調諧器、HD Radio 與場景依照 Denon 的指令清單實作，尚未在實體 AVR-X4000 上確認。

AVR-X4000 早於現代 Denon 協定，因此 AVR Maestro 只讀取接收機自身回報的內容，並僅提供這些控制項。由於該機型無法回應，Bluetooth、Loudness 和影院等化不會顯示。它也沒有多房間喇叭控制。
常見問題

Denon AVR-X4000 + AVR Maestro

有可以控制 Denon AVR-X4000 的 App 嗎？
可以，但有限度。AVR Maestro 透過網路控制 AVR-X4000：電源、輸入、環繞模式、Audyssey、音調與聲道電平皆可使用。瀏覽網路收音機選單與喇叭配置尚未提供。
需要雲端帳號嗎？
不需要 - 它直接透過你的區域網路與 AVR-X4000 通訊。不需要雲端帳號、不需要訂閱，也不需要額外硬體。
要如何連線？
在 AVR-X4000 上啟用網路控制，然後開啟「新增接收器」並在清單中點選它（若沒有任何回應，則輸入其 IP 位址）。完整步驟請見入門指南。

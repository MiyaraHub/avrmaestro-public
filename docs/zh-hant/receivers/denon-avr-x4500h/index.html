AVR-X4500H 能做的一切

Denon AVR-X4500H 上可用的功能

在 Denon AVR-X4500H 上，AVR Maestro 可控制接收器回報的環繞模式、Audyssey MultEQ 校正、喇叭預設與聲道電平（包含中央電平調整）、一鍵場景、分區 2 與分區 3，以及附預設電台的 FM/AM 調諧器。

所有環繞模式

Dolby Atmos、DTS:X、Auro-3D 與各種升混模式，並即時顯示目前的模式與聲道。

Audyssey 與校正

切換 Audyssey MultEQ 曲線、Dynamic EQ 與 Dynamic Volume，並跟隨目前使用的喇叭預設。

喇叭預設 & 電平

完整的配置、距離、聲道電平與分頻設定，並隨目前的喇叭預設而變動。

一鍵場景

儲存 AVR-X4500H 的完整狀態：輸入、模式、校正、分區、調諧器，並可立即還原。

多分區

獨立控制分區 2 / 分區 3 的電源、輸入與音量，打造全屋音響。

調諧器

附預設電台的 FM/AM 調諧器。

AVR-X4500H 的功能集會在連線時從接收器讀取。AVR Maestro 只顯示接收器開放的內容，因此你能使用它的完整功能，而且不會有無用的按鈕。
常見問題

Denon AVR-X4500H + AVR Maestro

有可以控制 Denon AVR-X4500H 的 App 嗎？
有 - AVR Maestro 是 AVR-X4500H 的付費第三方控制器。透過你的網路，它可控制環繞模式、Audyssey MultEQ、喇叭預設、電平、多分區、調諧器與一鍵場景。
需要雲端帳號嗎？
不需要 - 它直接透過你的區域網路與 AVR-X4500H 通訊。不需要雲端帳號、不需要訂閱，也不需要額外硬體。
要如何連線？
在 AVR-X4500H 上啟用網路控制，然後開啟「新增接收器」並在清單中點選它（若沒有任何回應，則輸入其 IP 位址）。完整步驟請見入門指南。

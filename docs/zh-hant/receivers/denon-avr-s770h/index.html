常見問題

Denon AVR-S770H + AVR Maestro

有可以控制 Denon AVR-S770H 的應用程式嗎？
有。AVR Maestro 是 AVR-S770H 的高階第三方控制器。透過網路即可控制環繞模式、Audyssey MultEQ、喇叭預設、音量電平、多分區、調諧器，以及一鍵場景。
AVR-S770H 在應用程式中支援 Dirac Live 嗎？
Denon AVR-S770H 採用 Audyssey MultEQ，不支援 Dirac Live，這是此機種的硬體限制，與應用程式無關。AVR Maestro 能從手機即時控制 S770H 上的 Audyssey MultEQ、Dynamic EQ、Dynamic Volume 與 LFC。請參閱 Audyssey & Dirac 指南。
需要雲端帳號嗎？
不需要，它直接透過您的區域網路與 AVR-S770H 通訊。不需要雲端帳號、訂閱或額外硬體。
要如何連線？
請在 AVR-S770H 上啟用網路控制，然後開啟「新增接收器」，並在清單中點選它（若沒有任何回應，請輸入其 IP 位址）。完整步驟請見入門指南。

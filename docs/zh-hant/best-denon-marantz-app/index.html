Denon & Marantz 接收器的最佳控制應用程式

用戶為何轉用

官方應用程式沒有提供的功能

如果您有一台具備網路功能的 Denon 或 Marantz 接收器，它的硬體能做的事遠比原廠應用程式讓您使用的多。AVR Maestro 填補了這個落差，還加入自己的特色：直接在接收器上重新命名分區、輸入與 Smart Select / Quick Select 預設，用您自己的圖片為輸入設定自訂圖示，在 iOS 與 Android 主畫面釘選小工具，並依您的喜好為整個應用程式換上主題。

⚡

快速又穩定

透過接收器的原生通訊協定直接控制網路連線，沒有卡頓的選單，不會斷線，也不會每次開啟都出現「重新連線中」的轉圈圈。

🎬

一鍵場景

儲存整組設定，包括輸入、音量、音效模式、Audyssey/Dirac、喇叭預設、分區，甚至調諧器，只要點一下就能全部叫用。官方應用程式完全沒有這種功能。

🎚️

Audyssey & Dirac Live

直接在應用程式中讀取並切換 Audyssey MultEQ 曲線與 Dirac Live 插槽，不必再翻找接收器的螢幕選單。

🔊

喇叭預設 & 電平

完整的喇叭預設控制、聲道電平微調與分頻設定，這些深入的設定正是原廠應用程式沒有提供的。

🏠

真正的多分區

獨立控制分區 2 與分區 3 的訊源、音量與電源，而不是其他應用程式那種可有可無的附屬功能。

📻

FM/AM 調諧器

在具備調諧器的接收器上，提供完整的調諧器介面與預設電台，這也是官方應用程式沒有做的功能。

有比 Denon 或 Marantz 官方應用程式更好的選擇嗎？
許多用戶改用 AVR Maestro。它使用接收器的原生通訊協定透過網路連線，反應即時，並提供官方應用程式藏得很深或根本沒有的控制功能，包括一鍵場景、完整的 Audyssey 與 Dirac Live、多分區、喇叭預設，以及 FM/AM 調諧器。
AVR Maestro 能搭配我的接收器使用嗎？
支援具備網路功能的 Denon 與 Marantz AV 接收器，包括 Marantz Cinema 30/40/50/60 系列，以及 Denon AVR-A1H、X3800H、X4800H、X6800H 與 AVR-S770H/S970H。無需雲端帳號或額外硬體，只要與接收器連上同一個 Wi-Fi 或區域網路即可。
免費嗎？有廣告或訂閱嗎？
一次買斷，沒有廣告，也沒有訂閱，您接收器的設定絕不會離開您的網路。可在 Google Play、App Store 與 Microsoft Store 取得。
可以控制 Audyssey 與 Dirac Live 嗎？
可以。在提供這些功能的接收器上，AVR Maestro 可直接讀取並切換 Audyssey MultEQ 曲線與 Dirac Live 插槽，同時支援環繞模式、聲道電平、喇叭預設與多分區控制。

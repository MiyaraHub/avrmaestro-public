连接

建立连接

“测试连接”失败
请确保手机和接收机处于同一个 Wi-Fi 网络和子网中，Mesh 系统、访客网络和 IoT VLAN 可能会隔离设备。在接收机上，Setup → Network → Network Control 必须设为 On。请对照接收机自己的 Network → Information 页面重新核对 IP，因为 DHCP 地址会变化。HTTP 是必需的；Telnet 和 HEOS 有则更好。如果接收机可以访问，但其网络堆栈已饱和（连接数被太多控制器应用占满），应用会用明确的网络繁忙消息告知，而不是给出笼统的失败提示；请关闭其他控制器，或稍等几秒。完整步骤请见快速入门指南。
连接每隔几秒就断开
接收机的 Telnet 端口在长时间运行后可能会卡住，请从墙上电源处给接收机断电重启以清除监听器。在 Wi-Fi 6 Mesh 网络上，请强制手机与接收机使用同一频段（AVR 通常位于 2.4 GHz，而手机更倾向于 5 GHz）。
我如何知道我的接收机是否受支持？
这取决于您的网络，而不只是型号。如果接收机的网页门户、HEOS 应用和 Denon/Marantz 官方应用都能连上它，AVR Maestro 也应该可以。请参阅支持的接收机页面。
控制 & 显示

为什么看起来不对劲

音量读数似乎不对
接收机报告的音量有绝对值 (0-98) 和相对值 (-80 至 +18 dB) 两种。应用两种都能处理；如果您最近更改了接收机的音量显示设置，请重启应用以重新读取刻度。您可以在设置 → 音频中切换优先显示哪个数值。
声音模式或功能标签置灰 / 显示“N/A”
环绕声模式和功能受输入源的音频格式和当前声音模式限制，例如 2 声道音源无法启用 Dolby Atmos。这是接收机的行为，而非应用的问题。点按 N/A 标签旁边的 (?)，即可查看具体要求。
缺少一些声音或扬声器标签页
标签页会根据机型和模式变化。Audyssey、Dirac Live、IMAX、Auro-3D、Surround Shape、距离和分频，只会出现在支持这些功能的接收机上。请查看设置 → 设备 → 设备信息，了解应用检测到的内容，或从设置 → 自定义标签页 / 自定义导航中重新添加被隐藏的标签页。
没有显示电台标签页
电台受功能限制：只有内置 FM/AM 调谐器的接收机才会出现。如果您的接收机有调谐器但标签页被隐藏，请确认调谐器已作为输入源出现在接收机上，并在设置 → 自定义导航中重新启用。请参阅电台指南。
正在播放卡片是空白的
当前输入源不提供元数据：模拟、光纤/同轴以及大多数 HDMI 直通音源都不会报告曲目信息。对于 HEOS 音源，请点按启动 HEOS 开始播放，然后返回，元数据就会显示出来。
主屏幕小组件显示“AVR off”或“Standby”
这是小组件的关闭状态，并非故障。当接收机关机、处于待机或无法访问时，小组件（iOS 和 Android）会显示“AVR off” / “Standby”，而不是上次的输入源和音量，这样您就不会看到过时的数据。在 Quick Control 小组件上，该状态下音量和静音按钮会隐藏，但电源按钮仍然可用，点按它即可直接从小组件唤醒接收机（接收机上必须启用 Network Standby）。
有些扬声器页面会在接收机的网页控制中打开
在一些 2025 年之前的接收机上（X4500H / X6700H / S960H / X4700H 这一类），接收机无法向应用提供扬声器布局或低音炮输出页面，因此 AVR Maestro 会给您一个一键按钮，进入接收机自带的网页控制来完成这些编辑。其他功能均正常；固件较新的接收机可在应用中提供所有页面。

帮助 & 故障排除

解决常见的 Denon 和 Marantz 应用问题

针对最常见问题的快速解决办法。如果仍然无法解决，请从设置 › 关于 AVR Maestro › 所有相关日志向我们发送日志，这是获得支持的最快方式 - 请在 Discord 或 Facebook 支持小组联系开发者，回复很快。

连接

建立连接

“测试连接”失败
请确保手机和接收机处于同一个 Wi-Fi 网络和子网中，Mesh 系统、访客网络和 IoT VLAN 可能会隔离设备。在接收机上，Setup → Network → Network Control 必须设为 On。请对照接收机自己的 Network → Information 页面重新核对 IP，因为 DHCP 地址会变化。HTTP 是必需的；Telnet 和 HEOS 有则更好。如果接收机可以访问，但其网络堆栈已饱和（连接数被太多控制器应用占满），应用会用明确的网络繁忙消息告知，而不是给出笼统的失败提示；请关闭其他控制器，或稍等几秒。完整步骤请见快速入门指南。
连接每隔几秒就断开
接收机的 Telnet 端口在长时间运行后可能会卡住，请从墙上电源处给接收机断电重启以清除监听器。在 Wi-Fi 6 Mesh 网络上，请强制手机与接收机使用同一频段（AVR 通常位于 2.4 GHz，而手机更倾向于 5 GHz）。
我如何知道我的接收机是否受支持？
这取决于您的网络，而不只是型号。如果接收机的网页门户、HEOS 应用和 Denon/Marantz 官方应用都能连上它，AVR Maestro 也应该可以。请参阅支持的接收机页面。
控制 & 显示

为什么看起来不对劲

音量读数似乎不对
音量可以用两种刻度显示：0-98 刻度，或从 -80 到 +18 dB 的分贝刻度。两者描述的是同一个音量。在设置 › 管理接收机 › 您的接收机 › 音频中，在顶部显示绝对音量选择哪一个作为大数字，遥控音量显示选择遥控标签页使用的刻度。参见音量指南。
声音模式或功能标签置灰 / 显示“N/A”
环绕声模式和功能受输入源的音频格式和当前声音模式限制 - 2 声道音源无法启用 Dolby Atmos。这是接收机的行为，而不是应用的。锁定控件指南说明了控件为何被锁定以及如何解锁。
缺少一些声音或扬声器标签页
标签页会感知机型和模式。Audyssey、Dirac Live、IMAX、Auro-3D、环绕声形状、距离和分频仅在提供它们的接收机上出现。请查看设置 › 管理接收机 › 您的接收机 › 设备信息，了解应用检测到了什么。您关闭的子标签页可从设置 › 自定义标签页恢复，底部标签页则从设置 › 自定义导航恢复。参见导航指南。
没有显示电台标签页
收音机取决于接收机功能：它只在带内置 FM/AM 调谐器的接收机上出现。如果您的接收机有调谐器但标签页被隐藏，请确认调谐器作为输入源出现在接收机上，并从设置 › 自定义导航重新启用它。参见收音机指南。
正在播放卡片是空白的
当前输入源不提供元数据：模拟、光纤/同轴以及大多数 HDMI 直通音源都不会报告曲目信息。对于 HEOS 音源，请点按启动 HEOS 开始播放，然后返回，元数据就会显示出来。
主屏幕小组件显示“AVR off”或“Standby”
这是小组件的关闭状态，不是故障。当接收机处于待机时，快速控制和状态小组件（iOS 和 Android）显示“待机”；无法连接时显示“AVR 已关闭”，而不是上一次的输入源和音量，因此您永远不会读到过时的数据。在 Android 上，该状态下快速控制的音量和静音按钮会隐藏，但电源按钮保持可用 - 轻点它即可直接从小组件唤醒接收机（接收机上必须启用网络待机）。参见小组件指南。
有些扬声器页面会在接收机的网页控制中打开
某些 Denon 和 Marantz 固件不会向应用返回扬声器布局、扬声器距离或扬声器分频。此时页面会说明这一点，并提供重试和一个在接收机自己的网页控制中打开该屏幕的按钮。如果您从不使用它，请在设置 › 自定义标签页中隐藏该标签页。如果接收机的网页控制页面在浏览器中打开着，请先将其关闭，因为它可能让接收机一直处于忙碌状态。
场景没有完全应用
接收机可能拒绝当前输入源、信号或声音模式不允许的设置。场景指南在“场景没有完全应用时”一节说明了需要检查什么。
支持

获取帮助并发送日志

所有支持相关内容都在设置 › 关于 AVR Maestro的支持与社区下。

  • Discord 社区：加入 MiyaraHub 社区，直接向开发者提问。
  • Facebook 支持小组：AVR Maestro 用户交流与问答。
  • 所有相关日志：所有应用和接收机日志打包在一个 zip 文件中，可直接发送给我们。
  1. 连接到出现问题的接收机，如果可以，请让问题出现一次。
  2. 打开设置 › 关于 AVR Maestro，找到所有相关日志。
  3. 轻点下载保存 zip，轻点分享用任意应用发送，或轻点电子邮件将其附加到邮件中。运行期间，应用会显示它正在收集什么以及进度如何。
  4. 请在 Discord 或 Facebook 小组中把 zip 发给我们，并简要描述出了什么问题。
zip 包含应用的调试日志和应用从您的接收机读取的内容，例如其设备信息和功能。如果您的设备没有电子邮件应用，电子邮件会改为打开分享面板。

还是没解决？我们很快就能帮到您

请从设置 › 关于 AVR Maestro 发送所有相关日志，并在 Discord 或 Facebook 联系开发者 - 回复很快。

多房间

多房间：分组、主房间、队列与音乐

在支持多房间的接收机上，AVR Maestro 会列出所有扬声器，让您对其分组与取消分组，为分组设置统一音量，并为其浏览、搜索和排队播放音乐。本指南将逐一介绍界面的每个部分。

界面

一个界面管理所有扬声器

  • 打开方式：在主屏幕的多房间卡片上点按打开，或从导航进入。标题为多房间。
  • 分组卡片位于顶部。每张卡片显示分组名称、正在播放的内容、上一首 / 播放 / 下一首、静音按钮、整个分组的统一音量滑块以及队列摘要。
  • 未分组列出所有独立的扬声器，每个都带有设备选项按钮。
  • 应用查找扬声器时会显示正在查找扬声器。若连接中断，会提示多房间连接已断开，正在重新连接。，并在恢复前显示最后已知的分组。
音量

分组音量与扬声器音量

  • 大滑块是分组音量。移动它，所有成员会一起变化。
  • 点按扬声器音量可展开每位成员各自的滑块，并带有独立静音。用它来平衡安静的房间与嘈杂的房间。
  • 被静音的扬声器会显示取消静音，音量读数为 0%。
播放

正在播放，附专辑封面

  • 卡片会实时显示分组正在播放内容的专辑封面、标题和艺术家。没有播放内容时显示未在播放。
  • 上一首、播放或暂停和下一首控制整个分组。
分组

创建、编辑和取消分组

  • 创建分组：点按它，勾选两个或更多扬声器（在勾选之前，面板会显示请至少选择两个扬声器），然后点按保存。勾选两个后，每一行都会出现主房间标签：点按您想作为主房间的那一个。若不选择，则以最先勾选的为主房间。
  • 主房间：分组播放内容的来源扬声器，其标签上标注主房间。当主房间就是您当前连接的接收机时，接收机会显示此接收机。
  • 编辑分组：使用同一面板更改成员或主房间。已在其他分组中的扬声器会显示在其他分组中。
  • 取消分组：立即移除该分组，所有成员回到未分组。应用会以分组已移除确认。
  • 重命名分组：点按卡片上的铅笔图标。名称仅在此应用中更改。
  • 正在播放的扬声器可能会在分组变更期间停止，面板会事先提醒您。
拖放

长按以加入、移动或移除

  • 长按扬声器标签，然后拖放到分组上加入该分组，或拖放到房间上将其移入该房间。
  • 将其拖放到拖放到此处以从分组中移除即可移出该扬声器。
  • 如果该扬声器正在播放，应用会在切换到分组播放内容之前询问：仍然加入。
音乐

音乐服务、浏览与收藏

  • 在分组卡片上点按音乐，可打开接收机已设置的服务列表，例如流媒体服务、电台、播放列表、历史记录和 AUX 输入。
  • 点按某项服务即可浏览。返回可回到上一级。
  • 对于列表项，您可以立即播放、下一首播放、添加到队列末尾或替换队列并播放。
  • 很长的列表会显示仅显示前 N 项。
  • 心形按钮将正在播放的内容加入收藏可保存当前播放的内容；再次点按同一按钮即可移除。如果服务未保留该更改，应用会予以说明。
  • 需要登录的服务会提示此服务需要您登录。请在接收机自带的应用中登录一次。未设置任何音乐服务的情况同理。
搜索

搜索音乐服务

  • 支持搜索的服务会显示搜索框以及每种搜索类型对应的标签，例如艺术家、专辑、曲目或播放列表。这些标签来自服务本身，因此各服务有所不同。
  • 选择一个标签，输入内容，然后按搜索。清除可清空搜索框。
  • 没有匹配项时显示无结果。
  • 如果该服务尚未在接收机上登录，搜索会被拒绝，并提示设备未接受该请求，请重试。
队列

队列

  • 分组卡片会概述队列（队列中有 3 项）和接下来的曲目。点按队列即可打开。
  • 该面板以主房间命名，按顺序列出曲目，并带有可清空队列的清除按钮。重复（关闭、全部、单曲）和随机播放也在这里；如果服务未保留播放模式，应用会予以说明。
  • 队列为空时显示队列中没有内容。如果扬声器没有响应，则显示无法读取队列。
房间

整理：房间与设备名称

  • 点按整理。添加房间可创建房间，每个扬声器都可通过设备选项 → 移至房间移入房间。
  • 扬声器进入房间后，将此房间分组可一次性将其全部分组。
  • 重命名设备仅在此应用中更改名称。使用原始名称可恢复。
  • 在拥有多个分区的接收机上，所有分区共用此接收机的同一个扬声器，因此分组适用于整台接收机。
主页

主屏幕卡片与主屏幕小组件

  • 主屏幕上的多房间卡片以标签形式列出扬声器和分组，并带有打开本界面的管理按钮。
  • 在扬声器或分组上选择固定到主屏幕小组件，即可将其放到多房间小组件上，小组件会显示其播放内容，并提供播放和音量控制。应用会以<name> 已在多房间小组件上确认。
故障排除

出现问题时

  • 无法连接到此接收机的多房间：请检查接收机是否已开机，并且在同一网络中。
  • 未找到扬声器：接收机没有列出任何扬声器。请使用通过 IP 地址连接，并输入路由器上显示的扬声器 IPv4 地址；忽略此扬声器可再次将其移除。
  • 无法分组：卡片会注明原因，例如接收机未列出或不支持多房间。
  • 分组变更失败：应用会说明发生了以下哪种情况：分组列表已变化、扬声器未及时响应、因另一项变更仍在进行而未发送、扬声器正忙，或变更未得到确认。请检查分组后重试。
常见问题

多房间常见问题

AVR Maestro 中的多房间是什么？
它是一个界面和主屏幕卡片，列出接收机能看到的所有扬声器、它们所在的分组以及各自正在播放的音乐，每个分组对应一个音量滑块。
主房间有什么作用？
主房间是分组播放内容的来源扬声器，其他成员跟随它。分组的队列和正在播放的内容就是它的队列和正在播放的内容。
如何取消扬声器分组？
打开多房间，找到分组卡片并点按取消分组，所有成员都会回到未分组。若只想移出某一个扬声器，请长按它并拖放到拖放到此处以从分组中移除。
为什么搜索提示设备未接受？
该音乐服务尚未在接收机上登录。请先在接收机自带的应用中登录一次，然后再从 AVR Maestro 重新搜索。
哪些接收机可以使用？
支持多房间并出现在多房间列表中的接收机。未出现的接收机会列在无法分组下，并注明原因。

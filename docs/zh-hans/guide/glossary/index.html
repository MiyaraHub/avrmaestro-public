通俗易懂的定义

AVR Maestro 术语表

对 AVR Maestro 和本指南中所用术语的简短通俗解释。其中哪些适用于您的接收机，取决于它的型号。

应用

  • 场景。一组已保存的接收机设置组合，例如输入源、声音模式和音量，轻点一下即可应用。请参阅场景。
  • Quick Select / Smart Select。接收机自带的输入源、音量和声音模式记忆插槽。Denon 称之为 Quick Select，Marantz 称之为 Smart Select。请参阅遥控。
  • 音量预设。应用中保存的 8 个音量级别之一。轻点即可跳转。请参阅音量。
  • 演示模式。在应用内运行一台模拟的 Marantz CINEMA 30，让您无需接收机就能体验每个屏幕。不会通过您的网络发送任何内容。
  • 家庭自动化专业版。一个把接收机连接到 Home Assistant、Hubitat 和 Webhook 的扩展。请参阅家庭自动化。
  • 助手。用平常的话要求更改接收机设置。它在您的设备上运行，并且只在能够运行它的设备上出现。请参阅助手。
  • Webhook。一个网址，由其他系统调用以让应用执行某些操作，或由应用在发生某些事情时调用。
  • Home Assistant / HACS / Hubitat。家庭自动化系统。HACS 是 Home Assistant 社区商店，用于安装附加组件。请参阅 Home Assistant 仪表板。
  • 锁定的控件。接收机目前不允许更改的设置，通常是因为声音模式或信号。请参阅锁定的控件。

网络与连接

  • IP 地址。接收机在家庭网络中的地址，例如 192.168.1.20。应用用它来连接。
  • MAC 地址。接收机网络端口固定的硬件 ID。显示在设备信息中。
  • HTTP 和 Telnet。应用通过网络与接收机通信的两种方式。HTTP 发送命令，Telnet 传回实时更新。
  • HEOS。内置于较新 Denon 和 Marantz 接收机中的流媒体与多房间系统。请参阅正在播放。
  • 网络待机。接收机的一项设置，使其在待机时保持网络开启，这样应用才能将其开机。

校准与房间校正

  • Audyssey MultEQ。Denon 和 Marantz 的房间校正。它用麦克风测量您的房间并校正声音。MultEQ XT32 是最精细的版本。
  • Dynamic EQ。Audyssey 功能，在小音量下保持低音和环绕声平衡。开启期间，音调控制会被锁定。
  • 参考电平偏移。告诉 Dynamic EQ 您的内容混音时有多响，以调整它的校正。
  • Dynamic Volume。Audyssey 功能，抹平突然出现的响亮与安静段落。
  • LFC (Low Frequency Containment)。Audyssey 功能，减少传到相邻房间的低音。抑制量决定减少多少。
  • Dirac Live。Dirac 的房间校正，部分接收机提供。启用后会取代 Audyssey。其结果存储在插槽中。
  • 扬声器预设。预设 1 或预设 2：两套完整的扬声器设置，各有自己的布局、距离、电平、分频和校准。

声音模式与处理

  • Dolby Atmos / DTS:X。包含高度声道的环绕声格式。
  • Dolby Surround。Dolby 的上混器，把立体声或环绕声扩展到您所有的扬声器。中置扩展仅在此模式下有效。
  • Neural:X。DTS 上混器。可与 DTS:X 声音模式配合使用。
  • Auro-3D / Auro-Matic。来自 Auro Technologies 的沉浸式格式和上混器，适用于支持它的接收机。
  • IMAX Enhanced。针对 IMAX Enhanced 内容的设置，适用于支持它的接收机。
  • Pure Direct / Direct。绕过大部分处理、以获得最纯净信号路径的声音模式。
  • DRC (动态范围压缩)。缩小响亮与安静声音之间的差距。适用于 Dolby 信号。
  • 响度管理。让 Dolby 内容保持一致的电平。
  • 对白增强。让人声更容易听清。
  • Cinema EQ。柔化影片声轨中刺耳的高音。
  • M-DAX。Marantz 功能，为压缩音乐恢复细节。关闭、低、中或高。
  • Restorer。Denon 功能，为压缩音乐恢复细节。
  • 扬声器虚拟化。模拟您没有的扬声器。
  • 房间大小、全景、维度、中置宽度。调整声场扩散方式，位于声音 › 形状下。
  • 音调控制。低音和高音调整。请参阅声音。
  • 图形均衡器。每个扬声器的分频段均衡器。请参阅图形均衡器。

扬声器与低音

  • Amp Assign。接收机功放声道的使用方式，例如用于增高扬声器或第二分区。
  • 分频。低于该频率时，扬声器的低音会改送到低音炮。
  • HPF / LPF。高通滤波器和低通滤波器。它们在扬声器和低音炮之间划分声音。
  • 低音管理。接收机在扬声器和低音炮之间分配低音的方式。
  • LFE。Low Frequency Effects：影片声轨中独立的低音声道，即 5.1 中的 .1。
  • 低音炮模式。LFE 只把低音声道送到低音炮。LFE + 主声道还会送出主扬声器的低音。
  • 声道电平。每个扬声器相对于其他扬声器的音量。
  • 距离。每个扬声器到您座位的距离。接收机用它来对齐声音的时间。
  • 中置电平调整。快速提升或衰减中置扬声器。
  • 扬声器网格。应用中您的扬声器及哪些正在发声的实时示意图。请参阅扬声器。

接收机与系统

  • 分区 2 / 分区 3。接收机可以播放到的额外房间，各自有独立的电源、音量和输入源。请参阅多分区。
  • 全分区立体声。在每个分区播放主分区的音源。
  • HDMI CEC。让电视和接收机通过 HDMI 互相控制。
  • eARC。增强型音频回传通道。通过 HDMI 把电视的全品质声音送到接收机。
  • ECO 模式。接收机节能。
  • 自动待机。在一段时间没有信号或操作后关闭接收机。
  • 睡眠。关闭接收机的定时器。
  • 触发输出。12V 输出，随接收机开关其他设备，例如屏幕或功放。在带有该输出的接收机上有自己的遥控子标签页。
  • 数字输入格式。强制指定接收机读取数字输入的方式：自动、PCM 或 DTS。
  • Bluetooth 发射。把接收机的声音发送到 Bluetooth 耳机或扬声器。
  • 设置锁定 / 遥控锁定。阻止菜单更改或遥控操作的接收机锁。请参阅锁定的控件。
  • 屏幕显示。接收机在电视上显示的信息，例如音量。请参阅屏幕显示。
  • 信号信息。输入和输出的音频与视频格式，例如色彩空间和像素深度。
常见问题

术语，答疑

Quick Select 和 Smart Select 是一回事吗？
是的。Denon 把接收机的记忆插槽叫作 Quick Select，Marantz 则叫作 Smart Select。AVR Maestro 使用与您的接收机相符的名称。
LFE 和低音炮有什么区别？
LFE 是影片声轨中独立的低音声道。低音炮是播放它的扬声器，同时还播放接收机从其他扬声器转移过来的低音。
我需要同时使用 Audyssey 和 Dirac Live 吗？
不需要。它们是两种房间校正。在带 Dirac Live 的接收机上，启用的 Dirac Live 校准会取代 Audyssey。

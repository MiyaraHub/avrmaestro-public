多分区

多分区：掌控全屋

在多分区 Denon 和 Marantz 接收机上，独立控制分区 2 和分区 3 的电源、输入源与音量 - 场景还能捕获并恢复分区状态。厨房播放音乐，影院放映电影，全在一个应用里搞定。

分区的工作方式

每个分区，完全独立

每个分区都有自己的电源、音量、静音、输入源和快速音量预设，与主分区完全分开。

🔌

独立电源

开关分区 2 或分区 3，完全不影响主分区。

🎵

独立输入源 & 音量

每个分区有不同的输入源和音量，并带快速音量预设芯片 - 预设默认平滑渐变（渐变音量预设位于设置 › 管理接收机 › 您的接收机 › 音频下）。

⚡

分区 Smart Select / Quick Select

分区自己的 Smart Select 或 Quick Select 插槽就在卡片上 - 点按插槽即可调用，长按则把该分区当前状态保存到其中。

✍️

重命名任意分区

在主页长按分区名称 - 主分区也可以。名称会保存到接收机本身，因此所有应用显示一致。

🔄

实时同步

在接收机面板或遥控器上更改分区，应用会在一秒内更新。

🎧

各分区独立的正在播放

分区开启时，其卡片会显示该分区的实时 HEOS 流，并带有播放控制。

🎭

可被场景捕获

场景可以连同其他所有内容一起捕获并恢复分区 2/3 的状态。

📱

在主页上

紧凑的分区小组件在主页上提供一目了然的状态和快捷控制。

开启分区，并指定播放来源

  • 1. 打开分区标签页。接收机声明的每个分区都有一张卡片。只有一个分区的接收机不会有这个标签页。
  • 2. 用卡片上的电源控制开启分区。主分区不受任何影响。
  • 3. 选择它的输入源。列表来自您的接收机本身，沿用您重命名后的名称，分区可以使用与主房间完全不同的输入源。
  • 4. 设置音量。该分区有自己的电平和自己的静音，快速音量芯片会调用您在该分区上设置的电平。预设会平滑渐变，除非您在设置 › 管理接收机 › 您的接收机 › 音频中关闭渐变音量预设，这会让预设直接跳到其电平。
  • 5. 可选：保存。长按分区自己的某个 Smart Select 或 Quick Select 插槽，即可存储该分区此刻的全部状态，之后点按它就能恢复。

在主页长按分区名称即可重命名。名称会写入接收机，因此前面板和其他所有应用都与本应用保持一致。

较旧的接收机

在卡片上查看每个分区的设置

在较旧的接收机上，例如 SR7015 和 X4500H 这一级别，分区 2 和分区 3 的卡片包含一个分区设置块，显示接收机自身的分区菜单是如何设置的。较新的接收机，例如 Cinema 30 这一级别，不显示此块。

您可能看到的内容，取决于接收机为该分区报告了什么：

  • 以 dB 为单位的低音和高音。
  • 高通滤波器 (HPF)：开或关。
  • 声道：立体声或单声道。
  • HDMI 音频（分区 2）：直通或 PCM。
  • 音量电平：可变，或固定电平。
  • 音量限制（关闭或某个电平）、开机音量（上次、静音或某个电平）和静音电平（完全、-20 dB 或 -40 dB）。
  • 自动待机：关闭、2 小时、4 小时或 8 小时。
此块为只读：从接收机读取。请在接收机本身更改这些设置。应用无法读取的值显示为未知。如果该块没有出现，说明读取失败或接收机不提供该项；下次您打开“分区”标签页时会再次尝试。
须知

为什么关闭主分区不会让其他房间停播

Denon 和 Marantz 接收机有两种不同的电源命令，如果家里其他地方正在播放音乐，这种区别就很重要。

系统级待机命令会关闭整台机器，接收机也会把其他分区一并关掉 - 在 Cinema 30 上实测，待机命令生效一毫秒后，机器就报告分区 2 已关闭。因此 AVR Maestro 的主电源控制特意改为发送主分区命令。从应用里关掉影院，厨房照样继续播放。

反过来也成立：从冷机状态开启主分区时会先唤醒整台机器，所以使用应用前无需另行开启接收机电源。

如果某个分区在主分区变化时自行关闭，那是接收机自身的设置所致，与应用无关。有些型号在其分区菜单中带有电源联动选项。
常见问题

多分区常见问题

我能用手机控制分区 2 和分区 3 吗？
可以 - 在多分区接收机上，每个分区都有各自的电源、音量、静音、输入源和快速音量预设，与主分区完全独立，并实时同步。
我能在分区中使用 Smart Select 或 Quick Select 吗？
可以 - 每个分区卡片都带有该分区自己的插槽，名称与您的接收机一致：Marantz 上是 Smart Select，Denon 上是 Quick Select。点按插槽即可调用；长按则可把该分区当前状态直接从卡片保存到其中。
我能重命名分区吗？
可以 - 在主页长按分区名称即可重命名任何分区，包括主分区。名称会写入接收机本身，因此厂商的应用和其他所有客户端都会显示，较旧的机型也不例外。
每个分区都会显示正在播放的内容吗？
会 - 分区开启时，其卡片会显示该分区的实时 HEOS 正在播放信息，并带有播放控制。
为什么我不能在应用里更改分区设置的数值？
较旧接收机（例如 SR7015 和 X4500H 这一级别）上的分区设置块，是接收机自身分区设置的只读显示。请在接收机本身的设置菜单中更改这些设置；卡片会在下次读取时显示新值。
场景可以设置我的分区吗？
可以 - 场景可以连同其余设置一起捕获并恢复分区 2/3 的电源、输入源和音量。

手动均衡

真正的图形均衡器编辑器，而不只是一个开关

当您不使用 Audyssey 或 Dirac 运行接收机时，手动图形均衡器任由您调整，而 AVR Maestro 把完整功能都搬到了手机上：为每个扬声器提供 63Hz 至 16kHz、-20 至 +6 dB 的 9-band 曲线，直接在图表上拖动，实时生效。

逐个频段塑造声音

  • 九个频段，63Hz 至 16kHz：频段中心与您的接收机开放的完全一致，每个频段可在 -20 到 +6 dB 之间调节。
  • 在图表上拖动：抓住一个频段向上或向下拖动，曲线会随之实时重绘，让您看到自己正在构建的形状。
  • 选择调整对象：用一条曲线调整全部扬声器，将左/右一对一起调整，或单独调整逐个扬声器，与接收机自身的图形均衡器页面保持一致。
  • 复制您的 Audyssey 曲线：“复制”按钮会把您测得的 Audyssey 结果作为起点导入，让您在已验证的校准上微调，而不必从平直开始。
  • 重置：将当前选择恢复为平直的 0 dB。
  • 应用：将曲线实时发送到接收机。
一次只用一套系统

房间校正运行时，它会自动锁定

您的接收机要么运行房间校正（Audyssey MultEQ 或 Dirac Live），要么使用手动图形均衡器，不会两者同时生效。因此只要 MultEQ 或 Dirac 处于活动状态，AVR Maestro 就会锁定图形均衡器，并明确告诉您原因，而不是任由您构建一条接收机会忽略的曲线。关闭房间校正后，编辑器会立即解锁。

旧版固件同样支持：逐扬声器的频段编辑在老机型和新机型上都能使用，而且均衡器设置会保持不变，在 AVC-X6700H 这类接收机上不会再自己关闭。
常见问题

图形均衡器常见问题

我什么时候可以使用图形均衡器？
当 Audyssey MultEQ 和 Dirac Live 都关闭时。接收机要么运行房间校正，要么使用手动图形均衡器，两者不会同时生效。因此只要房间校正关闭，编辑器就可用；只要房间校正开启，编辑器就会锁定，并给出清楚的说明。
频段和增益范围是多少？
从 63Hz 到 16kHz 共九个频段，每个频段可在 -20 到 +6 dB 之间调节，这正是接收机本身开放的范围。
我可以复制 Audyssey 校准结果作为起点吗？
可以。“复制”会把您测得的 Audyssey 曲线导入图形均衡器，让您在已验证的结果上微调。“重置”会将其恢复为平直的 0 dB。详情请参阅 Audyssey & Dirac 指南。
它支持较老的接收机吗？
支持。逐扬声器的频段编辑在旧版固件和新款机型上都能使用，而且在 AVC-X6700H 这类接收机上，开关不会再自己关闭。

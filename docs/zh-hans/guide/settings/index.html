应用之外

主屏幕小组件与设备音量按钮

  • 主屏幕小组件（iOS 和 Android）：快捷控制（电源 / 音量 / 静音 / 输入源）、正在播放和状态，提供多种尺寸，仅需点按，并可自动刷新。当接收机关机或无法连接时，小组件会显示清晰的“AVR 关闭”/“待机”状态，而不是过时的输入源和音量，电源按钮仍然可用，因此您可以直接从小组件唤醒接收机。
  • 设备音量按钮（Android 和 iOS）：当 AVR Maestro 位于前台时，设备的实体音量按钮会控制接收机的音量（使用您设置的音量步进），按住则会持续渐变。仅限前台使用；应用被其他应用盖住时，按钮会立即恢复控制设备本身，“设置”的“音频”中的开关可以关闭这一接管功能。
小组件、主题、备份 & 恢复，以及音量按钮接管功能，在 iOS 和 Android 上均可使用。
常见问题

设置常见问题解答

我可以更改应用的主题和颜色吗？
可以。支持浅色、深色、跟随设备或 AMOLED（纯黑），还有配色主题，您可以选择任意强调色，应用会据此重新生成整套配色。可以使用色轮，也可以输入十六进制代码（#FF8C00，或三位字符的简写形式）。如果代码有误，应用会告诉您错在哪里，而不是直接拒绝。您还可以设置显示/小组件大小，并自定义导航和标签页。
我可以备份我的设置吗？
可以。“设置”中的“备份”会把所有接收机、预设和偏好设置导出为一个 .zip 文件，其中同时打包了您的自定义输入图标；在新手机上导入即可恢复。较旧的 .json 备份仍然可以正常导入。文件中不含任何凭据，因此可以放心分享。
音量预设是直接跳到目标值，还是逐渐过渡？
由您决定。“设置”的“音频”中有“渐变/直接”开关。渐变（默认）会平滑地向预设的目标值过渡，这样一次点按绝不会让音量骤然猛增而冲击您的扬声器；直接则立即应用。主分区和分区 2/3 均适用。
我可以通过应用锁定接收机的实体遥控器吗？
可以，适用于支持该功能的接收机。“设置”的“接收机”中有“遥控锁定”开关，用于锁定或解锁接收机自带的红外遥控器。
主屏幕小组件只有 Android 才有吗？
不是。快捷控制（电源 / 音量 / 静音 / 输入源）、正在播放和状态小组件在 iOS 和 Android 上均提供。当接收机关机或无法连接时，它们会显示清晰的“AVR 关闭”/“待机”状态，而不是过时的数据，快捷控制的电源按钮仍然可用，因此您可以直接从小组件唤醒接收机。
手机的音量键可以控制接收机吗？
在 Android 上可以：应用位于前台时，您的音量键会控制接收机的音量。iOS 不允许这样做。
如何打开隐藏的调试菜单？
打开“设置”，进入“关于”，连续点按版本号七次。此后调试菜单会在每次启动后保持可用，其中包含实时调试日志，以及供技术支持使用的原始命令工具和诊断功能，直到您点按“移除调试菜单”再次将其隐藏。
“更多 MiyaraHub 应用”是什么？
“设置”中的一个板块，里面有浏览我们的所有应用按钮。点按后，您的应用商店会打开 MiyaraHub 开发者页面，具体是 Google Play、App Store 还是 Microsoft Store，取决于您的设备，您可以浏览我们制作的所有应用。

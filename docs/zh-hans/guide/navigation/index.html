标签页、滑动与手势

如何在 AVR Maestro 中移动：底部标签页及其更改方式、在页面间滑动、轻点和长按的作用、返回键、更新提示、消息，以及电脑上的键盘快捷键。

底部标签页

屏幕底部的栏放置您的主要标签页。默认是主页、遥控、声音、分区、场景、扬声器和设置。也可以添加收音机。搜索按钮位于每个标签页底部栏的右端（请参阅搜索）。

  • 主页始终包含且始终排在第一位。
  • 收音机仅在所选接收机带有调谐器时出现。请参阅收音机。
  • 您可以保留 2 到 7 个标签页。
分步操作

添加、移除或重新排序标签页

  1. 打开设置 › 自定义导航。顶部会显示该栏的预览。
  2. 在可用标签页下，勾选标签页即添加，取消勾选即移除。
  3. 在已启用标签页下，拖动某一行的手柄即可更改顺序。
  4. 轻点保存。消息导航已更新会确认操作。重置会恢复默认的标签页集合和顺序。
分步操作

隐藏您不使用的子标签页

声音、扬声器和遥控标签页的顶部各有一排子标签页，例如声音下的 Audyssey、Dirac Live、图形均衡器、声道和音调。

  1. 打开设置 › 自定义标签页（隐藏您不使用的子视图）。
  2. 在声音、扬声器或遥控下，关闭您不想要的每个子视图。预览会显示结果。
  3. 返回。该更改适用于每台接收机。
如果您的接收机不支持某项功能，例如没有 Audyssey 的接收机上的 Audyssey，它的子标签页已被隐藏，不会在这里列出。自定义标签页是在此基础上的第二层。

在页面间滑动

  • 在页面上向左或向右滑动，移到下一个或上一个子标签页。
  • 在最后一个子标签页继续滑动，就会移到下一个底部标签页。越过最后一个标签页则会按您设置的顺序回到第一个。
  • 沿底部标签栏滑动可直接切换标签页。这同样会循环。
  • 在有滑块的页面上，缓慢拖动会移动滑块。切换页面需要快速、基本为横向的轻扫。

在 iPhone、iPad 和 Mac 上向后滑动一步

在引导式场景创建器、欢迎与设置指南以及 Home Assistant 登录页面中，从屏幕左边缘向内滑动即可返回一步。在从右到左的语言中，则从右边缘向内滑动。滑过超过一半的距离，或快速轻扫。

轻点与长按

许多控件轻点是一种效果，按住则是另一种。

  • 音量预设。共有 8 个预设插槽。轻点标有 + 的空插槽，把当前音量保存到其中。轻点已保存的插槽，跳转到该音量。长按任意插槽，用当前音量覆盖它或清除它。若想渐变到预设而不是直接跳转，请在设置 › 管理接收机 › 您的接收机 › 音频中打开渐变音量预设。请参阅音量。
  • Quick Select 和 Smart Select。轻点插槽即可调用。长按可选择保存当前状态或重命名。
  • 主页输入网格。长按开始编辑网格。请参阅主屏幕。
  • 遥控输入源。长按输入源可为其设置自定义图标。请参阅自定义图标。
  • 分区名称。长按分区名称可重命名。请参阅多分区。
  • 收音机预设。轻点调用，长按保存当前电台。请参阅收音机。
  • 场景。轻点应用，按住查看选项。请参阅场景。
  • 接收机。在设置 › 管理接收机中，长按某台接收机可查看其选项。
  • 说明卡片。轻点横幅展开，长按则关闭它。可从设置 › 恢复已关闭的卡片找回。

返回、退出与消息

  • 子页面中的返回会带您回到标签页顶部。在主页编辑时，返回键会先退出编辑模式。
  • 标签页顶部的返回会询问退出 AVR Maestro？轻点退出应用关闭应用，或轻点取消留下。这适用于 Android 的返回键和返回手势。
  • 屏幕底部的消息带有关闭按钮。错误消息会一直停留，直到您关闭。其他消息会在几秒后自动关闭，较长的消息停留更久。新消息会替换屏幕上的消息。
开启手机的无障碍导航设置后，每条消息都会停留到您关闭为止。

有可用更新时

发布较新版本的 AVR Maestro 时，主屏幕会显示有可用更新。

  • 更新会打开应用在 Google Play、App Store 或 Microsoft Store 中的页面。
  • 稍后会将提示隐藏 3 天。
  • 跳过此版本会停止该版本的提示。
如果某个版本被标记为必需，提示会显示必须更新，只有更新按钮，并且无法关闭。

Windows 和 Mac 上的键盘快捷键

在 Windows 上使用 Ctrl，在 Mac 上使用 Cmd，配合：

  • 上 / 下方向键：增大或减小音量
  • M：开启或关闭静音
  • 空格键：播放或暂停
  • 右 / 左方向键：下一首或上一首
  • 句点 (.)：停止

键盘上的媒体键（播放、暂停、下一首、上一首、停止、音量和静音）同样可用。

在文本框中输入时，快捷键不起作用。静音和播放或暂停会等到接收机报告其当前状态之后才生效。

平台说明

  • Android：返回键退出前会询问。应用打开期间，手机的音量键可以更改接收机的音量（设备音量按钮，按接收机设置，默认开启）。
  • iPhone 和 iPad：在引导流程中，从边缘向内滑动可后退一步。设备音量按钮在这里同样可用。
  • Mac：边缘滑动后退一步、Cmd 快捷键和媒体键。
  • Windows：Ctrl 快捷键和媒体键。
常见问题

导航，答疑

如何更改 AVR Maestro 底部显示的标签页？
打开设置 › 自定义导航。在“可用标签页”下取消勾选一个标签页即可移除它，勾选则添加，拖动“已启用标签页”下的行可更改顺序，然后轻点“保存”。主页始终包含且始终排在第一位。您可以有 2 到 7 个标签页。
如何隐藏我从不使用的子标签页，例如 IMAX 或 Auro-3D？
打开设置 › 自定义标签页，在“声音”、“扬声器”或“遥控”下关闭您不想要的子视图。该选择适用于每台接收机。您的接收机不支持的功能已被隐藏，不会在那里列出。
为什么没有“收音机”标签页？
可以在设置 › 自定义导航中添加收音机，但只有当所选接收机带有调谐器时，该标签页才会出现。
可以在标签页之间滑动吗？
可以。在页面上向左或向右滑动即可在其子标签页之间移动。到最后一个子标签页时，再次滑动会移到下一个底部标签页，从最后一个标签页滑动则会回到第一个。您也可以沿底部标签栏本身滑动。
为什么 AVR Maestro 在关闭前会询问？
在 Android 上，在标签页顶部按返回键会询问“退出 AVR Maestro？”，这样误按返回键就不会关闭应用。轻点“退出应用”关闭，或轻点“取消”留下。在子页面中，返回键会先带您回到标签页顶部。
AVR Maestro 在 Windows 和 Mac 上有键盘快捷键吗？
有。Windows 上的 Ctrl 或 Mac 上的 Cmd 加上、下方向键可调节音量，加 M 切换静音，加空格键播放或暂停，加左、右方向键后退或前进，加句点键停止。键盘上的媒体键同样可用。在文本框中输入时，快捷键不起作用。

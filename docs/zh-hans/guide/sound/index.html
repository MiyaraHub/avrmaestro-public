“声音”标签页

接收机的每一项音频控制，尽在一个“声音”标签页

声音标签页最多有十个页面，它反映的是接收机自己的音频菜单，而不是简化版。本页逐个介绍：每个控件做什么、需要什么，以及接收机为什么有时不让您触碰它。

十个页面

打开屏幕底部的声音标签页。页面排在顶部；轻点页面名称或左右滑动即可在它们之间切换。

第一页

环绕声：选择声音模式并切换音频功能

顶部卡片按接收机报告的原样显示当前模式。其下的模式分为电影、音乐、游戏和 Pure，并且只列出接收机针对其当前正在解码的信号所提供的模式。

  1. 轻点一个类别：电影、音乐、游戏或 Pure。
  2. 轻点一个模式，例如 Dolby Surround 或 DTS Neural:X。图块亮起，当前模式卡片随之变化。
  3. 如果图块看起来已启用但没有任何反应，说明音频与该模式不匹配：Dolby 选项需要 Dolby 内容，DTS 选项需要 DTS。

音频功能

在模式列表下方，音频功能卡片包含您可以更改的开关。每行显示已启用或未启用；轻点药丸按钮开启或关闭该功能。显示 N/A 的行无法在当前模式或信号下使用：轻点它的问号，应用会告诉您它需要什么。

  • Neural:X - 在可使用它的模式中显示；它需要 DTS:X 环绕声模式。
  • IMAX Enhanced - 适用于带 IMAX 的接收机。IMAX 就绪时开启的药丸按钮显示自动，接收机检测到 IMAX 编码的流后显示已启用。
  • Cinema EQ - 在 Direct、Pure Direct、立体声和原始声音模式下不可用。
  • 中置扩展 - 仅适用于 Dolby Surround 声音模式。
  • 响度管理 - 需要 Dolby Digital、Dolby Digital Plus、Dolby TrueHD 或 Dolby Atmos 信号。
  • 扬声器虚拟化 - 适用于报告该功能的接收机；需要 Dolby Atmos、Dolby Surround 或“+Dolby Surround”模式。
  • LFE 电平 - 仅当接收机在当前声音模式下提供时才显示。用减号和加号在接收机报告的范围内步进。当接收机显示 LFE 电平但目前不允许更改时，该行会说明原因，而不是显示数字。
  • 低音炮 - 在已设置低音炮且允许此操作的接收机上，开启或关闭低音炮输出。

低音炮电平调整

在页面底部，低音炮电平卡片（有多个低音炮时为低音炮 1 电平、低音炮 2 电平等）是接收机按音源保存的播放偏移。它叠加在您校准后的低音炮电平之上，不会改变它。轻点减号或加号进行步进；步进为 0.5 dB 或 1 dB，取决于接收机。当前音源没有音频信号时，该卡片会隐藏。

第二页

对白增强与 DRC：更清晰的人声和夜间聆听

  • 对白增强 - 关闭、低、中或高。让人声更容易听清，而不触及您的校准。
  • 中置电平调整 - 在较旧的接收机（X4500H 和 SR7015 这一级别）上，它取代对白增强。它是适用于每个音源和快速预设的绝对中置扬声器电平，范围为 -12.0 到 +12.0 dB，以 0.5 dB 步进。轻点减号或加号更改，或轻点中间按钮回到 0 dB。Cinema 30 等较新的接收机没有该项。
  • 动态范围压缩 - 关闭、低、中、高或自动。缩小低语和爆炸之间的差距，这正是深夜所需要的。

压缩数据携带在 Dolby 比特流内部，所以在 PCM、DTS 或网络立体声音源上没有可压缩的内容。应用不会让您去按一个不起作用的按钮，而是将该行变灰并说明原因：播放 Dolby Digital、Dolby Digital Plus、Dolby TrueHD 或 Dolby Atmos 内容才能使用。

第三页

Audyssey：完整的校准菜单，不只是 MultEQ

  • MultEQ - 参考、旁通 LR、平直或关闭。参考是校准后的标准曲线；平直消除高频衰减；旁通 LR 让前置左右声道不做校正；关闭则关闭房间校正，其下的控件变暗。
  • Dynamic EQ - 开或关。降低音量时保持音色平衡，避免低音变单薄。
  • Reference Level Offset - 0、5、10 或 15 dB。告诉 Dynamic EQ 您的内容母带制作时比参考电平低多少。0 dB 适合电影；较高的偏移量适合音乐和电视节目。
  • Dynamic Volume - 关闭、轻、中或重。抹平响亮的广告与安静对白之间的差距。
  • Surround Level Compensation - 关、Light、Medium 或 Heavy。
  • Audyssey LFC - 开或关。Low Frequency Containment 防止深低音传到相邻房间。
  • 抑制量 - 减号和加号设置 LFC 的作用强度。它只在 Audyssey LFC 开启时响应；在此之前，页面会显示“请先在上方启用 Audyssey LFC，再调整抑制量。”

右上角的圆形刷新按钮（重新查询校准状态）会再次询问接收机当前扬声器预设使用哪种校准。如果您在接收机上自行切换预设后页面仍显示横幅，请使用它。

您可能会看到横幅而不是控件：此扬声器预设没有 Audyssey 校准、此扬声器预设未启用 Audyssey，或Dirac 占用了此扬声器预设 - Audyssey 不可用。每一条都是接收机自己的状态。请参阅控件为何被锁定。
第四页

Dirac Live：按您起的名字列出滤波器

运行过 Dirac Live 后，您导出的滤波器会存放在接收机的编号插槽中。AVR Maestro 会按您保存时的名称列出它们，名称下方显示插槽编号，另有一个关闭选项，可让预设在完全不使用滤波器的情况下运行。轻点一下即可切换滤波器。

在 Audyssey 占用的扬声器预设上，页面会显示Audyssey 占用了此扬声器预设 - Dirac 不可用，而不是显示空列表。刷新按钮（重新查询 Dirac 插槽信息）会再次读取插槽。

第五页

图形均衡器：九个频段，每只扬声器独立设置

真正的编辑器：页面顶部、重置和复制旁边的开/关开关用于开启或关闭图形均衡器，并在图表上拖动从 63Hz 到 16kHz、-20 到 +6 dB 的九个频段。选择全部、左/右或逐个扬声器，使用复制以您测得的 Audyssey 曲线为起点，使用重置恢复平直，并用待处理更改栏来应用。

接收机要么运行房间校正，要么运行手动均衡，二者不会同时生效，所以只要 MultEQ 或 Dirac 在运行，此页面就会锁定，并指明是哪一个。

第六页

声道：影片播放时随时微调任意扬声器

当前信号中每个扬声器的逐声道微调（单位 dB）：前左、前右、中置、环绕、后环绕、低音炮和高度层，每个下方都有简称，因此无需猜测哪个是哪个。

  • 拖动滑块进行大幅调节，或点按加减号做单步微调，聆听的同时都可以操作。
  • 全部重置会把每个声道恢复到 0 dB。
  • 多低音炮输出 - 设置了多个低音炮时，卡片会告诉您有几个；在声道列表中逐个微调（SW、SW2 等）。
  • 低音同步 - 低音炮延迟微调，0 到 16 ms。轻点减号或加号，使低音炮在时间上与主扬声器对齐。在具备该项的接收机上显示。
  • 触觉传感器 - 在自身菜单中显示该项的接收机上：一个启用开关、-12 到 +12 dB 以 0.5 dB 步进的电平，以及 40 到 250 Hz 的低通滤波器。

播放多声道音频时才会出现声道电平。Dirac Live 滤波器启用期间，接收机会锁定它们，页面会说明这一点。这些是随信号变化的实时微调；保存在扬声器预设上的各扬声器参考电平则位于扬声器标签页。

第七页

音调：低音、高音、DAC 滤波器和 M-DAX

  • 音调控制 - 总开关。只有它开启时，低音和高音才会传到接收机。
  • 低音和高音 - -6 dB 至 +6 dB，以 1 dB 为步进。
  • DAC 滤波器 - Filter 1 更温暖，衰减缓慢；Filter 2 是更锐利的参考响应。
  • 音频修复器 (M-DAX) - 关闭、低、中或高。重建因压缩或流媒体音频而丢失的细节，这正是您在低码率流媒体上想要的，而不是您在无损光盘上想要的。
只有 Dynamic EQ 会禁用音调控制。它开启时，页面会显示音调控制被 DYNAMIC EQ 锁定。要使用低音和高音，请在 Audyssey 页面关闭 Dynamic EQ，或将 MultEQ 设为关闭，这同样会关闭 Dynamic EQ。
第八页

形状：调校 Dolby Surround 和 Neural:X 上混器

这些控件决定上混器如何在房间里扩散声音。它们在 Dolby Surround 或 DTS Neural:X 启用时生效，所以“形状”页面只在其中一种模式（或 Auro 模式）播放时出现。请先在环绕声页面切换到其中一种。

  • 房间大小 - 小、中小、中、中大或大。
  • 全景 - 开或关。通过让主扬声器跨过中置混合来拓宽前方声场。仅在 Dolby Surround 模式下可闻。
  • 维度 - 减号和加号把声场向前或向后移动 (Dolby Surround)。
  • 中置宽度 - 减号和加号把中置声道的人声向左右主扬声器扩散。
只显示您的接收机支持的行。维度和中置宽度以步进方式发送，接收机不会回报它们的位置，所以屏幕上的数字是从您打开页面起累计的步数。如果需要确切的值，请查看接收机的屏幕显示。
第九页

IMAX：完整的 Enhanced 设置菜单

在支持 IMAX Enhanced 的机型上，应用提供完整的菜单，而不只是开关：

  • IMAX 模式 - 自动或关。
  • 音频设置 - 自动遵循 IMAX 推荐；手动则打开下方的控件。
  • 高通滤波器 (HPF) - 40Hz 到 250Hz。
  • 低通滤波器 (LPF) - 最高 250Hz；最低一档取决于接收机型号。
  • 低音炮 - 开或关，以及低音炮输出 - LFE+主声道或 LFE。
第十页

Auro-3D：有形态的上混

  • Auromatic 3D 预设 - 小、中、大、Speech 或 Movie。选择上混器所针对的房间与内容特性。
  • 强度 - Auromatic 生成多少高度信息。减号和加号在接收机报告的范围内步进，该范围印在数值下方。
  • Auro 3D 模式 - Direct 或 Channel Expansion。

这些设置仅在环绕声页面选中 Auro 模式时生效，而且只有配备 Auro-3D 解码器的机型才有此页面。

常见问题

声音标签页常见问题

为什么声音模式列表会变化？
因为接收机自己的列表会变化。Denon 或 Marantz 能接受哪些模式，取决于它正在解码什么：双声道信号会提供上混模式，Atmos 信号则提供支持 Atmos 的模式。AVR Maestro 每次都从接收机读取当前列表，而不是显示一个固定的菜单，那样的菜单有一半的时间都是错的。
为什么某个控件显示为灰色并标有 N/A？
N/A 表示接收机在当前状态下无法使用该功能，通常是因为输入信号或声音模式不携带它。轻点该行旁边的问号，应用会说明它需要什么。灰色控件绝不是被隐藏的故障，而是接收机自己的回答。
为什么我看不到“形状”页面？
“形状”页面只在 Dolby Surround、DTS Neural:X 或 Auro 模式播放时出现，并且仅限至少具备其中一项控制的接收机。在“环绕声”页面选择其中一种模式，“形状”页面就会出现。同时请检查您没有在设置 › 自定义标签页下将其隐藏。
“声道”和“电平”有什么区别？
“声道”（声音标签页）是针对当前正在播放的信号所做的实时各声道微调。“电平”（扬声器标签页）是保存在扬声器预设中的各扬声器参考电平，由您的校准得出。调整“声道”不会改写您的校准。
我可以同时使用音调控制和 Audyssey 吗？
Dynamic EQ 开启时不行，因为接收机会接管音调控制。在 Audyssey 页面关闭 Dynamic EQ，或将 MultEQ 设为关闭，低音和高音就能再次编辑。
我需要处于同一网络吗？
可以。AVR Maestro 通过局域网直接与您的接收机通信，没有云账号，中间也没有中继服务器。请参阅快速入门。

“声音”标签页

接收机的每一项音频控制，尽在一个“声音”标签页

“声音”标签页有九页之深，它镜像的是接收机自己的音频菜单，而不是简化后的版本。本页会逐一讲解这九页：每个控件的作用、它需要什么条件，以及接收机为何有时不让您操作它。

第一页

环绕声：当前模式，以及接收机的实际工作状态

顶部卡片显示接收机报告的当前模式，原样呈现。下方的模式分为电影、音乐、游戏和 Pure 几组，并且只提供接收机在当前解码信号下可以接受的模式。

  • Stereo、Dolby Surround、DTS Neural:X、Auro-3D、Auro Surround、Multi Ch Stereo 等模式，会根据您的机型和输入的音频流决定是否出现。
  • 下方的音频功能是实时读数，而不是愿望清单：Neural:X、IMAX Enhanced、Cinema EQ、Center Spread、Loudness Management、Speaker Virtualizer 等各自显示活动、未活动或 N/A。
  • N/A 表示当前信号无法使用该功能。点按旁边的问号，应用会告诉您什么样的信号可以使用。
第二页

对白增强 & DRC：清晰对白与夜间聆听

  • Dialog Enhancer - 关、弱、中或强。提升中置声道的对白清晰度，同时不影响您的校准。
  • 动态范围压缩 - 关、弱、中、强或自动。缩小耳语与爆炸之间的音量差距，深夜观影正需要这个。

DRC 最能说明 AVR Maestro 如何处理接收机不接受的控制项。压缩数据携带在 Dolby 比特流内部，所以对于 PCM、DTS 或网络立体声音源，没有可压缩的内容。应用不会让您按下一个没有作用的按钮，而是将该行置灰并写明原因：切换到 Dolby Digital、Dolby Digital Plus、Dolby TrueHD 或 Dolby Atmos 内容即可使用。

第三页

Audyssey：完整的校准菜单，不只是 MultEQ

  • MultEQ - Reference、Bypass LR、Flat 或关。Reference 是经过校准的标准曲线；Flat 去除高频衰减；Bypass LR 使前置左右声道不做校正；关则把均衡交还给您自己。
  • Dynamic EQ - 开或关。降低音量时保持音色平衡，避免低音变单薄。
  • Reference Level Offset - 0、5、10 或 15 dB。告诉 Dynamic EQ 您的内容母带制作时比参考电平低多少。0 dB 适合电影；较高的偏移量适合音乐和电视节目。
  • Dynamic Volume - 关、Light、Medium 或 Heavy。让嘈杂的广告与轻声的对白保持相近的响度。
  • Surround Level Compensation - 关、Light、Medium 或 Heavy。
此页面能否编辑，取决于当前扬声器预设归哪个系统管理。请参阅控制项为何被锁定。
第四页

Dirac Live：按您起的名字列出滤波器

运行过 Dirac Live 后，您导出的滤波器会存放在接收机的编号插槽中。AVR Maestro 会按您保存时的名称列出它们，名称下方显示插槽编号，另有一个关闭选项，可让预设在完全不使用滤波器的情况下运行。轻点一下即可切换滤波器。

如果扬声器预设中没有载入 Dirac 滤波器，页面会如实说明，而不是显示一个空列表。

第五页

图形均衡器：九个频段，每只扬声器独立设置

这是一个真正的编辑器，而不是一个开关：九个频段，从 63Hz 到 16kHz，范围 -20 至 +6 dB，在图表上拖动即可调节。可选择全部、左/右或逐个扬声器，用复制以实测的 Audyssey 曲线为起点，用重置恢复平坦，并通过待处理更改栏应用。

接收机要么运行房间校正，要么运行手动均衡，二者不会同时生效，因此只要 MultEQ 或 Dirac 在运行，本页面就会被锁定，并注明是哪一个。

第六页

声道：影片播放时随时微调任意扬声器

为当前信号中的每只扬声器提供以 dB 为单位的声道微调：前左、前右、中置、环绕、后环绕、两只低音炮以及高度声道层，每个声道下方都标有简称，不用猜哪个是哪个。

  • 拖动滑块进行大幅调节，或点按加减号做单步微调，聆听的同时都可以操作。
  • 全部重置会把每个声道恢复到 0 dB。
  • 底部的 Bass Sync 会使 LFE 声道与主声道在时间上对齐。

这些是针对当前信号的实时微调。保存在扬声器预设中的各扬声器参考电平则位于扬声器标签页，应用会在本页面自己的信息卡片中解释两者的区别。

第七页

音调：低音、高音、DAC 滤波器和 M-DAX

  • 音调控制 - 总开关。只有它处于活动状态时，低音和高音才会传到接收机。
  • 低音和高音 - -6 dB 至 +6 dB，以 1 dB 为步进。
  • DAC 滤波器 - Filter 1 更温暖，衰减缓慢；Filter 2 是更锐利的参考响应。
  • 音频修复器 (M-DAX) - 关、弱、中或强。重建在压缩音频或流媒体音频中丢失的细节，适合 128k 的网络电台，不适合无损光盘。
Audyssey Dynamic EQ 运行时会接管音调控制：接收机会掌控它们，AVR Maestro 会显示横幅加以说明，免得您纳闷为什么调低音没反应。
第八页

IMAX：完整的 Enhanced 设置菜单

在支持 IMAX Enhanced 的机型上，应用提供完整的菜单，而不只是开关：

  • IMAX 模式 - 自动或关。
  • 音频设置 - 自动遵循 IMAX 推荐设置；手动则开启下面四项控制。
  • 高通滤波器 - 40Hz 至 250Hz。
  • 低通滤波器 - 70Hz 至 250Hz。
  • 低音炮 - 开或关，以及低音炮输出 - LFE+主声道或 LFE。
第九页

Auro-3D：有形态的上混

  • Auromatic 3D 预设 - 小、中、大、Speech 或 Movie。选择上混器所针对的房间与内容特性。
  • 强度 - 0 至 15，决定 Auromatic 生成多少高度信息。
  • Auro 3D 模式 - Direct 或 Channel Expansion。

这些设置仅在环绕声页面选中 Auro 模式时生效，而且只有配备 Auro-3D 解码器的机型才有此页面。

常见问题

声音标签页常见问题

为什么声音模式列表会变化？
因为接收机自己的列表会变化。Denon 或 Marantz 能接受哪些模式，取决于它正在解码什么：双声道信号会提供上混模式，Atmos 信号则提供支持 Atmos 的模式。AVR Maestro 每次都从接收机读取当前列表，而不是显示一个固定的菜单，那样的菜单有一半的时间都是错的。
为什么某个控件显示为灰色并标有 N/A？
N/A 表示接收机在当前状态下没有该项的数值，通常是因为输入信号不带有该功能。点按该行旁边的问号，应用会说明什么样的信号才能启用它。灰色的控件绝不是被隐藏的故障，而是接收机自己的回答。
“声道”和“电平”有什么区别？
“声道”（声音标签页）是针对当前正在播放的信号所做的实时各声道微调。“电平”（扬声器标签页）是保存在扬声器预设中的各扬声器参考电平，由您的校准得出。调整“声道”不会改写您的校准。
我可以同时使用音调控制和 Audyssey 吗？
Dynamic EQ 开启时不行，此时接收机会接管音调控制。在 Audyssey 页面关闭 Dynamic EQ 后，低音和高音就可以重新编辑了。
我需要处于同一网络吗？
可以。AVR Maestro 通过局域网直接与您的接收机通信，没有云账号，中间也没有中继服务器。请参阅快速入门。

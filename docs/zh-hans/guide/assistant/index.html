询问您的接收机

向助手提问，答案来自您的接收机

大多数助手对接收机的一般知识了解很多，而这一款了解的是您的这一台：它此刻的音量、正在运行的扬声器预设、Dynamic EQ 是否开启、此刻正在解码的内容。它读取您自己的接收机并据此回答，使用的是在您设备上运行的模型，而不是别处的某项服务。

在哪里

助手标签页

输入问题，或按住麦克风说出来。无需登录，无需粘贴密钥，也无需账户。只要您的设备能运行设备端模型，打开助手即可使用。

用您自己的话来问。“现在音量多大”“我在用什么看这个”“载入的是哪个 Dirac 插槽”“Dynamic EQ 开了吗”，它会根据接收机实际报告的内容理解您的意思，所以您不必知道某项设置叫什么名字。

它能告诉您什么

应用从您的接收机读取的所有内容，也就是本指南各屏幕上的全部内容。这不是固定的清单：如果某台机器支持 IMAX，就可以询问 IMAX；如果不支持，就绝不会提供该选项。

询问它了解的内容
电源与音量开机或待机、以 dB 为单位的音量、静音、节能模式，以及接收机自身的音量上限
输入源与声音按您设定的名称显示所选输入源、声音模式，以及正在解码的格式
校准Audyssey MultEQ、Dynamic EQ、Dynamic Volume、参考电平偏移、LFC，以及载入的是哪个 Dirac Live 插槽
扬声器布局、各声道微调、低音炮电平以及配置了几台低音炮
视频输入和输出的分辨率与 HDR、画面模式、视频处理、输入模式、HDMI 音频输出、自动音画同步
分区各分区的电源、输入源、音量、声道微调、睡眠定时器以及 Smart Select / Quick Select 插槽
机身前面板亮度、自动待机、Bluetooth 发射器，以及按编号显示的各触发输出
正在播放网络音源上的曲目及其播放状态
在每个回答下方，它会列出生成该回答所读取的内容。这一行是系统记录的，而不是由模型撰写的，所以无法被编造，也是分辨真实答案与听起来很自信的错误答案的最快方法。

它能为您做什么

让它更改某项设置，它就会去更改。不同之处在于每个操作需要多少确认步骤，而这种不对等是有意为之。

请求结果
开机或关机、静音、取消静音立即执行，然后告诉您发送了什么
调低音量立即执行。当有人想要更安静的时候，恰恰是最不想看到弹窗的时候
调高音量先询问。这是唯一一个最坏情况（损坏扬声器单元）无法由房间里的人撤销的操作
切换输入源根据您自己的输入源列表，按您重命名后的名称进行匹配。如果有两个可能的匹配项，它会问您是哪一个

具体数值由您决定。“调低 5 dB”就会调低 5 dB；只说“调低一点”而不给数字，则调整一档，相当于按一次按钮。它不会自行决定您没有说出的数值。

暂不支持在此更改声音模式。您的接收机按类别组织声音模式，并在当前类别中进行选择，因此无法用单一名称发送指令，请在“声音”标签页中正确设置。

征求意见

“有什么校准建议吗？”“怎样让对白更清晰？”“我应该开启 Dynamic EQ 吗？”这些问题不同于查询，助手也会区别对待。它会根据您的读数进行推理，给出几个具体选项，每个都指向您的接收机上确实存在的设置，并说明它会先尝试哪一个。

不变的是数字的来源。它可以自由推理，但不得给出未曾获得的数字。如果您的读数不足以支持某项建议，它会说明还需要查看什么，而不是瞎猜。

用说的代替打字

按住麦克风按钮并说话。它会把您说的内容填入输入框，让您在发送前先看一遍。

请注意：语言模型在您的设备上运行，接收机也在您自己的网络中，因此您输入的问题及其回答都留在您的硬件上。将语音转为文字由手机自带的识别器完成，在大多数手机上，这会把音频发送给平台厂商进行转写。这是操作系统的行为，而不是应用的行为，使用键盘输入则完全避免这一点。
设备要求

哪些设备可以运行

助手会在您自己的设备上运行语言模型。无需账户，无需服务器，无需登录，这也意味着设备上必须已有模型。这不是应用能替您安装的，也是我们唯一无法绕过的要求。

平台所需条件
iPhone、iPad、MaciOS 26 或 macOS 26，且设备支持 Apple Intelligence 并已开启。如果未开启，应用会提示并引导您前往“设置”，而不是隐藏该功能。
Android通过 Google AICore 提供的 Gemini Nano。应用借助 Google 的 ML Kit Prompt API 访问它，而该 API 有自己的支持设备列表，请见下文。
Windows、Linux没有可运行的设备端模型，因此不会显示助手。应用的其余功能不受影响。

故障排除

当它说无法帮忙时

这些提示的措辞各不相同，是有意为之，因为每一种情况的解决办法都不一样。

  • “此设备无法运行设备端模型。”助手在 iPhone、iPad 或 Mac 上需要 Apple Intelligence，在 Android 上需要通过 Google AICore 运行的 Gemini Nano。许多性能不错的设备并不在支持范围内，包括一些当前的平板电脑，以及一些能为其他功能运行 Gemini Nano 的旗舰手机。请参阅上方的哪些设备可以运行。这一点无法在应用内更改。
  • 模型需要下载。Android 会在首次使用时于后台获取。这只需进行一次，文件较大，并且需要 Wi-Fi。
  • “您的接收机具备该功能，但目前没有可报告的内容。”该功能存在，只是当前处于空闲状态：在没有任何播放时询问正在播放什么，就会得到这个回答，而不是声称您的接收机没有 HEOS。
  • “此接收机不报告该信息。”这是关于您硬件的真实回答：机身没有这项功能，应用也不会假装有。
  • 某个子系统无法读取。结果是未知，而不是不存在。助手会如实说明，而不会把读取失败当作您没有这项功能。
  • “我目前还不能在这里更改这一项。”这是助手的局限，而不是接收机的局限，对应的设置界面是可以更改的。
助手是免费的。家庭自动化才是付费部分，两者相互独立：向接收机提问不需要专业版。
常见问题

助手问答

助手会把我的数据发送到别处吗？
语言模型在您的设备上运行，接收机在您自己的网络中，因此您输入的问题及其回答不会离开您的硬件。语音输入是个例外：语音转文字由手机自带的识别器完成，在大多数手机上，这意味着音频会发送给平台厂商进行转写。直接打字则完全避免了这一点。
为什么助手提示我的设备无法运行它？
助手需要设备端模型：iPhone、iPad 和 Mac 上为 Apple Intelligence，Android 上为通过 Google AICore 提供的 Gemini Nano。许多性能不错的设备并不具备这样的模型。应用会如实报告当前处于哪种状态，而不是隐藏该功能，这样您就能知道问题出在下载、设置还是硬件上。
助手会在不询问的情况下更改设置吗？
对于电源、静音、输入源切换和调低音量，它会直接执行，因为房间里的人可以轻松撤销这些操作。调高音量则一律先询问，因为这是唯一一个最坏情况会损坏扬声器单元的操作。
为什么它有时会说无法告诉我某些信息？
因为它不会瞎猜。它给出的每个数字都来自从您的接收机读取的数据，所以如果某项读数没有送达，它会说明无法读取该子系统，而不是编造一个看似合理的数字。听起来正确的错误答案，比没有答案更糟糕。

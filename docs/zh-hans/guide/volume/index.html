音量控制：一个上限、一个开机音量，和一个称心如意的静音

四项设置共同决定接收机最大能有多响、开机时是什么音量，以及静音时降多少。它们保存在接收机上，因此无论您使用应用、实体遥控器还是前面板，都同样有效。

在哪里设置

设置 › 音量控制

打开设置并滚动到音量控制 - “音量上限、开机音量和静音深度”。此页面上的所有内容都会直接写入接收机，所以关闭应用后依然有效，并适用于您控制它的所有方式。

逐项说明

每项设置的作用

音量刻度

音量如何显示，包括屏幕上和接收机自己的显示屏上。0 - 98 是大多数人熟悉的相对刻度；-79.5 至 18.0 dB 是绝对刻度，其中 0.0 dB 为参考电平。如果您见过评测写“-15 dB”，却不知道对应旋钮上的什么位置，这个开关就是答案。

音量上限

一个硬性上限。一旦设定，任何方式都无法超过它：应用不行，实体遥控器不行，前面板旋钮也不行，因为这个上限保存在接收机上，而不是应用里。最明显的用途是防止误触而损坏扬声器或吓到满屋的人，在把遥控器交给来家里的客人之前，就该用它。关则取消上限。

开机音量

使用上次音量默认开启：接收机开机时恢复到关机前的音量。关闭后，您可以改为固定一个音量，这样前一晚在高音量下听到很晚，第二天早上也不会吓一跳。

静音电平

静音时音量降低多少。完全表示完全无声。-40 dB 和 -20 dB 则是衰减而非完全静音，想在看电影时聊几句又不想错过剧情，这样更合适。

应用的其他位置

您每天都会用到的控制

  • 主页仪表盘提供主分区的总音量、静音和电源。
  • 遥控标签页在方向键和播放控制键旁边设有音量摇杆，并实时显示音量。遥控指南 →
  • 每一个音量加减按钮，无论在主页仪表盘、分区卡片还是遥控标签页，点按一下走一步，按住则持续步进，和实体遥控器一样。松手后最多再走一步就会停下。
  • 您手机的音量键在 Android 和 iPhone 上，应用位于前台时可直接控制接收机，让您不用看屏幕也能调节。按住同样会渐变。
  • 每个分区都有独立于主分区的音量。分区指南 →
  • 场景可以记录总音量，因此调用场景时，音量会连同其他设置一并设定。场景指南 →
  • 电视上的屏幕音量读数可以移动，也可以完全关闭。屏幕显示指南 →
音量变化是刻意控制节奏的，而不是每移动一个像素就发送一次，所以按住摇杆或滑动滑块时是平滑渐变，而不会向接收机塞入一堆命令，导致它排队后延迟执行。
常见问题

音量常见问题

音量上限对实体遥控器也有效吗？
有效。该上限是接收机的设置，而不是应用的设置，因此对所有控制途径都生效：应用、随机遥控器、前面板旋钮，以及您网络中的其他任何控制器。
这些设置适用于分区 2 和分区 3 吗？
音量控制涉及主分区。每个分区都有自己的音量，以及各自的电源和输入源，在分区标签页中设置。
为什么评测中用分贝，而应用显示的是 0 至 98？
这是同一个旋钮的两种显示方式。把音量刻度切换为 -79.5 至 18.0 dB，读数就和校准电平的常见表述一致，其中 0.0 dB 为参考电平。
可以使用手机的音量键吗？
可以，Android 和 iPhone 均支持。AVR Maestro 位于前台时，设备的音量键直接控制接收机，按一下调一步，按住则持续渐变；在设置的音频中有一个开关，可把音量键还给设备。

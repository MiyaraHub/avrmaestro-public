AVR Maestro 用户指南

在你的 Denon 或 Marantz 接收机上设置、连接并精通 AVR Maestro 所需的一切。每个界面都会适配你的型号：应用只显示你的机型实际开放的控制项，所以你的界面可能比这里列出的选项更少。

浏览指南

逐个界面详解

先从设置开始，再深入任何功能。重点主题有各自的深度指南，其余内容则在下方各节中介绍。

🚀

入门指南

系统要求、网络设置，以及一分钟内添加你的接收机。
🏠

主页

可自定义的主页：音量、输入源、声音模式、分区等小组件。
🎭

场景

保存你的整套设置，一键调用。这是旗舰功能。
🎨

自定义图标

为每个输入源和场景配上专属图片：可裁剪、可设定形状，并包含在你的备份中。
🎵

声音

全部九个页面：环绕声模式、对白增强 & DRC、Audyssey、Dirac Live、图形均衡器、逐声道微调、音调、IMAX 和 Auro-3D。
🎛️

图形均衡器

在 Audyssey 和 Dirac 关闭时，为每只扬声器塑造 9 段曲线：全部、左/右或逐个。
🔊

扬声器

布局、距离、电平、分频、低音炮和扬声器预设。
🔒

控件为何被锁定

扬声器布局被锁定、Audyssey 不可用、图形均衡器被保持：接收机冻结了哪些项的完整地图，以及如何解锁。
💬

助手

向您自己的接收机提问，或直接告诉它要调整什么。模型在您的设备上运行。

🏠️

家庭自动化

Home Assistant、Hubitat 和 Webhook - 您的场景变成脚本，无需手机也能运行。

🖥️

Home Assistant 仪表板

附完整 YAML 的实例：实时输入源高亮、真实 dB 音量、场景和图表。
🏢

分区

独立控制分区 2 和分区 3 的电源、输入源与音量 - 还有各分区专属的 Smart Select 或 Quick Select 插槽，以及重命名。
🎮

遥控

方向键、播放控制、可重命名并带自定义图标的输入源，以及系统控制。
📻

收音机 (FM/AM)

按频率调谐，或调用已保存的电台预设。
📺

屏幕显示

音量显示位置或关闭、信息横幅、正在播放、21:9 和屏幕保护。
⚙️

设置

设备、外观、按十六进制代码设置的配色主题、音频、帮助和备份。
🌐

语言

29 种语言，自动检测或在设置中选择；希伯来语和阿拉伯语会镜像整个应用。
🔊

音量控制

硬性音量上限、开机音量、静音时降低的幅度，以及 0-98 与分贝两种刻度。
💾

备份 & 恢复

将所有设置导出为一个文件，并在新手机上恢复 - 包括接收机、图标、场景和主题。
🎧

正在播放 & HEOS

专辑封面、曲目信息和播放控制，还可启动 HEOS 浏览音乐。
📱

小组件 & 更多功能

iOS 和 Android 主屏幕小组件，各平台均支持备份与恢复，两端都可使用手机音量键。
📡

支持的接收机

哪些 Denon 和 Marantz 型号可用，以及如何判断。

主页：您的大本营，您说了算

设备状态卡片固定在顶部，显示型号、连接和电源，下方是可自定义的小组件网格。添加、移除和重新排序卡片，让主页恰好显示您关心的内容。

打造专属风格

几秒钟即可完成自定义

轻点左上角的自定义主页图标进入编辑模式：

  • 拖动卡片来重新排序。
  • 轻点红色圆圈来移除卡片。
  • 添加会打开一个面板，列出您尚未添加的小组件。
  • 重置恢复默认设置；完成退出编辑。
编辑时卡片会变暗，避免您误改接收机设置。小组件只有在接收机提供相应功能时才会显示。
为您的房间命名

叫“客厅”，而不是“MAIN ZONE”

长按主页上的分区名称即可重命名任何分区，包括主分区。该名称会写入接收机本身，而不仅仅是应用，因此会显示在厂商自己的应用和其他所有客户端中，在较老的机型上也同样适用。只需重命名一次，家里的每个控制器就都对这个房间叫什么达成一致。

小组件

您可以固定的全部内容

小组件功能
音量带 dB 读数的滑块、静音，以及 8 个已保存的音量预设。
信号源打开输入源选择器；长按磁贴可重新排序。重命名后的信号源，以及您在遥控输入源网格中设置的自定义输入源图标，也会显示在这里。
声音模式当前环绕声模式；轻点可打开分组选择器。
正在播放HEOS 信号源的专辑封面、曲目信息和播放控制。
分区精简的分区 2 / 分区 3 状态和快捷控制，包括该分区自己的 Smart Select 或 Quick Select 存储位：轻点存储位即可调用，长按则将该分区当前的状态保存到其中。
Smart Select / Quick Select接收机自带的记忆存储位，沿用接收机自己的叫法：Marantz 上叫 Smart Select，Denon 上叫 Quick Select。重命名后的存储位保存在接收机上，因此您的命名会在所有应用中显示。
扬声器预设预设 1 / 2 切换器，仅在提供多个预设的接收机上显示。
Audyssey / Dirac一目了然的校准状态，外加快速跳转入口。
声道 / 低音炮电平各声道和低音炮的电平快照，带步进调节，低音炮数量会跟随接收机的实时配置。
ECO、Sleep、DRC、Restorer、Video、Room Size、LFE一键开关和选择器，仅在受支持时才会显示。
声音控制

声音中的快捷开关

  • 图形均衡器：在“声音”、“音频功能”中开启或关闭接收机的图形均衡器。仅在 Dirac Live 和 Audyssey 都没有运行房间校正时可用，应用与接收机自身的规则保持一致。
  • 低音炮：在“声音”、“音频功能”中静音或启用低音炮，无需进入扬声器设置。仅在报告并接受此功能的接收机上显示。
  • 音频修复器：接收机的压缩音频修复功能，Denon 上叫Restorer，Marantz 上叫 M-DAX，在“声音”、“音调”下以开关形式提供，紧挨着 DAC 滤波器。无需进入屏幕菜单，就能让 MP3 和流媒体音源重焕生机。
正在播放 & HEOS

查看并控制正在播放的内容

当前信号源提供元数据时，“正在播放”卡片会显示专辑封面、曲目/艺术家/电台信息和播放控制（播放/暂停/下一首/上一首）。

要浏览音乐，包括电台、队列、流媒体服务和 HEOS 房间，请轻点“正在播放”卡片上的启动 HEOS。AVR Maestro 会打开官方 HEOS 应用供您浏览；一旦在那里开始播放，AVR Maestro 就会重新接管正在播放的显示、播放控制和小组件。模拟、光纤/同轴和 HDMI 直通信号源不提供元数据，因此这类信号源的卡片会保持空白。

常见问题

主页常见问题

我可以自定义主页吗？
可以。轻点“自定义主页”，然后拖动重新排序，轻点红色圆圈移除，“添加”可增加更多小组件，“重置”恢复默认，“完成”结束编辑。编辑时卡片会变暗，避免您误改设置。
我可以重命名分区吗，包括主分区？
可以。长按主页上的分区名称即可。该名称会写入接收机本身，因此会显示在厂商的应用和其他所有客户端中，在较老的机型上也同样适用。
它会显示正在播放的内容吗？
会，前提是信号源提供元数据，包括专辑封面、曲目/艺术家/电台以及播放控制。轻点“启动 HEOS”进行浏览；播放开始后，AVR Maestro 会重新接管正在播放的显示。

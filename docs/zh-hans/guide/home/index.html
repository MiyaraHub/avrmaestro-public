主页

主页：您的大本营，您说了算

设备状态卡片固定在顶部，显示型号、连接和电源，下方是可自定义的小组件网格。添加、移除和重新排序卡片，让主页恰好显示您关心的内容。

打造专属风格

几秒钟即可完成自定义

轻点左上角的自定义主页图标进入编辑模式：

  • 拖动卡片来重新排序。
  • 轻点红色圆圈来移除卡片。
  • 添加会打开一个面板，列出您尚未添加的小组件。
  • 重置恢复默认设置；完成退出编辑。
编辑时卡片会变暗，以免您不小心更改接收机设置。只有接收机支持该功能时，小组件才会显示。全新的主屏幕从 Smart Select / Quick Select、音量、输入源、声音模式、场景、信号信息、正在播放和分区开始。每张卡片的更多说明见小组件指南。
多台接收机

从标题切换接收机

连接接收机后，它的名称会显示在主屏幕顶部 AVR Maestro 的旁边。轻点它可查看您添加的所有接收机，选择一台使其成为当前接收机，或选择管理接收机来添加和重新排序（设置 › 管理接收机）。状态卡片下方的搜索框可以找到应用中的任何设置；请参阅搜索指南、接收机指南和应用导览。

音量预设

八个音量级别，一键直达

  • 轻点空插槽，把当前音量保存到其中。
  • 轻点已存插槽，跳转到该音量。
  • 长按任意插槽，用当前音量覆盖它或清除它。

更多内容见音量指南。

为您的房间命名

叫“客厅”，而不是“MAIN ZONE”

长按主页上的分区名称即可重命名任何分区，包括主分区。该名称会写入接收机本身，而不仅仅是应用，因此会显示在厂商自己的应用和其他所有客户端中，在较老的机型上也同样适用。只需重命名一次，家里的每个控制器就都对这个房间叫什么达成一致。

小组件

您可以固定的全部内容

小组件功能
音量带 dB 读数的滑块、静音，以及 8 个已保存的音量预设（见下文）。
信号源打开输入源选择器；长按磁贴可重新排序。重命名后的信号源，以及您在遥控输入源网格中设置的自定义输入源图标，也会显示在这里。
声音模式当前环绕声模式；轻点可打开分组选择器。
信号信息音频输入 / 音频输出和视频输入 / 视频输出（分辨率和 HDR）、采样率，以及接收机报告的其他所有 HDMI 信号详情，例如色彩空间和像素深度。接收机没有报告的读数会被省略，而不是显示为空。
正在播放HEOS 音源的专辑封面、曲目信息和播放控制，以及收藏和启动 HEOS按钮。更多内容见正在播放与 HEOS 指南。
分区紧凑的分区 2 / 分区 3 状态与快速控制，包括该分区自己的 Smart Select 或 Quick Select 插槽 - 轻点插槽调用，长按则把该分区当前的状态保存到其中。仅限多分区接收机。
Smart Select / Quick Select接收机自带的记忆存储位，沿用接收机自己的叫法：Marantz 上叫 Smart Select，Denon 上叫 Quick Select。重命名后的存储位保存在接收机上，因此您的命名会在所有应用中显示。
ECO 模式自动、开或关，一键切换。
睡眠定时器关闭、30、60、90 或 120 分钟。
扬声器预设预设 1 / 2 切换器，当您的接收机报告有扬声器预设时显示。
音频修复压缩音频修复器：关闭、低、中或高，仅在接收机应答时显示。
场景一键调用已保存的场景。场景在场景页面创建。
扬声器布局输入和输出声道布局，例如 5.1.2。
扬声器网格哪些扬声器正在发声的实时网格，输入与输出并排显示。仅限提供该信息的接收机；请参阅扬声器指南。
视频处理视频模式：自动、电影、游戏或旁通。
DRC动态范围压缩：自动、关闭、低、中或高。
Dirac Live 滤波器当前扬声器预设上的 Dirac Live 插槽，附带深层链接。仅限 Dirac 接收机。
Audyssey 状态一目了然地显示 MultEQ、Dynamic EQ、参考电平偏移、Dynamic Volume、LFC 和抑制量。仅限 Audyssey 接收机。
声道电平快照接收机报告的每个声道电平的读数。
低音炮电平带加减按钮的低音炮电平调整。设置了低音炮并且有音频信号时显示。
音频延迟0 到 500 ms 的口型同步延迟，接收机报告该项时可用。
LFE 电平LFE 声道电平，接收机报告该项时可用。
声音控制

声音中的快捷开关

  • 图形均衡器：开关位于图形均衡器页面本身（声音 › 图形均衡器），在标题行中重置和复制按钮的旁边。只有当 Dirac Live 和 Audyssey 都没有运行房间校正时，才能编辑频段；应用与接收机自身的规则一致。请参阅图形均衡器指南。
  • 低音炮：从声音 › 环绕声 › 音频功能静音或启用低音炮，无需深入扬声器设置。仅在报告并接受该设置的接收机上显示。
  • 音频修复器：接收机的压缩音频修复器 - Denon 上叫 Restorer，Marantz 上叫 M-DAX - 位于声音 › 音调下。无需进入屏幕菜单，就能让 MP3 和流媒体音源重焕生机。
正在播放 & HEOS

查看并控制正在播放的内容

当前信号源提供元数据时，“正在播放”卡片会显示专辑封面、曲目/艺术家/电台信息和播放控制（播放/暂停/下一首/上一首）。

要浏览音乐 - 电台、队列、流媒体服务、HEOS 房间 - 请轻点“正在播放”卡片上的启动 HEOS。AVR Maestro 会打开官方 HEOS 应用供您浏览；一旦在那里开始播放，AVR Maestro 会重新接管正在播放的显示、播放控制和小组件。模拟、光纤/同轴和 HDMI 直通音源不报告元数据，因此这些音源的卡片保持为空。收藏按钮以及卡片上的其他一切内容，都在正在播放与 HEOS 指南中介绍。

常见问题

主页常见问题

我可以自定义主页吗？
可以。轻点“自定义主页”，然后拖动重新排序，轻点红色圆圈移除，“添加”可增加更多小组件，“重置”恢复默认，“完成”结束编辑。编辑时卡片会变暗，避免您误改设置。
我可以重命名分区吗，包括主分区？
可以。长按主页上的分区名称即可。该名称会写入接收机本身，因此会显示在厂商的应用和其他所有客户端中，在较老的机型上也同样适用。
可以在主屏幕上切换接收机吗？
可以。轻点顶部 AVR Maestro 旁边的接收机名称并选择另一台接收机，或选择“管理接收机”来添加或重新排序。
它会显示正在播放的内容吗？
会，前提是信号源提供元数据，包括专辑封面、曲目/艺术家/电台以及播放控制。轻点“启动 HEOS”进行浏览；播放开始后，AVR Maestro 会重新接管正在播放的显示。

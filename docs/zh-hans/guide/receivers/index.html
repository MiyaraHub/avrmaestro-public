管理接收机，每台接收机一个页面

您有多少台 Denon 和 Marantz 接收机就添加多少台，点两下即可在它们之间切换，并为每台设置各自的音频偏好。每台接收机都有自己的页面，用于名称、地址、锁定和固件。

在哪里设置

打开管理接收机

打开设置。最顶部的卡片是管理接收机：它显示您有多少台接收机以及哪一台处于活动状态。轻点它。

您会看到：“轻点接收机进行设置。轻点圆圈将其设为活动。拖动可重新排序。”这一行，然后是您的接收机，每台都带有名称、IP 地址和型号。活动的接收机会高亮显示，其圆圈为实心。列表下方是添加接收机按钮，如果您尚未处于演示模式，还有一个演示模式部分。

  • 轻点接收机可打开它自己的页面。
  • 轻点行首的圆圈，将该接收机设为活动。应用会显示已切换到及接收机的名称。
  • 拖动行末的手柄可更改顺序。主页顶部的接收机列表遵循同样的顺序。
  • 长按接收机可打开快捷菜单，其中有重命名、更改 IP、查找我的接收机和删除。
分步操作

添加接收机

  1. 打开设置 › 管理接收机并轻点添加接收机（或右上角的 +）。
  2. 在 iPhone、iPad、Mac、Android 和 Windows 上，该屏幕会扫描您的网络并列出在您网络上找到的接收机。轻点您的接收机。如果没有任何应答，请轻点重新扫描，或在 IP 地址中输入接收机的地址并轻点测试并保存。
  3. 应用会一次性测试连接并保存接收机。您会看到检测到的型号和功能，新接收机会成为活动接收机。
接收机的 IP 地址位于它自己菜单的设置 › 常规 › 网络 › 信息下。手机或电脑必须与接收机处于同一网络。网络检查清单请参阅开始使用。
点两下

从主页切换接收机

  1. 在主页标签页，轻点屏幕顶部 AVR Maestro 旁边显示的接收机名称。
  2. 会打开一份接收机列表，当前活动的接收机旁带有勾选标记。轻点另一台接收机即可切换到它，或轻点列表底部的管理接收机打开完整页面。

每台接收机都在您的设备上保存自己的数据，所以切换后会立即加载该接收机的设置。

设置 › 管理接收机 › 您的接收机

接收机页面

轻点接收机即可打开它的页面。顶部的卡片显示其连接状态和详情。如果它不是活动接收机，卡片下方会有一个设为活动按钮，因为音量限制、显示和锁定只能在活动接收机上更改。如果它处于活动状态但无法访问，页面会显示“应用目前未连接到接收机。”

音频

您对这台接收机的个人偏好。每台接收机保存各自的数值。音量指南 →

  • 音量步进：一次按键音量变化多少，0.5、1、1.5 或 2 dB。应用中的每个音量按钮都使用它。
  • 在顶部显示绝对音量：交换音量读数中哪个数字更大。关闭（默认）时 dB 大、音量刻度小；开启时音量刻度大、dB 小。
  • 遥控音量显示：遥控标签页显示 dB 刻度（绝对值 (dB)，例如 -40.5 dB）还是 0-98 刻度（相对值，例如 39.5）。
  • 渐变音量预设：开启（默认）时，轻点音量预设会以小步进渐变音量；关闭时，直接跳到已保存的电平。
  • 设备音量按钮（手机和平板）：应用打开期间，设备自带的音量键会更改接收机的音量。默认开启；关闭后音量键还给设备。
  • 音量控制：音量限制、开机音量和静音深度，写入接收机本身。应用连接到这台接收机时显示。音量控制指南 →

屏幕与锁定

连接期间为活动接收机显示。

  • 屏幕显示：音量读数、信息横幅、正在播放和 21:9。屏幕显示指南 →
  • 设置锁定：锁住接收机自己的设置菜单。锁定期间，音频、视频、扬声器及其他设置都无法在任何地方更改，不论是在接收机菜单、本应用还是它的网页门户。音量、输入源和调光等日常控制仍可使用。开启时会先询问（锁定接收机菜单？，然后锁定）；关闭开关即可解锁。
  • 遥控锁定：让接收机忽略来自其红外遥控器的按键，直到您解锁。应用和前面板仍可使用。
只有接收机报告其状态时，才会出现设置锁定和遥控锁定。如果您的接收机不报告某个锁，开关不会显示，而不是凭空猜测。应用中其他地方因设置锁定而变灰的控件，在控件为何被锁定中说明。

关于此接收机

  • 设备信息：接收机的详细状态。
  • 固件：已安装的固件版本。轻点检查询问接收机是否有可用更新。下方的文字行随后会说明您使用的是最新固件、有可用更新、更新正在进行，或无法读取状态。更新要在接收机自己的设置菜单中安装，而不是在应用中；更新期间请勿关闭接收机电源。

管理

  • 重命名：在设备名称中输入新名称并轻点保存。该名称仅存储在应用中。
  • 更改 IP：输入新的 IP 地址或主机名并轻点保存，例如在路由器分配了新地址之后。该接收机所有已保存的设置都会保留；只有地址改变。已被您的另一台接收机使用的地址会被拒绝。
  • 查找我的接收机：在网络上搜索这台接收机的新地址。如果它在别处找到了您的接收机，请轻点使用此地址。当保存的地址已经正确、没有任何应答，或有多台接收机可能是您的接收机时，它都会告诉您；在最后这种情况下它不会更改任何内容，请改用“更改 IP”。
  • 删除：询问要删除接收机吗？然后从应用中移除该接收机及其所有已保存的设置。删除活动接收机会让应用切换到另一台。
无需接收机

演示模式，进入与退出

演示模式在应用内运行一台模拟的 Marantz CINEMA 30。每个屏幕都和使用真实硬件时一样工作，不会通过您的网络发送任何内容。

  1. 启动方式：从设置 › 管理接收机 › 试用演示模式、“添加接收机”屏幕上的体验演示模式，或欢迎指南中的改为试用演示。演示接收机会成为活动接收机，应用打开主页。
  2. 预览专业版。演示运行期间，设置中会显示演示模式部分。它的预览专业版功能开关仅在本次演示会话中解锁家庭自动化和触发器。不会产生任何购买。
  3. 退出方式：设置 › 退出演示模式。演示接收机会被移除，应用回到您自己的接收机。
常见问题

接收机，答疑

如何切换到另一台接收机？
在主页标签页，轻点顶部 AVR Maestro 旁边的接收机名称，然后从列表中选择另一台接收机。您也可以打开设置 › 管理接收机，并轻点接收机行开头的圆圈。应用会以“已切换到”加接收机名称来确认。
我的接收机获得了新的 IP 地址。该怎么办？
通常无需操作：当路由器更改了接收机的地址时，应用会重新找到它，并只告诉您一次它已跟随。如果找不到，请打开设置 › 管理接收机，轻点该接收机，使用“查找我的接收机”搜索网络，或使用“更改 IP”自己输入新地址。该接收机所有已保存的设置都会保留；只有地址改变。
为什么我看不到“屏幕与锁定”或“关于此接收机”？
这些部分会实时读取和写入接收机，所以只有在应用已连接到当前接收机时才会显示。请用“设为活动”将该接收机设为当前接收机，并等待其连接。
设置锁定和遥控锁定有什么区别？
设置锁定会锁住接收机自己的设置菜单，因此任何人（包括本应用）都无法更改其设置和校准设置，直到您解锁。音量和输入源仍可使用。遥控锁定会让接收机忽略它的红外遥控器；应用和前面板仍可使用。只有当您的接收机报告该锁时，对应的开关才会出现。
删除接收机会怎样？
应用会移除该接收机及其所有已保存的设置。如果它是当前接收机，应用会切换到另一台。接收机本身不会有任何改变，您可以随时重新添加它。
没有接收机也能试用应用吗？
可以。在设置 › 管理接收机中轻点“试用演示模式”，或在“添加接收机”屏幕上轻点“体验演示模式”。演示模式在应用内运行一台模拟的 Marantz CINEMA 30，不会通过您的网络发送任何内容。可从设置 › 退出演示模式退出。

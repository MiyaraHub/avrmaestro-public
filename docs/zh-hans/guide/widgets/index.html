Android、iPhone 和 iPad

主屏幕小组件

无需打开应用即可控制接收机：电源、音量和静音、正在播放的内容、当前信号以及您的场景，就在主屏幕上。小组件适用于 Android 以及 iPhone 和 iPad。Mac 和 Windows 没有小组件。

四个小组件

  • 快速控制（Android：AVR Quick Control）。接收机名称、输入源和音量，带有电源、音量减、音量加和静音。在 Android 上还有“打开应用”，接收机关闭时音量和静音按钮会隐藏，只保留电源。
  • 正在播放（Android：AVR Now Playing）。封面、标题、艺术家和电台，带有上一首、播放或暂停和下一首。没有播放内容时，Android 上显示“No media playing”，iPhone 和 iPad 上显示“Nothing playing”。
  • 接收机状态（Android：AVR Signal Status）。输入源、输入和输出的音频与视频信号、采样率和音量。
  • 场景（Android：AVR Scenes）。为接收机保存的场景。轻点其中一个即可应用，无需打开应用。参见场景。
小组件跟随应用中选中的接收机。接收机处于待机时，快速控制和状态显示待机；无法连接时显示AVR 已关闭。
分步操作

添加小组件

  1. 先打开一次 AVR Maestro 并连接到接收机，让小组件有内容可显示。
  2. 触摸并按住主屏幕的空白处，然后选择手机的小组件选项。
  3. 找到 AVR Maestro 并选择一个小组件。在 Android 上，名称以 AVR 开头。在 iPhone 和 iPad 上，快速控制、正在播放和接收机状态为中等尺寸，场景为中等或大尺寸。
  4. 在 Android 上，拖动小组件的边缘可调整大小。小尺寸会切换为紧凑布局。
iPhone 和 iPad 小组件需要 iOS 或 iPadOS 17 或更高版本。

让小组件保持最新

  • 刷新按钮。快速控制、正在播放和场景有刷新按钮，可立即更新小组件。在 Android 上，正在播放在较大尺寸下显示该按钮。
  • 自动刷新。快速控制和状态会自行每隔约 15 分钟更新一次，在 Android 上正在播放也是如此。在 Android 上这需要网络连接。场景会在您于应用中更改场景或轻点刷新时更新。
在 Android 上，您第一次使用小组件时，应用会说明主屏幕小组件并提供打开设置。为了获得最可靠的后台更新，请在电池设置中允许 AVR Maestro 在后台运行。

小组件颜色

两项设置都位于设置的外观下，适用于 Android、iPhone 和 iPad。

  • 高对比度小组件会让小组件变为灰阶。
  • 小组件跟随应用配色会在小组件上使用您的配色主题强调色，而不是标志性的橙色。开启高对比度小组件时，此开关不可用，小组件保持灰阶。
同一部分中的小组件大小不会改变主屏幕小组件。它缩放应用内的按钮、芯片和卡片（小、中、大或更大）。参见设置。
常见问题

小组件，答疑

AVR Maestro 有哪些主屏幕小组件？
四个，适用于 Android 以及 iPhone 或 iPad：快速控制（电源、音量和静音）、正在播放（播放的内容，带上一首、播放或暂停和下一首）、iPhone 上的接收机状态或 Android 上的信号状态（输入源以及音频和视频信号），以及场景（应用已保存的场景）。Mac 或 Windows 上没有小组件。
小组件多久更新一次？
快速控制和接收机状态会自行每隔约 15 分钟更新一次，在 Android 上正在播放也是如此。快速控制、正在播放和场景还有刷新按钮，可立即更新小组件。
为什么我的小组件显示 AVR 已关闭或待机？
待机表示接收机处于待机状态。AVR 已关闭表示小组件无法连接到接收机，例如它已拔掉电源或在另一个网络上。
为什么场景小组件显示没有场景？
小组件列出为所选接收机保存的场景。请先打开 AVR Maestro 创建一个场景，参见场景指南。
小组件大小会改变主屏幕小组件吗？
不会。设置 › 小组件大小改变的是应用内按钮、芯片和卡片的大小。要更改主屏幕小组件的大小，请在主屏幕上调整它。
小组件可以使用我的主题颜色吗？
可以。开启设置 › 小组件跟随应用配色，小组件就会使用您的强调色而不是橙色。开启高对比度小组件时该选项不可用，因为那些小组件是灰阶的。

FM/AM 调谐器

真正的 FM/AM 收音机，预设还能命名

在内置调谐器的 Denon 和 Marantz 接收机上，AVR Maestro 为您提供完整的 FM/AM 收音机界面。电台卡片会显示实时的波段、频率和当前预设，并实时跟随接收机的状态。

工作方式

调谐、扫描与保存

  • 波段：FM / AM。调谐模式：自动（扫描到下一个强信号电台）或手动（按波段步进值逐步调节）。
  • 调谐：两个“调谐”按钮用于步进调节；输入频率会打开数字键盘，直接跳到某个电台（需要手动模式）。
  • 预设：由预设位置组成的网格，外加上下步进按钮。长按某个位置即可保存当前电台、添加/重命名标签（如“Jazz 88”“NPR”），或清除标签。
如果“电台”标签页被隐藏，请从设置 → 自定义导航中重新添加。只有接收机提供调谐器时，它才会出现。
常见问题

调谐器常见问题解答

我可以在应用中控制 FM/AM 收音机吗？
可以，适用于内置调谐器的接收机。应用提供实时的波段/频率/预设显示、FM/AM 切换、自动或手动调谐、可直接跳到某个频率的数字键盘，以及预设网格。
我可以给预设命名吗？
可以。长按某个位置即可保存当前电台，添加或重命名标签（如“Jazz 88”“NPR”），或清除标签。
为什么我看不到“电台”标签页？
只有内置调谐器的接收机才会显示该标签页。如果您的接收机有调谐器，请确认调谐器已显示为输入源，然后在“设置”的“自定义导航”中重新启用该标签页。

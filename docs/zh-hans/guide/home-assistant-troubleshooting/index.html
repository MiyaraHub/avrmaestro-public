当关联或脚本出问题时

Home Assistant，无法正常工作时

大多数 Home Assistant 问题都归结为关联状态、接收机实体 ID，或者手机与服务器之间的网络。先看关联卡片上写了什么，再逐项往下排查。

关联卡片在告诉你什么

Sync 按钮上方的卡片显示关联的状态，按钮会随之变化。

  • 已关联 Home Assistant：刚刚有一次经过身份验证的调用成功。Sync 按钮可用。
  • Home Assistant 关联已过期：服务器作出了应答，但拒绝了已保存的令牌。在你重新登录之前，Sync 按钮处于禁用状态。
  • 无法连接到 Home Assistant：无法连上你的服务器，而令牌可能完全有效。Sync 按钮仍然可用，也不会更改任何内容。
  • 未关联 Home Assistant：尚未保存地址或令牌。请添加你的地址并登录。
  • Home Assistant 关联未检查：演示模式已开启，或家庭自动化已锁定，所以没有向你的家发送任何内容，令牌也没有被尝试使用。
只有第一种会显示“已关联”，而且只是因为有内容通过了身份验证。仅仅保存了令牌，从来都不算关联。

脚本没有任何反应，或显示 Entity Not Found

  • 在 Home Assistant 的“设置”，“设备 & 服务”中安装官方 Denon AVR 集成。
  • 请确认 AVR Maestro 设置中的 Receiver Media Player Entity ID 与 Home Assistant 中的实体 ID 完全一致。
  • 场景被删除或重新创建后，请忽略任何显示 unavailable 的实体。场景脚本按场景创建的时间命名，所以脚本 ID 如何变化一次，请参见家庭自动化。

Home Assistant 中缺少新场景

每当你添加、编辑或删除场景时，场景都会在后台同步，所以不必每次都按 Sync。如果缺少某个场景，说明手机没能连上你的服务器。

  • 让手机接入与 Home Assistant 相同的本地 Wi-Fi 网络。
  • 打开设置并轻点 Sync Scenes。如果失败，它会显示具体的网络错误。

Home Assistant 日志中的 Failed login

几次失败的尝试，或者浏览器在关联完成前断开了连接，都会在 Home Assistant 中留下一条警告。它是历史记录，不是当前故障，关联正常之后你可以忽略它。

其他可能出问题的地方

  • 仪表板图块始终不亮：请参见 Home Assistant 仪表板指南。
  • Webhook 没有送达：请参见家庭自动化。
  • 还是卡住了？请到 Discord 提问，或查看帮助。
常见问题

Home Assistant 问题解答

我的脚本运行了，但显示 Entity Not Found，或者没有任何反应。
请确认 Home Assistant 中已安装官方 Denon AVR 集成。然后检查 AVR Maestro 设置中的 Receiver Media Player Entity ID 是否与 Home Assistant 中的实体 ID 完全一致，例如 media_player.living_room_receiver。
为什么我的 Home Assistant 日志里写着 Failed login？
如果关联时有过几次失败的尝试，或者浏览器在完成之前断开了连接，Home Assistant 就会记录一条警告。关联成功之后，你可以放心忽略这条旧警告。
我创建了新场景，但它没有出现在 Home Assistant 中。
请确认手机与 Home Assistant 服务器处于同一个本地 Wi-Fi 网络，因为手机连不上服务器时，后台同步会失败。打开设置并轻点 Sync Scenes，如果有网络错误，就能看到具体内容。
脚本运行时，应用需要保持打开吗？
不需要。脚本存放在 Home Assistant 中，所以手机放在口袋里时，它们也能通过你的仪表板、自动化或语音助手运行。只有在你更改场景时，应用才会构建并更新它们。

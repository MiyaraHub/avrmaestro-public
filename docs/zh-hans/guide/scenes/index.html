场景：一键设置整个房间

观影之夜、深夜模式、黑胶之夜。每一个场景都是一键完成，把输入源、声音模式、Audyssey 或 Dirac、电平和分区设成您喜欢的样子。您无需了解接收机的菜单就能创建场景：应用会问几个简单的问题，并且只提供接收机真正能做到的选项。

两种开始方式

点按“添加场景”，然后选择构建方式

  • 场景创建器会和您一起回答几个问题，只提供接收机支持的选项。最适合您的第一个场景，或是您知道想要什么、却不知道在哪个菜单里的时候。
  • 从当前状态创建会捕获接收机此刻的状态。先调出满意的声音，勾选要保留的设置，然后保存。
“场景”标签页里还什么都没有？它会推荐几个适合您接收机的起点，比如电影和电视或深夜。点按其中一个，场景创建器就会打开，并已选好该项。
场景创建器，一步一步来

大约一分钟，完成您的第一个场景

场景创建器根据您的回答构建场景。它不会读取接收机，保存也不会更改任何内容，所以您可以放心尝试各种想法。顶部的步骤计数器会显示您所处的位置，点按“返回”可回到之前的任何一个回答。

  1. 为它命名。起一个忙碌的晚上也能认出来的名字：观影之夜、周六听唱片、孩子们的卡通时间。
  2. 说明它的用途。电影和电视、音乐、游戏、深夜、其他房间，或是想自己选择一切时的自定义。这个选择只会突出显示通常适用的设置，不会替您勾选任何内容。
  1. 勾选它要控制的内容。设置按您思考的方式分组：路由 & 音量、声音、Audyssey & Dirac、扬声器 & 电平、分区、其他和外观。这里只列出接收机支持的设置，标有建议的是针对您在第 2 步所选用途的常用选择。
Audyssey 和 Dirac Live 是两种不同的房间校正系统，您的接收机每个扬声器预设只使用其中一种。当 Dirac Live 处于活动状态时，部分 Audyssey 设置会被接收机自身锁定，应用会在您勾选时就告知这一点，而不是让您保存一个无法应用的场景。请参阅控件为何被锁定。
  1. 为每项设置选择一个值。每个勾选的设置对应一个简短的页面，列出接收机报告的数值：声音模式、输入源、Dirac 插槽和扬声器预设，电平则按接收机的显示方式呈现。
  • 显示其他类型。接收机只会列出当前播放内容所属类型的声音模式。点按后，应用会短暂读取其他类型，然后把接收机恢复到原来的状态。
  • 显示哪些预设是 Audyssey 或 Dirac。对扬声器预设使用同样的办法，让每个位置在您选择之前就带有标签。
  • 保存时，声道电平会原样保留。想要不同的数值？请先在“扬声器”标签页中调整，然后再回来。
  1. 核对并保存。最后一页会准确列出场景将要保存的内容，分组方式与应用其余部分一致。点按保存，它就会出现在您的场景列表中，随时可用。
步骤数量取决于您勾选的内容：每个勾选的设置各占一页，所以包含三项设置的场景比包含十项设置的更短。
从当前状态创建

声音已经完美？那就留住它

当房间的声音已经恰到好处时，无需回答任何问题。点按添加场景，选择从当前状态创建，为它命名并勾选要保留的内容。场景会保存接收机当前的数值，而且只保存这些设置。

在场景创建器中选择自定义，您会得到同样完整的列表，而无需读取接收机，这在为以后做准备时很方便。

场景可以包含什么

几乎所有设置，且只包含您所选的

应用场景只会更改它包含的设置。深夜场景可以调低音量并开启 Dynamic Volume，同时让您的输入源、声音模式和校准保持原样。

电源、路由 & 音量

主分区电源、输入源和主音量。场景可以在加载时打开接收机。

声音

声音模式、Restorer、对白增强、音调、Cinema EQ、图形均衡器、IMAX Enhanced、扬声器虚拟化和中置扩散。

🎲

Audyssey & Dirac

MultEQ、Dynamic EQ、Dynamic Volume、LFC，以及当前的 Dirac Live 插槽。

扬声器 & 电平

扬声器预设，以及各声道和低音炮的电平。

分区

分区 2 和分区 3 的电源、输入源和音量，以及全分区立体声。

附加功能

ECO、睡眠定时器、调光、HDMI 音频输出、调谐器电台、接收机的设置锁定，甚至应用自己的配色主题。

具体出现哪些选项取决于您的接收机。应用只列出您的机型报告的内容，因此您绝不会围绕一个它没有的设置去创建场景。

使用和修改场景

点按即可应用，按住查看更多

点按某个场景，在设置按安全顺序逐项发送期间，它的磁贴会显示正在应用…。长按它可使用其余功能：

  • 用当前设置更新会保留名称、图标和设置列表，并采用接收机此刻的数值。无需删除后重新保存。
  • 编辑已捕获的设置可为场景添加或移除设置。
  • 重命名场景和更改图标 & 颜色，包括使用您自己的图片（参见自定义图标）。
  • 复制场景可制作一个变体，例如观影之夜和观影之夜（孩子已睡），无需从头再来。
  • 家庭自动化（专业版）会把场景发送到 Home Assistant 或 Hubitat，这样一个自动化就能同时调暗灯光并设置接收机。参见家庭自动化。
  • 删除场景会在此处将其移除，下一次 Home Assistant 同步会移除它创建的脚本。
拖动场景的手柄可对列表重新排序。场景也会作为卡片显示在主屏幕上，您无需打开应用就能从手机主屏幕触发：在 Android 上，从启动器的小组件列表添加 AVR Scenes 小组件；在 iPhone 上，从小组件库添加场景小组件。请参阅小组件。
场景与 Smart Select / Quick Select

您接收机的存储位，使用它们的真名

您的接收机也有若干自带的预设位。Marantz 称之为 Smart Select，Denon 称之为 Quick Select，AVR Maestro 在每个界面都使用您接收机自己的叫法：主页的那一行、遥控标签页、自定义标签页和设置指南。Marantz CINEMA 30 有五个。

  • Smart Select / Quick Select 存放在接收机里。可以从主页或遥控器触发某个位置，长按即可重命名。
  • 场景保存在应用中：每台接收机最多 20 个，每个都有自己的名称、图标和颜色，只保存您选择的设置，并且可以从主屏幕小组件触发，或成为 Home Assistant 脚本。

两者互不覆盖，所以请两者并用：存储位用于接收机自己的快速切换，其他一切交给场景。

故障排除

场景没有完全应用时

场景并不是一条命令，而是一个序列，按刻意安排的顺序发送，并控制节奏以便接收机跟得上，所以它需要片刻时间，而不是瞬间完成。

  • 电源最先，冷启动的接收机会获得唤醒的时间。如果场景要打开接收机，其他一切都会等它启动完成，因为还在启动中的接收机会忽略设置。
  • 声道电平会被检查并重发一次。一次收到大量内容时，接收机偶尔会漏掉某个声道。应用会读回实际生效的内容，重发没有生效的部分，并告诉您它重试了哪些声道。
  • 被锁定的控件无法被任何方式应用。如果您的扬声器预设由 Dirac Live 掌管，接收机本身会拒绝 Audyssey 的更改，包含这些更改的场景也会像屏幕上的控件一样被拒绝。请参阅控件为何被锁定。
  • 只会更改场景包含的内容。如果场景没有更改您预期的某项内容，多半是因为它没有被勾选。请长按它并使用“编辑已捕获的设置”，而不是再创建第二个场景。
  • 场景属于某一台接收机。列表是当前所选接收机的列表。另一台接收机有它自己的列表。
轻点之后

场景之后的消息是什么意思

场景完成时，应用会读回接收机做了什么，并在屏幕底部显示一条消息。它的颜色说明进展如何。每条消息都有关闭按钮；红色消息会一直停留，直到您关闭。

  • 绿色 - 场景“名称”已应用。场景所保存的一切都已到位。
  • 橙色 - 接收机选择了不同的值。您的接收机为以下项目选择了不同的值：...接收机按输入信号记忆某些设置，并为所列出的设置选择了自己的值。这是正常的；再次轻点场景可重试。
  • 蓝色 - 已发送，但未确认。您的接收机没有回报：...或您的接收机没有确认扬声器电平。应用无法判断这些是否生效。它并不是说它们失败了。再次轻点场景进行检查。
  • 红色 - 某项设置回读的值不同。您的接收机现在为以下项目报告了不同的值：...再次轻点场景，或检查接收机。
  • 红色 - 扬声器电平被拒绝。您的接收机没有接受这些扬声器电平：...这可能发生在它忙于切换声音模式时。应用已经重试过一次；再次轻点场景来设置它们。
常见问题

场景常见问题解答

什么是场景？
场景就是一键让接收机为某件事做好准备：一部电影、一张唱片、一局游戏、一个安静的深夜。它可以包含输入源、音量、声音模式、Audyssey 或 Dirac、扬声器预设、声道电平、分区、调谐器电台和电源状态。应用场景时，只会更改您选择的设置，其余一切保持原样。
如何创建我的第一个场景？
打开“场景”标签页，点按“添加场景”，然后选择“场景创建器”。为它命名，说明它的用途（电影和电视、音乐、游戏、深夜、其他房间或自定义），勾选它要控制的内容，从接收机提供的选项中为每项设置选择一个值，并在保存前检查摘要。整个过程大约只需一分钟。
从场景创建器保存场景会更改接收机上的任何内容吗？
不会。场景创建器根据您做出的选择构建场景，因此保存时不会从接收机读取任何内容，也不会向它发送任何内容。只有在您应用场景时，才会更改接收机。
“从当前状态创建”有什么用？
用于捕获您已有的设置。先把接收机调到您想要的声音效果，然后点按“添加场景”，选择“从当前状态创建”，命名并勾选要保留的设置。场景会保存接收机当前的数值。
应用场景会让我的接收机不堪重负吗？
不会。设置会按安全、有节奏的顺序逐项发送，电源最先，在接收机全部接受之前，磁贴会显示“正在应用…”。声道电平会被读回，接收机漏掉的内容会再发送一次。
我以后可以修改场景吗？
可以。长按场景可选择应用场景、用当前设置更新、编辑已捕获的设置、重命名场景、更改图标 & 颜色、复制场景、家庭自动化（专业版）和删除场景。拖动场景的手柄即可调整列表顺序。
场景可以打开我的接收机吗？
可以。包含电源状态后，应用场景时会先打开（或关闭）主分区，前提是接收机已启用网络待机，这样应用才能在接收机休眠时联系到它。
场景之后出现的彩色消息是什么意思？
绿色表示一切都已到位。橙色表示接收机为它按输入信号记忆的某项设置选择了自己的值，这是正常的；再次轻点场景可重试。蓝色表示接收机没有确认某些设置，所以应用无法判断它们是否生效。红色表示某项设置回读的值不同，或接收机拒绝了某些扬声器电平；再次轻点场景。红色消息会一直停留，直到您关闭。
场景与 Smart Select 或 Quick Select 有什么区别？
Smart Select (Marantz) 和 Quick Select (Denon) 是同一项接收机功能的两个名称：存储在接收机内部的若干插槽，Marantz CINEMA 30 上有五个。AVR Maestro 在应用各处都使用您接收机自己的叫法，让您从主屏幕和遥控触发它们，并允许您重命名。场景是 AVR Maestro 自己的功能：每台接收机最多 20 个，每个都有名称、图标和颜色，只保存您选择的设置，并且可以从主屏幕小组件触发，或发送到 Home Assistant 或 Hubitat。两者互不覆盖。

入门指南

用手机控制您的 Denon 或 Marantz

AVR Maestro 使用接收机的原生协议，通过您的本地网络与之通信，无需云账户，也无需额外硬件。一份简短的欢迎指南，几分钟内就能带您完成连接并创建第一个场景。

首次启动

五步欢迎向导，助您快速上手

首次打开 AVR Maestro 时，一份简短的向导会带您从零开始，一直到创建第一个场景。顶部的进度条显示您已完成多少，返回可回到任何之前的步骤，如果您想自己摸索，随时都可以点跳过。

  1. 欢迎。AVR Maestro 能做什么：通过您自己的网络全面控制您的 Denon 或 Marantz，不经过任何云端。它同样坦率地说明了自己不是什么：它是一款独立应用，既不是校准工具，也不是流媒体应用，让您在开始之前就清楚会得到什么。
  1. 您的接收机。应用会扫描您的网络，列出它发现的每一台接收机。轻点您的接收机即可添加，如果有多台，也可以都添加。没有列出？请使用通过 IP 地址添加，或轻点改用演示模式，通过自带现成场景的演示接收机先看看效果。
  1. 各项功能的位置。应用的快速导览：主页用于所有分区的电源、音量和输入源，声音用于声音模式、Audyssey 和 Dirac，场景用于您保存的设置。
  1. 场景。一个场景轻点一下就能做什么，以及它为何比接收机自带的 Smart Select 或 Quick Select 存储位走得更远：最多 20 个场景、主屏幕小组件和快捷方式，以及事后检查接收机是否真的接受了每一项设置。轻点创建我的第一个场景，场景创建器就会当场打开。
  1. 一切就绪。在哪里获得帮助：Discord 社区和 Facebook 支持小组，以及出现问题时如何从设置 → 关于 → 所有相关日志中分享您的日志。
想再看一遍导览，或为新接收机设置应用？随时打开设置 → 欢迎 & 设置指南。请参阅设置。
开始之前

您需要准备

  • 一部 iPhone、iPad、Mac、Android 手机或平板电脑，或一台 Windows 电脑，并与接收机处于同一网络。
  • 接收机已开机，并已启用网络待机（设置 → 常规 → 网络 → 网络控制 → 开），这样应用才能唤醒并连接它。
  • 无需其他准备：应用会自行在网络中找到接收机。如果您的网络阻止设备互相发现，则改用接收机的 IP 地址（设置 → 常规 → 网络 → 信息）。
  • 可选：启用 Wake-on-LAN，即可从深度待机状态开启接收机。
稍后添加接收机

有不止一台接收机？

  1. 打开设置 → 设备，然后轻点添加接收机。
  2. 该界面会扫描您的网络，列出它发现的每一台 Denon 或 Marantz 接收机。轻点您的接收机（如果没有任何应答，则输入它的 IP 地址），应用就会探测 HTTP、Telnet 和 HEOS。
  3. 确认检测到的型号和功能后保存。
  4. 随时可从设置 → 设备切换接收机。应用记住的是接收机本身，而不是它的地址：当路由器更改了它的地址时，应用会自动跟随，并只提示您一次。
故障排除

如果无法连接

大多数连接问题都出在网络上：手机和接收机位于不同子网，中间隔着访客网络或 IoT VLAN，或者接收机上的网络控制处于关闭状态。帮助与故障排除页面会逐步讲解连接测试失败、连接频繁中断的处理方法，以及如何判断您的接收机是否受支持。

遥控器

真正的遥控器，外加实时画面

完整的方向键和播放控制，带有显示输入源、声音模式和实际使用声道的实时标题 - 让您随时知道 Denon 或 Marantz 在做什么。滑动或轻点顶部的页面标签，在最多五个页面之间切换。

最多五个页面

无需实体遥控器，一切尽在手中

打开遥控标签页。您看到的页面取决于您的接收机：接收机没有的功能对应的页面会被省略。

  • 主遥控：命令栏（电源 / 信息 / 设置 / 选项 / 返回）、方向键、播放控制和音量条，顶部的实时顶栏显示输入源、声音模式以及正在使用的 IN/OUT 声道。
  • 输入源：完整的音源网格。轻点图块切换输入源。按住图块可为其设置自定义图标。网格使用您自己的名称和顺序（见下文重命名并重新排序输入源）。
  • Smart Select / Quick Select：AVR Maestro 会沿用您接收机的叫法：Marantz 上叫 Smart Select，Denon 上叫 Quick Select。点按某个位置即可调用接收机存放在其中的内容；按住可重命名或保存当前状态（向导会让您精确选择要捕获哪些设置）。位置的名称也会保存到接收机上，因此会跟随您出现在其他所有应用中。
  • 系统：针对整台接收机的直接控制（见下文列表）。
  • 触发输出：仅限带有 12V 触发输出的接收机。选择由哪些分区、输入源和 HDMI 输出来开启每个触发器（见下文）。
从不使用某个页面？在设置 › 自定义标签页中隐藏它。该设置适用于每台接收机。
分步操作

重命名并重新排序输入源

给输入源起它们本来的名字 - “Nvidia Shield”、“Xbox”、“PS5” - 并把最常用的放在最前面。

  1. 在主页标签页，轻点输入源卡片打开音源列表。
  2. 按住任意图块。列表切换到编辑状态：轻点图块可重命名，或拖动重新排序。完成后轻点“完成”。
  3. 要重命名，请轻点图块，输入新名称并轻点保存。
  4. 要重新排序，请把图块拖到新的位置。
  5. 轻点完成。
新名称会写入接收机本身，因此在厂商的应用和其他所有客户端（包括较旧的机型）中也会显示，应用会以输入源已重命名确认。如果接收机不接受，您会看到输入源仅在此设备上重命名，名称保留在 AVR Maestro 中。顺序按接收机保存，遥控的输入源页面同样使用它。
遥控 › 系统

针对整台接收机的直接控制

系统页面只显示您的接收机报告自己具备的功能，所以某些型号上的列表更短。您可能看到的内容，从上到下：

  • HDMI 输出和照明或调光（前面板显示亮度）。
  • 触发器：手动开启或关闭每个 12V 触发器。若要让触发器跟随分区、输入源或 HDMI 输出，请改用触发输出页面。
  • ECO 模式、自动待机和睡眠定时器。
  • HDMI CEC和HDMI 音频解码（AMP 或 TV）。
  • 扬声器预设：在接收机的扬声器预设之间切换。
  • Bluetooth 发射：适用于可向 Bluetooth 耳机或扬声器发送音频的型号。开启或关闭发射器，然后选择BT+扬声器（Bluetooth 与房间扬声器同时发声）或仅 BT。
  • 画面模式和视频处理模式（自动、游戏、电影、旁通）。游戏、电影和旁通仅在 HDMI 音源播放视频时生效；否则接收机保持自动。
  • 全分区立体声、自动口型同步（Marantz）、音频延迟和 LFE 电平。
  • 输入模式（自动、HDMI、数字、模拟）。
  • 数字输入格式：自动由接收机决定，PCM 强制 PCM 解码，DTS 强制 DTS 解码。当音源发送的格式被接收机误读而没有声音时使用。
某些接收机在特定输入源或环绕声模式启用时会锁定数字输入格式或 LFE 电平。此时应用会用锁定横幅显示当前值，而不是按钮。更改输入源或模式后，轻点标题旁边的刷新图标重新检查。请参阅控件为何被锁定。
遥控 › 触发输出

自动为您的屏幕、低音炮或功放通电

12V 触发输出会通知其他设备开机。在带有触发输出的接收机上，触发输出页面让您选择由什么来开启每个触发器。任何已启用的项目处于活动状态时，触发器就会触发。该列表从您的接收机实时读取。

  1. 打开遥控标签页并滑动到触发输出。
  2. 如果您的接收机有多个触发器，请在顶部选择触发输出 1、触发输出 2，依此类推。
  3. 打开应触发它的项目对应的开关，这些项目分组在分区、输入源和 HDMI 输出下。
每个开关都会立即发送到接收机。如果接收机不接受更改，一条以触发输出：开头的消息会告诉您，开关会显示接收机的实际状态。如果在带有触发器的接收机上看到触发输出不可用，可能是接收机正忙：如果它的网页控制页面在浏览器中打开着，请将其关闭，然后轻点重试。
音量，按您的方式调

以 dB 或相对刻度显示音量

主遥控的音量条实时显示主音量，标题芯片与之同步。更喜欢接收机自己的数字而不是分贝？可以在 dB 刻度（例如 -40.5 dB，默认）和 0-98 刻度（例如 39.5）之间切换读数。标题芯片和音量条都会遵循您的选择。

  1. 打开设置 › 管理接收机并轻点您的接收机。
  2. 在音频下，打开遥控音量显示并选择刻度。
该选择按接收机保存，所以两台接收机可以显示不同的刻度。
按住不放

音量按钮会像遥控器上的按键一样持续渐变

点按加号或减号，音量变化一档。按住不放，音量就会平滑地持续变化，直到您松手，和实体遥控器的表现一样，也符合您手指的预期。松手后，接收机会准确停在您停下的那一档，绝不会冲过头。

在底层，应用会做合并处理：它会累计您要去往的目标值，并控制实际发送的节奏，因此长按不会让应答较慢的接收机不堪重负。小幅调节同样平滑，几分贝的变化也是渐变而不是跳变。

信号，实时呈现

输入了什么，以及输出了什么

遥控顶栏带有一条精简的声道条：一行显示输入信号，另一行显示接收机正在驱动的声道，并列出接收机命名的每一只扬声器。一首经由网络播放的立体声曲目，会显示两个声道输入和完整的上混输出。

桌面版

Mac & Windows 上的键盘快捷键

在 Mac App Store 和 Microsoft Store 版本中，您可以直接用键盘控制播放和音量，无需伸手去拿鼠标。macOS 上使用 Cmd，Windows 上使用 Ctrl，键盘上的专用媒体键同样有效。在文本框中输入时不会触发任何快捷键，所以重命名输入源或输入 IP 时绝不会被打断。

快捷键操作
Cmd + 空格键 / Ctrl + 空格键播放 / 暂停
Cmd + . / Ctrl + .（句点）停止
Cmd + 右 / Ctrl + 右下一曲
Cmd + 左 / Ctrl + 左上一曲
Cmd + 上 / Ctrl + 上调高音量
Cmd + 下 / Ctrl + 下调低音量
Cmd + M / Ctrl + M切换静音
媒体键：播放、暂停、播放/暂停、停止对应的播放控制操作
媒体键：下一曲、上一曲跳到下一曲 / 上一曲
媒体键：音量增大、音量减小、静音调高音量、调低音量、静音
常见问题

遥控常见问题解答

我可以重命名输入源并调整顺序吗？
可以。在主页标签页轻点输入源卡片，然后按住任意图块开始编辑。轻点图块可重命名，拖动可重新排序，完成后轻点完成。新名称会写入接收机本身，因此在厂商的应用和其他所有客户端中也会显示；如果接收机不接受，应用会提示输入源仅在此设备上重命名。顺序按接收机保存，遥控的输入源页面也会遵循它。
我可以为输入源设置自定义图标吗？
可以。长按输入源磁贴，选择任意图片（PNG、JPG、ICO、WebP 等），在证件照式的裁剪器中调整位置并保存。详细步骤请参阅完整的《自定义输入图标》指南。
虚拟遥控器可以控制什么？
主遥控页面有命令栏（电源/信息/设置/选项/返回）、方向键、播放控制和音量，以及显示输入源、声音模式和正在使用的声道的实时标题。系统页面增加了直接控制（HDMI 输出、调光、触发器、ECO、睡眠、CEC、Bluetooth 发射、数字输入格式等），当您的接收机有 12V 触发输出时，还会出现单独的触发输出页面。接收机不支持的任何功能都会隐藏。
什么是 Smart Select / Quick Select？
Marantz 的 Smart Select 和 Denon 的 Quick Select 都是接收机自带的存储位。AVR Maestro 会沿用您接收机的叫法：Marantz 上叫 Smart Select，Denon 上叫 Quick Select。点按即可调用；长按可重命名，或通过捕获向导保存当前状态。
触发输出页面是什么？
当您的接收机有 12V 触发输出时，它会出现在遥控中。对于每个触发器，您选择由哪些分区、输入源和 HDMI 输出来开启它；任何已启用的项目处于活动状态时触发器就会触发，所以投影幕、低音炮或功放可以自行通电。该列表从您的接收机实时读取。如果接收机不接受更改，应用会告诉您，并显示接收机的实际状态。
AVR Maestro 在桌面版上有键盘快捷键吗？
有。在 Mac 和 Windows 上，您可以用键盘控制播放和音量。macOS 上使用 Cmd，Windows 上使用 Ctrl：空格键为播放/暂停，. （句点）为停止，左/右为上一曲/下一曲，上/下为调节音量，M 为静音。键盘上的专用媒体键（播放、暂停、下一曲、上一曲、停止、音量、静音）同样有效。在文本框中输入时，快捷键会暂停响应。

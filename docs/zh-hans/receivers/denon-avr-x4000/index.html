AVR-X4000 的全部功能

Denon AVR-X4000 上可用的功能

在 Denon AVR-X4000 上，AVR Maestro 可控制电源、输入源、接收机报告的环绕声模式、Audyssey MultEQ、音调和声道电平。浏览网络电台和媒体服务器菜单以及扬声器布局暂不可用。

环绕声模式

接收机所报告的环绕声模式。

Audyssey 与音调

切换 Audyssey MultEQ 模式，并设置音调、低音、高音和声道电平。

正在播放

网络电台会显示标题和电台名称。浏览顶层以下的菜单暂不可用。

扬声器设置

此接收机暂不支持布局、距离和分频设置。声道电平可在“声音”标签页中调整。

遥控按键

Information、Setup、Option 和 Back 在此接收机上暂不可用。电源、输入源和 System 可用。

依据命令列表构建

分区 2、分区 3、收藏、调谐器、HD Radio 和场景依据 Denon 的命令列表实现，尚未在真实的 AVR-X4000 上确认。

AVR-X4000 早于现代 Denon 协议，因此 AVR Maestro 只读取接收机自身报告的内容，并仅提供这些控制项。由于该机型无法响应，Bluetooth、Loudness 和 Cinema EQ 不会显示。它也没有多房间扬声器控制。
常见问题

Denon AVR-X4000 + AVR Maestro

有控制 Denon AVR-X4000 的应用吗？
可以，但有限制。AVR Maestro 通过网络控制 AVR-X4000：电源、输入源、环绕声模式、Audyssey、音调和声道电平均可使用。浏览网络电台菜单和扬声器布局暂不可用。
需要云账户吗？
不需要 - 它通过本地网络直接与 AVR-X4000 通信。无需云账户、无需订阅，也无需额外硬件。
如何连接？
在 AVR-X4000 上启用网络控制，然后打开“添加接收机”并在列表中点按它（如果没有响应，请输入其 IP 地址）。完整步骤见入门指南。

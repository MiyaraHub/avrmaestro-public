不确定？

真正的考验不在型号，而在网络

AVR Maestro 通过本地网络连接您的接收机，因此兼容性取决于接收机能否被访问，而不只是它的型号。

  • 在手机浏览器中可以打开接收机自带的网页控制台。
  • HEOS 应用能够找到并控制该接收机。
  • Denon 或 Marantz 官方应用能够连接到它。
  • 它的网络端口没有被访客网络、IoT VLAN 或严格的防火墙屏蔽。
只要以上这些都能与您的接收机通信，AVR Maestro 也一定能发现它 - 连接时它会读取您具体型号的功能，只显示您的机型实际提供的控制项。

关于旧版固件的说明

在部分 2025 年之前的接收机上（X4500H、X6700H、S960H 和 X4700H 这一类），接收机无法通过网络向应用提供扬声器布局或低音炮输出界面。对于这些设置，AVR Maestro 为您提供一键进入接收机自带网页控制的按钮 - 应用的其余部分均正常工作。使用较新固件的接收机则可直接提供所有界面。

常见问题

接收机支持常见问题解答

AVR Maestro 支持我的 Denon 或 Marantz 接收机吗？
AVR Maestro 支持大约 2014 年以后具备网络功能的 Denon 和 Marantz AV 接收机 - 包括 Marantz Cinema 30、40、50 和 60，Denon AVR-A1H、AVR-X1800H 至 X6800H、AVC-X8500HA、AVR-S770H 和 S970H，以及 Marantz SR 和 AV 系列。只要您接收机的网页控制台、HEOS 应用和 Denon 或 Marantz 官方应用都能在您的网络中访问它，AVR Maestro 也可以。
AVR Maestro 支持 Marantz Cinema 30 吗？
支持。Marantz Cinema 30 已获得完整支持，包括环绕声模式、Audyssey 和 Dirac Live、扬声器预设、多分区和调谐器，全部通过本地网络完成。
AVR Maestro 支持 Denon AVR-X3800H 或 AVR-A1H 吗？
支持。Denon AVR-X3800H 和旗舰 AVR-A1H 均受支持，可完整使用声音模式、房间校正、扬声器设置、声道电平和多分区控制。

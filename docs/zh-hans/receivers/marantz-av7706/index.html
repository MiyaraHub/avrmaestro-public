Marantz AV7706 + AVR Maestro

有控制 Marantz AV7706 的应用吗？
有 - AVR Maestro 是适用于 AV7706 的高级第三方控制器。通过你的网络，它可以控制环绕声模式、Audyssey MultEQ、扬声器预设、电平、多分区、调谐器和一键场景。
需要云账户吗？
不需要 - 它通过本地网络直接与 AV7706 通信。无需云账户、无需订阅，也无需额外硬件。
如何连接？
在 AV7706 上启用网络控制，然后打开“添加接收机”并在列表中点按它（如果没有响应，请输入其 IP 地址）。完整步骤见入门指南。

Denon AVR-A1H + AVR Maestro

有控制 Denon AVR-A1H 的应用吗？
有。AVR Maestro 是适用于 A1H 的高端第三方控制器。通过您的网络，它可以控制环绕声模式、Audyssey 和 Dirac Live、扬声器预设、声道电平、多分区、调谐器以及一键场景。
它能处理所有声道和分区吗？
可以。它会在连接时读取 A1H 的完整功能集，并提供各声道电平、布局、预设和独立的多分区控制。
需要云账户吗？
不需要。它通过本地网络直接与 A1H 通信。无需云账户，无需订阅，无需额外硬件，接收机的配置也绝不会离开您的网络。
如何连接？

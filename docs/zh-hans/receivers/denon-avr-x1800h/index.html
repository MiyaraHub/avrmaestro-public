常见问题

Denon AVR-X1800H + AVR Maestro

有控制 Denon AVR-X1800H 的应用吗？
有。AVR Maestro 是适用于 X1800H 的高端第三方控制器。通过您的网络，它可以控制环绕声模式、Audyssey MultEQ、扬声器预设、电平、多分区、调谐器以及一键场景。
X1800H 在应用中支持 Dirac Live 吗？
Denon AVR-X1800H 使用 Audyssey MultEQ，不支持 Dirac Live，这是该机型的硬件限制，与应用无关。AVR Maestro 可在手机上实时控制 X1800H 的 Audyssey MultEQ、Dynamic EQ、Dynamic Volume 和 LFC。请参阅 Audyssey & Dirac 指南。
需要云账户吗？
不需要 - 它通过本地网络直接与 X1800H 通信。无需云账户、订阅或额外硬件。
如何连接？
在X1800H上启用“网络控制”，然后打开“添加接收机”并在列表中点按它（如果没有任何设备应答，请输入其 IP 地址）。完整步骤请参阅入门指南。

除了官方应用，还有 iPhone 版 Marantz 应用吗？
有。AVR Maestro 是一款适用于 iPhone 和 iPad 上 Marantz 接收机的独立应用，可在 App Store 下载。它通过您的网络、使用接收机的原生协议连接，并带来一键场景、Audyssey 和 Dirac Live、扬声器预设以及多分区。了解用户为何改用它。
它支持我的 Marantz 接收机吗？
它支持大约 2014 年起具备网络功能的 Marantz AV 接收机，只需与 iPhone 处于同一 Wi-Fi 或局域网。无需云账户或额外硬件。查看支持的接收机。

可以。iPhone 和 iPad 版可在 App Store 下载，Mac 版可在 Mac App Store 下载。此外还有 Android 和 Windows 版本。

它是一次性购买，无广告，无订阅，无需账户，并通过本地网络直接控制您的接收机。

iPhone 上的 Marantz，答疑

除了官方应用，iPhone 上还有别的 Marantz 应用吗？
有。AVR Maestro 是适用于 iPhone 和 iPad 上 Marantz 接收机的独立应用，可从 App Store 获取。它使用接收机的原生协议通过网络连接，并增加了一键场景、Audyssey 和 Dirac Live、扬声器预设以及多分区。了解车主们为什么转用它。
它适用于我的 Marantz 接收机吗？
适用于大约 2014 年以后、支持网络的 Marantz AV 接收机，需与您的 iPhone 处于同一 Wi-Fi 或局域网。无需云账户或额外硬件。参见支持的接收机。
它也能在 iPad 和 Mac 上使用吗？
可以。它可在 iPhone 和 iPad 上通过 App Store 安装，在 Mac 上通过 Mac App Store 安装。也有 Android 和 Windows 版本。
它是免费的吗？有广告或订阅吗？
它是一次性购买，没有广告、没有订阅、无需账户，并通过本地网络直接控制您的接收机。

把您的 Marantz 装进 iPhone

一次性购买，无广告，无订阅。不到一分钟即可连接您的 Denon 或 Marantz。

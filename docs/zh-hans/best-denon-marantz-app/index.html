有比 Denon 或 Marantz 官方应用更好的应用吗？
很多用户改用了 AVR Maestro。它使用接收机的原生协议通过网络连接，响应迅速，并呈现官方应用深藏或缺失的控制项：一键场景、完整的 Audyssey 与 Dirac Live、多分区、扬声器预设和 FM/AM 调谐器。
AVR Maestro 支持我的接收机吗？
它支持具备网络功能的 Denon 和 Marantz AV 接收机，包括 Marantz Cinema 30/40/50/60 系列，以及 Denon AVR-A1H、X3800H、X4800H、X6800H 和 AVR-S770H/S970H。无需云端账户或额外硬件，只要与接收机处于同一 Wi-Fi 或局域网即可。
它是免费的吗？有广告或订阅吗？
它是一次性购买，无广告，无订阅，无需账户，并通过本地网络直接控制您的接收机。可在 Google Play、App Store 和 Microsoft Store 获取。
它能控制 Audyssey 和 Dirac Live 吗？
可以。对于支持这些功能的接收机，AVR Maestro 可直接读取并切换 Audyssey MultEQ 曲线和 Dirac Live 插槽，同时还能控制环绕声模式、声道电平、扬声器预设和多分区。

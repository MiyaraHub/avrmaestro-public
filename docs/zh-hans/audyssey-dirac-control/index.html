Audyssey

完整的 Audyssey MultEQ 控制

接收机 Audyssey 菜单中的所有内容，集中在一个读取实时状态的界面上。

  • MultEQ：在参考、旁通 L+R、平坦和关闭之间切换。
  • Dynamic EQ 和参考电平偏移，适合小音量聆听。
  • Dynamic Volume 平衡响亮与安静的段落。
  • LFC（低频抑制），可通过步进器调节抑制等级。
  • 只有接收机实际支持的控制项才会显示。
Dirac Live

按名称切换 Dirac Live 滤波器

如果您的接收机已获得 Dirac Live 授权，AVR Maestro 会把滤波器作为核心功能呈现。

  • 按名称选择滤波器插槽，也就是您在 Dirac Live 软件中设定的名称，而不是难懂的插槽编号。
  • 空插槽会被隐藏，只显示您真正的滤波器。
  • 如果您在接收机或其他位置更改了设置，当前插槽会实时更新。
  • 一键切换整个房间的调校方案：电影滤波器、音乐滤波器、深夜滤波器。

常见问题

Audyssey 与 Dirac Live 常见问题

我可以用手机控制 Audyssey 吗？
可以。对于配备 Audyssey 的接收机，AVR Maestro 可直接在应用中读取并切换 MultEQ（参考 / 旁通 L+R / 平坦 / 关闭）、Dynamic EQ、Dynamic Volume、参考电平偏移和 LFC。
AVR Maestro 可以切换 Dirac Live 滤波器吗？
可以。只要接收机已获得 Dirac Live 授权，应用就会按名称列出您的滤波器插槽，并一键切换当前使用的插槽。空插槽会被隐藏，当前插槽也会实时更新。
Audyssey 和 Dirac Live 有什么区别？
两者都能校正房间声学。Audyssey MultEQ 内置于大多数 Denon 和 Marantz 接收机，通过手机应用完成调校；Dirac Live 是可选的付费授权，深受许多发烧友喜爱，需通过电脑进行校准。在这些接收机上，两者对每个扬声器预设而言是互斥的，AVR Maestro 会控制您当前预设所使用的那一个。
可以同时使用两者吗？
不可以。在 Denon 和 Marantz 上，两者互斥，并与扬声器预设绑定。AVR Maestro 会按预设自动识别，因此您只需切换扬声器预设，即可切换当前生效的校准方案。

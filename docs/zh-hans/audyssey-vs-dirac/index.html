房间校正详解

Audyssey 与 Dirac Live

两者都能消除房间对声音的影响，但做法不同，也并非每台接收机都同时具备。这里用通俗的语言说明两者的差异、哪些 Denon 和 Marantz 型号支持哪一种，以及如何在手机上实时切换和控制。

简要概述

两者各自的作用

🎲

Audyssey MultEQ

几乎所有现代 Denon 和 Marantz 接收机都内置。使用随机附带的麦克风在多个座位测量房间，并将频率响应校平至目标曲线。最高级别的 MultEQ XT32 采用最高的滤波器分辨率，可分别校正每只扬声器和低音炮。另外还提供 Dynamic EQ（在小音量下保持均衡的听感）、Dynamic Volume 和 LFC。

🎵

Dirac Live

中高端和旗舰型号提供的付费升级。它不仅校正频率响应，还校正时域（脉冲响应），让声像定位更精准、低音更紧致。您可以在电脑或手机上使用完全自定义的目标曲线进行校准，再把结果载入接收机。更高等级还增加 Dirac Live Bass Control，旗舰型号则提供 Active Room Treatment (ART)。

谁有什么

哪些 Denon 和 Marantz 型号支持 Dirac Live

几乎所有当前型号都配备 Audyssey。Dirac Live 则是较高端型号上的付费附加项。

Audyssey + Dirac Live

Denon AVR-X4800H、AVR-X6800H、AVR-A1H；Marantz Cinema 30、Cinema 40 / 50。Dirac Live 为需额外购买的付费授权。

仅支持 Audyssey

入门和中端型号，例如 Denon AVR-S770H，运行 Audyssey MultEQ，不提供 Dirac Live。这是型号本身在硬件和授权上的限制，与任何应用无关。

型号支持情况会随时间和固件而变化，购买授权前，请务必确认您的接收机确实支持 Dirac Live。请查看完整的支持的接收机列表。

在手机上切换和控制两者

AVR Maestro 不执行校准，校准由麦克风以及 Audyssey 或 Dirac Live 应用完成。它的作用是把日常控制放进您的口袋。

🔄

按扬声器预设切换

如果您的接收机在一个扬声器预设中使用 Audyssey，在另一个中使用 Dirac Live，AVR Maestro 会按名称列出它们，并一键切换。

🎵

Audyssey 控制

在 Audyssey 预设下，它会提供 MultEQ 参考曲线以及 Dynamic EQ、Dynamic Volume 和 LFC，也就是您在看电影和听音乐之间真正会切换的选项。

🎲

Dirac 控制

在 Dirac Live 预设下，它会按名称列出您保存的 Dirac 滤波器插槽并切换当前插槽，让您在沙发上就能在不同校准之间切换。

常见问题

Audyssey 与 Dirac Live 常见问题

Dirac Live 比 Audyssey 更好吗？
没有绝对的赢家。Dirac Live 校正时域，并提供完全自定义的目标曲线，因此通常更精确、可调性更强，但它是付费升级项目，且仅限受支持的型号。Audyssey MultEQ XT32 表现非常出色，大多数接收机免费提供，也更简单。很多人先使用 Audyssey，之后才加装 Dirac Live。
哪些接收机支持 Dirac Live？
几乎所有现代 Denon 和 Marantz AVR 都配备 Audyssey。Dirac Live 是中高端和旗舰型号上的付费授权（例如 Denon X4800H、X6800H、A1H；Marantz Cinema 30/40/50），入门型号如 S770H 则不支持。
我可以用一个应用同时控制两者吗？
可以。AVR Maestro 可切换扬声器预设，并针对当前生效的校准方案显示相应的控制项：MultEQ 曲线加 Dynamic EQ/Volume/LFC，或您命名的 Dirac 滤波器插槽。它通过网络直接与接收机通信，无需云端中转，也无需订阅。
应用本身会执行校准吗？
不会。校准需使用麦克风以及 Audyssey MultEQ 或 Dirac Live 软件完成。AVR Maestro 负责在之后控制校准结果：切换、开关和调用，包括在一键场景中使用。

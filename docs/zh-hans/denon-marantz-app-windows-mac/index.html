键盘快捷键

用键盘操控接收机

在 Mac App Store 和 Microsoft Store 版本中，macOS 上使用 Cmd，Windows 上使用 Ctrl。键盘的媒体键同样可用，在文本框中输入时不会误触发。更多内容请参阅遥控指南。

快捷键操作
Cmd + 空格键 / Ctrl + 空格键播放 / 暂停
Cmd + . / Ctrl + .（句点）停止
Cmd + Left / Right，Ctrl + Left / Right上一曲 / 下一曲
Cmd + Up / Down，Ctrl + Up / Down音量加 / 减
Cmd + M / Ctrl + M切换静音
常见问题

Windows 和 Mac：常见问题

有 Windows 版的 Denon 或 Marantz 应用吗？
有。AVR Maestro 已上架 Microsoft Store，可在与接收机处于同一网络的 Windows PC 上控制具备网络功能的 Denon 和 Marantz AV 接收机。
有 Mac 版的 Denon 或 Marantz 应用吗？
有。AVR Maestro 已上架 Mac App Store，支持 Cmd 键盘快捷键和媒体键。
桌面版应用有键盘快捷键吗？
有。在 macOS 上使用 Cmd，在 Windows 上使用 Ctrl：Space 播放/暂停，.（句点）停止，Left/Right 上一曲/下一曲，Up/Down 调节音量，M 静音。媒体键同样可用，在文本框中输入时快捷键会暂停生效。
助手能在 Windows 上使用吗？
不能。助手需要设备端模型：iPhone、iPad 或 Mac（macOS 26）上的 Apple Intelligence，或 Android 上的 Gemini Nano。此列表中的其他功能都可在 Windows 上使用。请参阅助手指南。

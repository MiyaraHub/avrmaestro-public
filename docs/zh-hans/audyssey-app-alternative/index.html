适合日常控制的 Audyssey 应用替代品

在找 Audyssey 应用的替代品？AVR Maestro 可以用手机切换 Denon 或 Marantz 接收机的 Audyssey 设置：MultEQ 曲线（参考、旁通 L+R、平直或关闭）、Dynamic EQ、参考电平偏移、Dynamic Volume 和 LFC。它不运行校准：校准仍由麦克风和 Audyssey 应用完成，自定义目标曲线则需要付费的 MultEQ Editor 应用。

如实说明范围

AVR Maestro 能做什么，不能做什么

AVR Maestro 不是校准工具。它把日常控制放进您的口袋，把测量交给专门的工具。

任务AVR Maestro
切换 MultEQ 曲线、Dynamic EQ、Dynamic Volume、LFC是
按名称切换 Dirac Live 滤波器插槽可以，需要 Dirac Live 许可
用麦克风运行校准不能，这由 Audyssey 应用完成
自定义目标曲线不能，这需要付费的 MultEQ Editor 应用

在 Denon 和 Marantz 上，Audyssey 与 Dirac Live 与扬声器预设绑定，同一时间只有一个生效。请参阅 Audyssey 与 Dirac Live 控制和 Audyssey 对比 Dirac Live。AVR Maestro 是独立应用，与 Audyssey 没有关联。

常见问题

手机上的 Audyssey，答疑

日常使用有没有 Audyssey 应用的替代品？
有。AVR Maestro 可以直接在应用里读取并切换 MultEQ（参考 / 旁通 L+R / 平直 / 关闭）、Dynamic EQ、参考电平偏移、Dynamic Volume 和 LFC，适用于带 Audyssey 的 Denon 和 Marantz 接收机。
AVR Maestro 能校准我的房间吗？
不能。AVR Maestro 不运行校准。校准由麦克风和 Audyssey 或 Dirac Live 软件完成，应用负责日常控制校准的结果。
能在 AVR Maestro 里编辑 Audyssey 目标曲线吗？
不能。自定义 Audyssey 目标曲线需要付费的 MultEQ Editor 应用。AVR Maestro 有一个 9 段图形均衡器，可以从您测得的 Audyssey 曲线开始，在 MultEQ 和 Dirac 都关闭时使用。
它也支持 Dirac Live 吗？
支持。接收机上有 Dirac Live 许可时，应用会按名称列出您的滤波器插槽，并一键切换当前使用的插槽。

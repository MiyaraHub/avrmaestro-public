场景

整个房间，一键搞定。

观影之夜意味着合适的输入源、合适的声音模式、按您喜欢的方式设置的 Dirac 或 Audyssey、稍稍提升的中置声道，以及关闭分区 2。一个场景就能一次完成所有这些。AVR Maestro 会一步一步陪您构建，这样您再也不用记住哪个菜单里藏着什么。

  1. 先说明用途。电影和电视、音乐、游戏、深夜、其他房间或自定义，构建器会指出通常适合的设置。
  2. 选择要更改的内容。输入源、音量、声音模式、Audyssey 与 Dirac、扬声器电平、分区等，按照您的思路分组。不会替您预先勾选任何项目，如果接收机此刻无法应用某项设置，您一勾选就会立即告知原因。
  3. 检查并保存。为它命名，选择图标和颜色，并核对它将保存的每一项设置。保存不会改变接收机的任何设置；只有当您点按场景时，它才会生效。
  4. 随处一点即可。可从场景标签页、主页、Android 小组件或快捷方式启动，也可以让 Home Assistant 来运行，手机则留在口袋里。

常见问题

Denon & Marantz 控制常见问题解答

有没有更好的应用可以控制 Denon 或 Marantz 接收机？
有。AVR Maestro 是专为 Denon 和 Marantz AV 接收机打造的高端第三方控制器。它把官方应用藏得很深的控制项摆到台面上，增加了官方应用没有的一键场景，并让您在同一个地方使用 Audyssey、Dirac Live、扬声器预设、多分区和调谐器。
AVR Maestro 能用于我的 Denon 或 Marantz 接收机吗？
它适用于现代联网版 Denon 和 Marantz AV 接收机，包括 Cinema 系列 (Cinema 30/40/50/60)、Denon AVR-X 和 AVR-A 系列 (X1800H 至 AVR-A1H)、SR/NR 系列等。AVR Maestro 会在连接时读取每台接收机的功能，只显示您的机型实际支持的内容。请参阅支持的接收机完整列表。
需要订阅或云账号吗？
不需要。AVR Maestro 是一次性买断：没有订阅，没有广告，也没有云账号。它通过本地网络直接与您的接收机通信，因此您的任何设置信息都不会离开您的家。
它能控制 Audyssey MultEQ 和 Dirac Live 吗？
可以。AVR Maestro 可切换 Audyssey MultEQ 曲线、Dynamic EQ、Dynamic Volume 和 LFC；在支持 Dirac Live 的接收机上，它会按名称列出您的滤波器插槽并切换当前使用的插槽。请参阅 Audyssey & Dirac 控制指南。
支持多分区（分区 2 和分区 3）吗？
支持。分区 2 和分区 3 各自拥有独立的电源、输入源、音量，以及 Smart Select / Quick Select 调用，所以您可以用手机实现全屋音频。
AVR Maestro 是 Denon 或 Marantz 出品的吗？
不是。AVR Maestro 是由 MiyaraHub Technologies LLC 开发的独立应用，与 Denon、Marantz、D&M Holdings 或 Sound United 没有隶属、认可或赞助关系。它使用接收机自身的网络协议，通过您的本地网络控制接收机。

它是什么

AVR Maestro 是面向 Denon 和 Marantz AV 接收机的独立网络遥控应用。它通过本地网络与接收机通信，无需账号，没有广告，中间也没有云服务，并且只显示您的接收机型号实际具备的功能。

关键信息

  • 价格：$9.99，一次性付费。没有订阅，没有广告。可选的 Home Automation Pro 附加组件为 $2.99。
  • 平台：iPhone 和 iPad、Mac、Android 以及 Windows。
  • 接收机：Denon 和 Marantz 网络接收机；请参阅接收机列表。
  • 语言：30 种。
  • 开发者：MiyaraHub Technologies LLC。
  • 隐私：匿名崩溃报告和使用统计会发送到 Firebase，用于帮助修复错误。请参阅隐私政策。

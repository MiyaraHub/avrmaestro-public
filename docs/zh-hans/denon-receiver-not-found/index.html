Denon 或 Marantz 找不到接收机？修复连接

当 AVR Maestro 找不到或无法连接您的接收机时，原因几乎总是出在网络，而不是应用。请按顺序完成以下检查：Network Control、子网、IP 地址以及接收机是否繁忙。

四项检查即可解决大多数连接问题

每项只需一分钟。接收机一连上就可以停止。

同一网络和子网

手机和接收机必须处于同一网络。Mesh 系统、访客网络和 IoT VLAN 可能会隔离设备，位于不同子网的接收机不会被自动发现。

开启 Network Control

在接收机上，到“设置”中开启 Network Control，这样才能连接接收机并从待机中唤醒。具体菜单路径因型号而异。

检查 IP 地址

在接收机自身的 Network、Information 界面中读取地址，并与应用中的地址对比。DHCP 地址会变化，如果它总在变，请在路由器中为它保留地址。

接收机繁忙

如果有太多控制应用占用连接，应用会提示网络繁忙，而不是毫无缘由地失败。请关闭其他控制器，或等待几秒钟。

仍然断开

连接正常，随后断开

两种办法可以解决大部分情况。

拔掉电源再重新通电

长时间运行后，接收机的 Telnet 监听可能会卡住。将接收机断电片刻即可清除。

匹配 Wi-Fi 频段

接收机通常使用 2.4 GHz，而手机更倾向于 5 GHz。在 Wi-Fi 6 Mesh 网络中，请让手机与接收机使用同一频段。

完整步骤见入门指南和帮助与故障排除页面。要查看您的型号是否在列表中，请打开支持的接收机页面。

常见问题

找不到接收机，解答

AVR Maestro 为什么找不到我的 Denon 或 Marantz 接收机？
手机和接收机必须处于同一网络和同一子网。Mesh 系统、访客网络和 IoT VLAN 可能会隔离设备。请确认接收机已开机且 Network Control 设为 On，然后重试，或通过 IP 地址手动添加。
在哪里开启 Network Control？
在接收机上打开“设置”，进入 General 或 Network，将 Network Control 设为 On，这样接收机在待机时也能被连接。具体菜单路径因型号而异。
在哪里查看接收机的 IP 地址？
在接收机自身的 Network、Information 界面中查看。DHCP 地址可能会变化，因此如果原本正常的接收机无法连接，请重新查看，或在路由器中为它保留该地址。
连接总是断开，该怎么办？
将接收机的电源从插座拔掉再插上，以清除卡住的 Telnet 监听。在 Wi-Fi 6 Mesh 网络中，请让手机与接收机使用同一频段，因为接收机通常使用 2.4 GHz，而手机更倾向于 5 GHz。
“网络繁忙”提示是什么意思？
接收机可以访问，但其网络协议栈已饱和，通常是因为多个控制应用同时占用连接。请关闭其他控制器，或等待几秒钟。
我的接收机型号受支持吗？
不存在型号白名单。AVR Maestro 会在连接时检测接收机支持的功能，因此只要接收机的网页门户和 Denon 或 Marantz 官方应用能够连接它，AVR Maestro 也应该可以。

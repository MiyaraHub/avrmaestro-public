Atalhos de teclado

Comande o receptor pelo teclado

Nas versões da Mac App Store e da Microsoft Store, use Cmd no macOS ou Ctrl no Windows. As teclas de mídia do seu teclado também funcionam, e nada é acionado enquanto você digita em um campo de texto. Saiba mais no guia do controle remoto.

AtalhoAção
Cmd + Espaço / Ctrl + EspaçoReproduzir / Pausar
Cmd + . / Ctrl + . (ponto)Parar

Cmd + Cima / Baixo, Ctrl + Cima / BaixoAumentar / diminuir o volume
Cmd + M / Ctrl + MAtivar/desativar mudo
Perguntas frequentes

Windows e Mac: perguntas frequentes

Existe um app da Denon ou da Marantz para Windows?
Sim. O AVR Maestro está na Microsoft Store e controla receptores AV Denon e Marantz com rede a partir de um PC com Windows na mesma rede do receptor.
Existe um app da Denon ou da Marantz para Mac?
Sim. O AVR Maestro está na Mac App Store, com atalhos de teclado com Cmd e suporte a teclas de mídia.
O app para desktop tem atalhos de teclado?
Sim. Use Cmd no macOS ou Ctrl no Windows: Space (barra de espaço) para reproduzir/pausar, . (ponto) para parar, seta para a esquerda/direita para a faixa anterior/próxima, seta para cima/baixo para o volume e M para ativar o mudo. As teclas de mídia também funcionam, e os atalhos ficam pausados enquanto você digita em um campo de texto.
O assistente funciona no Windows?
Não. O assistente precisa de um modelo que roda no próprio dispositivo: Apple Intelligence no iPhone, iPad ou Mac (macOS 26), ou Gemini Nano no Android. Todo o resto desta lista funciona no Windows. Veja o guia do assistente.

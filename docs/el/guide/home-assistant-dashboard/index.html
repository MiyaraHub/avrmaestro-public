Home Assistant · βήμα προς βήμα

Φτιάξτε αυτό το dashboard του Home Assistant σε περίπου μία ώρα

Δέκα βήματα, το YAML κάθε κάρτας και μια πλήρης προβολή που επικολλάτε με μία κίνηση. Φτιάχτηκε και φωτογραφήθηκε σε πραγματικό Marantz CINEMA 30. Αλλάξτε δύο συμβολοσειρές και είναι δικό σας.

Βιάζεστε; Πηγαίνετε στο βήμα 10, κατεβάστε την πλήρη προβολή, αλλάξτε δύο συμβολοσειρές και επικολλήστε την. Τα ενδιάμεσα βήματα εξηγούν τι κάνει κάθε κομμάτι, ώστε να μπορείτε να το προσαρμόσετε.

Πριν ξεκινήσετε

  • Το AVR Maestro έχει συνδεθεί με το Home Assistant και έχει συγχρονιστεί. Ο οδηγός εγκατάστασης τα καλύπτει αυτά. Θα πρέπει να βλέπετε τα χειριστήριά σας στο Home Assistant πριν χτίσετε οτιδήποτε πάνω τους.
  • Ο δέκτης σας έχει προστεθεί στο Home Assistant. Ρυθμίσεις › Συσκευές & υπηρεσίες › Προσθήκη ενσωμάτωσης › Denon AVR, και μετά η τοπική του IP. Αυτό δίνει στον πίνακα ελέγχου τη ζωντανή κατάσταση.
  • Ο δέκτης σας είναι ενεργοποιημένος όσο τον στήνετε. Οι μισές από τις τιμές που θα γράψετε διαβάζουν ζωντανά δεδομένα, και ένας δέκτης σε αναμονή δεν δημοσιεύει σχεδόν τίποτα.

Δύο πηγές τροφοδοτούν αυτό το dashboard, και η διαφορά τους μετράει σε κάθε βήμα παρακάτω.

Και οι τέσσερις βρίσκονται στο προεπιλεγμένο κατάστημα του HACS. Στο Home Assistant: HACS › Frontend › Explore & Download Repositories, αναζητήστε το όνομα, πατήστε Download και ανανεώστε τον περιηγητή σας.

Βήμα 2

Βρείτε τα δύο ID οντοτήτων σας

Κάθε απόσπασμα σε αυτή τη σελίδα χρησιμοποιεί δύο σημεία αναπλήρωσης. Βρείτε τα δικά σας μία φορά και όλα τα υπόλοιπα είναι αντιγραφή και επικόλληση.

  • media_player.your_receiver → Ρυθμίσεις › Συσκευές & υπηρεσίες › ο δέκτης σας › η οντότητα media player. Κάτι σαν media_player.marantz_cinema_30.
  • script.avr_maestro_MAC_... → Εργαλεία προγραμματιστή › Καταστάσεις, και πληκτρολογήστε avr_maestro στο φίλτρο οντοτήτων. Εμφανίζεται ολόκληρη η λίστα χειριστηρίων σας.

Το μεσαίο μέρος κάθε ID σεναρίου είναι η διεύθυνση MAC του δέκτη σας, δώδεκα πεζοί χαρακτήρες, ίδιοι σε όλα. Αντιγράψτε το μία φορά. Παντού όπου αυτή η σελίδα γράφει MAC, βάλτε το δικό σας.

Αγνοήστε όσα γράφουν unavailable. Παλαιότερες εκδόσεις ονόμαζαν τα σενάρια με βάση το όνομα του δέκτη και όχι τη MAC. Αν είχατε συγχρονίσει τότε, αυτά τα παλιά εμφανίζονται ακόμη στη λίστα αλλά είναι νεκρά. Τα ενεργά είναι αυτά με όνομα βάσει MAC.
Βήμα 3

Δημιουργήστε την προβολή

  1. 1. Settings › Dashboards › Add Dashboard › New dashboard from scratch. Δώστε του όποιο όνομα θέλετε.
  2. 2. Ανοίξτε το και μετά πατήστε το εικονίδιο μολυβιού πάνω δεξιά για επεξεργασία.
  3. 3. Προσθέστε μια προβολή και επιλέξτε τη διάταξη Sections. Όχι Masonry. Η Sections είναι αυτή που κάνει την προβολή να προσαρμόζεται σωστά στο κινητό.
  4. 4. Στις ρυθμίσεις της προβολής, ορίστε το Max columns στο 3 και ενεργοποιήστε το Dense section placement.

Από εδώ και πέρα, κάθε βήμα είναι το ίδιο: προσθέτετε μια ενότητα και επικολλάτε κάρτες μέσα της. Για να επικολλήσετε YAML, χρησιμοποιήστε το μενού με τις τρεις τελείες σε μια κάρτα και επιλέξτε Edit in YAML, ή το μενού με τις τρεις τελείες του dashboard για το Raw configuration editor, ώστε να επικολλήσετε τα πάντα με τη μία.

# The view's own settings, if you prefer to type them
type: sections
title: AVR Maestro
icon: mdi:audio-video
max_columns: 3
dense_section_placement: true
Βήμα 4

Προσθέστε ένα χειριστήριο

Ξεκινήστε με το πιο απλό πράγμα στον πίνακα, ώστε να βεβαιωθείτε ότι τα ID των οντοτήτων σας είναι σωστά προτού χτίσετε οτιδήποτε περίπλοκο. Προσθέστε μια ενότητα, προσθέστε μια κάρτα, Edit in YAML και επικολλήστε:

type: button
name: Pure Direct
icon: mdi:speaker
tap_action:
  action: perform-action
  perform_action: script.turn_on
  target:
    entity_id: script.avr_maestro_MAC_mode_pure_direct

Στάνταρ Home Assistant. Δεν χρειάζεται HACS.

Πατήστε το. Αν ο δέκτης αλλάξει, τα ID σας είναι σωστά και όλα τα παρακάτω θα λειτουργήσουν. Αν δεν συμβεί τίποτα, γυρίστε στο βήμα 2.

Βήμα 5

Κάντε το να φωτίζεται όταν είναι το ενεργό

Αυτό είναι το μοτίβο που αξίζει να μάθετε, και κάθε πλακίδιο πηγής και surround στον πίνακα είναι αντίγραφό του. Η κάρτα στέλνει ένα σενάριο και παίρνει το χρώμα της από την οντότητα του δέκτη, έτσι η είσοδος στην οποία βρίσκεστε πραγματικά είναι φωτισμένη και οι υπόλοιπες όχι.

type: custom:mushroom-template-card
entity: script.avr_maestro_MAC_input_cd
icon: mdi:disc
primary: CD
icon_color: >-
  {{ 'orange' if (state_attr('media_player.your_receiver','source') or '')|lower
     == 'cd' else 'grey' }}
layout: vertical
fill_container: true
tap_action:
  action: perform-action
  perform_action: script.turn_on
  target:
    entity_id: script.avr_maestro_MAC_input_cd
card_mod:
  style: |
    ha-card {
      border-radius: 14px;
    {% if (state_attr('media_player.your_receiver','source') or '')|lower == 'cd' %}
      background: linear-gradient(160deg, rgba(226,86,10,0.34), rgba(15,15,17,0.88));
      border: 1px solid rgba(255,122,24,0.80);
    {% else %}
      background: rgba(15,15,17,0.72);
      border: 1px solid rgba(255,122,24,0.14);
    {% endif %}
    }

Αλλάξτε τρία πράγματα ανά είσοδο: το σενάριο, το εικονίδιο και τη συμβολοσειρά με την οποία γίνεται η σύγκριση.

Δύο πράγματα πρέπει να είναι σωστά, αλλιώς ένα πλακίδιο δεν θα φωτιστεί ποτέ:

  • Συγκρίνετε με ό,τι αναφέρει πραγματικά ο δέκτης σας. Developer Tools › States, η οντότητα media player σας, διαβάστε τα χαρακτηριστικά source_list και sound_mode_list. Αυτές είναι οι ακριβείς συμβολοσειρές. Συγκρίνετε με πεζά, όπως παραπάνω.
  • Μια μετονομασμένη είσοδος αναφέρει το νέο της όνομα. Μετονομάστε το GAME1 σε «Xbox» στον δέκτη και αναφέρει Xbox, ενώ το χειριστήριο του AVR Maestro εξακολουθεί να λέγεται input_game1. Ταιριάξτε με αυτό που αναφέρει ο δέκτης, όχι με το όνομα του σεναρίου.

Οι λειτουργίες surround είναι η ίδια κάρτα με sound_mode στη θέση του source.

Βήμα 7

Εμφανίστε την ένταση σε dB

Το Home Assistant αναφέρει την ένταση ως κλάσμα. Κανείς δεν ρυθμίζει έναν δέκτη στο «0.67». Μία γραμμή μαθηματικών το διορθώνει και ολόκληρη η ενότητα αρχίζει να διαβάζεται σαν δέκτης.

Η μετατροπή. Το Home Assistant δημοσιεύει το volume_level ως την κύρια ένταση διαιρεμένη με το 100, και στους δέκτες Denon και Marantz το MV 80 είναι το σημείο αναφοράς των 0 dB. Άρα dB = volume_level × 100 − 80. Ένα volume_level 0.67 αντιστοιχεί σε κύρια ένταση 67, δηλαδή −13.0 dB.
# The readout
type: custom:mushroom-template-card
entity: media_player.your_receiver
icon: mdi:volume-high
primary: >-
  {% set v = state_attr('media_player.your_receiver','volume_level') %}
  {% if v is not none %}{{ (v * 100 - 80) | round(1) }} dB{% else %}Standby{% endif %}
secondary: Master volume
layout: vertical
# The slider. media_controls must be empty or the bar becomes a power button
type: custom:mushroom-media-player-card
entity: media_player.your_receiver
volume_controls:
  - volume_set
media_controls: []
show_volume_level: true
# A preset. 0.50 is master volume 50, which is -30 dB
type: custom:mushroom-template-card
entity: media_player.your_receiver
icon: mdi:weather-night
primary: Night
secondary: "-30 dB"
tap_action:
  action: perform-action
  perform_action: media_player.volume_set
  target:
    entity_id: media_player.your_receiver
  data:
    volume_level: 0.50
Επιλέξτε την πιο δυνατή προεπιλογή σας με σκέψη. Το σετ παραπάνω σταματά στα −10 dB. Ένα dashboard πατιέται πολύ πιο εύκολα κατά λάθος από ένα τηλεχειριστήριο, και το επίπεδο αναφοράς σε έναν μεγάλο δέκτη είναι πραγματικά δυνατό.
Βήμα 8

Προσθέστε τις Σκηνές σας

Διαβάστε το όνομα από το σενάριο αντί να το πληκτρολογείτε, και η μετονομασία μιας Σκηνής στο AVR Maestro μετονομάζει το πλακίδιο χωρίς καμία επεξεργασία του dashboard.

type: custom:mushroom-template-card
entity: script.avr_maestro_MAC_scene_1234567890123
icon: mdi:theater
primary: >-
  {{ state_attr('script.avr_maestro_MAC_scene_1234567890123','friendly_name')
     | replace('AVR Maestro - ', '') | replace(' (Your Receiver)', '') }}
secondary: >-
  {% set t = states.script['avr_maestro_MAC_scene_1234567890123'].attributes.last_triggered %}
  {{ 'recalled ' ~ relative_time(t) ~ ' ago' if t else 'not run yet' }}
multiline_secondary: true
tap_action:
  action: perform-action
  perform_action: script.turn_on
  target:
    entity_id: script.avr_maestro_MAC_scene_1234567890123

Οι δύο κλήσεις replace() αφαιρούν το πρόθεμα και το όνομα του δέκτη από το φιλικό όνομα.

Μια δεύτερη γραμμή αξίζει το επιπλέον λεπτό. Ένας τοίχος από κουμπιά με φανταχτερά ονόματα δεν σας λέει τίποτα στις 11 το βράδυ· μια γραμμή που λέει τι επαναφέρει το καθένα σας δείχνει ποιο να πατήσετε.

Βήμα 9

Προσθέστε ιστορικό

Η οντότητα media player του δέκτη καταγράφεται από το Home Assistant όπως κάθε άλλη, οπότε παίρνετε ιστορικό ακρόασης δωρεάν. Όλα τα παρακάτω προέρχονται από αυτή τη μία οντότητα: χωρίς επιπλέον αισθητήρες, χωρίς helpers, τίποτα για να ρυθμίσετε πρώτα.

Η απλή χρονογραμμή καταστάσεων δεν χρειάζεται καθόλου προσαρμοσμένες κάρτες και είναι αυτή που αξίζει περισσότερο:

type: history-graph
hours_to_show: 168
entities:
  - entity: media_player.your_receiver
    name: Receiver

Ενεργός, ανενεργός και τι έκανε, σε διάστημα μιας εβδομάδας.

Η ένταση σε dB χρησιμοποιεί την ίδια μετατροπή με το βήμα 7:

type: custom:apexcharts-card
graph_span: 7d
header:
  show: true
  title: Master volume, last 7 days
series:
  - entity: media_player.your_receiver
    attribute: volume_level
    name: Master volume
    type: line
    curve: smooth
    unit: dB
    float_precision: 1
    transform: "return x == null ? null : Number(x) * 100 - 80;"
    extend_to: now
    group_by:
      duration: 1h
      func: last
      fill: last
apex_config:
  chart:
    height: 240
  yaxis:
    min: -60
    max: 0

Το group_by με fill: last μετατρέπει τα αραιά συμβάντα σε συνεχή γραμμή. Ο άξονας y πρέπει να μπει στο apex_config για να ισχύσει.

Ένας ημερήσιος μέσος όρος και μέγιστο μετατρέπει μια τραχιά γραμμή σε κάτι που έχει σχήμα:

type: custom:apexcharts-card
graph_span: 7d
span:
  end: day
header:
  show: true
  title: Master volume by day in dB, average and peak
series:
  - entity: media_player.your_receiver
    attribute: volume_level
    name: Day average
    type: column
    float_precision: 1
    transform: "return x == null ? null : Number(x) * 100;"
    group_by: {duration: 1d, func: avg, fill: 'null'}
  - entity: media_player.your_receiver
    attribute: volume_level
    name: Day peak
    type: line
    curve: smooth
    float_precision: 1
    transform: "return x == null ? null : Number(x) * 100;"
    group_by: {duration: 1d, func: max, fill: 'null'}
apex_config:
  yaxis:
    min: 0
    max: 80
    labels:
      formatter: "EVAL:function (v) { return (v - 80).toFixed(0); }"
  tooltip:
    y:
      formatter: "EVAL:function (v) { return v == null ? '' : (v - 80).toFixed(1) + ' dB'; }"

Δύο σειρές από το ίδιο χαρακτηριστικό, ομαδοποιημένες ανά ημέρα.

Γιατί αυτό σχεδιάζει από 0 έως 80 και μορφοποιεί σε dB, αντί να σχεδιάζει dB. Οι μπάρες μεγαλώνουν από τη βάση του άξονα. Αν σχεδιάσετε απευθείας dB, κάθε μπάρα κρέμεται προς τα κάτω από το 0, οπότε μια μακριά μπάρα σημαίνει χαμηλή ένταση, που διαβάζεται ανάποδα. Σχεδιάστε τον ακατέργαστο αριθμό της κύριας έντασης και αφαιρέστε 80 στους μορφοποιητές του άξονα και του tooltip, και οι μπάρες μεγαλώνουν προς τα πάνω ενώ ό,τι βλέπει ο αναγνώστης παραμένει σε dB. Το fill: 'null' σημαίνει ότι μια ημέρα χωρίς μετρήσεις δεν παίρνει μπάρα, αντί να μεταφερθεί η τιμή της χθεσινής.

Και τα δύο που απαντούν στο «σε τι βλέπω πραγματικά, και με ποια λειτουργία»: πηγή και λειτουργία surround, σχεδιασμένα ως χρονογραμμή του ποια ήταν επιλεγμένη.

type: custom:apexcharts-card
graph_span: 7d
span:
  end: day
header:
  show: true
  title: Source in use, last 7 days
series:
  - entity: media_player.your_receiver
    attribute: source
    name: Source
    type: line
    curve: stepline
    stroke_width: 3
    extend_to: now
    float_precision: 0
    transform: |
      if (x == null) return null;
      var m = ["Phono", "NET", "Xbox", "Nvidia Shield"];
      var i = m.indexOf(x);
      return i < 0 ? 0 : i + 1;
apex_config:
  yaxis:
    min: 0
    max: 4
    tickAmount: 4
    labels:
      formatter: >-
        EVAL:function (v) { return ["Other", "Phono", "HEOS Net", "Xbox",
        "Shield"][Math.round(v)] || ''; }
  tooltip:
    y:
      formatter: >-
        EVAL:function (v) { return v == null ? 'off' : ["Other", "Phono",
        "HEOS Net", "Xbox", "Shield"][Math.round(v)] || 'Other'; }

Βάλτε τις δικές σας πηγές στον πίνακα transform και στους δύο πίνακες μορφοποίησης. Κρατήστε το index 0 ως «Other».

Ο άξονας ενός γραφήματος χρειάζεται αριθμούς, οπότε το transform αντιστοιχίζει κάθε όνομα πηγής σε μια θέση και οι μορφοποιητές την επαναφέρουν σε όνομα για τις ετικέτες και το tooltip. Κάντε την αντιστοίχιση ολική: το null (δέκτης σβηστός) μένει κενό, και ό,τι δεν υπάρχει στη λίστα σας πέφτει στο «Other», ώστε τα δύο να μη μπερδεύονται ποτέ. Η ίδια κάρτα με sound_mode σας δίνει τη λειτουργία surround, με τις συμβολοσειρές σε κεφαλαία ακριβώς όπως τις αναφέρει ο δέκτης σας.

Κρατήστε το stepline σε αυτά τα δύο τελευταία. Μια πηγή ή μια λειτουργία surround είναι κατηγορία, όχι αριθμός. Εξομαλύνετε την καμπύλη και η γραμμή περνά από το Shield στο Xbox μέσα από ό,τι βρίσκεται ανάμεσά τους στον άξονα, σχεδιάζοντας μια είσοδο που δεν επιλέχθηκε ποτέ. Η ένταση είναι πραγματικό μέγεθος και εξομαλύνεται τίμια· μια κατηγορία όχι.
Ελέγξτε πρώτα τη διατήρηση δεδομένων του recorder. Το Home Assistant κρατά δέκα ημέρες από προεπιλογή, οπότε οι επτά ημέρες είναι περίπου το μέγιστο που μπορείτε να ζητήσετε με νόημα. Για να πάτε πιο πίσω χρειάζεστε έναν αισθητήρα template state_class: measurement, τον οποίο το Home Assistant κρατά ως μακροπρόθεσμα στατιστικά για χρόνια.
Μια ημέρα που λείπει συνήθως είναι σωστή. Το Home Assistant καταγράφει αλλαγές, όχι δείγματα. Αφήστε τον δέκτη σε μία είσοδο και μία ένταση για δύο ημέρες και δεν γράφει απολύτως τίποτα, οπότε εκείνη η ημέρα δεν έχει μπάρα. Μοιάζει με απώλεια δεδομένων και είναι το αντίθετο: δεν συνέβη τίποτα.
Βήμα 10

Ή πάρτε το σύνολο

Η πλήρης προβολή, κάθε ενότητα και κάθε κάρτα, με σημεία αναπλήρωσης αντί για ID οντοτήτων.

  1. 1. Λήψη του YAML της προβολής.
  2. 2. Ανοίξτε το σε οποιοδήποτε πρόγραμμα επεξεργασίας κειμένου και αντικαταστήστε δύο συμβολοσειρές, παντού όπου εμφανίζονται: το YOUR_RECEIVER με το όνομα της οντότητας media player σας, και το YOURMAC με τους δώδεκα χαρακτήρες του δέκτη σας από το βήμα 2.
  3. 3. Στο Home Assistant, ανοίξτε το dashboard σας, εικονίδιο μολυβιού, μενού τριών τελειών, Raw configuration editor, και επικολλήστε το ως προβολή.
Τα ID των Σκηνών σας δεν θα ταιριάζουν. Τα σενάρια των Σκηνών ονομάζονται με βάση το πότε δημιουργήθηκε η Σκηνή, οπότε οι τέσσερις του αρχείου δεν υπάρχουν στο σύστημά σας: αυτές οι κάρτες θα εμφανιστούν αλλά δεν θα κάνουν τίποτα. Αντικαταστήστε τα ID οντοτήτων τους με τα δικά σας από το βήμα 2, ή διαγράψτε την ενότητα Σκηνών και ξαναχτίστε την με το βήμα 8.
Δύο ακόμη πράγματα που πρέπει να περιμένετε. Τα γραφήματα πηγής και surround φέρουν τα ονόματα πηγών από τον δέκτη στον οποίο στήθηκε αυτό, οπότε επεξεργαστείτε αυτούς τους πίνακες όπως περιγράφει το βήμα 9. Και οι ετικέτες των πλακιδίων είναι στα αγγλικά· τίποτα στο αρχείο δεν είναι μεταφρασμένο.

Αν ένα πλακίδιο δεν φωτίζεται ποτέ

Προτού υποθέσετε ότι το χτίσατε λάθος: μερικά δεν μπορούν να φωτιστούν, και αξίζει να ξέρετε ποια.

Ένα πλακίδιο μπορεί να δείξει την κατάστασή του μόνο αν το Home Assistant μπορεί να τη διαβάσει, και διαβάζει τον δέκτη σας από δύο μέρη. Η ενσωμάτωση Denon AVR δημοσιεύει τα βασικά στην οντότητα media player. Το AVR Maestro δημοσιεύει τα υπόλοιπα: δημιουργεί έναν αισθητήρα Status Bridge, sensor.avr_maestro_your_receiver, και γράφει πάνω του ως χαρακτηριστικά τις μετρήσεις που ήδη διαθέτει.

Στην οντότητα media playerΣτον αισθητήρα Status Bridge
ΕνεργοποίησηΚαμπύλη Audyssey MultEQ
Επιλεγμένη πηγήDynamic Volume και επίπεδο αναφοράς
Λειτουργία surroundΠοια θέση Dirac είναι φορτωμένη
Ένταση και σίγασηDimmer μπροστινού πίνακα, λειτουργία Eco
Dynamic EQ, μερικές φορέςΠροεπιλογή ηχείων, τόνος και δεκάδες ακόμη

Και οι δύο στήλες είναι πλέον αναγνώσιμες. Πάρτε μια τιμή media player από το states['media_player.your_receiver'].attributes, και μια τιμή του Status Bridge με το state_attr('sensor.avr_maestro_your_receiver','dirac_slot'), ώστε ένα πλακίδιο να φωτίζεται για τη ρύθμιση που είναι πραγματικά ενεργή αντί να εκτελεί απλώς το σενάριο που την αλλάζει.

Μετρήθηκε στον δέκτη στον οποίο στήθηκε αυτό: η οντότητα media player μεταφέρει περίπου είκοσι από τα εξήντα χειριστήρια και ο αισθητήρας Status Bridge δημοσιεύει περίπου σαράντα ακόμη. Μαζί, ένα dashboard μπορεί να διαβάσει σχεδόν ό,τι μπορεί να αλλάξει - η διαφορά ανάμεσα σε έναν τοίχο από κουμπιά και μια πραγματική επιφάνεια ελέγχου.

Αν μια τιμή μπορεί να σημαίνει δύο πράγματα, πείτε το. Το Dynamic EQ φτάνει ως true, false, ή καθόλου. Αν το «καθόλου» το θεωρήσετε «απενεργοποιημένο», βάζετε στον τοίχο σας μια σίγουρη αλλά λάθος απάντηση.
icon_color: >-
  {% set d = state_attr('media_player.your_receiver','dynamic_eq') %}
  {{ 'orange' if d is true else 'grey' }}
secondary: >-
  {% set d = state_attr('media_player.your_receiver','dynamic_eq') %}
  {% if d is none %}state not published{% elif d %}on{% else %}off{% endif %}

Τρεις καταστάσεις, όχι δύο.

Άλλα πράγματα που αξίζει να ξέρετε

  • Τα πλακίδια βγαίνουν στο ένα τρίτο του πλάτους που περιμένετε. Σε μια ενότητα που εκτείνεται σε 3 στήλες, το εσωτερικό πλέγμα έχει 36 στήλες, όχι 12. Για τέσσερα πλακίδια σε σειρά, ορίστε grid_options: {columns: 9}. Για έξι σε σειρά, 6.
  • Το ρυθμιστικό έντασης δείχνει κουμπί λειτουργίας αντί για μπάρα. Αυτό συμβαίνει με το media_controls που περιέχει on_off. Ορίστε media_controls: [].
  • Οι ετικέτες κόβονται. Το «Volume Down» γίνεται «Volume Do...». Συντομεύστε το σε «Vol Down», ή φαρδύνετε το πλακίδιο.
  • Οι περιγραφές των Σκηνών κόβονται. Προσθέστε multiline_secondary: true.
  • Μια σταθερή γραμμή εξαφανίζεται από ένα γράφημα apexcharts. Αυτό είναι το experimental.color_threshold. Ζωγραφίζει τη γραμμή ως κάθετη διαβάθμιση, και ένα απολύτως οριζόντιο τμήμα έχει μηδενικό ύψος για να διαβαθμιστεί, οπότε αποδίδεται αόρατο. Μια συνεδρία 43 ωρών σε μία ένταση χάθηκε εντελώς. Χρησιμοποιήστε ένα συμπαγές color.
  • Προσαρμόζεται μόνο του στο κινητό. Οι προβολές Sections στοιβάζονται σε μία στήλη σε στενά πλάτη χωρίς καμία επιπλέον ρύθμιση.
Συχνές ερωτήσεις

Το dashboard, με απαντήσεις

Χρειάζομαι προσαρμοσμένες κάρτες από το HACS για να το φτιάξω;
Όχι για να δουλέψει. Κάθε χειριστήριο σε αυτή τη σελίδα λειτουργεί από μια απλή button card του Home Assistant. Τα Mushroom, button-card, card-mod και apexcharts-card είναι αυτά που το κάνουν να μοιάζει όπως στα στιγμιότυπα, και κάθε ενότητα παρακάτω λέει ποιο χρησιμοποιεί και τι χάνετε χωρίς αυτό.
Γιατί ορισμένα κουμπιά ανάβουν και άλλα όχι;
Ένα κουμπί φωτίζεται όταν το Home Assistant μπορεί να διαβάσει την αντίστοιχη κατάσταση από τον δέκτη σας. Η πηγή, η λειτουργία surround, η ένταση και η σίγαση επιστρέφονται από την ίδια την οντότητα media player του δέκτη, οπότε αυτά επισημαίνονται. Η καμπύλη Audyssey, η θέση Dirac, το dimmer, η λειτουργία eco και η προεπιλογή ηχείων δεν δημοσιεύονται από την ενσωμάτωση Denon, οπότε το Home Assistant δεν έχει τρόπο ν' αναγνωρίσει ποιο είναι ενεργό και τα κουμπιά παραμένουν σβηστά μέχρι να πατήσετε κάποιο.
Μπορώ να δω την πραγματική ένταση σε dB αντί για ποσοστό;
Ναι. Το Home Assistant δημοσιεύει το volume_level ως την κύρια ένταση του δέκτη διαιρεμένη με το 100, και στους δέκτες Denon και Marantz το MV 80 είναι το σημείο αναφοράς των 0 dB. Άρα τα dB ισούνται με volume_level επί 100, μείον 80. Ένα volume_level 0.67 αντιστοιχεί σε κύρια ένταση 67, δηλαδή σ' αυτή την περίπτωση -13.0 dB.
Θα ταιριάζουν τα ID των οντοτήτων μου με αυτά του οδηγού;
Το πρότυπο ναι, το μεσαίο μέρος όχι. Το AVR Maestro ονομάζει τα σενάρια (scripts) του με βάση τη διεύθυνση MAC του δέκτη, ώστε μια μετονομασία να ενημερώνει το ίδιο σενάριο αντί να δημιουργεί αντίγραφο. Το δικό σας θα έχει τη μορφή script.avr_maestro_, μετά τους δικούς σας δώδεκα χαρακτήρες και στο τέλος, απ' το χειριστήριο, το όνομά του. Ανοίξτε στο Home Assistant τα Developer Tools και μετά το States και φιλτράρετε με avr_maestro για να δείτε τη δική σας λίστα.

Σύνδεση

Πώς να συνδεθείτε

Η «Δοκιμή σύνδεσης» αποτυγχάνει
Βεβαιωθείτε ότι το κινητό και ο δέκτης βρίσκονται στο ίδιο δίκτυο Wi-Fi και στο ίδιο subnet - τα mesh συστήματα, τα δίκτυα επισκεπτών και τα IoT VLAN μπορούν να απομονώσουν συσκευές. Στον δέκτη, το Setup → Network → Network Control πρέπει να είναι On. Ελέγξτε ξανά την IP με βάση τη δική του οθόνη Network → Information, γιατί οι διευθύνσεις DHCP αλλάζουν. Το HTTP είναι απαραίτητο· το Telnet και το HEOS είναι καλό να υπάρχουν. Αν ο δέκτης είναι προσβάσιμος αλλά η στοίβα δικτύου του είναι κορεσμένη - πάρα πολλές εφαρμογές ελέγχου κρατούν συνδέσεις - η εφαρμογή το λέει με σαφές μήνυμα network busy αντί για μια γενική αποτυχία· κλείστε ένα άλλο χειριστήριο ή δώστε του λίγα δευτερόλεπτα. Αναλυτικά βήματα στον οδηγό έναρξης.
Η σύνδεση πέφτει κάθε λίγα δευτερόλεπτα
Οι θύρες Telnet του δέκτη μπορεί να «κολλήσουν» μετά από μεγάλο χρόνο λειτουργίας - κάντε power-cycle στον δέκτη από την πρίζα για να καθαρίσει ο ακροατής. Σε mesh Wi-Fi 6, αναγκάστε το τηλέφωνο να χρησιμοποιεί την ίδια μπάντα με τον δέκτη (οι AVR συνήθως δουλεύουν στα 2.4 GHz, ενώ τα τηλέφωνα προτιμούν τα 5 GHz).
Πώς ξέρω ότι ο δέκτης μου υποστηρίζεται;
Εξαρτάται από το δίκτυό σας, όχι μόνο από το μοντέλο. Αν η web πύλη του δέκτη, η εφαρμογή HEOS και η επίσημη εφαρμογή Denon/Marantz μπορούν όλες να τον προσεγγίσουν, μπορεί και το AVR Maestro. Δείτε τη σελίδα υποστηριζόμενων δεκτών.
Χειριστήρια & οθόνη

Γιατί κάτι φαίνεται περίεργο

Η ένδειξη έντασης φαίνεται λάθος
Οι δέκτες αναφέρουν την ένταση ως απόλυτη (0-98) ή σχετική (-80 έως +18 dB). Η εφαρμογή χειρίζεται και τις δύο· αν αλλάξατε πρόσφατα τη ρύθμιση εμφάνισης έντασης του δέκτη, επανεκκινήστε την εφαρμογή ώστε να διαβάσει ξανά την κλίμακα. Μπορείτε να αλλάξετε ποια τιμή εμφανίζεται πρώτη στις Ρυθμίσεις → Ήχος.
Οι λειτουργίες ήχου ή τα pills λειτουργιών είναι γκριζαρισμένα / «N/A»
Οι λειτουργίες και τα χαρακτηριστικά surround ελέγχονται από τη μορφή ήχου της εισόδου και την ενεργή λειτουργία ήχου - μια πηγή 2 καναλιών δεν θα ενεργοποιήσει το Dolby Atmos. Αυτή είναι συμπεριφορά του δέκτη, όχι της εφαρμογής. Πατήστε το (?) δίπλα σε ένα pill N/A για την ακριβή απαίτηση.
Λείπουν ορισμένες καρτέλες Ήχου ή Ηχείων
Οι καρτέλες προσαρμόζονται στο μοντέλο και τη λειτουργία. Τα Audyssey, Dirac Live, IMAX, Auro-3D, Surround Shape, Αποστάσεις και Crossovers εμφανίζονται μόνο σε δέκτες που τα διαθέτουν. Ελέγξτε τις Ρυθμίσεις → Συσκευές → Πληροφορίες Συσκευής για να δείτε τι εντόπισε η εφαρμογή, ή προσθέστε ξανά μια κρυφή καρτέλα από τις Ρυθμίσεις → Προσαρμογή Καρτελών / Προσαρμογή πλοήγησης.
Η καρτέλα Ραδιόφωνο δεν εμφανίζεται
Το Ραδιόφωνο εξαρτάται από τις δυνατότητες: εμφανίζεται μόνο σε δέκτες με ενσωματωμένο συντονιστή FM/AM. Αν ο δικός σας έχει, αλλά η καρτέλα είναι κρυφή, βεβαιωθείτε ότι ο συντονιστής εμφανίζεται ως είσοδος στον δέκτη και ενεργοποιήστε την ξανά από τις Ρυθμίσεις → Προσαρμογή πλοήγησης. Δείτε τον οδηγό Ραδιοφώνου.
Η κάρτα Αναπαράγεται τώρα είναι κενή
Η τρέχουσα είσοδος δεν εκθέτει μεταδεδομένα - οι αναλογικές, οι οπτικές/ομοαξονικές και οι περισσότερες πηγές HDMI passthrough δεν αναφέρουν στοιχεία κομματιού. Για πηγές HEOS, πατήστε Εκκίνηση HEOS για να ξεκινήσει η αναπαραγωγή, μετά επιστρέψτε και τα μεταδεδομένα συμπληρώνονται.
Το γραφικό στοιχείο της αρχικής οθόνης λέει «AVR off» ή «Standby»
Είναι η κατάσταση off του γραφικού στοιχείου, όχι βλάβη. Όταν ο δέκτης είναι απενεργοποιημένος, σε αναμονή ή μη προσβάσιμος, τα γραφικά στοιχεία (iOS και Android) δείχνουν «AVR off» / «Standby» αντί για την τελευταία είσοδο και ένταση, ώστε να μη διαβάζετε ποτέ παλιά δεδομένα. Στο γραφικό στοιχείο Quick Control τα κουμπιά έντασης και σίγασης κρύβονται σε αυτή την κατάσταση, αλλά το κουμπί ενεργοποίησης μένει ενεργό - πατήστε το για να ξυπνήσετε τον δέκτη απευθείας από το γραφικό στοιχείο (πρέπει να είναι ενεργοποιημένο το Network Standby στον δέκτη).
Ορισμένες οθόνες ηχείων ανοίγουν στο web control του δέκτη
Σε ορισμένους δέκτες πριν από το 2025 (κατηγορία X4500H / X6700H / S960H / X4700H), ο δέκτης δεν μπορεί να σερβίρει στην εφαρμογή τις οθόνες Διάταξης Ηχείων ή Εξόδου Subwoofer, οπότε το AVR Maestro σας δίνει ένα κουμπί ενός πατήματος προς το δικό του web control του δέκτη για αυτές τις αλλαγές. Όλα τα υπόλοιπα λειτουργούν κανονικά· το νεότερο υλικολογισμικό σερβίρει κάθε οθόνη μέσα στην εφαρμογή.

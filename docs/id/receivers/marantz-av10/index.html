Pertanyaan umum

Marantz AV10 + AVR Maestro

Adakah aplikasi untuk mengontrol Marantz AV10?
Ada - AVR Maestro adalah kontroler pihak ketiga premium untuk AV10. Melalui jaringan Anda, aplikasi ini mengontrol mode surround, Audyssey MultEQ XT32 dan Dirac Live, preset speaker, level, multi-zona, penala, dan Skenario satu ketukan.
Apakah AVR Maestro mengontrol Dirac Live pada AV10?
Ya. Pada Marantz AV10 dengan lisensi Dirac Live, AVR Maestro menampilkan slot filter Dirac Anda berdasarkan nama dan mengganti slot yang aktif. Dengan preset Audyssey standar, aplikasi ini justru mengontrol MultEQ, Dynamic EQ, Dynamic Volume, dan LFC. Lihat panduan Audyssey & Dirac.
Apakah saya perlu akun cloud?
Tidak - aplikasi berkomunikasi langsung dengan AV10 melalui jaringan lokal Anda. Tanpa akun cloud, tanpa langganan, dan tanpa perangkat keras tambahan.
Bagaimana cara menghubungkannya?
Aktifkan Network Control pada AV10, catat IP-nya, lalu tambahkan di aplikasi. Langkah lengkap ada di panduan memulai.

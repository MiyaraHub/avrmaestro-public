Marantz SR7015 + AVR Maestro

Adakah aplikasi untuk mengontrol Marantz SR7015?
Ada - AVR Maestro adalah kontroler pihak ketiga premium untuk SR7015. Melalui jaringan Anda, aplikasi ini mengontrol mode surround, Audyssey MultEQ XT32 dan Dirac Live, preset speaker, level, multi-zona, penala, dan Skenario satu ketukan.
Apakah AVR Maestro mengontrol Dirac Live pada SR7015?
Ya. Pada Marantz SR7015 dengan lisensi Dirac Live, AVR Maestro menampilkan slot filter Dirac Anda berdasarkan nama dan mengganti slot yang aktif. Dengan preset Audyssey standar, aplikasi ini justru mengontrol MultEQ, Dynamic EQ, Dynamic Volume, dan LFC. Lihat panduan Audyssey & Dirac.
Apakah saya perlu akun cloud?
Tidak - aplikasi berkomunikasi langsung dengan SR7015 melalui jaringan lokal Anda. Tanpa akun cloud, tanpa langganan, tanpa perangkat tambahan, dan konfigurasi receiver Anda tidak pernah keluar dari jaringan Anda.
Bagaimana cara menghubungkannya?
Aktifkan Network Control pada SR7015, catat IP-nya, lalu tambahkan di aplikasi. Langkah lengkap ada di panduan memulai.

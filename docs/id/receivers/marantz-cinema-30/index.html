Pertanyaan umum

Marantz Cinema 30 + AVR Maestro

Adakah aplikasi untuk mengontrol Marantz Cinema 30?
Ada - AVR Maestro adalah kontroler pihak ketiga premium untuk Cinema 30. Melalui jaringan Anda, aplikasi ini mengontrol mode surround, Audyssey dan Dirac Live, preset speaker, level, multi-zona, penala, dan Skenario satu ketukan.
Apakah aplikasi ini mengontrol Dirac Live pada Cinema 30?
Ya. Dengan lisensi Dirac Live, aplikasi ini mengganti slot filter Anda berdasarkan nama; dengan preset Audyssey standar, aplikasi ini mengontrol MultEQ, Dynamic EQ, Dynamic Volume, dan LFC. Lihat panduan Audyssey & Dirac.
Apakah saya perlu akun cloud?
Tidak - aplikasi berkomunikasi langsung dengan Cinema 30 melalui jaringan lokal Anda. Tanpa akun cloud, tanpa langganan, tanpa perangkat tambahan, dan konfigurasi receiver Anda tidak pernah keluar dari jaringan Anda.
Bagaimana cara menghubungkannya?
Aktifkan Network Control pada Cinema 30, catat IP-nya, lalu tambahkan di aplikasi. Langkah lengkap ada di panduan memulai.

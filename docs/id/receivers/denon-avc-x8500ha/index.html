Pertanyaan umum

Denon AVC-X8500HA + AVR Maestro

Apakah ada aplikasi untuk mengontrol Denon AVC-X8500HA?
Ada - AVR Maestro adalah pengontrol pihak ketiga premium untuk X8500HA. Lewat jaringan Anda, aplikasi ini mengontrol mode surround, Audyssey MultEQ XT32 dan Dirac Live, preset speaker, level, multi-zona, tuner, dan Skenario sekali ketuk.
Apakah AVR Maestro mengontrol Dirac Live di X8500HA?
Ya. Pada Denon AVC-X8500HA dengan lisensi Dirac Live, AVR Maestro menampilkan slot filter Dirac Anda berdasarkan nama dan mengganti slot yang aktif. Dengan preset Audyssey standar, aplikasi ini mengontrol MultEQ, Dynamic EQ, Dynamic Volume, dan LFC. Lihat panduan Audyssey & Dirac.
Apakah saya perlu akun cloud?
Tidak - aplikasi berkomunikasi langsung dengan X8500HA melalui jaringan lokal Anda. Tanpa akun cloud, tanpa langganan, dan tanpa perangkat keras tambahan.
Bagaimana cara menghubungkannya?
Aktifkan Network Control pada X8500HA, lalu buka Tambah Receiver dan ketuk receiver tersebut di daftar (atau masukkan alamat IP-nya jika tidak ada yang merespons). Langkah lengkap ada di panduan memulai.

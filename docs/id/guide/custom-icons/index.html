Jadikan milik Anda

Beri setiap input ikon kustom sendiri

Ganti gambar bawaan dengan milik Anda. Pasang sampul Blu-ray di pemutar Anda, logo konsol di input game, piringan hitam di Phono - apa pun yang membuat sumber langsung dikenali sekilas. Ikon Anda tampil di tile input, dasbor beranda, dan Remote, serta ikut terbawa dalam cadangan pengaturan Anda.

Tambahkan ikon dengan beberapa ketukan

  • Tekan lama tile input pada daftar input tab Remote, atau kartu input di dasbor beranda.
  • Pilih gambar apa pun - PNG, JPG, ICO, WebP, dan lainnya. Gunakan logo, sampul, foto, apa saja.
  • Pangkas di editor bergaya pas foto: seret untuk memosisikan dan cubit untuk memperbesar agar bagian terpenting berada di dalam bingkai.
  • Pilih bentuk: lingkaran, persegi bersudut membulat, dan lainnya - ikon langsung dimasker sesuai bentuk di alat pemangkas.
  • Simpan. Ikon memenuhi tile-nya - membentang di atas nama sumber dua baris, bukan kecil di tengah - dan muncul di mana pun input itu ditampilkan: daftar input, dasbor beranda, dan kartu input saat ini pada tab Remote.
Skenario juga

Gambar kustom untuk Skenario Anda

Setiap Skenario yang tersimpan juga bisa memiliki gambarnya sendiri. Buka lembar Ikon & Warna milik Skenario, unggah gambar, dan pangkas dengan cara yang sama. Skenario "Malam Film" bisa mengenakan gulungan film, "Minggu Vinyl" sebuah piringan hitam - sehingga setup satu ketukan Anda semudah dikenali seperti input Anda.

Ingin gambar memenuhi seluruh tile? Ikon sumber dan Skenario kustom bisa menyembunyikan labelnya, sehingga gambar berada di tengah dan memenuhi tile dari tepi ke tepi tanpa teks di atasnya. Nyalakan kembali label kapan saja dari lembar Ikon & Warna yang sama.
Pertanyaan umum

FAQ Ikon kustom

Di mana ikon input kustom ditampilkan?
Di tile input pada daftar input tab Remote, di kartu input pada dasbor beranda Anda, dan di kartu input saat ini pada tab Remote - di mana pun sumber itu muncul di aplikasi.
Format gambar apa yang bisa saya gunakan?
PNG, JPG, ICO, WebP, dan lainnya. Alat pemangkas bergaya pas foto memungkinkan Anda memosisikan, memperbesar, dan membentuk gambar apa pun.
Bisakah saya memakai ikon kustom untuk Skenario?
Ya. Buka lembar Ikon & Warna dari Skenario yang tersimpan dan unggah gambar dengan cara yang sama. Lihat panduan Skenario untuk selengkapnya tentang membuat dan memanggil Skenario.
Apakah ikon saya tetap ada setelah pemasangan ulang atau ganti ponsel?
Ya - ikon kustom disimpan dalam cadangan pengaturan aplikasi. Cadangkan dari Pengaturan, pulihkan di perangkat baru, dan gambar Anda ikut terbawa.
Bisakah saya menyembunyikan label agar gambar memenuhi tile?
Ya. Ikon sumber kustom maupun ikon Skenario kustom memiliki opsi sembunyikan label, sehingga gambar berada di tengah dan memenuhi tile tanpa teks di atasnya.

Di luar aplikasi

Widget layar utama dan tombol volume perangkat

  • Widget layar utama (iOS dan Android): Kontrol Cepat (daya / volume / bisu / sumber), Sedang Diputar, dan Status - dalam berbagai ukuran, hanya ketuk dan menyegarkan otomatis. Saat receiver mati atau tidak terjangkau, widget menampilkan status "AVR mati" / "Standby" yang jelas alih-alih input dan volume usang - dan tombol daya tetap aktif, sehingga Anda dapat membangunkan receiver langsung dari widget.
  • Tombol volume perangkat (Android dan iOS): selama AVR Maestro berada di latar depan, tombol volume fisik perangkat mengontrol volume receiver (memakai Langkah Volume Anda), dan menahannya menanjak bertahap. Hanya di latar depan; tombol kembali ke perangkat begitu aplikasi berada di balik aplikasi lain, dan sakelar di Pengaturan, Audio menonaktifkan pengambilalihan ini.
Widget, tema, Cadangan & Pemulihan, dan pengambilalihan tombol volume semuanya berfungsi di iOS maupun Android.
Pertanyaan umum

FAQ Pengaturan

Bisakah saya mengubah tema dan warna aplikasi?
Bisa - Terang, Gelap, Perangkat, atau AMOLED (hitam pekat), plus Tema Warna di mana Anda memilih warna aksen apa pun dan aplikasi menyusun ulang paletnya. Gunakan roda warna atau ketik kode hex (#FF8C00, atau singkatan tiga karakter). Jika kodenya salah, aplikasi memberi tahu apa yang salah alih-alih sekadar menolak. Anda juga dapat mengatur ukuran Tampilan/Widget serta menyesuaikan navigasi dan tab.
Bisakah saya mencadangkan setup saya?
Bisa - Pengaturan, Cadangan mengekspor setiap receiver, preset, dan preferensi ke file .zip yang juga menyertakan ikon input kustom Anda; impor untuk memulihkan di ponsel baru. Cadangan .json lama tetap dapat diimpor. Tidak ada kredensial di dalam file, jadi aman dibagikan.
Apakah preset volume langsung melompat ke target, atau naik bertahap?
Terserah Anda - Pengaturan, Audio memiliki sakelar Bertahap / Direct. Bertahap (bawaan) menaikkan dengan mulus menuju target preset sehingga satu ketukan tidak pernah menghantam speaker Anda dengan lonjakan mendadak. Direct menerapkannya seketika. Berfungsi di zona utama dan Zona 2/3.
Bisakah saya mengunci remote fisik receiver dari aplikasi?
Bisa, pada receiver yang mendukungnya - Pengaturan, Receiver memiliki sakelar Kunci Remote untuk mengunci atau membuka remote IR bawaan receiver.
Apakah widget layar utama hanya untuk Android?
Tidak - widget Kontrol Cepat (daya / volume / bisu / sumber), Sedang Diputar, dan Status tersedia di iOS maupun Android. Saat receiver mati atau tidak terjangkau, widget menampilkan status "AVR mati" / "Standby" yang jelas alih-alih data usang, dan tombol daya Kontrol Cepat tetap aktif sehingga Anda dapat membangunkan receiver dari widget.
Apakah tombol volume ponsel mengontrol receiver?
Di Android, ya - selama aplikasi berada di latar depan, tombol volume Anda mengontrol volume receiver. iOS tidak mengizinkan hal ini.
Bagaimana cara membuka menu debug tersembunyi?
Buka Pengaturan, Tentang, lalu ketuk nomor versi tujuh kali. Menu debug kemudian tetap tersedia di setiap peluncuran - log debug langsung plus alat perintah mentah dan diagnostik untuk dukungan - sampai Anda mengetuk "Hapus Menu Debug" untuk menyembunyikannya lagi.
Apa itu "Lainnya dari MiyaraHub"?
Bagian di Pengaturan dengan tombol Jelajahi semua aplikasi kami. Ketuk dan toko aplikasi Anda membuka halaman pengembang MiyaraHub - Google Play, App Store, atau Microsoft Store, tergantung perangkat Anda - sehingga Anda dapat menjelajahi setiap aplikasi buatan kami.

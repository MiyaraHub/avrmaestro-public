Saat tautan atau skrip bermasalah

Home Assistant, saat tidak berfungsi

Sebagian besar masalah Home Assistant berasal dari status tautan, ID entitas receiver, atau jaringan antara ponsel dan server Anda. Mulailah dari yang tertulis di kartu tautan, lalu telusuri ke bawah.

Arti kartu tautan

Kartu di atas tombol Sinkronkan menunjukkan status tautan, dan tombolnya mengikuti status itu.

  • Tertaut ke Home Assistant: panggilan terautentikasi baru saja berhasil. Tombol Sinkronkan tersedia.
  • Tautan Home Assistant telah kedaluwarsa: server Anda menjawab dan menolak token yang tersimpan. Tombol Sinkronkan dinonaktifkan sampai Anda masuk kembali.
  • Tidak dapat menjangkau Home Assistant: server Anda tidak dapat dijangkau, dan tokennya mungkin masih baik-baik saja. Tombol Sinkronkan tetap tersedia dan tidak ada yang diubah.
  • Tidak tertaut ke Home Assistant: belum ada alamat atau token yang tersimpan. Tambahkan alamat Anda lalu masuk.
  • Tautan Home Assistant belum diperiksa: Mode Demo aktif atau Otomasi Rumah terkunci, sehingga tidak ada yang dikirim ke rumah Anda dan token belum dicoba.
Hanya yang pertama yang berbunyi Tertaut, dan itu pun hanya karena ada yang berhasil terautentikasi. Token yang tersimpan saja tidak pernah dianggap sebagai tautan.

Skrip tidak melakukan apa-apa, atau menampilkan Entity Not Found

  • Pasang integrasi resmi Denon AVR di Home Assistant melalui Pengaturan, Perangkat & Layanan.
  • Pastikan ID Entitas Media Player Receiver di Pengaturan AVR Maestro persis sama dengan ID entitas di Home Assistant.
  • Abaikan entitas apa pun yang bertuliskan unavailable setelah skenario dihapus atau dibuat ulang. Skrip skenario dinamai menurut waktu skenario dibuat, jadi lihat Otomasi Rumah untuk mengetahui bagaimana ID skrip berubah satu kali.

Skenario baru tidak ada di Home Assistant

Skenario disinkronkan di latar belakang setiap kali Anda menambah, mengedit, atau menghapusnya, jadi Anda tidak perlu menekan Sinkronkan setiap saat. Jika ada yang hilang, berarti ponsel tidak dapat menjangkau server Anda.

  • Hubungkan ponsel Anda ke jaringan Wi-Fi lokal yang sama dengan Home Assistant.
  • Buka Pengaturan dan ketuk Sinkronkan Skenario. Jika gagal, aplikasi menampilkan kesalahan jaringan yang tepat.

Failed login di log Home Assistant Anda

Beberapa kali percobaan gagal, atau browser yang memutus koneksi sebelum penautan selesai, meninggalkan peringatan di Home Assistant. Itu hanya riwayat, bukan gangguan saat ini, dan Anda bisa mengabaikannya setelah tautan berfungsi.

Masalah lain yang bisa terjadi

  • Ubin dasbor tidak pernah menyala: lihat panduan dasbor Home Assistant.
  • Webhook tidak sampai: lihat Otomasi Rumah.
  • Masih buntu? Tanyakan di Discord atau lihat Bantuan.
Pertanyaan umum

Masalah Home Assistant, terjawab

Skrip saya berjalan tetapi menampilkan Entity Not Found, atau tidak terjadi apa-apa.
Pastikan integrasi resmi Denon AVR sudah terpasang di Home Assistant. Lalu periksa apakah ID Entitas Media Player Receiver di Pengaturan AVR Maestro persis sama dengan ID entitas di Home Assistant, misalnya media_player.living_room_receiver.
Mengapa log Home Assistant saya menampilkan Failed login?
Jika Anda beberapa kali gagal saat menautkan, atau browser memutus koneksi sebelum selesai, Home Assistant mencatat peringatan. Setelah penautan berhasil, Anda boleh mengabaikan peringatan lama itu.
Saya membuat skenario baru tetapi tidak muncul di Home Assistant.
Pastikan ponsel Anda berada di jaringan Wi-Fi lokal yang sama dengan server Home Assistant, karena sinkronisasi latar belakang gagal jika ponsel tidak dapat menjangkaunya. Buka Pengaturan dan ketuk Sinkronkan Skenario untuk melihat kesalahan jaringan yang tepat, jika ada.
Apakah aplikasi harus terbuka agar skrip saya berjalan?
Tidak. Skrip berada di Home Assistant, jadi dijalankan dari dasbor, otomasi, atau asisten suara Anda saat ponsel ada di saku. Aplikasi hanya membuat dan memperbarui skrip ketika Anda mengubah skenario.

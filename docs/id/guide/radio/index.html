Tuner FM/AM

Radio FM/AM sungguhan, dengan preset bernama

Pada receiver Denon dan Marantz dengan tuner bawaan, AVR Maestro menghadirkan antarmuka radio FM/AM yang sesungguhnya. Kartu stasiun menampilkan band, frekuensi, dan preset aktif secara langsung, dan mengikuti receiver secara real time.

Cara kerjanya

Tala, pindai, dan simpan

  • Band: FM / AM. Mode tuning: Otomatis (memindai ke stasiun kuat berikutnya) atau Manual (melangkah sesuai kenaikan band).
  • Tuning: dua tombol Tuning menggeser dial; Masukkan frekuensi membuka keypad untuk langsung menuju stasiun (memerlukan mode Manual).
  • Preset: kisi slot preset plus tombol naik/turun. Tekan lama sebuah slot untuk Simpan stasiun saat ini, Tambah / Ganti nama label ("Jazz 88", "NPR"), atau Hapus label.
Jika tab Radio tersembunyi, tambahkan kembali dari Pengaturan → Sesuaikan Navigasi - tab ini hanya muncul saat receiver Anda menyediakan tuner.
Pertanyaan umum

FAQ Tuner

Bisakah saya mengontrol radio FM/AM dari aplikasi?
Bisa, pada receiver dengan tuner bawaan - tampilan band/frekuensi/preset langsung, pergantian FM/AM, tuning Otomatis atau Manual, keypad untuk langsung menuju frekuensi, dan kisi preset.
Bisakah saya memberi nama preset?
Bisa - tekan lama sebuah slot untuk menyimpan stasiun saat ini, menambah atau mengganti nama label ("Jazz 88", "NPR"), atau menghapusnya.
Mengapa saya tidak melihat tab Radio?
Tab ini hanya muncul pada receiver dengan tuner bawaan. Jika receiver Anda memilikinya, pastikan tuner tampil sebagai input dan aktifkan kembali tab dari Pengaturan, Sesuaikan Navigasi.

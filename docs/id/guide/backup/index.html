Cadangkan & Pulihkan: seluruh setup Anda, dalam satu file

Mengganti nama setiap input, memilih gambar untuk masing-masing, mengurutkan sumber, dan membuat serangkaian Skenario itu bukan pekerjaan kecil. Semuanya seharusnya selamat saat ganti ponsel, dan memang begitu: satu ekspor, satu impor, dan perangkat baru terlihat persis seperti yang lama.

Ekspor

Simpan ke perangkat, atau bagikan langsung

Buka Pengaturan, gulir ke Cadangkan & Pulihkan, lalu pilih:

  • Simpan ke perangkat - menulis satu file JSON ke lokasi yang Anda tentukan.
  • Bagikan - menyerahkannya ke menu bagikan yang biasa Anda pakai, sehingga bisa langsung dikirim ke ponsel lain, penyimpanan cloud, atau pesan untuk diri sendiri.

File ini berupa teks biasa. Tidak ada isinya yang terkunci pada perangkat asalnya.

Impor

Memulihkan di ponsel baru

  1. Pasang AVR Maestro di perangkat baru dan pastikan perangkat itu berada di jaringan yang sama dengan receiver Anda.
  2. Buka Pengaturan › Cadangkan & Pulihkan.
  3. Ketuk Impor pengaturan dari file lalu pilih cadangannya.
  4. Mulai ulang aplikasi. Aplikasi juga akan memberi tahu Anda - mulai ulang membuat setiap pengaturan yang dipulihkan berlaku dengan bersih.
Impor menggantikan, bukan menggabungkan. Apa pun yang ada di perangkat itu akan ditimpa dengan isi cadangan. Jika setup saat ini berharga bagi Anda, ekspor dulu - hanya butuh dua ketukan.
Perlu diketahui

Cadangan adalah milik aplikasi, bukan receiver

Kalibrasi, Speaker Preset, level, jarak, crossover, dan filter Dirac Anda tersimpan di receiver. Semua itu tidak ada di dalam cadangan, dan mengimpor cadangan tidak akan mengganggunya. Ini berlaku dua arah: cadangan tidak akan memulihkan receiver yang sudah di-reset ke pengaturan pabrik, dan memang tidak perlu - menghubungkan kembali aplikasi ke receiver itu akan mengambil kembali pengaturannya dari receiver itu sendiri.

Cadangan juga layak dibuat sebelum penataan ulang besar-besaran. Ekspor, atur ulang input dan bangun ulang Skenario sesuka Anda, dan jika Anda lebih suka versi lamanya, filenya tersedia.

Pertanyaan umum

FAQ Cadangan

Bisakah saya memindahkan cadangan antara Android dan iPhone?
File-nya berupa JSON biasa dan tidak terikat pada perangkat yang membuatnya. Ekspor dari satu perangkat, pindahkan file ke perangkat lain, lalu impor.
Apakah mengimpor akan menimpa kalibrasi receiver saya?
Tidak. Cadangan hanya berisi pengaturan aplikasi. Semua yang disimpan receiver - kalibrasi, preset, level, jarak, filter Dirac - tetap di receiver dan tidak tersentuh.
Apakah Skenario saya ikut terbawa?
Ya, beserta pengaturan mana saja yang diperintahkan untuk direkam oleh tiap Skenario. Lihat panduan Skenario.
Di mana Simpan ke perangkat menaruh file-nya?
Di mana pun yang Anda pilih di pemilih file sistem Anda. Bagikan adalah jalur yang lebih cepat jika file hanya singgah dalam perjalanan ke ponsel lain.

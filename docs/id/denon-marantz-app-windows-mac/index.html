Pertanyaan umum

Windows dan Mac, terjawab

Adakah aplikasi Denon atau Marantz untuk Windows?
Ada. AVR Maestro tersedia di Microsoft Store dan mengendalikan receiver AV Denon dan Marantz berkemampuan jaringan dari PC Windows pada jaringan yang sama dengan receiver.
Adakah aplikasi Denon atau Marantz untuk Mac?
Ada. AVR Maestro tersedia di Mac App Store, dengan pintasan keyboard Cmd dan dukungan tombol media.
Apakah aplikasi desktop memiliki pintasan keyboard?
Ya. Gunakan Cmd di macOS atau Ctrl di Windows: Space untuk Play/Pause, . (titik) untuk Stop, Kiri/Kanan untuk lagu sebelumnya/berikutnya, Atas/Bawah untuk volume, dan M untuk mute. Tombol media juga berfungsi, dan pintasan dijeda saat Anda mengetik di kolom teks.
Apakah asisten bekerja di Windows?
Tidak. Asisten memerlukan model di perangkat: Apple Intelligence di iPhone, iPad, atau Mac (macOS 26), atau Gemini Nano di Android. Semua yang lain dalam daftar ini bekerja di Windows. Lihat panduan asisten.

Bantuan & pemecahan masalah

Solusi cepat untuk pertanyaan yang paling umum. Jika Anda masih buntu, Debug Log di aplikasi (Pengaturan → Bantuan → Simpan & Bagikan) adalah cara tercepat untuk mendapat dukungan - hubungi pengembang di Discord atau grup dukungan Facebook, balasannya cepat.

Koneksi

Menghubungkan

"Uji Koneksi" gagal
Pastikan ponsel dan receiver berada di jaringan Wi-Fi dan subnet yang sama - sistem mesh, jaringan tamu, dan VLAN IoT bisa mengisolasi perangkat. Pada receiver, Setup → Network → Network Control harus On. Periksa kembali IP pada layar Network → Information milik receiver, karena alamat DHCP bisa berubah. HTTP wajib; Telnet dan HEOS sifatnya tambahan. Jika receiver bisa dijangkau tetapi jaringannya jenuh - terlalu banyak aplikasi pengendali yang menahan koneksi - aplikasi menyatakannya dengan pesan network busy yang jelas, bukan kegagalan generik; tutup pengendali lain atau beri waktu beberapa detik. Langkah lengkap ada di panduan memulai.
Koneksi terputus setiap beberapa detik
Port Telnet receiver bisa menjadi macet setelah menyala lama - matikan daya receiver dari stopkontak untuk membersihkan listener. Pada mesh Wi-Fi 6, paksa ponsel ke pita yang sama dengan receiver (AVR biasanya berada di 2.4 GHz; ponsel lebih suka 5 GHz).
Bagaimana saya tahu receiver saya didukung?
Semuanya bergantung pada jaringan Anda, bukan hanya modelnya. Jika portal web receiver, aplikasi HEOS, dan aplikasi resmi Denon/Marantz semuanya bisa menjangkaunya, AVR Maestro seharusnya juga bisa. Lihat halaman receiver yang didukung.
Kontrol & tampilan

Mengapa ada yang terlihat janggal

Tampilan volume terlihat salah
Receiver melaporkan volume secara absolut (0-98) atau relatif (-80 hingga +18 dB). Aplikasi menangani keduanya; jika Anda baru mengubah pengaturan tampilan volume di receiver, mulai ulang aplikasi agar skalanya dibaca ulang. Anda bisa membalik nilai mana yang tampil di atas di Pengaturan → Audio.
Mode suara atau pill fitur dinonaktifkan / "N/A"
Mode dan fitur surround dibatasi oleh format audio input dan mode suara yang aktif - sumber 2 kanal tidak akan mengaktifkan Dolby Atmos. Itu perilaku receiver, bukan aplikasi. Ketuk (?) di samping pill N/A untuk melihat persyaratan persisnya.
Beberapa tab Suara atau Speaker hilang
Tab menyesuaikan model dan mode. Audyssey, Dirac Live, IMAX, Auro-3D, Surround Shape, Jarak, dan Crossover hanya muncul pada receiver yang menyediakannya. Periksa Pengaturan → Perangkat → Informasi Perangkat untuk melihat apa yang terdeteksi aplikasi, atau tambahkan kembali tab yang disembunyikan dari Pengaturan → Kustomisasi Tab / Kustomisasi Navigasi.
Tab Radio tidak muncul
Radio bergantung pada kemampuan perangkat: hanya muncul pada receiver dengan tuner FM/AM bawaan. Jika receiver Anda punya tuner tetapi tab-nya tersembunyi, pastikan tuner muncul sebagai input pada receiver dan aktifkan kembali dari Pengaturan → Kustomisasi Navigasi. Lihat panduan Radio.
Kartu Sedang Diputar kosong
Input saat ini tidak menyediakan metadata - sumber analog, optical/coaxial, dan sebagian besar passthrough HDMI tidak melaporkan data trek. Untuk sumber HEOS, ketuk Launch HEOS untuk memulai pemutaran, lalu kembali dan metadata akan terisi.
Widget layar utama menampilkan "AVR off" atau "Standby"
Itu adalah status mati widget, bukan kerusakan. Saat receiver mati, standby, atau tidak terjangkau, widget (iOS dan Android) menampilkan "AVR off" / "Standby" alih-alih input dan volume terakhir, sehingga Anda tidak pernah membaca data usang. Pada widget Quick Control, tombol volume dan mute disembunyikan dalam keadaan itu, tetapi tombol daya tetap aktif - ketuk untuk membangunkan receiver langsung dari widget (Network Standby harus diaktifkan pada receiver).
Beberapa layar speaker terbuka di kontrol web receiver
Pada beberapa receiver sebelum 2025 (kelas X4500H / X6700H / S960H / X4700H), receiver tidak bisa menyajikan layar Tata Letak Speaker atau Output Subwoofer ke aplikasi, jadi AVR Maestro memberi Anda tombol satu ketukan ke kontrol web milik receiver untuk perubahan tersebut. Semua yang lain berfungsi normal; firmware yang lebih baru menyajikan setiap layar di dalam aplikasi.

Mencari alternatif aplikasi Audyssey? AVR Maestro mengganti pengaturan Audyssey pada receiver Denon atau Marantz Anda dari ponsel: kurva MultEQ (Reference, Bypass L+R, Flat, atau Off), Dynamic EQ, Reference Level Offset, Dynamic Volume, dan LFC. Aplikasi ini tidak menjalankan kalibrasi: mikrofon dan aplikasi Audyssey tetap yang mengerjakannya, dan kurva target kustom memerlukan aplikasi MultEQ Editor berbayar.

Pertanyaan umum

Audyssey dari ponsel Anda, terjawab

Adakah alternatif untuk aplikasi Audyssey bagi pemakaian sehari-hari?
Ada. AVR Maestro membaca dan mengganti MultEQ (Reference / Bypass L+R / Flat / Off), Dynamic EQ, Reference Level Offset, Dynamic Volume, dan LFC pada receiver Denon dan Marantz yang memiliki Audyssey, langsung dari aplikasi.
Apakah AVR Maestro bisa mengkalibrasi ruangan saya?
Tidak. AVR Maestro tidak menjalankan kalibrasi. Itu dikerjakan oleh mikrofon dan perangkat lunak Audyssey atau Dirac Live; aplikasi ini mengendalikan hasilnya dari hari ke hari.
Bisakah saya mengedit kurva target Audyssey di AVR Maestro?
Tidak. Kurva target Audyssey kustom memerlukan aplikasi MultEQ Editor berbayar. AVR Maestro memiliki Graphic EQ 9 band yang dapat dimulai dari kurva Audyssey hasil pengukuran Anda, dan dapat dipakai saat MultEQ dan Dirac mati.
Apakah juga bekerja dengan Dirac Live?
Ya. Dengan lisensi Dirac Live pada receiver, aplikasi mencantumkan slot filter Anda berdasarkan nama dan mengganti slot aktif dengan satu ketukan.

Nas versões da Mac App Store e da Microsoft Store, use Cmd no macOS ou Ctrl no Windows. As teclas multimédia do seu teclado também funcionam, e nada é acionado enquanto escreve num campo de texto. Mais informações no guia do comando.

Perguntas frequentes

Windows e Mac: perguntas frequentes

Existe alguma app Denon ou Marantz para Windows?
Sim. O AVR Maestro está na Microsoft Store e controla recetores AV Denon e Marantz com ligação de rede a partir de um PC com Windows na mesma rede que o recetor.
Existe alguma app Denon ou Marantz para Mac?
Sim. O AVR Maestro está na Mac App Store, com atalhos de teclado com Cmd e suporte para teclas multimédia.
A app para computador tem atalhos de teclado?
Sim. Use Cmd no macOS ou Ctrl no Windows: Space (barra de espaço) para reproduzir/pausar, . (ponto) para parar, seta esquerda/direita para a faixa anterior/seguinte, seta para cima/baixo para o volume e M para silenciar. As teclas multimédia também funcionam, e os atalhos ficam em pausa enquanto escreve num campo de texto.
O assistente funciona no Windows?
Não. O assistente precisa de um modelo que corra no próprio dispositivo: Apple Intelligence no iPhone, iPad ou Mac (macOS 26), ou Gemini Nano no Android. Tudo o resto desta lista funciona no Windows. Consulte o guia do assistente.

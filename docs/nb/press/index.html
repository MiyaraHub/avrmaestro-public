Pressekit for AVR Maestro

Alt du trenger for å skrive om AVR Maestro: hva det er, faktaene som ikke endrer seg, appikonet og skjermbildene du kan bruke.

Hva det er

AVR Maestro er en uavhengig nettverksfjernkontroll for AV-mottakere fra Denon og Marantz. Den snakker med mottakeren over det lokale nettverket ditt, uten konto, uten reklame og uten skytjeneste imellom, og viser bare det mottakermodellen din faktisk har.

Nøkkelfakta

  • Pris: $9.99, betalt én gang. Ingen abonnement og ingen reklame. Det valgfrie tillegget Home Automation Pro koster $2.99.
  • Plattformer: iPhone og iPad, Mac, Android og Windows.
  • Mottakere: nettverksmottakere fra Denon og Marantz; se mottakerlisten.
  • Språk: 30.
  • Utvikler: MiyaraHub Technologies LLC.
  • Personvern: Anonyme krasjrapporter og bruksstatistikk sendes til Firebase for å hjelpe med å rette feil. Se personvernerklæringen.

Bruk av navnet

AVR Maestro er en uavhengig app og er ikke tilknyttet Denon, Marantz eller Masimo. Denon og Marantz er varemerker som tilhører eierne sine, og nevnes bare for å si hvilke mottakere appen fungerer med.

Spilles nå & HEOS

Spilles nå: hva som spilles, på én skjerm

Når kilden rapporterer metadata, setter Spilles nå-kortet i AVR Maestro albumcover, spor og avspillingskontroller rett på hjemskjermen din - og overlater til HEOS for å bla gjennom musikk, før det tar over igjen i samme øyeblikk musikken starter.

Alt du lytter til, på ett kort

  • Albumcover og sporinfo: kortet viser coveret, sporet og artisten eller stasjonen for det som spilles.
  • Avspillingskontroller: spill av, pause, neste og forrige, rett på kortet - uten å lete etter fjernkontrollen.
  • Start HEOS for å bla gjennom: trykk for å åpne den offisielle HEOS-appen for stasjoner, køer, HEOS-rom og strømmetjenester. Start noe der, så tar AVR Maestro over visningen av hva som spilles, avspillingskontrollene og widgetene igjen.
  • En del av hjemskjermen din: Spilles nå-kortet ligger sammen med widgetene for volum, kilde og lydmodus, så hva som spilles aldri er mer enn et blikk unna.
Kortet fylles ut for HEOS- og nettverkskilder som rapporterer metadata. Analoge, optiske/koaksiale og HDMI-gjennomløpskilder sender ikke sporinfo til mottakeren, så kortet forblir tomt på dem - det er kilden, ikke appen.
Vanlige spørsmål

Vanlige spørsmål om Spilles nå

Viser den hva som spilles?
Ja - for kilder som rapporterer metadata via HEOS får du albumcover, spor, artist eller stasjon og avspillingskontroller (spill av, pause, neste, forrige), live fra mottakeren.
Hvordan blar jeg gjennom musikk?
Trykk på Start HEOS på kortet Spilles nå. AVR Maestro åpner den offisielle HEOS-appen slik at du kan bla gjennom stasjoner, køer, HEOS-rom og strømmetjenester. Så snart avspillingen er i gang, overtar AVR Maestro igjen visningen av hva som spilles og avspillingskontrollene.
Hvorfor er kortet tomt på noen innganger?
Analoge, optiske/koaksiale og HDMI-gjennomløpskilder rapporterer ikke spormetadata, så det er ingenting å vise. Kortet fylles ut for HEOS- og nettverkskilder som gjør det.
Hvor finner jeg Spilles nå-kortet?
På hjemskjermen din, sammen med widgetene du velger - volum, kilde, lydmodus, soner og mer.

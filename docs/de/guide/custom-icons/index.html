Machen Sie es zu Ihrem

Geben Sie jedem Eingang sein eigenes Symbol

Tauschen Sie die Standardbilder gegen Ihre eigenen aus. Legen Sie ein Blu-ray-Cover auf Ihren Player, das Logo Ihrer Konsole auf den Spiele-Eingang, einen Plattenspieler auf Phono - alles, was die Quelle auf einen Blick erkennbar macht. Ihre Symbole erscheinen auf den Eingangskacheln, im Start-Dashboard und in der Fernbedienung und reisen mit Ihrer Einstellungssicherung.

Symbol in wenigen Fingertipps hinzufügen

  • Halten Sie eine Eingangskachel gedrückt - in der Eingangsliste des Tabs „Fernbedienung“ oder auf der Eingangskarte im Start-Dashboard.
  • Wählen Sie ein beliebiges Bild - PNG, JPG, ICO, WebP und mehr. Ein Logo, ein Cover, ein Foto, was Sie möchten.
  • Schneiden Sie es im Editor im Passfoto-Stil zu: Ziehen Sie zum Positionieren und spreizen Sie zum Zoomen, damit das Wichtige im Bildausschnitt liegt.
  • Wählen Sie eine Form: Kreis, abgerundetes Quadrat und mehr - das Symbol wird direkt im Editor auf die Form zugeschnitten.
  • Speichern. Das Symbol füllt seine Kachel - es erstreckt sich über den zweizeiligen Quellennamen, statt klein in der Mitte zu sitzen - und erscheint überall, wo dieser Eingang angezeigt wird: in der Eingangsliste, im Start-Dashboard und auf der Karte für den aktuellen Eingang im Tab „Fernbedienung“.
Auch für Szenen

Eigene Bilder für Ihre Szenen

Auch jede gespeicherte Szene kann ein eigenes Bild tragen. Öffnen Sie das Blatt Symbol & Farbe der Szene, laden Sie ein Bild hoch und schneiden Sie es auf dieselbe Weise zu. Eine Szene „Filmabend“ kann eine Filmrolle tragen, „Vinyl-Sonntag“ eine Schallplatte - so sind Ihre Ein-Tipp-Einrichtungen genauso leicht erkennbar wie Ihre Eingänge.

Soll das Bild die ganze Kachel ausfüllen? Eigene Quellen- und Szenensymbole können ihre Beschriftung ausblenden, sodass das Bild zentriert und randlos ohne Text darüber die Kachel füllt. Im selben Blatt „Symbol & Farbe“ können Sie die Beschriftung jederzeit wieder einschalten.
Häufige Fragen

FAQ zu eigenen Symbolen

Wo erscheinen eigene Eingangssymbole?
Auf den Eingangskacheln in der Eingangsliste des Tabs „Fernbedienung“, auf der Eingangskarte Ihres Start-Dashboards und auf der Karte für den aktuellen Eingang im Tab „Fernbedienung“ - überall dort, wo diese Quelle in der App auftaucht.
Welche Bildformate kann ich verwenden?
PNG, JPG, ICO, WebP und mehr. Mit dem Zuschnitt-Editor im Passfoto-Stil können Sie jedes davon positionieren, zoomen und in Form bringen.
Kann ich eigene Symbole auch für Szenen verwenden?
Ja. Öffnen Sie bei einer gespeicherten Szene das Blatt „Symbol & Farbe“ und laden Sie ein Bild auf dieselbe Weise hoch. Mehr zum Erstellen und Abrufen von Szenen finden Sie in der Anleitung zu Szenen.
Überleben meine Symbole eine Neuinstallation oder ein neues Telefon?
Ja - eigene Symbole werden in der Einstellungssicherung der App gespeichert. Sichern Sie in den Einstellungen, stellen Sie auf dem neuen Gerät wieder her, und Ihre Bilder kommen mit.
Kann ich die Beschriftung ausblenden, damit das Bild die Kachel ausfüllt?
Ja. Sowohl eigene Quellensymbole als auch eigene Szenensymbole haben eine Option zum Ausblenden der Beschriftung, sodass das Bild zentriert die Kachel ausfüllt, ohne darübergelegten Text.

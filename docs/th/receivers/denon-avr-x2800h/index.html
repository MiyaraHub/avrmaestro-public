AVR-X2800H คือเครื่องรับ Atmos 7.2 ช่องสัญญาณยอดนิยมของ Denon พร้อม 8K, Audyssey MultEQ XT และ HEOS ในราคาคุ้มค่า AVR Maestro ทำให้การควบคุมเป็นเรื่องง่าย ทั้งเร็ว เสถียร และครบทุกอย่างที่ X2800H รองรับ จากโทรศัพท์ของคุณ ไม่ต้องมีบัญชีคลาวด์ ไม่มีการสมัครสมาชิก ไม่มีโฆษณา

คำถามที่พบบ่อย

Denon AVR-X2800H + AVR Maestro

มีแอปสำหรับควบคุม Denon AVR-X2800H ไหม?
มี AVR Maestro เป็นตัวควบคุมพรีเมียมจากผู้พัฒนาอิสระสำหรับ X2800H ผ่านเครือข่ายของคุณ ควบคุมโหมดเซอร์ราวด์ Audyssey MultEQ XT ชุดตั้งค่าลำโพง ระดับเสียง หลายโซน จูนเนอร์ และฉากแบบแตะครั้งเดียว
X2800H รองรับ Dirac Live ในแอปไหม?
Denon AVR-X2800H ใช้ Audyssey MultEQ XT และไม่รองรับ Dirac Live ซึ่งเป็นข้อจำกัดด้านฮาร์ดแวร์ของรุ่นนี้ ไม่ใช่ข้อจำกัดของแอป AVR Maestro ควบคุม Audyssey MultEQ, Dynamic EQ, Dynamic Volume และ LFC บน X2800H ได้แบบสดจากโทรศัพท์ของคุณ ดูคู่มือ Audyssey & Dirac
ต้องมีบัญชีคลาวด์ไหม?
ไม่ต้อง แอปสื่อสารกับ X2800H โดยตรงผ่านเครือข่ายภายในของคุณ ไม่ต้องมีบัญชีคลาวด์ ไม่ต้องสมัครสมาชิก ไม่ต้องซื้ออุปกรณ์เพิ่ม และการตั้งค่าเครื่องรับของคุณจะไม่ออกจากเครือข่ายของคุณ
เชื่อมต่ออย่างไร?
เปิดใช้ Network Control บน X2800H จดที่อยู่ IP ของเครื่อง แล้วเพิ่มในแอป ดูขั้นตอนทั้งหมดได้ที่คู่มือเริ่มต้นใช้งาน

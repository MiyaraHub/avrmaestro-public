การประมวลผล 13.2 ช่องสัญญาณของ AV8805, การปรับเทียบเสียง XT32 และการรองรับ Dirac Live ถูกอ่านจากเครื่องรับเมื่อเชื่อมต่อ - AVR Maestro แสดงเฉพาะสิ่งที่ AV8805 มีให้ คุณจึงได้ฟีเจอร์ครบทั้งชุดโดยไม่มีปุ่มที่กดไม่ได้

Marantz AV8805 + AVR Maestro

มีแอปสำหรับควบคุม Marantz AV8805 ไหม?
มี - AVR Maestro เป็นตัวควบคุมระดับพรีเมียมจากผู้พัฒนารายอื่นสำหรับ AV8805 ควบคุมโหมดเซอร์ราวด์, Audyssey MultEQ XT32 และ Dirac Live, ชุดตั้งค่าลำโพง, ระดับเสียง, มัลติโซน, จูนเนอร์ และฉากแบบแตะครั้งเดียวผ่านเครือข่ายของคุณ
AVR Maestro ควบคุม Dirac Live บน AV8805 ได้ไหม?
ได้ สำหรับ Marantz AV8805 ที่มีไลเซนส์ Dirac Live AVR Maestro จะแสดงรายการสล็อตฟิลเตอร์ Dirac ตามชื่อและสลับสล็อตที่ใช้งานอยู่ ส่วนพรีเซ็ต Audyssey มาตรฐานจะควบคุม MultEQ, Dynamic EQ, Dynamic Volume และ LFC แทน ดูคู่มือ Audyssey & Dirac
ต้องมีบัญชีคลาวด์ไหม?
ไม่ - คุยกับ AV8805 โดยตรงผ่านเครือข่ายภายในของคุณ ไม่ต้องมีบัญชีคลาวด์ ไม่ต้องสมัครสมาชิก และไม่ต้องมีอุปกรณ์เพิ่ม
เชื่อมต่ออย่างไร?
เปิดใช้ Network Control บน AV8805 จดหมายเลข IP ของเครื่อง แล้วเพิ่มในแอป ขั้นตอนทั้งหมดอยู่ในคู่มือเริ่มต้นใช้งาน

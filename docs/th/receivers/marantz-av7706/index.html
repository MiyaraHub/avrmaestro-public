Marantz AV7706 + AVR Maestro

มีแอปสำหรับควบคุม Marantz AV7706 ไหม
มี - AVR Maestro เป็นแอปควบคุมจากผู้พัฒนารายอื่นระดับพรีเมียมสำหรับ AV7706 ผ่านเครือข่ายของคุณ ควบคุมโหมดเซอร์ราวด์ Audyssey MultEQ ชุดตั้งค่าลำโพง ระดับเสียง หลายโซน จูนเนอร์ และฉากแบบแตะครั้งเดียวได้
ต้องมีบัญชีคลาวด์ไหม?
ไม่ต้อง - แอปสื่อสารกับ AV7706 โดยตรงผ่านเครือข่ายภายในบ้านของคุณ ไม่ต้องมีบัญชีคลาวด์ ไม่ต้องสมัครสมาชิก และไม่ต้องซื้ออุปกรณ์เพิ่ม
เชื่อมต่ออย่างไร?
เปิดใช้งานการควบคุมผ่านเครือข่ายบน AV7706 จากนั้นเปิดหน้าเพิ่มเครื่องรับแล้วแตะที่รายการ (หรือป้อนที่อยู่ IP หากไม่พบ) ดูขั้นตอนทั้งหมดได้ในคู่มือเริ่มต้นใช้งาน

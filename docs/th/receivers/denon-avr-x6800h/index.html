คำถามที่พบบ่อย

Denon AVR-X6800H + AVR Maestro

มีแอปสำหรับควบคุม Denon AVR-X6800H ไหม?
มี AVR Maestro เป็นตัวควบคุมพรีเมียมจากผู้พัฒนาอิสระสำหรับ AVR-X6800H ผ่านเครือข่ายของคุณ ควบคุมโหมดเซอร์ราวด์ Audyssey MultEQ XT32 และ Dirac Live ชุดตั้งค่าลำโพง ระดับเสียง หลายโซน จูนเนอร์ และฉากแบบแตะครั้งเดียว
AVR Maestro ควบคุม Dirac Live บน AVR-X6800H ได้ไหม?
ได้ บน Denon AVR-X6800H ที่มีไลเซนส์ Dirac Live, AVR Maestro จะแสดงรายการช่องฟิลเตอร์ Dirac ของคุณตามชื่อ และสลับช่องที่ใช้งานอยู่ได้ ส่วนพรีเซ็ต Audyssey มาตรฐานจะควบคุม MultEQ, Dynamic EQ, Dynamic Volume และ LFC แทน ดูคู่มือ Audyssey & Dirac
ต้องมีบัญชีคลาวด์ไหม?
ไม่ - คุยกับ AVR-X6800H โดยตรงผ่านเครือข่ายภายในของคุณ ไม่ต้องมีบัญชีคลาวด์ ไม่ต้องสมัครสมาชิก และไม่ต้องมีอุปกรณ์เพิ่ม
เชื่อมต่ออย่างไร?
เปิดใช้งาน Network Control บนAVR-X6800H จากนั้นเปิด เพิ่มเครื่องรับ แล้วแตะเครื่องรับในรายการ (หรือป้อนที่อยู่ IP หากไม่มีเครื่องใดตอบสนอง) ดูขั้นตอนทั้งหมดได้ที่คู่มือเริ่มต้นใช้งาน

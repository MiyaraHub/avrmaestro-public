ตรวจสอบตามลำดับนี้

สี่การตรวจสอบที่แก้ปัญหาการเชื่อมต่อได้เกือบทั้งหมด

แต่ละข้อใช้เวลาไม่ถึงหนึ่งนาที หยุดได้ทันทีที่เครื่องรับเชื่อมต่อได้

เครือข่ายและซับเน็ตเดียวกัน

โทรศัพท์และเครื่องรับต้องใช้เครือข่ายเดียวกัน ระบบเมช เครือข่ายแขก และ IoT VLAN อาจแยกอุปกรณ์ออกจากกัน และเครื่องรับที่อยู่คนละซับเน็ตจะไม่ถูกค้นพบโดยอัตโนมัติ

เปิด Network Control

ที่เครื่องรับ ให้เปิด Network Control ในการตั้งค่า เพื่อให้เข้าถึงและปลุกเครื่องจากสแตนด์บายได้ เส้นทางเมนูที่แน่นอนจะแตกต่างกันไปตามรุ่น

ตรวจสอบที่อยู่ IP

อ่านที่อยู่จากหน้าจอ Network, Information ของเครื่องรับเอง แล้วเปรียบเทียบกับที่อยู่ในแอป ที่อยู่ DHCP เปลี่ยนได้ ดังนั้นให้จองที่อยู่ไว้ในเราเตอร์หากเปลี่ยนบ่อย

เครื่องรับไม่ว่าง

หากมีแอปควบคุมเชื่อมต่อค้างไว้มากเกินไป แอปจะแจ้งว่าเครือข่ายไม่ว่าง แทนที่จะล้มเหลวโดยไม่มีสาเหตุ ให้ปิดตัวควบคุมอื่นหรือรอสักครู่

ยังหลุดอยู่

เชื่อมต่อได้ แล้วก็หลุด

สองวิธีนี้แก้ได้เกือบทุกกรณี

ถอดปลั๊กแล้วเสียบใหม่

เมื่อเปิดใช้งานต่อเนื่องนาน Telnet listener ของเครื่องรับอาจค้างได้ การถอดปลั๊กเครื่องรับสักครู่จะล้างปัญหานี้

ใช้ความถี่ Wi-Fi ให้ตรงกัน

เครื่องรับมักอยู่ที่ 2.4 GHz ขณะที่โทรศัพท์นิยมใช้ 5 GHz บนเมช Wi-Fi 6 ให้ใช้โทรศัพท์บนความถี่เดียวกับเครื่องรับ

ขั้นตอนทั้งหมดอยู่ในคู่มือเริ่มต้นใช้งานและหน้าความช่วยเหลือและการแก้ไขปัญหา หากต้องการดูว่ารุ่นของคุณอยู่ในรายการหรือไม่ ให้เปิดหน้าเครื่องรับที่รองรับ

คำถามที่พบบ่อย

ไม่พบเครื่องรับ พร้อมคำตอบ

ทำไม AVR Maestro จึงไม่พบเครื่องรับ Denon หรือ Marantz ของฉัน
โทรศัพท์และเครื่องรับต้องอยู่ในเครือข่ายและซับเน็ตเดียวกัน ระบบเมช เครือข่ายแขก และ IoT VLAN อาจแยกอุปกรณ์ออกจากกัน ตรวจสอบว่าเครื่องรับเปิดอยู่และตั้งค่า Network Control เป็น On จากนั้นลองอีกครั้ง หรือเพิ่มด้วยที่อยู่ IP
จะเปิด Network Control ได้ที่ไหน
ที่เครื่องรับ ให้เปิดการตั้งค่า แล้วไปที่ General หรือ Network และตั้งค่า Network Control เป็น On เพื่อให้เข้าถึงเครื่องรับได้แม้อยู่ในโหมดสแตนด์บาย เส้นทางเมนูที่แน่นอนจะแตกต่างกันไปตามรุ่น
จะดูที่อยู่ IP ของเครื่องรับได้จากที่ไหน
ที่หน้าจอ Network, Information ของเครื่องรับเอง ที่อยู่ DHCP อาจเปลี่ยนได้ ดังนั้นให้ตรวจสอบอีกครั้งหากเครื่องรับที่เคยใช้ได้เชื่อมต่อไม่ได้ หรือจองที่อยู่ไว้ในเราเตอร์
การเชื่อมต่อหลุดบ่อย ทำอย่างไรดี
ถอดปลั๊กเครื่องรับแล้วเสียบใหม่เพื่อล้าง Telnet listener ที่ค้างอยู่ บนเมช Wi-Fi 6 ให้ใช้โทรศัพท์บนความถี่เดียวกับเครื่องรับ เพราะเครื่องรับมักอยู่ที่ 2.4 GHz ขณะที่โทรศัพท์นิยมใช้ 5 GHz
ข้อความเครือข่ายไม่ว่างหมายความว่าอย่างไร
เข้าถึงเครื่องรับได้ แต่สแตกเครือข่ายของเครื่องเต็มแล้ว มักเกิดจากแอปควบคุมหลายแอปเชื่อมต่อค้างไว้พร้อมกัน ให้ปิดตัวควบคุมอื่นหรือรอสักครู่
เครื่องรับรุ่นของฉันรองรับหรือไม่
ไม่มีรายชื่อรุ่นที่อนุญาตเท่านั้น AVR Maestro จะตรวจหาสิ่งที่เครื่องรับของคุณรองรับเมื่อเชื่อมต่อ ดังนั้นหากเว็บพอร์ทัลของเครื่องรับและแอป Denon หรือ Marantz อย่างเป็นทางการเข้าถึงเครื่องได้ AVR Maestro ก็ควรเข้าถึงได้เช่นกัน

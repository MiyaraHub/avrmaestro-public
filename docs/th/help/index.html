การเชื่อมต่อ

“Test Connection” ล้มเหลว
ตรวจสอบให้แน่ใจว่าโทรศัพท์และเครื่องรับอยู่ในเครือข่าย Wi-Fi และซับเน็ตเดียวกัน - ระบบเมช เครือข่ายแขก และ IoT VLAN อาจแยกอุปกรณ์ออกจากกัน บนเครื่องรับ Setup → Network → Network Control ต้องเปิดอยู่ ตรวจสอบ IP ซ้ำกับหน้าจอ Network → Information ของเครื่องรับเอง เพราะที่อยู่ DHCP เปลี่ยนได้ ต้องใช้ HTTP ส่วน Telnet และ HEOS มีไว้ก็ดี หากเข้าถึงเครื่องรับได้แต่เครือข่ายของมันเต็ม - มีแอปควบคุมถือการเชื่อมต่อไว้มากเกินไป - แอปจะแจ้งด้วยข้อความ network busy ที่ชัดเจนแทนข้อผิดพลาดทั่วไป ให้ปิดตัวควบคุมอื่นหรือรอสักครู่ ขั้นตอนทั้งหมดอยู่ในคู่มือเริ่มต้นใช้งาน
การเชื่อมต่อหลุดทุกไม่กี่วินาที
พอร์ต Telnet ของเครื่องรับอาจค้างหลังเปิดใช้งานต่อเนื่องเป็นเวลานาน ให้ถอดปลั๊กเครื่องรับออกจากผนังแล้วเสียบใหม่เพื่อล้างตัวรับฟังการเชื่อมต่อ บนเมช Wi-Fi 6 ให้บังคับโทรศัพท์ไปใช้ย่านความถี่เดียวกับเครื่องรับ (AVR มักอยู่บน 2.4 GHz ส่วนโทรศัพท์มักเลือก 5 GHz)
ฉันจะรู้ได้อย่างไรว่าเครื่องรับของฉันรองรับ
ขึ้นอยู่กับเครือข่ายของคุณ ไม่ใช่แค่รุ่น หากพอร์ทัลเว็บของเครื่องรับ แอป HEOS และแอป Denon/Marantz ทางการเข้าถึงได้ทั้งหมด AVR Maestro ก็ควรเข้าถึงได้เช่นกัน ดูหน้าเครื่องรับที่รองรับ

ระดับเสียงที่แสดงดูผิดปกติ
เครื่องรับรายงานระดับเสียงแบบสัมบูรณ์ (0-98) หรือสัมพัทธ์ (-80 ถึง +18 dB) แอปรองรับทั้งสองแบบ หากคุณเพิ่งเปลี่ยนการตั้งค่าการแสดงระดับเสียงของเครื่องรับ ให้รีสตาร์ตแอปเพื่ออ่านสเกลใหม่ คุณสลับค่าที่จะแสดงเป็นหลักได้ในการตั้งค่า → เสียง
โหมดเสียงหรือป้ายฟีเจอร์เป็นสีเทา / "N/A"
โหมดเซอร์ราวด์และฟีเจอร์ถูกจำกัดโดยรูปแบบเสียงของอินพุตและโหมดเสียงที่ใช้อยู่ - แหล่งสัญญาณ 2 ช่องจะเปิดใช้ Dolby Atmos ไม่ได้ นั่นเป็นพฤติกรรมของเครื่องรับ ไม่ใช่ของแอป แตะ (?) ข้างป้าย N/A เพื่อดูข้อกำหนดที่แน่ชัด
แท็บเสียงหรือลำโพงบางแท็บหายไป
แท็บขึ้นอยู่กับรุ่นและโหมด Audyssey, Dirac Live, IMAX, Auro-3D, รูปทรงเซอร์ราวด์, ระยะห่าง และครอสโอเวอร์ จะปรากฏเฉพาะบนเครื่องรับที่รองรับ ตรวจสอบที่การตั้งค่า → อุปกรณ์ → ข้อมูลอุปกรณ์เพื่อดูว่าแอปตรวจพบอะไร หรือเพิ่มแท็บที่ซ่อนไว้กลับมาได้จากการตั้งค่า → ปรับแต่งแท็บ / ปรับแต่งการนำทาง
ไม่เห็นแท็บวิทยุ
วิทยุขึ้นอยู่กับความสามารถของเครื่อง: จะปรากฏเฉพาะบนเครื่องรับที่มีจูนเนอร์ FM/AM ในตัว หากเครื่องของคุณมีแต่แท็บถูกซ่อน ให้ตรวจสอบว่าจูนเนอร์ปรากฏเป็นอินพุตบนเครื่องรับ แล้วเปิดใช้อีกครั้งจากการตั้งค่า → ปรับแต่งการนำทาง ดูคู่มือวิทยุ
การ์ดกำลังเล่นว่างเปล่า
อินพุตปัจจุบันไม่ส่งข้อมูลเมทาดาตา - แหล่งสัญญาณแอนะล็อก ออปติคัล/โคแอกเชียล และ HDMI แบบส่งผ่านส่วนใหญ่ไม่รายงานข้อมูลแทร็ก สำหรับแหล่งสัญญาณ HEOS ให้แตะเปิด HEOSเพื่อเริ่มเล่น แล้วกลับมา ข้อมูลจะปรากฏขึ้น
วิดเจ็ตหน้าจอหลักแสดง "AVR off" หรือ "Standby"
นั่นคือสถานะปิดของวิดเจ็ต ไม่ใช่ข้อผิดพลาด เมื่อเครื่องรับปิดอยู่ อยู่ในสแตนด์บาย หรือเข้าถึงไม่ได้ วิดเจ็ต (iOS และ Android) จะแสดง"AVR off" / "Standby" แทนอินพุตและระดับเสียงล่าสุด คุณจึงไม่เคยอ่านข้อมูลเก่า บนวิดเจ็ต Quick Control ปุ่มระดับเสียงและปิดเสียงจะถูกซ่อนในสถานะนี้ แต่ปุ่มเปิด/ปิดเครื่องยังใช้งานได้ - แตะเพื่อปลุกเครื่องรับจากวิดเจ็ตได้เลย (ต้องเปิด Network Standby บนเครื่องรับ)
บางหน้าจอลำโพงเปิดในเว็บควบคุมของเครื่องรับ
บนเครื่องรับก่อนปี 2025 บางรุ่น (กลุ่ม X4500H / X6700H / S960H / X4700H) เครื่องรับไม่สามารถส่งหน้าจอผังลำโพงหรือเอาต์พุตซับวูฟเฟอร์ให้แอปได้ AVR Maestro จึงมีปุ่มแตะครั้งเดียวพาคุณเข้าสู่เว็บควบคุมของเครื่องรับเองเพื่อแก้ไขส่วนนั้น ส่วนอื่นทำงานตามปกติ เฟิร์มแวร์ใหม่กว่าส่งให้ครบทุกหน้าจอในแอป

การเชื่อมต่อ

“Test Connection” ล้มเหลว
ตรวจสอบให้แน่ใจว่าโทรศัพท์และเครื่องรับอยู่ในเครือข่าย Wi-Fi และซับเน็ตเดียวกัน - ระบบเมช เครือข่ายแขก และ IoT VLAN อาจแยกอุปกรณ์ออกจากกัน บนเครื่องรับ Setup → Network → Network Control ต้องเปิดอยู่ ตรวจสอบ IP ซ้ำกับหน้าจอ Network → Information ของเครื่องรับเอง เพราะที่อยู่ DHCP เปลี่ยนได้ ต้องใช้ HTTP ส่วน Telnet และ HEOS มีไว้ก็ดี หากเข้าถึงเครื่องรับได้แต่เครือข่ายของมันเต็ม - มีแอปควบคุมถือการเชื่อมต่อไว้มากเกินไป - แอปจะแจ้งด้วยข้อความ network busy ที่ชัดเจนแทนข้อผิดพลาดทั่วไป ให้ปิดตัวควบคุมอื่นหรือรอสักครู่ ขั้นตอนทั้งหมดอยู่ในคู่มือเริ่มต้นใช้งาน
การเชื่อมต่อหลุดทุกไม่กี่วินาที
พอร์ต Telnet ของเครื่องรับอาจค้างหลังเปิดใช้งานต่อเนื่องเป็นเวลานาน ให้ถอดปลั๊กเครื่องรับออกจากผนังแล้วเสียบใหม่เพื่อล้างตัวรับฟังการเชื่อมต่อ บนเมช Wi-Fi 6 ให้บังคับโทรศัพท์ไปใช้ย่านความถี่เดียวกับเครื่องรับ (AVR มักอยู่บน 2.4 GHz ส่วนโทรศัพท์มักเลือก 5 GHz)
ฉันจะรู้ได้อย่างไรว่าเครื่องรับของฉันรองรับ
ขึ้นอยู่กับเครือข่ายของคุณ ไม่ใช่แค่รุ่น หากพอร์ทัลเว็บของเครื่องรับ แอป HEOS และแอป Denon/Marantz ทางการเข้าถึงได้ทั้งหมด AVR Maestro ก็ควรเข้าถึงได้เช่นกัน ดูหน้าเครื่องรับที่รองรับ
การควบคุม & การแสดงผล

ทำไมบางอย่างดูผิดปกติ

ระดับเสียงที่แสดงดูผิดปกติ
ระดับเสียงแสดงได้สองสเกล: สเกล 0-98 หรือสเกลเดซิเบลจาก -80 ถึง +18 dB ทั้งสองบอกระดับเสียงเดียวกัน ในการตั้งค่า › จัดการเครื่องรับ › เครื่องรับของคุณ › Audio Show absolute volume on top เลือกว่าสเกลใดเป็นตัวเลขใหญ่ และRemote volume displayเลือกสเกลที่ใช้บนแท็บรีโมท ดูคู่มือระดับเสียง
โหมดเสียงหรือป้ายฟีเจอร์เป็นสีเทา / "N/A"
โหมดเซอร์ราวด์และฟีเจอร์ถูกจำกัดโดยรูปแบบเสียงของอินพุตและโหมดเสียงที่ใช้งานอยู่ - แหล่งสัญญาณ 2 ช่องจะเปิด Dolby Atmos ไม่ได้ นั่นเป็นพฤติกรรมของเครื่องรับ ไม่ใช่ของแอปคู่มือตัวควบคุมที่ถูกล็อกอธิบายว่าเหตุใดตัวควบคุมจึงถูกล็อกและอะไรปลดล็อกได้
แท็บเสียงหรือลำโพงบางแท็บหายไป
แท็บปรับตามรุ่นและโหมด Audyssey, Dirac Live, IMAX, Auro-3D, Surround Shape, Distances และ Crossovers ปรากฏเฉพาะบนเครื่องรับที่มี ตรวจที่การตั้งค่า › จัดการเครื่องรับ › เครื่องรับของคุณ › Device Informationเพื่อดูว่าแอปตรวจพบอะไร แท็บย่อยที่คุณปิดไว้กลับมาได้จากการตั้งค่า › Customize Tabs และแท็บด้านล่างจากการตั้งค่า › Customize Navigation ดูคู่มือการนำทาง
ไม่เห็นแท็บวิทยุ
วิทยุขึ้นกับความสามารถของเครื่อง: ปรากฏเฉพาะบนเครื่องรับที่มีจูนเนอร์ FM/AM ในตัว หากของคุณมีแต่แท็บถูกซ่อน ตรวจว่าจูนเนอร์ปรากฏเป็นอินพุตบนเครื่องรับ แล้วเปิดใหม่จากการตั้งค่า › Customize Navigation ดูคู่มือวิทยุ
การ์ดกำลังเล่นว่างเปล่า
อินพุตปัจจุบันไม่ส่งข้อมูลเมทาดาตา - แหล่งสัญญาณแอนะล็อก ออปติคัล/โคแอกเชียล และ HDMI แบบส่งผ่านส่วนใหญ่ไม่รายงานข้อมูลแทร็ก สำหรับแหล่งสัญญาณ HEOS ให้แตะเปิด HEOSเพื่อเริ่มเล่น แล้วกลับมา ข้อมูลจะปรากฏขึ้น
วิดเจ็ตหน้าจอหลักแสดง "AVR off" หรือ "Standby"
นั่นคือสถานะปิดของวิดเจ็ต ไม่ใช่ข้อผิดพลาด วิดเจ็ต Quick Control และ Status (iOS และ Android) แสดง"Standby"เมื่อเครื่องรับอยู่ในสแตนด์บาย และ"AVR off"เมื่อติดต่อไม่ได้ แทนอินพุตและระดับเสียงล่าสุด คุณจึงไม่เคยอ่านข้อมูลเก่า บน Android ปุ่มระดับเสียงและปิดเสียงของ Quick Control ซ่อนในสถานะนั้น แต่ปุ่มเปิดปิดยังใช้ได้ - แตะเพื่อปลุกเครื่องรับจากวิดเจ็ตได้เลย (ต้องเปิด Network Standby บนเครื่องรับ) ดูคู่มือวิดเจ็ต
บางหน้าจอลำโพงเปิดในเว็บควบคุมของเครื่องรับ
เฟิร์มแวร์ Denon และ Marantz บางรุ่นไม่ส่ง Speaker Layout, Speaker Distance หรือ Speaker Crossover กลับมาให้แอป หน้านั้นจะบอกไว้ พร้อมRetryและปุ่มที่เปิดหน้าจอนั้นในการควบคุมผ่านเว็บของเครื่องรับเอง หากคุณไม่ได้ใช้ ให้ซ่อนแท็บในการตั้งค่า › Customize Tabs หากหน้าควบคุมผ่านเว็บของเครื่องรับเปิดอยู่ในเบราว์เซอร์ ให้ปิดก่อน เพราะอาจทำให้เครื่องรับยุ่งอยู่
ฉากไม่ถูกใช้ครบ
เครื่องรับอาจปฏิเสธการตั้งค่าที่อินพุต สัญญาณ หรือโหมดเสียงปัจจุบันไม่อนุญาตคู่มือฉากอธิบายว่าต้องตรวจอะไรในหัวข้อเมื่อฉากไม่ถูกใช้ครบ

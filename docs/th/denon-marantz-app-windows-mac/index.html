แป้นพิมพ์ลัด

ควบคุมเครื่องรับจากแป้นพิมพ์

ในเวอร์ชัน Mac App Store และ Microsoft Store ใช้ Cmd บน macOS หรือ Ctrl บน Windows ปุ่มมีเดียบนแป้นพิมพ์ก็ใช้ได้เช่นกัน และจะไม่มีอะไรทำงานขณะที่คุณพิมพ์ในช่องข้อความ ดูเพิ่มเติมในคู่มือรีโมท

ปุ่มลัดการทำงาน

Cmd + ซ้าย / ขวา, Ctrl + ซ้าย / ขวาแทร็กก่อนหน้า / ถัดไป

Windows และ Mac พร้อมคำตอบ

มีแอป Denon หรือ Marantz สำหรับ Windows หรือไม่
มี AVR Maestro มีบน Microsoft Store และควบคุมเครื่องรับ AV ของ Denon และ Marantz ที่รองรับเครือข่ายจาก PC Windows ที่อยู่ในเครือข่ายเดียวกับเครื่องรับ
มีแอป Denon หรือ Marantz สำหรับ Mac หรือไม่
มี AVR Maestro มีบน Mac App Store พร้อมแป้นพิมพ์ลัด Cmd และรองรับปุ่มมีเดีย
แอปบนเดสก์ท็อปมีแป้นพิมพ์ลัดหรือไม่
มี ใช้ Cmd บน macOS หรือ Ctrl บน Windows: Space เพื่อเล่น/หยุดชั่วคราว . (จุด) เพื่อหยุด ซ้าย/ขวาเพื่อไปแทร็กก่อนหน้า/ถัดไป ขึ้น/ลงเพื่อปรับเสียง และ M เพื่อปิดเสียง ปุ่มมีเดียก็ใช้ได้เช่นกัน และแป้นพิมพ์ลัดจะหยุดทำงานขณะที่คุณพิมพ์ในช่องข้อความ
ผู้ช่วยใช้งานบน Windows ได้หรือไม่
ไม่ได้ ผู้ช่วยต้องใช้โมเดลในอุปกรณ์ ได้แก่ Apple Intelligence บน iPhone, iPad หรือ Mac (macOS 26) หรือ Gemini Nano บน Android ส่วนอื่นทั้งหมดในรายการนี้ใช้งานบน Windows ได้ ดูคู่มือผู้ช่วย

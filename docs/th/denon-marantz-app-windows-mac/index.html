คีย์ลัด

ควบคุมเครื่องรับจากคีย์บอร์ด

ในเวอร์ชันจาก Mac App Store และ Microsoft Store ใช้ Cmd บน macOS หรือ Ctrl บน Windows ปุ่มมีเดียบนคีย์บอร์ดก็ใช้ได้ และจะไม่มีคำสั่งใดทำงานขณะคุณพิมพ์ในช่องข้อความ ดูเพิ่มเติมในคู่มือรีโมท

ปุ่มลัดการทำงาน
Cmd + Space / Ctrl + Spaceเล่น / หยุดชั่วคราว
Cmd + . / Ctrl + . (จุด)หยุด
Cmd + ซ้าย / ขวา, Ctrl + ซ้าย / ขวาแทร็กก่อนหน้า / ถัดไป
Cmd + ขึ้น / ลง, Ctrl + ขึ้น / ลงเพิ่ม / ลดระดับเสียง
Cmd + M / Ctrl + Mสลับปิด/เปิดเสียง

คำตอบเรื่อง Windows และ Mac

มีแอป Denon หรือ Marantz สำหรับ Windows ไหม?
มี AVR Maestro อยู่บน Microsoft Store และควบคุมเครื่องรับ AV ของ Denon และ Marantz ที่เชื่อมต่อเครือข่ายได้ จาก PC ที่ใช้ Windows ซึ่งอยู่บนเครือข่ายเดียวกับเครื่องรับ
มีแอป Denon หรือ Marantz สำหรับ Mac ไหม?
มี AVR Maestro อยู่บน Mac App Store พร้อมคีย์ลัดแบบ Cmd และรองรับปุ่มมีเดีย
แอปเดสก์ท็อปมีคีย์ลัดไหม?
มี ใช้ Cmd บน macOS หรือ Ctrl บน Windows: Space สำหรับเล่น/หยุดชั่วคราว . (จุด) สำหรับหยุด ซ้าย/ขวา สำหรับแทร็กก่อนหน้า/ถัดไป ขึ้น/ลง สำหรับระดับเสียง และ M เพื่อปิดเสียง ปุ่มมีเดียก็ใช้ได้ และคีย์ลัดจะหยุดทำงานชั่วคราวขณะคุณพิมพ์ในช่องข้อความ
ผู้ช่วยใช้งานบน Windows ได้ไหม?
ไม่ได้ ผู้ช่วยต้องใช้โมเดลบนอุปกรณ์: Apple Intelligence บน iPhone, iPad หรือ Mac (macOS 26) หรือ Gemini Nano บน Android ส่วนอื่นทั้งหมดในรายการนี้ใช้งานได้บน Windows ดูคู่มือผู้ช่วย

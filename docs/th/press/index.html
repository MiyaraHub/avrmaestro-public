ชุดข้อมูลสื่อ AVR Maestro

ทุกอย่างที่ต้องใช้เพื่อเขียนถึง AVR Maestro: แอปนี้คืออะไร ข้อเท็จจริงที่ไม่เปลี่ยนแปลง ไอคอนแอปและภาพหน้าจอที่ใช้ได้

แอปนี้คืออะไร

AVR Maestro เป็นรีโมตเครือข่ายอิสระสำหรับเครื่องรับ AV ของ Denon และ Marantz สื่อสารกับเครื่องรับผ่านเครือข่ายภายในบ้านของคุณ โดยไม่ต้องมีบัญชี ไม่มีโฆษณา และไม่มีบริการคลาวด์คั่นกลาง และแสดงเฉพาะสิ่งที่เครื่องรับรุ่นของคุณมีจริง ๆ

  • ราคา: $9.99 จ่ายครั้งเดียว ไม่มีการสมัครสมาชิกและไม่มีโฆษณา ส่วนเสริม Home Automation Pro ที่เลือกใช้ได้ราคา $2.99
  • แพลตฟอร์ม: iPhone และ iPad, Mac, Android และ Windows
  • เครื่องรับ: เครื่องรับเครือข่ายของ Denon และ Marantz ดูรายการเครื่องรับ
  • ภาษา: 30
  • ผู้พัฒนา: MiyaraHub Technologies LLC
  • ความเป็นส่วนตัว: รายงานข้อขัดข้องและสถิติการใช้งานแบบไม่ระบุตัวตนจะส่งไปยัง Firebase เพื่อช่วยแก้ไขข้อบกพร่อง ดูนโยบายความเป็นส่วนตัว

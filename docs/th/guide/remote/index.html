รีโมท

รีโมทตัวจริง พร้อมภาพสถานะแบบสด

ควบคุม D-pad และปุ่มควบคุมการเล่นได้เต็มรูปแบบ พร้อมส่วนหัวสดที่แสดงอินพุต โหมดเสียง และช่องสัญญาณที่ใช้อยู่จริง คุณจึงรู้เสมอว่า Denon หรือ Marantz ของคุณกำลังทำอะไร ปัดหรือแตะแท็บหน้าที่ด้านบนเพื่อเลื่อนระหว่างหน้าได้สูงสุดห้าหน้า

สูงสุดห้าหน้า

ครบทุกอย่าง โดยไม่ต้องใช้รีโมทจริง

เปิดแท็บรีโมท หน้าที่คุณเห็นขึ้นอยู่กับเครื่องรับของคุณ หน้าสำหรับสิ่งที่เครื่องรับของคุณไม่มีจะถูกละไว้

  • รีโมทหลัก: แถบคำสั่ง (เปิด-ปิดเครื่อง / ข้อมูล / การตั้งค่า / ตัวเลือก / กลับ) D-pad ปุ่มควบคุมการเล่น และแถบระดับเสียง พร้อมส่วนหัวแบบสดที่แสดงอินพุต โหมดเสียง และช่องสัญญาณ IN/OUT ที่ใช้งานอยู่
  • Inputs: ตารางแหล่งสัญญาณทั้งหมด แตะไทล์เพื่อสลับอินพุต กดไทล์ค้างเพื่อกำหนดไอคอนเอง ตารางใช้ชื่อและลำดับของคุณเอง (ดูเปลี่ยนชื่อและจัดลำดับอินพุตของคุณด้านล่าง)
  • Smart Select / Quick Select: AVR Maestro เรียกชื่อตามที่เครื่องรับของคุณใช้ คือ Smart Select บน Marantz และ Quick Select บน Denon แตะที่ช่องเพื่อเรียกค่าที่เครื่องรับเก็บไว้ในช่องนั้น กดค้างเพื่อเปลี่ยนชื่อหรือบันทึกสถานะปัจจุบัน (ตัวช่วยจะให้คุณเลือกได้ว่าจะบันทึกการตั้งค่าใดบ้าง) ชื่อช่องที่เปลี่ยนจะถูกบันทึกลงเครื่องรับด้วย จึงตามคุณไปยังแอปอื่นทุกตัว
  • System: ตัวควบคุมโดยตรงสำหรับทั้งเครื่องรับ (ระบุไว้ด้านล่าง)
  • Trigger Out: มีเฉพาะบนเครื่องรับที่มีเอาต์พุตทริกเกอร์ 12V เลือกโซน อินพุต และเอาต์พุต HDMI ที่เปิดแต่ละทริกเกอร์ (ดูด้านล่าง)
ไม่เคยใช้หน้าใดหรือ ซ่อนไว้ในการตั้งค่า › ปรับแต่งแท็บ การตั้งค่านี้ใช้กับทุกเครื่องรับ
ทีละขั้นตอน

เปลี่ยนชื่อและจัดลำดับอินพุตของคุณ

เรียกอินพุตของคุณตามสิ่งที่มันเป็น - "Nvidia Shield", "Xbox", "PS5" - และวางอันที่ใช้บ่อยที่สุดไว้ก่อน

  1. บนแท็บหน้าแรก แตะการ์ดInput Sourceเพื่อเปิดรายการแหล่งสัญญาณ
  2. กดไทล์ใดก็ได้ค้างไว้ รายการจะเปลี่ยนเป็นโหมดแก้ไข: แตะไทล์เพื่อเปลี่ยนชื่อ หรือลากเพื่อจัดลำดับใหม่ แตะ Done เมื่อเสร็จ
  3. หากต้องการเปลี่ยนชื่อ แตะไทล์ พิมพ์ชื่อใหม่ แล้วแตะบันทึก
  4. หากต้องการจัดลำดับใหม่ ลากไทล์ไปยังตำแหน่งใหม่
  5. แตะDone
ชื่อใหม่จะถูกเขียนลงเครื่องรับเอง จึงแสดงในแอปของผู้ผลิตและไคลเอนต์อื่นทุกตัวด้วย รวมถึงตัวเครื่องรุ่นเก่า และแอปยืนยันด้วยSource renamed หากเครื่องรับไม่ยอมรับ คุณจะเห็นSource renamed on this device onlyและชื่อนั้นอยู่ใน AVR Maestro เท่านั้น ลำดับจะบันทึกต่อเครื่องรับ และหน้า Inputs ของรีโมทก็ใช้ลำดับนั้นด้วย
รีโมท › System

ตัวควบคุมโดยตรงสำหรับทั้งเครื่องรับ

หน้า System แสดงเฉพาะสิ่งที่เครื่องรับของคุณรายงานว่ามี รายการจึงสั้นลงในบางรุ่น สิ่งที่คุณอาจเห็น จากบนลงล่าง:

  • HDMI Output และIlluminationหรือDimmer (ความสว่างของจอแสดงผลด้านหน้า)
  • Triggers: เปิดหรือปิดทริกเกอร์ 12V แต่ละตัวด้วยมือ หากต้องการให้ทริกเกอร์ตามโซน อินพุต หรือเอาต์พุต HDMI ให้ใช้หน้า Trigger Out แทน
  • ECO Mode Auto Standby และSleep Timer
  • HDMI CEC และHDMI Audio Decode (AMP หรือ TV)
  • Speaker Preset: สลับระหว่างชุดตั้งค่าลำโพงของเครื่องรับ
  • Bluetooth Transmitter: บนรุ่นที่ส่งเสียงไปยังหูฟังหรือลำโพงบลูทูธได้ เปิดหรือปิดTransmitter แล้วเลือกBT+ลำโพง (บลูทูธและลำโพงในห้องของคุณพร้อมกัน) หรือBT Only
  • Picture Mode และVideo Processing Mode (Auto, Game, Movie, Bypass) Game, Movie และ Bypass ใช้ได้เฉพาะขณะที่แหล่งสัญญาณ HDMI กำลังเล่นวิดีโอ มิฉะนั้นเครื่องรับจะอยู่ที่ Auto
  • All Zone Stereo Auto Lip Sync (Marantz) Audio Delay และLFE Level
  • Input Mode (Auto, HDMI, Digital, Analog)
  • Digital Input Format: Auto ให้เครื่องรับตัดสินใจ PCM บังคับถอดรหัส PCM และ DTS บังคับถอดรหัส DTS ใช้เมื่อแหล่งสัญญาณส่งรูปแบบที่เครื่องรับอ่านผิดจนเงียบไป
เครื่องรับบางรุ่นล็อก Digital Input Format หรือ LFE Level ขณะที่อินพุตหรือโหมดเซอร์ราวด์บางอย่างทำงานอยู่ แอปจะแสดงค่าปัจจุบันพร้อมแบนเนอร์ล็อกแทนปุ่ม แตะไอคอนรีเฟรชข้างหัวข้อเพื่อตรวจสอบอีกครั้งหลังจากเปลี่ยนอินพุตหรือโหมด ดูเหตุใดตัวควบคุมจึงถูกล็อก
รีโมท › Trigger Out

เปิดจอ ซับ หรือแอมป์ของคุณโดยอัตโนมัติ

เอาต์พุตทริกเกอร์ 12V บอกอุปกรณ์อื่นให้เปิดเครื่อง บนเครื่องรับที่มีเอาต์พุตนี้ หน้า Trigger Out ให้คุณเลือกสิ่งที่เปิดแต่ละทริกเกอร์ ทริกเกอร์จะทำงานเมื่อรายการที่เปิดใช้งานรายการใดก็ได้ทำงานอยู่ รายการอ่านสดจากเครื่องรับของคุณ

  1. เปิดแท็บรีโมทแล้วปัดไปที่Trigger Out
  2. หากเครื่องรับของคุณมีทริกเกอร์มากกว่าหนึ่งตัว ให้เลือกTrigger Out 1 Trigger Out 2 และอื่น ๆ ที่ด้านบน
  3. เปิดสวิตช์ของรายการที่ควรทำให้ทริกเกอร์ทำงาน ซึ่งจัดกลุ่มไว้ใต้Zones Sources และHDMI Out
สวิตช์แต่ละตัวถูกส่งไปยังเครื่องรับทันที หากเครื่องรับไม่ยอมรับการเปลี่ยนแปลง ข้อความที่ขึ้นต้นด้วยTrigger Out:จะแจ้งคุณ และสวิตช์จะแสดงสถานะจริงของเครื่องรับ หากคุณเห็นTrigger Out unavailableบนเครื่องรับที่มีทริกเกอร์ เครื่องรับอาจกำลังยุ่ง ให้ปิดหน้าควบคุมผ่านเว็บของเครื่องหากเปิดอยู่ในเบราว์เซอร์ แล้วแตะRetry
ระดับเสียง ตามแบบของคุณ

อ่านระดับเสียงเป็น dB หรือมาตราส่วนสัมพัทธ์

แถบระดับเสียงของ Main Remote แสดงระดับเสียงหลักแบบสด และชิปส่วนหัวสะท้อนค่าเดียวกัน ต้องการตัวเลขของเครื่องรับเองมากกว่าเดซิเบลหรือไม่ สลับการแสดงผลระหว่างสเกล dB (เช่น -40.5 dB ซึ่งเป็นค่าเริ่มต้น) และสเกล 0-98 (เช่น 39.5) ทั้งชิปส่วนหัวและแถบระดับเสียงจะตามตัวเลือกของคุณ

  1. เปิดการตั้งค่า › จัดการเครื่องรับแล้วแตะเครื่องรับของคุณ
  2. ใต้เสียง เปิดการแสดงระดับเสียงในรีโมทแล้วเลือกสเกล
ตัวเลือกนี้บันทึกต่อเครื่องรับ เครื่องรับสองเครื่องจึงแสดงสเกลต่างกันได้
กดค้าง

ปุ่มระดับเสียงไล่ระดับได้ เหมือนปุ่มบนรีโมทจริง

แตะปุ่มบวกหรือลบ ระดับเสียงจะขยับทีละขั้น กดค้างไว้ ระดับเสียงจะขยับต่อเนื่องอย่างนุ่มนวลจนกว่าคุณจะปล่อย เหมือนรีโมทจริงและตรงกับที่มือของคุณคาดหวัง เมื่อปล่อย เครื่องรับจะหยุดที่ขั้นที่คุณปล่อยพอดี ไม่เลยไปจากนั้น

เบื้องหลัง แอปจะรวบรวมคำสั่ง โดยสะสมทิศทางที่คุณกำลังไปและควบคุมจังหวะของสิ่งที่ส่งออกไปจริง การกดค้างนาน ๆ จึงไม่ท่วมเครื่องรับที่ตอบสนองช้า การปรับเล็กน้อยก็นุ่มนวลเช่นกัน การเปลี่ยนแปลงไม่กี่เดซิเบลจะไล่ระดับขึ้นหรือลง ไม่กระโดดทันที

จะปรากฏบนรีโมทเมื่อเครื่องรับของคุณมีเอาต์พุตทริกเกอร์ 12V สำหรับแต่ละทริกเกอร์ คุณเลือกว่าโซน แหล่งอินพุต และเอาต์พุต HDMI ใดเปิดทริกเกอร์ ทริกเกอร์จะทำงานเมื่อรายการที่เปิดใช้งานรายการใดก็ได้ทำงานอยู่ จอโปรเจกเตอร์ ซับวูฟเฟอร์ หรือแอมป์จึงเปิดเองได้ รายการอ่านสดจากเครื่องรับของคุณ หากเครื่องรับไม่ยอมรับการเปลี่ยนแปลง แอปจะแจ้งและแสดงสถานะจริงของเครื่องรับ
AVR Maestro มีปุ่มลัดบนเดสก์ท็อปไหม
มี บน Mac และ Windows คุณควบคุมการเล่นและระดับเสียงจากคีย์บอร์ดได้ ใช้ Cmd บน macOS หรือ Ctrl บน Windows: Space เพื่อเล่น/หยุดชั่วคราว . (จุด) เพื่อหยุด ซ้าย/ขวาเพื่อไปแทร็กก่อนหน้า/ถัดไป ขึ้น/ลงเพื่อปรับระดับเสียง และ M เพื่อปิดเสียง ปุ่มมีเดียเฉพาะของคุณ (เล่น หยุดชั่วคราว ถัดไป ก่อนหน้า หยุด ระดับเสียง ปิดเสียง) ก็ใช้ได้เช่นกัน ปุ่มลัดจะหยุดทำงานขณะที่คุณพิมพ์ในช่องข้อความ

รีโมท

รีโมทตัวจริง พร้อมภาพสถานะแบบสด

D-pad และปุ่มควบคุมการเล่นครบถ้วน พร้อมส่วนหัวแบบสดที่แสดงอินพุต โหมดเสียง และช่องสัญญาณที่ใช้งานอยู่จริง คุณจึงรู้เสมอว่า Denon หรือ Marantz ของคุณกำลังทำอะไรอยู่ มีสี่หน้า ปัดหรือแตะแท็บหน้าเพื่อสลับ

สี่หน้า

ครบทุกอย่าง โดยไม่ต้องใช้รีโมทจริง

  • รีโมทหลัก: แถบคำสั่ง (เปิด-ปิดเครื่อง / ข้อมูล / การตั้งค่า / ตัวเลือก / กลับ) D-pad ปุ่มควบคุมการเล่น และแถบระดับเสียง พร้อมส่วนหัวแบบสดที่แสดงอินพุต โหมดเสียง และช่องสัญญาณ IN/OUT ที่ใช้งานอยู่
  • อินพุต: ตารางแหล่งสัญญาณทั้งหมด เปลี่ยนชื่อและจัดลำดับใหม่ให้ตรงกับอุปกรณ์ของคุณ เปิดรายการแหล่งสัญญาณ แตะไทล์เพื่อแก้ไข แตะแหล่งสัญญาณเพื่อเปลี่ยนชื่อ แล้วลากเพื่อจัดลำดับใหม่ ชื่อใหม่จะถูกเขียนลงเครื่องรับโดยตรง จึงแสดงทันทีที่นี่ ในแอปของผู้ผลิต และในแอปอื่นทุกตัว รวมถึงเครื่องรุ่นเก่า ลำดับจะถูกบันทึกแยกตามเครื่องรับ
  • Smart Select / Quick Select: AVR Maestro เรียกชื่อตามที่เครื่องรับของคุณใช้ คือ Smart Select บน Marantz และ Quick Select บน Denon แตะที่ช่องเพื่อเรียกค่าที่เครื่องรับเก็บไว้ในช่องนั้น กดค้างเพื่อเปลี่ยนชื่อหรือบันทึกสถานะปัจจุบัน (ตัวช่วยจะให้คุณเลือกได้ว่าจะบันทึกการตั้งค่าใดบ้าง) ชื่อช่องที่เปลี่ยนจะถูกบันทึกลงเครื่องรับด้วย จึงตามคุณไปยังแอปอื่นทุกตัว
  • ระบบ: ปุ่มควบคุมโดยตรง ได้แก่ เอาต์พุต HDMI ตัวหรี่ไฟ/ไฟส่องสว่าง ทริกเกอร์ ECO สแตนด์บายอัตโนมัติ ตั้งเวลาปิด CEC เอาต์พุตเสียง HDMI พรีเซ็ตลำโพง โหมดภาพ/วิดีโอ สเตอริโอทุกโซน ลิปซิงก์อัตโนมัติ หน่วงเวลาเสียง โหมดอินพุต รายการที่ไม่รองรับจะถูกซ่อนไว้
ระดับเสียง ตามแบบของคุณ

อ่านระดับเสียงเป็น dB หรือมาตราส่วนสัมพัทธ์

แถบระดับเสียงของรีโมทหลักแสดงระดับเสียงหลักแบบสด และชิปบนส่วนหัวแสดงค่าเดียวกัน อยากใช้ตัวเลขของเครื่องรับเองแทนเดซิเบลใช่ไหม ในการตั้งค่า คุณสลับการแสดงระดับเสียงระหว่างdB สัมบูรณ์ (เช่น -62.5 dB) กับมาตราส่วนสัมพัทธ์ได้ ทั้งชิปบนส่วนหัวและแถบระดับเสียงจะเปลี่ยนตามที่คุณเลือก รีโมททั้งหมดจึงใช้หน่วยที่คุณคุ้นเคย

กดค้าง

ปุ่มระดับเสียงไล่ระดับได้ เหมือนปุ่มบนรีโมทจริง

แตะปุ่มบวกหรือลบ ระดับเสียงจะขยับทีละขั้น กดค้างไว้ ระดับเสียงจะขยับต่อเนื่องอย่างนุ่มนวลจนกว่าคุณจะปล่อย เหมือนรีโมทจริงและตรงกับที่มือของคุณคาดหวัง เมื่อปล่อย เครื่องรับจะหยุดที่ขั้นที่คุณปล่อยพอดี ไม่เลยไปจากนั้น

เบื้องหลัง แอปจะรวบรวมคำสั่ง โดยสะสมทิศทางที่คุณกำลังไปและควบคุมจังหวะของสิ่งที่ส่งออกไปจริง การกดค้างนาน ๆ จึงไม่ท่วมเครื่องรับที่ตอบสนองช้า การปรับเล็กน้อยก็นุ่มนวลเช่นกัน การเปลี่ยนแปลงไม่กี่เดซิเบลจะไล่ระดับขึ้นหรือลง ไม่กระโดดทันที

ปุ่มลัดบน Mac & Windows

ในเวอร์ชัน Mac App Store และ Microsoft Store คุณควบคุมการเล่นและระดับเสียงจากคีย์บอร์ดได้เลย ไม่ต้องเอื้อมไปจับเมาส์ ใช้ Cmd บน macOS หรือ Ctrl บน Windows และปุ่มมีเดียเฉพาะบนคีย์บอร์ดของคุณก็ใช้ได้เช่นกัน จะไม่มีอะไรทำงานขณะที่คุณพิมพ์ในช่องข้อความ การเปลี่ยนชื่ออินพุตหรือป้อน IP จึงไม่ถูกขัดจังหวะ

คำถามที่พบบ่อยเกี่ยวกับรีโมท

เปลี่ยนชื่อและจัดลำดับอินพุตใหม่ได้ไหม
ได้ เปิดรายการแหล่งสัญญาณ แตะไทล์เพื่อแก้ไข แตะแหล่งสัญญาณเพื่อเปลี่ยนชื่อ แล้วลากเพื่อจัดลำดับใหม่ ตั้งชื่อเป็น “Nvidia Shield”, “Xbox”, “PS5” ก็ได้ ชื่อใหม่จะถูกเขียนลงในเครื่องรับโดยตรง จึงแสดงทันทีใน AVR Maestro ในแอปของผู้ผลิต และในแอปอื่นทุกตัว รวมถึงเครื่องรุ่นเก่า ลำดับจะถูกบันทึกแยกตามเครื่องรับในทุกที่
ใส่ไอคอนกำหนดเองให้อินพุตได้ไหม
ได้ กดค้างที่ไทล์อินพุต เลือกภาพใดก็ได้ (PNG, JPG, ICO, WebP และอื่น ๆ) จัดตำแหน่งในเครื่องมือครอปแบบรูปติดบัตร แล้วบันทึก ดูขั้นตอนทั้งหมดได้ในคู่มือไอคอนอินพุตกำหนดเอง
รีโมทเสมือนควบคุมอะไรได้บ้าง
แถบคำสั่ง (เปิด-ปิดเครื่อง/ข้อมูล/การตั้งค่า/ตัวเลือก/กลับ) D-pad ปุ่มควบคุมการเล่น และระดับเสียง พร้อมส่วนหัวแบบสดที่แสดงอินพุต โหมดเสียง และช่องสัญญาณที่ใช้งาน หน้าระบบมีปุ่มควบคุมโดยตรง (เอาต์พุต HDMI ตัวหรี่ไฟ ทริกเกอร์ ECO ตั้งเวลาปิด CEC และอื่น ๆ) รายการที่ไม่รองรับจะถูกซ่อนไว้
Smart Select / Quick Select คืออะไร
Smart Select ของ Marantz และ Quick Select ของ Denon คือช่องหน่วยความจำในตัวเครื่องรับ AVR Maestro เรียกชื่อตามที่เครื่องรับของคุณใช้ คือ Smart Select บน Marantz และ Quick Select บน Denon แตะเพื่อเรียกใช้ กดค้างเพื่อเปลี่ยนชื่อ หรือบันทึกสถานะปัจจุบันด้วยตัวช่วยบันทึกค่า
AVR Maestro มีปุ่มลัดบนเดสก์ท็อปไหม

(จุด) เพื่อหยุด ซ้าย/ขวาเพื่อไปแทร็กก่อนหน้า/ถัดไป ขึ้น/ลงเพื่อปรับระดับเสียง และ M เพื่อปิดเสียง ปุ่มมีเดียเฉพาะของคุณ (เล่น หยุดชั่วคราว ถัดไป ก่อนหน้า หยุด ระดับเสียง ปิดเสียง) ก็ใช้ได้เช่นกัน ปุ่มลัดจะหยุดทำงานขณะที่คุณพิมพ์ในช่องข้อความ

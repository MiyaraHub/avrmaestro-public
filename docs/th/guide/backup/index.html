สำรองข้อมูล & กู้คืน: การตั้งค่าทั้งหมดของคุณในไฟล์เดียว

การเปลี่ยนชื่ออินพุตทุกช่อง เลือกภาพประกอบให้แต่ละช่อง จัดลำดับแหล่งสัญญาณ และสร้างชุดฉากขึ้นมา เป็นงานที่ต้องใช้เวลาจริง ๆ สิ่งเหล่านี้ควรอยู่รอดเมื่อเปลี่ยนโทรศัพท์ และมันก็เป็นเช่นนั้น ส่งออกหนึ่งครั้ง นำเข้าหนึ่งครั้ง เครื่องใหม่ก็หน้าตาเหมือนเครื่องเดิมทุกประการ

ส่งออก

บันทึกลงอุปกรณ์ หรือแชร์ต่อได้ทันที

เปิดการตั้งค่า เลื่อนไปที่สำรองข้อมูล & กู้คืน แล้วเลือก:

  • บันทึกลงอุปกรณ์ - เขียนไฟล์ JSON ไฟล์เดียวไปยังตำแหน่งที่คุณระบุ
  • แชร์ - ส่งไฟล์ไปยังชีตแชร์ที่คุณใช้เป็นประจำ เพื่อส่งตรงไปยังโทรศัพท์อีกเครื่อง ไดรฟ์ในระบบคลาวด์ หรือข้อความถึงตัวคุณเอง

เป็นไฟล์ข้อความธรรมดา ไม่มีสิ่งใดในไฟล์ที่ผูกติดกับอุปกรณ์ต้นทาง

ลำดับแหล่งสัญญาณของแต่ละเครื่องลำดับที่คุณลากอินพุตไปจัดไว้ เก็บแยกตามเครื่องรับแต่ละเครื่อง
ธีมและสีธีมสีเน้นและตัวเลือกรูปลักษณ์ของคุณ

ค่ากำหนดระดับเสียงพฤติกรรมระดับเสียงในฝั่งแอป
สถานะการ์ดคำอธิบายแบนเนอร์ข้อมูลที่คุณปิดไปแล้ว จะได้ยังคงถูกปิดอยู่
ผลการตรวจสอบที่แคชไว้ผลการตรวจสอบ HEOS ฟีเจอร์ และความสามารถด้านเพลง เพื่อให้โทรศัพท์เครื่องใหม่ไม่ต้องเริ่มต้นจากศูนย์
ชื่ออินพุตและภาพประกอบที่กำหนดเองเป็นส่วนหนึ่งของการตั้งค่าเครื่องรับ จึงย้ายมาพร้อมกัน ดูคู่มือไอคอนกำหนดเอง
นำเข้า

การกู้คืนบนโทรศัพท์เครื่องใหม่

  1. ติดตั้ง AVR Maestro บนอุปกรณ์เครื่องใหม่ และตรวจสอบให้แน่ใจว่าอยู่ในเครือข่ายเดียวกับเครื่องรับของคุณ
  2. เปิดการตั้งค่า › สำรองข้อมูล & กู้คืน
  3. แตะนำเข้าการตั้งค่าจากไฟล์ แล้วเลือกไฟล์สำรอง
  4. รีสตาร์ตแอป แอปจะแจ้งเรื่องนี้เช่นกัน การรีสตาร์ตช่วยให้ทุกการตั้งค่าที่กู้คืนมามีผลอย่างสมบูรณ์
การนำเข้าเป็นการแทนที่ ไม่ใช่การรวม ทุกอย่างที่อยู่บนอุปกรณ์เครื่องนั้นจะถูกเขียนทับด้วยเนื้อหาในไฟล์สำรอง หากการตั้งค่าปัจจุบันมีค่ากับคุณ ให้ส่งออกไว้ก่อน ใช้เพียงสองแตะ
ควรรู้ไว้

ไฟล์สำรองคือข้อมูลของแอป ไม่ใช่ของเครื่องรับ

การสอบเทียบ ชุดตั้งค่าลำโพง ระดับเสียง ระยะห่าง ครอสโอเวอร์ และตัวกรอง Dirac ของคุณอยู่ในเครื่องรับ สิ่งเหล่านี้ไม่ได้อยู่ในไฟล์สำรอง และการนำเข้าไฟล์สำรองจะไม่กระทบสิ่งเหล่านั้น ซึ่งมีผลทั้งสองทาง ไฟล์สำรองจะไม่กู้คืนเครื่องรับที่คุณรีเซ็ตเป็นค่าจากโรงงาน และก็ไม่จำเป็นต้องทำ เพียงเชื่อมต่อแอปกับเครื่องรับนั้นอีกครั้ง แอปก็จะดึงการตั้งค่ากลับมาจากเครื่องรับเอง

ควรสำรองไว้ก่อนการจัดระเบียบครั้งใหญ่ด้วย ส่งออกไว้ แล้วจัดอินพุตใหม่และสร้างฉากใหม่ได้อย่างเต็มที่ หากชอบแบบเดิมมากกว่า ไฟล์ก็พร้อมอยู่ตรงนั้น

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับการสำรองข้อมูล

ย้ายไฟล์สำรองระหว่าง Android กับ iPhone ได้ไหม
ไฟล์เป็น JSON ธรรมดาและไม่ผูกกับอุปกรณ์ที่สร้างไฟล์ ส่งออกจากเครื่องหนึ่ง ย้ายไฟล์ไปยังอีกเครื่อง แล้วนำเข้าได้เลย
การนำเข้าจะเขียนทับการสอบเทียบของเครื่องรับของฉันไหม
ไม่ ไฟล์สำรองมีเฉพาะการตั้งค่าของแอปเท่านั้น ทุกอย่างที่เครื่องรับจัดเก็บไว้เอง ไม่ว่าจะเป็นการสอบเทียบ พรีเซ็ต ระดับเสียง ระยะห่าง และตัวกรอง Dirac อยู่ในเครื่องรับและจะไม่ถูกแตะต้อง
ฉากของฉันจะย้ายมาด้วยไหม
ได้ พร้อมกับรายการการตั้งค่าที่แต่ละฉากถูกกำหนดให้บันทึกไว้ ดูคู่มือฉาก
ตัวเลือกบันทึกลงอุปกรณ์จะเก็บไฟล์ไว้ที่ไหน

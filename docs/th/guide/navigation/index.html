การเดินทางในแอป

แท็บ การปัด และท่าทาง

วิธีใช้งานรอบ AVR Maestro: แท็บด้านล่างและวิธีเปลี่ยน การปัดระหว่างหน้า สิ่งที่การแตะและการกดค้างทำ ปุ่มย้อนกลับ ข้อความแจ้งอัปเดต ข้อความ และแป้นพิมพ์ลัดบนคอมพิวเตอร์

แท็บด้านล่าง

แถบที่ด้านล่างของหน้าจอเก็บแท็บหลักของคุณ เมื่อเริ่มต้นได้แก่ หน้าแรก รีโมท เสียง โซน ฉาก ลำโพง และการตั้งค่า เพิ่มวิทยุได้เช่นกัน ปุ่มค้นหาอยู่ที่ปลายด้านขวาของแถบในทุกแท็บ (ดูค้นหา)

  • หน้าแรกรวมอยู่เสมอและอยู่ลำดับแรกเสมอ
  • วิทยุปรากฏเมื่อเครื่องรับที่เลือกมีจูนเนอร์เท่านั้น ดูวิทยุ
  • คุณเก็บแท็บไว้ได้ระหว่าง 2 ถึง 7 แท็บ
ทีละขั้นตอน

เพิ่ม นำออก หรือจัดลำดับแท็บใหม่

  1. เปิดการตั้งค่า › ปรับแต่งการนำทาง ตัวอย่างของแถบแสดงอยู่ที่ด้านบน
  2. ใต้Available Tabs ติ๊กแท็บเพื่อเพิ่ม หรือเลิกติ๊กเพื่อนำออก
  3. ใต้Active Tabs ลากแถวที่ตัวจับเพื่อเปลี่ยนลำดับ
  4. แตะบันทึก ข้อความNavigation updatedยืนยันการบันทึก รีเซ็ตจะกลับไปใช้ชุดและลำดับเริ่มต้น
ทีละขั้นตอน

ซ่อนแท็บย่อยที่คุณไม่ใช้

แท็บเสียง ลำโพง และรีโมทแต่ละแท็บมีแถวแท็บย่อยตามแนวด้านบน เช่น Audyssey, Dirac Live, Graphic EQ, Channels และ Tone บนเสียง

  1. เปิดการตั้งค่า › ปรับแต่งแท็บ (Hide sub-views you don't use)
  2. ใต้เสียง ลำโพง หรือรีโมท ปิดแต่ละมุมมองย่อยที่คุณไม่ต้องการ ตัวอย่างจะแสดงผลลัพธ์
  3. ย้อนกลับ การเปลี่ยนแปลงนี้ใช้กับทุกเครื่องรับ
หากเครื่องรับของคุณไม่รองรับฟีเจอร์ใด เช่น Audyssey บนเครื่องรับที่ไม่มี Audyssey แท็บย่อยของฟีเจอร์นั้นถูกซ่อนไว้แล้วและไม่แสดงที่นี่ ปรับแต่งแท็บเป็นชั้นที่สองซ้อนทับบนนั้น

ปัดระหว่างหน้า

  • ปัดซ้ายหรือขวาบนหน้าเพื่อไปยังแท็บย่อยถัดไปหรือก่อนหน้า
  • ปัดต่อที่แท็บย่อยสุดท้ายแล้วคุณจะไปยังแท็บด้านล่างถัดไป เมื่อเลยแท็บสุดท้ายจะวนกลับไปแท็บแรก ตามลำดับที่คุณตั้งไว้
  • ปัดตามแถบแท็บด้านล่างเพื่อสลับแท็บโดยตรง แถบนี้วนกลับเช่นกัน
  • บนหน้าที่มีแถบเลื่อน การลากช้า ๆ จะเลื่อนแถบเลื่อน การเปลี่ยนหน้าต้องปัดเร็ว ๆ ในแนวนอนเป็นหลัก

ปัดย้อนกลับหนึ่งขั้นบน iPhone, iPad และ Mac

ในตัวสร้างฉากแบบมีคำแนะนำ คู่มือต้อนรับและตั้งค่า และหน้าลงชื่อเข้าใช้ Home Assistant ให้ปัดเข้าจากขอบซ้ายของหน้าจอเพื่อย้อนกลับหนึ่งขั้น ในภาษาที่เขียนจากขวาไปซ้าย ให้ปัดเข้าจากขอบขวา ปัดให้เกินครึ่งหน้าจอ หรือปัดเร็ว ๆ

แตะและกดค้าง

ตัวควบคุมหลายอย่างทำอย่างหนึ่งเมื่อแตะ และทำอีกอย่างเมื่อกดค้าง

  • ค่าตั้งล่วงหน้าระดับเสียง มีสล็อต 8 ช่อง แตะสล็อตว่างที่มีเครื่องหมาย + เพื่อบันทึกระดับเสียงปัจจุบัน แตะสล็อตที่บันทึกไว้เพื่อข้ามไปยังระดับเสียงนั้น กดค้างที่สล็อตใดก็ได้เพื่อบันทึกระดับเสียงปัจจุบันทับหรือล้างค่า หากต้องการให้เสียงค่อย ๆ ปรับไปยังค่าตั้งล่วงหน้าแทนการข้ามทันที ให้เปิดค่าตั้งล่วงหน้าระดับเสียงแบบค่อยเป็นค่อยไปในการตั้งค่า › จัดการเครื่องรับ › เครื่องรับของคุณ › เสียง ดูระดับเสียง
  • Quick Select และ Smart Select แตะสล็อตเพื่อเรียกกลับมา กดค้างเพื่อบันทึกสถานะปัจจุบันหรือเปลี่ยนชื่อ
  • ตารางอินพุตหน้าแรก กดค้างเพื่อเริ่มแก้ไขตาราง ดูหน้าจอหลัก
  • อินพุตรีโมท กดอินพุตค้างเพื่อกำหนดไอคอนเอง ดูไอคอนกำหนดเอง
  • ชื่อโซน กดชื่อโซนค้างเพื่อเปลี่ยนชื่อ ดูหลายโซน
  • ค่าตั้งล่วงหน้าวิทยุ แตะเพื่อเรียกกลับมา กดค้างเพื่อบันทึกสถานีปัจจุบัน ดูวิทยุ
  • ฉาก แตะเพื่อใช้ กดค้างเพื่อดูตัวเลือก ดูฉาก
  • เครื่องรับ ในการตั้งค่า › จัดการเครื่องรับ กดเครื่องรับค้างเพื่อดูตัวเลือกของเครื่อง
  • การ์ดคำอธิบาย แตะแบนเนอร์เพื่อขยาย กดค้างเพื่อปิด นำกลับมาได้จากการตั้งค่า › กู้คืนการ์ดที่ปิดไว้

ย้อนกลับ ออกจากแอป และข้อความ

  • ย้อนกลับบนหน้าย่อยจะพากลับไปที่ด้านบนของแท็บ บนหน้าแรกขณะแก้ไข ย้อนกลับจะออกจากโหมดแก้ไขก่อน
  • ย้อนกลับที่ด้านบนของแท็บจะถามว่าExit AVR Maestro? แตะExit Appเพื่อปิดแอป หรือCancelเพื่ออยู่ต่อ ใช้กับปุ่มย้อนกลับและท่าทางย้อนกลับของ Android
  • ข้อความที่ด้านล่างของหน้าจอมีปุ่มปิด ข้อความแสดงข้อผิดพลาดจะอยู่จนกว่าคุณจะปิด ข้อความอื่นปิดเองหลังไม่กี่วินาที นานกว่านั้นสำหรับข้อความที่ยาวกว่า ข้อความใหม่จะมาแทนที่ข้อความที่อยู่บนหน้าจอ
เมื่อเปิดการตั้งค่าการนำทางแบบเข้าถึงได้ของโทรศัพท์ ทุกข้อความจะอยู่จนกว่าคุณจะปิด

แป้นพิมพ์ลัดบน Windows และ Mac

ใช้ Ctrl บน Windows หรือ Cmd บน Mac ร่วมกับ:

  • ลูกศรขึ้น / ลง: เพิ่มหรือลดระดับเสียง
  • M: เปิดหรือปิดเสียง
  • Space: เล่นหรือหยุดชั่วคราว
  • ลูกศรขวา / ซ้าย: แทร็กถัดไปหรือก่อนหน้า
  • จุด (.): หยุด

ปุ่มมีเดียบนแป้นพิมพ์ (เล่น หยุดชั่วคราว ถัดไป ก่อนหน้า หยุด ระดับเสียง และปิดเสียง) ก็ใช้ได้เช่นกัน

แป้นพิมพ์ลัดจะไม่ทำงานขณะที่คุณพิมพ์ในช่องข้อความ ปิดเสียงและเล่นหรือหยุดชั่วคราวจะรอจนกว่าเครื่องรับรายงานสถานะปัจจุบัน

หมายเหตุตามแพลตฟอร์ม

  • Android: ย้อนกลับจะถามก่อนออก ปุ่มปรับเสียงของโทรศัพท์เปลี่ยนระดับเสียงของเครื่องรับได้ขณะเปิดแอป (ปุ่มปรับเสียงของอุปกรณ์ ตั้งต่อเครื่องรับ เปิดโดยค่าเริ่มต้น)
  • iPhone และ iPad: ปัดเข้าจากขอบเพื่อย้อนกลับหนึ่งขั้นในขั้นตอนที่มีคำแนะนำ ปุ่มปรับเสียงของอุปกรณ์ใช้ได้ที่นี่เช่นกัน
  • Mac: ปัดจากขอบเพื่อย้อนกลับ แป้นพิมพ์ลัด Cmd และปุ่มมีเดีย
  • Windows: แป้นพิมพ์ลัด Ctrl และปุ่มมีเดีย
คำถามที่พบบ่อย

การนำทาง พร้อมคำตอบ

ฉันเปลี่ยนแท็บที่อยู่ด้านล่างของ AVR Maestro ได้อย่างไร
เปิดการตั้งค่า › ปรับแต่งการนำทาง เลิกติ๊กแท็บใต้ Available Tabs เพื่อนำออก ติ๊กแท็บเพื่อเพิ่ม ลากแถวใต้ Active Tabs เพื่อเปลี่ยนลำดับ แล้วแตะบันทึก หน้าแรกรวมอยู่เสมอและอยู่ลำดับแรกเสมอ คุณมีแท็บได้ 2 ถึง 7 แท็บ
ฉันซ่อนแท็บย่อยที่ไม่เคยใช้ เช่น IMAX หรือ Auro-3D ได้อย่างไร
เปิดการตั้งค่า › ปรับแต่งแท็บ แล้วปิดมุมมองย่อยที่ไม่ต้องการใต้เสียง ลำโพง หรือรีโมท ตัวเลือกนี้ใช้กับทุกเครื่องรับ ฟีเจอร์ที่เครื่องรับของคุณไม่รองรับถูกซ่อนไว้แล้วและไม่แสดงในรายการนั้น
ทำไมจึงไม่มีแท็บวิทยุ
เพิ่มวิทยุได้ใน การตั้งค่า › ปรับแต่งการนำทาง แต่แท็บจะปรากฏเมื่อเครื่องรับที่เลือกมีจูนเนอร์เท่านั้น
ปัดระหว่างแท็บได้หรือไม่
ได้ ปัดซ้ายหรือขวาบนหน้าเพื่อเลื่อนผ่านแท็บย่อยของหน้านั้น ที่แท็บย่อยสุดท้าย การปัดครั้งถัดไปจะไปยังแท็บด้านล่างถัดไป และจากแท็บสุดท้ายจะวนกลับไปแท็บแรก คุณยังปัดตามแถบแท็บด้านล่างเองได้ด้วย
ทำไม AVR Maestro จึงถามก่อนปิด
บน Android การกดย้อนกลับที่ด้านบนของแท็บจะถามว่า Exit AVR Maestro? เพื่อไม่ให้การกดย้อนกลับพลาดปิดแอป แตะ Exit App เพื่อปิด หรือ Cancel เพื่ออยู่ต่อ จากหน้าย่อย ย้อนกลับจะพากลับไปที่ด้านบนของแท็บก่อน
AVR Maestro มีแป้นพิมพ์ลัดบน Windows และ Mac หรือไม่
มี Ctrl บน Windows หรือ Cmd บน Mac บวกปุ่มลูกศรขึ้นหรือลงเปลี่ยนระดับเสียง บวก M สลับปิดเสียง บวก Space เล่นหรือหยุดชั่วคราว บวกปุ่มลูกศรซ้ายหรือขวาข้ามไปข้างหลังหรือข้างหน้า และบวกปุ่มจุดเพื่อหยุด ปุ่มมีเดียบนแป้นพิมพ์ก็ใช้ได้เช่นกัน แป้นพิมพ์ลัดจะไม่ทำงานขณะที่คุณพิมพ์ในช่องข้อความ

อภิธานศัพท์ AVR Maestro

คำอธิบายสั้น ๆ ที่เข้าใจง่ายของคำศัพท์ที่ใช้ใน AVR Maestro และในคู่มือนี้ รายการใดที่เครื่องรับของคุณมีขึ้นอยู่กับรุ่น

แอป

  • ฉาก ชุดการตั้งค่าเครื่องรับที่บันทึกไว้ เช่น อินพุต โหมดเสียง และระดับเสียง ซึ่งใช้ได้ด้วยการแตะเดียว ดูฉาก
  • Quick Select / Smart Select สล็อตหน่วยความจำของเครื่องรับเองสำหรับอินพุต ระดับเสียง และโหมดเสียง Denon เรียกว่า Quick Select ส่วน Marantz เรียกว่า Smart Select ดูรีโมท
  • ค่าตั้งล่วงหน้าระดับเสียง หนึ่งใน 8 ระดับเสียงที่บันทึกไว้ในแอป แตะเพื่อข้ามไปยังระดับนั้น ดูระดับเสียง
  • โหมดทดลอง รันเครื่องรับ Marantz CINEMA 30 จำลองภายในแอป เพื่อให้คุณลองทุกหน้าจอได้โดยไม่ต้องมีเครื่องรับ ไม่มีสิ่งใดถูกส่งผ่านเครือข่ายของคุณ
  • ระบบบ้านอัตโนมัติ Pro ส่วนเสริมที่เชื่อมต่อเครื่องรับของคุณกับ Home Assistant, Hubitat และเว็บฮุก ดูระบบบ้านอัตโนมัติ
  • ผู้ช่วย สั่งเปลี่ยนค่าเครื่องรับด้วยภาษาธรรมดา ทำงานในอุปกรณ์ของคุณ และปรากฏเฉพาะบนอุปกรณ์ที่รองรับ ดูผู้ช่วย
  • เว็บฮุก ที่อยู่เว็บที่ระบบอื่นเรียกเพื่อให้แอปทำบางอย่าง หรือที่แอปเรียกเมื่อมีเหตุการณ์เกิดขึ้น
  • Home Assistant / HACS / Hubitat ระบบบ้านอัตโนมัติ HACS คือ Home Assistant Community Store ใช้ติดตั้งส่วนเสริม ดูแดชบอร์ด Home Assistant
  • ตัวควบคุมที่ถูกล็อก การตั้งค่าที่เครื่องรับไม่ยอมเปลี่ยนในขณะนี้ มักเป็นเพราะโหมดเสียงหรือสัญญาณ ดูตัวควบคุมที่ถูกล็อก

เครือข่ายและการเชื่อมต่อ

  • ที่อยู่ IP ที่อยู่ของเครื่องรับบนเครือข่ายภายในบ้านของคุณ เช่น 192.168.1.20 แอปใช้ที่อยู่นี้เพื่อเชื่อมต่อ
  • ที่อยู่ MAC รหัสฮาร์ดแวร์คงที่ของพอร์ตเครือข่ายของเครื่องรับ แสดงใน Device Information
  • HTTP และ Telnet สองวิธีที่แอปคุยกับเครื่องรับผ่านเครือข่ายของคุณ HTTP ส่งคำสั่ง ส่วน Telnet นำการอัปเดตสดกลับมา
  • HEOS ระบบสตรีมมิงและมัลติรูมที่มีมาในเครื่องรับ Denon และ Marantz รุ่นใหม่ ดูกำลังเล่น
  • Network Standby การตั้งค่าของเครื่องรับที่คงเครือข่ายไว้ขณะสแตนด์บาย เพื่อให้แอปเปิดเครื่องได้

การปรับเทียบเสียงและการแก้ไขเสียงห้อง

  • Audyssey MultEQ การแก้ไขเสียงห้องของ Denon และ Marantz วัดห้องของคุณด้วยไมโครโฟนแล้วแก้ไขเสียง MultEQ XT32 เป็นเวอร์ชันที่ละเอียดที่สุด
  • Dynamic EQ ฟีเจอร์ของ Audyssey ที่รักษาสมดุลของเบสและเสียงเซอร์ราวด์เมื่อฟังเบา ขณะที่เปิดอยู่ โทนเสียงจะถูกล็อก
  • Reference Level Offset บอก Dynamic EQ ว่าเนื้อหาถูกมิกซ์มาดังเพียงใด เพื่อปรับการแก้ไขเสียง
  • Dynamic Volume ฟีเจอร์ของ Audyssey ที่ปรับช่วงเสียงดังและเสียงเบาที่เปลี่ยนกะทันหันให้สม่ำเสมอ
  • LFC (Low Frequency Containment) ฟีเจอร์ของ Audyssey ที่ลดเบสที่ลอดไปยังห้องข้างเคียง Containment Amount กำหนดปริมาณที่ลด
  • Dirac Live การแก้ไขเสียงห้องจาก Dirac มีบนเครื่องรับบางรุ่น เมื่อใช้งานจะมาแทนที่ Audyssey ผลลัพธ์เก็บไว้ในสล็อต
  • ชุดตั้งค่าลำโพง Preset 1 หรือ Preset 2: การตั้งค่าลำโพงที่สมบูรณ์สองชุด แต่ละชุดมีผัง ระยะห่าง ระดับเสียง ครอสโอเวอร์ และการปรับเทียบเสียงของตัวเอง

โหมดเสียงและการประมวลผล

  • Dolby Atmos / DTS:X รูปแบบเซอร์ราวด์ที่มีช่องสัญญาณด้านความสูง
  • Dolby Surround ตัวอัปมิกซ์ของ Dolby ที่กระจายเสียงสเตอริโอหรือเซอร์ราวด์ไปยังลำโพงทั้งหมดของคุณ Center Spread ทำงานได้ในโหมดนี้เท่านั้น
  • Neural:X ตัวอัปมิกซ์ของ DTS ใช้ได้กับโหมดเสียง DTS:X
  • Auro-3D / Auro-Matic รูปแบบเสียงล้อมรอบและตัวอัปมิกซ์จาก Auro Technologies บนเครื่องรับที่รองรับ
  • IMAX Enhanced การตั้งค่าสำหรับเนื้อหา IMAX Enhanced บนเครื่องรับที่รองรับ
  • Pure Direct / Direct โหมดเสียงที่ข้ามการประมวลผลส่วนใหญ่เพื่อเส้นทางสัญญาณที่สะอาดที่สุด
  • DRC (Dynamic Range Compression) ลดช่องว่างระหว่างเสียงดังและเสียงเบา ใช้ได้กับสัญญาณ Dolby
  • Loudness Management รักษาระดับเสียงของเนื้อหา Dolby ให้สม่ำเสมอ
  • Dialog Enhancer ทำให้ได้ยินเสียงพูดชัดขึ้น
  • Cinema EQ ลดเสียงแหลมที่แสบหูในซาวด์แทร็กภาพยนตร์
  • M-DAX ฟีเจอร์ของ Marantz ที่คืนรายละเอียดให้เพลงที่ถูกบีบอัด Off, Low, Med หรือ High
  • Restorer ฟีเจอร์ของ Denon ที่คืนรายละเอียดให้เพลงที่ถูกบีบอัด
  • Speaker Virtualizer จำลองลำโพงที่คุณไม่มี
  • Room Size, Panorama, Dimension, Center Width การปรับวิธีกระจายสนามเสียง อยู่ใต้ เสียง › Shape
  • Tone Control การปรับเบสและเสียงแหลม ดูเสียง
  • Graphic EQ อีควอไลเซอร์รายแบนด์สำหรับแต่ละลำโพง ดูGraphic EQ

ลำโพงและเบส

  • Amp Assign วิธีใช้ช่องแอมป์ของเครื่องรับ เช่น สำหรับลำโพงไฮต์หรือโซนที่สอง
  • ครอสโอเวอร์ ความถี่ที่ต่ำกว่านั้น เบสของลำโพงจะถูกส่งไปยังซับวูฟเฟอร์แทน
  • HPF / LPF ฟิลเตอร์ไฮพาสและฟิลเตอร์โลว์พาส แบ่งเสียงระหว่างลำโพงและซับวูฟเฟอร์
  • การจัดการเบส วิธีที่เครื่องรับส่งเบสระหว่างลำโพงและซับวูฟเฟอร์
  • LFE Low Frequency Effects: ช่องเบสแยกต่างหากในซาวด์แทร็กภาพยนตร์ คือ .1 ใน 5.1
  • Subwoofer Mode LFE ส่งเฉพาะช่องเบสไปยังซับวูฟเฟอร์ LFE + Main ส่งเบสจากลำโพงหลักไปด้วย
  • ระดับเสียงช่องสัญญาณ ความดังของแต่ละลำโพงเทียบกับลำโพงอื่น
  • ระยะห่าง ลำโพงแต่ละตัวอยู่ห่างจากที่นั่งของคุณเท่าใด เครื่องรับใช้ค่านี้เพื่อจัดจังหวะเสียง
  • Center Level Adjust การเพิ่มหรือลดลำโพงกลางอย่างรวดเร็ว
  • Speaker Grid ภาพสดของลำโพงในแอปและลำโพงที่กำลังเล่นอยู่ ดูลำโพง

เครื่องรับและระบบ

  • Zone 2 / Zone 3 ห้องเพิ่มเติมที่เครื่องรับเล่นเสียงไปถึงได้ แต่ละห้องมีการเปิดปิดเครื่อง ระดับเสียง และอินพุตของตัวเอง ดูหลายโซน
  • All Zone Stereo เล่นแหล่งสัญญาณของโซนหลักในทุกโซน
  • HDMI CEC ให้ทีวีและเครื่องรับควบคุมกันและกันผ่าน HDMI
  • eARC Enhanced Audio Return Channel ส่งเสียงคุณภาพเต็มจากทีวีไปยังเครื่องรับผ่าน HDMI
  • ECO Mode การประหยัดพลังงานของเครื่องรับ
  • Auto Standby ปิดเครื่องรับหลังจากช่วงเวลาที่ไม่มีสัญญาณหรือไม่มีการใช้งาน
  • Sleep ตัวตั้งเวลาที่ปิดเครื่องรับ
  • Trigger Out เอาต์พุต 12V ที่เปิดปิดอุปกรณ์อื่น เช่น จอหรือแอมป์ พร้อมกับเครื่องรับ มีแท็บย่อยรีโมทของตัวเองบนเครื่องรับที่มีฟีเจอร์นี้
  • รูปแบบอินพุตดิจิทัล บังคับวิธีที่เครื่องรับอ่านอินพุตดิจิทัล: Auto, PCM หรือ DTS
  • Bluetooth Transmitter ส่งเสียงของเครื่องรับไปยังหูฟังหรือลำโพงบลูทูธ
  • Setup Lock / Remote Lock การล็อกของเครื่องรับที่ป้องกันการเปลี่ยนแปลงเมนูหรือรีโมทคอนโทรล ดูตัวควบคุมที่ถูกล็อก
  • การแสดงผลบนหน้าจอ ข้อมูลที่เครื่องรับแสดงบนทีวีของคุณ เช่น ระดับเสียง ดูการแสดงผลบนหน้าจอ
  • Signal Info รูปแบบเสียงและวิดีโอขาเข้าและขาออก เช่น พื้นที่สีและความลึกพิกเซล
คำถามที่พบบ่อย

คำศัพท์พร้อมคำตอบ

Quick Select กับ Smart Select เหมือนกันหรือไม่
เหมือนกัน Denon เรียกสล็อตหน่วยความจำของเครื่องรับว่า Quick Select ส่วน Marantz เรียกว่า Smart Select AVR Maestro ใช้ชื่อที่ตรงกับเครื่องรับของคุณ
LFE ต่างจากซับวูฟเฟอร์อย่างไร
LFE คือช่องเบสแยกต่างหากในซาวด์แทร็ก ส่วนซับวูฟเฟอร์คือลำโพงที่เล่นช่องนั้น รวมถึงเบสใด ๆ ที่เครื่องรับเปลี่ยนเส้นทางมาจากลำโพงอื่นของคุณ
ต้องมีทั้ง Audyssey และ Dirac Live หรือไม่
ไม่ต้อง ทั้งสองเป็นการแก้ไขเสียงห้องคนละแบบ บนเครื่องรับที่มี Dirac Live การปรับเทียบ Dirac Live ที่ใช้งานอยู่จะมาแทนที่ Audyssey

จัดการเครื่องรับ หนึ่งหน้าต่อเครื่อง

เพิ่มเครื่องรับ Denon และ Marantz ได้เท่าที่คุณมี สลับระหว่างเครื่องได้ในสองแตะ และตั้งค่าความชอบด้านเสียงของแต่ละเครื่องแยกกัน เครื่องรับทุกเครื่องมีหน้าของตัวเองสำหรับชื่อ ที่อยู่ การล็อก และเฟิร์มแวร์

อยู่ตรงไหน

เปิดจัดการเครื่องรับ

เปิดการตั้งค่า การ์ดบนสุดคือจัดการเครื่องรับ แสดงจำนวนเครื่องรับที่คุณมีและเครื่องที่ใช้งานอยู่ แตะการ์ดนั้น

สิ่งที่คุณจะเห็น: บรรทัด "Tap a receiver to set it up. Tap the circle to make it active. Drag to reorder." แล้วตามด้วยเครื่องรับของคุณ แต่ละเครื่องมีชื่อ ที่อยู่ IP และรุ่น เครื่องรับที่ใช้งานอยู่จะถูกไฮไลต์และวงกลมของเครื่องจะถูกเติมเต็ม ใต้รายการมีปุ่มเพิ่มเครื่องรับ และหากคุณยังไม่ได้อยู่ในนั้น จะมีส่วนDEMO MODE

  • แตะเครื่องรับเพื่อเปิดหน้าของเครื่องนั้น
  • แตะวงกลมที่ต้นแถวเพื่อให้เครื่องรับนั้นเป็นเครื่องที่ใช้งาน แอปจะแจ้งSwitched toและชื่อเครื่องรับ
  • ลากที่จับที่ท้ายแถวเพื่อเปลี่ยนลำดับ รายการเครื่องรับที่ด้านบนของหน้าแรกก็เรียงตามลำดับเดียวกัน
  • กดเครื่องรับค้างเพื่อเปิดเมนูด่วนที่มี Rename, Change IP, Find My Receiver และ Delete
ทีละขั้นตอน

เพิ่มเครื่องรับ

  1. เปิดการตั้งค่า › จัดการเครื่องรับแล้วแตะเพิ่มเครื่องรับ (หรือ+ที่มุมขวาบน)
  2. บน iPhone, iPad, Mac, Android และ Windows หน้าจอจะสแกนเครือข่ายของคุณและแสดงรายการReceivers found on your network แตะเครื่องของคุณ หากไม่มีเครื่องใดตอบสนอง แตะScan again หรือพิมพ์ที่อยู่ของเครื่องรับในIP Address แล้วแตะทดสอบและบันทึก
  3. แอปทดสอบการเชื่อมต่อและบันทึกเครื่องรับในขั้นตอนเดียว คุณจะเห็นรุ่นและฟีเจอร์ที่ตรวจพบ และเครื่องรับใหม่จะกลายเป็นเครื่องที่ใช้งาน
ที่อยู่ IP ของเครื่องรับอยู่ในเมนูของตัวเครื่องใต้Setup › General › Network › Information โทรศัพท์หรือคอมพิวเตอร์ต้องอยู่ในเครือข่ายเดียวกับเครื่องรับ ดูเริ่มต้นใช้งานสำหรับรายการตรวจสอบเครือข่าย
สองแตะ

สลับเครื่องรับจากหน้าแรก

  1. บนแท็บหน้าแรก แตะชื่อเครื่องรับที่แสดงข้างAVR Maestro ที่ด้านบนของหน้าจอ
  2. รายการเครื่องรับของคุณจะเปิดขึ้น พร้อมเครื่องหมายถูกข้างเครื่องที่ใช้งาน แตะเครื่องรับอื่นเพื่อสลับไปใช้ หรือแตะจัดการเครื่องรับที่ด้านล่างของรายการเพื่อเปิดหน้าเต็ม

เครื่องรับแต่ละเครื่องเก็บข้อมูลของตัวเองไว้บนอุปกรณ์ของคุณ การสลับจึงโหลดการตั้งค่าของเครื่องรับนั้นทันที

การตั้งค่า › จัดการเครื่องรับ › เครื่องรับของคุณ

หน้าเครื่องรับ

แตะเครื่องรับเพื่อเปิดหน้าของเครื่องนั้น การ์ดด้านบนแสดงสถานะการเชื่อมต่อและรายละเอียด หากไม่ใช่เครื่องรับที่ใช้งานอยู่ จะมีปุ่มMake activeอยู่ใต้การ์ด เพราะขีดจำกัดระดับเสียง การแสดงผล และการล็อกเปลี่ยนได้เฉพาะบนเครื่องรับที่ใช้งานอยู่ หากใช้งานอยู่แต่เข้าถึงไม่ได้ หน้าจะแสดง "The app is not connected to the receiver right now."

เสียง

ความชอบของคุณเองสำหรับเครื่องรับนี้ เครื่องรับแต่ละเครื่องเก็บค่าของตัวเอง คู่มือระดับเสียง →

  • Volume Step: การกดหนึ่งครั้งเลื่อนระดับเสียงไกลเท่าใด 0.5, 1, 1.5 หรือ 2 dB ปุ่มปรับเสียงทุกปุ่มในแอปใช้ค่านี้
  • Show absolute volume on top: สลับว่าตัวเลขใดเป็นตัวใหญ่ในการแสดงระดับเสียง ปิด (ค่าเริ่มต้น) แสดง dB ตัวใหญ่และสเกลระดับเสียงตัวเล็ก เปิดแสดงสเกลระดับเสียงตัวใหญ่และ dB ตัวเล็ก
  • การแสดงระดับเสียงในรีโมท: แท็บรีโมทแสดงสเกล dB (สัมบูรณ์ (dB) เช่น -40.5 dB) หรือสเกล 0-98 (Relative เช่น 39.5)
  • ค่าตั้งล่วงหน้าระดับเสียงแบบค่อยเป็นค่อยไป: เปิด (ค่าเริ่มต้น) การแตะค่าตั้งล่วงหน้าระดับเสียงจะปรับระดับเป็นขั้นเล็ก ๆ ปิด จะข้ามไปยังระดับที่บันทึกไว้ทันที
  • ปุ่มปรับเสียงของอุปกรณ์ (โทรศัพท์และแท็บเล็ต): ขณะเปิดแอป ปุ่มปรับเสียงของอุปกรณ์เองจะเปลี่ยนระดับเสียงของเครื่องรับ เปิดโดยค่าเริ่มต้น ปิดเพื่อคืนปุ่มให้อุปกรณ์
  • การควบคุมระดับเสียง: ขีดจำกัดระดับเสียง ระดับเมื่อเปิดเครื่อง และความลึกของการปิดเสียง เขียนลงเครื่องรับเอง แสดงขณะที่แอปเชื่อมต่อกับเครื่องรับนี้ คู่มือการควบคุมระดับเสียง →

หน้าจอและการล็อก

แสดงสำหรับเครื่องรับที่ใช้งานอยู่ขณะเชื่อมต่อ

  • การแสดงผลบนหน้าจอ: ตัวแสดงระดับเสียง แบนเนอร์ข้อมูล กำลังเล่น และ 21:9 คู่มือการแสดงผลบนหน้าจอ →
  • Setup Lock: ล็อกเมนูตั้งค่าของเครื่องรับเอง ขณะที่ล็อกอยู่ การตั้งค่า Audio, Video, Speaker และอื่น ๆ เปลี่ยนที่ไหนไม่ได้เลย ทั้งในเมนูของเครื่องรับ ในแอปนี้ และในเว็บพอร์ทัลของเครื่อง ตัวควบคุมประจำวัน เช่น ระดับเสียง อินพุต และไดเมอร์ ยังใช้งานได้ การเปิดจะถามก่อน (Lock the receiver menu? จากนั้นLock) ปิดสวิตช์เพื่อปลดล็อก
  • Remote Lock: ทำให้เครื่องรับไม่สนใจการกดปุ่มจากรีโมท IR จนกว่าคุณจะปลดล็อก แอปและแผงด้านหน้ายังใช้งานได้
Setup Lock และ Remote Lock ปรากฏเมื่อเครื่องรับรายงานสถานะของมันเท่านั้น หากเครื่องรับของคุณไม่รายงานการล็อก สวิตช์จะไม่แสดงแทนที่จะเดา ตัวควบคุมที่เป็นสีเทาที่อื่นในแอปเพราะ Setup Lock อธิบายไว้ในเหตุใดตัวควบคุมจึงถูกล็อก

เกี่ยวกับเครื่องรับนี้

  • Device Information: สถานะโดยละเอียดของเครื่องรับ
  • Firmware: เวอร์ชันเฟิร์มแวร์ที่ติดตั้ง แตะCheckเพื่อถามเครื่องรับว่ามีอัปเดตหรือไม่ บรรทัดด้านล่างจะบอกว่าคุณใช้เฟิร์มแวร์ล่าสุดแล้ว มีอัปเดตพร้อมใช้ อัปเดตกำลังดำเนินการ หรืออ่านสถานะไม่ได้ การอัปเดตติดตั้งจากเมนู Setup ของเครื่องรับเอง ไม่ใช่จากแอป ห้ามปิดเครื่องรับระหว่างอัปเดต

จัดการ

  • Rename: พิมพ์ชื่อใหม่ในDevice Nameแล้วแตะSave ชื่อนี้เก็บไว้ในแอปเท่านั้น
  • Change IP: พิมพ์IP Address or Hostnameใหม่แล้วแตะSave เช่น หลังจากเราเตอร์ให้ที่อยู่ใหม่ การตั้งค่าที่บันทึกไว้ทั้งหมดของเครื่องรับยังคงอยู่ มีเพียงที่อยู่ที่เปลี่ยน ที่อยู่ที่เครื่องรับอื่นของคุณใช้อยู่แล้วจะถูกปฏิเสธ
  • Find My Receiver: ค้นหาที่อยู่ใหม่ของเครื่องรับนี้ในเครือข่าย หากพบเครื่องรับของคุณที่อื่น แตะUse This Address แอปจะแจ้งเมื่อที่อยู่ที่บันทึกไว้ถูกต้องอยู่แล้ว เมื่อไม่มีเครื่องใดตอบ และเมื่ออาจเป็นเครื่องรับของคุณได้มากกว่าหนึ่งเครื่อง ซึ่งในกรณีนั้นแอปจะไม่เปลี่ยนอะไรและคุณใช้ Change IP แทน
  • Delete: ถามว่าDelete Receiver?แล้วนำเครื่องรับและการตั้งค่าที่บันทึกไว้ทั้งหมดออกจากแอป การลบเครื่องรับที่ใช้งานอยู่จะสลับแอปไปใช้เครื่องอื่น
ไม่ต้องมีเครื่องรับ

โหมดทดลอง เข้าและออก

โหมดทดลองรัน Marantz CINEMA 30 จำลองภายในแอป ทุกหน้าจอทำงานเหมือนกับมีฮาร์ดแวร์จริง และไม่มีอะไรถูกส่งผ่านเครือข่ายของคุณ

  1. เริ่มจากการตั้งค่า › จัดการเครื่องรับ › ลองโหมดทดลอง จากสำรวจโหมดทดลองบนหน้าจอเพิ่มเครื่องรับ หรือจากTry the demo insteadในคู่มือต้อนรับ เครื่องรับทดลองจะกลายเป็นเครื่องที่ใช้งานและแอปเปิดหน้าแรก
  2. ดูตัวอย่าง Pro ขณะที่โหมดทดลองทำงาน การตั้งค่าจะแสดงส่วนDEMO MODE สวิตช์Preview Pro featuresของส่วนนั้นปลดล็อกระบบบ้านอัตโนมัติและทริกเกอร์สำหรับเซสชันทดลองนี้เท่านั้น ไม่มีการซื้อเกิดขึ้น
  3. ออกด้วยการตั้งค่า › Leave Demo Mode เครื่องรับทดลองจะถูกนำออกและแอปกลับไปใช้เครื่องรับของคุณเอง
คำถามที่พบบ่อย

เครื่องรับ พร้อมคำตอบ

ฉันสลับไปใช้เครื่องรับอื่นได้อย่างไร
บนแท็บหน้าแรก แตะชื่อเครื่องรับข้าง AVR Maestro ที่ด้านบนแล้วเลือกเครื่องรับอื่นจากรายการ หรือเปิดการตั้งค่า › จัดการเครื่องรับ แล้วแตะวงกลมที่ต้นแถวของเครื่องรับ แอปจะยืนยันด้วย Switched to และชื่อเครื่องรับ
เครื่องรับของฉันได้ที่อยู่ IP ใหม่ ฉันต้องทำอย่างไร
โดยทั่วไปไม่ต้องทำอะไร: เมื่อเราเตอร์ย้ายที่อยู่ของเครื่องรับ แอปจะหาเครื่องเจออีกครั้งและแจ้งคุณเพียงครั้งเดียวว่าตามไปแล้ว หากทำไม่ได้ ให้เปิดการตั้งค่า › จัดการเครื่องรับ แตะเครื่องรับ แล้วใช้ Find My Receiver เพื่อค้นหาในเครือข่าย หรือ Change IP เพื่อพิมพ์ที่อยู่ใหม่เอง การตั้งค่าที่บันทึกไว้ทั้งหมดของเครื่องรับยังคงอยู่ มีเพียงที่อยู่ที่เปลี่ยน
ทำไมฉันจึงไม่เห็น Screen & Locks หรือ About this receiver
ส่วนเหล่านั้นอ่านและเขียนค่ากับเครื่องรับแบบสด จึงปรากฏเฉพาะสำหรับเครื่องรับที่ใช้งานอยู่ขณะที่แอปเชื่อมต่ออยู่ ตั้งให้เครื่องรับเป็นเครื่องที่ใช้งานด้วย Make active แล้วรอให้เชื่อมต่อ
Setup Lock กับ Remote Lock ต่างกันอย่างไร
Setup Lock ล็อกเมนูตั้งค่าของเครื่องรับเอง จึงไม่มีใครเปลี่ยนการตั้งค่าและการปรับเทียบเสียงได้ รวมถึงแอปนี้ จนกว่าคุณจะปลดล็อก ระดับเสียงและอินพุตยังใช้งานได้ Remote Lock ทำให้เครื่องรับไม่สนใจรีโมทคอนโทรลแบบ IR ส่วนแอปและแผงด้านหน้ายังใช้งานได้ สวิตช์แต่ละตัวปรากฏเมื่อเครื่องรับรายงานการล็อกนั้นเท่านั้น
จะเกิดอะไรขึ้นเมื่อฉันลบเครื่องรับ
แอปจะนำเครื่องรับและการตั้งค่าที่บันทึกไว้ทั้งหมดของเครื่องนั้นออก หากเป็นเครื่องรับที่ใช้งานอยู่ แอปจะสลับไปใช้เครื่องอื่น ไม่มีอะไรเปลี่ยนบนเครื่องรับเอง และคุณเพิ่มกลับได้ทุกเมื่อ
ลองใช้แอปโดยไม่มีเครื่องรับได้หรือไม่
ได้ แตะ Try Demo Mode ในการตั้งค่า › จัดการเครื่องรับ หรือ Explore Demo Mode บนหน้าจอเพิ่มเครื่องรับ โหมดทดลองรัน Marantz CINEMA 30 จำลองภายในแอปและไม่ส่งอะไรผ่านเครือข่ายของคุณ ออกได้จากการตั้งค่า › Leave Demo Mode

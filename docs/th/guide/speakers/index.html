ตั้งค่าลำโพง & พรีเซ็ต

เวิร์กช็อปลำโพงโดยเฉพาะ

พรีเซ็ตลำโพง เลย์เอาต์ ระยะ ระดับ ครอสโอเวอร์ ซับวูฟเฟอร์ และการจัดการเบส: ชุดตั้งค่าครบ อ่านสดจากเครื่องรับ Denon หรือ Marantz ของคุณ โดยแต่ละหน้าตาม Speaker Preset ที่ใช้งานอยู่

ทุกหน้าจอตั้งค่า บนโทรศัพท์ของคุณ

เปิดแท็บลำโพงที่ด้านล่างของหน้าจอ หน้าต่าง ๆ เรียงอยู่ด้านบนตามลำดับนี้ แตะชื่อหรือปัดซ้ายขวาเพื่อเลื่อนระหว่างหน้า

  • Preset: สลับระหว่าง Speaker Preset 1 และ 2 แต่ละอันเก็บเลย์เอาต์ ระยะ ระดับ ครอสโอเวอร์ และการคาลิเบรตของตัวเอง และทุกหน้าอื่นของ Speakers ตามอันที่ใช้งานอยู่ รุ่นที่มีการกำหนดค่าลำโพงเพียงแบบเดียวจะแสดงSpeaker Preset unavailableแทนสวิตช์
  • Speaker Layout: Amp Assign และการกำหนดค่าต่อลำโพง บนตัวเครื่องที่มีให้ Front Speaker กำหนดว่าเครื่องรับขับขั้วต่อหน้าชุดใด (A, B หรือ A+B) เมื่อเครื่องรับทำเป็นสีเทา แอปจะบอกว่าถูกล็อกแทนที่จะแสร้งว่าการเปลี่ยนจะมีผล
  • ระยะห่าง: ระยะห่างของแต่ละลำโพงจากที่นั่งของคุณ ในหน่วยของเครื่องรับ (m หรือ ft)
  • Levels: ระดับ trim ต่อลำโพงที่เก็บไว้ในพรีเซ็ต
  • Crossovers: ความถี่ที่ต่ำกว่านั้นเบสจะถูกส่งไปยังซับวูฟเฟอร์ แสดงเฉพาะลำโพง "small" ที่นี่ 0 Hz หมายถึง Full Range บนเครื่องรับที่รายงาน คุณเลือกAll (ค่าที่ใช้ร่วมกันค่าเดียว) หรือIndividualได้
  • Subwoofer: Subwoofer Output, LFE หรือ LFE + Main เก็บต่อ Speaker Preset หน้านี้ปรากฏเฉพาะเมื่อเครื่องรับของคุณตั้งค่าซับวูฟเฟอร์ไว้
  • Bass: LPF for LFE (จุดตัด low-pass ของช่อง LFE) และ LFE Distribution (ส่งช่อง LFE .1 ไปยังลำโพงฟูลเรนจ์ เสนอเฉพาะเมื่อเครื่องรับอนุญาต)
การเปลี่ยนAmp Assignจะถามก่อน: เพราะจะกำหนดค่าลำโพงทุกตัวใหม่และรีเซ็ตเลย์เอาต์เป็นค่าเริ่มต้นของโหมดใหม่ การตั้งค่าเช่น Height และ Surround Back จะหายไป เมื่อ Audyssey คาลิเบรตแล้ว พรอมต์เดียวกันเตือนว่าการเปลี่ยนนี้ปิด Audyssey ด้วย (MultEQ XT32, Dynamic EQ, Dynamic Volume) และหน้าเตือนว่าการเปลี่ยนการตั้งค่าเลย์เอาต์ลำโพงใด ๆ จะลบฟิลเตอร์ Dirac Live
เครื่องรับรุ่นเก่า

ตระกูล SR7015 และเครื่องรับอื่นที่ใช้เมนูตั้งค่ารุ่นก่อน

เครื่องรับรุ่นเก่าบางรุ่น (เช่น ตระกูล Marantz SR7015) ใช้เมนูตั้งค่าเวอร์ชันก่อนหน้า AVR Maestro จดจำได้จากเมนูของเครื่องรับเอง และปรับหน้าให้เหมาะ:

  • Speaker Layout แสดงAmp Assign (Floor, Height / Dolby speakers, Height layout) และทุกแถวของSpeaker Config และเปลี่ยนได้ทั้งหมดจากแอป
  • Bass แก้ไขได้: จุดตัด low-pass ของ LFE และโหมดซับวูฟเฟอร์ (LFE หรือ LFE + Main) บล็อก LFE Distribution ถูกซ่อน เพราะเครื่องรับเหล่านี้ไม่มี
  • Subwoofer ขึ้นว่าOn this firmware, Subwoofer Output is set on the Bass tab. ให้ใช้หน้า Bass แทน
  • Crossovers สลับระหว่าง All และ Individual ได้ และแก้ไขได้เฉพาะแถวที่เครื่องรับอนุญาต
หากเครื่องรับตอบช้า หน้า Layout มีRetry หากเมนูตั้งค่าของเครื่องถูกล็อก จะแสดงการ์ดล็อก เฉพาะเครื่องรับที่ปฏิเสธการอ่านทั้งสองแบบเท่านั้นที่จะได้รับข้อความNot available on this firmware พร้อมปุ่มOpen in Web Controlที่เปิดหน้าเว็บของเครื่องรับเองสำหรับการแก้ไขนั้น คุณซ่อนหน้าที่ใช้ไม่ได้ได้ในการตั้งค่า › Customize Tabs
มุมมองสด

ดูว่ากำลังเล่นอะไรอยู่จริงๆ ทีละช่องสัญญาณ

Speaker Grid แสดงสิ่งที่สัญญาณขาเข้ามีทางซ้าย และสิ่งที่เครื่องรับของคุณกำลังขับอยู่จริงทางขวา แทร็กสเตอริโอแสดงช่องขาเข้าสองช่องข้างทุกเอาต์พุตที่อัพมิกซ์กำลังป้อน คุณจึงเห็นอัพมิกซ์ทำงาน

  • เครื่องรับตั้งชื่อลำโพงของตัวเอง ทุกป้ายมาจากเครื่องรับ ตัวเครื่องที่มีลำโพงซึ่งแอปไม่เคยรู้จักก็ยังวาดในตำแหน่งที่ถูกต้อง
  • สามสถานะ ไม่ใช่สอง: กำลังเล่น เชื่อมต่อแต่เงียบ และไม่มี ลำโพงที่เครื่องรับบอกว่าไม่อยู่ในสัญญาณนี้จะไม่ถูกวาดเลย
  • หาได้ที่ไหน: เพิ่มการ์ดSpeaker Gridไปที่แท็บหน้าแรก หรือดูที่หน้าหลักของแท็บรีโมท
เครื่องรับรุ่นเก่า (ตระกูล X4500H และ SR7015) ตอบคำขอ grid ด้วยค่าว่าง grid จึงถูกซ่อนไว้ที่นั่น และไม่เสนอการ์ด Speaker Grid
ฉลาดเรื่อง Dirac

ไม่ปล่อยให้คุณส่งการแก้ไขที่เครื่องรับจะปฏิเสธ

หน้าข้างต้นแก้ไขได้เต็มที่บน Speaker Preset มาตรฐาน แต่เมื่อฟิลเตอร์ Dirac Live ทำงานอยู่บนพรีเซ็ต Dirac เป็นเจ้าของเลย์เอาต์ ระยะ ครอสโอเวอร์ เอาต์พุตซับวูฟเฟอร์ และการจัดการเบส แทนที่จะให้คุณทำการเปลี่ยนแปลงที่เครื่องรับจะเพิกเฉยเงียบ ๆ AVR Maestro แสดงการล็อกที่ชัดเจนและบอกเหตุผล สลับไปพรีเซ็ตที่ไม่ใช่ Dirac เพื่อแก้ไข

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับการตั้งค่าลำโพง

ตั้งค่าระยะห่างและระดับเสียงจากแอปได้ไหม
ได้ Amp assign และเลย์เอาต์ ระยะต่อลำโพง ระดับช่อง ครอสโอเวอร์ และการตั้งค่าซับวูฟเฟอร์ ทั้งหมดอ่านสดและตาม Speaker Preset ที่ใช้งานอยู่
ทำไมบางหน้าจอลำโพงถึงถูกล็อก
เมื่อฟิลเตอร์ Dirac Live ทำงานอยู่บนพรีเซ็ต Dirac จะเป็นเจ้าของผังลำโพง ระยะห่าง และครอสโอเวอร์ แอปจะแสดงเครื่องหมายล็อกแทนที่จะให้คุณส่งการแก้ไขที่เครื่องรับจะปฏิเสธ สลับไปใช้พรีเซ็ตที่ไม่ใช่ Dirac เพื่อแก้ไข ดูเพิ่มเติมในคู่มือ Audyssey & Dirac
ชุดตั้งค่าลำโพงคืออะไร
Preset 1 และ 2 แต่ละอันเก็บเลย์เอาต์ ระยะ ระดับ ครอสโอเวอร์ และการคาลิเบรตของตัวเอง สลับระหว่างสองอันบนหน้า Preset ทุกหน้าของ Speakers ตามพรีเซ็ตที่ใช้งานอยู่ รุ่นที่มีการกำหนดค่าลำโพงเพียงแบบเดียวจะแสดง Speaker Preset unavailable แทน
SR7015 ของฉันบอกว่า Subwoofer Output ตั้งไว้ที่แท็บ Bass ถูกต้องไหม
ถูกต้อง บนเฟิร์มแวร์นั้น โหมดซับวูฟเฟอร์ (LFE หรือ LFE + Main) อยู่คู่กับจุดตัด low-pass ของ LFE แอปจึงพาคุณไปที่หน้า Bass ซึ่งเปลี่ยนได้ทั้งสองอย่าง หน้า Speaker Layout บนเครื่องรับเหล่านี้ก็แก้ไขได้เต็มที่เช่นกัน รวมถึง Amp Assign
ส่งช่องสัญญาณ LFE ไปยังลำโพงหน้าโดยไม่มีซับวูฟเฟอร์ได้ไหม
ได้ บนเครื่องรับที่รองรับ เมื่อลำโพงหลักของคุณตั้งเป็น Full Range ใน Crossovers และเครื่องรับไม่ได้ส่ง LFE ไปยังซับวูฟเฟอร์ LFE Distribution ของหน้า Bass จะส่งช่อง LFE (.1) ไปยังลำโพงเหล่านั้นพร้อมระดับต่อลำโพง AVR Maestro เสนอตัวเลือกนี้เฉพาะเมื่อเครื่องรับอนุญาต: หากลำโพงไม่ใช่ Full Range หรือซับวูฟเฟอร์ถูกตั้งให้รับ LFE เครื่องรับจะล็อกการตั้งค่านี้และแอปแสดงเหตุผล ตัวควบคุม LPF for LFE บนหน้าเดียวกันกำหนดจุดตัด low-pass ของช่อง LFE

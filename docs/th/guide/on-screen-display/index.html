การแสดงผลบนหน้าจอ ควบคุมจากที่นั่งของคุณ

ตัวเลขระดับเสียงที่แวบขึ้นกลางเรื่อง แบนเนอร์เมื่อเปลี่ยนแหล่งสัญญาณ หน้าจอกำลังเล่นที่ค้างอยู่ตอนฟังเพลง ทั้งหมดนี้อยู่ในเมนูตั้งค่าของเครื่องรับ ซึ่งหมายความว่าต้องลุกขึ้นไปเปิดเมนูบนหน้าจอที่คุณกำลังดูอยู่ AVR Maestro ย้ายทั้งหมดมาไว้บนโทรศัพท์ของคุณแทน

สิ่งที่คุณเปลี่ยนได้

  • ระดับเสียง: ล่าง, บน หรือ ปิด เลือกตำแหน่งที่ตัวเลขระดับเสียงปรากฏเมื่อคุณปรับ หรือจะไม่แสดงเลยก็ได้ ตัวเลือกปิดคือสิ่งที่หลายคนมองหาระหว่างดูหนัง
  • ข้อมูล: แบนเนอร์สถานะที่เครื่องรับแสดงเมื่อเปลี่ยนแหล่งสัญญาณหรือโหมดเสียง
  • กำลังเล่น: กำหนดว่าหน้าจอกำลังเล่นจะค้างอยู่ขณะเล่นแหล่งสัญญาณเครือข่าย หรือหายไปเองหลังผ่านไปครู่หนึ่ง
  • โหมด 21:9: ปรับตำแหน่งเมนูของเครื่องรับให้เหมาะกับหน้าจอ 21:9 แบบความสูงคงที่ เพื่อไม่ให้โปรเจกเตอร์ตัดเมนูออกไป
  • สกรีนเซฟเวอร์: เลื่อนภาพบนหน้าจอหลังจากไม่มีการเคลื่อนไหวระยะหนึ่ง ช่วยปกป้องแผงจอที่เสี่ยงภาพติดค้าง
เฉพาะสิ่งที่เครื่องรับของคุณมี

ตัวเครื่องของคุณเป็นผู้กำหนดว่าคุณจะเห็นอะไรบ้าง

ไม่ใช่ทุกเครื่องรับที่มีครบทั้งห้าอย่าง แทนที่จะแสดงปุ่มควบคุมที่ใช้งานไม่ได้ AVR Maestro จะสอบถามตัวเครื่องว่าเปิดให้ใช้ตัวเลือกการแสดงผลบนหน้าจอใดบ้าง แล้วแสดงเฉพาะตัวเลือกเหล่านั้น เครื่องรับรุ่นเก่าที่ไม่มีสกรีนเซฟเวอร์จึงไม่เห็นการ์ดนั้น

หากมีการตั้งค่านั้นอยู่แต่เครื่องรับไม่ตอบในครั้งนี้ แอปจะบอกตรง ๆ และเสนอให้ลองอีกครั้ง แอปจะไม่ทำให้ “อ่านค่าไม่ได้” กลายเป็น “เครื่องรับของคุณไม่มีฟีเจอร์นี้” เพราะสองอย่างนี้เป็นคนละคำตอบ และมีเพียงอย่างเดียวที่เป็นความจริง

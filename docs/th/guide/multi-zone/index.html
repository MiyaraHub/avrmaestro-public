หลายโซน: คุมได้ทั้งบ้าน

เปิด-ปิดเครื่อง เลือกอินพุต และปรับระดับเสียงของโซน 2 และโซน 3 แยกอิสระบนเครื่องรับ Denon และ Marantz แบบหลายโซน - และฉากก็บันทึกและกู้คืนสถานะของโซนได้ด้วย เพลงในครัว หนังในห้องโฮมเธียเตอร์ ทั้งหมดจากแอปเดียว

เปิด-ปิดเครื่องแยกอิสระ

เปิดหรือปิดโซน 2 หรือโซน 3 ได้โดยไม่กระทบโซนหลัก

🎵

แหล่งสัญญาณ & ระดับเสียงของตัวเอง

อินพุตและระดับเสียงต่างกันในแต่ละโซน พร้อมชิปพรีเซ็ตระดับเสียงด่วน - พรีเซ็ตจะค่อยๆ ปรับระดับเสียงโดยค่าเริ่มต้น (การตั้งค่า เสียง: ค่อยเป็นค่อยไป / Direct)

⚡

Zone Smart Select / Quick Select

ช่อง Smart Select หรือ Quick Select ของโซนนั้นเอง อยู่บนการ์ดเลย - แตะช่องเพื่อเรียกใช้ กดค้างเพื่อบันทึกสถานะปัจจุบันของโซนลงในช่องนั้น

✍️

เปลี่ยนชื่อโซนใดก็ได้

กดชื่อโซนค้างบนหน้าแรก - รวมถึงโซนหลัก ชื่อจะถูกบันทึกลงในเครื่องรับเอง ทุกแอปจึงเห็นตรงกัน

🔄

ซิงค์สด

เปลี่ยนโซนจากแผงหน้าปัดหรือรีโมทของเครื่องรับ แล้วแอปจะอัปเดตภายในหนึ่งวินาที

🎧

กำลังเล่นของแต่ละโซน

เมื่อโซนเปิดอยู่ การ์ดจะแสดงสตรีม HEOS แบบสดของโซนนั้นพร้อมปุ่มควบคุมการเล่น

🎭

ฉากบันทึกให้ได้

ฉาก สามารถบันทึกและกู้คืนสถานะของโซน 2/3 ไปพร้อมกับทุกอย่างอื่น

📱

บนหน้าแรก

วิดเจ็ตโซนขนาดกะทัดรัดแสดงสถานะเพียงแวบเดียวและปุ่มควบคุมด่วนบนหน้าแรก

เปิดโซน และกำหนดว่าจะให้เล่นอะไร

  • 1. เปิดแท็บโซน ทุกโซนที่เครื่องรับของคุณประกาศไว้จะมีการ์ดของตัวเอง เครื่องรับที่มีโซนเดียวจะไม่มีแท็บนี้
  • 2. เปิดโซน ด้วยปุ่มเปิด-ปิดเครื่องบนการ์ดของโซนนั้น โซนหลักไม่เปลี่ยนแปลงใดๆ
  • 3. เลือกแหล่งสัญญาณ รายการเป็นของเครื่องรับของคุณเอง ตามชื่อที่คุณเปลี่ยนไว้ และโซนหนึ่งใช้อินพุตที่ต่างจากห้องหลักโดยสิ้นเชิงได้
  • 4. ตั้งระดับเสียง โซนมีระดับเสียงและปุ่มปิดเสียงของตัวเอง และชิประดับเสียงด่วนจะเรียกระดับที่คุณตั้งไว้ในโซนนั้น พรีเซ็ตจะค่อยๆ ปรับระดับเสียงเว้นแต่คุณจะเปลี่ยนเป็น Direct ในการตั้งค่า เสียง
  • 5. ทางเลือก: บันทึกไว้ กดช่อง Smart Select หรือ Quick Select ของโซนค้างไว้เพื่อเก็บทุกอย่างที่โซนกำลังทำอยู่ตอนนี้ แล้วแตะภายหลังเพื่อเรียกกลับมา

เปลี่ยนชื่อโซนโดยกดชื่อค้างบนหน้าแรก ชื่อจะถูกเขียนลงในเครื่องรับ ทั้งแผงหน้าปัดและแอปอื่นทุกตัวจึงตรงกับแอป

ควรรู้ไว้

ทำไมการเปิดหรือปิดโซนหลักจึงไม่ปิดห้องอื่นของคุณ

เครื่องรับ Denon และ Marantz มีคำสั่งเปิด-ปิดเครื่องสองแบบที่ต่างกัน และความแตกต่างนี้สำคัญเมื่อมีเพลงเล่นอยู่ที่อื่นในบ้าน

คำสั่งสแตนด์บายทั้งระบบจะปิดตัวเครื่องทั้งหมด และเครื่องรับจะปิดโซนอื่นไปด้วย - จากการวัดบน Cinema 30 ตัวเครื่องรายงานว่าโซน 2 ปิดหลังคำสั่งสแตนด์บายถึงเพียงหนึ่งมิลลิวินาที ปุ่มเปิด-ปิดหลักใน AVR Maestro จึงส่งคำสั่งโซนหลักแทนโดยเจตนา ปิดโฮมเธียเตอร์จากแอป แล้วห้องครัวก็ยังเล่นเพลงต่อ

ทำงานกลับกันได้ด้วย: การเปิดโซนหลักจากเครื่องรับที่ปิดสนิทจะปลุกตัวเครื่องก่อน คุณจึงไม่ต้องเปิดเครื่องรับแยกต่างหากก่อนใช้แอป

หากโซนใดปิดตัวเองเมื่อโซนหลักเปลี่ยน นั่นเป็นเพราะการตั้งค่าของเครื่องรับเอง ไม่ใช่แอป บางรุ่นมีตัวเลือกการเชื่อมโยงการเปิด-ปิดเครื่องในเมนูโซน
คำถามที่พบบ่อย

คำถามที่พบบ่อยเรื่องหลายโซน

ฉันควบคุมโซน 2 และโซน 3 จากโทรศัพท์ได้ไหม
ได้ - บนเครื่องรับแบบหลายโซน แต่ละโซนมีการเปิด-ปิดเครื่อง ระดับเสียง ปิดเสียง อินพุต และพรีเซ็ตระดับเสียงด่วนของตัวเอง แยกจากโซนหลักโดยสมบูรณ์ และซิงค์แบบสด
ฉันใช้ Smart Select หรือ Quick Select ในแต่ละโซนได้ไหม
ได้ - การ์ดของแต่ละโซนมีช่องของโซนนั้นเอง ตั้งชื่อตามที่เครื่องรับของคุณเรียก: Smart Select บน Marantz และ Quick Select บน Denon แตะช่องเพื่อเรียกใช้ กดค้างเพื่อบันทึกสถานะปัจจุบันของโซนลงในช่องนั้นได้จากการ์ดเลย
ฉันเปลี่ยนชื่อโซนได้ไหม
ได้ - กดชื่อโซนค้างบนหน้าแรกเพื่อเปลี่ยนชื่อโซนใดก็ได้ รวมถึงโซนหลัก ชื่อจะถูกเขียนลงในเครื่องรับเอง จึงแสดงในแอปของผู้ผลิตและแอปอื่นทุกตัว รวมถึงตัวเครื่องรุ่นเก่าด้วย
แต่ละโซนแสดงสิ่งที่กำลังเล่นไหม
แสดง - เมื่อโซนเปิดอยู่ การ์ดจะแสดงสตรีมกำลังเล่นของ HEOS แบบสดสำหรับโซนนั้น พร้อมปุ่มควบคุมการเล่น
ฉากตั้งค่าโซนให้ได้ไหม
ได้ - ฉาก สามารถบันทึกและกู้คืนการเปิด-ปิดเครื่อง อินพุต และระดับเสียงของโซน 2/3 ไปพร้อมกับการตั้งค่าส่วนอื่นของคุณ

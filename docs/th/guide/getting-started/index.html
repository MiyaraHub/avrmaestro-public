เริ่มต้นใช้งาน

ควบคุม Denon หรือ Marantz ของคุณจากโทรศัพท์

AVR Maestro สื่อสารกับเครื่องรับของคุณผ่านเครือข่ายภายในด้วยโปรโตคอลดั้งเดิมของเครื่อง ไม่ต้องมีบัญชีคลาวด์ ไม่ต้องมีฮาร์ดแวร์เพิ่ม คู่มือต้อนรับสั้น ๆ จะพาคุณเชื่อมต่อและสร้างฉากแรกได้ภายในไม่กี่นาที

การเปิดใช้งานครั้งแรก

ขั้นตอนต้อนรับห้าขั้นตอนที่ช่วยตั้งค่าให้คุณ

เมื่อเปิด AVR Maestro เป็นครั้งแรก คู่มือสั้น ๆ จะพาคุณจากศูนย์ไปจนถึงฉากแรกของคุณ แถบด้านบนแสดงว่าคุณมาถึงขั้นไหนแล้ว กลับ พาคุณย้อนไปขั้นตอนก่อนหน้าได้ทุกขั้น และ ข้าม มีให้เสมอหากคุณอยากสำรวจเอง

  1. ยินดีต้อนรับ AVR Maestro คือการควบคุม Denon หรือ Marantz ของคุณอย่างเต็มรูปแบบผ่านเครือข่ายของคุณเอง โดยไม่ผ่านคลาวด์เลย และบอกอย่างชัดเจนเช่นกันว่าแอปไม่ใช่อะไร คือเป็นแอปอิสระ ไม่ใช่เครื่องมือสอบเทียบ และไม่ใช่แอปสตรีมมิง คุณจึงรู้ว่าควรคาดหวังอะไรก่อนเริ่มต้น
  1. เครื่องรับของคุณ แอปสแกนเครือข่ายและแสดงรายการเครื่องรับทุกเครื่องที่พบ แตะเครื่องของคุณเพื่อเพิ่ม และเพิ่มได้มากกว่าหนึ่งเครื่องหากคุณมีหลายเครื่อง ไม่พบรายการใดเลยใช่ไหม ใช้เพิ่มด้วยที่อยู่ IP หรือแตะลองใช้เดโมแทนเพื่อสำรวจด้วยเครื่องรับเดโมที่มีฉากพร้อมให้ลอง
  1. แต่ละอย่างอยู่ตรงไหน แผนที่ย่อของแอป: หน้าแรก สำหรับเปิดปิดเครื่อง ระดับเสียง และอินพุตในทุกโซน เสียง สำหรับโหมดเสียง Audyssey และ Dirac และ ฉาก สำหรับชุดการตั้งค่าที่บันทึกไว้
  1. ฉาก สิ่งที่ฉากทำได้ในแตะเดียว และเหตุที่ไปได้ไกลกว่าช่องหน่วยความจำ Smart Select หรือ Quick Select ของเครื่องรับเอง: มีได้สูงสุด 20 ฉาก วิดเจ็ตและทางลัดบนหน้าจอหลัก และการตรวจสอบภายหลังว่าเครื่องรับรับทุกการตั้งค่าไปจริง แตะสร้างฉากแรกของฉัน แล้วตัวสร้างฉากจะเปิดขึ้นทันที
  1. คุณพร้อมแล้ว ช่องทางขอความช่วยเหลือ ได้แก่ ชุมชน Discord และกลุ่มสนับสนุนบน Facebook และวิธีแชร์บันทึกของคุณจากการตั้งค่า → เกี่ยวกับ → บันทึกที่เกี่ยวข้องทั้งหมดหากมีสิ่งใดผิดปกติ
อยากดูแนะนำอีกครั้ง หรือตั้งค่าแอปกับเครื่องรับเครื่องใหม่ใช่ไหม เปิดการตั้งค่า → ยินดีต้อนรับ & คู่มือการตั้งค่าได้ทุกเมื่อ ดูการตั้งค่า
ก่อนเริ่มต้น

สิ่งที่คุณต้องมี

  • iPhone, iPad, Mac, โทรศัพท์หรือแท็บเล็ต Android หรือพีซี Windows ที่อยู่ในเครือข่ายเดียวกันกับเครื่องรับ
  • เครื่องรับที่เปิดอยู่และเปิดใช้งาน Network Standby (Setup → General → Network → Network Control → On) เพื่อให้แอปปลุกและเชื่อมต่อกับเครื่องได้
  • ไม่ต้องมีอย่างอื่น แอปจะค้นหาเครื่องรับในเครือข่ายเอง หากเครือข่ายของคุณไม่ให้อุปกรณ์มองเห็นกันและกัน ให้ใช้ที่อยู่ IP ของเครื่องรับ (Setup → General → Network → Information) แทน
  • ไม่บังคับ: เปิดใช้งาน Wake-on-LAN เพื่อเปิดเครื่องรับจากสถานะสแตนด์บายเต็มรูปแบบ
การเพิ่มเครื่องรับภายหลัง

มีเครื่องรับมากกว่าหนึ่งเครื่องใช่ไหม

  1. เปิดการตั้งค่า → อุปกรณ์ แล้วแตะเพิ่มเครื่องรับ
  2. หน้าจอจะสแกนเครือข่ายและแสดงรายการเครื่องรับ Denon หรือ Marantz ทุกเครื่องที่ตรวจพบ แตะเครื่องของคุณ (หรือพิมพ์ที่อยู่ IP หากไม่พบอะไรเลย) แล้วแอปจะตรวจสอบ HTTP, Telnet และ HEOS
  3. ยืนยันรุ่นและความสามารถที่ตรวจพบเพื่อบันทึกเครื่องรับ
  4. สลับระหว่างเครื่องรับได้ทุกเมื่อจากการตั้งค่า → อุปกรณ์ แอปจำตัวเครื่องรับ ไม่ใช่ที่อยู่ของเครื่อง เมื่อเราเตอร์ย้ายที่อยู่ของเครื่อง แอปจะตามไปและแจ้งคุณเพียงครั้งเดียว
การแก้ไขปัญหา

หากเชื่อมต่อไม่ได้

ปัญหาการเชื่อมต่อส่วนใหญ่มาจากเครือข่าย: โทรศัพท์และเครื่องรับอยู่คนละซับเน็ต มีเครือข่ายแขกหรือ IoT VLAN คั่นกลาง หรือปิด Network Control ไว้บนเครื่องรับ หน้าความช่วยเหลือและการแก้ไขปัญหา จะพาคุณแก้กรณี Test Connection ไม่ผ่าน การเชื่อมต่อที่หลุดบ่อย และวิธีตรวจสอบว่าเครื่องรับของคุณรองรับหรือไม่

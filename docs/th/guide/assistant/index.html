ถามผู้ช่วย - คำตอบมาจากเครื่องรับของคุณ

ผู้ช่วยส่วนใหญ่รู้เรื่องเครื่องรับโดยทั่วไปมาก แต่ตัวนี้รู้เรื่องเครื่องรับของคุณ ทั้งระดับเสียงตอนนี้ ชุดตั้งค่าลำโพงที่กำลังใช้ Dynamic EQ เปิดอยู่หรือไม่ และกำลังถอดรหัสอะไรอยู่ในวินาทีนี้ ผู้ช่วยอ่านค่าจากเครื่องรับของคุณเองและตอบจากข้อมูลนั้น โดยใช้โมเดลที่ทำงานบนอุปกรณ์ของคุณ ไม่ใช่บริการที่อยู่ที่อื่น

อยู่ตรงไหน

แท็บผู้ช่วย

พิมพ์คำถาม หรือกดค้างที่ไมโครโฟนแล้วพูด ไม่ต้องลงชื่อเข้าใช้ ไม่ต้องวางคีย์ และไม่ต้องมีบัญชี หากอุปกรณ์ของคุณรันโมเดลบนอุปกรณ์ได้ ผู้ช่วยก็ใช้งานได้ทันทีที่เปิด

ถามด้วยคำพูดของคุณเองได้เลย เช่น “เสียงดังแค่ไหน” “ตอนนี้ดูผ่านอะไรอยู่” “โหลดสล็อต Dirac ไหนอยู่” “Dynamic EQ เปิดอยู่ไหม” ผู้ช่วยจะจับความหมายที่คุณต้องการเทียบกับสิ่งที่เครื่องรับรายงานจริง คุณจึงไม่ต้องรู้ว่าการตั้งค่านั้นเรียกว่าอะไร

ผู้ช่วยบอกอะไรคุณได้บ้าง

ทุกอย่างที่แอปอ่านได้จากเครื่องรับของคุณ ซึ่งก็คือทุกอย่างบนหน้าจอในคู่มือนี้ ไม่ใช่รายการตายตัว เครื่องรับที่รายงานว่ามี IMAX จะถูกถามเรื่อง IMAX ส่วนเครื่องที่ไม่มีจะไม่ถูกเสนอตัวเลือกนี้เลย

ถามเกี่ยวกับและผู้ช่วยรู้
การเปิดเครื่องและระดับเสียงเปิดเครื่องหรือสแตนด์บาย ระดับเสียงเป็น dB ปิดเสียง โหมด ECO และขีดจำกัดระดับเสียงของเครื่องรับเอง
แหล่งสัญญาณและเสียงอินพุตที่เลือกอยู่ตามชื่อที่คุณตั้งไว้ โหมดเสียง และรูปแบบที่กำลังถอดรหัส
การปรับเทียบAudyssey MultEQ, Dynamic EQ, Dynamic Volume, ค่าชดเชยระดับอ้างอิง, LFC และสล็อต Dirac Live ที่โหลดอยู่
ลำโพงผังลำโพง ค่าปรับของแต่ละช่องสัญญาณ ระดับซับวูฟเฟอร์ และจำนวนซับที่กำหนดค่าไว้
วิดีโอความละเอียดและ HDR ขาเข้าและขาออก โหมดภาพ การประมวลผลวิดีโอ โหมดอินพุต เอาต์พุตเสียง HDMI และ auto lip sync
โซนการเปิดเครื่อง อินพุต ระดับเสียง ค่าปรับช่องสัญญาณ ตัวจับเวลาปิดเครื่อง และสล็อต Smart Select / Quick Select ของแต่ละโซน
ตัวเครื่องความสว่างหน้าจอแผงด้านหน้า สแตนด์บายอัตโนมัติ ตัวส่งสัญญาณบลูทูธ และทริกเกอร์แต่ละตัวตามหมายเลข
กำลังเล่นอะไรอยู่เพลงจากแหล่งสัญญาณเครือข่ายและสถานะการเล่น
ใต้แต่ละคำตอบ ผู้ช่วยจะแสดงค่าที่อ่านมาเพื่อสร้างคำตอบนั้น บรรทัดนั้นถูกบันทึกไว้ ไม่ได้เขียนโดยโมเดล จึงแต่งขึ้นเองไม่ได้ และเป็นวิธีที่เร็วที่สุดในการแยกคำตอบจริงออกจากคำตอบผิดที่ฟังดูมั่นใจ

สิ่งที่ผู้ช่วยทำให้คุณได้

สั่งให้เปลี่ยนอะไร ผู้ช่วยก็เปลี่ยนให้ สิ่งที่ต่างกันคือแต่ละการกระทำต้องผ่านขั้นตอนมากน้อยเพียงใด และความไม่สมมาตรนี้ตั้งใจให้เป็นเช่นนั้น

สั่งให้จะเกิดอะไรขึ้น
เปิดหรือปิดเครื่อง ปิดเสียง เปิดเสียงทำทันที แล้วบอกคุณว่าส่งอะไรไป
ลดระดับเสียงทำทันที ตอนที่ใครสักคนอยากให้เสียงเบาลงคือตอนที่เขาไม่อยากเจอกล่องข้อความที่สุด
เพิ่มระดับเสียงถามก่อน เป็นการกระทำเดียวที่กรณีเลวร้ายที่สุด คือลำโพงเสียหาย ซึ่งคนที่ยืนอยู่ในห้องย้อนกลับไม่ได้
เปลี่ยนอินพุตจับคู่กับรายการแหล่งสัญญาณของคุณเองตามชื่อที่คุณตั้งใหม่ หากตรงได้สองรายการ ผู้ช่วยจะถามว่าหมายถึงรายการไหน

ปริมาณเป็นสิ่งที่คุณเป็นผู้กำหนด “ลดลง 5 dB” จะลดลง 5 dB ส่วน “ลดเสียงลง” โดยไม่ระบุตัวเลขจะลดหนึ่งขั้น เท่ากับกดปุ่มหนึ่งครั้ง ผู้ช่วยจะไม่ตัดสินใจเลือกตัวเลขที่คุณไม่ได้พูด

ยังไม่รองรับการเปลี่ยนโหมดเสียงจากที่นี่ เครื่องรับของคุณจัดโหมดเสียงเป็นหมวดหมู่และเลือกภายในหมวดที่ใช้งานอยู่ จึงไม่ใช่ชื่อเดียวที่ส่งไปได้ ใช้แท็บเสียงเพื่อทำให้ถูกต้อง

ขอความเห็น

“มีคำแนะนำเรื่องการปรับเทียบไหม” “ทำอย่างไรให้เสียงพูดชัดขึ้น” “ควรเปิด Dynamic EQ ไหม” คำถามเหล่านี้ต่างจากการค้นหาข้อมูล และผู้ช่วยก็จัดการต่างกัน ผู้ช่วยจะวิเคราะห์จากค่าที่อ่านได้ของคุณ แล้วเสนอทางเลือกที่เป็นรูปธรรมสองสามข้อ แต่ละข้อระบุการตั้งค่าที่เครื่องรับของคุณมีจริง พร้อมบอกว่าจะลองข้อไหนก่อน

สิ่งที่ไม่เปลี่ยนคือที่มาของตัวเลข ผู้ช่วยให้เหตุผลได้อย่างอิสระ แต่จะไม่พูดตัวเลขที่ไม่ได้รับมา หากค่าที่อ่านได้ไม่พอสำหรับการแนะนำ ผู้ช่วยจะบอกว่าต้องดูอะไรเพิ่มแทนที่จะเดา

พูดแทนการพิมพ์

กดค้างที่ปุ่มไมโครโฟนแล้วพูด ข้อความที่คุณพูดจะปรากฏในช่องให้เห็นก่อนส่ง

ควรรู้: โมเดลภาษาทำงานบนอุปกรณ์ของคุณ และเครื่องรับอยู่ในเครือข่ายของคุณเอง คำถามที่พิมพ์และคำตอบจึงอยู่บนฮาร์ดแวร์ของคุณ การแปลงเสียงพูดเป็นข้อความทำโดยตัวรู้จำเสียงของโทรศัพท์ และในโทรศัพท์ส่วนใหญ่จะส่งเสียงไปยังผู้ให้บริการแพลตฟอร์มเพื่อถอดเป็นข้อความ นั่นเป็นการทำงานของระบบปฏิบัติการ ไม่ใช่ของแอป และการพิมพ์เลี่ยงเรื่องนี้ได้ทั้งหมด
ข้อกำหนดของอุปกรณ์

อุปกรณ์ใดรองรับบ้าง

ผู้ช่วยรันโมเดลภาษาบนอุปกรณ์ของคุณเอง ไม่ต้องมีบัญชี ไม่ต้องใช้เซิร์ฟเวอร์ ไม่ต้องลงชื่อเข้าใช้ ซึ่งหมายความว่าอุปกรณ์ต้องมีโมเดลอยู่ในเครื่อง แอปติดตั้งสิ่งนี้ให้ไม่ได้ และเป็นข้อกำหนดข้อเดียวที่เราหลีกเลี่ยงไม่ได้

แพลตฟอร์มสิ่งที่ต้องมี
iPhone, iPad, MaciOS 26 หรือ macOS 26 บนอุปกรณ์ที่มี Apple Intelligence และเปิดใช้งานอยู่ หากปิดอยู่ แอปจะบอกและพาคุณไปที่การตั้งค่าแทนการซ่อนฟีเจอร์
AndroidGemini Nano ผ่าน Google AICore แอปเข้าถึงได้ด้วย ML Kit Prompt API ของ Google และ API นั้นมีรายการอุปกรณ์ที่รองรับของตัวเอง ดูด้านล่าง
Windows, Linuxไม่มีโมเดลบนอุปกรณ์ให้รัน จึงไม่แสดงผู้ช่วย ส่วนอื่นของแอปไม่ได้รับผลกระทบ

Android: อุปกรณ์ที่ Google รองรับ

นี่คือรายการของ Google ไม่ใช่ของเรา เรานำมาแสดงไว้ที่นี่เพราะเป็นสิ่งเดียวที่กำหนดว่าผู้ช่วยจะปรากฏบนโทรศัพท์ Android หรือไม่ และ Google เผยแพร่ไว้ในที่ที่คนส่วนใหญ่ไม่เคยดู

รายชื่ออุปกรณ์ที่รองรับ ML Kit GenAI Prompt API ตามที่ Google เผยแพร่ ณ วันที่ 20 สิงหาคม 2026 Google เพิ่มอุปกรณ์เข้ามาเรื่อย ๆ และหน้านี้เป็นเพียงสำเนา หากอุปกรณ์ของคุณใหม่กว่ารายการนี้ โปรดตรวจสอบรายการของ Google

หากโทรศัพท์ของคุณไม่อยู่ในรายการนั้น แต่คุณมั่นใจว่าน่าจะรองรับ: Google เผยแพร่รายการมากกว่าหนึ่งรายการ ตัวอย่างเช่น Galaxy S25 และ S25 Ultra ใช้งาน Gemini Nano ได้ไม่มีปัญหา และอยู่ในรายการของ Google สำหรับฟีเจอร์อื่นที่ทำงานบนอุปกรณ์ เช่น การสรุปความ การตรวจทาน และการเรียบเรียงข้อความใหม่ แต่ผู้ช่วยต้องใช้ Prompt API ซึ่งทำให้ถามคำถามอิสระเกี่ยวกับเครื่องรับของคุณได้ แทนที่จะเพียงปรับแต่งข้อความที่มีอยู่แล้ว และ API ตัวนี้รองรับอุปกรณ์น้อยกว่า S25 ยังไม่อยู่ในรายการนี้ ส่วน S26 อยู่ในรายการแล้ว ขณะนี้มีคำขอที่ยื่นไว้กับ Google เพื่อเพิ่มซีรีส์ S25 หากได้รับการอนุมัติ ผู้ช่วยจะปรากฏบนเครื่องเหล่านั้นโดยไม่ต้องรอการอัปเดตจากเรา

อุปกรณ์ที่เราทดลองใช้เองแล้ว

แยกจากรายการของ Google และสั้นกว่า เพราะมีเฉพาะอุปกรณ์ที่เราได้ใช้งานจริงเท่านั้น

อุปกรณ์ผลลัพธ์
Pixel 10 Pro XLทดสอบกับ Marantz Cinema 30 โดยอ้างอิงค่าที่อ่านได้จากตัวเครื่องรับเอง

หากอุปกรณ์ของคุณอยู่ในรายการของ Google ด้านบน ผู้ช่วยจะปรากฏและใช้งานได้ ตารางที่สองนี้ครอบคลุมเฉพาะอุปกรณ์ที่เราได้ลองกับมือจริงเท่านั้น เราขอระบุชื่ออุปกรณ์เพียงรุ่นเดียวอย่างซื่อสัตย์ ดีกว่าทำให้ดูเหมือนว่าเรามีห้องแล็บ

การแก้ไขปัญหา

เมื่อผู้ช่วยบอกว่าช่วยไม่ได้

ข้อความแต่ละแบบแตกต่างกันโดยตั้งใจ เพราะแต่ละแบบมีวิธีแก้ไขที่ต่างกัน

  • “อุปกรณ์นี้ไม่สามารถเรียกใช้โมเดลบนอุปกรณ์ได้” ผู้ช่วยต้องใช้ Apple Intelligence บน iPhone, iPad หรือ Mac หรือ Gemini Nano ผ่าน Google AICore บน Android อุปกรณ์ที่มีความสามารถสูงหลายรุ่นยังไม่รองรับ รวมถึงแท็บเล็ตรุ่นปัจจุบันบางรุ่นและสมาร์ตโฟนเรือธงบางรุ่นที่ใช้ Gemini Nano กับฟีเจอร์อื่นได้ ดูอุปกรณ์ที่เรียกใช้ได้ด้านบน เรื่องนี้ไม่สามารถแก้ไขจากในแอปได้
  • ต้องดาวน์โหลดโมเดลก่อน Android จะดาวน์โหลดให้เบื้องหลังในครั้งแรก ทำเพียงครั้งเดียว ไฟล์มีขนาดใหญ่ และต้องใช้ Wi-Fi
  • “เครื่องรับของคุณมีฟีเจอร์นั้น แต่ตอนนี้ไม่มีข้อมูลให้รายงาน” ฟีเจอร์นี้มีอยู่จริงเพียงแต่ไม่ได้ทำงานอยู่ เช่น ถามว่ากำลังเล่นอะไรอยู่ทั้งที่ไม่มีอะไรเล่นอยู่ ก็จะได้คำตอบนี้ ไม่ได้หมายความว่าเครื่องรับของคุณไม่มี HEOS
  • “เครื่องรับนี้ไม่รายงานข้อมูลนั้น” นี่คือคำตอบที่ตรงกับความเป็นจริงของฮาร์ดแวร์ของคุณ ตัวเครื่องไม่มีฟีเจอร์นั้น และแอปไม่ได้แสร้งว่ามี
  • อ่านค่าระบบย่อยไม่ได้ หมายถึงไม่ทราบ ไม่ใช่ไม่มี ผู้ช่วยจะแจ้งตามนั้น แทนที่จะถือว่าการอ่านค่าล้มเหลวคือคุณไม่มีฟีเจอร์นั้น
  • “ตอนนี้ฉันยังเปลี่ยนค่านั้นจากตรงนี้ไม่ได้” เป็นข้อจำกัดของผู้ช่วย ไม่ใช่ของเครื่องรับ ส่วนหน้าจอการตั้งค่านั้นทำได้

ผู้ช่วยส่งข้อมูลของฉันไปที่ไหนหรือไม่
โมเดลภาษาทำงานบนอุปกรณ์ของคุณ และเครื่องรับอยู่ในเครือข่ายของคุณเอง คำถามที่พิมพ์และคำตอบจึงไม่ออกจากอุปกรณ์ของคุณ การป้อนด้วยเสียงเป็นข้อยกเว้น เพราะการแปลงเสียงพูดเป็นข้อความทำโดยตัวรู้จำเสียงของโทรศัพท์คุณเอง และในโทรศัพท์ส่วนใหญ่หมายความว่าเสียงจะถูกส่งไปยังผู้ให้บริการแพลตฟอร์มเพื่อถอดเป็นข้อความ การพิมพ์ช่วยเลี่ยงเรื่องนี้ได้ทั้งหมด
ทำไมผู้ช่วยบอกว่าอุปกรณ์ของฉันใช้ไม่ได้
ผู้ช่วยต้องใช้โมเดลบนอุปกรณ์ ได้แก่ Apple Intelligence บน iPhone, iPad และ Mac หรือ Gemini Nano ผ่าน Google AICore บน Android อุปกรณ์ที่สเปกดีหลายรุ่นก็ยังไม่มีโมเดลนี้ แอปจะรายงานสถานะที่เป็นอยู่อย่างตรงไปตรงมาแทนที่จะซ่อนฟีเจอร์ไว้ คุณจึงรู้ว่าปัญหาอยู่ที่การดาวน์โหลด การตั้งค่า หรือฮาร์ดแวร์
ผู้ช่วยจะเปลี่ยนการตั้งค่าโดยไม่ถามก่อนหรือไม่
ผู้ช่วยจะทำทันทีกับการเปิดปิดเครื่อง ปิดเสียง เปลี่ยนอินพุต และลดระดับเสียง เพราะทั้งหมดนี้คนที่อยู่ในห้องย้อนกลับได้ง่ายมาก ส่วนการเพิ่มระดับเสียงจะถามก่อนเสมอ เพราะเป็นการกระทำเดียวที่กรณีเลวร้ายที่สุดคือลำโพงเสียหาย
ทำไมบางครั้งผู้ช่วยถึงบอกว่าตอบไม่ได้
เพราะผู้ช่วยจะไม่เดา ตัวเลขทุกตัวที่ให้มาล้วนมาจากค่าที่อ่านได้จากเครื่องรับของคุณ หากไม่ได้รับค่านั้น ผู้ช่วยจะบอกว่าอ่านค่าระบบย่อยนั้นไม่ได้ แทนที่จะแต่งตัวเลขที่ฟังดูเป็นไปได้ขึ้นมา คำตอบที่ผิดแต่ฟังดูถูกแย่กว่าไม่มีคำตอบ

การ์ดสถานะอุปกรณ์ปักหมุดอยู่ด้านบนเสมอ แสดงรุ่น การเชื่อมต่อ และสถานะเปิดปิดเครื่อง โดยมีตารางวิดเจ็ตที่ปรับแต่งได้อยู่ด้านล่าง เพิ่ม ลบ และจัดลำดับการ์ดเพื่อให้หน้าจอหลักแสดงสิ่งที่คุณสนใจจริง ๆ

ทำให้เป็นสไตล์คุณ

ปรับแต่งได้ในไม่กี่วินาที

แตะไอคอน Customize Home (ซ้ายบน) เพื่อเข้าสู่โหมดแก้ไข:

  • ลากการ์ดเพื่อจัดลำดับ
  • แตะวงกลมสีแดงเพื่อลบการ์ด
  • Add เปิดชีตวิดเจ็ตที่คุณยังไม่มี
  • Reset คืนค่าเริ่มต้น ส่วน Done ใช้ออกจากโหมดแก้ไข
การ์ดจะหรี่ลงขณะแก้ไข เพื่อไม่ให้คุณเปลี่ยนการตั้งค่าของเครื่องรับโดยไม่ตั้งใจ วิดเจ็ตจะแสดงเมื่อเครื่องรับของคุณเปิดให้ใช้ฟีเจอร์นั้นเท่านั้น หน้าจอหลักใหม่เริ่มต้นด้วย Smart Select / Quick Select, ระดับเสียง, แหล่งสัญญาณ, โหมดเสียง, ฉาก, ข้อมูลสัญญาณ, กำลังเล่น และโซน ดูรายละเอียดของทุกการ์ดในคู่มือวิดเจ็ต
เครื่องรับมากกว่าหนึ่งเครื่อง

สลับเครื่องรับจากชื่อเรื่อง

เมื่อเชื่อมต่อเครื่องรับแล้ว ชื่อเครื่องรับจะอยู่ข้าง AVR Maestro ที่ด้านบนของหน้าจอหลัก แตะเพื่อดูเครื่องรับทุกเครื่องที่คุณเพิ่มไว้ เลือกเครื่องใดเครื่องหนึ่งให้เป็นเครื่องที่ใช้งาน หรือเลือกจัดการเครื่องรับเพื่อเพิ่มและจัดลำดับใหม่ (การตั้งค่า › จัดการเครื่องรับ) ช่องค้นหาใต้การ์ดสถานะจะหาการตั้งค่าใดก็ได้ในแอป ดูคู่มือการค้นหา คู่มือเครื่องรับ และการใช้งานรอบแอป

ค่าตั้งล่วงหน้าระดับเสียง

แปดระดับเสียง แตะครั้งเดียวถึง

  • แตะสล็อตว่างเพื่อบันทึกระดับเสียงปัจจุบันลงไป
  • แตะสล็อตที่มีค่าอยู่เพื่อข้ามไปยังระดับเสียงนั้น
  • กดค้างที่สล็อตใดก็ได้เพื่อบันทึกระดับเสียงปัจจุบันทับ หรือล้างค่า

กดค้างที่ชื่อโซนบนหน้าจอหลักเพื่อเปลี่ยนชื่อโซนใดก็ได้ รวมถึงโซนหลัก ชื่อจะถูกเขียนลงในเครื่องรับเอง ไม่ใช่แค่ในแอป จึงแสดงในแอปของผู้ผลิตและไคลเอนต์อื่นทุกตัว และใช้ได้กับเครื่องรุ่นเก่าด้วย เปลี่ยนชื่อครั้งเดียว ตัวควบคุมทุกตัวในบ้านก็เรียกห้องนั้นตรงกัน

วิดเจ็ตทำอะไรได้
ระดับเสียงแถบเลื่อนพร้อมตัวเลข dB ปิดเสียง และค่าตั้งล่วงหน้าระดับเสียงที่บันทึกไว้ 8 ค่า (ดูด้านล่าง)
แหล่งสัญญาณเปิดตัวเลือกอินพุต กดค้างที่ไทล์เพื่อจัดลำดับใหม่ ชื่อแหล่งสัญญาณที่เปลี่ยนไว้และไอคอนอินพุตแบบกำหนดเองที่คุณตั้งในตารางอินพุตของรีโมทจะแสดงที่นี่ด้วย
โหมดเสียงโหมดเซอร์ราวด์ปัจจุบัน แตะเพื่อเปิดตัวเลือกแบบจัดกลุ่ม
ข้อมูลสัญญาณAUDIO IN / AUDIO OUT และ VIDEO IN / VIDEO OUT (ความละเอียดและ HDR) อัตราสุ่มตัวอย่าง และรายละเอียดอื่นทั้งหมดที่เครื่องรับรายงานเกี่ยวกับสัญญาณ HDMI เช่น พื้นที่สีและความลึกพิกเซล ค่าที่เครื่องรับไม่รายงานจะถูกละไว้แทนที่จะแสดงเป็นค่าว่าง
กำลังเล่นภาพปก ข้อมูลแทร็ก และปุ่มควบคุมการเล่นสำหรับแหล่งสัญญาณ HEOS พร้อมปุ่มรายการโปรดและเปิด HEOS ดูเพิ่มเติมในคู่มือกำลังเล่นและ HEOS
โซนสถานะ Zone 2 / Zone 3 แบบกะทัดรัดพร้อมตัวควบคุมด่วน รวมถึงสล็อต Smart Select หรือ Quick Select ของโซนนั้นเอง แตะสล็อตเพื่อเรียกกลับมา กดค้างเพื่อบันทึกสถานะปัจจุบันของโซนลงไป มีเฉพาะบนเครื่องรับหลายโซน
Smart Select / Quick Selectช่องหน่วยความจำของเครื่องรับเอง ตั้งชื่อตามที่เครื่องรับเรียก: Smart Select บน Marantz, Quick Select บน Denon ชื่อช่องที่เปลี่ยนไว้จะถูกบันทึกในเครื่องรับ ชื่อของคุณจึงแสดงในทุกแอป
ECO ModeAuto, On หรือ Off ในการแตะเดียว
ตัวตั้งเวลาปิดเครื่องOff, 30, 60, 90 หรือ 120 นาที
พรีเซ็ตลำโพงตัวสลับ Preset 1 / 2 แสดงเมื่อเครื่องรับของคุณรายงานชุดตั้งค่าลำโพง
ฟื้นฟูสัญญาณเสียงตัวฟื้นฟูเสียงที่ถูกบีบอัด: Off, Low, Med หรือ High แสดงเฉพาะเมื่อเครื่องรับตอบสนองฟีเจอร์นี้
ฉากเรียกฉากที่บันทึกไว้กลับมาในการแตะเดียว สร้างฉากได้ที่หน้าฉาก
การจัดวางลำโพงผังช่องสัญญาณขาเข้าและขาออก เช่น 5.1.2
Speaker Gridตารางสดของลำโพงที่กำลังเล่นอยู่ อินพุตอยู่ข้างเอาต์พุต มีเฉพาะบนเครื่องรับที่ให้ข้อมูลนี้ ดูคู่มือลำโพง
การประมวลผลวิดีโอโหมดวิดีโอ: Auto, Movie, Game หรือ Bypass
DRCDynamic Range Compression: Auto, Off, Low, Mid หรือ High

สถานะ AudysseyMultEQ, Dynamic EQ, Reference Level Offset, Dynamic Volume, LFC และ Containment Amount ในมุมมองเดียว มีเฉพาะบนเครื่องรับ Audyssey
สรุประดับช่องสัญญาณรายการระดับของทุกช่องสัญญาณที่เครื่องรับรายงาน

ดีเลย์เสียงดีเลย์ลิปซิงก์ตั้งแต่ 0 ถึง 500 ms เมื่อเครื่องรับรายงานค่านี้

ตัวควบคุมเสียง

สวิตช์ด่วนในหน้าเสียง

  • Graphic EQ: สวิตช์เปิด/ปิดอยู่ในหน้า Graphic EQ เอง (เสียง › Graphic EQ) ในแถวส่วนหัวข้างปุ่ม Reset และ Copy แก้ไขแบนด์ได้เมื่อไม่มีทั้ง Dirac Live และ Audyssey ทำการแก้ไขเสียงห้องอยู่เท่านั้น แอปทำตามกฎของเครื่องรับเอง ดูคู่มือ Graphic EQ
  • ซับวูฟเฟอร์: ปิดเสียงหรือเปิดใช้งานซับวูฟเฟอร์จาก เสียง › เซอร์ราวด์ › Audio Features โดยไม่ต้องลงลึกไปที่การตั้งค่าลำโพง แสดงเฉพาะบนเครื่องรับที่รายงานและรับค่านี้
  • ตัวฟื้นฟูสัญญาณเสียง: ตัวฟื้นฟูเสียงที่ถูกบีบอัดของเครื่องรับ - Restorer บน Denon, M-DAX บน Marantz - ใต้ เสียง › โทนเสียง คืนความมีชีวิตชีวาให้ไฟล์ MP3 และแหล่งสตรีมโดยไม่ต้องเข้าเมนูบนหน้าจอ
กำลังเล่น & HEOS

ดูและควบคุมสิ่งที่กำลังเล่น

เมื่อแหล่งสัญญาณที่ใช้งานอยู่ส่งข้อมูลเมทาดาตา การ์ดกำลังเล่นจะแสดงปกอัลบั้ม ข้อมูลแทร็ก / ศิลปิน / สถานี และปุ่มควบคุมการเล่น (เล่น / หยุดชั่วคราว / ถัดไป / ก่อนหน้า)

หากต้องการเรียกดูเพลง ทั้งสถานี คิว บริการสตรีมมิง และห้อง HEOS ให้แตะเปิด HEOSบนการ์ดกำลังเล่น AVR Maestro จะเปิดแอป HEOS อย่างเป็นทางการสำหรับการเรียกดู และเมื่อเริ่มเล่นที่นั่นแล้ว AVR Maestro จะกลับมาควบคุมการแสดงผลกำลังเล่น ปุ่มควบคุมการเล่น และวิดเจ็ต แหล่งสัญญาณอะนาล็อก ออปติคัล/โคแอกเซียล และ HDMI passthrough ไม่รายงานข้อมูลเมทาดาทา การ์ดจึงว่างอยู่สำหรับแหล่งเหล่านั้น ปุ่มรายการโปรดและทุกอย่างอื่นบนการ์ดอธิบายไว้ในคู่มือกำลังเล่นและ HEOS

คำถามที่พบบ่อยเกี่ยวกับหน้าจอหลัก

ปรับแต่งหน้าจอหลักได้ไหม
ได้ แตะ Customize Home แล้วลากเพื่อจัดลำดับ แตะวงกลมสีแดงเพื่อลบ Add เพื่อเพิ่มวิดเจ็ต Reset เพื่อกลับเป็นค่าเริ่มต้น และ Done เมื่อเสร็จ การ์ดจะหรี่ลงขณะแก้ไข คุณจึงไม่เผลอเปลี่ยนการตั้งค่า
เปลี่ยนชื่อโซนได้ไหม รวมถึงโซนหลัก
ได้ กดค้างที่ชื่อโซนบนหน้าจอหลัก ชื่อจะถูกเขียนลงในเครื่องรับเอง จึงแสดงในแอปของผู้ผลิตและไคลเอนต์อื่นทุกตัว และใช้ได้กับเครื่องรุ่นเก่าด้วย
สลับระหว่างเครื่องรับจากหน้าจอหลักได้หรือไม่
ได้ แตะชื่อเครื่องรับข้างๆ AVR Maestro ที่ด้านบนแล้วเลือกเครื่องรับอื่น หรือเลือกจัดการเครื่องรับเพื่อเพิ่มหรือจัดลำดับใหม่
แสดงสิ่งที่กำลังเล่นไหม
แสดง สำหรับแหล่งสัญญาณที่ส่งข้อมูลเมทาดาตา ได้แก่ ปกอัลบั้ม แทร็ก ศิลปิน สถานี และปุ่มควบคุมการเล่น แตะ Launch HEOS เพื่อเรียกดู เมื่อเริ่มเล่นแล้ว AVR Maestro จะกลับมาควบคุมการแสดงผลกำลังเล่นอีกครั้ง

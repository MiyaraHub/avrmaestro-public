หน้าจอหลัก

หน้าจอหลัก: ฐานบัญชาการของคุณ ในแบบของคุณ

การ์ดสถานะอุปกรณ์ปักหมุดอยู่ด้านบนเสมอ แสดงรุ่น การเชื่อมต่อ และสถานะเปิดปิดเครื่อง โดยมีตารางวิดเจ็ตที่ปรับแต่งได้อยู่ด้านล่าง เพิ่ม ลบ และจัดลำดับการ์ดเพื่อให้หน้าจอหลักแสดงสิ่งที่คุณสนใจจริง ๆ

ทำให้เป็นสไตล์คุณ

ปรับแต่งได้ในไม่กี่วินาที

แตะไอคอน Customize Home (ซ้ายบน) เพื่อเข้าสู่โหมดแก้ไข:

  • ลากการ์ดเพื่อจัดลำดับ
  • แตะวงกลมสีแดงเพื่อลบการ์ด
  • Add เปิดชีตวิดเจ็ตที่คุณยังไม่มี
  • Reset คืนค่าเริ่มต้น ส่วน Done ใช้ออกจากโหมดแก้ไข
การ์ดจะหรี่ลงขณะแก้ไข คุณจึงไม่เผลอเปลี่ยนการตั้งค่าของเครื่องรับ วิดเจ็ตจะแสดงก็ต่อเมื่อเครื่องรับของคุณมีฟีเจอร์นั้น
ตั้งชื่อห้องของคุณ

“ห้องนั่งเล่น” ไม่ใช่ “MAIN ZONE”

กดค้างที่ชื่อโซนบนหน้าจอหลักเพื่อเปลี่ยนชื่อโซนใดก็ได้ รวมถึงโซนหลัก ชื่อจะถูกเขียนลงในเครื่องรับเอง ไม่ใช่แค่ในแอป จึงแสดงในแอปของผู้ผลิตและไคลเอนต์อื่นทุกตัว และใช้ได้กับเครื่องรุ่นเก่าด้วย เปลี่ยนชื่อครั้งเดียว ตัวควบคุมทุกตัวในบ้านก็เรียกห้องนั้นตรงกัน

วิดเจ็ต

ทุกอย่างที่ปักหมุดได้

วิดเจ็ตทำอะไรได้
ระดับเสียงแถบเลื่อนพร้อมค่า dB ปิดเสียง และพรีเซ็ตระดับเสียงที่บันทึกไว้ 8 ค่า
แหล่งสัญญาณเปิดตัวเลือกอินพุต กดค้างที่ไทล์เพื่อจัดลำดับใหม่ ชื่อแหล่งสัญญาณที่เปลี่ยนไว้และไอคอนอินพุตแบบกำหนดเองที่คุณตั้งในตารางอินพุตของรีโมทจะแสดงที่นี่ด้วย
โหมดเสียงโหมดเซอร์ราวด์ปัจจุบัน แตะเพื่อเปิดตัวเลือกแบบจัดกลุ่ม
กำลังเล่นปกอัลบั้ม ข้อมูลแทร็ก และปุ่มควบคุมการเล่นสำหรับแหล่งสัญญาณ HEOS
โซนสถานะโซน 2 / โซน 3 แบบย่อ พร้อมตัวควบคุมด่วน รวมถึงช่อง Smart Select หรือ Quick Select ของโซนนั้น แตะช่องเพื่อเรียกใช้ กดค้างเพื่อบันทึกสถานะปัจจุบันของโซนลงในช่องนั้น
Smart Select / Quick Selectช่องหน่วยความจำของเครื่องรับเอง ตั้งชื่อตามที่เครื่องรับเรียก: Smart Select บน Marantz, Quick Select บน Denon ชื่อช่องที่เปลี่ยนไว้จะถูกบันทึกในเครื่องรับ ชื่อของคุณจึงแสดงในทุกแอป
พรีเซ็ตลำโพงตัวสลับ Preset 1 / 2 - แสดงเฉพาะบนเครื่องรับที่มีมากกว่าหนึ่งพรีเซ็ต
Audyssey / Diracสถานะการสอบเทียบในพริบตา พร้อมลิงก์ลัดเข้าสู่หน้าที่เกี่ยวข้อง
ระดับช่องสัญญาณ / ซับวูฟเฟอร์ภาพรวมระดับเสียงรายช่องสัญญาณและซับวูฟเฟอร์พร้อมปุ่มปรับทีละขั้น จำนวนซับวูฟเฟอร์เป็นไปตามการตั้งค่าเครื่องรับปัจจุบันของคุณ
ECO, Sleep, DRC, Restorer, Video, Room Size, LFEสวิตช์และตัวเลือกแบบแตะครั้งเดียว แต่ละรายการแสดงเฉพาะเมื่อเครื่องรองรับ
ตัวควบคุมเสียง

สวิตช์ด่วนในหน้าเสียง

  • Graphic EQ: เปิดหรือปิด Graphic EQ ของเครื่องรับจากเสียง ฟีเจอร์เสียง ใช้ได้เฉพาะเมื่อไม่มีทั้ง Dirac Live และ Audyssey ทำงานปรับแก้เสียงห้องอยู่ แอปทำตามกฎของเครื่องรับเอง
  • ซับวูฟเฟอร์: ปิดเสียงหรือเปิดใช้งานซับวูฟเฟอร์จากเสียง ฟีเจอร์เสียง โดยไม่ต้องลงไปในการตั้งค่าลำโพง แสดงเฉพาะบนเครื่องรับที่รายงานและรับคำสั่งนี้ได้
  • Audio Restorer: ตัวคืนคุณภาพเสียงบีบอัดของเครื่องรับ - Restorer บน Denon, M-DAX บน Marantz - เป็นสวิตช์ใต้เสียง โทนเสียง ถัดจาก DAC Filter พอดี คืนชีวิตให้ไฟล์ MP3 และแหล่งสตรีมมิงได้โดยไม่ต้องเข้าเมนูบนหน้าจอ
กำลังเล่น & HEOS

ดูและควบคุมสิ่งที่กำลังเล่น

เมื่อแหล่งสัญญาณที่ใช้งานอยู่ส่งข้อมูลเมทาดาตา การ์ดกำลังเล่นจะแสดงปกอัลบั้ม ข้อมูลแทร็ก / ศิลปิน / สถานี และปุ่มควบคุมการเล่น (เล่น / หยุดชั่วคราว / ถัดไป / ก่อนหน้า)

หากต้องการเรียกดูเพลง ไม่ว่าจะเป็นสถานี คิว บริการสตรีมมิง หรือห้อง HEOS ให้แตะ Launch HEOS บนการ์ดกำลังเล่น AVR Maestro จะเปิดแอป HEOS ทางการเพื่อเรียกดู และเมื่อเริ่มเล่นที่นั่นแล้ว AVR Maestro จะกลับมาควบคุมการแสดงผลกำลังเล่น ปุ่มควบคุมการเล่น และวิดเจ็ต แหล่งสัญญาณอะนาล็อก ออปติคัล/โคแอกเชียล และ HDMI พาสทรูไม่ส่งเมทาดาตา การ์ดจึงว่างเปล่าสำหรับแหล่งสัญญาณเหล่านั้น

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับหน้าจอหลัก

ปรับแต่งหน้าจอหลักได้ไหม
ได้ แตะ Customize Home แล้วลากเพื่อจัดลำดับ แตะวงกลมสีแดงเพื่อลบ Add เพื่อเพิ่มวิดเจ็ต Reset เพื่อกลับเป็นค่าเริ่มต้น และ Done เมื่อเสร็จ การ์ดจะหรี่ลงขณะแก้ไข คุณจึงไม่เผลอเปลี่ยนการตั้งค่า
เปลี่ยนชื่อโซนได้ไหม รวมถึงโซนหลัก
ได้ กดค้างที่ชื่อโซนบนหน้าจอหลัก ชื่อจะถูกเขียนลงในเครื่องรับเอง จึงแสดงในแอปของผู้ผลิตและไคลเอนต์อื่นทุกตัว และใช้ได้กับเครื่องรุ่นเก่าด้วย
แสดงสิ่งที่กำลังเล่นไหม
แสดง สำหรับแหล่งสัญญาณที่ส่งข้อมูลเมทาดาตา ได้แก่ ปกอัลบั้ม แทร็ก ศิลปิน สถานี และปุ่มควบคุมการเล่น แตะ Launch HEOS เพื่อเรียกดู เมื่อเริ่มเล่นแล้ว AVR Maestro จะกลับมาควบคุมการแสดงผลกำลังเล่นอีกครั้ง

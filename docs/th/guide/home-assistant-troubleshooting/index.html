เมื่อการเชื่อมโยงหรือสคริปต์ทำงานผิดปกติ

Home Assistant เมื่อใช้งานไม่ได้

ปัญหา Home Assistant ส่วนใหญ่มาจากสถานะการเชื่อมโยง entity ID ของเครื่องรับ หรือเครือข่ายระหว่างโทรศัพท์กับเซิร์ฟเวอร์ ให้เริ่มจากข้อความบนการ์ดการเชื่อมโยง แล้วไล่ตรวจลงไป

การ์ดการเชื่อมโยงบอกอะไรคุณ

การ์ดเหนือปุ่ม Sync แสดงสถานะของการเชื่อมโยง และปุ่มจะเปลี่ยนตามสถานะนั้น

  • เชื่อมโยงกับ Home Assistant แล้ว: การเรียกที่ผ่านการยืนยันตัวตนสำเร็จเมื่อครู่ ปุ่ม Sync ใช้งานได้
  • การเชื่อมโยง Home Assistant หมดอายุ: เซิร์ฟเวอร์ตอบกลับแต่ปฏิเสธโทเค็นที่บันทึกไว้ ปุ่ม Sync จะถูกปิดใช้งานจนกว่าคุณจะลงชื่อเข้าใช้อีกครั้ง
  • ไม่สามารถเชื่อมต่อกับ Home Assistant ได้: ติดต่อเซิร์ฟเวอร์ของคุณไม่ได้ และโทเค็นอาจยังใช้งานได้ดีอยู่ ปุ่ม Sync ยังคงใช้งานได้และไม่มีอะไรถูกเปลี่ยนแปลง
  • ยังไม่ได้เชื่อมโยงกับ Home Assistant: ยังไม่ได้บันทึกที่อยู่หรือโทเค็น เพิ่มที่อยู่ของคุณแล้วลงชื่อเข้าใช้
  • ยังไม่ได้ตรวจสอบการเชื่อมโยง Home Assistant: โหมดทดลองเปิดอยู่หรือระบบบ้านอัตโนมัติถูกล็อก จึงไม่มีอะไรถูกส่งไปยังบ้านของคุณ และยังไม่ได้ลองใช้โทเค็น
มีเพียงข้อแรกเท่านั้นที่ขึ้นว่าเชื่อมโยงแล้ว และเป็นเพราะมีบางอย่างผ่านการยืนยันตัวตน โทเค็นที่บันทึกไว้เฉยๆ ไม่นับเป็นการเชื่อมโยง

สคริปต์ไม่ทำงาน หรือขึ้น Entity Not Found

  • ติดตั้งอินทิเกรชัน Denon AVR อย่างเป็นทางการใน Home Assistant ที่การตั้งค่า, อุปกรณ์ & บริการ
  • ตรวจสอบว่า Receiver Media Player Entity ID ในการตั้งค่า AVR Maestro ตรงกับ entity ID ใน Home Assistant ทุกตัวอักษร
  • เพิกเฉยต่อเอนทิตีใดๆ ที่ขึ้นว่า unavailable หลังจากลบหรือสร้างฉากใหม่ สคริปต์ของฉากตั้งชื่อตามเวลาที่สร้างฉาก ดังนั้นดู ระบบบ้านอัตโนมัติ เพื่อดูว่า ID ของสคริปต์เปลี่ยนไปอย่างไรเพียงครั้งเดียว

ฉากใหม่หายไปจาก Home Assistant

ฉากจะซิงค์ในเบื้องหลังทุกครั้งที่คุณเพิ่ม แก้ไข หรือลบฉาก คุณจึงไม่ต้องกด Sync ทุกครั้ง หากฉากใดหายไป แสดงว่าโทรศัพท์เข้าถึงเซิร์ฟเวอร์ของคุณไม่ได้

  • ให้โทรศัพท์อยู่ในเครือข่าย Wi-Fi ภายในเดียวกับ Home Assistant
  • เปิดการตั้งค่าแล้วแตะ Sync Scenes หากล้มเหลว จะแสดงข้อผิดพลาดของเครือข่ายที่ตรงจริง

Failed login ในบันทึกของ Home Assistant

การพยายามที่ไม่สำเร็จหลายครั้ง หรือเบราว์เซอร์ที่ตัดการเชื่อมต่อก่อนการเชื่อมโยงเสร็จ จะทิ้งคำเตือนไว้ใน Home Assistant นี่เป็นเพียงประวัติ ไม่ใช่ข้อผิดพลาดในปัจจุบัน และคุณเพิกเฉยได้เมื่อการเชื่อมโยงใช้งานได้แล้ว

ปัญหาอื่นๆ ที่อาจเกิดขึ้น

  • ไทล์บนแดชบอร์ดไม่เคยสว่างขึ้น: ดูคู่มือแดชบอร์ด Home Assistant
  • เว็บฮุกไม่มาถึง: ดูระบบบ้านอัตโนมัติ
  • ยังแก้ไม่ได้ใช่ไหม ถามใน Discord หรือดูวิธีใช้

ปัญหา Home Assistant พร้อมคำตอบ

สคริปต์ของฉันทำงานแล้วแต่ขึ้น Entity Not Found หรือไม่มีอะไรเกิดขึ้น
ตรวจสอบว่าติดตั้งอินทิเกรชัน Denon AVR อย่างเป็นทางการใน Home Assistant แล้ว จากนั้นตรวจสอบว่า Receiver Media Player Entity ID ในการตั้งค่า AVR Maestro ตรงกับ entity ID ใน Home Assistant ทุกตัวอักษร เช่น media_player.living_room_receiver
ทำไมบันทึกของ Home Assistant จึงขึ้น Failed login
หากคุณพยายามเชื่อมโยงไม่สำเร็จหลายครั้ง หรือเบราว์เซอร์ตัดการเชื่อมต่อก่อนเสร็จสิ้น Home Assistant จะบันทึกคำเตือนไว้ เมื่อเชื่อมโยงสำเร็จแล้ว คุณสามารถเพิกเฉยต่อคำเตือนเก่านั้นได้อย่างปลอดภัย
ฉันสร้างฉากใหม่แต่ไม่ปรากฏใน Home Assistant
ตรวจสอบว่าโทรศัพท์อยู่ในเครือข่าย Wi-Fi ภายในเดียวกับเซิร์ฟเวอร์ Home Assistant เพราะการซิงค์เบื้องหลังจะล้มเหลวหากโทรศัพท์เข้าถึงเซิร์ฟเวอร์ไม่ได้ เปิดการตั้งค่าแล้วแตะ Sync Scenes เพื่อดูข้อผิดพลาดของเครือข่ายที่ตรงจริง หากมี
ต้องเปิดแอปไว้เพื่อให้สคริปต์ของฉันทำงานหรือไม่
ไม่ต้อง สคริปต์อยู่ใน Home Assistant จึงทำงานจากแดชบอร์ด ระบบอัตโนมัติ หรือผู้ช่วยเสียงของคุณได้ ขณะที่โทรศัพท์อยู่ในกระเป๋า แอปจะสร้างและอัปเดตสคริปต์ก็ต่อเมื่อคุณเปลี่ยนแปลงฉากเท่านั้น

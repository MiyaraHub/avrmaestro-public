Multi-Room

Multi-Room: กลุ่ม ตัวควบคุม คิว และเพลง

บนเครื่องรับที่รองรับ multi-room AVR Maestro จะแสดงลำโพงทุกตัว ให้คุณจัดกลุ่มและเลิกจัดกลุ่ม ตั้งระดับเสียงเดียวสำหรับทั้งกลุ่ม รวมถึงเรียกดู ค้นหา และจัดคิวเพลงให้กลุ่มนั้น คู่มือนี้อธิบายทุกส่วนของหน้าจอ

หน้าจอ

หน้าจอเดียวสำหรับลำโพงทุกตัว

  • เปิดหน้าจอนี้จากการ์ด Multi-Room บนหน้าแรก (แตะ เปิด) หรือจากเมนูนำทาง ชื่อหน้าจอคือ Multi-Room
  • การ์ดกลุ่มอยู่ด้านบน แต่ละการ์ดแสดงชื่อกลุ่ม เพลงที่กำลังเล่น ปุ่มก่อนหน้า / เล่น / ถัดไป ปุ่มปิดเสียง แถบเลื่อนระดับเสียงเดียวสำหรับทั้งกลุ่ม และสรุปคิว
  • ไม่อยู่ในกลุ่มแสดงลำโพงทุกตัวที่อยู่ตามลำพัง โดยแต่ละตัวมีปุ่ม ตัวเลือกอุปกรณ์
  • ขณะที่แอปกำลังค้นหาลำโพง คุณจะเห็น กำลังค้นหาลำโพง หากการเชื่อมต่อขาด แอปจะแสดง การเชื่อมต่อ Multi-Room ขาดหาย กำลังเชื่อมต่อใหม่ และแสดงกลุ่มล่าสุดที่ทราบจนกว่าจะเชื่อมต่อได้อีกครั้ง
ระดับเสียง

ระดับเสียงกลุ่มและระดับเสียงลำโพง

  • แถบเลื่อนขนาดใหญ่คือระดับเสียงกลุ่ม เมื่อเลื่อน สมาชิกทุกตัวจะเปลี่ยนไปพร้อมกัน
  • แตะ ระดับเสียงลำโพงเพื่อเปิดแถบเลื่อนหนึ่งแถบต่อสมาชิกหนึ่งตัว โดยแต่ละตัวมีปุ่มปิดเสียงของตัวเอง ใช้เพื่อปรับสมดุลระหว่างห้องที่เงียบกับห้องที่เสียงดัง
  • ลำโพงที่คุณปิดเสียงไว้จะแสดง เปิดเสียง และแสดงค่า 0%
กำลังเล่น

กำลังเล่น พร้อมปกอัลบั้ม

  • การ์ดแสดงปกอัลบั้ม ชื่อเพลง และศิลปินของเพลงที่กลุ่มกำลังเล่นแบบสด เมื่อไม่มีเพลงจะแสดง ไม่มีเพลงที่กำลังเล่น
  • ปุ่มก่อนหน้า เล่นหรือหยุดชั่วคราว และถัดไป ควบคุมทั้งกลุ่ม
กลุ่ม

สร้าง แก้ไข และเลิกจัดกลุ่ม

  • สร้างกลุ่ม: แตะปุ่มนี้ แล้วเลือกลำโพงตั้งแต่สองตัวขึ้นไป (แผ่นตัวเลือกจะแสดง เลือกลำโพงอย่างน้อยสองตัว จนกว่าคุณจะเลือกครบ) จากนั้นแตะ บันทึก เมื่อเลือกครบสองตัวแล้ว ทุกแถวจะแสดงชิป ตัวควบคุม ให้แตะตัวที่ต้องการให้เป็นตัวควบคุม หากไม่เลือก ตัวแรกที่คุณเลือกจะเป็นตัวควบคุม
  • ตัวควบคุม: ลำโพงที่กลุ่มเล่นเพลงจากตัวนั้น มีป้าย ตัวควบคุม บนชิปของตัวนั้น เครื่องรับจะแสดง เครื่องรับนี้ เมื่อตัวควบคุมคือเครื่องที่คุณเชื่อมต่ออยู่
  • แก้ไขกลุ่ม: เปลี่ยนสมาชิกหรือตัวควบคุมด้วยแผ่นตัวเลือกเดียวกัน ลำโพงที่อยู่ในกลุ่มอื่นแล้วจะแสดง อยู่ในกลุ่มอื่น
  • เลิกจัดกลุ่ม: ลบกลุ่มทันที และสมาชิกทุกตัวจะกลับไปอยู่ที่ ไม่อยู่ในกลุ่ม แอปจะยืนยันด้วย ลบกลุ่มแล้ว
  • เปลี่ยนชื่อกลุ่ม: แตะไอคอนดินสอบนการ์ด ชื่อจะเปลี่ยนในแอปนี้เท่านั้น
  • ลำโพงที่กำลังเล่นอยู่อาจหยุดขณะที่กลุ่มเปลี่ยนแปลง และแผ่นตัวเลือกจะเตือนคุณก่อน
ลากและวาง

กดค้างเพื่อเข้าร่วม ย้าย หรือนำออก

  • กดค้างที่ชิปลำโพง แล้วปล่อยลงที่กลุ่มเพื่อเข้าร่วม หรือปล่อยลงที่ห้องเพื่อย้าย
  • ปล่อยลงที่ ปล่อยที่นี่เพื่อนำออกจากกลุ่ม เพื่อนำลำโพงตัวนั้นออก
  • หากลำโพงกำลังเล่นอยู่ แอปจะถามก่อนสลับไปเล่นสิ่งที่กลุ่มเล่น: เข้าร่วมต่อไป
เพลง

บริการเพลง การเรียกดู และรายการโปรด

  • แตะ เพลงบนการ์ดกลุ่มเพื่อเปิดรายการบริการที่เครื่องรับตั้งค่าไว้ เช่น บริการสตรีมมิง วิทยุ เพลย์ลิสต์ ประวัติ และอินพุต AUX
  • แตะบริการเพื่อเรียกดู กลับจะขึ้นไปหนึ่งระดับ
  • บนรายการต่าง ๆ คุณสามารถ เล่นทันที เล่นถัดไป เพิ่มท้ายคิว หรือ แทนที่คิวและเล่น
  • รายการที่ยาวมากจะแสดง แสดง N รายการแรก
  • ปุ่มรูปหัวใจ เพิ่มเพลงที่กำลังเล่นลงในรายการโปรด จะบันทึกเพลงที่กำลังเล่น และปุ่มเดียวกันจะนำออกอีกครั้ง หากบริการไม่เก็บการเปลี่ยนแปลงไว้ แอปจะแจ้งให้ทราบ
  • บริการที่ต้องเข้าสู่ระบบจะแสดง บริการนี้ต้องให้คุณลงชื่อเข้าใช้ ให้ลงชื่อเข้าใช้หนึ่งครั้งในแอปของเครื่องรับเอง กรณี ไม่ได้ตั้งค่าบริการเพลงไว้ ก็ใช้วิธีเดียวกัน
ค้นหา

ค้นหาบริการเพลง

  • บริการที่ค้นหาได้จะแสดงช่องค้นหาและชิปหนึ่งอันต่อการค้นหาแต่ละประเภท เช่น ศิลปิน อัลบั้ม เพลง หรือ เพลย์ลิสต์ ชิปเหล่านี้มาจากตัวบริการเอง จึงแตกต่างกันไปตามแต่ละบริการ
  • เลือกชิป พิมพ์ แล้วกดค้นหา ล้างจะล้างช่องค้นหา
  • หากไม่พบ จะแสดง ไม่มีผลลัพธ์
  • หากบริการยังไม่ได้ลงชื่อเข้าใช้บนเครื่องรับ การค้นหาจะถูกปฏิเสธพร้อมข้อความ อุปกรณ์ไม่ยอมรับคำสั่งนั้น ลองอีกครั้ง
คิว

คิว

  • การ์ดกลุ่มสรุปคิว (3 ในคิว) และเพลงถัดไป แตะ คิวเพื่อเปิด
  • แผ่นตัวเลือกใช้ชื่อของตัวควบคุม แสดงรายการเพลงตามลำดับ และมีปุ่ม ล้างที่ทำให้คิวว่าง นอกจากนี้ยังมีการเล่นซ้ำ (ปิด ทั้งหมด หนึ่งเพลง) และสุ่มเพลง หากบริการไม่เก็บโหมดการเล่นไว้ แอปจะแจ้งให้ทราบ
  • คิวว่างจะแสดง ไม่มีอะไรในคิว หากลำโพงไม่ตอบสนอง จะแสดง อ่านคิวไม่ได้
ห้อง

จัดระเบียบ: ห้องและชื่ออุปกรณ์

  • แตะ จัดระเบียบ เพิ่มห้องจะสร้างห้อง และลำโพงแต่ละตัวสามารถย้ายเข้าห้องได้ด้วย ตัวเลือกอุปกรณ์ → ย้ายไปห้อง
  • เมื่อลำโพงอยู่ในห้องแล้ว จัดกลุ่มห้องนี้จะจัดกลุ่มลำโพงทั้งหมดในห้องพร้อมกัน
  • เปลี่ยนชื่ออุปกรณ์จะเปลี่ยนชื่อในแอปนี้เท่านั้น ใช้ชื่อเดิมจะคืนชื่อกลับ
  • บนเครื่องรับที่มีหลายโซน ทุกโซนใช้ลำโพงตัวเดียวของเครื่องรับร่วมกัน การจัดกลุ่มจึงมีผลกับทั้งเครื่องรับ
หน้าแรก

การ์ดบนหน้าแรกและวิดเจ็ตหน้าจอหลัก

  • การ์ด Multi-Room บนหน้าแรกแสดงลำโพงและกลุ่มเป็นชิป พร้อมปุ่ม จัดการที่เปิดหน้าจอนี้
  • ปักหมุดไปยังวิดเจ็ตหน้าจอหลักบนลำโพงหรือกลุ่มจะวางไว้บนวิดเจ็ต Multi-Room ซึ่งแสดงสิ่งที่กำลังเล่นพร้อมปุ่มควบคุมการเล่นและระดับเสียง แอปจะยืนยันด้วย <name> อยู่บนวิดเจ็ต Multi-Room
การแก้ไขปัญหา

เมื่อบางอย่างใช้งานไม่ได้

  • เข้าถึง Multi-Room บนเครื่องรับนี้ไม่ได้: ตรวจสอบว่าเครื่องรับเปิดอยู่และอยู่ในเครือข่ายเดียวกัน
  • ไม่พบลำโพง: เครื่องรับไม่แสดงลำโพงใดเลย ใช้ เชื่อมต่อด้วยที่อยู่ IP แล้วพิมพ์ที่อยู่ IPv4 ของลำโพงคุณจากเราเตอร์ ลืมลำโพงนี้จะนำลำโพงออกอีกครั้ง
  • จัดกลุ่มไม่ได้: การ์ดจะระบุเหตุผล เช่น เครื่องรับไม่อยู่ในรายการหรือไม่รองรับ multi-room
  • การเปลี่ยนแปลงกลุ่มล้มเหลว: แอปจะแจ้งว่าเกิดอะไรขึ้นจากสาเหตุเหล่านี้ รายการกลุ่มเปลี่ยนไป ลำโพงไม่ตอบสนองทันเวลา ไม่ได้ส่งการเปลี่ยนแปลงเพราะมีอีกรายการกำลังทำงานอยู่ ลำโพงไม่ว่าง หรือไม่ได้รับการยืนยันการเปลี่ยนแปลง ให้ตรวจสอบกลุ่มแล้วลองอีกครั้ง

Multi-Room ใน AVR Maestro คืออะไร
คือหน้าจอและการ์ดบนหน้าแรกที่แสดงลำโพงทุกตัวที่เครื่องรับมองเห็น กลุ่มที่ลำโพงเหล่านั้นอยู่ และเพลงที่กำลังเล่นในแต่ละกลุ่ม พร้อมแถบเลื่อนระดับเสียงหนึ่งแถบต่อหนึ่งกลุ่ม
ตัวควบคุมของกลุ่มทำหน้าที่อะไร
ตัวควบคุมคือลำโพงที่กลุ่มเล่นเพลงจากตัวนั้น ส่วนสมาชิกอื่นจะเล่นตาม คิวและเพลงที่กำลังเล่นของตัวควบคุมจึงเป็นของทั้งกลุ่ม
จะเลิกจัดกลุ่มลำโพงได้อย่างไร
เปิด Multi-Room หาการ์ดกลุ่ม แล้วแตะ เลิกจัดกลุ่ม สมาชิกทุกตัวจะกลับไปอยู่ที่ ไม่อยู่ในกลุ่ม หากต้องการนำลำโพงออกเพียงตัวเดียว ให้กดค้างที่ลำโพงนั้นแล้วปล่อยลงที่ ปล่อยที่นี่เพื่อนำออกจากกลุ่ม
ทำไมการค้นหาจึงแจ้งว่าอุปกรณ์ไม่ยอมรับ
บริการเพลงยังไม่ได้ลงชื่อเข้าใช้บนเครื่องรับ ให้ลงชื่อเข้าใช้หนึ่งครั้งในแอปของเครื่องรับเอง แล้วค้นหาอีกครั้งจาก AVR Maestro
เครื่องรับรุ่นใดใช้งานได้บ้าง
เครื่องรับที่รองรับ multi-room และปรากฏในรายการ Multi-Room เครื่องรับที่ไม่ปรากฏจะอยู่ในรายการ จัดกลุ่มไม่ได้ พร้อมระบุเหตุผล

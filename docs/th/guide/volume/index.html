การตั้งค่า › การควบคุมระดับเสียง

การควบคุมระดับเสียง: เพดานเสียง ระดับตอนเปิดเครื่อง และปิดเสียงที่ทำตามใจคุณ

สี่การตั้งค่าที่ร่วมกันกำหนดว่าเครื่องรับของคุณดังได้สูงสุดเท่าใด จะทำอย่างไรเมื่อเปิดเครื่อง และปิดเสียงแล้วลดลงมากแค่ไหน การตั้งค่าเหล่านี้อยู่บนเครื่องรับ จึงมีผลไม่ว่าคุณจะใช้แอป รีโมทจริง หรือแผงหน้าปัด

อยู่ตรงไหน

การตั้งค่า › การควบคุมระดับเสียง

เปิดการตั้งค่าแล้วเลื่อนไปที่การควบคุมระดับเสียง - "Volume limit, power-on level, and mute depth" ทุกอย่างในหน้านี้ถูกเขียนลงเครื่องรับโดยตรง จึงยังคงอยู่แม้ปิดแอป และมีผลกับทุกวิธีที่คุณใช้ควบคุม

ทีละอย่าง

แต่ละการตั้งค่าทำอะไร

สเกลระดับเสียง

วิธีแสดงระดับเสียง ทั้งบนหน้าจอและบนจอแสดงผลของเครื่องรับเอง 0 - 98 คือสเกลสัมพัทธ์ที่คนส่วนใหญ่คุ้นเคย -79.5 ถึง 18.0 dB คือสเกลสัมบูรณ์ ซึ่ง 0.0 dB คือระดับอ้างอิง หากคุณเคยเห็นรีวิวระบุ "-15 dB" แล้วสงสัยว่าตรงกับปุ่มของคุณตรงไหน นี่คือสวิตช์ที่ตอบคำถามนั้น

ขีดจำกัดระดับเสียง

เพดานเสียงที่เด็ดขาด เมื่อตั้งแล้วไม่มีอะไรเกินไปได้ ไม่ว่าจะเป็นแอป รีโมทจริง หรือปุ่มหมุนบนแผงหน้า เพราะขีดจำกัดอยู่บนเครื่องรับ ไม่ใช่ในแอป การใช้งานที่ชัดเจนคือป้องกันลำโพงหรือคนทั้งห้องจากการแตะพลาด และเป็นการตั้งค่าที่ควรใช้ก่อนส่งรีโมทให้แขกที่มาบ้าน ปิดคือยกเลิกเพดาน

ระดับเสียงตอนเปิดเครื่อง

ใช้ระดับเสียงล่าสุดเปิดไว้เป็นค่าเริ่มต้น: เครื่องรับจะตื่นขึ้นที่ระดับเดิมตอนที่คุณปิดเครื่อง หากปิดตัวเลือกนี้ คุณสามารถกำหนดระดับคงที่แทนได้ เพื่อให้การดูตอนดึกที่เสียงดังไม่กลายเป็นเรื่องไม่น่าพอใจในเช้าวันถัดไป

ระดับการปิดเสียง

ปิดเสียงจะลดระดับเสียงลงมากแค่ไหน เต็มคือเงียบสนิท -40 dB และ -20 dB คือลดทอนลงแทน ซึ่งเหมาะกว่าเมื่อคุณอยากคุยกันระหว่างดูหนังโดยไม่พลาดเนื้อเรื่อง

ที่อื่นในแอป

ตัวควบคุมที่คุณใช้ทุกวัน

  • แดชบอร์ดหน้าแรกมีระดับเสียงหลัก ปิดเสียง และเปิด/ปิดเครื่องของโซนหลัก
  • แท็บรีโมทมีปุ่มปรับระดับเสียงข้าง D-pad และปุ่มควบคุมการเล่น พร้อมแสดงระดับเสียงขณะปรับ คู่มือรีโมท →
  • ปุ่มบวกและลบระดับเสียงทุกปุ่ม - บนแดชบอร์ดหน้าแรก การ์ดโซน และแท็บรีโมท - แตะหนึ่งครั้งขยับหนึ่งขั้น และขยับต่อเนื่องเมื่อกดค้าง เหมือนรีโมทจริง ปล่อยแล้วหยุดภายในหนึ่งขั้น
  • ปุ่มปรับระดับเสียงของโทรศัพท์ ทั้งบน Android และ iPhone ควบคุมเครื่องรับขณะที่แอปอยู่เบื้องหน้า คุณจึงปรับได้โดยไม่ต้องมอง กดค้างก็ไล่ระดับได้เช่นกัน
  • แต่ละโซนมีระดับเสียงของตัวเอง อิสระจากโซนหลัก คู่มือโซน →
  • ฉากสามารถบันทึกระดับเสียงหลักได้ ดังนั้นเมื่อเรียกใช้ฉากก็จะตั้งระดับเสียงพร้อมกับทุกอย่างอื่น คู่มือฉาก →
  • การแสดงระดับเสียงบนหน้าจอของทีวีคุณสามารถย้ายตำแหน่งหรือปิดไปเลยก็ได้ คู่มือการแสดงผลบนหน้าจอ →
การเปลี่ยนระดับเสียงถูกควบคุมจังหวะอย่างตั้งใจ ไม่ได้ส่งทุกพิกเซลที่ขยับ ดังนั้นการกดปุ่มปรับค้างหรือลากแถบเลื่อนจะไล่ระดับอย่างนุ่มนวล แทนที่จะท่วมเครื่องรับด้วยคำสั่งที่มันต้องเข้าคิวแล้วทำช้า
คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับระดับเสียง

ขีดจำกัดระดับเสียงมีผลกับรีโมทจริงด้วยไหม
มีผล ขีดจำกัดเป็นการตั้งค่าของเครื่องรับ ไม่ใช่ของแอป จึงจำกัดทุกช่องทาง: แอป รีโมทที่แถมมา ปุ่มหมุนบนแผงหน้า และตัวควบคุมอื่นๆ ในเครือข่ายของคุณ
การตั้งค่าเหล่านี้ใช้กับโซน 2 และโซน 3 ด้วยไหม
การควบคุมระดับเสียงครอบคลุมโซนหลัก แต่ละโซนมีระดับเสียง การเปิดเครื่อง และอินพุตของตัวเองในแท็บโซน
ทำไมแอปแสดง 0 ถึง 98 ในขณะที่รีวิวระบุเป็นเดซิเบล
ทั้งสองเป็นมุมมองของปุ่มเดียวกัน เปลี่ยนสเกลระดับเสียงเป็น -79.5 ถึง 18.0 dB แล้วค่าที่แสดงจะตรงกับวิธีที่ระดับการปรับเทียบมักระบุกัน ซึ่ง 0.0 dB คือระดับอ้างอิง
ใช้ปุ่มปรับระดับเสียงของโทรศัพท์ได้ไหม
ได้ ทั้งบน Android และ iPhone ขณะที่ AVR Maestro อยู่เบื้องหน้า ปุ่มปรับระดับเสียงของอุปกรณ์จะควบคุมเครื่องรับโดยตรง กดหนึ่งครั้งขยับหนึ่งขั้น และกดค้างจะไล่ระดับขึ้นลง สวิตช์ในการตั้งค่า เสียง จะคืนปุ่มให้อุปกรณ์

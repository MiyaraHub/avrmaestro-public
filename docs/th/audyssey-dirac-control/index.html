Audyssey

ควบคุม Audyssey MultEQ ได้ครบ

ทุกอย่างในเมนู Audyssey ของเครื่องรับ รวมอยู่ในหน้าจอเดียวที่อ่านสถานะจริงแบบเรียลไทม์

  • MultEQ: สลับระหว่าง Reference, Bypass L+R, Flat และ Off
  • Dynamic EQ และ ค่าชดเชยระดับอ้างอิง สำหรับการฟังที่ระดับเสียงต่ำ
  • Dynamic Volume ช่วยปรับช่วงเสียงดังและเสียงเบาให้สมดุลกัน
  • LFC (Low Frequency Containment) พร้อมตัวปรับระดับการควบคุมทีละขั้น
  • ตัวควบคุมแต่ละรายการจะปรากฏเฉพาะเมื่อเครื่องรับของคุณรองรับจริงเท่านั้น
Dirac Live

สลับฟิลเตอร์ Dirac Live ตามชื่อ

หากเครื่องรับของคุณมีไลเซนส์ Dirac Live แอป AVR Maestro จะให้ความสำคัญกับฟิลเตอร์เหล่านั้นอย่างเต็มที่

  • เลือกสล็อตฟิลเตอร์ตามชื่อที่คุณตั้งไว้ในซอฟต์แวร์ Dirac Live ไม่ใช่หมายเลขสล็อตที่อ่านแล้วงง
  • สล็อตว่างจะถูกซ่อนไว้ คุณจึงเห็นเฉพาะฟิลเตอร์ที่ใช้งานจริง
  • สล็อตที่ใช้งานอยู่จะอัปเดตแบบเรียลไทม์ หากคุณเปลี่ยนจากตัวเครื่องรับหรือจากที่อื่น
  • สลับการปรับแต่งเสียงทั้งห้องได้ในแตะเดียว ไม่ว่าจะเป็นฟิลเตอร์สำหรับดูหนัง ฟังเพลง หรือใช้ตอนดึก

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับ Audyssey & Dirac Live

ฉันควบคุม Audyssey จากโทรศัพท์ได้หรือไม่
ได้ - บนเครื่องรับที่มี Audyssey แอป AVR Maestro จะอ่านค่าและสลับ MultEQ (Reference / Bypass L+R / Flat / Off), Dynamic EQ, Dynamic Volume, ค่าชดเชยระดับอ้างอิง และ LFC ได้ในแอปโดยตรง
AVR Maestro สลับฟิลเตอร์ Dirac Live ได้หรือไม่
ได้ หากเครื่องรับมีไลเซนส์ Dirac Live แอปจะแสดงรายการสล็อตฟิลเตอร์ของคุณตามชื่อ และสลับสล็อตที่ใช้งานได้ในแตะเดียว สล็อตว่างจะถูกซ่อนไว้ และสล็อตที่ใช้งานอยู่จะอัปเดตแบบเรียลไทม์
Audyssey กับ Dirac Live ต่างกันอย่างไร
ทั้งคู่ช่วยปรับเสียงให้เหมาะกับห้อง Audyssey MultEQ มาพร้อมกับเครื่องรับ Denon และ Marantz ส่วนใหญ่ และปรับจูนด้วยแอปบนโทรศัพท์ ส่วน Dirac Live เป็นไลเซนส์เสริมแบบเสียเงินที่ผู้ที่หลงใหลในเสียงจำนวนมากชื่นชอบ และปรับเทียบจากคอมพิวเตอร์ ทั้งสองระบบใช้พร้อมกันไม่ได้ในแต่ละชุดตั้งค่าลำโพงบนเครื่องรับเหล่านี้ และ AVR Maestro จะควบคุมระบบที่ชุดตั้งค่าที่คุณใช้อยู่เลือกใช้
ใช้ทั้งสองอย่างพร้อมกันได้หรือไม่
ไม่ได้ - บน Denon และ Marantz ทั้งสองระบบใช้พร้อมกันไม่ได้ และผูกอยู่กับชุดตั้งค่าลำโพง AVR Maestro ตรวจพบข้อนี้ในแต่ละชุดตั้งค่า คุณจึงเปลี่ยนระบบปรับเทียบที่ใช้งานได้ด้วยการสลับชุดตั้งค่าลำโพง

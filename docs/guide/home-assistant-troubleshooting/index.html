When a link or a script misbehaves

Home Assistant, when it does not work

Most Home Assistant problems come down to the link state, the receiver entity ID or the network between your phone and your server. Start with what the link card says, then work down.

What the link card is telling you

The card above the Sync button shows the state of the link, and the button follows it.

  • Linked to Home Assistant: an authenticated call succeeded just now. The Sync button is available.
  • Home Assistant link has expired: your server answered and refused the saved token. The Sync button is disabled until you sign in again.
  • Cannot reach Home Assistant: your server could not be reached, and the token may be perfectly good. The Sync button stays available and nothing is changed.
  • Not linked to Home Assistant: no address or no token is saved yet. Add your address and sign in.
  • Home Assistant link not checked: Demo mode is on or Home Automation is locked, so nothing was sent to your home and the token has not been tried.
Only the first one says Linked, and only because something authenticated. A saved token on its own never counts as a link.

A script does nothing, or says Entity Not Found

  • Install the official Denon AVR integration in Home Assistant under Settings, Devices & Services.
  • Make sure the Receiver Media Player Entity ID in AVR Maestro Settings matches the entity ID in Home Assistant exactly.
  • Ignore any entity that says unavailable after a scene was deleted or recreated. Scene scripts are named after when the scene was created, so see Home Automation for how script IDs change once.

A new scene is missing in Home Assistant

Scenes sync in the background whenever you add, edit or delete one, so you do not need to press Sync each time. If one is missing, the phone could not reach your server.

  • Put your phone on the same local Wi-Fi network as Home Assistant.
  • Open Settings and tap Sync Scenes. If it fails, it shows the exact network error.

Failed login in your Home Assistant log

Several failed attempts, or a browser that dropped the connection before linking finished, leave a warning in Home Assistant. It is history, not a current fault, and you can ignore it once the link works.

Other things that go wrong

  • A dashboard tile never lights up: see the Home Assistant dashboard guide.
  • A webhook does not arrive: see Home Automation.
  • Still stuck? Ask in the Discord or see Help.
Common questions

Home Assistant problems, answered

My script ran but it shows Entity Not Found, or nothing happens.
Make sure the official Denon AVR integration is installed in Home Assistant. Then check that the Receiver Media Player Entity ID in AVR Maestro Settings matches the entity ID in Home Assistant exactly, for example media_player.living_room_receiver.
Why does my Home Assistant log say Failed login?
If you had several failed attempts while linking, or your browser dropped the connection before it finished, Home Assistant records a warning. Once a link has succeeded you can safely ignore that old warning.
I created a new scene and it is not appearing in Home Assistant.
Check that your phone is on the same local Wi-Fi network as your Home Assistant server, because background sync fails when the phone cannot reach it. Open Settings and tap Sync Scenes to see the exact network error if there is one.
Does the app need to be open for my scripts to run?
No. The scripts live in Home Assistant, so they run from your dashboard, automations or voice assistants while the phone is in your pocket. The app only builds and updates them when you change a scene.

Backup & Restore: your whole setup, in one file

Renaming every input, picking artwork for each one, ordering your sources and building a set of Scenes is real work. It should survive a new phone, and it does: one export, one import, and the new device looks exactly like the old one.

Export

Save to device, or share it straight across

  1. Open Settings and scroll to Backup & About.
  2. Tap Backup & Restore.
  3. Under Export, tap Save to device to pick a folder for the file, or Share to send it through your share sheet straight to the other phone, a cloud drive or a message to yourself.

The backup is a single .zip file named like avr-maestro-backup- followed by the date and time. Inside are your settings and the images you picked for custom icons. Nothing in it is locked to the device it came from.

Set up Home Automation again on the new device; your existing Scene scripts keep their ids, so automations that point at them keep working. Input names you renamed are stored on the receiver itself, so they show up as soon as the new device connects.
Import

Restoring on the new phone

Before you restore: if AVR Maestro is open on another phone or tablet connected to the same receiver, close it there first. Two devices talking to the same receiver at the moment of a restore can cause a connection conflict that locks up the receiver's firmware. The app warns you about this too.
  1. Install AVR Maestro on the new device and make sure it is on the same network as your receiver.
  2. Open Settings › Backup & Restore.
  3. Under Import, tap Import settings from file and pick the backup (.zip, or a .json file from an older version of the app).
  4. Check the summary in Replace all settings?: how many entries it holds, the app version and when it was exported. Tap Replace.
  5. When you see Backup restored, tap Got it, then force-close AVR Maestro and open it again so every screen loads the restored settings.
Import replaces, it does not merge. Whatever is on that device is erased and replaced with the contents of the backup, and this cannot be undone. If the current setup is worth anything to you, export it first.
Worth knowing

A backup is the app, not the receiver

Your calibration, Speaker Presets, levels, distances, crossovers and Dirac filters live on the receiver. They are not in the backup, and importing one cannot disturb them. That cuts both ways: a backup will not restore a receiver you have factory-reset, and it does not need to - reconnecting the app to that receiver picks its settings back up from the receiver itself.

It is also a reasonable thing to take before a big reorganization. Export, rearrange your inputs and rebuild your Scenes freely, and if you preferred it the old way the file is right there.

Common questions

Backup FAQ

Can I move a backup between Android and iPhone?
Yes. The backup is a .zip file that is not tied to the device that wrote it. Export from one, get the file onto the other, and import.
Will importing overwrite my receiver's calibration?
No. A backup contains app settings only. Everything the receiver stores - calibration, presets, levels, distances, Dirac filters - is on the receiver and is untouched.
Do my Scenes come across?
Yes, with the settings each Scene holds and its custom icon. See the Scenes guide.
Why should I close the app on my other devices before restoring?
If another phone or tablet has AVR Maestro open and connected to the same receiver, two devices can talk to the receiver at once during the restore. That can cause a connection conflict that locks up the receiver's firmware. Close the app on the other device, restore, then force-close and reopen AVR Maestro on this one.
Where does Save to device put the file?
Wherever you choose in your system's file picker. Share is the quicker route if the file is only passing through on its way to another phone.

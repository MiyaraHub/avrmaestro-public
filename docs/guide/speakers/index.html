Speaker setup & presets

A dedicated Speakers workshop

Speaker presets, layout, distances, levels, crossovers, subwoofer and bass management: the full setup suite, read live from your Denon or Marantz receiver, with each screen following the active Speaker Preset.

Every setup screen, on your phone

Open the Speakers tab at the bottom of the screen. The pages run across the top in this order; tap a name or swipe left and right to move between them.

  • Preset: switch between Speaker Preset 1 and 2. Each stores its own layout, distances, levels, crossovers and calibration, and every other Speakers page follows the one that is active. A model with a single speaker configuration shows Speaker Preset unavailable instead of a switch.
  • Speaker Layout: Amp Assign and the per-speaker configuration. On the chassis that offer it, Front Speaker sets which front terminals the receiver drives (A, B or A+B); where the receiver has greyed it out, the app says it is locked rather than pretending the change will take.
  • Distances: per-speaker distance from your seat, in the receiver's units (m or ft).
  • Levels: per-speaker trim level stored on the preset.
  • Crossovers: the frequency below which bass is sent to the subwoofer. Only "small" speakers appear here; 0 Hz means Full Range. On receivers that report it, you can choose All (one shared value) or Individual.
  • Subwoofer: Subwoofer Output, LFE or LFE + Main, stored per Speaker Preset. This page only appears when your receiver has a subwoofer set up.
  • Bass: LPF for LFE (the low-pass cutoff for the LFE channel) and LFE Distribution (route the LFE .1 channel to full-range speakers, only offered when the receiver allows it).
Changing Amp Assign asks first: it reconfigures every speaker and resets the layout to the default for the new mode, so settings such as Height and Surround Back are lost. When Audyssey is calibrated, the same prompt warns that the change also turns off Audyssey (MultEQ XT32, Dynamic EQ, Dynamic Volume), and the page reminds you that changing any speaker layout setting removes a Dirac Live filter.
Older receivers

The SR7015 family and other receivers with the earlier setup menu

Some older receivers (the Marantz SR7015 family, for example) use an earlier version of the setup menu. AVR Maestro recognises it from the receiver's own menu and adapts the pages:

  • Speaker Layout shows Amp Assign (Floor, Height / Dolby speakers, Height layout) and every Speaker Config row, and all of them can be changed from the app.
  • Bass is editable: the LFE low-pass cutoff and the subwoofer mode (LFE or LFE + Main). The LFE Distribution block is hidden because these receivers do not have it.
  • Subwoofer says On this firmware, Subwoofer Output is set on the Bass tab. Use the Bass page instead.
  • Crossovers can switch between All and Individual, and only rows the receiver allows are editable.
If the receiver is slow to answer, the Layout page offers Retry; if its setup menu is locked, it shows the lock card. Only a receiver that refuses both reads is told Not available on this firmware, with an Open in Web Control button that opens the receiver's own web page for that edit. You can hide a page you cannot use under Settings › Customize Tabs.
Live view

See what is actually playing, channel by channel

The Speaker Grid shows what the incoming signal carries on the left and what your receiver is actually driving on the right. A stereo track shows two input channels beside every output the upmix is feeding, so you can see the upmix doing its work.

  • The receiver names its own speakers. Every label comes from the receiver, so a chassis with speakers this app has never heard of still draws them in the right places.
  • Three states, not two: playing, connected but silent, and absent. A speaker your receiver says is not in this signal is not drawn at all.
  • Where to find it: add the Speaker Grid card to the Home tab, or look on the Remote tab's main page.
Older receivers (the X4500H and SR7015 families) answer the grid request with nothing, so the grid stays hidden there and the Speaker Grid card is not offered.
Smart about Dirac

It won't let you push edits the receiver would reject

The pages above are fully editable on a standard Speaker Preset. But when a Dirac Live filter is active on a preset, Dirac owns the layout, distances, crossovers, subwoofer output and bass management, so instead of letting you make changes the receiver would silently ignore, AVR Maestro shows a clear lock and tells you why. Switch to a non-Dirac preset to edit them.

Common questions

Speaker setup FAQ

Can I set distances and levels from the app?
Yes. Amp assign and layout, per-speaker distances, channel levels, crossovers and subwoofer settings are all read live and follow the active Speaker Preset.
Why are some speaker screens locked?
When a Dirac Live filter is active on the preset, Dirac owns the layout, distances and crossovers. The app shows a lock instead of letting you push edits the receiver would reject. Switch to a non-Dirac preset to edit them. More on the Audyssey & Dirac guide.
What are Speaker Presets?
Preset 1 and 2 each store their own layout, distances, levels, crossovers and calibration. Switch between them on the Preset page; every Speakers page follows the active preset. A model with a single speaker configuration shows Speaker Preset unavailable instead.
My SR7015 says Subwoofer Output is set on the Bass tab. Is that right?
Yes. On that firmware the subwoofer mode (LFE or LFE + Main) lives with the LFE low-pass cutoff, so the app sends you to the Bass page, where both can be changed. The Speaker Layout page on these receivers is fully editable too, including Amp Assign.
Can I send the LFE channel to my front speakers without a subwoofer?
Yes, on receivers that support it. When your main speakers are set to Full Range in Crossovers and the receiver isn't routing the LFE to a subwoofer, the Bass page's LFE Distribution sends the LFE (.1) channel to those speakers with a per-speaker level. AVR Maestro only offers it when the receiver allows it: if the speakers aren't Full Range, or a subwoofer is set to take the LFE, the receiver locks the setting and the app shows why. The LPF for LFE control on the same page sets the low-pass cutoff for the LFE channel.
